Page Object Model (POM) for the left navigation sidebar present on all authenticated pages of the OpenFrame application, providing locators, state queries, and navigation actions via Playwright.

## Key Components

| Member | Type | Description |
|---|---|---|
| `NavigationSidebar(Page)` | Constructor | Initializes the POM with a Playwright `Page` instance |
| `sidebar()` | Locator | Root `<aside>` element selector |
| `*NavItem()` | Locators | Locators for all 11 nav items (primary + secondary) |
| `isExpanded()` / `isCollapsed()` | State query | Detects sidebar mode via "Hide Menu" button visibility |
| `isNavItemActive(Locator)` | State query | Checks `aria-current="page"` on a given nav button |
| `getActiveNavItemLabel()` | State query | Returns the `aria-label` of the currently active item |
| `goTo*()` | Navigation actions | Clicks a nav item and waits for the expected URL fragment |
| `goToDevices()` | Navigation action | Returns a `DevicesPage` after waiting for full page load |
| `goToMonitoring()` | Navigation action | Returns a `MonitoringPage` after waiting for summary card |
| `collapse()` | Sidebar control | Collapses to icon-only mode; no-op if already collapsed |

## Usage Example

```java
// Obtain a NavigationSidebar from an authenticated page
NavigationSidebar nav = new NavigationSidebar(page);

// Navigate to Devices and interact with the returned page object
DevicesPage devicesPage = nav.goToDevices();

// Assert the correct item is active
assert nav.isNavItemActive(nav.devicesNavItem());
assert "Devices".equals(nav.getActiveNavItemLabel());

// Collapse the sidebar for viewport-sensitive tests
nav.collapse();
assert nav.isCollapsed();

// Navigate to Monitoring and get a typed page object
MonitoringPage monitoring = nav.goToMonitoring();
```

## Notes

- **Collapsed state** (56 px): buttons expose only icons; labels are carried as `title`/`aria-label` attributes.
- **Expanded state** (224 px): buttons include a `<span class="text-h4">` label child; "Hide Menu" button is visible.
- `goToDevices()` and `goToMonitoring()` return typed page objects and apply a **120 s** readiness timeout; all other `goTo*()` methods use a **10 s** URL-settle timeout.
- Selectors are anchored to `aside[aria-label='Main navigation sidebar']` for isolation from other page elements.
