Page Object for the authentication method picker screen (Step 2 of the OpenFrame login flow), providing locators and actions for the SSO, Google, and Microsoft provider buttons rendered inline at `/auth/login`.

## Key Components

| Member | Type | Description |
|---|---|---|
| `URL` | `String` constant | Target URL: `https://openframe.build/auth/login` |
| `ssoButton()` | `Locator` | Selects the "OpenFrame SSO" provider button |
| `googleButton()` | `Locator` | Selects the "Continue with Google" provider button |
| `microsoftButton()` | `Locator` | Selects the "Continue with Microsoft" provider button |
| `clickSignInWithOpenFrameSso()` | `SsoLoginPage` | Clicks the SSO button and waits for navigation to `/sas/login`, returning the next page object |

**Selector strategy note:** Buttons are matched via `:has-text()` on the ancestor `<button>` element rather than `:text-is()`, because the visible label lives inside a child `<span>` next to a provider icon and the buttons expose no accessible name for `getByRole()`.

## Usage Example

```java
// Assumes emailPage.submitEmail() has already been called
AuthMethodPage authMethodPage = new AuthMethodPage(page);

// Assert provider options are visible
assertThat(authMethodPage.ssoButton()).isVisible();
assertThat(authMethodPage.googleButton()).isVisible();
assertThat(authMethodPage.microsoftButton()).isVisible();

// Proceed with OpenFrame SSO — navigates to /sas/login
SsoLoginPage ssoLoginPage = authMethodPage.clickSignInWithOpenFrameSso();
```
