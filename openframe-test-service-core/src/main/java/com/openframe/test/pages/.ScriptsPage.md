Page Object Model class for the OpenFrame Scripts section, providing Playwright locators and navigation helpers for both the Scripts List and Scripts Schedules tabs at `/scripts/`.

## Key Components

### Constants
- `URL` — base scripts page URL
- `URL_SCHEDULES` — direct URL to the Schedules tab

### Navigation Methods
- `navigate()` — loads the Scripts List tab and waits for network idle
- `navigateToSchedules()` — loads the Schedules tab and waits for network idle

### Tab Bar
- `scriptsListTab()` / `schedulesTab()` — locators for tab buttons
- `getActiveTabLabel()` — returns the visible label of the currently active tab
- `clickScriptsListTab()` / `clickSchedulesTab()` — clicks tab and awaits URL change

### Scripts List
- `scriptRows()` — all script card rows
- `scriptRowByName(String name)` — scoped row locator by visible name
- `rowMenuButton(String scriptName)` — ⋯ context menu trigger for a named row
- `rowRunButton(String scriptName)` — ▷ Run button for a named row
- `searchInput()`, `openFiltersButton()`, `addScriptButton()`, `resultsCount()`

### Context Menu
- `contextMenu()`, `ctxEditScript()`, `ctxScriptDetails()`

### Filter Panel
- `filterPanel()`, `filterApplyButton()`, `filterResetButton()`
- Shell type checkboxes: `filterCmdCheckbox()`, `filterPowershellCheckbox()`, `filterPythonCheckbox()`, `filterShellCheckbox()`
- OS checkboxes: `filterMacOsCheckbox()`, `filterLinuxCheckbox()`, `filterWindowsCheckbox()`
- Category checkboxes: `filterCustomCheckbox()`, `filterDeprecatedCheckbox()`, `filterOpenFrameCheckbox()`

### Schedules Tab
- `scheduleRows()`, `scheduleRowByName(String name)`, `scheduleEditButton(String scheduleName)`
- `addScheduleButton()`, `searchScheduleInput()`

### Helpers
- `getResultsCount()` — parses the integer from "Showing N results"

## Usage Example

```java
ScriptsPage scripts = new ScriptsPage(page);

// Navigate and verify active tab
scripts.navigate();
assert scripts.getActiveTabLabel().equals("Scripts List");

// Search and check results
scripts.searchInput().fill("Restart Service");
int count = scripts.getResultsCount();

// Open context menu for a named script
scripts.rowMenuButton("Restart Service").click();
scripts.ctxScriptDetails().click();

// Apply a filter
scripts.openFiltersButton().click();
scripts.filterWindowsCheckbox().click();
scripts.filterApplyButton().click();

// Switch to schedules tab
scripts.clickSchedulesTab();
scripts.scheduleEditButton("Weekly Cleanup").click();
```
