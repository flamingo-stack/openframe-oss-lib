Page Object Model implementation for the Device Details page (`/devices/details/{id}/`), providing typed accessors and actions for device header info, metadata fields, action bar controls, tab navigation, and agent status using Microsoft Playwright.

## Key Components

| Member | Type | Description |
|---|---|---|
| `getDeviceName()` | Method | Returns the device name from the main `h1` heading |
| `getDeviceStatus()` | Method | Returns the connectivity status badge text (`ONLINE`, `OFFLINE`, `ARCHIVED`) |
| `getLastUpdatedText()` | Method | Returns the "Updated X seconds" timestamp; returns empty string if absent |
| `getInfoField(String label)` | Method | Looks up a metadata field value by its label (e.g. `"Hostname"`, `"UUID"`) |
| `clickBackToDevices()` | Method | Clicks the Back button in the page header |
| `openRemoteDesktop()` | Method | Clicks Remote Control and returns a `RemoteDesktopPage` |
| `openFileManager()` | Method | Opens the ⋯ menu → Manage Files and returns a `FileManagerPage` |
| `openRemoteShellCmd()` | Method | Opens Remote Shell dropdown and selects CMD |
| `openRemoteShellPowerShell()` | Method | Opens Remote Shell dropdown, selects PowerShell, returns `RemoteShellPage` |
| `clickTab(String tabName)` | Method | Activates a tab by name (`"Hardware"`, `"Network"`, `"Agents"`, etc.) |
| `isTabActive(String tabName)` | Method | Returns `true` if the named tab carries the active gradient class |
| `getAgentStatus(String agentName)` | Method | Returns agent status pill text (`"ONLINE"`, `"OFFLINE"`) by agent card name |
| `clickRunScript()` | Method | Opens ⋯ menu and clicks Run Script |
| `clickArchiveDevice()` | Method | Opens ⋯ menu and clicks Archive Device |
| `clickDeleteDevice()` | Method | Opens ⋯ menu and clicks Delete Device |
| `isLoaded()` | Method | Returns `true` when both device name and status are non-empty |

## Usage Example

```java
// Navigate to a device detail page
page.navigate("/devices/details/abc123/");
DeviceDetailsPage detailsPage = new DeviceDetailsPage(page);

// Assert the page is loaded
assertTrue(detailsPage.isLoaded());

// Read header information
String name   = detailsPage.getDeviceName();   // e.g. "VM115982"
String status = detailsPage.getDeviceStatus(); // e.g. "ONLINE"

// Read metadata from the info card
String hostname = detailsPage.getInfoField("Hostname"); // e.g. "vm115982"
String serial   = detailsPage.getInfoField("Serial Number");

// Navigate to the Agents tab and check an agent
detailsPage.clickTab("Agents");
String meshStatus = detailsPage.getAgentStatus("MeshCentral"); // e.g. "ONLINE"

// Open Remote Shell (PowerShell)
RemoteShellPage shell = detailsPage.openRemoteShellPowerShell();

// Open File Manager via more-actions menu
FileManagerPage files = detailsPage.openFileManager();

// Check tab active state
boolean isHardwareActive = detailsPage.isTabActive("Hardware");
```
