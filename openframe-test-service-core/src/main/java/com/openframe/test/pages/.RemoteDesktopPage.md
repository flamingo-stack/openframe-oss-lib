Page Object representing a Remote Desktop session in the OpenFrame test framework, providing locators and state-inspection helpers for the noVNC/MeshCentral canvas-based stream.

## Key Components

| Member | Type | Description |
|---|---|---|
| `remoteDesktopCanvas()` | Locator | Targets the noVNC `<canvas>` element via `tabindex='0'` |
| `deviceNameHeading()` | Locator | Device name `<h1>` in the remote desktop header |
| `deviceSubtitle()` | Locator | Subtitle `<p>` (e.g. `"Desktop • Default"`) below the heading |
| `actionsButton()` | Locator | Radix UI `Actions` dropdown trigger (`aria-haspopup="menu"`) |
| `settingsButton()` | Locator | Plain `Settings` submit button (no `aria-haspopup`) |
| `backToDeviceButton()` | Locator | Navigation button returning to Device Details |
| `getCanvasWidth()` / `getCanvasHeight()` | `int` | DOM `width`/`height` attributes of the canvas (expected `1024×768`) |
| `waitForCanvasVisible(int)` | `RemoteDesktopPage` | Blocks until canvas state is `VISIBLE`, fluent return |
| `waitForDesktop()` | `boolean` | Blocks until `canvasIsNotBlank()` is truthy |
| `canvasIsNotBlank()` | `boolean` | Evaluates center pixel RGB via JavaScript; returns `true` if any channel is non-zero |
| `goBackToDevice()` | `DeviceDetailsPage` | Clicks back button and waits for URL to leave `/remote-desktop/` |

## Usage Example

```java
// Instantiate after navigation to the remote desktop URL
RemoteDesktopPage rdp = new RemoteDesktopPage(page);

// Wait for canvas to appear and the stream to render content
rdp.waitForCanvasVisible(15_000);
rdp.waitForDesktop();

// Assert session metadata
assertThat(rdp.getDeviceName()).isEqualTo("WORKSTATION-01");
assertThat(rdp.getDeviceSubtitle()).isEqualTo("Desktop • Default");

// Assert canvas has expected dimensions
assertThat(rdp.getCanvasWidth()).isEqualTo(1024);
assertThat(rdp.getCanvasHeight()).isEqualTo(768);

// Navigate back to Device Details
DeviceDetailsPage details = rdp.goBackToDevice();
```

## Notes

- **Canvas blank-check** uses `page.evaluate()` to sample the center pixel — a fully black canvas (`0,0,0`) is treated as a non-started stream.
- **Session readiness** requires all four signals: URL contains `/remote-desktop/`, canvas is visible with non-zero dimensions, header elements are present, and Actions/Settings controls are rendered.
