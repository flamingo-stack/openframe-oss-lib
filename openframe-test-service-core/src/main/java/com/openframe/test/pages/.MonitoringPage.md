Playwright Page Object Model implementation for the OpenFrame Monitoring page (`/monitoring/`), providing locator definitions and fluent action/assertion helpers for both the **Policies** and **Queries** tabs.

## Key Components

### URL Constants
| Constant | Value |
|---|---|
| `BASE_URL` | `/monitoring` |
| `POLICIES_URL` | `/monitoring` |
| `QUERIES_URL` | `/monitoring?tab=queries` |

### Locator Groups
- **Tab navigation** — `tabPolicies`, `tabQueries`
- **Policies header** — `policiesHeading`, `addPolicyButtonText`, `addPolicyButtonIcon`, `searchPoliciesInput`
- **Metric cards** — `totalPoliciesCard/Value`, `complianceRateCard/Ratio/Percent`, `failedPoliciesCard/Value`, `updatedCard/Timestamp`
- **Policy list** — `resultsCountLabel`, `policyRows` (scoped to `div[class*='h-[68px]']`)
- **Queries tab** — `queriesHeading`, `addQueryButtonText/Icon`, `searchQueriesInput`, `queriesEmptyState`

### Key Methods
| Method | Description |
|---|---|
| `navigate()` / `navigateToPoliciesTab()` / `navigateToQueriesTab()` | Direct URL navigation |
| `clickPoliciesTab()` / `clickQueriesTab()` | Tab switching via click |
| `clickAddPolicy()` / `clickAddQuery()` | Open creation flows |
| `searchPolicies(String)` / `searchQueries(String)` | Fill search inputs |
| `clickMoreActionsForPolicy(int)` | Open row context menu by 0-based index |
| `getPolicyStatusByName(String)` | Returns status badge text for a named policy row |
| `getTotalPoliciesCount()` / `getFailedPoliciesCount()` | Parse metric card values as integers |
| `getComplianceRateRatio()` / `getComplianceRatePercent()` | Return compliance strings (e.g. `"1/1"`, `"(100%)"`) |

## Usage Example

```java
MonitoringPage monitoring = new MonitoringPage(page);

// Navigate and assert heading
monitoring.navigate();
assert monitoring.getPoliciesHeadingText().contains("Policies");

// Check metric cards
int total = monitoring.getTotalPoliciesCount();    // e.g. 3
int failed = monitoring.getFailedPoliciesCount();  // e.g. 1
String ratio = monitoring.getComplianceRateRatio(); // e.g. "2/3"

// Find a specific policy's status
String status = monitoring.getPolicyStatusByName("Disk Usage Policy");
// → "Compliant" or "Non-Compliant"

// Switch to Queries tab
monitoring.clickQueriesTab();
monitoring.searchQueries("endpoint");

// Navigate directly to Queries via URL
monitoring.navigateToQueriesTab();
```

## Notes
- All action methods return `this` for method chaining (fluent API).
- `policyRows` targets `div[class*='h-[68px]']`; column index mapping is `[0] Name | [1] Severity | [2] Status | [3] Actions | [4] Link`.
- Both text-label and icon-only button locators are defined to support responsive layout testing.
