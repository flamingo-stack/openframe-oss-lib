Page Object Model class for the Devices list page (`/devices/`), providing structured locators and helper methods for interacting with device listing UI elements in Playwright-based end-to-end tests.

## Key Components

**Locator Methods**
- `pageHeading()` — targets the `<h1>` page title
- `tableViewButton()` / `gridViewButton()` — view toggle controls
- `addDeviceButton()` — visible "Add Device" submit button
- `searchInput()` — search bar with placeholder `"Search for Devices"`
- `openFiltersButton()` — opens the "Sort and Filter" modal
- `resultsCount()` — span matching `"N results"` pattern
- `deviceRows()` — all device row cards (anchors linking to `/devices/details`)
- `deviceRowByName(String name)` — first row whose text contains `name`
- `rowMenuButtonByName(String deviceName)` — the three-dot "More actions" button within a named row

**Filter Panel Methods**
- `filterPanel()` — the `[role="dialog"][aria-modal="true"]` modal
- `filterResetButton()` / `filterApplyButton()` — panel action buttons
- `filterTagKeyCheckbox(String tagKey)` — checkbox for a specific tag key in the "Tag Keys" section

**Active Filter Chip Methods**
- `activeFilterChip(String chipText)` — filter chip in the search bar, format `"key:value"`

## Usage Example

```java
DevicesPage devicesPage = new DevicesPage(page);

// Verify the page loaded
assertThat(devicesPage.pageHeading()).hasText("Devices");

// Search for a specific device
devicesPage.searchInput().fill("workstation-01");

// Open the filter panel and apply a tag filter
devicesPage.openFiltersButton().click();
devicesPage.filterTagKeyCheckbox("purpose").click();
devicesPage.filterApplyButton().click();

// Verify filter chip is visible
assertThat(devicesPage.activeFilterChip("purpose:auto_test")).isVisible();

// Open the context menu for a specific device
devicesPage.rowMenuButtonByName("workstation-01").click();
```
