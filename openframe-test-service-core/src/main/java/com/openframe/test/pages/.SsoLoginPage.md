Page Object Model class for the OpenFrame SSO credential form at `/sas/login`, providing locators and fluent action methods for Playwright-based end-to-end tests.

## Key Components

| Member | Type | Description |
|---|---|---|
| `URL` | Constant | Target URL: `https://openframe.build/sas/login` |
| `formHeading()` | Locator | `h2` with "OpenFrame Single Sign-On" text |
| `emailInput()` | Locator | `#username` field |
| `passwordInput()` | Locator | `#password` field |
| `submitButton()` | Locator | `#submitBtn` (type="submit") |
| `forgotPasswordButton()` | Locator | `#forgotPasswordBtn` |
| `togglePasswordButton()` | Locator | `#passwordToggle` eye icon |
| `enterEmail()` | Action | Fills the email field, returns `this` for chaining |
| `enterPassword()` | Action | Fills the password field, returns `this` for chaining |
| `clickSubmit()` | Action | Clicks submit, waits for navigation away from `/sas/login`, returns `DashboardPage` |
| `login()` | Action | Convenience method combining `enterEmail` + `enterPassword` + `clickSubmit` |
| `isLoginFailed()` | Query | Returns `true` if URL still contains `/sas/login` after submission |
| `getEmailValue()` | Query | Returns the current value of the email field |

## Usage Example

```java
// Successful login
DashboardPage dashboard = new SsoLoginPage(page)
    .login("user@example.com", "securePassword");

// Manual step-by-step with failure check
SsoLoginPage loginPage = new SsoLoginPage(page);
DashboardPage result = loginPage
    .enterEmail("user@example.com")
    .enterPassword("wrongPassword")
    .clickSubmit();

if (loginPage.isLoginFailed()) {
    // Verify email field is retained after failed attempt
    String retained = loginPage.getEmailValue();
    assertEquals("user@example.com", retained);
}
```

## Notes

- **Flow position:** Step 3 in the OpenFrame SSO sequence; success issues a `?devTicket=…` query redirect to `/dashboard`.
- **Failure behavior:** A failed POST redirects back to GET `/sas/login` with no inline error — use `isLoginFailed()` to detect it.
- **Fluent API:** `enterEmail` and `enterPassword` return `this`, enabling method chaining before calling `clickSubmit`.
- **Navigation timeout:** `clickSubmit` waits up to 15 seconds for the URL to leave `/sas/login`.
