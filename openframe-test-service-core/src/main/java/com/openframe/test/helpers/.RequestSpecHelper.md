Provides factory methods for building reusable RestAssured `RequestSpecification` and `ResponseSpecification` objects, centralizing base URL resolution, authentication cookie injection, SSL configuration, and request logging for OpenFrame API tests.

## Key Components

| Member | Description |
|---|---|
| `setBaseUrl(String)` / `getBaseUrl()` | Thread-local base URL override, falling back to `EnvironmentConfig.getBaseUrl()` |
| `setEnableLogging(boolean)` | Toggles per-request logging to SLF4J output stream |
| `graphqlSuccess()` | `ResponseSpecification` asserting HTTP 200 and no `errors` field in body |
| `getAuthorizedSpec()` | `RequestSpecification` with JSON content type and auth cookies from `AuthHelper` |
| `getUnAuthorizedSpec()` | `RequestSpecification` without auth cookies, pointed at the tenant base URL |
| `getUnAuthorizedAuthSpec()` | Unauthenticated JSON spec pointed at the apex auth host (`getAuthUrl()`), used for endpoints like `/sas/invitations/accept` that are not served on tenant subdomains |
| `getAuthFlowRequestSpec()` | Bare spec targeting the auth host, used for authentication flow requests |
| `baseRequestSpec(String)` | Private builder configuring SSL relaxation, SLF4J logging, and `RetryingHttpClientFactory` |

## Usage Example

```java
// Authenticated GraphQL request
given()
    .spec(RequestSpecHelper.getAuthorizedSpec())
    .body(myGraphqlPayload)
.when()
    .post("/graphql")
.then()
    .spec(RequestSpecHelper.graphqlSuccess());

// Unauthenticated request to apex auth host
given()
    .spec(RequestSpecHelper.getUnAuthorizedAuthSpec())
    .body(acceptPayload)
.when()
    .post("/sas/invitations/accept")
.then()
    .statusCode(200);

// Override base URL per thread (e.g., in parallel tests)
RequestSpecHelper.setBaseUrl("https://tenant-a.openframe.ai");
```

> **Note:** `baseUrl` is stored in a `ThreadLocal`, making this safe for parallel test execution across different tenant environments.
