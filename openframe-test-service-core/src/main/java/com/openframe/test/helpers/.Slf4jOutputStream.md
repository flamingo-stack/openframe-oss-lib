Bridges a standard `OutputStream` to an SLF4J `Logger`, emitting one log entry per newline-terminated chunk. Primarily used to route RestAssured's request/response logging through SLF4J in test helpers.

## Key Components

| Member | Description |
|---|---|
| `Slf4jOutputStream(Logger)` | Constructor accepting an SLF4J `Logger` instance to write to |
| `write(int b)` | Buffers bytes, flushing to the logger on each newline (`\n`) |
| `write(byte[], int, int)` | Delegates to `write(int)` byte-by-byte over the specified range |
| `flush()` | Flushes any remaining buffered content not yet terminated by a newline |
| `flushLine()` | Drains the internal `StringBuilder`, logging non-blank lines at `INFO` level |

## Usage Example

```java
import org.slf4j.LoggerFactory;
import java.io.PrintStream;

Logger logger = LoggerFactory.getLogger(MyTest.class);
PrintStream logStream = new PrintStream(new Slf4jOutputStream(logger));

// Route RestAssured logging through SLF4J
RestAssured.config = RestAssuredConfig.config()
    .logConfig(LogConfig.logConfig()
        .defaultStream(logStream));
```

Blank lines are silently discarded, keeping logs clean from RestAssured's decorative separators. The internal `StringBuilder` is reset after each flush to avoid memory accumulation across requests.

## Notes

- Package-private (`class`, not `public`) — intended for use within `com.openframe.test.helpers` only
- Log level is fixed at `INFO`; adjust `flushLine()` if `DEBUG` output is preferred during local development
