Provides a test API helper for creating tags via GraphQL mutations in the OpenFrame test suite.

## Key Components

- **`createTag(String key, String entityType, String description, String color)`** — Static method that constructs and sends an authenticated GraphQL mutation to create a tag, returning the resulting `TagDefinition` object.

## Usage Example

```java
TagDefinition tag = TagApi.createTag(
    "priority-high",
    "TICKET",
    "High priority items",
    "#FF0000"
);
```

## Notes

- Uses `RequestSpecHelper.getAuthorizedSpec()` to attach auth credentials to each request.
- Validates the response with `graphqlSuccess()` before extracting the payload.
- The GraphQL mutation query is sourced from `TagQueries.CREATE_TAG`.
- The endpoint is resolved from `EnvironmentConfig.GRAPHQL`.
