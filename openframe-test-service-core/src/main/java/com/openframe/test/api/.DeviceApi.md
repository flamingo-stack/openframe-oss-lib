`DeviceApi.java` provides a static API client for interacting with device-related endpoints in the OpenFrame test framework, covering GraphQL queries, REST operations, and integrations with Fleet MDM and MeshCentral tool connections.

## Key Components

| Method | Description |
|---|---|
| `getDeviceHostnames(filter)` | Returns a list of hostnames matching the given filter via GraphQL |
| `getDeviceIds(filter)` | Returns device machine IDs for a given filter |
| `getAllDeviceIds(filter, first)` | Paginates through all device IDs using cursor-based pagination |
| `getDevice(machineId)` | Fetches a full `Machine` object by machine ID |
| `getAnyDevice(filters...)` | Returns the first available device matching any of the provided filters |
| `getDevices(filter)` | Returns a list of `Machine` objects matching the filter |
| `getAllDevices(filter, first)` | Paginates all devices and extracts Fleet MDM agent IDs |
| `updateDeviceStatus(device, status)` | PATCHes a device's status via REST (`204` expected) |
| `archiveDevice(device)` | Shortcut to set status to `ARCHIVED` |
| `deleteDevice(device)` | Shortcut to set status to `DELETED` |
| `searchDevice(filter, search)` | Searches devices by filter and text query, returns first result |
| `getMeshInfo(meshId)` | Fetches MeshCentral device status as `MeshDevice` |
| `getFleetInfo(fleetId)` | Fetches Fleet MDM host details as `FleetHost` |
| `getFleetOsVersion(fleetId)` | Returns the OS version string for a Fleet host, or `null` on failure |
| `getDeviceFilters()` | Fetches available device filter options |
| `getDeviceFilters(filter)` | Fetches device filters pre-scoped to a given filter input |

## Usage Example

```java
// Fetch all device IDs matching an online Windows filter with pagination
DeviceFilterInput filter = new DeviceFilterInput();
filter.setOs("Windows");
filter.setStatus("ONLINE");

List<String> allIds = DeviceApi.getAllDeviceIds(filter, 50);

// Retrieve full device details and archive it
Machine device = DeviceApi.getDevice(allIds.get(0));
DeviceApi.archiveDevice(device);

// Look up Fleet MDM OS version for a specific host
String osVersion = DeviceApi.getFleetOsVersion("fleet-host-123");

// Search for a device by hostname substring
Machine found = DeviceApi.searchDevice(filter, "workstation-42");
```

## Notes

- All GraphQL operations use the `getAuthorizedSpec()` + `graphqlSuccess()` helpers from `RequestSpecHelper`.
- Cursor-based pagination in `getAllDeviceIds` and `getAllDevices` loops until `pageInfo.hasNextPage` is `false`.
- `getAllDevices` specifically filters tool connections for `FLEET_MDM` type before collecting agent IDs.
