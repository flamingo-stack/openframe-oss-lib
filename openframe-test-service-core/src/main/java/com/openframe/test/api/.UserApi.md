REST-Assured API client for user management endpoints, providing static helper methods to interact with user profile, user administration, and password reset flows in test scenarios.

## Key Components

| Method | Description |
|---|---|
| `me()` | Fetches the current authenticated user's profile (`MeResponse`) |
| `getUsers()` | Retrieves all users as a list of `AuthUser` objects |
| `getUsers(UserRole role)` | Filters users by a specific `UserRole` |
| `getUser(String userId)` | Fetches a single user by ID |
| `deleteUser(String userId)` | Deletes a user, returning the raw HTTP status code |
| `resetPassword(User user)` | Initiates a password reset request (expects `202`) |
| `confirmReset(ResetConfirmRequest request)` | Confirms a password reset (expects `204`) |
| `attemptConfirmReset(ResetConfirmRequest request)` | Asserts a failed reset attempt (expects `400`, returns `ErrorResponse`) |

**Endpoint Constants**

| Constant | Path |
|---|---|
| `ME` | `api/me` |
| `USERS` | `api/users` |
| `PASSWORD_RESET` | `sas/password-reset/request` |
| `CONFIRM_RESET` | `sas/password-reset/confirm` |

> **Note:** `sas/*` endpoints use `getUnAuthorizedAuthSpec()` targeting the apex auth host, not the tenant subdomain.

## Usage Example

```java
// Get current user profile
MeResponse me = UserApi.me();

// Retrieve all users with a specific role
List<AuthUser> admins = UserApi.getUsers(UserRole.ADMIN);

// Delete a user and assert HTTP 204
int status = UserApi.deleteUser("user-123");
assertThat(status).isEqualTo(204);

// Trigger and confirm a password reset
UserApi.resetPassword(user);
UserApi.confirmReset(new ResetConfirmRequest(token, "newPassword"));

// Assert failed reset returns a structured error

assertThat(error.getMessage()).isNotNull();
```
