GraphQL query and mutation string constants for the Knowledge Base API, used in integration and API tests across the OpenFrame platform.

## Key Components

| Constant | Type | Description |
|---|---|---|
| `KNOWLEDGE_BASE_ITEM` | Query | Fetch a single KB item by ID with full detail (author, tags, attachments) |
| `KNOWLEDGE_BASE_ITEMS` | Query | Paginated list of KB items with optional filtering and search |
| `KNOWLEDGE_BASE_FOLDER_TREE` | Query | Flat list of all folders for tree construction |
| `KNOWLEDGE_BASE_ARTICLE_TREE` | Query | Flat list of all articles with status for tree construction |
| `KNOWLEDGE_BASE_TAGS` | Query | Tags scoped to an optional folder |
| `ARCHIVED_ARTICLES` | Query | Paginated archived articles with tag/search filtering |
| `CREATE_ARTICLE` | Mutation | Create a new KB article |
| `PUBLISH_ARTICLE` | Mutation | Transition an article to published status |
| `UPDATE_ARTICLE` | Mutation | Update article content, name, or parent |
| `ARCHIVE_ARTICLE` / `UNARCHIVE_ARTICLE` | Mutation | Toggle article archive state |
| `CREATE_FOLDER` / `RENAME_FOLDER` / `MOVE_TO_FOLDER` / `DELETE_FOLDER` | Mutations | Full folder lifecycle management |
| `CREATE_ATTACHMENT_UPLOAD_URL` | Mutation | Generate a presigned upload URL for a permanent attachment |
| `CREATE_TEMP_ATTACHMENT_UPLOAD_URL` | Mutation | Generate a presigned upload URL for a temporary attachment |
| `LINK_TEMP_ATTACHMENTS_TO_ARTICLE` | Mutation | Promote temp attachments to a published article |
| `DELETE_ATTACHMENT` / `DELETE_TEMP_ATTACHMENT` | Mutations | Remove permanent or temporary attachments |
| `ATTACHMENT_DOWNLOAD_URL` | Query | Resolve a download URL for a specific attachment |

Private constants `FOLDER_FIELDS`, `ARTICLE_LIFECYCLE_FIELDS`, and `TAG_OP_FIELDS` are reusable field fragments composed into related mutations via `String.formatted()`.

## Usage Example

```java
// Fetch a single knowledge base item
Map<String, Object> variables = Map.of("id", "kb-item-123");
GraphQLResponse response = graphQLClient.execute(
    KnowledgeBaseQueries.KNOWLEDGE_BASE_ITEM,
    variables
);

// Paginated item list with filter and search
Map<String, Object> listVars = Map.of(
    "first", 20,
    "after", "cursor-abc",
    "search", "VPN setup",
    "filter", Map.of("status", "PUBLISHED")
);
GraphQLResponse items = graphQLClient.execute(
    KnowledgeBaseQueries.KNOWLEDGE_BASE_ITEMS,
    listVars
);

// Create a new article
Map<String, Object> createVars = Map.of(
    "input", Map.of(
        "name", "How to Reset VPN",
        "content", "Step 1...",
        "parentId", "folder-456"
    )
);
GraphQLResponse created = graphQLClient.execute(
    KnowledgeBaseQueries.CREATE_ARTICLE,
    createVars
);
```
