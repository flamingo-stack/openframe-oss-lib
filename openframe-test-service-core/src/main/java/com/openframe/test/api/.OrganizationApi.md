`OrganizationApi.java` provides a static API client for managing organizations in the OpenFrame test framework, supporting both GraphQL queries and REST operations.

## Key Components

| Method | Type | Description |
|---|---|---|
| `listOrganizations()` | GraphQL | Paginates through all organizations (100 per page), with optional filter and sort |
| `getOrganizations(boolean)` | GraphQL | Filters organizations by `isDefault` flag |
| `getOrganizationsLastActivity(...)` | GraphQL | Extracts `lastActivityAt` timestamps, with filter or sort overloads |
| `retrieveOrganizationByOrganizationId(String)` | GraphQL | Fetches a single organization by its ID |
| `createOrganization(CreateOrganizationRequest)` | REST POST | Creates an organization; expects HTTP 201 |
| `updateOrganization(String, CreateOrganizationRequest)` | REST PUT | Updates an organization by ID; expects HTTP 200 |
| `archiveOrganization(Organization)` | REST PATCH | Sets organization status to `ARCHIVED`; expects HTTP 204 |

## Usage Example

```java
// List all organizations
List<Organization> all = OrganizationApi.listOrganizations();

// List with filter and sort
OrganizationFilterInput filter = new OrganizationFilterInput();
OrganizationSortInput sort = new OrganizationSortInput();
List<Organization> filtered = OrganizationApi.listOrganizations(filter, sort);

// Retrieve a specific organization via GraphQL
Organization org = OrganizationApi.retrieveOrganizationByOrganizationId("org-123");

// Create a new organization
CreateOrganizationRequest request = new CreateOrganizationRequest();
Organization created = OrganizationApi.createOrganization(request);

// Archive an organization
OrganizationApi.archiveOrganization(created);
```

## Notes

- All methods use `RequestSpecHelper.getAuthorizedSpec()` for authenticated requests.
- `listOrganizations` handles cursor-based pagination automatically, aggregating all pages into a single list.
- GraphQL operations post to the `GRAPHQL` endpoint; REST operations target `api/organizations`.
