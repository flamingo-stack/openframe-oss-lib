Provides a static utility class for interacting with the Script GraphQL API in integration tests, wrapping common CRUD and lifecycle operations using RestAssured.

## Key Components

| Method | Description |
|---|---|
| `listScripts()` | Fetches a paginated list of active scripts (first 20) via relay-style query |
| `getScript(String id)` | Retrieves a single script by ID |
| `createScript(CreateScriptInput input)` | Creates a new script from the provided input DTO |
| `updateScript(UpdateScriptInput input)` | Updates an existing script from the provided input DTO |
| `deleteScript(String id)` | Deletes a script by ID, returns a confirmation string |
| `archiveScript(String id)` | Archives a script by ID, returns the updated `Script` object |

All methods use `getAuthorizedSpec()` for authenticated requests and `graphqlSuccess()` to assert a successful GraphQL response.

## Usage Example

```java
// List all active scripts
List<Script> scripts = ScriptApi.listScripts();

// Create a new script
CreateScriptInput input = new CreateScriptInput("My Script", "echo hello");
Script created = ScriptApi.createScript(input);

// Update an existing script
UpdateScriptInput updateInput = new UpdateScriptInput(created.getId(), "echo world");
Script updated = ScriptApi.updateScript(updateInput);

// Archive a script
Script archived = ScriptApi.archiveScript(created.getId());

// Delete a script
String result = ScriptApi.deleteScript(created.getId());
```

## Notes

- All methods are `static` — no instantiation required.
- `listScripts()` filters by `ACTIVE` status and caps results at 20; adjust variables in `ScriptQueries` if pagination behavior needs to change.
