Provides a test API client for interacting with OpenFrame's agent registration endpoints, encapsulating authenticated HTTP requests for agent enrollment operations.

## Key Components

- **`AgentApi`** — Static utility class wrapping agent-related REST API calls using RestAssured.
- **`getActiveRegistrationSecret()`** — Retrieves the tenant's currently active agent registration secret (`key`), used as the `initialKey` during device enrollment. Requires an authenticated user context from the target tenant.
- **`ACTIVE_REGISTRATION_SECRET`** — Constant defining the endpoint path: `api/agent/registration-secret/active`.

## Usage Example

```java
// Retrieve the active registration secret for the authenticated tenant
String registrationKey = AgentApi.getActiveRegistrationSecret();

// Use the key to enroll a device
DeviceEnrollmentRequest request = new DeviceEnrollmentRequest();
request.setInitialKey(registrationKey);
```

## Notes

- Relies on `RequestSpecHelper.getAuthorizedSpec()` to inject authentication headers — ensure the test context has a valid session/token before calling.
- Expects a `200` HTTP response; RestAssured will throw an assertion error on any other status code.
- Extracts the `key` field from the JSON response body.
