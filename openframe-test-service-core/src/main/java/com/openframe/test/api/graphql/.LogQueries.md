Defines GraphQL query string constants used for log-related API operations in the OpenFrame test suite.

## Key Components

| Constant | Description |
|---|---|
| `LOG_FILTERS` | Retrieves available filter options (tool types, event types, severities, organizations) for the log query UI |
| `LOGS` | Paginated log listing query supporting filtering, search, and sorting; returns connection-style edges with `pageInfo` |
| `LOG_DETAILS` | Fetches full details for a single log entry identified by its composite key (`ingestDay`, `toolType`, `eventType`, `timestamp`, `toolEventId`) |

## Usage Example

```java
// Fetch paginated logs with a filter and sort
GraphQLResponse response = graphQLClient.query(
    LogQueries.LOGS,
    Map.of(
        "filter", Map.of("severity", "ERROR", "toolType", "RMM"),
        "search", "disk",
        "sort",  Map.of("field", "TIMESTAMP", "direction", "DESC")
    )
);

// Fetch details for a specific log entry
GraphQLResponse details = graphQLClient.query(
    LogQueries.LOG_DETAILS,
    Map.of(
        "ingestDay",  "2024-01-15",
        "toolType",   "RMM",
        "eventType",  "ALERT",
        "timestamp",  Instant.parse("2024-01-15T10:30:00Z"),
        "toolEventId","evt-abc-123"
    )
);
```

## Notes

- All queries are declared as `public static final String` constants, making them safe to reference statically across test classes without instantiation.
- `LOGS` uses a [Relay-style connection](https://relay.dev/graphql/connections.htm) pattern (`edges`/`node`/`pageInfo`), enabling cursor-based pagination.
- `LOG_DETAILS` returns the additional `message` and `details` fields not present in the list query.
