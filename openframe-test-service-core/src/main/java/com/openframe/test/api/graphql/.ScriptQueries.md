Defines GraphQL query and mutation string constants used by the test client to interact with the Scripts API, covering CRUD operations, archival, and paginated listing with facet filters.

## Key Components

| Constant | Type | Description |
|---|---|---|
| `SCRIPTS_TABLE_RELAY_QUERY` | Query | Relay-style paginated scripts list with `scriptFilters` facets (shells, platforms, authors) |
| `GET_SCRIPT` | Query | Fetches a single script by ID with full field detail |
| `CREATE_SCRIPT` | Mutation | Creates a new script from a `CreateScriptInput` |
| `UPDATE_SCRIPT` | Mutation | Updates an existing script from an `UpdateScriptInput` |
| `DELETE_SCRIPT` | Mutation | Hard-deletes a script by ID |
| `ARCHIVE_SCRIPT` | Mutation | Soft-deletes a script by ID, returning updated `id` and `status` |

## Usage Example

```java
// Paginated scripts table with filters
Map<String, Object> variables = Map.of(
    "first", 20,
    "filter", Map.of("shell", "POWERSHELL")
);
graphqlClient.execute(ScriptQueries.SCRIPTS_TABLE_RELAY_QUERY, variables);

// Fetch a single script
graphqlClient.execute(ScriptQueries.GET_SCRIPT, Map.of("id", "script-123"));

// Create a new script
Map<String, Object> input = Map.of(
    "name", "Disk Cleanup",
    "shell", "POWERSHELL",
    "scriptBody", "Get-PSDrive"
);
graphqlClient.execute(ScriptQueries.CREATE_SCRIPT, Map.of("input", input));

// Archive instead of delete
graphqlClient.execute(ScriptQueries.ARCHIVE_SCRIPT, Map.of("id", "script-123"));
```

## Notes

- `SCRIPTS_TABLE_RELAY_QUERY` uses a named fragment (`scriptsTableRelay_query`) mirroring the web app's Relay compiler output — tests exercise the exact same query shape as the UI.
- `envVars` fields include a `secret` flag; test assertions should account for redacted values in production responses.
