A GraphQL API client for querying and filtering log data in the OpenFrame test framework, providing methods to retrieve log events, apply filters/sorting, search logs, and fetch detailed log information.

## Key Components

| Method | Description |
|---|---|
| `getLogFilters()` | Fetches available filter options as a `LogFilters` object |
| `getLogs()` | Retrieves all log events without parameters |
| `getLogs(LogFilterInput)` | Retrieves logs filtered by a `LogFilterInput` criteria |
| `getLogs(LogSortInput)` | Retrieves logs sorted by a `LogSortInput` criteria |
| `getLogs(LogFilterInput, LogSortInput)` | Retrieves logs with both filter and sort applied |
| `searchLogs(String)` | Searches logs by a plain text query string |
| `getLogsTimestamps(LogSortInput)` | Extracts sorted `Instant` timestamps from log results |
| `getLogsTimestamps(LogFilterInput)` | Extracts filtered `Instant` timestamps from log results |
| `getLogDetails(LogEvent)` | Fetches full `LogDetails` for a specific `LogEvent` |

## Usage Example

```java
// Fetch all available log filter options
LogFilters filters = LogsApi.getLogFilters();

// Retrieve logs with a filter
LogFilterInput filter = new LogFilterInput();
filter.setToolType("PSA");
List<LogEvent> filteredLogs = LogsApi.getLogs(filter);

// Retrieve logs with both filter and sort
LogSortInput sort = new LogSortInput();
sort.setField("timestamp");
sort.setOrder("DESC");
List<LogEvent> sortedFilteredLogs = LogsApi.getLogs(filter, sort);

// Search logs by keyword
List<LogEvent> searchResults = LogsApi.searchLogs("connection timeout");

// Get timestamps from sorted logs
List<Instant> timestamps = LogsApi.getLogsTimestamps(sort);

// Fetch detailed information for a specific log event
LogEvent logEvent = filteredLogs.get(0);
LogDetails details = LogsApi.getLogDetails(logEvent);
```

## Notes

- All methods use `getAuthorizedSpec()` to inject authentication headers automatically.
- GraphQL responses are validated via `graphqlSuccess()` before data extraction.
- Timestamps are parsed from `String` to `java.time.Instant` via the private `extractTimestamps` helper.
