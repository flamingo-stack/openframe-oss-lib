GraphQL API client for Knowledge Base operations in the OpenFrame test suite, providing static methods to interact with knowledge base articles, folders, tags, and attachments via GraphQL mutations and queries.

## Key Components

| Method | Type | Description |
|---|---|---|
| `getKnowledgeBaseItem(String id)` | Query | Fetches a single KB item by ID |
| `getKnowledgeBaseFolderTree()` | Query | Returns the full folder hierarchy |
| `getKnowledgeBaseArticleTree()` | Query | Returns the full article hierarchy |
| `getKnowledgeBaseItems(filter, search, first)` | Query | Paginated, filtered item listing |
| `getKnowledgeBaseTags(folderId)` | Query | Lists tags scoped to a folder |
| `createArticle(input)` | Mutation | Creates a new KB article |
| `publishArticle(articleId)` | Mutation | Publishes a draft article |
| `updateArticle(input)` | Mutation | Updates article content/metadata |
| `createFolder(name, parentId)` | Mutation | Creates a folder, optionally nested |
| `renameFolder(folderId, name)` | Mutation | Renames an existing folder |
| `moveToFolder(itemId, parentId)` | Mutation | Moves an item to a different folder |
| `deleteFolder(input)` | Mutation | Deletes a folder, returns boolean |
| `archiveArticle(articleId)` | Mutation | Archives an article |
| `unarchiveArticle(articleId, parentId)` | Mutation | Restores an archived article |
| `getArchivedArticles(search, tagIds, first)` | Query | Lists archived articles with optional filters |
| `createAttachmentUploadUrl(input)` | Mutation | Generates a presigned upload URL for attachments |

All methods use `getAuthorizedSpec()` for authentication and `graphqlSuccess()` to assert a successful GraphQL response.

## Usage Example

```java
// Fetch a single knowledge base item
KnowledgeBaseItem item = KnowledgeBaseApi.getKnowledgeBaseItem("item-id-123");

// Create and publish an article
CreateArticleInput input = new CreateArticleInput("My Article", "folderId-456");
KnowledgeBaseItem article = KnowledgeBaseApi.createArticle(input);
KnowledgeBaseApi.publishArticle(article.getId());

// List items with a filter and search term
KnowledgeBaseFilterInput filter = new KnowledgeBaseFilterInput(KnowledgeBaseItemType.ARTICLE);
List<KnowledgeBaseItem> items = KnowledgeBaseApi.getKnowledgeBaseItems(filter, "search term", 20);

// Archive and later restore an article
KnowledgeBaseApi.archiveArticle(article.getId());
KnowledgeBaseApi.unarchiveArticle(article.getId(), "folderId-456");

// Retrieve archived articles filtered by tags
List<KnowledgeBaseItem> archived = KnowledgeBaseApi.getArchivedArticles("query", List.of("tag-1"), 10);
```
