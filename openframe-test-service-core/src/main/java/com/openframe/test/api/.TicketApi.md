GraphQL API client for ticket-related operations in the OpenFrame test framework, providing methods to query, create, mutate, and manage tickets and ticket statuses via REST Assured HTTP calls.

## Key Components

| Method | Description |
|---|---|
| `getTickets(filter, pagination)` | Fetches a paginated list of tickets with optional filtering and search |
| `getTicket(id)` | Retrieves a single ticket by ID |
| `createTicket(input)` | Creates a new ticket; throws `AssertionError` on `userErrors` |
| `reorderTicket(input)` | Reorders a ticket within its column |
| `transitionTicket(ticketId, toStatusId)` | Transitions a ticket to a new lifecycle status |
| `attemptTransitionTicketErrors(ticketId, toStatusId)` | Attempts a transition expected to fail; returns raw GraphQL errors instead of asserting success |
| `getTicketStatuses()` | Returns all ticket status definitions |
| `createTicketStatus(input)` | Creates a new custom ticket status |
| `deleteTicketStatus(id)` | Deletes a status, optionally reassigning tickets to a replacement status |
| `attemptDeleteTicketStatusErrors(id)` | Attempts deletion of a protected/system status; returns raw GraphQL errors |
| `resolveSystemStatusId(kind)` | Resolves the ID of a system status by lifecycle kind (e.g. `RESOLVED`, `ARCHIVED`) |
| `getTicketLabels()` | Returns all available ticket labels |
| `findColumnWithAtLeastTwoTickets()` | Iterates statuses to find a column containing 2+ tickets (useful for ordering tests) |
| `mutateTicket(query, mutationName, variables)` | Private helper that executes any ticket mutation and unwraps the `ticket` payload, throwing on `userErrors` |

## Usage Example

```java
// Create a ticket and transition it to a resolved state
Ticket ticket = TicketApi.createTicket(
    CreateTicketInput.builder()
        .title("Printer offline")
        .build()
);

String resolvedStatusId = TicketApi.resolveSystemStatusId("RESOLVED");
Ticket resolved = TicketApi.transitionTicket(ticket.getId(), resolvedStatusId);

// Verify an invalid transition is rejected
List<GraphqlError> errors = TicketApi.attemptTransitionTicketErrors(
    ticket.getId(), resolvedStatusId
);
assertFalse(errors.isEmpty());

// Fetch tickets filtered by status with pagination
TicketConnection page = TicketApi.getTickets(
    TicketGenerator.ticketsWithStatusId(resolvedStatusId),
    CursorGenerator.limit(10)
);
```

> **Note:** Methods suffixed with `Errors` (e.g. `attemptTransitionTicketErrors`, `attemptDeleteTicketStatusErrors`) bypass the `graphqlSuccess()` response spec intentionally — domain violations like invalid lifecycle transitions surface as top-level GraphQL errors rather than `userErrors` entries.
