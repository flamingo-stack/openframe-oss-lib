Provides static utility methods for uploading and downloading file attachments via authorized HTTP requests using RestAssured.

## Key Components

| Method | Description |
|---|---|
| `uploadAttachmentFile(String uploadUrl, Path file, String contentType)` | Uploads a file to the given URL via HTTP `PUT`, asserting a `200` response |
| `downloadAttachmentFile(String downloadUrl)` | Downloads a file from the given URL via HTTP `GET` and returns its raw bytes, asserting a `200` response |

Both methods use `getAuthorizedSpec()` from `RequestSpecHelper` to inject authentication headers, and disable URL encoding to preserve pre-formed upload/download URLs.

## Usage Example

```java
// Upload a file attachment
Path filePath = Path.of("/tmp/report.pdf");
AttachmentApi.uploadAttachmentFile(
    "https://storage.example.com/upload/report.pdf",
    filePath,
    "application/pdf"
);

// Download a file attachment
byte[] fileBytes = AttachmentApi.downloadAttachmentFile(
    "https://storage.example.com/download/report.pdf"
);
Files.write(Path.of("/tmp/downloaded_report.pdf"), fileBytes);
```

## Notes

- All requests are authenticated via `RequestSpecHelper.getAuthorizedSpec()`
- URL encoding is explicitly disabled — ensure upload/download URLs are already properly encoded
- Both methods assert HTTP `200`; non-200 responses will fail the test immediately
- Part of the `com.openframe.test.api` test package — intended for use in integration/API tests
