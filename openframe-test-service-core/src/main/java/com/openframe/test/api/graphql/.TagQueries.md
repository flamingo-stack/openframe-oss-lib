Provides GraphQL mutation strings for tag-related API operations used in test contexts.

## Key Components

- **`CREATE_TAG`** – Static constant containing a GraphQL `createTag` mutation. Accepts `key`, `entityType`, `description`, and `color` as variables and returns the created tag's `id`, `key`, `description`, `color`, `entityType`, and `createdAt` fields.

## Usage Example

```java
import com.openframe.test.api.graphql.TagQueries;

// Use the mutation string with a GraphQL client in a test
String mutation = TagQueries.CREATE_TAG;

Map<String, Object> variables = new HashMap<>();
variables.put("key", "priority");
variables.put("entityType", "TICKET");
variables.put("description", "Priority level");
variables.put("color", "#FF5733");

graphQLClient.execute(mutation, variables);
```

## Notes

- All fields in `CREATE_TAG` except `key` and `entityType` are optional (`description`, `color`).
- Intended for use in integration or API tests within the OpenFrame platform.
- Part of the [`com.openframe.test.api.graphql`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/test/api/graphql) test utilities package.
