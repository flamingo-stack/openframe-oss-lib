Utility class for creating temporary test files with random ASCII content, used to support file upload scenarios in integration tests.

## Key Components

| Member | Type | Description |
|---|---|---|
| `UPLOAD_DIR` | `Path` | Fixed upload staging directory: `target/files/upload` |
| `createRandomFile(long size)` | `static Path` | Creates a temp file of the given byte size filled with random ASCII characters |

## Usage Example

```java
// Create a 1 KB random file for upload testing
Path testFile = FileUtils.createRandomFile(1024);

// Use the file in a multipart upload test
mockMvc.perform(multipart("/api/upload")
        .file(new MockMultipartFile(
                "file",
                testFile.getFileName().toString(),
                "text/plain",
                Files.readAllBytes(testFile)
        )))
        .andExpect(status().isOk());
```

## Behavior Notes

- **Directory creation:** `target/files/upload` is created automatically if it does not exist.
- **File naming:** Temp files follow the pattern `upload-<random>.txt`.
- **Encoding:** Content is written as `US-ASCII`; the `size` parameter maps directly to the character count.
- **Exception handling:** `IOException` is wrapped in `UncheckedIOException` to keep test code free of checked exception handling.

> **Note:** Output files land under `target/` and are typically cleaned by `mvn clean`. For large file tests, ensure the `size` argument does not exceed `Integer.MAX_VALUE`, as the internal cast from `long` to `int` will silently truncate.
