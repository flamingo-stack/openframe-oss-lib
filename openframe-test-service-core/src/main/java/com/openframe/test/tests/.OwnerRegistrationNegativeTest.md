Negative test suite for owner user registration flows, verifying that the system correctly rejects invalid or disallowed registration attempts.

## Key Components

- **`testRegistrationClosed()`** — Generates a fresh registration request and asserts the API returns HTTP 400+ when registration is disabled/closed.
- **`testRegisterExistingUser()`** — Fetches existing `OWNER`-role users, attempts to re-register with the last known user's credentials, and asserts the API returns HTTP 400+.

**Tags:** `oss`, `registration-negative`

## Usage Example

```java
// Run all negative registration tests via JUnit 5
@Tag("registration-negative")
public class OwnerRegistrationNegativeTest extends BaseTest {

    @Test
    public void testRegistrationClosed() {
        // Generates a valid-looking request payload
        UserRegistrationRequest request = RegistrationGenerator.userRegistrationRequest();

        // Expects 4xx/5xx when registration is closed
        int statusCode = RegistrationApi.attemptRegistration(request);
        assertThat(statusCode).isGreaterThanOrEqualTo(400);
    }

    @Test
    public void testRegisterExistingUser() {
        // Retrieves an already-registered OWNER user
        List<AuthUser> users = UserApi.getUsers(UserRole.OWNER);
        UserRegistrationRequest request = RegistrationGenerator.existingUserRequest(users.getLast());

        // Expects duplicate registration to be rejected
        int statusCode = RegistrationApi.attemptRegistration(request);
        assertThat(statusCode).isGreaterThanOrEqualTo(400);
    }
}
```

## Notes

- Extends `BaseTest` for shared setup/teardown and configuration.
- Relies on `RegistrationGenerator` for both fresh and duplicate request payloads.
- `UserApi.getUsers(UserRole.OWNER)` requires at least one pre-existing owner in the system; the test will fail fast if none exist.
