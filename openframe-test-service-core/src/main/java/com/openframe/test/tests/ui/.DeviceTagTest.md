UI test that verifies device tag filtering functionality on the Devices page using Playwright and JUnit 5.

## Key Components

| Component | Description |
|---|---|
| `DeviceTagTest` | JUnit 5 test class tagged with `@Tag("device")`, extends `BaseUITest` |
| `openDeviceDetails()` | `@BeforeEach` setup method that navigates to the Devices page |
| `testFilterByTag()` | Test verifying that filtering devices by a key/value tag returns correct results |

**Test Data Constants:**

| Constant | Value |
|---|---|
| `TAG_KEY` | `"purpose"` |
| `TAG_VALUE` | `"auto_test"` |
| `EXPECTED_CHIP` | `"purpose:auto_test"` |
| `DEVICE_NAME` | `"vm115982"` |

## Usage Example

```java
// The test navigates to the devices list and applies a tag filter,
// then asserts three conditions:

devicesPage.filterByTag("purpose", "auto_test");

// 1. At least one device row is returned
assertThat(devicesPage.deviceRows().count()).isNotZero();

// 2. The specific target device is visible in results
PlaywrightAssertions.assertThat(devicesPage.deviceRowByName("vm115982")).isVisible();

// 3. The active filter chip displays the correct "key:value" label
PlaywrightAssertions.assertThat(devicesPage.activeFilterChip("purpose:auto_test")).isVisible();
```

## Notes

- Extends `BaseUITest`, which is expected to provide `navigationSidebar` and shared Playwright browser context setup.
- Combines AssertJ (`assertThat`) for count assertions and Playwright's native `PlaywrightAssertions` for DOM visibility checks.
