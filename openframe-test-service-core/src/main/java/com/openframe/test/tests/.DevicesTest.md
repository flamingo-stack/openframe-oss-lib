JUnit 5 integration test suite for the OpenFrame device management API, validating device listing, filtering, detail retrieval, Fleet MDM info, MeshCentral info, search, and archive/delete lifecycle operations.

## Key Components

| Method | Tags | Description |
|---|---|---|
| `testGetDeviceFilters()` | `saas`, `read` | Validates device filter response includes statuses, OS types, and organization IDs with non-empty counts |
| `testGetDevice()` | `saas`, `read` | Fetches a device by `machineId` and asserts all required fields, tool connections (`MESHCENTRAL`, `FLEET_MDM`), and installed agents |
| `testFleetInfo()` | `saas`, `read` | Retrieves Fleet MDM host details and validates hardware, users, software, and optional CVE vulnerability data |
| `testMeshInfo()` | `saas`, `read` | Retrieves MeshCentral node details and validates `nodeId`, `lastConnectTime`, and `lastConnectAddr` |
| `testSearchDevices()` | `saas`, `read` | Searches by hostname and asserts the returned device matches the queried hostname |
| `testFilterDevices()` | `saas`, `read` | Filters devices by `WINDOWS` OS type and asserts all results match |
| `testArchiveDevice()` | `archive`, Order 1 | Archives an offline device and confirms it no longer appears in listed-status results |
| `testDeleteDevice()` | `archive`, Order 2 | Deletes the archived device (created by Order 1) and confirms removal from listed-status results |

## Usage Example

```java
// Run only read-tagged tests (non-destructive)
// mvn test -Dgroups="saas & read"

// Run full archive lifecycle (Order 1 → Order 2)
// mvn test -Dgroups="archive"

// Example: fetching and asserting a device with tool connections
Machine device = DeviceApi.getAnyDevice(onlineDevicesFilter(), offlineDevicesFilter());
device = DeviceApi.getDevice(device.getMachineId());

assertThat(device.getToolConnections())
    .extracting(ToolConnection::getToolType)
    .containsAll(List.of("MESHCENTRAL", "FLEET_MDM"));
```

> **Note:** `testArchiveDevice` and `testDeleteDevice` are stateful and ordered — run them together using the `archive` tag to avoid state inconsistency. The `saas`/`read` tests are safe to run in isolation.
