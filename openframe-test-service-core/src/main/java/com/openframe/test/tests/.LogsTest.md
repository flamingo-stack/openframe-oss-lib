JUnit 5 integration test suite for the OpenFrame Logs API, validating retrieval, filtering, searching, sorting, and detail resolution of log events.

## Key Components

| Method | Tag | Description |
|---|---|---|
| `testGetLogFilters()` | `read` | Asserts that `LogFilters` returns non-empty tool types, event types, and severities |
| `testListLogs()` | `read` | Validates all required fields on each `LogEvent` in the full log listing |
| `testGetLogDetails()` | `read` | Fetches details for the first log entry and verifies field consistency with the parent `LogEvent` |
| `testSearchLogs()` | `read` | Extracts a search term from a log summary and confirms the API returns matching results |
| `testFilterLogs()` | `read` | Applies a severity filter from available `LogFilters` and asserts all returned logs match that severity |
| `testSortLogsByTimestampAscending()` | `read` | Requests logs sorted `ASC` and verifies the returned `Instant` list is naturally ordered |
| `testFilterLogsByTimestampRange()` | `read` | Derives a `from`/`to` range from sorted timestamps and validates all results fall within it |

## Usage Example

```java
// Run all Logs tests (saas + read tagged)
// via Maven:
// mvn test -Dgroups="saas & read" -Dtest=LogsTest

// Standalone assertion pattern used throughout the suite
List<LogEvent> logs = LogsApi.getLogs();
assertThat(logs).isNotEmpty();
assertThat(logs.getFirst().getToolEventId()).isNotNull();

// Filtering by severity
LogFilters filters = LogsApi.getLogFilters();
String severity = filters.getSeverities().getFirst();
List<LogEvent> filtered = LogsApi.getLogs(LogGenerator.severityFilter(severity));
assertThat(filtered).allSatisfy(log ->
    assertThat(log.getSeverity()).isEqualTo(severity)
);
```

## Notes

- Extends `BaseTest` for shared setup/teardown and client configuration.
- All tests are tagged `@Tag("saas")` and `@Tag("read")`, enabling targeted CI execution.
- Timestamp assertions use `java.time.Instant` with AssertJ's `isBetween` and `isSorted` for precision.
- Helper factories (`searchTerm`, `timestampRangeFilter`, `timestampSort`) are sourced from `LogGenerator`.
