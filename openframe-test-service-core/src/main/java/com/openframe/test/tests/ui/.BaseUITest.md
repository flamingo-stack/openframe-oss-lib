Abstract base class for Playwright-based UI integration tests. Manages browser lifecycle, per-test browser contexts with tracing, automatic login via `UILoginFlow`, and failure artifact capture (screenshots, HTML dumps, trace zips).

## Key Components

| Member | Description |
|---|---|
| `launchBrowser()` / `closeBrowser()` | `@BeforeAll`/`@AfterAll` hooks that create and tear down the shared Chromium `Browser` instance |
| `newContext()` | `@BeforeEach` hook that creates a 1920×1080 `BrowserContext`, starts Playwright tracing, wires console/error/request-failed listeners, and performs login via `UILoginFlow` |
| `closeContext()` | `@AfterEach` hook that safely closes the `BrowserContext` |
| `captureArtifacts()` | On test failure, saves a `.trace.zip`, `.html` page dump, and `.png` full-page screenshot to `/tmp/playwright-failures/` |
| `afterTest` (`AfterTestExecutionCallback`) | JUnit 5 extension that triggers artifact capture after each test method |
| `beforeEachFail` (`LifecycleMethodExecutionExceptionHandler`) | JUnit 5 extension that captures artifacts when a `@BeforeEach` method itself throws |
| `navigationSidebar` | Returned by `UILoginFlow.login()` — available to subclasses as the post-login page entry point |

## Usage Example

```java
class DashboardTest extends BaseUITest {

    @Test
    void dashboardLoadsWidgets() {
        // 'page' and 'navigationSidebar' are ready after @BeforeEach login
        DashboardPage dashboard = navigationSidebar.goToDashboard();
        Assertions.assertTrue(dashboard.widgetsVisible());
    }
}
```

On failure, artifacts are written to `/tmp/playwright-failures/` with a sanitized test-name slug and millisecond timestamp, e.g.:

```text
/tmp/playwright-failures/
  dashboardLoadsWidgets-1718000000000.trace.zip
  dashboardLoadsWidgets-1718000000000.html
  dashboardLoadsWidgets-1718000000000.png
```
