End-to-end test suite that validates the owner registration flow, covering user signup and subsequent login as the first ordered steps in the broader test pipeline.

## Key Components

| Component | Role |
|---|---|
| `testRegisterNewUser()` | Submits a registration request and asserts all required response fields (`id`, `ownerId`, `updatedAt`) are present, then publishes the new tenant to `PipelineContext` for downstream tests |
| `testLoginNewUser()` | Authenticates the newly registered user via `AuthFlow`, stores cookies via `AuthHelper`, and verifies the `/me` endpoint returns `authenticated: true` |
| `setup()` | `@BeforeAll` — randomises `EnvironmentConfig` and `UserConfig` to ensure each run uses a unique, isolated user identity |

**Tags:** `registration`, `login`  
**Ordering:** `@TestMethodOrder(MethodOrderer.OrderAnnotation.class)` — registration must complete before login is attempted.

## Usage Example

```java
// Run only the registration suite
./gradlew test -Dgroups="registration"

// The suite executes in order:
// 1. OwnerRegistrationTest.testRegisterNewUser()  → registers, publishes tenant
// 2. OwnerRegistrationTest.testLoginNewUser()     → logs in, validates session
```

```java
// PipelineContext receives the tenant after a successful registration,
// allowing subsequent pipeline tests to run against the live tenant.
PipelineContext.setRegisteredTenant(
    UserConfig.getEmail(),
    EnvironmentConfig.getTestUserDomain()
);
```
