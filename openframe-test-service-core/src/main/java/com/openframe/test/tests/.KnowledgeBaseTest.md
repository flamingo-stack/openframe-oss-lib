Ordered JUnit 5 test suite that validates the OpenFrame Knowledge Base API, covering folder/article CRUD operations, tree traversal, item lookup, file attachment upload/download, and folder mutation (rename/move).

## Key Components

| Test Method | Order | Description |
|---|---|---|
| `testCreateFolder()` | 1 | Creates a root folder and validates id, type, name, and null parentId |
| `testCreateArticle()` | 2 | Creates a draft article under an existing folder; asserts all fields including author |
| `testGetRootFolders()` | 3 | Fetches root folder listing and validates structure of each item |
| `testGetAllTags()` | 4 | Retrieves all KB tags (currently `@Disabled`) |
| `testGetFolderTree()` | 5 | Validates the full folder hierarchy tree |
| `testGetArticleTree()` | 6 | Validates all nodes in the article tree are `ARTICLE` type |
| `testGetKnowledgeBaseItemById()` | 7 | Fetches both a folder and an article by ID and compares field values |
| `testCreateUploadAndDownloadAttachment()` | 8 | Full attachment lifecycle: create upload URL → PUT file → GET download URL → assert byte count |
| `testRenameFolder()` | 9 | Renames a root folder and asserts the new name is persisted |
| `testMoveToFolder()` | 10 | Moves a folder under another parent (truncated in source) |

**Key dependencies:** `KnowledgeBaseApi`, `AttachmentApi`, `KnowledgeBaseGenerator` (data factories), AssertJ, JUnit 5.

## Usage Example

```java
// Run the full ordered suite
@TestMethodOrder(MethodOrderer.OrderAnnotation.class)
public class KnowledgeBaseTest extends BaseTest { ... }

// Or target a specific tag from CLI/CI
// mvn test -Dgroups="saas,read"

// Key API calls exercised internally:
KnowledgeBaseItem folder  = KnowledgeBaseApi.createFolder(folderName(), null);
KnowledgeBaseItem article = KnowledgeBaseApi.createArticle(draftArticle(folder.getId()));
KnowledgeBaseAttachmentUploadPayload upload =
    KnowledgeBaseApi.createAttachmentUploadUrl(attachmentInput(article.getId(), file));
AttachmentApi.uploadAttachmentFile(upload.getUploadUrl(), file, input.getContentType());
```

> **Note:** Tests are ordered and stateful — early tests seed data (folder, article) that later read/mutation tests depend on. Tag-based filtering (`saas`, `read`) supports selective execution in CI pipelines.
