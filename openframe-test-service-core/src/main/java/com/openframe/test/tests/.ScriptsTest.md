JUnit 5 integration test suite validating the full CRUD lifecycle for the Scripts resource in the OpenFrame API, including creation, listing, retrieval, update, and archival operations.

## Key Components

| Component | Description |
|---|---|
| `ScriptApi` | API client for all script-related HTTP operations |
| `ScriptGenerator` | Test data factory for generating `CreateScriptInput` and `UpdateScriptInput` payloads |
| `BaseTest` | Shared test base class providing common setup/teardown |
| `@Tag("saas")` | Marks the suite for SaaS environment execution |
| `@Tag("read")` | Marks read-only tests for selective test runs |
| `@TestMethodOrder(OrderAnnotation.class)` | Enforces sequential execution order across the lifecycle |

## Test Methods

| Order | Method | Description |
|---|---|---|
| 1 | `testAddScript()` | Creates a script and asserts all fields are persisted correctly |
| 2 | `testListScripts()` | Verifies the list endpoint returns non-empty results with mandatory fields |
| 3 | `testGetScript()` | Fetches a script by ID and validates field consistency with the list response |
| 4 | `testEditScript()` | Updates a script's description and re-fetches to confirm persistence |
| 5 | `testArchiveScript()` | Archives a script and asserts the status transitions to `ARCHIVED` |

## Usage Example

```java
// Run the full suite via Maven
// mvn test -Dgroups="saas"

// Run only read-only tests
// mvn test -Dgroups="read"

// Manually invoke a single operation (mirrors test logic)
CreateScriptInput input = ScriptGenerator.createScriptRequest();
Script created = ScriptApi.createScript(input);
assertThat(created.getId()).isNotNull();
```

> **Note:** Tests are order-dependent — `testListScripts`, `testGetScript`, `testEditScript`, and `testArchiveScript` all rely on at least one script existing, which `testAddScript` seeds in order 1.
