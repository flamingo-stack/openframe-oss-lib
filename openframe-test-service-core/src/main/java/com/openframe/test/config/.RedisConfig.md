Holds static configuration for connecting to the OpenFrame Redis cluster and resolving the tenant key namespace used by the test library (e.g., reading password-reset tokens written by the auth-server).

## Key Components

| Member | Type | Description |
|---|---|---|
| `DEFAULT_NODES` | `String` constant | Comma-separated fallback cluster nodes (`redis-cluster-0/1/2` in `datasources` namespace) |
| `DEFAULT_TENANT` | `String` constant | Fallback tenant namespace (`shared`) |
| `setNodes(String)` | Static setter | Injects a CSV list of `host:port` cluster nodes at runtime |
| `setTenant(String)` | Static setter | Injects the tenant namespace at runtime |
| `getClusterNodes()` | Static getter | Returns a `Set<HostAndPort>` resolved via: programmatic value → `REDIS_NODES` env var → in-cluster defaults |
| `getTenant()` | Static getter | Returns the tenant namespace resolved via: programmatic value → `REDIS_TENANT` env var → `"shared"` |

**Resolution priority (both fields):**
1. Value set via `setNodes` / `setTenant`
2. `REDIS_NODES` / `REDIS_TENANT` environment variables
3. Hardcoded in-cluster defaults

## Usage Example

```java
// Injected by the host Spring service at startup
RedisConfig.setNodes(
    environment.getProperty("spring.data.redis.cluster.nodes")
);
RedisConfig.setTenant(
    environment.getProperty("openframe.redis.tenant-id", "shared")
);

// Used inside test helpers to build the auth-server key:
// of:{<tenant>}:pwdreset:<token>
Set<HostAndPort> nodes = RedisConfig.getClusterNodes();
String keyPrefix = "of:{" + RedisConfig.getTenant() + "}:pwdreset:";

JedisCluster jedis = new JedisCluster(nodes);
String token = jedis.get(keyPrefix + resetToken);
```

> **Standalone / CI runs:** Skip the `set*` calls and export `REDIS_NODES` and `REDIS_TENANT` as environment variables; the class falls back automatically.
