Static configuration holder for MongoDB connection settings, supporting two initialization modes: a full connection string injected by a host service, or discrete environment variables for standalone test runs.

## Key Components

| Member | Description |
|---|---|
| `setConnectionString(String)` | Injects a pre-built MongoDB URI from a host service (e.g., Spring Boot app) |
| `getConnectionString()` | Returns the injected connection string, or `null` if not set |
| `hasConnectionString()` | Guard check — returns `true` when a full URI is available |
| `getMongoDbUri()` | Lazily reads `MONGODB_URI` env var; throws if absent |
| `getDatabaseName()` | Lazily reads `MONGODB_DATABASE` env var; throws if absent |
| `getMongoUser()` | Lazily reads `MONGODB_USERNAME` env var; throws if absent |
| `getMongoPassword()` | Lazily reads `MONGODB_PASSWORD` env var; throws if absent |
| `getAuthDatabase()` | Lazily reads `MONGODB_AUTH_DATABASE` env var; throws if absent |

## Usage Example

**Embedded mode** (host service injects the URI):

```java
// Called once during host service startup
MongoConfig.setConnectionString(springMongoProperties.getUri());

// Downstream test code resolves the connection
if (MongoConfig.hasConnectionString()) {
    MongoClient client = MongoClients.create(MongoConfig.getConnectionString());
}
```

**Standalone mode** (env vars required):

```bash
export MONGODB_URI=mongodb://localhost:27017
export MONGODB_DATABASE=openframe_test
export MONGODB_USERNAME=admin
export MONGODB_PASSWORD=secret
export MONGODB_AUTH_DATABASE=admin
```

```java
// Falls back to env-var resolution automatically
String uri  = MongoConfig.getMongoDbUri();
String db   = MongoConfig.getDatabaseName();
MongoClient client = MongoClients.create(uri);
```

> **Note:** All env-var getters cache their value after the first read. A `RuntimeException` is thrown immediately if a required variable is missing, failing fast before any test execution begins.
