Centralized configuration class for resolving test environment URLs and credentials from environment variables or programmatic setup.

## Key Components

| Member | Type | Description |
|---|---|---|
| `OSS`, `DEV`, `STAGE`, `PROD` | Constants | Environment mode identifiers |
| `DEFAULT_BASE_URL`, `GRAPHQL`, `CHAT_GRAPHQL` | Constants | Default URL and API path constants |
| `configure(baseUrl, userDomain)` | Static method | Programmatically sets base URL and tenant domain, bypassing env var loading |
| `random()` | Static method | Generates a random `test-??????` tenant subdomain using Datafaker |
| `getEnvMode()` | Static method | Returns `TEST_ENV_MODE` env var value, defaulting to `DEV` |
| `getBaseUrl()` | Static method | Builds tenant-aware base URL; returns `https://localhost/` when domain contains `localhost` |
| `getAuthUrl()` | Static method | Returns auth endpoint URL from `TEST_BASE_URL` |
| `getUserDomain()` | Static method | Returns `localhost` in OSS mode, otherwise `{subdomain}.{baseDomain}` |
| `getTestUserDomain()` | Static method | Returns the raw tenant subdomain (e.g. `test-abcdef`) |
| `getRegistrationUrl()` | Static method | Returns registration URL, optionally appending `PORT` |
| `loadEnv()` | Private static | Lazy-loads `TEST_BASE_URL`, `TEST_USER_DOMAIN`, and `PORT` from environment variables; throws `RuntimeException` if required vars are missing |

## Usage Example

```java
// Option 1: Programmatic setup (e.g. local dev or unit tests)
EnvironmentConfig.configure("openframe.example.com", "test-tenant");

// Option 2: Random subdomain for isolated test runs
EnvironmentConfig.random();

// Option 3: Environment variable-driven (CI/CD)
// Requires TEST_BASE_URL and TEST_USER_DOMAIN to be set
// export TEST_BASE_URL=openframe.example.com
// export TEST_USER_DOMAIN=test-tenant
// export TEST_ENV_MODE=STAGE  (optional, defaults to DEV)

String baseUrl    = EnvironmentConfig.getBaseUrl();
// → "https://test-tenant.openframe.example.com/"

String graphqlUrl = EnvironmentConfig.getBaseUrl() + EnvironmentConfig.GRAPHQL;
// → "https://test-tenant.openframe.example.com/api/graphql"

String authUrl    = EnvironmentConfig.getAuthUrl();
// → "https://openframe.example.com/"

String domain     = EnvironmentConfig.getUserDomain();
// OSS mode  → "localhost"
// DEV mode  → "test-tenant.openframe.example.com"
```

> **Note:** `loadEnv()` is lazy and idempotent — environment variables are read only once. Calling `configure()` before any getter prevents env var lookup entirely.
