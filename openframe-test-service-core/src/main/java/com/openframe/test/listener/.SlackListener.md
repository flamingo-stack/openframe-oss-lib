A JUnit `TestExecutionListener` that aggregates test results across a test plan execution and posts a formatted summary report to Slack via `SlackClient`.

## Key Components

| Member | Description |
|---|---|
| `SlackListener(SlackClient)` | Constructor accepting a `SlackClient` dependency for posting results |
| `testPlanExecutionStarted(TestPlan)` | Resets counters and result list at the start of each test plan run |
| `executionStarted(TestIdentifier)` | Increments the test-found counter for each discovered test |
| `executionFinished(TestIdentifier, TestExecutionResult)` | Records per-test outcome (✅ success, ❌ failed/aborted) with emoji-prefixed display names |
| `executionSkipped(TestIdentifier, String)` | Records skipped tests with a cleaned-up skip reason |
| `sendResults(String tag, String domain, String baseUrl)` | Builds and dispatches a threaded Slack report with environment info, pass/fail status, and per-test details |
| `skipReason(String)` | Collapses JUnit's verbose `@Disabled` default message into `"Disabled"`; preserves custom reasons |
| `truncateMessage(String)` | Trims failure messages to the first line, capped at 300 characters |

## Usage Example

```java
SlackClient slackClient = new SlackClient(webhookUrl);
SlackListener listener = new SlackListener(slackClient);

LauncherDiscoveryRequest request = LauncherDiscoveryRequestBuilder.request()
        .selectors(selectPackage("com.openframe.test"))
        .build();

Launcher launcher = LauncherFactory.create();
launcher.discover(request);
launcher.registerTestExecutionListeners(listener);
launcher.execute(request);

// After execution, publish results to Slack
listener.sendResults("smoke", "acme", "openframe.ai");
```

The Slack report uses a two-message threaded format: a summary block (environment, tag, overall pass/fail circle) as the parent, and a detailed per-test breakdown as the thread reply.
