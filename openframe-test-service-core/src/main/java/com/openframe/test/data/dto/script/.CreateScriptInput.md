DTO representing the request payload for the `createScript` GraphQL mutation, with null fields automatically omitted to preserve server-side defaults.

## Key Components

| Field | Type | Description |
|---|---|---|
| `name` | `String` | Script display name |
| `description` | `String` | Optional script description |
| `shell` | `String` | Shell interpreter (e.g., `bash`, `powershell`) |
| `privilegeLevel` | `String` | Execution privilege level |
| `scriptBody` | `String` | Script source content |
| `supportedPlatforms` | `List<String>` | Target platforms (e.g., `windows`, `linux`) |
| `defaultTimeoutSeconds` | `Integer` | Execution timeout override |
| `defaultArgs` | `List<String>` | Default argument list |
| `envVars` | `List<ScriptEnvVar>` | Environment variable definitions |
| `tagIds` | `List<String>` | Tag association IDs |

**Key annotations:**
- `@JsonInclude(NON_NULL)` — null fields are excluded from serialization, leaving server defaults intact
- `@Builder` — fluent builder pattern for clean test data construction

## Usage Example

```java
CreateScriptInput input = CreateScriptInput.builder()
    .name("Restart Service")
    .shell("bash")
    .privilegeLevel("admin")
    .scriptBody("systemctl restart $1")
    .supportedPlatforms(List.of("linux"))
    .defaultTimeoutSeconds(60)
    .tagIds(List.of("tag-abc123"))
    .build();
```
