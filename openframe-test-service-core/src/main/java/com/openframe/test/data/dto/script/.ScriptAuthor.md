A lightweight DTO representing the author of a script, containing only the user fields selected by the scripts table query.

## Key Components

**`ScriptAuthor`** — Top-level DTO with the following fields:

| Field | Type | Description |
|---|---|---|
| `id` | `String` | Unique identifier of the author |
| `firstName` | `String` | Author's first name |
| `lastName` | `String` | Author's last name |
| `email` | `String` | Author's email address |
| `image` | `Image` | Nested avatar/profile image data |

**`ScriptAuthor.Image`** — Nested static DTO for profile image metadata:

| Field | Type | Description |
|---|---|---|
| `imageUrl` | `String` | URL of the author's profile image |
| `hash` | `String` | Image hash (e.g., for cache busting or blurhash) |

Both classes use Lombok (`@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor`) and `@JsonIgnoreProperties(ignoreUnknown = true)` for safe deserialization.

## Usage Example

```java
ScriptAuthor author = ScriptAuthor.builder()
    .id("user-123")
    .firstName("Jane")
    .lastName("Doe")
    .email("jane.doe@example.com")
    .image(ScriptAuthor.Image.builder()
        .imageUrl("https://cdn.example.com/avatars/jane.png")
        .hash("LKO2?U%2Tw=w")
        .build())
    .build();

String fullName = author.getFirstName() + " " + author.getLastName();
// → "Jane Doe"
```
