Provides static factory methods for building `DeviceFilterInput` query objects and extracting tool-specific identifiers from `Machine` devices in test scenarios.

## Key Components

| Method | Description |
|---|---|
| `onlineDevicesFilter()` | Returns a filter for `ONLINE` devices |
| `offlineDevicesFilter()` | Returns a filter for `OFFLINE` devices |
| `archivedDevicesFilter()` | Returns a filter for `ARCHIVED` devices |
| `osDevicesFilter(String os)` | Filters devices by OS type |
| `listedStatusesDevicesFilter()` | Filter covering all standard statuses (ONLINE, OFFLINE, ACTIVE, INACTIVE, MAINTENANCE, DECOMMISSIONED, PENDING) |
| `statDevicesFilter()` | Filter for stat-relevant statuses (excludes DECOMMISSIONED and PENDING) |
| `osAndStatusDevicesFilter(String os, DeviceStatus... statuses)` | Combines OS type and one or more statuses |
| `statusDevicesFilter(DeviceStatus... statuses)` | Varargs filter builder for arbitrary status combinations |
| `orgAndStatusDevicesFilter(String organizationId, DeviceStatus... statuses)` | Scopes filter to a specific organization and statuses |
| `getFleetId(Machine device)` | Extracts the `FLEET_MDM` agent tool ID from a device's tool connections |
| `getMeshId(Machine device)` | Extracts the `MESHCENTRAL` agent tool ID from a device's tool connections |

## Usage Example

```java
// Filter online Windows devices in a specific org
DeviceFilterInput filter = DeviceGenerator.osAndStatusDevicesFilter("WINDOWS", DeviceStatus.ONLINE);

// Get the Fleet MDM ID for a device
String fleetId = DeviceGenerator.getFleetId(machine);

// Get all devices across common operational statuses
DeviceFilterInput statFilter = DeviceGenerator.statDevicesFilter();
```
