A simple DTO (Data Transfer Object) used to capture input for deleting a ticket status, optionally specifying a replacement status for reassignment.

## Key Components

| Field | Type | Description |
|---|---|---|
| `id` | `String` | The ID of the ticket status to delete |
| `replacementStatusId` | `String` | Optional ID of the status to reassign existing tickets to |

**Annotations:**
- `@Data` — Generates getters, setters, `equals`, `hashCode`, and `toString`
- `@Builder` — Enables the builder pattern for construction
- `@NoArgsConstructor` / `@AllArgsConstructor` — Generates both default and full constructors
- `@JsonInclude(NON_NULL)` — Omits `null` fields during JSON serialization

## Usage Example

```java
// Using the builder pattern
DeleteTicketStatusInput input = DeleteTicketStatusInput.builder()
    .id("status-123")
    .replacementStatusId("status-456")
    .build();

// Delete without reassignment (replacementStatusId omitted from JSON output)
DeleteTicketStatusInput inputNoReplacement = DeleteTicketStatusInput.builder()
    .id("status-123")
    .build();
```

## Notes

- `replacementStatusId` is optional; when `null`, it is excluded from the serialized JSON payload due to `@JsonInclude(NON_NULL)`
- Typically used in test data layers within the OpenFrame OSS test suite
