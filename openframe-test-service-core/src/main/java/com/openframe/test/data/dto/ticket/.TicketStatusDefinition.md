A data transfer object (DTO) representing the definition of a ticket status within the OpenFrame platform, including its display properties and system classification.

## Key Components

| Field | Type | Description |
|---|---|---|
| `id` | `String` | Unique identifier for the status definition |
| `name` | `String` | Display name of the ticket status |
| `color` | `String` | Color associated with the status (e.g., hex code) |
| `position` | `String` | Ordering position within a status list |
| `kind` | `String` | Category or type classification of the status |
| `system` | `boolean` | Indicates if this is a system-managed status (`@JsonProperty("isSystem")`) |
| `systemKey` | `String` | Key used to identify predefined system statuses |

Lombok annotations (`@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor`) auto-generate getters, setters, builder pattern, and constructors.

## Usage Example

```java
// Build a custom ticket status definition
TicketStatusDefinition status = TicketStatusDefinition.builder()
    .id("status-001")
    .name("In Progress")
    .color("#FFA500")
    .position("2")
    .kind("active")
    .system(false)
    .systemKey(null)
    .build();

// Deserializes "isSystem": true from JSON into the boolean field
// {"id":"status-002","name":"Closed","isSystem":true,"systemKey":"closed"}
TicketStatusDefinition systemStatus = objectMapper.readValue(json, TicketStatusDefinition.class);
```
