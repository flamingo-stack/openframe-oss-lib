Represents the response payload returned after initiating a knowledge base attachment upload, containing the attachment metadata, a pre-signed upload URL, and any mutation errors.

## Key Components

| Field | Type | Description |
|---|---|---|
| `attachment` | `KnowledgeBaseItemAttachment` | Metadata for the created attachment object |
| `uploadUrl` | `String` | Pre-signed URL used to upload the attachment file |
| `userErrors` | `List<MutationError>` | Validation or mutation errors returned from the operation |

## Usage Example

```java
KnowledgeBaseAttachmentUploadPayload payload = KnowledgeBaseAttachmentUploadPayload.builder()
    .attachment(knowledgeBaseItemAttachment)
    .uploadUrl("https://storage.example.com/upload?token=abc123")
    .userErrors(List.of())
    .build();

if (payload.getUserErrors().isEmpty()) {
    String url = payload.getUploadUrl();
    // Proceed with file upload to url
} else {
    payload.getUserErrors().forEach(err -> System.err.println(err.getMessage()));
}
```

## Notes

- Annotated with `@JsonIgnoreProperties(ignoreUnknown = true)` to gracefully handle extra fields in API responses.
- Uses Lombok (`@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor`) to reduce boilerplate.
- Typically used in conjunction with a multipart or PUT request to the `uploadUrl` after the mutation succeeds.
