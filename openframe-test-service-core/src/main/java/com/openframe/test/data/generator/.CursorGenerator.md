Utility class for generating `CursorPaginationInput` objects used in cursor-based pagination test scenarios.

## Key Components

- **`limit(int limit)`** — Static factory method that creates a `CursorPaginationInput` instance configured with the specified page size limit.

## Usage Example

```java
// Create a cursor pagination input with a limit of 10 items
CursorPaginationInput pagination = CursorGenerator.limit(10);

// Use in a paginated query test
List<Item> results = itemService.findAll(pagination);
```

## Notes

- All methods are static; no instantiation required.
- Built on top of `CursorPaginationInput`'s builder pattern, making it easy to extend with additional cursor parameters (e.g., `after`, `before` tokens) in the future.
