Data Transfer Object (DTO) for providing input parameters when creating a temporary attachment in the Knowledge Base, capturing the file's metadata before upload.

## Key Components

| Field | Type | Description |
|---|---|---|
| `fileName` | `String` | Name of the file to be attached |
| `contentType` | `String` | MIME type of the file (e.g., `application/pdf`) |
| `fileSize` | `Long` | Size of the file in bytes |

## Usage Example

```java
CreateKnowledgeBaseTempAttachmentInput input = CreateKnowledgeBaseTempAttachmentInput.builder()
    .fileName("network-diagram.pdf")
    .contentType("application/pdf")
    .fileSize(204800L)
    .build();
```

> Unknown JSON fields are silently ignored via `@JsonIgnoreProperties(ignoreUnknown = true)`, making the DTO resilient to API response changes.
