A data transfer object (DTO) representing a temporary attachment record in the OpenFrame knowledge base, used to carry file metadata during upload workflows.

## Key Components

| Field | Type | Description |
|---|---|---|
| `id` | `String` | Unique identifier for the temporary attachment |
| `fileName` | `String` | Original name of the uploaded file |
| `contentType` | `String` | MIME type of the file |
| `fileSize` | `Long` | Size of the file in bytes |
| `uploadUrl` | `String` | Pre-signed or temporary URL used for uploading |
| `createdAt` | `String` | Timestamp of when the attachment record was created |

**Lombok annotations:** `@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor` auto-generate getters, setters, builder pattern, and constructors.

**`@JsonIgnoreProperties(ignoreUnknown = true)`** ensures forward compatibility by silently ignoring unrecognised JSON fields during deserialization.

## Usage Example

```java
// Build a TempAttachment using the Lombok builder
TempAttachment attachment = TempAttachment.builder()
    .id("att_abc123")
    .fileName("network-diagram.png")
    .contentType("image/png")
    .fileSize(204800L)
    .uploadUrl("https://storage.example.com/temp/att_abc123?token=xyz")
    .createdAt("2024-06-01T12:00:00Z")
    .build();

// Deserialize from JSON (unknown fields are safely ignored)
TempAttachment fromJson = objectMapper.readValue(jsonString, TempAttachment.class);
```
