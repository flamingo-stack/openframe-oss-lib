Data Transfer Object (DTO) representing a full ticket entity in the OpenFrame test suite, encapsulating all ticket metadata, relationships, and lifecycle timestamps.

## Key Components

| Field | Type | Description |
|---|---|---|
| `id` | `String` | Unique ticket identifier |
| `ticketNumber` | `Integer` | Human-readable ticket number |
| `title` / `description` | `String` | Ticket content fields |
| `status` | `String` | Raw status string |
| `statusDefinition` | `TicketStatusDefinition` | Structured status metadata |
| `owner` | `TicketOwner` | Ticket owner details |
| `assignedTo` / `assignedName` | `String` | Assignee identifiers |
| `assigneeImage` / `organizationImage` | `TicketImage` | Associated image references |
| `tags` | `List<TicketTag>` | Categorization tags |
| `dialog` | `TicketDialog` | Conversation/dialog thread |
| `attachments` | `List<TicketAttachment>` | File attachments |
| `notes` | `List<TicketNote>` | Internal notes |
| `createdAt` / `updatedAt` / `resolvedAt` | `Instant` | Lifecycle timestamps |

Lombok annotations (`@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor`) auto-generate boilerplate. `@JsonIgnoreProperties(ignoreUnknown = true)` ensures safe deserialization when the API returns undocumented fields.

## Usage Example

```java
Ticket ticket = Ticket.builder()
    .id("tkt-001")
    .ticketNumber(42)
    .title("Workstation unreachable")
    .status("OPEN")
    .organizationId("org-123")
    .organizationName("Acme Corp")
    .assignedTo("usr-456")
    .assignedName("Jane Doe")
    .createdAt(Instant.now())
    .build();

// Deserialize from API response
Ticket fromJson = objectMapper.readValue(apiResponse, Ticket.class);
```
