Represents the GraphQL mutation response payload for creating a temporary knowledge base attachment, wrapping the resulting `TempAttachment` object alongside any `MutationError` entries returned by the API.

## Key Components

| Field | Type | Description |
|---|---|---|
| `tempAttachment` | `TempAttachment` | The temporary attachment created by the mutation |
| `userErrors` | `List<MutationError>` | Validation or business logic errors returned by the server |

## Usage Example

```java
KnowledgeBaseTempAttachmentPayload payload = KnowledgeBaseTempAttachmentPayload.builder()
        .tempAttachment(new TempAttachment())
        .userErrors(List.of())
        .build();

if (payload.getUserErrors() != null && !payload.getUserErrors().isEmpty()) {
    payload.getUserErrors().forEach(error -> System.err.println(error.getMessage()));
} else {
    TempAttachment attachment = payload.getTempAttachment();
    // proceed with attachment
}
```

## Notes

- `@JsonIgnoreProperties(ignoreUnknown = true)` ensures forward compatibility when the API response includes additional fields not yet mapped in this DTO.
- Lombok annotations (`@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor`) eliminate boilerplate for getters, setters, and constructors.
- Part of the `com.openframe.test.data.dto.knowledgebase` package within the [openframe-oss-lib](https://github.com/flamingo-stack/openframe-oss-lib) test data layer.
