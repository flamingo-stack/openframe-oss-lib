Provides static query methods for retrieving `AuthUser` documents from the MongoDB `users` collection, supporting filtering by ID, status, role, or arbitrary field-value pairs.

## Key Components

| Method | Description |
|---|---|
| `findUser()` | Returns the first user document in the collection |
| `findUser(String id)` | Looks up a user by `_id` |
| `findUser(UserStatus status)` | Finds the first `ADMIN` user matching the given status |
| `findUser(UserRole role)` | Finds the first `ACTIVE` user matching the given role |
| `findUser(String field, String value)` | Generic field equality lookup |
| `findUser(UserStatus status, UserRole role)` | Finds the most recently created user matching both status and role |

> **Note:** The `findUser(UserStatus, UserRole)` overload sorts results by `createdAt` descending. This ensures that in reused test tenants where multiple users share the same status/role, the most recently created — and therefore still valid — user is returned.

## Usage Example

```java
// Get any user
AuthUser anyUser = UsersCollection.findUser();

// Get user by ID
AuthUser byId = UsersCollection.findUser("user-abc-123");

// Get the most recent active technician
AuthUser technician = UsersCollection.findUser(UserStatus.ACTIVE, UserRole.TECHNICIAN);

// Get the most recent active admin (role defaults to ADMIN)
AuthUser admin = UsersCollection.findUser(UserStatus.ACTIVE);

// Get by arbitrary field
AuthUser byEmail = UsersCollection.findUser("email", "jane@example.com");
```
