Provides MongoDB query utilities for retrieving invitation documents from the `invitations` collection, supporting lookups by email address or invitation status.

## Key Components

### `findInvitation(String email)`
Queries the `invitations` collection for a single document matching the provided email address. Returns the first result as an `Invitation` DTO or `null` if not found.

### `findInvitation(InvitationStatus status)`
Queries the `invitations` collection for a single document matching the provided `InvitationStatus` enum value. Results are sorted **descending by `createdAt`** to return the most recently created matching invitation — this prevents stale 404s on reused tenants where multiple invitations may share the same status across test runs.

## Usage Example

```java
// Look up an invitation by email
Invitation invite = InvitationsCollection.findInvitation("user@example.com");

// Look up the most recent pending invitation
Invitation pending = InvitationsCollection.findInvitation(InvitationStatus.PENDING);
if (pending != null) {
    System.out.println("Invite token: " + pending.getToken());
}
```

> **Note:** Both methods close the MongoDB connection via `closeConnection()` after each query. Ensure connection handling is consistent with the rest of the test data layer if queries are chained.
