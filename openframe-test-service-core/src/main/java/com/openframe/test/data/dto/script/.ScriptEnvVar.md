Represents a single script environment variable DTO used in OpenFrame test data, serving as both a response model and a `ScriptEnvVarInput` mutation payload for create/update operations.

## Key Components

| Field | Type | Description |
|---|---|---|
| `name` | `String` | Environment variable name |
| `value` | `String` | Environment variable value |
| `secret` | `Boolean` | Marks the variable as a secret (masked) |

**Annotations:**
- `@Data` / `@Builder` / `@NoArgsConstructor` / `@AllArgsConstructor` — Lombok-generated boilerplate
- `@JsonIgnoreProperties(ignoreUnknown = true)` — tolerates extra fields in API responses

## Usage Example

```java
// Build a plain env var
ScriptEnvVar apiUrl = ScriptEnvVar.builder()
    .name("API_URL")
    .value("https://api.example.com")
    .secret(false)
    .build();

// Build a secret env var (e.g. for a mutation payload)
ScriptEnvVar apiKey = ScriptEnvVar.builder()
    .name("API_KEY")
    .value("supersecret123")
    .secret(true)
    .build();
```

## Notes

- The class shape is intentionally identical to `ScriptEnvVarInput` in the GraphQL schema, so the same object can be deserialized from query responses and serialized as a mutation input without conversion.
