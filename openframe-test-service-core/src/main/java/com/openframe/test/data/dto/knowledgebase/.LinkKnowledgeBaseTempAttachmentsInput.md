Data Transfer Object (DTO) for linking temporary attachments to a knowledge base article, carrying the target article ID and a list of temporary attachment identifiers.

## Key Components

| Field | Type | Description |
|---|---|---|
| `articleId` | `String` | The ID of the target knowledge base article |
| `tempIds` | `List<String>` | List of temporary attachment IDs to link to the article |

## Usage Example

```java
// Build using Lombok builder
LinkKnowledgeBaseTempAttachmentsInput input = LinkKnowledgeBaseTempAttachmentsInput.builder()
    .articleId("kb-article-001")
    .tempIds(List.of("temp-123", "temp-456", "temp-789"))
    .build();

// Or via all-args constructor
LinkKnowledgeBaseTempAttachmentsInput input = new LinkKnowledgeBaseTempAttachmentsInput(
    "kb-article-001",
    List.of("temp-123", "temp-456")
);
```
