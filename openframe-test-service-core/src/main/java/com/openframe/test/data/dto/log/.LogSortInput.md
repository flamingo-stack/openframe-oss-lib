A lightweight DTO representing sorting parameters for log queries, encapsulating a sort field and direction.

## Key Components

| Member | Type | Description |
|--------|------|-------------|
| `field` | `String` | The log field to sort by (e.g., `"timestamp"`, `"level"`) |
| `direction` | `String` | Sort direction (e.g., `"ASC"` or `"DESC"`) |

**Lombok Annotations:**
- `@Data` — generates getters, setters, `equals`, `hashCode`, and `toString`
- `@Builder` — enables the builder pattern for fluent construction
- `@NoArgsConstructor` / `@AllArgsConstructor` — generates both default and full constructors
- `@JsonInclude(NON_NULL)` — omits `null` fields during JSON serialization

## Usage Example

```java
// Builder pattern
LogSortInput sort = LogSortInput.builder()
    .field("timestamp")
    .direction("DESC")
    .build();

// Constructor
LogSortInput sort = new LogSortInput("level", "ASC");

// Used in a log query
LogQueryInput query = LogQueryInput.builder()
    .sort(sort)
    .build();
```

## Notes

- Both fields are nullable; `null` values are excluded from serialized JSON output due to `@JsonInclude(NON_NULL)`.
- No enum constraint is enforced on `direction` at the DTO level — validate acceptable values (`ASC`/`DESC`) at the service layer.
