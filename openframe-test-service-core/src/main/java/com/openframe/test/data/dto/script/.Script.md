DTO representing a saved RMM script returned by the `scripts`/`script` GraphQL API in `openframe-api-service-core`.

## Key Components

| Field | Type | Description |
|---|---|---|
| `id` | `String` | Relay node ID |
| `name` | `String` | Script display name |
| `shell` | `String` | Shell type enum (e.g. `POWERSHELL`, `BASH`) |
| `privilegeLevel` | `String` | Execution privilege level |
| `scriptBody` | `String` | Raw script content |
| `supportedPlatforms` | `List<String>` | Platform enums (e.g. `WINDOWS`, `LINUX`) |
| `defaultTimeoutSeconds` | `Integer` | Execution timeout |
| `defaultArgs` | `List<String>` | Default argument values |
| `envVars` | `List<ScriptEnvVar>` | Environment variable definitions |
| `status` | `String` | Lifecycle status enum (e.g. `ACTIVE`) |
| `author` | `ScriptAuthor` | Script author metadata |

Lombok annotations (`@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor`) generate accessors, builder, and constructors. `@JsonIgnoreProperties(ignoreUnknown = true)` allows safe deserialization when the API adds new fields.

## Usage Example

```java
Script script = Script.builder()
    .id("U2NyaXB0OjE=")
    .name("Restart Service")
    .shell("POWERSHELL")
    .privilegeLevel("ADMIN")
    .scriptBody("Restart-Service -Name 'Spooler'")
    .supportedPlatforms(List.of("WINDOWS"))
    .defaultTimeoutSeconds(60)
    .status("ACTIVE")
    .author(ScriptAuthor.builder().id("author-1").name("Admin").build())
    .build();

String shell = script.getShell(); // "POWERSHELL"
```
