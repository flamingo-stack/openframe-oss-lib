Represents a single domain-level mutation error entry from a GraphQL mutation payload's `userErrors` array, mapping the shared `MutationError` type with `field` and `message` fields.

## Key Components

| Member | Type | Description |
|---|---|---|
| `field` | `List<String>` | Path to the field(s) that caused the error |
| `message` | `String` | Human-readable error description |

## Usage Example

```java
// Deserializing from a GraphQL mutation response
MutationError error = new MutationError(
    List.of("email"),
    "Email address is already in use."
);

// Checking for user errors after a mutation
List<MutationError> userErrors = mutationPayload.getUserErrors();
if (!userErrors.isEmpty()) {
    userErrors.forEach(e ->
        System.out.printf("Field %s: %s%n", e.getField(), e.getMessage())
    );
}
```

> **Note:** This is distinct from a top-level [`GraphqlError`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/test/data/dto/shared/GraphqlError.java) — `MutationError` represents business-logic validation failures returned inside the mutation payload, while `GraphqlError` covers transport/execution-level errors.
