Represents a tag key definition DTO used across entity types (`DEVICE`, `TICKET`, `KNOWLEDGE_ARTICLE`), mapping to the GraphQL `Tag` type. Named `TagDefinition` to avoid collision with JUnit's `@Tag` annotation.

## Key Components

| Field | Type | Description |
|---|---|---|
| `id` | `String` | Unique identifier for the tag definition |
| `key` | `String` | Tag key name |
| `description` | `String` | Human-readable description |
| `color` | `String` | Display color for UI rendering |
| `values` | `List<String>` | Allowed values for this tag key |
| `entityType` | `String` | Target entity type (`DEVICE`, `TICKET`, `KNOWLEDGE_ARTICLE`) |
| `createdAt` | `String` | Creation timestamp |

**Lombok annotations:** `@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor` — generates getters/setters, builder pattern, and both constructors.

**`@JsonIgnoreProperties(ignoreUnknown = true)`** — tolerates extra fields in GraphQL responses without failing deserialization.

## Usage Example

```java
// Build via Lombok builder
TagDefinition tag = TagDefinition.builder()
    .id("tag-001")
    .key("environment")
    .description("Deployment environment tier")
    .color("#FF5733")
    .values(List.of("production", "staging", "dev"))
    .entityType("DEVICE")
    .createdAt("2024-01-15T10:00:00Z")
    .build();

// Deserialize from GraphQL response
TagDefinition deserialized = objectMapper.readValue(graphqlJson, TagDefinition.class);
String entityType = deserialized.getEntityType(); // "TICKET"
```
