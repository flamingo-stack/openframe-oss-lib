A simple DTO used as input for delete mutation operations, carrying only the identifier of the resource to be deleted.

## Key Components

| Element | Description |
|---|---|
| `id` | The unique identifier of the resource targeted for deletion |
| `@Data` | Lombok annotation generating getters, setters, `equals`, `hashCode`, and `toString` |
| `@Builder` | Enables the builder pattern for object construction |
| `@NoArgsConstructor` / `@AllArgsConstructor` | Generates both no-arg and all-arg constructors |
| `@JsonIgnoreProperties` | Tolerates unknown JSON fields during deserialization |

## Usage Example

```java
// Build using the builder pattern
MutationDeleteInput input = MutationDeleteInput.builder()
    .id("resource-123")
    .build();

// Or via the all-args constructor
MutationDeleteInput input = new MutationDeleteInput("resource-456");

// Serialize to JSON (produces: {"id":"resource-123"})
String json = objectMapper.writeValueAsString(input);

// Deserialize from JSON
MutationDeleteInput input = objectMapper.readValue(
    "{\"id\": \"resource-123\"}",
    MutationDeleteInput.class
);
```

## Notes

- Lives in the `shared` package, making it reusable across multiple delete mutation test scenarios.
- `@JsonIgnoreProperties(ignoreUnknown = true)` ensures forward compatibility if the API response includes additional fields not defined in this DTO.
