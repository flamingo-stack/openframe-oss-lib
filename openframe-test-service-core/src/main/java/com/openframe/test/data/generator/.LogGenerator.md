Provides static factory methods for building log query objects used in test data generation, including filters and sort inputs for log-related GraphQL or API queries.

## Key Components

| Method | Description |
|---|---|
| `severityFilter(String severity)` | Creates a `LogFilterInput` with a single severity level (e.g., `"ERROR"`, `"WARN"`) |
| `timestampRangeFilter(String from, String to)` | Creates a `LogFilterInput` scoped to a timestamp range |
| `timestampSort(String direction)` | Creates a `LogSortInput` sorting by `TIMESTAMP` in the given direction (`"ASC"` / `"DESC"`) |
| `searchTerm(String summary)` | Extracts the first word from a summary string to use as a search keyword |

## Usage Example

```java
// Filter logs by severity
LogFilterInput errorFilter = LogGenerator.severityFilter("ERROR");

// Filter logs within a time range
LogFilterInput rangeFilter = LogGenerator.timestampRangeFilter(
    "2024-01-01T00:00:00Z",
    "2024-01-31T23:59:59Z"
);

// Sort logs by timestamp descending
LogSortInput sort = LogGenerator.timestampSort("DESC");

// Extract a search term from a log summary
String term = LogGenerator.searchTerm("Connection timeout occurred");
// Returns: "Connection"
```

## Notes

- All methods are `static` — no instantiation required.
- `severityFilter` wraps the value in a `List`, supporting the multi-value `severities` field on `LogFilterInput`.
- `searchTerm` uses a simple whitespace split; summaries with only one word return the full string.
