A simple DTO (Data Transfer Object) used to carry input data when creating a ticket status, supporting fields for the status name and display color.

## Key Components

| Field | Type | Description |
|-------|------|-------------|
| `name` | `String` | The display name of the ticket status |
| `color` | `String` | The color associated with the ticket status |

**Lombok Annotations:**
- `@Data` — Generates getters, setters, `equals`, `hashCode`, and `toString`
- `@Builder` — Enables the builder pattern for object construction
- `@NoArgsConstructor` / `@AllArgsConstructor` — Generates both default and full constructors
- `@JsonInclude(NON_NULL)` — Omits `null` fields during JSON serialization

## Usage Example

```java
// Builder pattern
CreateTicketStatusInput input = CreateTicketStatusInput.builder()
    .name("In Progress")
    .color("#FFA500")
    .build();

// All-args constructor
CreateTicketStatusInput input = new CreateTicketStatusInput("Resolved", "#00FF00");

// Serialized JSON output (null fields omitted)
// { "name": "In Progress", "color": "#FFA500" }
```

## Notes

- `null` fields are excluded from JSON serialization due to `@JsonInclude(NON_NULL)`, keeping API payloads clean when only partial data is provided.
- Typically consumed by ticket status creation endpoints within the OpenFrame test data layer.
