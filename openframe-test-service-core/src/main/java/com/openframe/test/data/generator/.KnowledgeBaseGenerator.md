Provides factory methods for generating test data DTOs used in Knowledge Base API tests, leveraging `Faker` for randomized values.

## Key Components

| Method | Description |
|---|---|
| `folderName()` | Generates a random QA test folder name |
| `rootFoldersFilter()` | Builds a filter input scoped to `FOLDER` type items |
| `draftArticle(parentFolderId)` | Creates a `CreateArticleInput` with `DRAFT` status and faker-generated content |
| `randomFolderName()` | Generates a random test folder name using a faker sentence |
| `updateArticleRequest(article)` | Builds an `UpdateArticleInput` from an existing `KnowledgeBaseItem`, appending `(edited)` to the name |
| `attachmentFile()` | Creates a temporary random file between 1–4096 bytes |
| `attachmentInput(articleId, file)` | Builds a `CreateKnowledgeBaseAttachmentInput` with `text/plain` content type |
| `tempAttachmentInput(file)` | Builds a `CreateKnowledgeBaseTempAttachmentInput` without an article ID |
| `linkTempAttachmentsInput(articleId, tempIds)` | Links a list of temp attachment IDs to an article |
| `deleteInput(id)` | Wraps an ID in a `MutationDeleteInput` |
| `deleteFolderArchivingChildren(folderId)` | Builds a `DeleteFolderInput` that archives child items on deletion |

## Usage Example

```java
// Create a draft article under a known folder
CreateArticleInput article = KnowledgeBaseGenerator.draftArticle("folder-123");

// Prepare and link a temp attachment
Path file = KnowledgeBaseGenerator.attachmentFile();
CreateKnowledgeBaseTempAttachmentInput tempInput = KnowledgeBaseGenerator.tempAttachmentInput(file);

// After upload, link temp attachment to article
LinkKnowledgeBaseTempAttachmentsInput linkInput =
    KnowledgeBaseGenerator.linkTempAttachmentsInput("article-456", List.of("temp-id-1"));

// Delete a folder and archive its children
DeleteFolderInput deleteFolder = KnowledgeBaseGenerator.deleteFolderArchivingChildren("folder-123");
```

## Notes

- All string fields use `net.datafaker.Faker` to ensure test isolation and avoid hardcoded values.
- `attachmentFile()` delegates to `FileUtils.createRandomFile()` for temp file creation.
