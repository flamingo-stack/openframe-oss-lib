A Data Transfer Object (DTO) representing the response payload returned after a delete mutation operation, containing the deleted record's ID and any associated user errors.

## Key Components

| Field | Type | Description |
|---|---|---|
| `deletedId` | `String` | The identifier of the successfully deleted record |
| `userErrors` | `List<MutationError>` | A list of user-facing errors encountered during the delete operation |

## Usage Example

```java
// Deserializing a delete mutation response
MutationDeletePayload payload = objectMapper.readValue(responseJson, MutationDeletePayload.class);

if (payload.getUserErrors() != null && !payload.getUserErrors().isEmpty()) {
    // Handle errors returned from the mutation
    payload.getUserErrors().forEach(error -> 
        System.out.println("Error: " + error.getMessage())
    );
} else {
    // Successfully deleted
    System.out.println("Deleted record ID: " + payload.getDeletedId());
}
```

## Notes

- Annotated with `@JsonIgnoreProperties(ignoreUnknown = true)` to safely handle additional fields in API responses without throwing deserialization errors.
- Lombok annotations (`@Data`, `@NoArgsConstructor`, `@AllArgsConstructor`) auto-generate boilerplate: getters, setters, constructors, `equals`, `hashCode`, and `toString`.
- Typically used in GraphQL or REST mutation test assertions within the OpenFrame test suite.
