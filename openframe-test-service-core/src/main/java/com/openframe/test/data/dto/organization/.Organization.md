A MongoDB document DTO representing a company or business entity in the OpenFrame system, capturing organizational metadata, contact details, revenue, contract lifecycle, and status tracking.

## Key Components

| Field | Type | Description |
|---|---|---|
| `id` | `String` | MongoDB BSON `ObjectId` (primary key) |
| `organizationId` | `String` | Application-level organization identifier |
| `name` | `String` | Organization display name |
| `category` | `String` | Business category/type |
| `numberOfEmployees` | `Integer` | Headcount |
| `contactInformation` | `ContactInformationDto` | Nested contact details |
| `monthlyRevenue` | `String` | Revenue figure |
| `contractStartDate` / `contractEndDate` | `LocalDate` | Contract period bounds |
| `isDefault` | `Boolean` | Marks the default organization |
| `createdAt` / `updatedAt` / `lastActivityAt` | `Instant` | Audit timestamps |
| `status` / `statusChangedAt` | `String` / `Instant` | Lifecycle status with change tracking |

**Annotations used:**
- `@BsonId` + `@BsonRepresentation(BsonType.OBJECT_ID)` — maps `id` to MongoDB's `_id` field
- `@JsonIgnoreProperties(ignoreUnknown = true)` — tolerates extra JSON fields during deserialization
- Lombok `@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor` — eliminates boilerplate

## Usage Example

```java
Organization org = Organization.builder()
    .organizationId("org-001")
    .name("Acme IT Services")
    .category("MSP")
    .numberOfEmployees(50)
    .monthlyRevenue("25000")
    .contractStartDate(LocalDate.of(2024, 1, 1))
    .contractEndDate(LocalDate.of(2025, 1, 1))
    .status("ACTIVE")
    .isDefault(false)
    .createdAt(Instant.now())
    .build();
```
