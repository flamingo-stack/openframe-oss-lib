Full-replacement (PUT) payload DTO for the `updateScript` GraphQL mutation, carrying all editable fields of a script resource including identity, execution configuration, and metadata.

## Key Components

| Field | Type | Description |
|---|---|---|
| `id` | `String` | Target script identifier (required for routing the update) |
| `name` | `String` | Human-readable script name (required) |
| `description` | `String` | Optional freetext description |
| `shell` | `String` | Shell/interpreter to use (required) |
| `privilegeLevel` | `String` | Execution privilege level (required) |
| `scriptBody` | `String` | Full script content (required) |
| `supportedPlatforms` | `List<String>` | Platform compatibility list |
| `defaultTimeoutSeconds` | `Integer` | Execution timeout override |
| `defaultArgs` | `List<String>` | Default argument list |
| `envVars` | `List<ScriptEnvVar>` | Environment variable definitions |
| `tagIds` | `List<String>` | Associated tag identifiers |

**Annotations:** Lombok `@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor`; `@JsonInclude(NON_NULL)` suppresses null fields during serialization.

## Usage Example

```java
UpdateScriptInput input = UpdateScriptInput.builder()
    .id("script-abc123")
    .name("Disk Cleanup")
    .shell("powershell")
    .privilegeLevel("admin")
    .scriptBody("Get-PSDrive -PSProvider FileSystem")
    .defaultTimeoutSeconds(120)
    .supportedPlatforms(List.of("windows"))
    .tagIds(List.of("tag-maintenance"))
    .build();
```

> **Note:** Null fields are excluded from the serialized JSON payload via `@JsonInclude(NON_NULL)`, so only explicitly set fields are sent in the mutation request.
