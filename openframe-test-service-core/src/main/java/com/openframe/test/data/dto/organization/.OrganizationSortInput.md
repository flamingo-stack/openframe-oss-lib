A DTO representing sort parameters for organization queries, encapsulating a field name and sort direction.

## Key Components

| Member | Type | Description |
|---|---|---|
| `field` | `String` | The organization field to sort by (e.g., `"name"`, `"createdAt"`) |
| `direction` | `String` | Sort direction (e.g., `"ASC"` or `"DESC"`) |

**Annotations:**
- `@Data` — Generates getters, setters, `equals`, `hashCode`, and `toString`
- `@Builder` — Enables fluent builder pattern construction
- `@NoArgsConstructor` / `@AllArgsConstructor` — Generates both default and full constructors
- `@JsonInclude(NON_NULL)` — Omits `null` fields during JSON serialization

## Usage Example

```java
// Using the builder
OrganizationSortInput sort = OrganizationSortInput.builder()
    .field("name")
    .direction("ASC")
    .build();

// Using the all-args constructor
OrganizationSortInput sort = new OrganizationSortInput("createdAt", "DESC");
```
