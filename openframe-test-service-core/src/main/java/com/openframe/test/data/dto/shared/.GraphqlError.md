Represents a top-level GraphQL error entry from the `errors` array of a GraphQL response, distinct from domain-level `userErrors`. Used in ticket lifecycle mutations (e.g., `transitionTicket`) to surface invalid transitions via extension codes.

## Key Components

| Field | Type | Description |
|---|---|---|
| `message` | `String` | Human-readable error message |
| `extensions` | `Map<String, Object>` | Structured metadata, e.g. `extensions.code = "TICKET_INVALID_TRANSITION"` |

**Annotations:**
- `@Data` / `@NoArgsConstructor` / `@AllArgsConstructor` — Lombok-generated boilerplate
- `@JsonIgnoreProperties(ignoreUnknown = true)` — Tolerates extra fields in the GraphQL response

## Usage Example

```java
// Deserializing a GraphQL response errors array
List<GraphqlError> errors = response.getErrors();

for (GraphqlError error : errors) {
    String code = (String) error.getExtensions().get("code");

    if ("TICKET_INVALID_TRANSITION".equals(code)) {
        // Handle invalid ticket state transition
        System.out.println("Transition failed: " + error.getMessage());
    }
}
```

## Notes

- This class maps to the **top-level** `errors` field in a GraphQL response payload, not the `data.*.userErrors` field used for domain validation.
- The `extensions` map is flexible by design — GraphQL servers may include arbitrary metadata such as `code`, `path`, or `timestamp`.
