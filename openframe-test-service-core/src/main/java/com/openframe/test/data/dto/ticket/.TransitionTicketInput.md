A simple DTO (Data Transfer Object) used to encapsulate the input required to transition a ticket from one status to another.

## Key Components

| Field | Type | Description |
|---|---|---|
| `ticketId` | `String` | The unique identifier of the ticket to transition |
| `toStatusId` | `String` | The target status ID to transition the ticket to |

**Annotations:**
- `@Data` — Generates getters, setters, `equals`, `hashCode`, and `toString`
- `@Builder` — Enables the builder pattern for object construction
- `@NoArgsConstructor` / `@AllArgsConstructor` — Generates both default and all-args constructors
- `@JsonInclude(NON_NULL)` — Excludes `null` fields from JSON serialization

## Usage Example

```java
// Using the builder pattern
TransitionTicketInput input = TransitionTicketInput.builder()
    .ticketId("TICKET-123")
    .toStatusId("STATUS-456")
    .build();

// Using the all-args constructor
TransitionTicketInput input = new TransitionTicketInput("TICKET-123", "STATUS-456");

// Typical usage in a test or API call
ticketService.transitionTicket(input);
```

## Notes

- `null` fields are omitted from JSON output due to `@JsonInclude(NON_NULL)`, keeping payloads clean in partial-update scenarios.
