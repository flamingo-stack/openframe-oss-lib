Generates test data for OAuth2 PKCE authentication flows, including code verifiers, code challenges, state parameters, and password reset request payloads.

## Key Components

| Member | Type | Description |
|---|---|---|
| `NEW_PASSWORD` | Constant | Placeholder password value for reset flow tests |
| `resetConfirmRequest(String token)` | Method | Builds a `ResetConfirmRequest` using the configured user password, ensuring subsequent logins remain valid after the reset flow |
| `invalidTokenResponse()` | Method | Returns a canned `ErrorResponse` for expired/invalid token scenarios |
| `clearedCookies()` | Method | Produces a map of blank cookie values (`access_token`, `refresh_token`, `JSESSIONID`) to simulate logout state |
| `generateAuthParts(User, String tenantId)` | Method | Assembles a complete `AuthParts` object with email, password, tenant ID, PKCE verifier/challenge pair, and state |
| `generateCodeVerifier()` | Private | Creates a cryptographically secure 32-byte URL-safe Base64 verifier |
| `generateCodeChallenge(String)` | Private | Derives the PKCE code challenge via SHA-256 hash of the verifier |
| `generateState()` | Private | Generates a secure 16-byte URL-safe Base64 state token |

## Usage Example

```java
// Build PKCE auth parts for an OAuth2 authorization request
User testUser = UserGenerator.defaultUser();
AuthParts authParts = AuthGenerator.generateAuthParts(testUser, "tenant-abc");

// Use in authorization request
String codeChallenge = authParts.getCodeChallenge(); // S256-hashed verifier
String state         = authParts.getState();          // CSRF protection token

// Build a password reset confirmation request
ResetConfirmRequest resetRequest = AuthGenerator.resetConfirmRequest(resetToken);

// Assert error shape for an expired token
ErrorResponse expected = AuthGenerator.invalidTokenResponse();
```

## Notes

- PKCE challenge method is implicitly **S256** (SHA-256); ensure the authorization server is configured to match.
- `resetConfirmRequest` intentionally resets back to the **configured** password (via `UserConfig.getPassword()`) rather than `NEW_PASSWORD`, keeping the test pipeline stateless across runs.
