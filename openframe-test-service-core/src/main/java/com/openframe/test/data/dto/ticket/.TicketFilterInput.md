A data transfer object (DTO) used to pass ticket filtering criteria — specifically status filters — into ticket query operations.

## Key Components

| Member | Type | Description |
|---|---|---|
| `statuses` | `List<String>` | Filter tickets by status name/label |
| `statusIds` | `List<String>` | Filter tickets by status identifier |

**Annotations:**
- `@Data` — Generates getters, setters, `equals`, `hashCode`, and `toString`
- `@Builder` — Enables the builder pattern for construction
- `@NoArgsConstructor` / `@AllArgsConstructor` — Generates both default and full constructors
- `@JsonInclude(NON_NULL)` — Omits `null` fields during JSON serialization

## Usage Example

```java
// Using the builder pattern
TicketFilterInput filter = TicketFilterInput.builder()
    .statuses(List.of("Open", "In Progress"))
    .statusIds(List.of("status-001", "status-002"))
    .build();

// Using the all-args constructor
TicketFilterInput filter = new TicketFilterInput(
    List.of("Closed"),
    List.of("status-003")
);

// Passing to a ticket query
List<Ticket> results = ticketService.getTickets(filter);
```

> **Note:** Both `statuses` and `statusIds` are optional. When `null`, they are excluded from the serialized JSON payload due to `@JsonInclude(NON_NULL)`, allowing partial filter inputs without polluting the request body.
