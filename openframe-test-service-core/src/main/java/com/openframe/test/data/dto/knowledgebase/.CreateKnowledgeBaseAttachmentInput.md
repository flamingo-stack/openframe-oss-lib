Data Transfer Object (DTO) representing the input payload for creating a knowledge base article attachment, encapsulating file metadata required for the upload operation.

## Key Components

| Field | Type | Description |
|---|---|---|
| `articleId` | `String` | ID of the parent knowledge base article |
| `fileName` | `String` | Name of the file being attached |
| `contentType` | `String` | MIME type of the attachment |
| `fileSize` | `Long` | Size of the file in bytes |

**Annotations:**
- `@Data` / `@Builder` / `@NoArgsConstructor` / `@AllArgsConstructor` — Lombok-generated boilerplate
- `@JsonIgnoreProperties(ignoreUnknown = true)` — tolerates extra JSON fields during deserialization

## Usage Example

```java
CreateKnowledgeBaseAttachmentInput input = CreateKnowledgeBaseAttachmentInput.builder()
    .articleId("article-abc123")
    .fileName("network-diagram.png")
    .contentType("image/png")
    .fileSize(204800L)
    .build();
```

## Notes

- Used in test data layer (`com.openframe.test.data.dto.knowledgebase`), so it primarily supports integration/API tests rather than production request handling.
- `fileSize` uses `Long` (boxed) to allow `null` values when size is unknown or not yet determined.
