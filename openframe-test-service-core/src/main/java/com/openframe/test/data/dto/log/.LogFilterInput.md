A DTO (Data Transfer Object) used to encapsulate filter criteria when querying log entries, supporting date ranges, event types, severities, and organizational scoping.

## Key Components

| Field | Type | Description |
|---|---|---|
| `startDate` | `String` | Start of the date range filter |
| `endDate` | `String` | End of the date range filter |
| `timestampFrom` | `String` | Precise timestamp lower bound |
| `timestampTo` | `String` | Precise timestamp upper bound |
| `eventTypes` | `List<String>` | Filter by specific event type identifiers |
| `toolTypes` | `List<String>` | Filter by tool/integration types |
| `severities` | `List<String>` | Filter by severity levels (e.g., `INFO`, `ERROR`) |
| `organizationIds` | `List<String>` | Scope results to specific organizations |
| `deviceId` | `String` | Filter logs for a single device |

**Annotations:**
- `@Data` / `@Builder` / `@NoArgsConstructor` / `@AllArgsConstructor` — Lombok-generated boilerplate
- `@JsonInclude(NON_NULL)` — Omits `null` fields during JSON serialization, keeping requests clean

## Usage Example

```java
LogFilterInput filter = LogFilterInput.builder()
    .startDate("2024-01-01")
    .endDate("2024-01-31")
    .severities(List.of("ERROR", "WARN"))
    .organizationIds(List.of("org-123", "org-456"))
    .deviceId("device-789")
    .build();
```

> **Note:** All fields are optional (`@JsonInclude(NON_NULL)` ensures unset fields are excluded from the serialized payload), allowing callers to compose only the filters relevant to their query.
