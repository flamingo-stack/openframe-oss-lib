A filter input DTO for querying organizations based on various criteria, used to pass filtering parameters in organization search or list requests.

## Key Components

| Field | Type | Description |
|---|---|---|
| `category` | `String` | Filter by organization category |
| `minEmployees` | `Integer` | Minimum employee count threshold |
| `maxEmployees` | `Integer` | Maximum employee count threshold |
| `hasActiveContract` | `Boolean` | Filter by active contract status |
| `status` | `String` | Filter by organization status |
| `lastActivityFrom` | `String` | Start date for last activity range |
| `lastActivityTo` | `String` | End date for last activity range |

**Annotations:**
- `@JsonInclude(NON_NULL)` — null fields are omitted from serialization, keeping filter payloads clean
- `@Builder` — supports fluent construction of partial filters
- `@Data` / `@NoArgsConstructor` / `@AllArgsConstructor` — standard Lombok boilerplate

## Usage Example

```java
// Build a filter for mid-sized orgs with active contracts
OrganizationFilterInput filter = OrganizationFilterInput.builder()
    .category("ENTERPRISE")
    .minEmployees(50)
    .maxEmployees(500)
    .hasActiveContract(true)
    .status("ACTIVE")
    .lastActivityFrom("2024-01-01")
    .lastActivityTo("2024-12-31")
    .build();

// Partial filter — null fields are excluded from JSON output
OrganizationFilterInput partialFilter = OrganizationFilterInput.builder()
    .status("PENDING")
    .hasActiveContract(false)
    .build();
```
