Provides cached access to Fleet MDM API resources (hosts, queries, and policies) using Spring Cache, supporting activity stream enrichment with lazy-initialized client and optional multi-tenancy.

## Key Components

| Member | Type | Description |
|---|---|---|
| `getAgentId(Integer hostId)` | `@Cacheable` | Returns the UUID of a Fleet host from cache or API; maps host IDs to agent identifiers |
| `getQueryById(Long queryId)` | `@Cacheable` | Fetches and caches a `Query` object by ID; returns `null` on deletion or API failure |
| `getPolicyById(Long policyId)` | `@Cacheable` | Fetches and caches a `Policy` wrapped in `Optional`; safe against deleted policies |
| `evictPolicyCache(Long policyId)` | `@CacheEvict` | Manually invalidates a policy cache entry on mutation events (e.g., `edited_policy`, `deleted_policy`) |
| `validateTenantConfig()` | `@PostConstruct` | Validates multi-tenancy configuration at startup via `FleetTenantHeader.validate()` |
| `getFleetMdmClient()` | private | Lazy-initializes `FleetMdmClient` using credentials from `IntegratedToolService`; returns `null` if unconfigured |

**Cache names:** `hostAgentCache`, `fleetQueryCache`, `fleetPolicyCache`

## Usage Example

```java
@Service
@RequiredArgsConstructor
public class FleetActivityEnricher {

    private final FleetMdmCacheService cacheService;

    public void enrich(FleetActivity activity) {
        // Resolve host UUID from host ID (cached after first call)
        String agentId = cacheService.getAgentId(activity.getHostId());

        // Resolve query name from query ID (cached)
        Query query = cacheService.getQueryById(activity.getQueryId());

        // Resolve policy (Optional-wrapped, cached)
        Optional<Policy> policy = cacheService.getPolicyById(activity.getPolicyId());

        // Invalidate policy cache after a mutation event
        cacheService.evictPolicyCache(activity.getPolicyId());
    }
}
```

## Configuration Properties

| Property | Description |
|---|---|
| `fleet.mdm.base-url` | Base URL of the Fleet MDM server |
| `TENANT_ID` | Tenant identifier for multi-tenant deployments (optional) |
| `openframe.fleet.multi-tenancy.enabled` | Enables multi-tenancy header validation (default: `false`) |
