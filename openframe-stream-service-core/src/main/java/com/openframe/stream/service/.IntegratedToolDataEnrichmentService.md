Enriches deserialized Debezium messages from integrated tools with machine, organization, and tenant context by querying Redis caches and resolving tenant identity for both shared and dedicated cluster deployments.

## Key Components

| Member | Type | Description |
|---|---|---|
| `getExtraParams(DeserializedDebeziumMessage)` | `IntegratedToolEnrichedData` | Entry point; orchestrates machine and tenant enrichment, returning a populated `IntegratedToolEnrichedData` object |
| `enrichFromMachine(...)` | `private void` | Looks up `CachedMachineInfo` by `agentId` via `MachineIdCacheService`, then resolves the parent `CachedOrganizationInfo` to populate machine ID, hostname, and organization fields |
| `enrichFromTenant(...)` | `private void` | Resolves `tenantId` using either `TenantIdProvider` (dedicated tenant cluster) or `ClusterTenantIdResolver` (shared cluster, e.g. MeshCentral domain mapping) |
| `getType()` | `DataEnrichmentServiceType` | Returns `INTEGRATED_TOOLS_EVENTS`, identifying this service within the `DataEnrichmentService` strategy registry |
| `ClusterTenantIdResolver` | `@Autowired(required = false)` | Optional bean; absence signals a single-tenant cluster where `TenantIdProvider` is used directly |

## Usage Example

```java
// Injected automatically as a DataEnrichmentService<DeserializedDebeziumMessage> bean
@Autowired
private IntegratedToolDataEnrichmentService enrichmentService;

DeserializedDebeziumMessage message = debeziumConsumer.deserialize(rawEvent);

IntegratedToolEnrichedData enriched = enrichmentService.getExtraParams(message);

// Downstream processing with resolved context
log.info("Tenant: {}, Machine: {}, Org: {}",
    enriched.getTenantId(),
    enriched.getMachineId(),
    enriched.getOrganizationName());
```

> **Note:** If `agentId` is absent or has no Redis cache entry, machine/organization fields are left unpopulated and a `WARN` log is emitted. Null messages return an empty `IntegratedToolEnrichedData` without throwing.
