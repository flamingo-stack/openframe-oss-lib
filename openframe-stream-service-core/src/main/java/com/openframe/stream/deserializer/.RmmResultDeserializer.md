Abstract base deserializer for OpenFrame native RMM execution results (commands and scripts) consumed from Debezium CDC events published by the client-service.

## Key Components

| Member | Type | Description |
|--------|------|-------------|
| `RmmResultDeserializer` | Abstract class | Extends `IntegratedToolEventDeserializer`; shared extraction logic for both command and script execution results |
| `getTenantId` | Method | Extracts `tenantId` from the Debezium `after` node |
| `getAgentId` | Method | Extracts `machineId` as the agent identifier |
| `getEventToolId` | Method | Composes a composite `executionId:machineId` correlation key |
| `getResult` | Method | Builds a JSON object containing `output`, `exit_code`, and `execution_time_ms` from stdout |
| `getError` | Method | Builds a JSON error object when `timedOut`, non-zero `exitCode`, `stderr`, or `error` fields are present |
| `getDetails` | Method | Builds a JSON details object with `exit_code`, `execution_time_ms`, and `timed_out` |
| `getSourceEventType` | Abstract method | Implemented by subclasses to return `COMMAND_EXECUTED` or `SCRIPT_EXECUTED` |
| `getMessage` | Abstract method | Implemented by subclasses to supply a human-readable message |

## Usage Example

```java
// Concrete subclass for command execution results
public class CommandResultDeserializer extends RmmResultDeserializer {

    public CommandResultDeserializer(ObjectMapper mapper) {
        super(mapper);
    }

    @Override
    protected Optional<String> getSourceEventType(JsonNode after) {
        return Optional.of("COMMAND_EXECUTED");
    }

    @Override
    protected Optional<String> getMessage(JsonNode after) {
        return parseStringField(after, "stdout");
    }
}
```

Concrete subclasses are bound to their respective `MessageType` routing key (`COMMAND_EXECUTED` / `SCRIPT_EXECUTED`), which is the only structural difference between command and script result handling downstream.
