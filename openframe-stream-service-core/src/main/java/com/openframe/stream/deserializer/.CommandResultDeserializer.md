Deserializer that binds the shared `RmmResultDeserializer` logic to the `COMMAND_EXECUTED` message type, handling result payloads for native OpenFrame commands.

## Key Components

| Member | Description |
|---|---|
| `getType()` | Returns `MessageType.COMMAND_EXECUTED` to register this deserializer for command result messages |
| `getSourceEventType()` | Always returns `SourceEventTypes.Rmm.CMD_RUN_FINISHED` |
| `getMessage()` | Builds a human-readable status string from `exitCode` / `timedOut` fields |
| `FIELD_EXIT_CODE` | JSON field name `"exitCode"` |
| `FIELD_TIMED_OUT` | JSON field name `"timedOut"` |

## Routing Behaviour

All command results are fanned out to **every** registered sink without per-message routing decisions:

- Generic event log + Pinot (surfaces in the Logs UI alongside script results)
- Cassandra `command_results` table
- MongoDB `CommandExecution` write-back

Correlation on `(machineId, executionId)` is handled downstream by each sink.

## Usage Example

```java
// Spring auto-wires the component; manual construction for illustration:
ObjectMapper mapper = new ObjectMapper();
CommandResultDeserializer deserializer = new CommandResultDeserializer(mapper);

// Identify which Kafka message type this handles
MessageType type = deserializer.getType();
// → MessageType.COMMAND_EXECUTED

// Build a display message from a raw CDC "after" node
JsonNode after = mapper.readTree("""
    { "exitCode": "0", "timedOut": "false" }
    """);

Optional<String> msg = deserializer.getMessage(after);
// → Optional["Command finished (exit code 0)"]

JsonNode timedOutNode = mapper.readTree("""
    { "timedOut": "true" }
    """);

Optional<String> timedOutMsg = deserializer.getMessage(timedOutNode);
// → Optional["Command timed out"]
```
