Represents a deserialized Debezium CDC (Change Data Capture) event enriched with OpenFrame fleet-specific metadata for downstream stream processing.

## Key Components

**Class:** `DeserializedDebeziumMessage extends CommonDebeziumMessage`

| Field | Type | Description |
|---|---|---|
| `unifiedEventType` | `UnifiedEventType` | Normalized event classification across integrated tools |
| `ingestDay` | `String` | Partition/routing key for day-based ingestion |
| `toolEventId` | `String` | Original event ID from the source integrated tool |
| `agentId` | `String` | Identifier of the agent that produced the event |
| `sourceEventType` | `String` | Raw event type string from the originating tool |
| `integratedToolType` | `IntegratedToolType` | Enum identifying the source MSP tool (e.g., ConnectWise, HaloPSA) |
| `debeziumMessage` | `String` | Raw serialized Debezium payload |
| `eventTimestamp` | `Long` | Epoch timestamp of the original event |
| `skipProcessing` | `Boolean` | Flag to bypass downstream processing logic |
| `isVisible` | `Boolean` | Controls event visibility in the unified feed |
| `tenantId` | `String` | Multi-tenant isolation identifier |
| `excludedDestinations` | `Set<Destination>` | Destinations to skip during event routing |

## Usage Example

```java
DeserializedDebeziumMessage message = DeserializedDebeziumMessage.builder()
    .tenantId("tenant-abc")
    .agentId("agent-001")
    .unifiedEventType(UnifiedEventType.TICKET_CREATED)
    .integratedToolType(IntegratedToolType.CONNECTWISE)
    .toolEventId("CW-98765")
    .eventTimestamp(System.currentTimeMillis())
    .ingestDay("2025-01-15")
    .skipProcessing(false)
    .isVisible(true)
    .excludedDestinations(Set.of(Destination.EMAIL))
    .build();
```

## Notes

- Extends `CommonDebeziumMessage` via `@SuperBuilder`, inheriting base Debezium envelope fields (offset, partition, op type).
- `excludedDestinations` enables per-event routing control without modifying global destination configuration.
