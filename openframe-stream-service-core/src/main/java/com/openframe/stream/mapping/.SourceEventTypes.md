Defines string constants for event types emitted by integrated MSP tools, organized as nested interfaces per source system to enable type-safe event routing in the OpenFrame stream mapping layer.

## Key Components

| Interface | Description |
|---|---|
| `SourceEventTypes.Rmm` | OpenFrame native RMM events (command/script execution) |
| `SourceEventTypes.MeshCentral` | MeshCentral remote management events (server, user, node, relay, mesh group) |
| `SourceEventTypes.Fleet` | Fleet MDM events covering the full device lifecycle and platform management |

## Usage Example

```java
// Route an incoming event by source type
public void handleEvent(String tool, String eventType, EventPayload payload) {
    if (SourceEventTypes.MeshCentral.NODE_ADD.equals(eventType)) {
        deviceService.registerNode(payload);
    } else if (SourceEventTypes.Fleet.MDM_ENROLLED.equals(eventType)) {
        mdmService.onDeviceEnrolled(payload);
    } else if (SourceEventTypes.Rmm.SCRIPT_RUN_FINISHED.equals(eventType)) {
        automationService.onScriptCompleted(payload);
    }
}

// Use in a switch/pattern mapper
switch (eventType) {
    case SourceEventTypes.Fleet.LOCKED_HOST   -> hostService.lock(payload);
    case SourceEventTypes.Fleet.WIPED_HOST    -> hostService.wipe(payload);
    case SourceEventTypes.Fleet.UNLOCKED_HOST -> hostService.unlock(payload);
}
```

## Notes

- All constants are plain `String` values matching the raw event type strings emitted by each tool's webhook or API.
- `MeshCentral` includes a small set of standalone events (e.g., `SCAN_AMT_DEVICE`, `WS_SESSION_COUNT`) that arrive without an `etype` field — handle these separately from the structured event categories.
- Add new tool integrations as additional nested interfaces (e.g., `interface Halo { ... }`) to keep constants isolated per source.
