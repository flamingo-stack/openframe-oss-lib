Translates tool-specific event type strings from integrated MSP tools (MeshCentral, Fleet MDM, RMM) into a canonical `UnifiedEventType` for normalized event processing across the OpenFrame platform.

## Key Components

### `mapToUnifiedType(IntegratedToolType, String)`
Primary public method. Looks up a unified event type using a composite key of `toolName:sourceEventType`. Returns `UnifiedEventType.UNKNOWN` if no mapping is registered, with debug logging for both hit and miss cases.

### `registerMapping(IntegratedToolType, String, UnifiedEventType)`
Private static helper that stores a `toolDbName:sourceEventType → UnifiedEventType` entry in the internal `HashMap`. Emits an `INFO`-level log on each registration.

### `initializeDefaultMappings()` (static initializer)
Bulk-registers all built-in mappings at class load time, organized by tool and event category:

| Tool | Categories |
|---|---|
| `RMM` | Command/script execution results |
| `MeshCentral` | User, mesh, node, relay, user-group, server events |
| `Fleet MDM` | Auth, user management, device enrollment, policies, queries, teams, agent options |

## Usage Example

```java
// Resolve a MeshCentral node addition to its unified type
UnifiedEventType type = EventTypeMapper.mapToUnifiedType(
    IntegratedToolType.MESHCENTRAL,
    SourceEventTypes.MeshCentral.NODE_ADD
);
// Returns UnifiedEventType.DEVICE_REGISTERED

// Unmapped event falls back to UNKNOWN
UnifiedEventType unknown = EventTypeMapper.mapToUnifiedType(
    IntegratedToolType.MESHCENTRAL,
    "some.unknown.event"
);
// Returns UnifiedEventType.UNKNOWN
```

## Notes

- The mapping table is static and initialized once at class load; extend `initializeDefaultMappings()` or add a public `registerMapping` overload to support dynamic tool integrations.
- Source event type constants are co-located in `SourceEventTypes` inner classes per tool, keeping string literals out of call sites.
- See the full source at [`flamingo-stack/openframe-oss-lib`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/stream/mapping/EventTypeMapper.java).
