A `MessageHandler` implementation that processes Debezium CDC events and persists command execution results to a Cassandra `command_results` table. Active only when `CassandraRepository` is on the classpath and `spring.data.cassandra.enabled=true`.

## Key Components

| Member | Description |
|---|---|
| `getType()` | Returns `EventHandlerType.COMMON_TYPE` — registers as a general-purpose handler |
| `getDestination()` | Returns `Destination.CASSANDRA_COMMAND_RESULT` — routes messages to this handler |
| `handle(...)` | Extracts the `after` payload from a Debezium message, builds a result JSON blob, and saves a `CommandResult` row via `CommandResultRepository` |
| `buildResultJson(JsonNode)` | Packs agent result fields (`stdout`, `stderr`, `exitCode`, `executionTimeMs`, `timedOut`, `error`) into a serialized JSON string |
| `putText/putInt/putLong/putBool` | Null-safe helpers that coerce `JsonNode` fields into typed values on the output `ObjectNode` |

**TTL note:** No per-write TTL is set; expiry relies on the Cassandra table's `default_time_to_live`.

## Usage Example

```java
// Spring auto-wires this handler when Cassandra is enabled.
// To activate, set in application.properties:
spring.data.cassandra.enabled=true

// The handler is discovered via MessageHandler routing by destination:
Destination.CASSANDRA_COMMAND_RESULT

// Incoming Debezium payload example (after field):
// {
//   "executionId": "exec-123",
//   "machineId":   "machine-456",
//   "stdout":      "OK",
//   "stderr":      "",
//   "exitCode":    0,
//   "executionTimeMs": 420,
//   "timedOut":    false,
//   "error":       null
// }

// On a valid message the handler saves one CommandResult row:
CommandResult row = new CommandResult();
row.setKey(new CommandResult.CommandResultKey(executionId, machineId));
row.setResult(buildResultJson(after));
commandResultRepository.save(row);
```
