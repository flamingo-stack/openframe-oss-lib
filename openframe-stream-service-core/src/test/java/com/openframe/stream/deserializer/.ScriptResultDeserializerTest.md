Unit test suite for `ScriptResultDeserializer`, verifying script name resolution, message formatting, fallback behavior, and routing metadata for the `SCRIPT_EXECUTED` event type.

## Key Components

| Test | What It Verifies |
|---|---|
| `getTypeIsScriptExecuted` | `getType()` returns `MessageType.SCRIPT_EXECUTED` |
| `sourceEventTypeIsScriptRunFinished` | Source event maps to `SourceEventTypes.Rmm.SCRIPT_RUN_FINISHED` |
| `inheritsResultExtraction` | `getResult()` correctly maps `stdout`, `exitCode`, `executionTimeMs` |
| `getMessage_resolvesNameViaScript_returnsFormattedSummary` | Happy path: resolves name via `executionId → scriptId → Script.name`, returns `"Script <name> executed."` |
| `getMessage_alsoForFailedRuns` | Message format is exit-code-invariant (`exitCode != 0` still produces formatted summary) |
| `getMessage_rowMissing_fallsBackToGeneric` | Missing `ScriptExecution` row returns `"Script executed"` without querying `ScriptRepository` |
| `getMessage_scriptMissing_fallsBackToGeneric` | Hard-deleted `Script` document falls back gracefully |
| `getMessage_missingIdentifiers_fallsBackWithoutMongoCall` | Missing `tenantId`/`executionId` falls back without any Mongo calls |
| `getMessage_mongoFailure_fallsBackQuietly` | Repository exception is swallowed to protect the Kafka consumer thread |
| `getMessage_blankScriptName_fallsBackToGeneric` | Blank/empty `Script.name` triggers fallback |
| `getMessage_nullScriptId_fallsBackToGeneric` | Null `scriptId` on execution row falls back without querying `ScriptRepository` |

## Usage Example

```java
// Minimal wiring under test
ScriptResultDeserializer deserializer = new ScriptResultDeserializer(
    mapper,
    scriptExecutionRepository,
    scriptRepository
);

// Happy-path getMessage invocation
ObjectNode after = mapper.createObjectNode()
    .put("tenantId", "tenant-1")
    .put("executionId", "exec-1")
    .put("exitCode", 0);

when(scriptExecutionRepository.findFirstByTenantIdAndExecutionId("tenant-1", "exec-1"))
    .thenReturn(Optional.of(ScriptExecution.builder().scriptId("script-1").build()));
when(scriptRepository.findByTenantIdAndId("tenant-1", "script-1"))
    .thenReturn(Optional.of(scriptWithName("disk usage")));

assertThat(deserializer.getMessage(after)).contains("Script disk usage executed.");
```

## Notes

- Script name is resolved **at read time** via a two-hop lookup (`executionId → ScriptExecution.scriptId → Script.name`); it is not snapshotted on the execution row.
- All failure modes (missing row, deleted script, null/blank name, missing identifiers, Mongo exception) converge on the generic `"Script executed"` fallback — the deserializer must never throw inside a Kafka consumer thread.
- `getResult()` field mapping is shared with `CommandResultDeserializer` via inheritance and is verified here as a regression guard.
