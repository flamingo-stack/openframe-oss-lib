Unit tests for `CommandResultDeserializer`, validating how RMM agent `CommandExecutionResult` payloads are parsed and mapped into unified result/error/details JSON structures.

## Key Components

| Test Method | What It Validates |
|---|---|
| `typeAndSourceEventType()` | Deserializer type is `COMMAND_EXECUTED`; source event is always `CMD_RUN_FINISHED` |
| `idsExtraction()` | `agentId` maps to `machineId`; `eventToolId` combines `executionId:machineId` for batch uniqueness |
| `eventToolId_distinctPerMachineWithinBatch()` | Two machines sharing an `executionId` produce distinct event IDs (prevents `unified_logs` collisions) |
| `tenantIdExtraction()` | `tenantId` read from payload; absent returns empty |
| `timestampExtraction()` | `eventTimestamp` parsed as `long`; absent returns empty |
| `message()` | Priority: timed out → exit code → generic fallback |
| `result()` | Builds `output`/`exit_code`/`execution_time_ms`; returns `null` when no relevant fields present |
| `error()` | `null` on clean success (`exit 0`, no stderr/error/timeout); populated otherwise |
| `details()` | Extracts `exit_code`/`execution_time_ms`/`timed_out`; `null` when absent |
| `nonNumericExitCodeFallsBackToString()` | Non-numeric `exitCode` (e.g. `"n/a"`) is preserved as a string via `putIntOrString` |

## Usage Example

```java
// Instantiate (same package — exercises package-private hooks directly)
CommandResultDeserializer deserializer = new CommandResultDeserializer(new ObjectMapper());

ObjectNode after = mapper.createObjectNode()
    .put("machineId",       "machine-42")
    .put("executionId",     "exec-1")
    .put("exitCode",        0)
    .put("stdout",          "Hello\n")
    .put("executionTimeMs", 150L);

// agentId → "machine-42"
Optional<String> agentId = deserializer.getAgentId(after);

// eventToolId → "exec-1:machine-42"  (unique per machine within a batch)
Optional<String> eventToolId = deserializer.getEventToolId(after);

// result JSON → { "output": "Hello\n", "exit_code": 0, "execution_time_ms": 150 }
String resultJson = deserializer.getResult(after);

// error → null (exit 0, no stderr, not timed out)
String errorJson = deserializer.getError(after);
```
