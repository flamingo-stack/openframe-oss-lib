Unit tests for `CommandResultCassandraMessageHandler`, verifying that incoming Debezium CDC messages are correctly transformed and persisted as `CommandResult` rows in Cassandra.

## Key Components

| Component | Description |
|---|---|
| `savesPackedResult()` | Asserts a full payload is saved with correct composite key `(executionId, machineId)` and that string-encoded fields (`exitCode`, `executionTimeMs`, `timedOut`) are coerced to their proper JSON types |
| `missingExecutionId_shortCircuits()` | Asserts the handler short-circuits without writing anything when `executionId` is absent from the payload |
| `fullAfter()` | Builds a realistic `after` node simulating how Debezium delivers numeric/boolean fields as raw strings |
| `message(ObjectNode)` | Wraps an `after` node into a `DeserializedDebeziumMessage` for handler input |

## Usage Example

```java
// Arrange
CommandResultCassandraMessageHandler handler =
    new CommandResultCassandraMessageHandler(commandResultRepository, mapper);

ObjectNode after = mapper.createObjectNode();
after.put("executionId", "exec-1");
after.put("machineId", "machine-1");
after.put("stdout", "hello");
after.put("exitCode", "0");       // string from Debezium → typed by handler
after.put("timedOut", "false");   // string from Debezium → typed by handler

DebeziumMessage.Payload<JsonNode> payload = new DebeziumMessage.Payload<>();
payload.setAfter(after);
DeserializedDebeziumMessage msg = DeserializedDebeziumMessage.builder()
    .payload(payload).build();

// Act
handler.handle(msg, null);

// Assert — verify composite key and typed JSON result
ArgumentCaptor<CommandResult> captor = ArgumentCaptor.forClass(CommandResult.class);
verify(commandResultRepository).save(captor.capture());
assertThat(captor.getValue().getKey().getExecutionId()).isEqualTo("exec-1");
```

## Notes

- String-to-typed coercion (`"0"` → `int`, `"false"` → `boolean`) is a key contract under test; reflect any changes to this logic in `fullAfter()`.
- The defensive short-circuit test relies on `verifyNoInteractions`, ensuring no partial writes occur on malformed payloads.
