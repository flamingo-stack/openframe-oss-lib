Reactive BFF (Backend-for-Frontend) service that orchestrates the OAuth 2.0 Authorization Code flow with PKCE for the OpenFrame gateway, handling authorization redirects, callback processing, token exchange, refresh, and revocation.

## Key Components

| Method | Description |
|--------|-------------|
| `buildAuthorizeRedirect` | Generates PKCE verifier/challenge, state token, and the full authorization URL for redirecting the user to the auth server |
| `handleCallback` | Validates the OAuth state cookie, exchanges the authorization code for tokens, and resolves the post-login redirect target |
| `exchangeCodeForTokens` | Back-channel `POST /oauth2/token` call using `authorization_code` grant with PKCE verifier |
| `refreshTokensPublic` | Refreshes tokens for a known `tenantId` using the `refresh_token` grant |
| `refreshTokensByLookup` | Best-effort token refresh that resolves `tenantId` from MongoDB when it is not available in the calling context — returns `Mono.empty()` on failure |
| `revokeRefreshToken` | Revokes a refresh token against the auth server (body truncated in source) |
| `validateAndExtractCookieData` | Decodes the JWT stored in the `of_oauth_<state>` cookie and validates state binding |
| `extractUserId` | Parses the `userId` claim from the freshly issued access token without signature verification (trusted back-channel path) |

## Usage Example

```java
// Build the authorization redirect (called from the BFF controller)
Mono<AuthorizeData> authorize = oAuthBffService.buildAuthorizeRedirect(
    "acme",          // tenantId
    "/dashboard",    // post-login destination
    "google",        // identity provider hint
    false,           // not a mobile auth flow
    serverRequest
);

// Handle the callback after the user returns from the IdP
Mono<OAuthCallbackResult> result = oAuthBffService.handleCallback(
    code,   // authorization code from query param
    state,  // state value from query param
    serverRequest
);

// Refresh an existing session (tenantId known)
Mono<TokenResponse> refreshed = oAuthBffService.refreshTokensPublic(
    "acme",
    refreshToken,
    serverRequest
);

// Refresh without tenantId (resolved via MongoDB lookup)
Mono<TokenResponse> refreshedByLookup = oAuthBffService.refreshTokensByLookup(
    refreshToken,
    serverRequest
);
```

## Configuration

The service is activated only when `openframe.gateway.oauth.enable=true`. Required properties:

```text
openframe.auth.server.url          # Base URL of the authorization server
openframe.auth.server.authorize-url # Authorization endpoint base URL
openframe.gateway.oauth.client-id
openframe.gateway.oauth.client-secret
openframe.gateway.oauth.redirect-uri
```
