A reactive Spring WebFlux REST controller implementing the Backend-for-Frontend (BFF) OAuth 2.0 pattern, handling login initiation, authorization callbacks, token refresh, logout, and mobile/dev token exchange for the OpenFrame gateway.

## Key Components

| Endpoint | Method | Description |
|---|---|---|
| `GET /oauth/login` | `login()` | Initiates OAuth flow with PKCE/state; clears existing SAS cookies and redirects to the authorization server |
| `GET /oauth/continue` | `continueFlow()` | Starts OAuth authorize redirect without clearing cookies; used in post-SSO "continue" flows |
| `GET /oauth/callback` | `callback()` | Handles the authorization server callback, exchanges code for tokens, sets auth cookies |
| `POST /oauth/refresh` | `refresh()` | Refreshes tokens via cookie or header; supports both tenant-aware and lookup-based refresh |
| `GET /oauth/logout` | `logout()` | Clears auth cookies and revokes the refresh token at the authorization server |
| `GET /oauth/dev-exchange` | `devExchange()` | Consumes a one-time dev/mobile ticket and returns tokens as response headers |

**Supporting helpers:**
- `buildStateJwt` / `addOAuthStateCookie` — PKCE state management via signed JWT cookie
- `computeTargetWithOptionalDevTicketReactive` — appends a short-lived dev ticket to the redirect URL for mobile flows
- `addDevHeaders` — injects raw access/refresh token headers for native clients

**Conditional activation:** Enabled only when `openframe.gateway.oauth.enable=true`.

## Usage Example

```java
// Trigger login flow (browser redirect)
// GET /oauth/login?tenantId=acme&redirectTo=/dashboard&provider=google

// Token refresh from a mobile client (sends Refresh-Token header)
// POST /oauth/refresh
// Header: Refresh-Token: <token>

// Exchange a dev ticket for tokens (mobile/dev environments)
// GET /oauth/dev-exchange?ticket=abc123
// Response headers: Access-Token, Refresh-Token
```

**Configuration properties:**

```yaml
openframe:
  gateway:
    oauth:
      enable: true
      state-cookie-ttl-seconds: 180
      dev-ticket-enabled: true
      mobile-auth-enabled: true
  auth:
    error-url: https://app.example.com/auth-error
```
