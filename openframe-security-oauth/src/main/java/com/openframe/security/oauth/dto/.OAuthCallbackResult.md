Immutable data transfer object representing the result of an OAuth callback operation, bundling tenant context, redirect destination, token payload, and mobile authentication flag.

## Key Components

| Field | Type | Description |
|---|---|---|
| `tenantId` | `String` | Identifier of the tenant associated with the OAuth callback |
| `redirectTo` | `String` | URL to redirect the user to after successful authentication |
| `tokens` | `TokenResponse` | Access/refresh token payload returned from the OAuth provider |
| `authMobile` | `boolean` | Indicates whether the authentication flow originated from a mobile client |

## Usage Example

```java
TokenResponse tokens = new TokenResponse(accessToken, refreshToken, expiresIn);

OAuthCallbackResult result = new OAuthCallbackResult(
    "tenant-abc123",
    "/dashboard",
    tokens,
    false
);

String destination = result.redirectTo();
boolean isMobile   = result.authMobile();
```

> Being a Java `record`, all fields are immutable and accessor methods are auto-generated (e.g., `result.tenantId()`, `result.tokens()`). No explicit getters or constructors are needed.
