Configures the MongoDB infrastructure layer for the OpenFrame data module, activating only when `spring.data.mongodb.enabled=true` and running before Spring's default `MongoDataAutoConfiguration`.

## Key Components

| Component | Description |
|---|---|
| `@ConditionalOnProperty` | Guards the entire configuration — MongoDB beans are only registered when the property is explicitly set to `true` |
| `@AutoConfigureBefore` | Ensures this config runs before `MongoDataAutoConfiguration` so the custom converter takes precedence |
| `@EnableMongoAuditing` | Activates Spring Data auditing (`@CreatedDate`, `@LastModifiedDate`, etc.) for MongoDB documents |
| `@Import(MongoCustomConversionsConfig.class)` | Pulls in custom type converters defined in the companion config class |
| `mappingMongoConverter` | The primary bean — builds a `MappingMongoConverter` with custom conversions and replaces `.` in map keys with `__dot__` to avoid MongoDB field-name conflicts |

## Usage Example

```java
// application.yml — enable the MongoDB infrastructure
// spring:
//   data:
//     mongodb:
//       enabled: true
//       uri: mongodb://localhost:27017/openframe

// A document using auditing fields activated by @EnableMongoAuditing
@Document(collection = "devices")
public class DeviceDocument {

    @Id
    private String id;

    // Map field — dots in keys will be stored as "__dot__"
    private Map<String, Object> metadata;

    @CreatedDate
    private Instant createdAt;

    @LastModifiedDate
    private Instant updatedAt;
}
```

> **Note:** The `__dot__` key replacement (`converter.setMapKeyDotReplacement("__dot__")`) is important when storing `Map<String, Object>` fields whose keys may contain `.` characters — MongoDB rejects dotted field names natively.
