Activates MongoDB repository scanning for tenant-isolated sync operations when both MongoDB and tenant isolation are enabled in the application configuration.

## Key Components

- **`TenantAwareSyncConfig`** — Spring `@Configuration` class that conditionally enables MongoDB repositories under `com.openframe.data.repository` only when both `spring.data.mongodb.enabled` and `openframe.tenant-isolation.enabled` resolve to `true`.

## Conditional Activation

| Property | Default | Required Value |
|---|---|---|
| `spring.data.mongodb.enabled` | `false` | `true` |
| `openframe.tenant-isolation.enabled` | `false` | `true` |

Both conditions must be satisfied simultaneously; if either is absent or `false`, the configuration is skipped entirely.

## Usage Example

```yaml
# application.yml
spring:
  data:
    mongodb:
      enabled: true
      uri: mongodb://localhost:27017/openframe

openframe:
  tenant-isolation:
    enabled: true
```

```java
// Repositories in this package are auto-registered when conditions are met
package com.openframe.data.repository;

import org.springframework.data.mongodb.repository.MongoRepository;

public interface TenantSyncRepository extends MongoRepository<SyncRecord, String> {
    // tenant-scoped queries
}
```

> **Note:** This config acts as a guard — disabling either flag in non-multi-tenant or non-MongoDB deployments prevents unwanted repository wiring without requiring code changes.
