Configures synchronous (non-reactive) MongoDB repositories for OpenFrame when standard MongoDB is enabled and tenant isolation is **not** active.

## Key Components

| Element | Description |
|---|---|
| `@ConditionalOnExpression` | Activates only when `spring.data.mongodb.enabled=true` **and** `openframe.tenant-isolation.enabled=false` |
| `@EnableMongoRepositories` | Scans `com.openframe.data.repository` for standard Spring Data MongoDB repositories |
| `excludeFilters` | Excludes any repository annotated with `@TenantAwareRepository` to prevent conflicts with the tenant-isolated configuration |

## Usage Example

Enable this configuration via `application.properties` or `application.yml`:

```yaml
spring:
  data:
    mongodb:
      enabled: true
      uri: mongodb://localhost:27017/openframe

openframe:
  tenant-isolation:
    enabled: false  # Must be false for MongoSyncConfig to activate
```

Repositories in the scanned package will be auto-registered unless annotated with `@TenantAwareRepository`:

```java
// Picked up by MongoSyncConfig
public interface DeviceRepository extends MongoRepository<Device, String> { }

// Excluded — handled by tenant-aware config instead
@TenantAwareRepository
public interface TenantDeviceRepository extends MongoRepository<Device, String> { }
```

## Notes

- Mutually exclusive with any tenant-isolation MongoDB config — only one is active at runtime based on the conditional expression.
- See [`MongoTenantConfig`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/data/config/MongoTenantConfig.java) for the counterpart configuration when `openframe.tenant-isolation.enabled=true`.
