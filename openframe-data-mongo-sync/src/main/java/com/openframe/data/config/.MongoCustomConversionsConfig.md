Defines the single `MongoCustomConversions` bean for the library, ensuring Spring Data MongoDB has exactly one conversions registration to avoid ambiguity errors on context startup.

## Key Components

- **`mongoCustomConversions` (Bean)** — Creates and configures the `MongoCustomConversions` instance by always registering `LocalDateUtcMongoConverters` (UTC date handling) and then applying any additional `MongoConversionsContributor` beans discovered in the application context via `ObjectProvider`.

## Usage Example

To extend converters without introducing a second `MongoCustomConversions` bean, publish a `MongoConversionsContributor`:

```java
@Configuration
public class MyModuleMongoConfig {

    @Bean
    public MongoConversionsContributor myConverters() {
        return adapter -> adapter.registerConverters(List.of(
            new MyCustomReadConverter(),
            new MyCustomWriteConverter()
        ));
    }
}
```

The contributor is automatically picked up and applied by `MongoCustomConversionsConfig` during context initialization — no changes to the core config required.

> **Note:** Never define a second `MongoCustomConversions` bean. Spring Data allows only one; a duplicate will fail context startup with an ambiguity error. Always use `MongoConversionsContributor` for additions.
