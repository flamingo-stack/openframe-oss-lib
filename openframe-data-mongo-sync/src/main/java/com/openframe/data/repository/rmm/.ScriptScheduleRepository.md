Spring Data MongoDB repository interface for `ScriptSchedule` documents, providing tenant-scoped CRUD operations and scheduling queries for the RMM (Remote Monitoring and Management) module.

## Key Components

| Method | Description |
|---|---|
| `findByTenantIdAndId` | Fetches a single schedule by tenant and document ID |
| `findByTenantIdAndIdIn` | Batch-fetches schedules by a collection of IDs within a tenant |
| `findByTenantIdAndName` | Looks up a schedule by its unique name within a tenant |
| `existsByTenantIdAndNameAndStatusIn` | Checks for name conflicts across specified statuses (useful for create validation) |
| `existsByTenantIdAndNameAndIdNotAndStatusIn` | Same conflict check but excludes a specific ID (useful for update validation) |
| `findByStatusAndNextRunAtLessThanEqual` | Retrieves all schedules due for execution at or before a given `Instant` cutoff |

**Extends:**
- `MongoRepository<ScriptSchedule, String>` — standard Spring Data CRUD
- `CustomScriptScheduleRepository` — cursor-style pagination via `MongoTemplate`

## Usage Example

```java
// Fetch a tenant-scoped schedule by ID
Optional<ScriptSchedule> schedule = scriptScheduleRepository
    .findByTenantIdAndId("tenant-123", "schedule-abc");

// Validate name uniqueness before update (exclude self)
boolean nameConflict = scriptScheduleRepository
    .existsByTenantIdAndNameAndIdNotAndStatusIn(
        "tenant-123",
        "Nightly Patch Run",
        "schedule-abc",
        List.of(ScriptStatus.ACTIVE, ScriptStatus.PAUSED)
    );

// Poll for schedules due now or overdue
Instant now = Instant.now();
List<ScriptSchedule> dueSchedules = scriptScheduleRepository
    .findByStatusAndNextRunAtLessThanEqual(ScriptStatus.ACTIVE, now);
```

## Notes

- All tenant-facing queries are explicitly scoped by `tenantId` — no cross-tenant data leakage.
- Pagination and list operations are handled by `CustomScriptScheduleRepository`. See [`ScriptRepository`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/data/repository/rmm/ScriptRepository.java) for the mirrored pattern.
