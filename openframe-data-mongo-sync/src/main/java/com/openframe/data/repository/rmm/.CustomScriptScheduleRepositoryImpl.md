Custom MongoDB repository implementation for `ScriptSchedule` pagination, filtering, faceting, and counting. Provides cursor-based keyset pagination with compound `(sortField, _id)` cursors to handle tie-breaking across repeated sort values.

## Key Components

| Method | Description |
|---|---|
| `findPageForTenant` | Main paginated query; dispatches to aggregation pipeline when sorting by `deviceCount` |
| `findPageAggregatedByDeviceCount` | Aggregation-based page fetch joining the `script_schedules_machines_assigned` collection to compute live device counts |
| `countForTenant` | Returns the total matching document count for a given filter/search combination |
| `buildBaseCriteria` | Shared predicate builder (tenant scope + status/platform/author filters + text search) |
| `platformFacet` / `authorFacet` | Aggregation-based facet counts for filter dropdowns; each excludes its own field so all values remain selectable |
| `applyCursor` | Injects keyset cursor bounds (`$gt`/`$lt`) into the query criteria |
| `appendDeviceCountCursor` | Parses compound `count|id` cursor and injects `$or` match stage into the aggregation pipeline |

**Sortable fields:** `_id`, `name`, `createdAt`, `updatedAt`, `repeat`, `deviceCount`

## Usage Example

```java
// Forward page, sorted by name ascending, with a filter and search term
List<ScriptSchedule> page = repo.findPageForTenant(
    "tenant-123",
    ScriptScheduleQueryFilter.builder()
        .statuses(List.of(ScriptStatus.ACTIVE))
        .platforms(List.of("windows"))
        .build(),
    "patch",          // search
    "name",           // sortField
    Sort.Direction.ASC,
    null,             // cursor — first page
    false,            // backward
    25                // limit
);

// Cursor for the next page is encoded from the last item's sortField value + _id
// e.g. "DailyPatch|664a1f2e8b3c4d5e6f7a8b9c"

long total = repo.countForTenant("tenant-123", filter, "patch");

Map<String, Integer> platforms = repo.platformFacet("tenant-123", filter);
// → {"windows": 12, "linux": 5, "macos": 3}
```

## Notes

- Backward pagination flips `sortDirection` and reverses `$gt`/`$lt` comparison operators.
- An invalid or unparseable cursor is logged as a warning and silently falls back to first-page behavior.
- Soft-deleted schedules (`ScriptStatus.DELETED`) are excluded by default unless an explicit status filter is provided.
