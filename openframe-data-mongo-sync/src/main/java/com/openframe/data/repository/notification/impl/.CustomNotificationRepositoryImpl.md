Tenant-aware MongoDB implementation of `CustomNotificationRepository` that provides cursor-based paginated notification queries for a specific recipient, supporting read-state filtering, text search, and bidirectional navigation.

## Key Components

| Member | Description |
|---|---|
| `findPageForRecipient(...)` | Main entry point; resolves effective sort direction and delegates to read-state and notification fetches |
| `fetchReadStates(...)` | Queries `NotificationReadState` collection with all filters applied; returns an ordered map of `notificationId → ReadStatus` |
| `fetchNotificationsPreservingOrder(...)` | Fetches full `Notification` documents by ID and reassembles them in the original cursor order |
| `effectiveDirection(...)` | Flips sort direction when `backward = true` to support bidirectional pagination |
| `applyStatusFilter(...)` | Adds a `status` criterion: excludes `DELETED` (null filter), matches `READ`, or matches `UNREAD` |
| `applyCursor(...)` | Adds a `lt`/`gt` bound on `notificationId` depending on sort direction |
| `applySearch(...)` | Appends a case-insensitive regex filter on the `title` field |

The class is activated only when `openframe.tenant-isolation.enabled=true` and extends `TenantAwareRepositorySupport` to automatically scope every query to the current tenant.

## Usage Example

```java
// Fetch the first page of unread notifications, newest first
NotificationPage page = repository.findPageForRecipient(
    "user-123",           // recipientId
    RecipientType.USER,   // recipientType
    false,                // readFilter: false = UNREAD only
    null,                 // no search term
    null,                 // no cursor (first page)
    false,                // forward navigation
    Sort.Direction.DESC,  // newest first
    20                    // page size
);

// Fetch the next page using the last notification ID as cursor
NotificationPage nextPage = repository.findPageForRecipient(
    "user-123",
    RecipientType.USER,
    false,
    null,
    "64f1a2b3c4d5e6f7a8b9c0d1", // cursor from previous page
    false,
    Sort.Direction.DESC,
    20
);
```
