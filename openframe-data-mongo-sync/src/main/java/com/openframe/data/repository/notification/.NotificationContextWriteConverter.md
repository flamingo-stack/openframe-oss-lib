A Spring Data `@WritingConverter` that serializes `NotificationContext` objects into MongoDB `Document` instances using Jackson, enabling polymorphic notification context storage in BSON format.

## Key Components

| Element | Description |
|---|---|
| `@WritingConverter` | Registers this converter in the Spring Data MongoDB write pipeline |
| `convert(NotificationContext)` | Serializes a `NotificationContext` to a BSON `Document` via Jackson JSON |
| `ObjectMapper` | Injected Jackson mapper used for JSON serialization |

## Usage Example

```java
// Registered automatically via Spring Data MongoDB configuration
@Configuration
public class MongoConfig extends AbstractMongoClientConfiguration {

    @Bean
    public NotificationContextWriteConverter notificationContextWriteConverter(ObjectMapper objectMapper) {
        return new NotificationContextWriteConverter(objectMapper);
    }

    @Override
    protected void configureConverters(MongoCustomConversions.MongoConverterConfigurationAdapter adapter) {
        adapter.registerConverter(notificationContextWriteConverter(objectMapper));
    }
}

// The converter is invoked transparently when saving a document
// containing a NotificationContext field:
NotificationContext ctx = new AlertNotificationContext("ALERT", "Disk usage critical");
notificationRepository.save(new Notification(ctx));
// ctx is automatically converted → Document.parse(jackson.writeValueAsString(ctx))
```

## Error Handling

If Jackson fails to serialize the `NotificationContext`, an `IllegalStateException` is thrown with the failing context's `type` field included in the message, making it easier to diagnose polymorphic serialization issues.

## Notes

- Null inputs return `null` safely without throwing.
- Pairs with a corresponding `NotificationContextReadConverter` for the full read/write lifecycle.
