Custom MongoDB repository interface for advanced ticket querying and bulk operations beyond standard Spring Data capabilities.

## Key Components

| Method | Description |
|---|---|
| `buildTicketQuery(...)` | Constructs a MongoDB `Query` from a `TicketQueryFilter`, with optional full-text search, ID restriction, and machine owner scoping |
| `findTicketsWithCursor(...)` | Cursor-based paginated ticket retrieval with configurable sort field and direction |
| `countTickets(Query)` | Returns total count matching an arbitrary query |
| `countTicketsByStatus()` | Aggregates ticket counts grouped by `TicketStatus` |
| `countTicketsByStatusKind()` | Aggregates ticket counts grouped by `TicketStatusKind` |
| `countTicketsByStatusId()` | Aggregates ticket counts grouped by status ID string |
| `getTotalCount()` | Returns the overall ticket count across all statuses |
| `getAverageResolutionTimeMs()` | Computes average resolution time in milliseconds |
| `updateStatusBulk(...)` | Bulk-transitions all tickets from one status to another |
| `reassignTicketsToStatus(...)` | Reassigns tickets matching a status ID (or query) to a new status ID and kind |
| `updateTitle(...)` | Updates the title of a single ticket by ID |
| `isSortableField(String)` | Validates whether a field name is allowed for sorting |
| `getDefaultSortField()` | Returns the default sort field name |

## Usage Example

```java
// Build a filtered query and paginate with cursor
Query query = ticketRepository.buildTicketQuery(
    filter, "network issue", List.of("t1", "t2"), "machine-abc"
);

List<Ticket> page = ticketRepository.findTicketsWithCursor(
    query, lastCursorId, 25, "createdAt", "DESC"
);

// Bulk status transition (e.g., auto-close resolved tickets)
int updated = ticketRepository.updateStatusBulk(resolvedStatus, closedStatus);

// Reassign tickets when a custom status is deleted
ticketRepository.reassignTicketsToStatus(
    deletedStatusId, defaultStatusId, TicketStatusKind.OPEN
);

// Aggregated dashboard metrics
Map<TicketStatusKind, Long> kindCounts = ticketRepository.countTicketsByStatusKind();
Optional<Long> avgResolution = ticketRepository.getAverageResolutionTimeMs();
```

## Notes

- Implemented alongside a Spring Data `MongoRepository` via the standard `Custom` suffix pattern.
- `buildTicketQuery` provides a default overload that omits search, ID restriction, and machine scoping for simple filter-only use cases.
