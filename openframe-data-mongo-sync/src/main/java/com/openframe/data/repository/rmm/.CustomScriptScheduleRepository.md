Custom MongoTemplate-backed repository interface for querying and paginating [`ScriptSchedule`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/data/document/rmm/ScriptSchedule.java) documents, providing cursor-based pagination, filtering, faceting, and sort utilities outside of Spring Data derived methods.

## Key Components

| Method | Description |
|---|---|
| `findPageForTenant` | Returns a paginated list of `ScriptSchedule` documents for a tenant using cursor-based navigation with filter, search, sort, and direction support |
| `countForTenant` | Returns the total count of schedules matching a tenant's filter and search criteria |
| `platformFacet` | Aggregates schedule counts grouped by platform for a given tenant and filter |
| `authorFacet` | Aggregates schedule counts grouped by author for a given tenant and filter |
| `isSortableField` | Validates whether a given field name is permitted as a sort key |
| `getDefaultSortField` | Returns the default field used for sorting when none is specified |
| `encodeCursor` | Builds the raw (pre-base64) cursor string for a `ScriptSchedule` row under the active sort field |

## Usage Example

```java
// Paginate script schedules for a tenant
List<ScriptSchedule> page = customScriptScheduleRepository.findPageForTenant(
    "tenant-abc",
    new ScriptScheduleQueryFilter(),
    "nightly backup",
    "createdAt",
    Sort.Direction.DESC,
    null,   // no cursor = first page
    false,
    25
);

// Count total matches
long total = customScriptScheduleRepository.countForTenant(
    "tenant-abc",
    new ScriptScheduleQueryFilter(),
    "nightly backup"
);

// Retrieve facet breakdown by platform
Map<String, Integer> platforms = customScriptScheduleRepository.platformFacet(
    "tenant-abc",
    new ScriptScheduleQueryFilter()
);

// Encode cursor for the next page
String cursor = customScriptScheduleRepository.encodeCursor(page.get(page.size() - 1), "createdAt");
```

> **Implementation note:** Backed by `CustomScriptScheduleRepositoryImpl` using `MongoTemplate` directly. Mirrors [`CustomScriptRepository`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/data/repository/rmm/CustomScriptRepository.java) but omits shell/tag facets.
