Defines the custom repository interface for time entry data access operations beyond standard Spring Data MongoDB queries, providing cursor-based pagination, aggregation, and filtering capabilities.

## Key Components

| Method | Description |
|---|---|
| `buildTimeEntryQuery` | Constructs a MongoDB `Query` from a `TimeEntryQueryFilter` |
| `findTimeEntriesWithCursor` | Fetches paginated time entries using cursor-based navigation with sort control |
| `countTimeEntries` | Returns total count for a given query |
| `sumDurationSeconds` | Aggregates total duration (in seconds) for completed entries, scoped by users, organizations, and time range |
| `countCompletedEntries` | Counts completed entries filtered by users, organizations, and time range |
| `countDistinctActiveDays` | Returns the number of distinct days with activity for the given scope |
| `sumDurationSecondsByTicketIds` | Returns a map of ticket ID → total duration in seconds |
| `isSortableField` | Validates whether a given field name is allowed for sorting |
| `getDefaultSortField` | Returns the default sort field name |

## Usage Example

```java
// Build a filtered query and paginate results
Query query = customTimeEntryRepository.buildTimeEntryQuery(filter);

List<TimeEntry> entries = customTimeEntryRepository.findTimeEntriesWithCursor(
    query,
    "cursor-token-abc123",
    25,
    "startTime",
    "DESC"
);

// Aggregate duration for a user set within a time range
long totalSeconds = customTimeEntryRepository.sumDurationSeconds(
    List.of("user-1", "user-2"),
    List.of("org-1"),
    Instant.parse("2024-01-01T00:00:00Z"),
    Instant.parse("2024-01-31T23:59:59Z")
);

// Per-ticket duration rollup
Map<String, Long> ticketDurations = customTimeEntryRepository
    .sumDurationSecondsByTicketIds(List.of("TICK-101", "TICK-202"));
```

## Notes

- Pass `null` or empty lists for `userIds`/`organizationIds` to query all users in the tenant or skip org filtering respectively.
- Implementations are typically backed by `MongoTemplate` in a `CustomTimeEntryRepositoryImpl`.
