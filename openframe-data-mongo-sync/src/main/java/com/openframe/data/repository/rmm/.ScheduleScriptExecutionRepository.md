Spring Data MongoDB repository interface for `ScheduleScriptExecution` header documents, providing CRUD operations and a tenant-scoped lookup by execution ID.

## Key Components

| Element | Description |
|---|---|
| `MongoRepository<ScheduleScriptExecution, String>` | Inherits full CRUD + pagination support for the `ScheduleScriptExecution` document |
| `findByTenantIdAndExecutionId` | Derived query returning an `Optional` header row matching a specific tenant and execution ID |

## Usage Example

```java
@Service
public class ScheduleScriptExecutionService {

    private final ScheduleScriptExecutionRepository repository;

    public ScheduleScriptExecutionService(ScheduleScriptExecutionRepository repository) {
        this.repository = repository;
    }

    public ScheduleScriptExecution getExecution(String tenantId, String executionId) {
        return repository.findByTenantIdAndExecutionId(tenantId, executionId)
                .orElseThrow(() -> new EntityNotFoundException(
                        "Execution not found: " + executionId));
    }
}
```

## Notes

- Stores **header-level** records only — one document per schedule fire. Per-(script, machine) leaf rows are managed separately via `ScriptExecutionRepository`.
- The `tenantId` scope on the query enforces multi-tenant data isolation.
