Spring Data MongoDB repository interface for managing `IntegratedToolAgent` documents, providing CRUD operations and custom query methods for tool agent lifecycle management.

## Key Components

| Method | Return Type | Description |
|---|---|---|
| `findByStatus(ToolAgentStatus status)` | `List<IntegratedToolAgent>` | Retrieves all tool agents matching a given status |
| `findByReleaseVersionTrue()` | `List<IntegratedToolAgent>` | Retrieves all tool agents flagged as release versions |
| `findByKey(String key)` | `Optional<IntegratedToolAgent>` | Looks up a single tool agent by its unique key |

Inherits full CRUD operations from `MongoRepository<IntegratedToolAgent, String>`.

## Usage Example

```java
@Service
public class ToolAgentService {

    private final IntegratedToolAgentRepository repository;

    public ToolAgentService(IntegratedToolAgentRepository repository) {
        this.repository = repository;
    }

    public List<IntegratedToolAgent> getActiveAgents() {
        return repository.findByStatus(ToolAgentStatus.ACTIVE);
    }

    public List<IntegratedToolAgent> getReleasedAgents() {
        return repository.findByReleaseVersionTrue();
    }

    public Optional<IntegratedToolAgent> getAgentByKey(String key) {
        return repository.findByKey(key);
    }
}
```

## Notes

- Annotated with `@Repository` for Spring component scanning and exception translation.
- Query methods follow Spring Data naming conventions — no manual query implementation required.
- `findByKey` returns an `Optional` to safely handle missing agents without null checks.
