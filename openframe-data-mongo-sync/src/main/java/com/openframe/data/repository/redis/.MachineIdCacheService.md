A Spring `@Service` that provides cached lookups for machine and organization metadata using Spring's Cache abstraction, reducing repeated MongoDB queries by storing lightweight DTOs in Redis.

## Key Components

| Method | Cache Name | Key | Description |
|---|---|---|---|
| `getMachine(agentId)` | `machineCache` | `agentId` | Resolves agent ID → `ToolConnection` → machine record → `CachedMachineInfo` |
| `getMachineByMachineId(machineId)` | `machineByIdCache` | `machineId` | Direct lookup by native OpenFrame machine ID, bypassing `ToolConnection` indirection |
| `getOrganization(organizationId)` | `organizationCache` | `organizationId` | Fetches organization name and ID into `CachedOrganizationInfo` |

**Conditional activation:** only loaded when `openframe.machine-id.cache.enabled=true` is set.

All methods return `null` on miss or error, and `unless = "#result == null"` prevents null values from being cached.

## Usage Example

```java
// Inject the service
@Autowired
private MachineIdCacheService machineIdCacheService;

// Resolve a machine via its agent tool ID (e.g., from an incoming RMM agent)
CachedMachineInfo machine = machineIdCacheService.getMachine("agent-abc-123");
if (machine != null) {
    String machineId = machine.getMachineId();
    String hostname  = machine.getHostname();
    String orgId     = machine.getOrganizationId();
}

// Direct lookup when the native machineId is already known
CachedMachineInfo byId = machineIdCacheService.getMachineByMachineId("mach-xyz-456");

// Fetch organization details
CachedOrganizationInfo org = machineIdCacheService.getOrganization("org-789");
```

**Configuration:**

```yaml
openframe:
  machine-id:
    cache:
      enabled: true
```

> **Note:** This service requires servlet-based MongoDB repositories to be present at startup. It is not activated in reactive/WebFlux-only contexts.
