Spring Data MongoDB repository interface for managing `IntegratedTool` documents, providing lookup operations by tool type and key identifiers.

## Key Components

| Component | Description |
|---|---|
| `IntegratedToolRepository` | Main repository interface extending `MongoRepository<IntegratedTool, String>` |
| `BaseIntegratedToolRepository` | Base contract providing generic CRUD/query signatures |
| `CustomIntegratedToolRepository` | Extension interface for custom query logic |
| `findByType(String type)` | Retrieves an `IntegratedTool` by its type field |
| `findByKey(String key)` | Retrieves an `IntegratedTool` by its unique key field |

## Usage Example

```java
@Service
public class IntegratedToolService {

    private final IntegratedToolRepository toolRepository;

    public IntegratedToolService(IntegratedToolRepository toolRepository) {
        this.toolRepository = toolRepository;
    }

    public IntegratedTool getToolByType(String type) {
        return toolRepository.findByType(type)
                .orElseThrow(() -> new RuntimeException("Tool not found for type: " + type));
    }

    public IntegratedTool getToolByKey(String key) {
        return toolRepository.findByKey(key)
                .orElseThrow(() -> new RuntimeException("Tool not found for key: " + key));
    }
}
```

## Notes

- Both query methods return `Optional<IntegratedTool>`, enforcing null-safe handling at the call site.
- Spring Data automatically implements the repository at runtime — no manual query implementation is required.
- Annotated with `@Repository` to ensure proper Spring bean registration and exception translation.
