Manages persistence for `UserOnboardingProgress` documents in MongoDB, scoped by both `userId` and `tenantId`.

## Key Components

| Element | Description |
|---|---|
| `UserOnboardingProgressRepository` | Spring Data MongoDB repository interface extending `MongoRepository<UserOnboardingProgress, String>` |
| `findByUserIdAndTenantId` | Derived query method returning an `Optional<UserOnboardingProgress>` for a given user/tenant pair |

## Design Notes

This repository is intentionally annotated with plain `@Repository` rather than a tenant-aware variant. The SaaS-side runtime operates with tenant isolation disabled, so tenant context is **not** injected automatically — callers must supply `tenantId` explicitly in every lookup.

## Usage Example

```java
@Service
public class OnboardingService {

    private final UserOnboardingProgressRepository progressRepository;

    public OnboardingService(UserOnboardingProgressRepository progressRepository) {
        this.progressRepository = progressRepository;
    }

    public UserOnboardingProgress getProgress(String userId, String tenantId) {
        return progressRepository
                .findByUserIdAndTenantId(userId, tenantId)
                .orElseThrow(() -> new NotFoundException(
                        "No onboarding progress found for user " + userId));
    }
}
```
