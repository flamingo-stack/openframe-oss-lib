Custom MongoDB repository implementation for querying and paginating `Organization` documents. Supports dynamic filter criteria, cursor-based pagination (including compound keyset pagination for `updatedAt`), and field sorting.

## Key Components

| Member | Description |
|---|---|
| `buildOrganizationQuery()` | Constructs a MongoDB `Query` from an `OrganizationQueryFilter` and optional search string; combines all criteria with `$and` |
| `findOrganizationsWithFilters()` | Executes a filter+search query and returns matching `Organization` documents |
| `findOrganizationsWithCursor()` | Applies cursor-based pagination to a pre-built query, with configurable sort field/direction |
| `applyLastActivityKeyset()` | Handles compound `(updatedAt, _id)` keyset pagination by decoding a `"millis_objectId"` cursor string |
| `countOrganizations()` | Returns the document count for a given query |
| `isSortableField()` | Validates that a field name is in the allowed sort list (`_id`, `name`, `organizationId`, `createdAt`, `updatedAt`) |
| `getDefaultSortField()` | Returns `"_id"` as the default sort field |

**Supported filters:** `status`, `category` (case-insensitive), `minEmployees`/`maxEmployees`, `hasActiveContract`, `lastActivityFrom`/`lastActivityTo`, and free-text `search` across `name`, `organizationId`, and `category`.

## Usage Example

```java
// Build and execute a filtered + paginated query
OrganizationQueryFilter filter = OrganizationQueryFilter.builder()
    .status("ACTIVE")
    .minEmployees(10)
    .hasActiveContract(true)
    .build();

// Basic filter query
List<Organization> orgs = repo.findOrganizationsWithFilters(filter, "acme");

// Cursor-based pagination (second page, sorted by updatedAt DESC)
Query baseQuery = repo.buildOrganizationQuery(filter, "acme");
long total       = repo.countOrganizations(baseQuery);

Query pageQuery  = repo.buildOrganizationQuery(filter, "acme");
List<Organization> page2 = repo.findOrganizationsWithCursor(
    pageQuery,
    "1718000000000_664f1a2b3c4d5e6f7a8b9c0d", // "updatedAtMillis_objectId"
    25,
    "updatedAt",
    "DESC"
);
```

> **Cursor format:** For `updatedAt` sorting, the cursor must be encoded as `"<epochMillis>_<objectId>"`. For all other sort fields, pass a plain MongoDB `ObjectId` string.
