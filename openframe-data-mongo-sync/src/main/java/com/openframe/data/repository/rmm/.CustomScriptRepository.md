Defines the contract for MongoTemplate-backed custom queries against the `Script` document collection, enabling cursor-based pagination, filtered counting, and faceted aggregation that cannot be expressed through Spring Data derived methods alone.

## Key Components

| Method | Description |
|---|---|
| `findPageForTenant` | Fetches a single paginated page of scripts for a tenant with optional filter, search, sort, and cursor-based navigation |
| `countForTenant` | Returns the total count of scripts matching tenant + filter + search, without pagination |
| `shellFacet` | Aggregates `value → count` map for the shell-type dropdown filter |
| `platformFacet` | Aggregates `value → count` for `supportedPlatforms` (unwound from array before grouping) |
| `authorFacet` | Aggregates `value → count` for distinct `createdBy` user IDs |
| `isSortableField` | Guards against arbitrary sort injection by validating an allowed-field list |
| `getDefaultSortField` | Returns the fallback sort field when none is supplied by the caller |

## Usage Example

```java
// Inject the repository
@Autowired
private CustomScriptRepository scriptRepository;

// Paginate forward from a cursor
List<Script> page = scriptRepository.findPageForTenant(
    tenantId,
    filter,          // ScriptQueryFilter, or null for no extra constraints
    "backup",        // case-insensitive name search
    "name",          // sort field
    Sort.Direction.ASC,
    cursorHex,       // null = first page
    false,           // forward pagination
    pageSize + 1     // fetch one extra to detect next page
);

// Get total matching count for UI display
long total = scriptRepository.countForTenant(tenantId, filter, "backup");

// Load facet counts for the Shell dropdown
Map<String, Integer> shells = scriptRepository.shellFacet(tenantId, filter);
```

> **Implementation note:** The concrete logic lives in `CustomScriptRepositoryImpl`. Facet methods intentionally exclude a facet's own field from its filter criteria so dropdowns remain fully populated regardless of the currently selected value.
