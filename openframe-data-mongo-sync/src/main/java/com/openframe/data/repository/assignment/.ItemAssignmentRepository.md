MongoDB repository interface for managing `ItemAssignment` documents, providing tenant-scoped CRUD operations and targeted deletion of item assignments by target type and ID.

## Key Components

| Component | Description |
|---|---|
| `ItemAssignmentRepository` | Main repository interface extending `MongoRepository<ItemAssignment, String>` and `CustomItemAssignmentRepository` |
| `@TenantAwareRepository` | Ensures all queries are scoped to the current tenant context |
| `deleteByItemIdAndTargetTypeAndTargetId` | Removes a specific assignment matching item ID, target type, and target ID |
| `deleteByItemIdAndTargetType` | Removes all assignments for a given item ID and target type |

## Usage Example

```java
// Delete a specific assignment from a single target
itemAssignmentRepository.deleteByItemIdAndTargetTypeAndTargetId(
    "item-123",
    AssignmentTargetType.DEVICE,
    "device-456"
);

// Remove all assignments of a given type for an item
itemAssignmentRepository.deleteByItemIdAndTargetType(
    "item-123",
    AssignmentTargetType.USER
);
```

## Notes

- Extends `CustomItemAssignmentRepository` for any additional query logic beyond Spring Data's derived methods.
- The `@TenantAwareRepository` annotation enforces multi-tenancy, preventing cross-tenant data leakage automatically.
- Both delete methods are derived query methods — no explicit `@Query` annotations are required; Spring Data MongoDB generates the implementation at runtime.
