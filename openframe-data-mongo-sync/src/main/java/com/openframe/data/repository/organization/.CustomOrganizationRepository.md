Custom repository interface defining advanced MongoDB query operations for Organization documents, supporting filtering, cursor-based pagination, and sorting beyond standard Spring Data capabilities.

## Key Components

| Method | Description |
|---|---|
| `buildOrganizationQuery` | Constructs a MongoDB `Query` from an `OrganizationQueryFilter` and optional search string |
| `findOrganizationsWithFilters` | Executes a filtered/searched query, returning a list of matching `Organization` documents |
| `findOrganizationsWithCursor` | Fetches a paginated slice of organizations using keyset (cursor) pagination with configurable sort field, direction, and limit |
| `countOrganizations` | Returns the total document count for a base query, ignoring any cursor or pagination constraints |
| `isSortableField` | Validates whether a given field name is allowed as a sort key |
| `getDefaultSortField` | Returns the default field used for sorting when none is specified |

## Usage Example

```java
// Inject the repository (typically via a composite Spring Data repository)
@Autowired
private CustomOrganizationRepository customOrgRepo;

OrganizationQueryFilter filter = new OrganizationQueryFilter();
filter.setActive(true);

// Build the base query for reuse across count + paginated fetch
Query baseQuery = customOrgRepo.buildOrganizationQuery(filter, "acme");

// Get total matching records (no pagination applied)
long total = customOrgRepo.countOrganizations(baseQuery);

// Fetch first page using cursor pagination
String sortField = customOrgRepo.getDefaultSortField();
List<Organization> page = customOrgRepo.findOrganizationsWithCursor(
    baseQuery, null, 20, sortField, "ASC"
);
```

## Notes

- Implement this interface in a `CustomOrganizationRepositoryImpl` class using `MongoTemplate` for full query control.
- `countOrganizations` must receive the **base query only** — without cursor keyset predicates or skip/limit — to return accurate totals.
- Use `isSortableField` to guard against unsupported sort fields before invoking cursor-based queries.
