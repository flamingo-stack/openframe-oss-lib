Custom MongoDB repository implementation for `TimeEntry` documents, providing tenant-isolated, cursor-based pagination with flexible filtering and multi-field sorting.

## Key Components

- **`CustomTimeEntryRepositoryImpl`** — Extends `TenantAwareRepositorySupport` and implements `CustomTimeEntryRepository`. Active only when `openframe.tenant-isolation.enabled=true`.
- **`buildTimeEntryQuery(TimeEntryQueryFilter)`** — Constructs a MongoDB `Query` from a filter object supporting user IDs, ticket IDs, organization IDs, sources, date ranges, state (`ACTIVE`/`COMPLETED`), and free-text search.
- **`findTimeEntriesWithCursor(...)`** — Cursor-based pagination entry point. Delegates to `findWithDateSort` when sorting by `date`, otherwise applies standard keyset pagination.
- **`findWithDateSort(...)`** — Aggregation pipeline that groups entries by calendar day (`_workDay`) of `startedAt`, then sorts by `(workDay, createdAt, _id)` to keep backdated entries in their correct date group.
- **`applyDateCursor(...)`** — Decodes a compound cursor (`dayKey_createdAtMillis_objectId`) and injects a `$match` stage for the correct page boundary.
- **`applyCursorCriteria(...)`** — Resolves a single `ObjectId` cursor against any sortable field using a two-branch OR predicate (`past sort value` OR `same sort value + past ID`).

## Usage Example

```java
// Build a filtered, paginated query for completed entries by a specific user
TimeEntryQueryFilter filter = TimeEntryQueryFilter.builder()
    .userIds(List.of("user-123"))
    .state(TimeEntryStateFilter.COMPLETED)
    .startedFrom(Instant.parse("2024-01-01T00:00:00Z"))
    .startedTo(Instant.parse("2024-02-01T00:00:00Z"))
    .search("network")
    .build();

Query query = repository.buildTimeEntryQuery(filter);

// Fetch first page (date DESC)
List<TimeEntry> page1 = repository.findTimeEntriesWithCursor(
    query, null, 25, "date", "DESC"
);

// Fetch next page using compound cursor: "dayKey_createdAtMillis_objectId"
String cursor = "2024-01-15_1705276800000_65a1b2c3d4e5f6a7b8c9d0e1";
List<TimeEntry> page2 = repository.findTimeEntriesWithCursor(
    query, cursor, 25, "date", "DESC"
);
```

> **Note:** Cursor format depends on sort field. For `date` sort, use the compound `dayKey_millis_objectId` format. For all other sortable fields (`startedAt`, `endedAt`, `durationSeconds`, `createdAt`, `updatedAt`), pass a plain MongoDB `ObjectId` string.
