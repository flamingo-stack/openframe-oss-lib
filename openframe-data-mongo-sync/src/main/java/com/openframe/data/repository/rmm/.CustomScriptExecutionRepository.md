Custom MongoTemplate-backed repository interface for querying and paginating [`ScriptExecution`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/data/document/rmm/ScriptExecution.java) documents. Provides cursor-based pagination, full-text search, and faceted filtering capabilities that exceed the expressiveness of Spring Data's derived query methods.

## Key Components

| Method | Description |
|---|---|
| `findPageForScript` | Fetches a single cursor-paginated page of executions for a given script within a tenant, supporting bidirectional traversal, filtering, sorting, and substring search |
| `countForScript` | Returns the total execution count for a script/filter combination, independent of pagination, used to populate `filteredCount` in the UI |
| `initiatorFacet` | Returns a `Map<userId, count>` of "Executed by" options, excluding `initiatedByIds` from its own constraints to keep the dropdown fully populated |
| `statusFacet` | Returns a `Map<status, count>` of execution statuses, excluding `statuses` from its own constraints |
| `machineFacet` | Returns a `Map<machineId, count>` of targeted devices, excluding `machineIds` from its own constraints |
| `isSortableField` | Guards sort field input against unsupported field names |
| `getDefaultSortField` | Provides the fallback sort field when none is specified by the caller |

## Usage Example

```java
// Fetch the first page of executions for a script
List<ScriptExecution> page = repository.findPageForScript(
    "tenant-123",
    "script-456",
    filter,           // ScriptExecutionQueryFilter (nullable)
    "createdAt",      // sortField
    Sort.Direction.DESC,
    null,             // null cursor = first page
    false,            // forward pagination
    26,               // pageSize + 1 to detect hasNextPage
    "timeout"         // optional search term
);

// Get total count for pagination metadata
long total = repository.countForScript("tenant-123", "script-456", filter, "timeout");

// Fetch facet options for the Status filter dropdown
Map<String, Integer> statusOptions = repository.statusFacet("tenant-123", "script-456", filter, "timeout");
```

> **Implementation note:** This interface is backed by `CustomScriptExecutionRepositoryImpl` using `MongoTemplate` directly. Cursor values are raw `ObjectId` hex strings (base64-decoded by the caller before passing). When `backward=true`, the returned list should be reversed by the caller before display.
