Base abstract class that enforces tenant-scoped data access across all custom MongoDB repository implementations in tenant-side services.

## Key Components

| Member | Type | Description |
|--------|------|-------------|
| `mongoTemplate` | `TenantAwareMongoTemplate` | Protected field; replaces raw `MongoTemplate` to ensure tenant isolation |
| `TenantAwareRepositorySupport(TenantAwareMongoTemplate)` | Constructor | Accepts only `TenantAwareMongoTemplate`, blocking raw template injection |
| `tenantCriteria()` | `Criteria` | Returns a MongoDB `Criteria` scoped to the current tenant; use as the first `$match` stage in aggregations |
| `tenantId()` | `String` | Returns the current pod's tenant ID; use for composite keys and explicit field filters |

## Usage Example

```java
@Repository
public class DeviceRepositoryImpl extends TenantAwareRepositorySupport
        implements DeviceRepositoryCustom {

    public DeviceRepositoryImpl(TenantAwareMongoTemplate mongoTemplate) {
        super(mongoTemplate);
    }

    @Override
    public List<Device> findActiveDevices() {
        Criteria criteria = tenantCriteria().and("status").is("ACTIVE");
        Query query = new Query(criteria);
        return mongoTemplate.find(query, Device.class);
    }

    @Override
    public List<DeviceSummary> aggregateByType() {
        MatchOperation match = Aggregation.match(tenantCriteria());
        GroupOperation group = Aggregation.group("type").count().as("total");
        Aggregation agg = Aggregation.newAggregation(match, group);
        return mongoTemplate.aggregate(agg, Device.class, DeviceSummary.class)
                            .getMappedResults();
    }
}
```

## Architecture Enforcement

ArchUnit rules (in `TenantRepositoryArchitectureTest`) guarantee:
- Every `*RepositoryImpl` under `com.openframe.data.repository` **must** extend this class.
- No `*RepositoryImpl` may declare a field of raw type `MongoTemplate`.

This prevents accidental cross-tenant data leaks by making compliant tenant scoping a compile-time and test-time constraint rather than a convention.
