MongoTemplate-backed repository implementation for paginating, filtering, and faceting `Script` documents scoped to a tenant, using cursor-based pagination on `_id`.

## Key Components

| Method | Description |
|---|---|
| `findPageForTenant` | Returns a paginated list of `Script` documents for a tenant, applying filters, cursor, sort, and limit |
| `countForTenant` | Returns the total count matching the same predicate as a page fetch, without pagination |
| `shellFacet` | Aggregates script counts grouped by shell type |
| `platformFacet` | Aggregates script counts grouped by supported platform (unwinds the array) |
| `authorFacet` | Aggregates script counts grouped by `createdBy` user |
| `buildBaseCriteria` | Shared predicate builder combining tenant scope, status, shells, platforms, tags, author, and search |
| `applyTagIdsFilter` | Resolves `tagIds` filter via the `tag_assignments` collection before applying an `_id IN [...]` constraint |
| `applyCursor` | Parses a 24-char hex `ObjectId` cursor and appends the correct `$lt`/`$gt` comparison for forward/backward pagination |
| `facetCriteria` | Builds the filter predicate for a facet query, excluding the facet's own field to keep all options visible |
| `isSortableField` / `getDefaultSortField` | Enforces a sort-field allowlist (`_id`, `name`, `createdAt`, `updatedAt`); defaults to `_id` |

## Usage Example

```java
// Paginate scripts for a tenant, filtered by shell and tag
ScriptQueryFilter filter = ScriptQueryFilter.builder()
    .shells(List.of("bash", "powershell"))
    .tagIds(List.of("tagA", "tagB"))
    .build();

List<Script> page = customScriptRepository.findPageForTenant(
    "tenant-123",
    filter,
    "deploy",               // search term
    "_id",                  // sort field
    Sort.Direction.DESC,    // sort direction
    null,                   // no cursor = first page
    false,                  // forward pagination
    25                      // page size
);

long total = customScriptRepository.countForTenant("tenant-123", filter, "deploy");

// Facet dropdown counts (shell filter excluded so all shells are visible)
Map<String, Integer> shellCounts = customScriptRepository.shellFacet("tenant-123", filter);
// e.g. {"bash": 12, "powershell": 8}
```

## Notes

- **Cursor pagination** compares against a BSON `ObjectId` (not a `String`) to satisfy MongoDB's type-bracketing rules. Invalid cursors fall back to the first page with a `WARN` log rather than throwing.
- **Soft-delete default**: scripts with `status = DELETED` are excluded unless the caller explicitly passes `DELETED` in the status filter.
- **Tag resolution** is handled entirely in the data layer via a preliminary query against `tag_assignments`, keeping service code tag-agnostic.
