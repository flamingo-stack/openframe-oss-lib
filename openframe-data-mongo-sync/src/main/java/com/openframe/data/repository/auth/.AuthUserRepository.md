Spring Data MongoDB repository interface for `AuthUser` documents, providing query methods for user lookup, tenant-scoped filtering, and CRM sync state management.

## Key Components

| Method | Description |
|---|---|
| `findByEmailAndStatus` | Looks up a single active user by email address globally |
| `findByEmailAndTenantIdAndStatus` | Looks up a single active user by email scoped to a specific tenant |
| `existsByEmailAndTenantId` | Checks whether a user exists for a given email/tenant combination |
| `findByEmailAndTenantId` | Retrieves a user by email within a tenant regardless of their status |
| `deleteByTenantId` | Removes all users belonging to a given tenant |
| `findByCrmSyncedFalseOrCrmSyncedIsNull` | Returns all users pending CRM synchronization |

## Usage Example

```java
// Authenticate an active user globally
Optional<AuthUser> user = authUserRepository
    .findByEmailAndStatus("alice@example.com", UserStatus.ACTIVE);

// Authenticate an active user scoped to a tenant
Optional<AuthUser> tenantUser = authUserRepository
    .findByEmailAndTenantIdAndStatus("alice@example.com", "tenant-123", UserStatus.ACTIVE);

// Check for duplicate email before registration
boolean exists = authUserRepository
    .existsByEmailAndTenantId("alice@example.com", "tenant-123");

// Fetch users awaiting CRM sync
List<AuthUser> pendingSync = authUserRepository
    .findByCrmSyncedFalseOrCrmSyncedIsNull();

// Remove all users when a tenant is deprovisioned
authUserRepository.deleteByTenantId("tenant-123");
```

## Notes

- Extends `MongoRepository<AuthUser, String>`, so all standard CRUD and pagination methods are available out of the box.
- Tenant-scoped methods isolate data per tenant, supporting OpenFrame's multi-tenant architecture.
- `findByCrmSyncedFalseOrCrmSyncedIsNull` handles both explicitly `false` and legacy documents where the field is absent.
