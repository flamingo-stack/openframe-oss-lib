Tenant-aware MongoDB repository implementation for querying and aggregating `ItemAssignment` documents with cursor-based pagination, filtering, and grouped counts.

## Key Components

| Member | Description |
|---|---|
| `findAssignmentsWithCursor` | Retrieves a paginated list of assignments using keyset/cursor-based pagination with configurable sort field and direction |
| `applyCursorCriteria` | Builds MongoDB `$or` criteria to position the query after the cursor document, handling tie-breaking via `_id` |
| `countAssignments` | Returns total count of assignments matching item ID, target type, and optional search filter |
| `countByItemIdGroupedByTargetType` | Runs a MongoDB aggregation pipeline returning a per-`AssignmentTargetType` count map |
| `buildAssignmentQuery` | Constructs the base `Query` with mandatory `itemId`/`targetType` filters and optional case-insensitive `displayName` regex search |
| `isSortableField` / `getDefaultSortField` | Guards against arbitrary sort injection; permits only `createdAt` and `displayName` |

**Activation:** Only registered when `openframe.tenant-isolation.enabled=true` (via `@ConditionalOnProperty`).

## Usage Example

```java
// Inject via Spring context
@Autowired
private CustomItemAssignmentRepository assignmentRepository;

// First page
List<ItemAssignment> page1 = assignmentRepository.findAssignmentsWithCursor(
    "item-123",
    AssignmentTargetType.USER,
    "alice",          // search term
    "createdAt",      // sort field
    "DESC",           // sort direction
    null,             // no cursor = first page
    20                // page size
);

// Next page — pass last document's _id as cursor
String nextCursor = page1.get(page1.size() - 1).getId().toHexString();
List<ItemAssignment> page2 = assignmentRepository.findAssignmentsWithCursor(
    "item-123", AssignmentTargetType.USER,
    "alice", "createdAt", "DESC", nextCursor, 20
);

// Grouped counts per target type
Map<AssignmentTargetType, Long> counts =
    assignmentRepository.countByItemIdGroupedByTargetType("item-123");
// e.g. { USER=42, GROUP=7 }
```
