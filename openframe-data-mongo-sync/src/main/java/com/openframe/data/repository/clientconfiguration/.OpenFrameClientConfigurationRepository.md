Defines the Spring Data MongoDB repository interface for managing `OpenFrameClientConfiguration` documents, providing tenant-aware and time-ordered lookup capabilities.

## Key Components

| Member | Type | Description |
|---|---|---|
| `findFirstByOrderByCreatedAtDesc()` | Query Method | Retrieves the most recently created client configuration document |
| `findByTenantId(String tenantId)` | Query Method | Looks up a client configuration by its associated tenant identifier |

Inherits full CRUD operations from `MongoRepository<OpenFrameClientConfiguration, String>`.

## Usage Example

```java
@Service
public class ClientConfigService {

    private final OpenFrameClientConfigurationRepository repository;

    public ClientConfigService(OpenFrameClientConfigurationRepository repository) {
        this.repository = repository;
    }

    public OpenFrameClientConfiguration getConfigForTenant(String tenantId) {
        return repository.findByTenantId(tenantId)
            .orElseThrow(() -> new ConfigNotFoundException("No config for tenant: " + tenantId));
    }

    public OpenFrameClientConfiguration getLatestConfig() {
        return repository.findFirstByOrderByCreatedAtDesc()
            .orElseThrow(() -> new ConfigNotFoundException("No configurations found"));
    }
}
```

## Notes

- Both query methods return `Optional<OpenFrameClientConfiguration>` — callers should handle the empty case explicitly.
- `findFirstByOrderByCreatedAtDesc()` is useful during bootstrapping or single-tenant scenarios where a global fallback config is needed.
- The `@Repository` annotation enables Spring component scanning and Spring Data exception translation.
