MongoDB-backed repository implementation providing cursor-based pagination, filtering, full-text search, and faceted aggregation for `ScriptExecution` documents scoped to a tenant and script.

## Key Components

| Method | Description |
|---|---|
| `findPageForScript()` | Returns a paginated list of executions using `_id`-based cursor pagination with configurable sort direction and forward/backward traversal |
| `countForScript()` | Returns the total matching count for a given tenant/script/filter/search tuple without cursor or limit constraints |
| `initiatorFacet()` | Aggregates execution counts grouped by `initiatedBy`, excluding the initiator filter from its own predicate |
| `statusFacet()` | Aggregates execution counts grouped by `status`, excluding the status filter from its own predicate |
| `machineFacet()` | Aggregates execution counts grouped by `machineId`, excluding the machine filter from its own predicate |
| `isSortableField()` | Validates a field name against the allowlist: `_id`, `dispatchedAt`, `finishedAt`, `statusChangedAt` |
| `getDefaultSortField()` | Returns `_id` as the fallback sort field |

**Internal helpers:**
- `baseCriteria()` — builds the tenant/script/status/initiator/machine predicate
- `withSearch()` — appends a case-insensitive regex OR across `executionId`, `machineId`, `stdout`, `stderr`
- `applyCursor()` — parses the cursor into a BSON `ObjectId` and applies `$lt`/`$gt` with direction logic; invalid cursors fall back gracefully to page one
- `facetCounts()` — runs a `match → group → count` aggregation and collapses results into a `Map<String, Integer>`

## Usage Example

```java
// Fetch the first page (newest first), filtered by status
ScriptExecutionQueryFilter filter = new ScriptExecutionQueryFilter();
filter.setStatuses(Set.of("COMPLETED", "FAILED"));

List<ScriptExecution> page = repository.findPageForScript(
    "tenant-abc",          // tenantId
    "script-xyz",          // scriptId
    filter,
    "_id",                 // sortField
    Sort.Direction.DESC,   // sortDirection
    null,                  // cursor (null = first page)
    false,                 // backward
    25,                    // limit
    "timeout"              // search term
);

// Get facet counts for the status filter panel
Map<String, Integer> statusCounts = repository.statusFacet(
    "tenant-abc", "script-xyz", filter, "timeout"
);
// e.g. {"COMPLETED": 18, "FAILED": 7}

// Paginate forward using the last record's _id as cursor
String nextCursor = page.get(page.size() - 1).getId().toHexString();
List<ScriptExecution> nextPage = repository.findPageForScript(
    "tenant-abc", "script-xyz", filter,
    "_id", Sort.Direction.DESC, nextCursor, false, 25, "timeout"
);
```

> **Cursor note:** Cursors must be valid 24-character hex `ObjectId` strings. An invalid cursor logs a warning and returns the first page rather than throwing an error.
