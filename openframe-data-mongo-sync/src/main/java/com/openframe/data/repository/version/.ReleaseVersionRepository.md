MongoDB repository interface for `ReleaseVersion` document operations, providing tenant-scoped access to the single release version record maintained per tenant.

## Key Components

| Method | Return Type | Description |
|---|---|---|
| `findFirstByOrderByCreatedAtAsc()` | `Optional<ReleaseVersion>` | Retrieves the oldest release version document, ordered by creation date ascending |
| `findFirstBy()` | `Optional<ReleaseVersion>` | Retrieves the single release version for the current tenant; auto-scoped by `TenantAwareMongoTemplate` |

## Usage Example

```java
@Service
public class ReleaseVersionService {

    private final ReleaseVersionRepository releaseVersionRepository;

    public ReleaseVersionService(ReleaseVersionRepository releaseVersionRepository) {
        this.releaseVersionRepository = releaseVersionRepository;
    }

    public ReleaseVersion getCurrentVersion() {
        return releaseVersionRepository.findFirstBy()
                .orElseThrow(() -> new EntityNotFoundException("No release version found for tenant"));
    }

    public ReleaseVersion getEarliestVersion() {
        return releaseVersionRepository.findFirstByOrderByCreatedAtAsc()
                .orElseThrow(() -> new EntityNotFoundException("No release version records found"));
    }
}
```

## Notes

- Extends `MongoRepository<ReleaseVersion, String>`, inheriting standard CRUD operations.
- Designed to hold a **single document per tenant** — `findFirstBy()` is the primary accessor.
- Tenant isolation is handled transparently by `TenantAwareMongoTemplate`; no manual tenant filtering is required in queries.
