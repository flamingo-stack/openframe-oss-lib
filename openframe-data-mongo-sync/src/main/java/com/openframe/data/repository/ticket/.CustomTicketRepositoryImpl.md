Tenant-aware MongoDB repository implementation providing advanced querying, cursor-based pagination, and aggregation operations for `Ticket` documents within the OpenFrame platform.

## Key Components

| Method | Description |
|---|---|
| `buildTicketQuery()` | Constructs a MongoDB `Query` from a `TicketQueryFilter`, supporting filtering by status, organization, assignee, device, creation source, date range, search text, and owner machine ID |
| `findTicketsWithCursor()` | Executes cursor-based pagination over tickets with configurable sort field and direction |
| `applyCursorCriteria()` | Handles compound cursor logic for both `_id`-only and multi-field sort scenarios |
| `countTickets()` | Returns total count for a given query |
| `countTicketsByStatus()` | Aggregates ticket counts grouped by `TicketStatus` enum |
| `countTicketsByStatusKind()` | Aggregates ticket counts grouped by `TicketStatusKind` enum |
| `countTicketsByStatusId()` | Aggregates ticket counts grouped by raw `statusId` string |

**Activation:** Conditionally registered only when `openframe.tenant-isolation.enabled=true`.

## Usage Example

```java
// Build a filtered query
TicketQueryFilter filter = TicketQueryFilter.builder()
        .statusKinds(List.of(TicketStatusKind.OPEN))
        .organizationIds(List.of("org-123"))
        .createdAtFrom(Instant.parse("2024-01-01T00:00:00Z"))
        .build();

Query query = repo.buildTicketQuery(filter, "printer", null, null);

// Paginate with cursor
List<Ticket> page1 = repo.findTicketsWithCursor(query, null, 25, "createdAt", "DESC");
String nextCursor = page1.get(page1.size() - 1).getId();

// Fetch next page
Query query2 = repo.buildTicketQuery(filter, "printer", null, null);
List<Ticket> page2 = repo.findTicketsWithCursor(query2, nextCursor, 25, "createdAt", "DESC");

// Count by status
Map<TicketStatus, Long> statusCounts = repo.countTicketsByStatus();
```
