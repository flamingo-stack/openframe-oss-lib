MongoDB repository interface for `Ticket` documents, providing tenant-aware CRUD operations, status-based queries, and aggregation pipelines for kanban-style column ordering. Supports both legacy enum-based status lookups and the newer lifecycle feature flag system using `statusId`.

## Key Components

| Method | Description |
|---|---|
| `findByTicketNumber` | Looks up a ticket by its human-readable number |
| `findByStatus` | Returns all tickets matching a legacy `TicketStatus` enum |
| `findByOrganizationId` | Fetches tickets scoped to an organization |
| `findByAssignedTo` | Lists tickets assigned to a specific user |
| `findByDeviceId` | Retrieves tickets linked to a device |
| `findByIdIn` | Batch lookup by a list of IDs |
| `findByIdAndOwnerMachineId` | Validates ticket ownership by machine ID |
| `findFirstInColumn` / `findLastInColumn` | Retrieves the first or last ordered ticket in a status column (legacy) |
| `findFirstAfter` / `findFirstBefore` | Navigates adjacent tickets by `order` field within a column (legacy) |
| `countByStatusId` | Counts tickets in a lifecycle status |
| `findFirstInColumnByStatusId` | Retrieves the first ordered ticket in a lifecycle status column |
| `findFirstAfterByStatusId` / `findFirstBeforeByStatusId` | Navigates adjacent tickets by `order` using `statusId` (lifecycle) |

## Usage Example

```java
// Legacy: fetch first ticket in a kanban column
Optional<Ticket> first = ticketRepository.findFirstInColumn(TicketStatus.OPEN, "tenant-123");

// Legacy: navigate to the next ticket after a given order value
Optional<Ticket> next = ticketRepository.findFirstAfter(TicketStatus.OPEN, "0.5", "tenant-123");

// Lifecycle: count tickets in a custom status
long count = ticketRepository.countByStatusId("status-abc");

// Lifecycle: get the first ticket in a lifecycle column
Optional<Ticket> firstLifecycle = ticketRepository
    .findFirstInColumnByStatusId("status-abc", "tenant-123");

// Validate ticket belongs to a specific machine
Optional<Ticket> owned = ticketRepository
    .findByIdAndOwnerMachineId("ticket-id", "machine-xyz");
```

> **Note:** Methods marked with legacy comments (`findByStatus`, `findFirstInColumn`, etc.) are pending removal after the lifecycle feature flag rollout completes. Prefer `*ByStatusId` variants for new code.
