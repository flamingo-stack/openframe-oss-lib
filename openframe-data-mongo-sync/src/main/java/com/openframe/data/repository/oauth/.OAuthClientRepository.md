Spring Data MongoDB repository interface for managing `OAuthClient` documents, providing standard CRUD operations plus custom lookup methods by client ID and machine ID.

## Key Components

| Method | Description |
|---|---|
| `findByClientId(String clientId)` | Looks up an OAuth client by its OAuth `clientId` |
| `findByMachineId(String machineId)` | Looks up an OAuth client by its associated machine ID |
| `existsByMachineId(String machineId)` | Checks whether an OAuth client is registered for a given machine ID |

Extends `MongoRepository<OAuthClient, String>`, inheriting full CRUD and pagination support out of the box.

## Usage Example

```java
@Service
public class OAuthClientService {

    private final OAuthClientRepository oAuthClientRepository;

    public OAuthClientService(OAuthClientRepository oAuthClientRepository) {
        this.oAuthClientRepository = oAuthClientRepository;
    }

    public OAuthClient getByClientId(String clientId) {
        return oAuthClientRepository.findByClientId(clientId)
                .orElseThrow(() -> new EntityNotFoundException("OAuth client not found: " + clientId));
    }

    public boolean isMachineRegistered(String machineId) {
        return oAuthClientRepository.existsByMachineId(machineId);
    }
}
```

## Notes

- All custom finders return `Optional<OAuthClient>` to safely handle missing records without null checks.
- `existsByMachineId` provides a lightweight existence check, avoiding a full document fetch when only presence needs to be confirmed.
