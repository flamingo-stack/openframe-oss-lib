MongoDB repository interface for managing `ScriptScheduleMachineAssigned` documents, which represent the many-to-many association between script schedules and machines within a tenant-scoped RMM context.

## Key Components

| Method | Description |
|--------|-------------|
| `findByTenantIdAndScriptScheduleId` | Retrieves all machine assignments for a specific schedule within a tenant |
| `findByTenantIdAndScriptScheduleIdIn` | Batch-fetches assignments for multiple schedule IDs within a tenant |
| `findByTenantIdAndMachineId` | Returns all schedule assignments linked to a specific machine within a tenant |
| `deleteByTenantIdAndScriptScheduleId` | Removes all machine assignments for a given schedule; returns deleted count |
| `deleteByTenantIdAndScriptScheduleIdAndMachineIdIn` | Selectively removes assignments for specific machines from a schedule; returns deleted count |

## Usage Example

```java
// Fetch all machines assigned to a specific schedule
List<ScriptScheduleMachineAssigned> assignments =
    repository.findByTenantIdAndScriptScheduleId("tenant-123", "schedule-abc");

// Batch lookup across multiple schedules
List<ScriptScheduleMachineAssigned> bulkAssignments =
    repository.findByTenantIdAndScriptScheduleIdIn(
        "tenant-123",
        List.of("schedule-abc", "schedule-def")
    );

// Remove selected machines from a schedule
long removed = repository.deleteByTenantIdAndScriptScheduleIdAndMachineIdIn(
    "tenant-123",
    "schedule-abc",
    List.of("machine-1", "machine-2")
);
```

## Notes

- All queries are **tenant-scoped** via `tenantId` to enforce data isolation.
- Delete methods return a `long` count of affected documents, useful for audit logging or validation.
- Extends `MongoRepository<ScriptScheduleMachineAssigned, String>`, inheriting standard CRUD operations.
