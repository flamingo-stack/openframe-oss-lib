Integrations test suite for `ScriptRepository`, verifying MongoDB persistence, tenant isolation, cursor-based pagination, soft-delete filtering, and name-collision detection for the `Script` document in the RMM module.

## Key Components

| Component | Description |
|---|---|
| `ScriptRepositoryIT` | Main integration test class extending `BaseMongoIntegrationTest` |
| `resetCollection()` | `@BeforeEach` teardown that removes all `Script` and `TagAssignment` documents while preserving indexes |
| `save_populatesAuditingTimestamps` | Verifies Spring Data auditing populates `createdAt`/`updatedAt` on persist |
| `findByTenantIdAndId_isolatesByTenant` | Ensures cross-tenant document access is blocked |
| `findByTenantIdAndName_isolatesByTenant` | Ensures name lookups are scoped per tenant |
| `findPageForTenant_*` tests | Covers no-cursor, forward-cursor, backward-cursor, limit, tenant isolation, and DELETED exclusion for cursor pagination |
| `countForTenant_*` tests | Verifies accurate counts ignoring pagination, excluding soft-deleted rows, and isolating by tenant |
| `existsByTenantIdAndNameAndStatusIn_*` tests | Validates name-uniqueness checks: tenant isolation, deleted rows excluded, archived rows reserved |
| `existsByTenantIdAndNameAndIdNotAndStatusIn_*` tests | Validates update-safe name collision detection (excludes the document being edited) |

## Usage Example

```java
// Typical usage of the repository methods under test

// Find a script by tenant + ID
Optional<Script> script = scriptRepository.findByTenantIdAndId("tenant-a", scriptId);

// Paginate newest-first (no cursor = first page)
List<Script> page = scriptRepository.findPageForTenant(
    "tenant-a", null, null,
    "_id", Sort.Direction.DESC,
    null, false, 20
);

// Paginate with a forward cursor (next page)
List<Script> nextPage = scriptRepository.findPageForTenant(
    "tenant-a", null, null,
    "_id", Sort.Direction.DESC,
    lastSeenId, false, 20
);

// Count active/archived scripts for a tenant
long total = scriptRepository.countForTenant("tenant-a", null, null);

// Check name availability before create (excludes DELETED)
boolean taken = scriptRepository.existsByTenantIdAndNameAndStatusIn(
    "tenant-a", "Restart Spooler",
    List.of(ScriptStatus.ACTIVE, ScriptStatus.ARCHIVED)
);

// Check name availability before update (excludes the document itself)
boolean collision = scriptRepository.existsByTenantIdAndNameAndIdNotAndStatusIn(
    "tenant-a", "Restart Spooler", existingId,
    List.of(ScriptStatus.ACTIVE, ScriptStatus.ARCHIVED)
);
```
