Integration test suite for `NotificationReadStateService`, verifying read/unread lifecycle operations against a real MongoDB instance using `BaseMongoIntegrationTest`.

## Key Components

| Element | Description |
|---|---|
| `NotificationReadStateServiceIT` | Main test class; extends `BaseMongoIntegrationTest`, requires `-Dintegration.tests=true` |
| `resetCollections()` | `@BeforeEach` teardown that drops `Notification` and `NotificationReadState` collections |
| Test constants | `ALICE`, `BOB`, `MACHINE_1`, `CAT_TICKETS`, `CAT_MINGO` — reusable fixture identifiers |

## Test Coverage

| Test | Behaviour Verified |
|---|---|
| `unread_to_read_round_trip` | `createForAudience` → `hasUnread` → `markRead` lifecycle |
| `blank_input_throws` | `ConstraintViolationException` on null/blank inputs |
| `mark_read_no_audience` | `markRead` returns `false` when recipient is not in audience |
| `audience_isolation_by_id` | Per-recipient isolation: marking one read does not affect another |
| `audience_isolation_by_type` | `USER` vs `MACHINE` states are scoped independently |
| `mark_all_as_read` | Bulk flip of all UNREAD rows; returns affected count |
| `dismiss_for_all_recipients_*` | Lifecycle-resolve flips all UNREAD rows; leaves DELETED rows untouched |
| `read_at_is_a_real_instant_not_literal_now` | Regression: `readAt` deserializes as `Instant`, not the literal string `"$$NOW"` |
| `delete_notification_soft_deletes` | Per-recipient soft-delete sets `status=DELETED` |
| `delete_all_read` | Bulk soft-delete targets only READ rows; UNREAD rows remain |
| `unread_counts_by_category` | Aggregation returns per-category UNREAD counts |

## Usage Example

```java
// Run integration tests explicitly via Maven:
// mvn verify -Dintegration.tests=true

// Typical service interaction pattern exercised by the tests:
service.createForAudience("notif-1", NotificationCategory.TICKETS, "New ticket", RecipientType.USER, Set.of("user-alice"));
boolean hasUnread = service.hasUnread("user-alice", RecipientType.USER); // true
boolean marked    = service.markRead("user-alice", RecipientType.USER, "notif-1"); // true
hasUnread         = service.hasUnread("user-alice", RecipientType.USER); // false

// Lifecycle-resolve (e.g. approval actioned by one admin dismisses for everyone):
long affected = service.dismissForAllRecipients("notif-1");

// Category-level unread counts:
Map<NotificationCategory, Long> counts = service.unreadCountsByCategory("user-alice", RecipientType.USER);
```

> Tests are gated by `@EnabledIfSystemProperty(named = "integration.tests", matches = "true")` and must be run against a live MongoDB instance configured in `BaseMongoIntegrationTest`.
