Minimal Spring Boot test application context for Organization repository integration tests, restricting component scanning to the organization package and explicitly wiring the custom repository fragment.

## Key Components

- **`@SpringBootConfiguration`** — Marks this as the root configuration for the test application context
- **`@EnableAutoConfiguration`** — Enables Spring Boot auto-configuration for MongoDB and related infrastructure
- **`@EnableMongoRepositories(basePackageClasses = OrganizationRepository.class)`** — Limits repository scanning to the organization package, preventing unrelated repositories from requiring wiring
- **`@Import(CustomOrganizationRepositoryImpl.class)`** — Explicitly registers the custom repository fragment, which is not auto-detected by `@EnableMongoRepositories` alone
- **Auditing intentionally disabled** — Mongo auditing (`@EnableMongoAuditing`) is omitted so that `@LastModifiedDate`-annotated fields (e.g., `updatedAt`) are persisted verbatim, giving pagination and range-filter tests precise control over timestamps

## Usage Example

```java
@DataMongoTest
@SpringBootTest(classes = OrganizationIntegrationTestApplication.class)
class OrganizationRepositoryIntegrationTest {

    @Autowired
    private OrganizationRepository organizationRepository;

    @Test
    void shouldPersistAndRetrieveOrganization() {
        Organization org = new Organization("test-org");
        org.setUpdatedAt(Instant.parse("2024-01-15T10:00:00Z")); // controlled timestamp

        organizationRepository.save(org);

        Optional<Organization> found = organizationRepository.findById(org.getId());
        assertThat(found).isPresent();
    }
}
```

## Notes

- Mirrors the pattern established in `RmmIntegrationTestApplication`
- The explicit `@Import` of `CustomOrganizationRepositoryImpl` is required because Spring Data's repository factory does not scan fragment implementations as standalone beans
- See source: [`OrganizationIntegrationTestApplication.java`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/test/java/com/openframe/data/integration/support/OrganizationIntegrationTestApplication.java)
