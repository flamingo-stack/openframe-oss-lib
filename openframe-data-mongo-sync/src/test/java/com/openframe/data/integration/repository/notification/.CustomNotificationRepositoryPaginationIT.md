Integration test suite that verifies cursor-based pagination, audience isolation, read-status filtering, and title-search streaming behavior for `NotificationRepository` against a real MongoDB instance.

## Key Components

| Component | Role |
|---|---|
| `CustomNotificationRepositoryPaginationIT` | Main test class; extends `BaseMongoIntegrationTest` for embedded/real Mongo lifecycle |
| `NotificationRepository` | Repository under test; provides the custom `page(...)` query |
| `NotificationWithStatus` | DTO pairing a `Notification` document with its `ReadStatus` |
| `NotificationPage` | Page result wrapper returned by the repository |
| `NotificationFixtures` | Test-data builder for creating `Notification` documents |
| `seedSequentialForRecipient` / `seedReadState` | Helper methods that populate `Notification` and `NotificationReadState` collections |
| `resetCollection()` (`@BeforeEach`) | Drops both collections before each test to ensure isolation |

## Test Coverage

| Scenario | Test Method |
|---|---|
| Default descending order, no cursor | `given_no_cursor_returns_descending` |
| Forward cursor (older items) | `given_forward_cursor_returns_older_rows` |
| Backward cursor (newer items) | `given_backward_cursor_returns_newer_rows` |
| Isolation by recipient ID | `audience_isolation_by_id` |
| Isolation by recipient type (`USER` vs `MACHINE`) | `audience_isolation_by_type` |
| Page size limit enforced | `limit_honored` |
| Empty result when no rows exist | `empty_when_no_rows` |
| `DELETED` status excluded by default | `deleted_excluded_by_default` |
| Read/unread filter (`readFilter=true/false`) | `read_filter_true`, `read_filter_false` |
| Case-insensitive title search | `search_filters_by_title` |
| Streaming search fills full page from sparse matches | `search_streams_until_full_page_collected` |
| Search exhausts when fewer matches than limit | `search_exhausts_when_fewer_matches_than_limit` |
| Streaming batch grows to reach distant matches past batch window | `search_grows_batch_to_reach_distant_matches` |

## Usage Example

```java
// Tests run only when the system property is set:
// mvn verify -Dintegration.tests=true

// Example: seed 5 notifications for Alice and verify newest-first ordering
List<Notification> seeded = seedSequentialForRecipient(ALICE, RecipientType.USER, 5);

List<NotificationWithStatus> page = page(ALICE, RecipientType.USER,
    null,   // readFilter (null = all non-deleted)
    null,   // search term
    null,   // cursor (null = first page)
    false,  // backward
    10      // limit
);

assertThat(page.get(0).notification().getId()).isEqualTo(seeded.get(4).getId()); // newest first
assertThat(page).allSatisfy(item -> assertThat(item.status()).isEqualTo(ReadStatus.UNREAD));
```

> **Note:** Tests are guarded by `@EnabledIfSystemProperty(named = "integration.tests", matches = "true")` and require a running/embedded MongoDB. See [`BaseMongoIntegrationTest`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/test/java/com/openframe/data/integration/BaseMongoIntegrationTest.java) for container setup.
