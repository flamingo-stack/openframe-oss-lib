Integration test that verifies polymorphic deserialization of `Notification` context documents stored in MongoDB, ensuring Jackson's type discriminator correctly dispatches to concrete `NotificationContext` subclasses on read-back.

## Key Components

| Element | Description |
|---|---|
| `given_extended_context_when_reread_then_dispatches_to_concrete_subclass` | Persists a `Notification` with a `TestExtendedContext`, re-reads it, and asserts the context deserializes to the concrete subclass with all extra fields intact |
| `given_generic_context_when_reread_then_round_trips_as_generic` | Persists a `Notification` with a `GenericContext`, re-reads it, and asserts the raw payload string survives the round-trip |
| `given_saved_notification_when_inspecting_raw_doc_then_context_has_type_discriminator` | Reads the raw MongoDB `Document` directly via `MongoTemplate` and asserts the embedded `context` subdocument contains a `type` discriminator field used by Jackson for polymorphic dispatch |
| `resetCollection` (`@BeforeEach`) | Drops the `Notification` collection before each test to ensure isolation |

## Usage Example

```java
// Run only when integration.tests system property is set to "true"
// mvn verify -Dintegration.tests=true

// Typical assertion pattern used in these tests:
Notification persisted = repository.save(original);
Optional<Notification> retrieved = repository.findById(persisted.getId());

assertThat(retrieved).isPresent();
assertThat(retrieved.get().getContext()).isInstanceOf(TestExtendedContext.class);

TestExtendedContext ctx = (TestExtendedContext) retrieved.get().getContext();
assertThat(ctx.getExtraField()).isEqualTo("extra-value");
```

> **Note:** Tests are gated by `@EnabledIfSystemProperty(named = "integration.tests", matches = "true")` and tagged `integration`, so they are skipped in standard unit test runs. They require a live MongoDB instance configured via `BaseMongoIntegrationTest`.
