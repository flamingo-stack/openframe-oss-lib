Integration test suite for `ScriptScheduleRepository` and `CustomScriptScheduleRepositoryImpl`, validating cursor-based pagination, tenant isolation, sorting, and compound keyset pagination against a real MongoDB instance via Testcontainers.

## Key Components

| Component | Description |
|---|---|
| `ScriptScheduleRepositoryIT` | Main test class extending `BaseMongoIntegrationTest` |
| `resetCollection()` | `@BeforeEach` hook that clears documents while preserving indexes |
| `save()` / `saveActive()` / `saveWithRepeat()` | Helper methods for inserting `ScriptSchedule` fixtures |
| `ScriptScheduleRepository` | Repository under test, autowired via Spring context |
| `MongoTemplate` | Used directly for collection reset between tests |

## Key Test Scenarios

- **Tenant isolation** — `findByTenantIdAndId` confirms cross-tenant lookups return empty
- **Cursor pagination** — no-cursor returns newest-first; forward cursor returns only older rows
- **Sort allowlist** — `isSortableField` permits `repeat`, rejects unknown fields
- **`repeat` sorting** — ASC places `null` one-shot schedules first; DESC places longest interval first
- **Tie-breaking** — equal `repeat` values fall back to `_id` DESC for stable ordering
- **Compound keyset pagination** — pages cleanly through tie groups without skipping or duplicating rows
- **Null boundary crossing** — ASC pagination correctly crosses `null → numeric` repeat boundary
- **`encodeCursor` formats** — plain ID for `_id` sort; `value|id` for compound sort; `|id` for null repeat
- **Malformed cursor resilience** — bad cursor input falls back to first page instead of throwing

## Usage Example

```java
// Run integration tests with the required system property
// mvn verify -Dintegration.tests=true

// Example: paginating through schedules sorted by repeat interval
String cursor = null;
List<String> allIds = new ArrayList<>();

do {
    List<ScriptSchedule> page = scheduleRepository.findPageForTenant(
        "tenant-a", null, null,
        "repeat", Sort.Direction.DESC,
        cursor, false, 2
    );
    if (page.isEmpty()) break;
    page.forEach(s -> allIds.add(s.getId()));
    cursor = scheduleRepository.encodeCursor(page.getLast(), "repeat");
} while (true);
```

> **Note:** Tests are gated by `@EnabledIfSystemProperty(named = "integration.tests", matches = "true")` and require a running Testcontainers-compatible Docker environment.
