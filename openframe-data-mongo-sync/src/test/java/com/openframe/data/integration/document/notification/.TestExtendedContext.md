A test fixture class that extends `NotificationContext` to demonstrate and validate polymorphic deserialization of notification contexts with additional fields.

## Key Components

| Member | Type | Description |
|---|---|---|
| `TYPE` | `static final String` | Type discriminator constant — `"TEST_EXTENDED_CONTEXT"` |
| `extraField` | `String` | Additional string field for testing extended context payloads |
| `extraNumber` | `int` | Additional numeric field for testing extended context payloads |
| `getType()` | `@Override` | Returns `TYPE`, used for polymorphic serialization |

## Usage Example

```java
// Build an instance using Lombok's SuperBuilder
TestExtendedContext ctx = TestExtendedContext.builder()
    .extraField("some-value")
    .extraNumber(42)
    .build();

// Type discriminator is serialized as a getter-only field
String type = ctx.getType(); // "TEST_EXTENDED_CONTEXT"

// Jackson ignores "type" on deserialization (allowGetters = true)
// so the type field is written out but not required on read
ObjectMapper mapper = new ObjectMapper();
String json = mapper.writeValueAsString(ctx);
TestExtendedContext restored = mapper.readValue(json, TestExtendedContext.class);
```

## Notes

- `@JsonIgnoreProperties(value = "type", allowGetters = true)` ensures the `type` field is included in serialized output but ignored during deserialization, preventing unknown-field errors in polymorphic scenarios.
- Inherits all fields and builder support from `NotificationContext` via `@SuperBuilder` and `callSuper = true` on `@EqualsAndHashCode` / `@ToString`.
- Intended for use in integration tests within the [`com.openframe.data.integration.document.notification`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/test/java/com/openframe/data/integration/document/notification/TestExtendedContext.java) package.
