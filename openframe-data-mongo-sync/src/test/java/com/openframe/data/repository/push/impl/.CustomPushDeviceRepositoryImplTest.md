Unit tests for `CustomPushDeviceRepositoryImpl`, verifying the upsert-based device token registration logic across four concurrency and ownership scenarios.

## Key Components

| Method | What it verifies |
|---|---|
| `new_token_is_created_and_filtered_by_token_only` | New token triggers an upsert; query filter contains the token value (tenant injected by template) |
| `existing_token_is_reassociated_to_the_caller` | Existing token upsert uses `$set` on `userId` so a reassigned device stops delivering pushes to the prior owner |
| `lost_insert_race_settles_with_a_plain_update` | `DuplicateKeyException` from a concurrent insert falls back to `updateFirst` instead of retrying the upsert |
| `registration_is_not_lost_if_the_winning_row_disappears` | If `updateFirst` matches nothing (row deleted mid-race), a second upsert is issued to avoid silently dropping the registration |

Helper factories (`upserted`, `matchedAndUpdated`, `matchedNothing`) produce typed `UpdateResult` mocks that drive the boolean return value of `registerToken`.

## Usage Example

```java
// Reproducing the race-condition fallback path in isolation
when(mongoTemplate.upsert(...))
    .thenThrow(new DuplicateKeyException("E11000 duplicate key"))
    .thenReturn(inserted);          // second call succeeds
when(mongoTemplate.updateFirst(...))
    .thenReturn(matchedNothing());  // row vanished before update

boolean created = repository.registerToken("alice", "tok-1", PushPlatform.IOS);
assertThat(created).isTrue();       // second upsert succeeded → device is registered

// Verify exactly two upsert attempts were made
verify(mongoTemplate, times(2))
    .upsert(any(Query.class), any(Update.class), eq(PushDevice.class));
```

## Notes

- Uses **Mockito** `ArgumentCaptor` to assert on query/update document contents rather than just call counts.
- The four tests map directly to the four branches in the production method: insert, update, race-lost-then-updated, race-lost-then-deleted.
- `TenantAwareMongoTemplate` is mocked, so tenant isolation logic is tested at the template layer separately.
