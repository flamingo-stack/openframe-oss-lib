Integration test suite for `CustomOrganizationRepositoryImpl`, verifying MongoDB-backed organization querying and keyset pagination using Testcontainers.

## Key Components

| Component | Description |
|---|---|
| `walkByLastActivity()` | Helper that exhausts all pages via compound `(updatedAt, _id)` cursor, collecting names in visit order |
| `save()` | Utility to persist an `Organization` with a controlled `updatedAt` timestamp |
| `compoundCursor()` | Builds the `epochMillis_id` cursor string used by the `updatedAt` sort path |
| `activeFilter()` | Produces a reusable `OrganizationQueryFilter` scoped to `ACTIVE` status |

## Test Coverage

| Test | What It Verifies |
|---|---|
| `lastActivityRangeInclusive` | `lastActivityFrom` and `lastActivityTo` are both inclusive bounds |
| `lastActivityFromOnly` | Lower-bound filter applied without an upper bound |
| `lastActivityToOnly` | Upper-bound filter applied without a lower bound |
| `descPaginationCoversAllPages` | DESC keyset walk returns all 5 records in correct reverse order |
| `ascPaginationCoversAllPages` | ASC keyset walk returns all 5 records in correct natural order |
| `tieBreakerForEqualLastActivity` | `_id` tie-breaker ensures deterministic, duplicate-free paging when `updatedAt` values collide |
| `countReturnsFilteredTotal` | `countOrganizations` reflects the full filtered total regardless of page size |
| `legacyIdCursorPaginates` | Legacy `_id`-only cursor path produces non-overlapping pages |

## Usage Example

```java
// Enabled only when -Dintegration.tests=true is passed to the JVM
// Run via Maven:
// mvn verify -Dintegration.tests=true

// Typical page-walk pattern exercised by the tests:
Query query = repository.buildOrganizationQuery(activeFilter(), null);
List<Organization> page = repository.findOrganizationsWithCursor(
        query, /* cursor */ null, /* pageSize */ 20, "updatedAt", "DESC");

// Advance to next page using compound cursor:
String nextCursor = page.get(page.size() - 1).getUpdatedAt().toEpochMilli()
        + "_" + page.get(page.size() - 1).getId();
```

> **Note:** Tests are gated by `@EnabledIfSystemProperty(named = "integration.tests", matches = "true")` and require a running MongoDB instance managed by Testcontainers via `BaseMongoIntegrationTest`.
