Unit test suite for `NotificationContextWriteConverter`, verifying the conversion of `NotificationContext` objects into BSON `Document` instances for MongoDB persistence.

## Key Components

| Test Method | Purpose |
|---|---|
| `given_null_source_when_converting_then_returns_null` | Ensures null input returns null without invoking Jackson |
| `given_generic_context_when_converting_then_document_contains_type_and_payload` | Validates a populated `GenericContext` produces a BSON document with correct `type` and `payload` fields |
| `given_jackson_failure_when_converting_then_throws_with_type_in_message` | Confirms a Jackson serialization failure wraps into an `IllegalStateException` with the discriminator type in the message for production diagnostics |

## Usage Example

```java
// Instantiate the converter under test with a real or mocked ObjectMapper
ObjectMapper objectMapper = new ObjectMapper();
NotificationContextWriteConverter converter = new NotificationContextWriteConverter(objectMapper);

// Convert a GenericContext to a BSON Document
GenericContext context = GenericContext.builder()
        .type("GENERIC")
        .payload("hello")
        .build();

Document bsonDoc = converter.convert(context);
// bsonDoc.getString("type")    → "GENERIC"
// bsonDoc.getString("payload") → "hello"

// Null input short-circuits without touching Jackson
Document nullResult = converter.convert(null);
// nullResult → null
```

## Notes

- Uses **Mockito BDD-style** stubbing (`given(...).willThrow(...)`) to simulate Jackson failures without real serialization.
- The `IllegalStateException` message includes the **type discriminator** (`EXOTIC_TYPE`), ensuring failures remain diagnosable in production logs.
