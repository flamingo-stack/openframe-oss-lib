A DTO used to carry filter criteria when querying time entries, supporting filtering by employees, organizations, and a date/time range.

## Key Components

| Field | Type | Description |
|---|---|---|
| `employeeIds` | `List<String>` | Filter results to specific employee IDs |
| `organizationIds` | `List<String>` | Filter results to specific organization IDs |
| `startedFrom` | `Instant` | Lower bound (inclusive) of the time entry start range |
| `startedTo` | `Instant` | Upper bound (inclusive) of the time entry start range |

Lombok annotations (`@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor`) generate getters/setters, a fluent builder, and both no-arg and all-arg constructors.

## Usage Example

```java
// Builder pattern — filter by org and date range
TimeEntryFilterInput filter = TimeEntryFilterInput.builder()
    .organizationIds(List.of("org-001", "org-002"))
    .startedFrom(Instant.parse("2024-01-01T00:00:00Z"))
    .startedTo(Instant.parse("2024-01-31T23:59:59Z"))
    .build();

// Builder pattern — filter by specific employees
TimeEntryFilterInput employeeFilter = TimeEntryFilterInput.builder()
    .employeeIds(List.of("emp-123", "emp-456"))
    .build();
```

> **Note:** All fields are optional. Passing `null` for any field is treated as "no filter applied" for that criterion, allowing partial or fully open-ended queries.
