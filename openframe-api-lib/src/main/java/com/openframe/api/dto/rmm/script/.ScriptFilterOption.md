A DTO representing a single option in a script-list filter dropdown, carrying the filter value, display label, and the count of matching scripts. Mirrors the structure of `DeviceFilterOption`.

## Key Components

| Field | Type | Description |
|---|---|---|
| `value` | `String` | Raw filter value used in query logic |
| `label` | `String` | Human-readable label displayed in the UI dropdown |
| `count` | `Integer` | Number of scripts matching this filter option |

Lombok annotations (`@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor`) auto-generate getters/setters, a builder pattern, and both no-arg and all-arg constructors.

## Usage Example

```java
// Build via constructor
ScriptFilterOption option = new ScriptFilterOption("bash", "Bash Scripts", 42);

// Build via builder
ScriptFilterOption option = ScriptFilterOption.builder()
    .value("powershell")
    .label("PowerShell Scripts")
    .count(17)
    .build();
```

## Notes

- Typically used as part of a filter-options response when populating script-list dropdowns (e.g., filtering by OS type, category, or author).
- Designed as a plain DTO with no validation annotations — validation is expected upstream.
