A command DTO used to finalize an active timer session in the time tracking system. Optionally overrides staged `ticketId` or `notes` values set during timer start or edit operations; the resulting entry must satisfy the "ticket or notes required" invariant.

## Key Components

| Field | Type | Description |
|---|---|---|
| `ticketId` | `String` | Optional ticket reference; overrides any staged value |
| `organizationId` | `String` | Scopes the stop operation to a specific organization |
| `notes` | `String` | Optional free-text notes; overrides any staged value |

## Usage Example

```java
// Stop a timer and attach it to a ticket
StopTimerCommand command = StopTimerCommand.builder()
    .organizationId("org-123")
    .ticketId("TICKET-456")
    .build();

// Stop a timer with notes only (no ticket)
StopTimerCommand notesOnly = StopTimerCommand.builder()
    .organizationId("org-123")
    .notes("Investigated network latency on client router.")
    .build();
```

> **Invariant:** At least one of `ticketId` or `notes` must be present when the timer is finalized. Passing neither will fail validation at the service layer.
