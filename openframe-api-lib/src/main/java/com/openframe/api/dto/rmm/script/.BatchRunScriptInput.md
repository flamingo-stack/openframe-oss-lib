DTO for submitting a batch script execution request across multiple machines in the RMM (Remote Monitoring and Management) module.

## Key Components

| Field | Type | Description |
|---|---|---|
| `MAX_BATCH_SIZE` | `int` (100) | Maximum number of machines per batch |
| `machineIds` | `List<String>` | Non-empty list of target machine IDs (alphanumeric, `_`, `-` only) |
| `scriptId` | `String` | ID of the script to execute |
| `privilegeLevel` | `PrivilegeLevel` | Required execution privilege level |
| `args` | `List<String>` | Optional argument override for the script's `defaultArgs` |
| `timeoutSeconds` | `Integer` | Optional timeout (1–600 seconds); max 10 minutes |
| `envVars` | `List<ScriptEnvVarInput>` | Optional runtime env vars merged over stored script env vars (same name overrides) |

## Validation Rules

- `machineIds`: non-empty, max 100 entries, each matching `^[A-Za-z0-9_-]+$`
- `scriptId`: non-blank string
- `privilegeLevel`: non-null
- `timeoutSeconds`: positive integer, max 600
- `envVars`: each entry validated via `@Valid` → `ScriptEnvVarInput`

## Usage Example

```java
BatchRunScriptInput input = new BatchRunScriptInput();
input.setMachineIds(List.of("machine_001", "machine-002"));
input.setScriptId("script-abc123");
input.setPrivilegeLevel(PrivilegeLevel.ADMIN);
input.setTimeoutSeconds(120);
input.setArgs(List.of("--verbose", "--dry-run"));

ScriptEnvVarInput envVar = new ScriptEnvVarInput();
envVar.setName("LOG_LEVEL");
envVar.setValue("DEBUG");
input.setEnvVars(List.of(envVar));
```

> **Note:** `envVars` are merged at runtime over the script's stored environment variables — duplicate names in `envVars` take precedence over stored values.
