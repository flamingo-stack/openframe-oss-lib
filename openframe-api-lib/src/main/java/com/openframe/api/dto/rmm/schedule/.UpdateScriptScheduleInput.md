DTO for fully replacing an existing script schedule via PUT semantics. All writable fields overwrite stored values, including `null`s which clear the respective field — callers must send the complete resource on every update.

## Key Components

| Field | Type | Constraints | Description |
|---|---|---|---|
| `id` | `String` | `@NotBlank` | Unique identifier of the schedule to update |
| `name` | `String` | `@NotBlank` | Display name of the schedule |
| `description` | `String` | — | Optional description; `null` clears the stored value |
| `supportedPlatforms` | `List<ScriptPlatform>` | — | Target OS/platform filters; `null` clears platforms |
| `scriptIds` | `List<String>` | — | Scripts to execute; `null` clears the list |
| `trigger` | `ScriptScheduleTrigger` | `@NotNull` | Execution trigger type |
| `startAt` | `Instant` | — | First run as an absolute UTC instant; `null` stops scheduling |
| `repeat` | `Long` | `@Min(1800)` | Recurrence interval in seconds (30-min grid); `null` = one-shot |

## Usage Example

```java
UpdateScriptScheduleInput input = new UpdateScriptScheduleInput();
input.setId("sched_abc123");
input.setName("Weekly Patch Run");
input.setDescription("Applies patches every Sunday at 02:00 UTC");
input.setSupportedPlatforms(List.of(ScriptPlatform.WINDOWS, ScriptPlatform.LINUX));
input.setScriptIds(List.of("script_001", "script_002"));
input.setTrigger(ScriptScheduleTrigger.RECURRING);
input.setStartAt(Instant.parse("2025-01-05T02:00:00Z"));
input.setRepeat(604800L); // 7 days in seconds

// Pass to service layer
scriptScheduleService.update(input);
```

> **Note:** `repeat` must be a multiple of `1800` (30 minutes) to align with the runner's tick grid. Setting `startAt` to `null` halts the schedule; changing it reschedules the next run via `ScriptScheduleService.update`.
