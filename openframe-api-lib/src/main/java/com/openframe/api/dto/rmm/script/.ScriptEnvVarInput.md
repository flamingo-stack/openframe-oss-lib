Symmetric DTO representing a single script environment variable, used for both create/update requests and API responses.

## Key Components

| Member | Type | Description |
|---|---|---|
| `name` | `String` | Variable name; required (`@NotBlank`) |
| `value` | `String` | Variable value; may be `null` for secret variables awaiting injection |
| `secret` | `boolean` | Marks the value as sensitive (passwords, API keys, tokens) |

## Usage Example

```java
// Build a plain environment variable
ScriptEnvVarInput dbHost = ScriptEnvVarInput.builder()
    .name("DB_HOST")
    .value("db.internal.example.com")
    .secret(false)
    .build();

// Build a secret environment variable
ScriptEnvVarInput apiKey = ScriptEnvVarInput.builder()
    .name("API_KEY")
    .value("sk-abc123")
    .secret(true)
    .build();
```

## Notes

- The DTO is intentionally symmetric — the same class is used for both inbound payloads and outbound responses, keeping the API shape consistent.
- **Secret handling is incomplete**: until the secret-management story (encryption at rest + secure agent delivery) is implemented, `secret=true` values are stored in plaintext. UI layers and audit logs are responsible for masking until then. See the [source file](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/api/dto/rmm/script/ScriptEnvVarInput.java) for the tracked TODO.
