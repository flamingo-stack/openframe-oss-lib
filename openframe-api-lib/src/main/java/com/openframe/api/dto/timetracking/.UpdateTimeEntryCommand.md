A command DTO used to update an existing time entry. Null fields are treated as "leave unchanged," while empty strings for `ticketId`, `notes`, and `organizationId` explicitly clear those values.

## Key Components

| Field | Type | Description |
|---|---|---|
| `id` | `String` | Identifier of the time entry to update |
| `userId` | `String` | User associated with the time entry |
| `ticketId` | `String` | Linked ticket; empty string clears the value |
| `organizationId` | `String` | Linked organization; empty string clears the value |
| `notes` | `String` | Entry notes; empty string clears the value |
| `startedAt` | `Instant` | Start timestamp of the time entry |
| `durationSeconds` | `Long` | Duration of the entry in seconds |

## Usage Example

```java
// Update only the duration and notes; leave all other fields unchanged
UpdateTimeEntryCommand command = UpdateTimeEntryCommand.builder()
    .id("entry-abc123")
    .durationSeconds(3600L)
    .notes("Resolved network configuration issue")
    .build();

// Explicitly clear the ticketId association
UpdateTimeEntryCommand clearTicket = UpdateTimeEntryCommand.builder()
    .id("entry-abc123")
    .ticketId("")
    .build();
```

> **Null vs. empty string:** Pass `null` to leave a field unchanged; pass `""` to clear `ticketId`, `notes`, or `organizationId`.
