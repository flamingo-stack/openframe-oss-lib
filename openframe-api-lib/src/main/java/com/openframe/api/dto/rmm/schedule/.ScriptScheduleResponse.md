Immutable API response DTO representing a script schedule resource returned to callers. The internal `tenantId` is intentionally excluded since the caller's tenant context is derived from authentication.

## Key Components

| Field | Type | Description |
|---|---|---|
| `id` | `String` | Unique schedule identifier |
| `name` / `description` | `String` | Human-readable schedule metadata |
| `supportedPlatforms` | `List<String>` | Target OS/platform identifiers (e.g., `Windows`, `Linux`) |
| `scriptIds` | `List<String>` | Ordered list of script IDs to execute |
| `trigger` | `String` | Schedule trigger expression (e.g., cron string or event name) |
| `startAt` / `nextRunAt` / `lastRunAt` | `Instant` | Temporal anchors for schedule execution lifecycle |
| `repeat` | `Long` | Repeat interval in milliseconds (or seconds, per contract) |
| `createdBy` | `String` | Identity of the schedule creator |
| `status` | `String` | Current schedule state (e.g., `ACTIVE`, `PAUSED`) |
| `statusChangedAt` / `createdAt` / `updatedAt` | `Instant` | Audit timestamps |

Lombok `@Data` generates getters, setters, `equals`, `hashCode`, and `toString`. `@Builder` provides a fluent construction API.

## Usage Example

```java
ScriptScheduleResponse response = ScriptScheduleResponse.builder()
    .id("sched-abc123")
    .name("Nightly Patch Run")
    .description("Applies OS patches across managed endpoints")
    .supportedPlatforms(List.of("Windows", "Linux"))
    .scriptIds(List.of("script-001", "script-002"))
    .trigger("0 2 * * *")
    .startAt(Instant.parse("2024-01-01T02:00:00Z"))
    .repeat(86400000L)
    .nextRunAt(Instant.now().plusSeconds(3600))
    .status("ACTIVE")
    .createdBy("user-xyz")
    .createdAt(Instant.now())
    .updatedAt(Instant.now())
    .build();
```
