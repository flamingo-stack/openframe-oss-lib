Data Transfer Object (DTO) representing a script resource in the RMM (Remote Monitoring & Management) API response layer, omitting internal tenant context from the wire format.

## Key Components

| Field | Type | Description |
|---|---|---|
| `id` | `String` | Unique script identifier |
| `name` / `description` | `String` | Human-readable metadata |
| `shell` | `String` | Shell enum name (e.g. `POWERSHELL`) |
| `privilegeLevel` | `PrivilegeLevel` | Execution privilege — `USER` or `ADMIN` |
| `scriptBody` | `String` | Raw script content |
| `supportedPlatforms` | `List<String>` | Serialized platform enum names |
| `defaultTimeoutSeconds` | `Integer` | Execution timeout |
| `defaultArgs` / `envVars` | `List` | Runtime parameters and environment variables |
| `createdBy` | `String` | Author user ID; resolved via GraphQL `author` field |
| `status` | `String` | Lifecycle status enum name (e.g. `ACTIVE`) |
| `statusChangedAt` / `createdAt` / `updatedAt` | `Instant` | Audit timestamps |

Lombok `@Data` + `@Builder` provide accessors, `equals`/`hashCode`, and a fluent builder automatically.

## Usage Example

```java
ScriptResponse response = ScriptResponse.builder()
    .id("script-001")
    .name("Disk Cleanup")
    .shell("POWERSHELL")
    .privilegeLevel(PrivilegeLevel.ADMIN)
    .scriptBody("Remove-Item -Path $env:TEMP\\* -Recurse -Force")
    .supportedPlatforms(List.of("WINDOWS"))
    .defaultTimeoutSeconds(300)
    .status("ACTIVE")
    .createdBy("user-abc")
    .createdAt(Instant.now())
    .build();
```

> **Note:** `tenantId` is intentionally excluded — the caller's tenant is resolved from authentication context and never serialized to the wire.
