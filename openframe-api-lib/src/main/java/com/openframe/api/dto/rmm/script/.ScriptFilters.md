Represents the available faceted filter options (with live counts) for the scripts list, serving as the script-domain counterpart to `DeviceFilters`. Each filter facet is computed with all other active filters applied but excluding its own field, ensuring dropdowns continue to offer all switchable values.

## Key Components

| Field | Type | Description |
|---|---|---|
| `shells` | `List<ScriptFilterOption>` | Available shell types with counts (e.g., PowerShell, Bash) |
| `platforms` | `List<ScriptFilterOption>` | Available target platforms with counts |
| `authors` | `List<ScriptFilterOption>` | Available script authors with counts |
| `filteredCount` | `Integer` | Total scripts matching ALL currently active filters |

## Usage Example

```java
// Build a ScriptFilters response for a script listing endpoint
ScriptFilters filters = ScriptFilters.builder()
    .shells(List.of(
        new ScriptFilterOption("powershell", 42),
        new ScriptFilterOption("bash", 17)
    ))
    .platforms(List.of(
        new ScriptFilterOption("windows", 38),
        new ScriptFilterOption("linux", 21)
    ))
    .authors(List.of(
        new ScriptFilterOption("admin", 30),
        new ScriptFilterOption("jdoe", 29)
    ))
    .filteredCount(59)
    .build();
```

## Notes

- Faceted counts are computed independently per dimension — each facet excludes its own field from the filter predicate, preserving all selectable options even when other filters are active.
- Pairs with [`ScriptFilterOption`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/api/dto/rmm/script/ScriptFilterOption.java) for individual option label/count pairs.
- Lombok annotations (`@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor`) generate all boilerplate automatically.
