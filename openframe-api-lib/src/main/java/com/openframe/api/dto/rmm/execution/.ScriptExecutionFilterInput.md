Represents the API-layer filter input for querying script execution history, carrying optional constraints on execution status, initiating users, and target devices.

## Key Components

| Field | Type | Description |
|---|---|---|
| `statuses` | `List<ExecutionStatus>` | Filter by one or more execution statuses; `null`/empty disables this constraint |
| `initiatorIds` | `List<String>` | Filter by raw (non-Relay-encoded) IDs of users who initiated executions |
| `machineIds` | `List<String>` | Filter by raw (non-Relay-encoded) machine IDs of target devices; `null`/empty disables this constraint |

Generated via Lombok: `@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor`.

> **Note:** This DTO mirrors `ScriptFilterInput` at the API layer. The service layer maps it to the data-layer `ScriptExecutionQueryFilter`.

## Usage Example

```java
// Build a filter for failed or timed-out executions on specific machines
ScriptExecutionFilterInput filter = ScriptExecutionFilterInput.builder()
    .statuses(List.of(ExecutionStatus.FAILED, ExecutionStatus.TIMED_OUT))
    .initiatorIds(List.of("user-abc123", "user-def456"))
    .machineIds(List.of("machine-001", "machine-002"))
    .build();

// Pass to the execution history service
Page<ScriptExecutionSummary> history = executionService.listExecutions(filter, pageable);
```
