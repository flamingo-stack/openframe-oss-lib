Utility class for generating stable, opaque cursor strings used in cursor-based pagination of `Organization` records.

## Key Components

| Member | Type | Description |
|---|---|---|
| `LAST_ACTIVITY_FIELD` | `public static final String` | Document field name (`"updatedAt"`) used as the sort key for cursor-based pagination |
| `lastActivity(Organization)` | `static String` | Generates a composite cursor string encoding the organization's last activity timestamp and ID |
| `OrganizationCursors()` | `private` constructor | Prevents instantiation; this is a pure utility class |

## Cursor Format

The `lastActivity` cursor is a composite string with the format:

```text
{epochMillis}_{organizationId}
```

**Fallback chain for the timestamp component:**
1. `updatedAt` (preferred)
2. `createdAt` (if `updatedAt` is null)
3. `0` (if both are null)

This ensures cursors remain sortable and unique even for partially populated records.

## Usage Example

```java
// Generating a cursor for the last item in a page
Organization org = organizationRepository.findById("org-123");
String cursor = OrganizationCursors.lastActivity(org);
// e.g. "1718000000000_org-123"

// Use the cursor field constant when building queries
Sort sort = Sort.by(OrganizationCursors.LAST_ACTIVITY_FIELD).ascending();
```

## Notes

- The `_` separator guarantees the cursor can be split unambiguously since epoch milliseconds contain only digits.
- Cursors are intended to be **opaque** to clients; do not parse them on the consumer side.
