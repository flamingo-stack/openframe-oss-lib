Data Transfer Object (DTO) capturing the validated input required to dispatch an ad-hoc shell command to a remote agent via the OpenFrame GraphQL API.

## Key Components

| Field | Type | Constraints |
|---|---|---|
| `machineId` | `String` | Non-blank; alphanumeric + `_-` only (subject-safe token) |
| `command` | `String` | Non-blank |
| `shell` | `ScriptShell` | Non-null enum; specifies shell interpreter |
| `privilegeLevel` | `PrivilegeLevel` | Non-null enum; e.g. standard vs. elevated |
| `timeoutSeconds` | `Integer` | Positive; max `600` (10 minutes) |

## Usage Example

```java
RunCommandInput input = new RunCommandInput();
input.setMachineId("agent-node_01");
input.setCommand("Get-Service | Where-Object { $_.Status -eq 'Running' }");
input.setShell(ScriptShell.POWERSHELL);
input.setPrivilegeLevel(PrivilegeLevel.ADMIN);
input.setTimeoutSeconds(30);
```

> **Note:** `machineId` is validated against `^[A-Za-z0-9_-]+$` to ensure it is safe for use as a NATS subject token. Commands exceeding 600 seconds will fail Bean Validation before dispatch.
