Data Transfer Object (DTO) for the `batchRunCommand` GraphQL mutation, carrying the payload needed to dispatch a single ad-hoc shell command to multiple agents simultaneously.

## Key Components

| Field | Type | Constraints | Description |
|---|---|---|---|
| `MAX_BATCH_SIZE` | `int` (constant) | — | Hard cap of 100 machines per batch to prevent unbounded NATS fan-out |
| `machineIds` | `List<String>` | `@NotEmpty`, `@Size(max=100)`, each entry `@Pattern(^[A-Za-z0-9_-]+$)` | Target agent machine IDs; must be NATS subject-safe tokens |
| `command` | `String` | `@NotBlank` | The shell command to execute |
| `shell` | `ScriptShell` | `@NotNull` | Shell interpreter (e.g., `bash`, `powershell`) |
| `privilegeLevel` | `PrivilegeLevel` | `@NotNull` | Execution privilege level (e.g., standard vs. elevated) |
| `timeoutSeconds` | `Integer` | `@Positive`, `@Max(600)` | Execution timeout; capped at 600 seconds (10 minutes) |

## Usage Example

```java
BatchRunCommandInput input = new BatchRunCommandInput();

input.setMachineIds(List.of("agent_001", "agent_002", "agent-003"));
input.setCommand("df -h");
input.setShell(ScriptShell.BASH);
input.setPrivilegeLevel(PrivilegeLevel.STANDARD);
input.setTimeoutSeconds(30);

// Pass to the batchRunCommand GraphQL resolver — the server mints
// a shared executionId and publishes to each
// machine.<id>.command-execution NATS subject.
```

> **NATS subject safety:** Every entry in `machineIds` is validated against `^[A-Za-z0-9_-]+$` before the server interpolates it into the NATS subject `machine.<id>.command-execution`, preventing subject injection.
