Data Transfer Object (DTO) for capturing the input required to cancel an ongoing state machine execution, with validation constraints on both fields.

## Key Components

| Element | Description |
|---|---|
| `machineId` | Alphanumeric machine identifier; validated as a single subject-safe token matching `^[A-Za-z0-9_-]+$` |
| `executionId` | Non-blank string identifying the specific execution to cancel |
| `@Data` | Lombok annotation generating getters, setters, `equals`, `hashCode`, and `toString` |
| `@NotBlank` | Ensures neither field is null or whitespace |
| `@Pattern` | Restricts `machineId` to URL/subject-safe characters only |

## Usage Example

```java
CancelExecutionInput input = new CancelExecutionInput();
input.setMachineId("order-processor_v2");
input.setExecutionId("exec-7f3a1b9c");

// Typically deserialized from an HTTP request body and validated
// by the Jakarta Bean Validation framework before reaching the service layer
Set<ConstraintViolation<CancelExecutionInput>> violations =
    validator.validate(input);

if (violations.isEmpty()) {
    executionService.cancel(input.getMachineId(), input.getExecutionId());
}
```

> **Validation note:** `machineId` values containing spaces, dots, or special characters (e.g., `order.processor` or `my machine`) will fail the `@Pattern` constraint. Use only `A-Z`, `a-z`, `0-9`, `_`, or `-`.
