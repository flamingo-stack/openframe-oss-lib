A data transfer object (DTO) representing the command payload for creating a new time entry in the time tracking system.

## Key Components

| Field | Type | Description |
|---|---|---|
| `userId` | `String` | ID of the user logging the time |
| `ticketId` | `String` | Associated ticket reference |
| `organizationId` | `String` | Organization context for the entry |
| `notes` | `String` | Optional descriptive notes |
| `startedAt` | `Instant` | UTC timestamp when work began |
| `durationSeconds` | `long` | Duration of the time entry in seconds |

## Usage Example

```java
CreateTimeEntryCommand command = CreateTimeEntryCommand.builder()
    .userId("usr_abc123")
    .ticketId("tkt_xyz789")
    .organizationId("org_flamingo01")
    .notes("Investigated network connectivity issue")
    .startedAt(Instant.now())
    .durationSeconds(3600L)
    .build();
```

> Supports both builder and all-args constructor patterns via Lombok annotations (`@Builder`, `@AllArgsConstructor`, `@NoArgsConstructor`).
