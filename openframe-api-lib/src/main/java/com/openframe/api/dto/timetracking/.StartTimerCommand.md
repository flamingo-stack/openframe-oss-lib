A Data Transfer Object (DTO) representing the command payload to initiate a time tracking timer for a specific ticket within an organization.

## Key Components

| Field | Type | Description |
|---|---|---|
| `ticketId` | `String` | Identifier of the ticket to track time against |
| `organizationId` | `String` | Identifier of the organization owning the ticket |
| `notes` | `String` | Optional notes to associate with the timer session |

**Lombok Annotations:**
- `@Data` — generates getters, setters, `equals`, `hashCode`, and `toString`
- `@Builder` — enables fluent builder pattern construction
- `@NoArgsConstructor` / `@AllArgsConstructor` — generates both default and full constructors

## Usage Example

```java
// Using the builder pattern
StartTimerCommand command = StartTimerCommand.builder()
    .ticketId("TKT-1042")
    .organizationId("org-abc123")
    .notes("Investigating network latency issue")
    .build();

// Using the all-args constructor
StartTimerCommand command = new StartTimerCommand("TKT-1042", "org-abc123", "Initial triage");
```
