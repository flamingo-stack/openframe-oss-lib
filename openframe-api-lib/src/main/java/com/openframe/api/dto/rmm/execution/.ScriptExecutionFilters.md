Represents the available filter facets and their live counts for a single script's Execution History view, serving as the execution-specific counterpart to `ScriptFilters`.

## Key Components

| Field | Type | Description |
|---|---|---|
| `initiators` | `List<ScriptFilterOption>` | "Executed by" facet — who triggered each execution |
| `statuses` | `List<ScriptFilterOption>` | Execution result/status facet |
| `machines` | `List<ScriptFilterOption>` | Target machine facet |
| `filteredCount` | `Integer` | Total executions matching all currently active filters |

Each facet entry reuses [`ScriptFilterOption`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/api/dto/rmm/script/ScriptFilterOption.java), which carries a `value`, `label`, and live `count`.

## Usage Example

```java
ScriptExecutionFilters filters = ScriptExecutionFilters.builder()
    .initiators(List.of(
        new ScriptFilterOption("user-1", "Alice", 12),
        new ScriptFilterOption("user-2", "Bob", 5)
    ))
    .statuses(List.of(
        new ScriptFilterOption("SUCCESS", "Success", 14),
        new ScriptFilterOption("FAILED", "Failed", 3)
    ))
    .machines(List.of(
        new ScriptFilterOption("machine-42", "DESKTOP-ABC", 7)
    ))
    .filteredCount(17)
    .build();
```

The `filteredCount` reflects the total matching executions after **all** active filters are applied, not the sum of any individual facet.
