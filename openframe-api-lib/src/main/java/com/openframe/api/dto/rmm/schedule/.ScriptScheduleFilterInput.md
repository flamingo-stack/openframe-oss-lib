A filter input DTO used to query and narrow down script schedules based on status, platform compatibility, and authorship criteria.

## Key Components

| Field | Type | Description |
|---|---|---|
| `statuses` | `List<ScriptStatus>` | Filter by one or more script lifecycle statuses |
| `supportedPlatforms` | `List<ScriptPlatform>` | Filter by target platform(s) the script supports |
| `authorIds` | `List<String>` | Filter by one or more author identifiers |

## Usage Example

```java
ScriptScheduleFilterInput filter = ScriptScheduleFilterInput.builder()
    .statuses(List.of(ScriptStatus.ACTIVE))
    .supportedPlatforms(List.of(ScriptPlatform.WINDOWS, ScriptPlatform.LINUX))
    .authorIds(List.of("user-123", "user-456"))
    .build();
```

All fields are optional — omit any to skip that filter criterion. Powered by Lombok (`@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor`) for zero-boilerplate construction, mutation, and equality checks.
