Internal DTO used to encapsulate filter criteria when querying organizations, supporting filtering by category, employee count range, contract status, activity window, and general status.

## Key Components

| Field | Type | Description |
|---|---|---|
| `category` | `String` | Filter organizations by category |
| `minEmployees` | `Integer` | Minimum employee count bound |
| `maxEmployees` | `Integer` | Maximum employee count bound |
| `hasActiveContract` | `Boolean` | Filter by active contract presence |
| `status` | `String` | Filter by organization status |
| `lastActivityFrom` | `Instant` | Start of last activity time window |
| `lastActivityTo` | `Instant` | End of last activity time window |

Built with Lombok annotations (`@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor`) for automatic generation of getters, setters, and builder pattern support.

## Usage Example

```java
OrganizationFilterOptions filters = OrganizationFilterOptions.builder()
    .category("MSP")
    .minEmployees(10)
    .maxEmployees(500)
    .hasActiveContract(true)
    .status("ACTIVE")
    .lastActivityFrom(Instant.now().minus(30, ChronoUnit.DAYS))
    .lastActivityTo(Instant.now())
    .build();

List<Organization> results = organizationService.findAll(filters);
```

## Notes

- All fields are optional; unset fields are ignored during query construction.
- `lastActivityFrom` / `lastActivityTo` should be provided as a pair when filtering by activity window.
