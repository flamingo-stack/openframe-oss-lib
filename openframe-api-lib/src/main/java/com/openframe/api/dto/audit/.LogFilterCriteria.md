A DTO (Data Transfer Object) used to encapsulate filter criteria for querying audit logs within the OpenFrame API.

## Key Components

| Field | Type | Description |
|---|---|---|
| `startDate` | `LocalDate` | Start of the date range filter |
| `endDate` | `LocalDate` | End of the date range filter |
| `timestampFrom` | `Instant` | Precise start timestamp for filtering |
| `timestampTo` | `Instant` | Precise end timestamp for filtering |
| `eventTypes` | `List<String>` | Filter by specific audit event types |
| `toolTypes` | `List<String>` | Filter by tool/integration types |
| `severities` | `List<String>` | Filter by log severity levels |
| `organizationIds` | `List<String>` | Filter logs scoped to specific organizations |
| `deviceId` | `String` | Filter logs for a single device |

Lombok annotations (`@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor`) auto-generate getters/setters, a fluent builder, and constructors.

## Usage Example

```java
LogFilterCriteria criteria = LogFilterCriteria.builder()
    .startDate(LocalDate.now().minusDays(7))
    .endDate(LocalDate.now())
    .severities(List.of("ERROR", "WARN"))
    .organizationIds(List.of("org-123", "org-456"))
    .eventTypes(List.of("LOGIN", "CONFIG_CHANGE"))
    .deviceId("device-789")
    .build();

// Pass to audit log service or repository
List<AuditLog> logs = auditLogService.findByCriteria(criteria);
```

> **Note:** `startDate`/`endDate` provide day-level granularity, while `timestampFrom`/`timestampTo` allow precise millisecond-level filtering. Use both together for fine-grained range queries.
