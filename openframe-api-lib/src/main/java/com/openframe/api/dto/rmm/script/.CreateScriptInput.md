Data Transfer Object (DTO) representing the validated request payload for creating a new RMM script. Tenant attribution is derived from the authenticated principal server-side; clients must not supply tenant information.

## Key Components

| Field | Type | Constraints | Description |
|---|---|---|---|
| `name` | `String` | `@NotBlank` | Display name for the script |
| `description` | `String` | — | Optional human-readable description |
| `shell` | `ScriptShell` | `@NotNull` | Target shell/interpreter (e.g., PowerShell, Bash) |
| `privilegeLevel` | `PrivilegeLevel` | `@NotNull` | Execution privilege level (e.g., admin, standard) |
| `scriptBody` | `String` | `@NotBlank` | Raw script content |
| `supportedPlatforms` | `List<ScriptPlatform>` | — | Platforms the script is compatible with |
| `defaultTimeoutSeconds` | `Integer` | `@Positive`, `@Max(600)` | Execution timeout; capped at 600 s (10 min) |
| `defaultArgs` | `List<String>` | — | Optional default arguments passed at runtime |
| `envVars` | `List<ScriptEnvVarInput>` | `@Valid` | Cascading validation on each env var entry |
| `tagIds` | `List<String>` | — | Tag references for categorisation/filtering |

## Usage Example

```java
CreateScriptInput input = new CreateScriptInput();
input.setName("Disk Cleanup");
input.setDescription("Removes temp files older than 7 days");
input.setShell(ScriptShell.POWERSHELL);
input.setPrivilegeLevel(PrivilegeLevel.ADMIN);
input.setScriptBody("Remove-Item $env:TEMP\\* -Recurse -Force");
input.setSupportedPlatforms(List.of(ScriptPlatform.WINDOWS));
input.setDefaultTimeoutSeconds(120);
input.setTagIds(List.of("tag-abc123"));
```

> **Security note:** The `tenantId` is intentionally absent from this DTO. It is always resolved from the authenticated principal at the controller/resolver layer to prevent tenant-spoofing attacks.
