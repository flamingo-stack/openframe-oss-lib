Immutable DTO that carries aggregated work-time statistics for a single employee, used to populate the Employee Work Time dashboard block.

## Key Components

| Field | Type | Description |
|---|---|---|
| `todayTotalSeconds` | `long` | Total tracked seconds for the current calendar day |
| `todayEntryCount` | `long` | Number of time entries logged today |
| `periodTotalSeconds` | `long` | Total tracked seconds across the selected reporting period |
| `periodEntryCount` | `long` | Number of time entries in the reporting period |
| `averagePerDaySeconds` | `long` | `periodTotalSeconds` ÷ distinct active days; `0` when no time was tracked |

All durations are raw seconds — formatting to `HH:MM:SS` is handled by the UI layer.

Lombok annotations (`@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor`) generate getters, setters, a fluent builder, and both constructors automatically.

## Usage Example

```java
// Build from aggregated query results
EmployeeTimeStats stats = EmployeeTimeStats.builder()
    .todayTotalSeconds(3600L)
    .todayEntryCount(2L)
    .periodTotalSeconds(72000L)
    .periodEntryCount(18L)
    .averagePerDaySeconds(14400L)
    .build();

// Access in a service or controller
long avgSeconds = stats.getAveragePerDaySeconds(); // 14400 → "04:00:00" in UI
```

## Notes

- `averagePerDaySeconds` excludes days with zero tracked time from the denominator, preventing artificially low averages over sparse periods.
- Part of the `com.openframe.api.dto.timetracking` package — see related DTOs in [`openframe-oss-lib`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/api/dto/timetracking/).
