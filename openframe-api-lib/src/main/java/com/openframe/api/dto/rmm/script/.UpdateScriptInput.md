DTO for replacing an existing RMM script resource via PUT semantics. All fields are overwritten on the stored document, including `null` values that clear optional fields — partial updates are not supported.

## Key Components

| Field | Type | Constraints | Description |
|---|---|---|---|
| `id` | `String` | `@NotBlank` | ID of the script to update |
| `name` | `String` | `@NotBlank` | Display name of the script |
| `description` | `String` | Optional | Clears stored value if `null` |
| `shell` | `ScriptShell` | `@NotNull` | Target shell/interpreter |
| `privilegeLevel` | `PrivilegeLevel` | `@NotNull` | Execution privilege level |
| `scriptBody` | `String` | `@NotBlank` | Full script source code |
| `supportedPlatforms` | `List<ScriptPlatform>` | Optional | Clears stored value if `null` |
| `defaultTimeoutSeconds` | `Integer` | `@Positive`, `@Max(600)` | Max 10 minutes; `null` clears |
| `defaultArgs` | `List<String>` | Optional | Clears stored value if `null` |
| `envVars` | `List<ScriptEnvVarInput>` | `@Valid`, Optional | Validated env var entries |
| `tagIds` | `List<String>` | Optional | Replaces the full tag assignment set |

## Usage Example

```java
UpdateScriptInput input = new UpdateScriptInput();
input.setId("script-abc123");
input.setName("Restart Service");
input.setShell(ScriptShell.POWERSHELL);
input.setPrivilegeLevel(PrivilegeLevel.ADMIN);
input.setScriptBody("Restart-Service -Name $args[0]");
input.setDefaultTimeoutSeconds(120);
input.setSupportedPlatforms(List.of(ScriptPlatform.WINDOWS));
input.setTagIds(List.of("tag-001", "tag-002"));

// null optional fields are intentionally cleared on the stored document
input.setDescription(null);
input.setDefaultArgs(null);
```

> **PUT semantics:** Callers must send the complete resource on every request. Fields not included (or sent as `null`) will overwrite — not preserve — the current stored value.
