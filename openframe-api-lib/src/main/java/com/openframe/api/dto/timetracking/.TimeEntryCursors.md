Utility class for generating stable, sortable cursor strings used in paginating `TimeEntry` records by date.

## Key Components

- **`DATE_FIELD`** — Constant identifying the cursor field name (`"date"`), used to reference this cursor type externally.
- **`date(TimeEntry entry)`** — Static factory method that builds a composite cursor string from three ordered components:
  - UTC calendar date derived from `startedAt` (falls back to `"0000-00-00"` if null)
  - `createdAt` epoch milliseconds (falls back to `0` if null)
  - `entry.getId()` as a tie-breaker for uniqueness

## Usage Example

```java
TimeEntry entry = timeEntryRepository.findById(someId);
String cursor = TimeEntryCursors.date(entry);
// cursor → "2024-06-15_1718467200000_abc123"

// Use in a paginated query
Page<TimeEntry> nextPage = timeEntryRepository.findAfterCursor(
    TimeEntryCursors.DATE_FIELD,
    cursor,
    PageRequest.of(0, 25)
);
```

## Notes

- The cursor format `YYYY-MM-DD_<epochMillis>_<id>` is lexicographically sortable, ensuring consistent pagination ordering even across entries sharing the same date.
- The class is non-instantiable (`private` constructor) and `final`, following the static utility class pattern.
- All timestamps are normalized to **UTC** to avoid timezone-related sort inconsistencies.
