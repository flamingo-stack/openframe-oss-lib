Represents the available faceted filter options and total result count for the script-schedules list endpoint, where each filter facet is computed with all other active filters applied but not its own field.

## Key Components

| Field | Type | Description |
|---|---|---|
| `platforms` | `List<ScriptFilterOption>` | Faceted platform filter options with live counts |
| `authors` | `List<ScriptFilterOption>` | Faceted author filter options with live counts |
| `filteredCount` | `Integer` | Total records matching all currently active filters |

Reuses [`ScriptFilterOption`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/api/dto/rmm/script/ScriptFilterOption.java) (value / label / count) for each facet entry.

## Usage Example

```java
ScriptScheduleFilters filters = ScriptScheduleFilters.builder()
    .platforms(List.of(
        new ScriptFilterOption("windows", "Windows", 12),
        new ScriptFilterOption("linux", "Linux", 5)
    ))
    .authors(List.of(
        new ScriptFilterOption("user-1", "Alice", 8),
        new ScriptFilterOption("user-2", "Bob", 9)
    ))
    .filteredCount(17)
    .build();
```
