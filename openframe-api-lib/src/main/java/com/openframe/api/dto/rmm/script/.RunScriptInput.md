Data Transfer Object (DTO) representing the GraphQL input payload for dispatching a saved script to an RMM agent.

## Key Components

| Field | Type | Constraints |
|---|---|---|
| `machineId` | `String` | Required; alphanumeric with `_` and `-` only |
| `scriptId` | `String` | Required; identifies the saved script |
| `privilegeLevel` | `PrivilegeLevel` | Required; e.g., `USER` or `ELEVATED` |
| `args` | `List<String>` | Optional; positional arguments passed to the script |
| `timeoutSeconds` | `Integer` | Optional; positive integer, max `600` (10 minutes) |
| `envVars` | `List<ScriptEnvVarInput>` | Optional; validated environment variable pairs |

## Usage Example

```java
RunScriptInput input = new RunScriptInput();
input.setMachineId("agent-abc123");
input.setScriptId("script_789");
input.setPrivilegeLevel(PrivilegeLevel.ELEVATED);
input.setArgs(List.of("--verbose", "--dry-run"));
input.setTimeoutSeconds(120);

ScriptEnvVarInput envVar = new ScriptEnvVarInput();
envVar.setName("LOG_LEVEL");
envVar.setValue("DEBUG");
input.setEnvVars(List.of(envVar));
```

## Validation Notes

- `machineId` is restricted to the regex `^[A-Za-z0-9_-]+$` to ensure it is safe as a NATS subject token.
- `timeoutSeconds` must be a positive integer and cannot exceed `600`; omit to use the agent's default timeout.
- `envVars` entries are cascaded with `@Valid`, so each [`ScriptEnvVarInput`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/api/dto/rmm/script/ScriptEnvVarInput.java) is individually validated.
