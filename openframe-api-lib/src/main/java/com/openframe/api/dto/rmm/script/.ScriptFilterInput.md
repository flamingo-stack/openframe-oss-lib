A DTO used to filter RMM scripts by multiple optional criteria, passed as input to script listing or search endpoints.

## Key Components

| Field | Type | Description |
|---|---|---|
| `shells` | `List<ScriptShell>` | Filter by shell type (e.g., PowerShell, Bash) |
| `statuses` | `List<ScriptStatus>` | Filter by script status; excludes `DELETED` by default when null/empty |
| `supportedPlatforms` | `List<ScriptPlatform>` | Match scripts supporting **any** of the given platforms |
| `tagIds` | `List<String>` | Match scripts assigned **any** of the given `Tag` entity IDs |
| `authorIds` | `List<String>` | Match scripts created by **any** of the given user IDs (raw, not Relay-encoded) |

All fields are optional — omitting a field applies no constraint for that dimension.

## Usage Example

```java
ScriptFilterInput filter = ScriptFilterInput.builder()
    .shells(List.of(ScriptShell.POWERSHELL))
    .statuses(List.of(ScriptStatus.ACTIVE, ScriptStatus.DRAFT))
    .supportedPlatforms(List.of(ScriptPlatform.WINDOWS))
    .tagIds(List.of("tag-abc123", "tag-def456"))
    .authorIds(List.of("user-789"))
    .build();
```

> **Note:** `authorIds` expects raw internal user IDs. Do not pass Relay-encoded (Base64 GraphQL) IDs — decode them first before populating this field.
