Read-side DTO representing the projection of a script execution record, used to surface execution history and detail data to the GraphQL layer.

## Key Components

| Field | Type | Description |
|---|---|---|
| `id` / `executionId` | `String` | Record and execution identifiers |
| `scriptId` | `String` | Reference to the originating script; display name resolved at read time via script DataLoader |
| `scheduleId` | `String` | Source schedule; `null` for ad-hoc runs |
| `machineId` | `String` | Target machine for the execution |
| `privilegeLevel` | `PrivilegeLevel` | Privilege context used during execution |
| `initiatedBy` | `String` | Raw user ID; resolved to full initiator via user DataLoader |
| `status` | `ExecutionStatus` | Current execution status |
| `dispatchedAt` / `statusChangedAt` / `finishedAt` | `Instant` | Execution lifecycle timestamps |
| `exitCode` | `Integer` | Process exit code |
| `executionTimeMs` | `Long` | Total wall-clock duration in milliseconds |
| `timedOut` | `Boolean` | Whether execution was terminated by timeout |
| `stdout` / `stderr` | `String` | Captured output streams |
| `stdoutTruncated` / `stderrTruncated` | `Boolean` | Indicates truncated output |
| `error` | `String` | Execution-level error message |

## Usage Example

```java
ScriptExecutionResponse response = ScriptExecutionResponse.builder()
    .id("rec_abc123")
    .executionId("exec_xyz789")
    .scriptId("script_deploy_patch")
    .machineId("machine_win10_01")
    .privilegeLevel(PrivilegeLevel.SYSTEM)
    .initiatedBy("user_456")
    .status(ExecutionStatus.COMPLETED)
    .dispatchedAt(Instant.now().minusSeconds(30))
    .finishedAt(Instant.now())
    .executionTimeMs(28_500L)
    .exitCode(0)
    .timedOut(false)
    .stdout("Patch applied successfully.")
    .stdoutTruncated(false)
    .build();
```

> **Note:** `initiatedBy` and `scriptId` are intentionally left as raw IDs. The corresponding `initiator` and `scriptName` GraphQL fields are resolved lazily via their respective DataLoaders, following the same pattern as `Script.author`.
