A specialized exception for signaling that a requested time entry resource could not be located, extending the core `NotFoundException` with a dedicated `TIME_ENTRY_NOT_FOUND` error code.

## Key Components

| Element | Description |
|---|---|
| `TimeEntryNotFoundException` | Custom runtime exception extending `NotFoundException` |
| `ErrorCode.TIME_ENTRY_NOT_FOUND` | Standardized error code automatically applied on construction |
| `message` | Developer-facing description of the missing resource |

## Usage Example

```java
// Throw when a time entry lookup returns no result
TimeEntry entry = timeEntryRepository.findById(entryId)
    .orElseThrow(() -> new TimeEntryNotFoundException(
        "Time entry not found with ID: " + entryId
    ));
```

> The error code `TIME_ENTRY_NOT_FOUND` is hardcoded in the constructor, ensuring consistent error classification across all API responses without requiring callers to supply it.
