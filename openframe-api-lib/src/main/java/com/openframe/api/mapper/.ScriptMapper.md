Bidirectional mapper between `Script` domain entities and their corresponding DTOs (`CreateScriptInput`, `UpdateScriptInput`, `ScriptResponse`), designed for reuse across GraphQL, REST, and messaging transports.

## Key Components

| Method | Description |
|---|---|
| `toEntity(tenantId, CreateScriptInput)` | Builds a new `Script` document from a creation DTO, scoped to a tenant |
| `updateEntity(Script, UpdateScriptInput)` | Mutates an existing `Script` entity in-place from an update DTO |
| `toResponse(Script)` | Converts a `Script` entity to a `ScriptResponse` DTO, with enum-to-string coercion and safe defaults (`PrivilegeLevel.USER`, `ScriptStatus.ACTIVE`) |
| `mapEnvVarsToEntity(...)` | Private helper: maps `ScriptEnvVarInput` list → `ScriptEnvVar` entity list |
| `mapEnvVarsToResponse(...)` | Private helper: maps `ScriptEnvVar` entity list → `ScriptEnvVarInput` list (secret masking pending) |
| `mapPlatformsToResponse(...)` | Private helper: serializes `ScriptPlatform` enums to their string names |

> **Note:** GraphQL-specific concerns (Relay Connection, cursor pagination) are intentionally kept in `GraphQLScriptMapper` alongside the DGS resolver.

## Usage Example

```java
@Service
public class ScriptService {

    private final ScriptMapper scriptMapper;
    private final ScriptRepository scriptRepository;

    // Create a new script
    public ScriptResponse createScript(String tenantId, CreateScriptInput input) {
        Script entity = scriptMapper.toEntity(tenantId, input);
        Script saved = scriptRepository.save(entity);
        return scriptMapper.toResponse(saved);
    }

    // Update an existing script
    public ScriptResponse updateScript(String scriptId, UpdateScriptInput input) {
        Script existing = scriptRepository.findById(scriptId).orElseThrow();
        scriptMapper.updateEntity(existing, input);
        return scriptMapper.toResponse(scriptRepository.save(existing));
    }
}
```
