Maps `ScriptSchedule` entities to/from DTOs, handling creation, updates, and response serialization for the RMM script scheduling domain.

## Key Components

| Method | Description |
|---|---|
| `toEntity(String, CreateScriptScheduleInput)` | Builds a new `ScriptSchedule` document from a tenant ID and creation input |
| `updateEntity(ScriptSchedule, UpdateScriptScheduleInput)` | Mutates an existing `ScriptSchedule` in-place with updated field values |
| `toResponse(ScriptSchedule)` | Converts a `ScriptSchedule` entity to a `ScriptScheduleResponse` DTO |
| `defaultTrigger(ScriptScheduleTrigger)` | Falls back to `DATE_TIME` if no trigger is supplied |
| `mapPlatformsToResponse(List<ScriptPlatform>)` | Converts `ScriptPlatform` enums to their string names for the response |

**Notes:**
- Enum fields (`trigger`, `status`, `supportedPlatforms`) are serialized to their `.name()` string values in the response.
- `status` defaults to `ScriptStatus.ACTIVE` when the entity field is `null`.
- GraphQL-specific concerns (cursor pagination, Relay envelope) are intentionally delegated to `GraphQLScriptScheduleMapper`.

## Usage Example

```java
@Service
public class ScriptScheduleService {

    private final ScriptScheduleMapper mapper;

    // Create a new schedule entity from API input
    public ScriptSchedule create(String tenantId, CreateScriptScheduleInput input) {
        return mapper.toEntity(tenantId, input);
    }

    // Apply updates to an existing schedule
    public void update(ScriptSchedule existing, UpdateScriptScheduleInput input) {
        mapper.updateEntity(existing, input);
    }

    // Convert a saved entity to an API response
    public ScriptScheduleResponse toResponse(ScriptSchedule saved) {
        return mapper.toResponse(saved);
    }
}
```
