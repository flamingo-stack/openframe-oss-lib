Provides faceted filter options (OS platform and author dropdowns) for the script-schedules list UI, mirroring `ScriptFilterService` but without the shell facet.

## Key Components

| Member | Type | Description |
|---|---|---|
| `getScriptScheduleFilters` | `public` | Resolves tenant context, queries platform/author facets and filtered count, then assembles a `ScriptScheduleFilters` response |
| `toQueryFilter` | `private static` | Maps a nullable `ScriptScheduleFilterInput` DTO to a `ScriptScheduleQueryFilter` for repository queries |

**Dependencies injected via constructor:**

- `ScriptScheduleRepository` — executes `platformFacet`, `authorFacet`, and `countForTenant` queries
- `ScriptFilterOptionMapper` — converts raw facet maps to labeled option lists (`selfLabeled` for platforms, `userLabeled` for authors)
- `TenantIdProvider` — supplies the current tenant scope for all queries

## Usage Example

```java
// Inject the service
@Autowired
private ScriptScheduleFilterService scriptScheduleFilterService;

// Build input with optional filter constraints
ScriptScheduleFilterInput input = ScriptScheduleFilterInput.builder()
        .statuses(List.of("ACTIVE"))
        .supportedPlatforms(List.of("WINDOWS"))
        .authorIds(List.of("user-123"))
        .build();

// Retrieve faceted filter options
ScriptScheduleFilters filters = scriptScheduleFilterService.getScriptScheduleFilters(input);

// Null input returns all unfiltered facet options
ScriptScheduleFilters all = scriptScheduleFilterService.getScriptScheduleFilters(null);
```

> **Note:** Passing `null` as input results in a `null` query filter being forwarded to the repository, which should be interpreted as "no constraints" by each facet query.
