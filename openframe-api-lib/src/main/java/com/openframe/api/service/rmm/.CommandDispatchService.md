Dispatches ad-hoc shell commands from the OpenFrame dashboard to target agent(s) over core NATS (fire-and-forget transport), handling single, batch, and cancel operations.

## Key Components

| Method | Description |
|---|---|
| `runCommand(RunCommandInput)` | Validates the target machine, generates a UUID execution ID, and publishes a single `CommandMessage` via NATS. Stateless — nothing is persisted. |
| `batchRunCommand(BatchRunCommandInput, String)` | Validates all target machines up front, persists one `RUNNING` `CommandExecution` row per machine via `CommandExecutionService.createBatch`, then fans out the same `CommandMessage` to every machine under a shared execution ID. |
| `cancelExecution(CancelExecutionInput)` | Publishes a `CancelMessage` to interrupt an in-flight execution. Stateless. |

**Dependencies:**
- `CommandNatsPublisher` — NATS transport layer
- `DeviceService` — tenant-scoped machine validation
- `CommandExecutionService` — batch execution persistence

> **Note:** Activated only when `spring.cloud.stream.enabled` is set (`@ConditionalOnProperty`).

## Usage Example

```java
// Single command dispatch
RunCommandInput input = RunCommandInput.builder()
    .machineId("machine-abc-123")
    .command("Get-Process")
    .shell("powershell")
    .privilegeLevel("admin")
    .timeoutSeconds(30)
    .build();

DispatchResponse response = commandDispatchService.runCommand(input);
String executionId = response.getExecutionId(); // track result via this ID

// Batch dispatch
BatchRunCommandInput batchInput = BatchRunCommandInput.builder()
    .machineIds(List.of("machine-abc-123", "machine-xyz-456"))
    .command("Get-Process")
    .shell("powershell")
    .privilegeLevel("admin")
    .timeoutSeconds(30)
    .build();

DispatchResponse batchResponse = commandDispatchService.batchRunCommand(batchInput, "admin@tenant.com");

// Cancel an in-flight execution
CancelExecutionInput cancelInput = CancelExecutionInput.builder()
    .executionId(executionId)
    .machineId("machine-abc-123")
    .build();

commandDispatchService.cancelExecution(cancelInput);
```
