Computes faceted filter options (shell type, OS platform, author) for the RMM scripts list UI, powering the live-count dropdowns used to filter the tenant's script library.

## Key Components

| Member | Description |
|---|---|
| `getScriptFilters(ScriptFilterInput)` | Fetches all three facets plus a total filtered count, then assembles a `ScriptFilters` response DTO |
| `toQueryFilter(ScriptFilterInput)` | Converts the incoming filter DTO into a `ScriptQueryFilter` used by repository facet queries |
| `ScriptRepository` | Executes per-facet MongoDB/DB aggregations (`shellFacet`, `platformFacet`, `authorFacet`, `countForTenant`) |
| `ScriptFilterOptionMapper` | Resolves raw facet maps into labeled options; `selfLabeled` for enum-style values, `userLabeled` for author-id-to-name resolution |
| `TenantIdProvider` | Supplies the current tenant scope for all repository calls |

## Usage Example

```java
// Inject and call from a GraphQL resolver or REST controller
ScriptFilterInput input = ScriptFilterInput.builder()
        .shells(List.of("bash", "powershell"))
        .supportedPlatforms(List.of("LINUX", "WINDOWS"))
        .build();

ScriptFilters filters = scriptFilterService.getScriptFilters(input);

// filters.getShells()    → [{ label: "bash", count: 12 }, ...]
// filters.getPlatforms() → [{ label: "LINUX", count: 8 }, ...]
// filters.getAuthors()   → [{ label: "Alice", count: 5 }, ...]
// filters.getFilteredCount() → 20
```

> Each facet is computed with the **other** active filters applied but **not its own**, so every dropdown always shows the full switchable option set with live counts — matching the behavior documented in [`DeviceFilterService`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/api/service/rmm/DeviceFilterService.java).
