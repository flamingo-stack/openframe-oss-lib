Provides CRUD operations and timer lifecycle management for time tracking entries, including start/pause/resume/stop timer workflows and cursor-based paginated querying with filtering and sorting.

## Key Components

| Method | Description |
|---|---|
| `startTimer(userId, cmd)` | Creates a new active timer entry, enforces single-active-timer constraint via unique index |
| `pauseTimer(userId)` | Records pause timestamp on the active timer |
| `resumeTimer(userId)` | Accumulates break seconds and clears pause state |
| `stopTimer(userId, cmd)` | Finalizes the timer, calculates net `durationSeconds`, validates ticket/notes requirement |
| `cancelTimer(userId)` | Deletes the active timer without saving a completed entry |
| `createTimeEntry(actingUserId, cmd)` | Manually creates a completed entry with explicit start time and duration |
| `updateTimeEntry(actingUserId, cmd)` | Updates a stopped entry; blocks edits on running timers |
| `unlinkTicketFromTimeEntry(actingUserId, entryId)` | Removes ticket association if notes are present |
| `deleteTimeEntry(actingUserId, entryId)` | Soft-deletes an entry by ID |
| `queryEntries(input, search, pagination, sort)` | Cursor-paginated query with filter, sort, and total count |
| `getCurrentTimer(userId)` | Returns the active (non-ended) timer for a user |

**Validation helpers (private):** `requireActiveTimer`, `requireActiveTicket`, `requireTicketOrNotes`, `requireEntry`, `resolveOrganizationId`, `applyOrganizationChange`, `populateTicketReference`, `validateSortField`, `validatePeriod`

## Usage Example

```java
// Start a timer linked to a ticket
StartTimerCommand cmd = StartTimerCommand.builder()
    .ticketId("ticket-abc")
    .notes("Working on login bug")
    .build();
TimeEntry active = timeEntryService.startTimer("user-123", cmd);

// Pause and later resume
timeEntryService.pauseTimer("user-123");
timeEntryService.resumeTimer("user-123");

// Stop with updated notes
StopTimerCommand stopCmd = StopTimerCommand.builder()
    .notes("Resolved authentication issue")
    .build();
TimeEntry completed = timeEntryService.stopTimer("user-123", stopCmd);

// Create a manual entry
CreateTimeEntryCommand manual = CreateTimeEntryCommand.builder()
    .userId("user-123")
    .ticketId("ticket-xyz")
    .startedAt(Instant.parse("2024-01-15T09:00:00Z"))
    .durationSeconds(3600L)
    .build();
TimeEntry entry = timeEntryService.createTimeEntry("admin-456", manual);

// Query with pagination
CountedGenericQueryResult<TimeEntry> results = timeEntryService.queryEntries(
    filterInput, "search term", paginationCriteria, sortInput
);
```
