A Spring service that handles querying, filtering, and retrieving detailed audit log events by coordinating between Apache Pinot (for fast analytical queries) and Apache Cassandra (for full event detail retrieval).

## Key Components

| Method | Description |
|--------|-------------|
| `queryLogs()` | Fetches a paginated, sorted list of log events from Pinot; routes to full-text search or exact-match filtering based on the presence of a search term |
| `findLogDetails()` | Retrieves the full payload of a single log event from Cassandra by composite key |
| `getLogFilters()` | Returns available filter options (tool types, event types, severities, organizations) for the current tenant |
| `buildLogQueryResult()` | Private helper that maps raw `LogProjection` results into a cursor-paginated `GenericQueryResult<LogEvent>` |
| `validateSortField()` | Guards against invalid sort fields by falling back to the repository default |

**Activation:** The bean is only registered when `spring.data.cassandra.enabled=true`.

## Usage Example

```java
// Inject the service
@Autowired
private LogService logService;

// Build filter and pagination inputs
LogFilterCriteria filter = LogFilterCriteria.builder()
        .startDate(LocalDate.now().minusDays(7))
        .endDate(LocalDate.now())
        .severities(List.of("ERROR", "WARN"))
        .build();

CursorPaginationCriteria pagination = CursorPaginationCriteria.builder()
        .limit(25)
        .cursor(null) // first page
        .build();

SortInput sort = SortInput.builder()
        .field("eventTimestamp")
        .direction(SortDirection.DESC)
        .build();

// Query paginated logs with optional full-text search
GenericQueryResult<LogEvent> result = logService.queryLogs(filter, pagination, "login failed", sort);

// Fetch full details for a specific event
Optional<LogDetails> details = logService.findLogDetails(
        "2024-01-15", "rmm", "agent_disconnect",
        Instant.now(), "tool-event-id-123");

// Retrieve available filter options
LogFilters filters = logService.getLogFilters(filter);
```
