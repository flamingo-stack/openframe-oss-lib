Manages the many-to-many relationship between `Script` entities and `Tag` entities via `TagAssignment` rows, using `TagEntityType.SCRIPT` as the discriminator. Tags are stored externally in `tag_assignments` rather than embedded on the script document.

## Key Components

| Method | Description |
|---|---|
| `getTagsByScriptIds(List<String>)` | Batch-loads tags for multiple script IDs in input order; designed for GraphQL `Script.tags` DataLoader usage |
| `getAllTags(boolean archived)` | Returns all tags assigned to either active or archived scripts depending on the `archived` flag |
| `replaceTags(String, List<String>)` | PUT-semantics full replacement of a script's tag assignments; clears existing assignments before writing new ones |

## Usage Example

```java
// Batch load tags for a list of script IDs (DataLoader pattern)
List<List<Tag>> tagsByScript = scriptTagService.getTagsByScriptIds(
    List.of("script-001", "script-002")
);

// Get all tags associated with active (non-archived) scripts
List<Tag> activeTags = scriptTagService.getAllTags(false);

// Replace all tags on a script (create or update flow)
scriptTagService.replaceTags("script-001", List.of("tag-abc", "tag-def"));

// Clear all tags from a script
scriptTagService.replaceTags("script-001", List.of());
```

## Notes

- Mirrors the pattern established in `KnowledgeBaseTagService` for consistency across entity types.
- `getTagsByScriptIds` preserves input list order, returning an empty list for any script with no assignments.
- `replaceTags` is `@Transactional` (read-write), while all read methods use the class-level `readOnly = true` transaction.
