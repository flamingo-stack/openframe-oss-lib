Orchestrates the dispatch of saved scripts to one or more agent-connected devices over NATS, handling single-device runs, batch multi-device runs, and ad-hoc schedule executions.

## Key Components

| Method | Description |
|---|---|
| `runScript(RunScriptInput, String)` | Dispatches a single saved script to one device; generates an `executionId` and publishes via `ScriptNatsPublisher` |
| `batchRunScript(BatchRunScriptInput, String)` | Validates all target machines upfront, then fans out a script to multiple devices as a single batch |
| `runSchedule(String, String)` | Ad-hoc fires all ACTIVE scripts in a schedule to every assigned device; persists a header `ScheduleScriptExecution` record before publishing |
| `mergeEnvVars(...)` *(private)* | Merges script-level default env vars with per-request overrides |
| `verifyMachines(...)` *(private)* | Rejects a batch early if any machine ID is unknown |
| `effectiveTimeout(...)` *(private)* | Resolves the timeout from request input, falling back to the script default |

**Key dependencies:**

- `ScriptNatsPublisher` — publishes single/batch script messages to `machine.{machineId}.script`
- `ScriptScheduleExecutionNatsPublisher` — publishes batched schedule payloads to `machine.{machineId}.script-schedule-execution`
- `ScriptExecutionService` — persists leaf execution rows for watchdog and history
- `ScheduleScriptExecutionRepository` — persists the header schedule-fire record

## Usage Example

```java
// Single device dispatch
RunScriptInput input = RunScriptInput.builder()
    .machineId("machine-abc")
    .scriptId("script-123")
    .privilegeLevel(PrivilegeLevel.ADMIN)
    .timeoutSeconds(60)
    .build();

DispatchResponse response = scriptDispatchService.runScript(input, "user@example.com");
String executionId = response.getExecutionId(); // correlate async result

// Batch dispatch to multiple devices
BatchRunScriptInput batchInput = BatchRunScriptInput.builder()
    .machineIds(List.of("machine-1", "machine-2", "machine-3"))
    .scriptId("script-123")
    .privilegeLevel(PrivilegeLevel.USER)
    .build();

DispatchResponse batchResponse = scriptDispatchService.batchRunScript(batchInput, "user@example.com");

// Ad-hoc schedule run
DispatchResponse scheduleResponse = scriptDispatchService.runSchedule("schedule-xyz", "user@example.com");
```

> **Note:** This service is conditionally enabled via `spring.cloud.stream.enabled`. The `executionId` is generated server-side and intentionally excluded from the agent-bound wire payload — correlation is handled on a separate result channel.
