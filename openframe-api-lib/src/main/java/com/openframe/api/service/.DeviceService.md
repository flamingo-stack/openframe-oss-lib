Manages device (machine) querying, filtering, and status updates within the OpenFrame platform, providing cursor-based pagination and tag-based filtering capabilities backed by MongoDB repositories.

## Key Components

| Component | Description |
|---|---|
| `findByMachineId` | Looks up a single `Machine` document by its machine ID |
| `queryDevices` | Queries all devices using filter criteria, cursor pagination, search, and sort |
| `queryAssignedDevices` | Same as `queryDevices` but scoped to a specific set of machine IDs (e.g. for script schedules) |
| `updateStatusByMachineId` | Updates a device's `DeviceStatus` and triggers post-processing via `DeviceStatusProcessor` |
| `updateNickname` | Sets (or clears, when the value is blank/null) a device's user-defined `nickname`; trims input and persists it as an atomic `$set` on `nickname` + `updatedAt` |
| `buildDeviceQuery` | Constructs a MongoDB `Query` from `DeviceFilterCriteria`, intersecting tag and caller-scoped machine ID restrictions |
| `resolveTagFilterToMachineIds` | Translates `tagKeys`/`tagValues` filter criteria into a list of matching machine IDs via `TagAssignmentRepository` |
| `intersectMachineIds` | Combines tag-filter and caller restrictions into a single `$in` set; `null` means no restriction |
| `paginate` | Handles cursor-based pagination logic, total count, and `PageInfo` construction |

## Usage Example

```java
// Query devices with tag and status filters, cursor pagination
DeviceFilterCriteria filter = DeviceFilterCriteria.builder()
    .statuses(List.of(DeviceStatus.ONLINE))
    .tagKeys(List.of("environment"))
    .tagValues(List.of("production"))
    .build();

CursorPaginationCriteria pagination = CursorPaginationCriteria.builder()
    .limit(20)
    .cursor(null) // first page
    .build();

SortInput sort = SortInput.builder()
    .field("updatedAt")
    .direction(SortDirection.DESC)
    .build();

CountedGenericQueryResult<Machine> result =
    deviceService.queryDevices(filter, pagination, "web-server", sort);

// Update a device's status
deviceService.updateStatusByMachineId("machine-abc-123", DeviceStatus.OFFLINE);

// Set (or clear) a device nickname
deviceService.updateNickname("machine-abc-123", "Reception iMac");
```

## Notes

- Tag filters resolve to machine IDs by querying `TagAssignment` records scoped to `TagEntityType.DEVICE`.
- An empty intersection of tag/caller restrictions returns no results rather than falling back to all devices.
- `updateStatusByMachineId` is a no-op if the device already holds the target status; post-processing failures are logged but do not propagate.
- `updateNickname` trims the value and stores a blank/null nickname as `null` (cleared); it throws `DeviceNotFoundException` for an unknown `machineId`.
- `updateNickname` writes through `MachineRepository.updateNickname` (an atomic `$set`), never `save()` — a load-mutate-save round trip would rewrite the whole document and drop concurrent status, heartbeat, or inventory updates.
