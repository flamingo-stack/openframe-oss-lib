Manages the full lifecycle of tags and their assignments to entities (primarily devices), providing CRUD operations, autocomplete search, and batch retrieval of tag data scoped to a tenant.

## Key Components

| Method | Description |
|---|---|
| `listTags()` | Returns all device-scoped tags tenant-wide |
| `findByEntityType(TagEntityType)` | Lists tags filtered by entity type |
| `searchTagKeys(String, Integer)` | Autocomplete search over tag keys with limit enforcement |
| `searchTagValues(String, String, Integer)` | Autocomplete search over values for a specific tag key |
| `getTagValueOptions(String)` | Returns distinct tag values with device counts for filter UI dropdowns |
| `getTagsForMachines(List<String>)` | Batch-loads tags for multiple machines, preserving per-device assignment values |
| `getTagsForMachine(String)` | Loads tags for a single machine |
| `createTag(...)` | Creates a new tag; returns existing if key+entityType already exists (idempotent) |
| `updateTag(...)` | Partially updates key, description, or color of an existing tag |
| `deleteTag(String)` | Deletes a tag and cascades removal of all its assignments |

**Constants:** `DEFAULT_LIMIT = 20`, `MAX_LIMIT = 100` applied via `normalizeLimit()`.

## Usage Example

```java
// Autocomplete tag keys for a search input
List<Tag> suggestions = tagService.searchTagKeys("env", 10);

// Populate a filter dropdown with value counts
List<DeviceFilterOption> options = tagService.getTagValueOptions("environment");
// → [{ value: "production", label: "production", count: 42 }, ...]

// Batch-load tags for a list of devices
List<String> machineIds = List.of("device-1", "device-2");
List<List<Tag>> tagsByMachine = tagService.getTagsForMachines(machineIds);

// Create and assign a tag
Tag tag = tagService.createTag("environment", TagEntityType.DEVICE, "Deployment env", "#00FF00");

// Clean up a tag and all its assignments
tagService.deleteTag(tag.getId());
```
