Provides application-level CRUD and lifecycle management for RMM scripts within a tenant-scoped pod, including cursor-paginated listing, soft-delete, archive, and restore operations.

## Key Components

| Member | Description |
|---|---|
| `create(CreateScriptInput, String)` | Creates a new script; enforces name uniqueness across `ACTIVE`/`ARCHIVED` statuses |
| `get(String)` | Fetches a single visible (non-deleted) script by ID; throws `NotFoundException` |
| `findById(String)` | Non-throwing optional lookup; returns empty for missing or soft-deleted scripts |
| `getScriptsByIds(Collection<String>)` | Batch lookup including soft-deleted records; used by the `scriptDataLoader` for execution history resolution |
| `list(...)` | Cursor-paginated, filtered, and sortable script listing with filtered total count |
| `update(UpdateScriptInput)` | Full replacement (PUT semantics); enforces name uniqueness against other scripts |
| `delete(String)` | Idempotent soft-delete; sets status to `DELETED`, retains document for history |
| `archive(String)` | Idempotent transition to `ARCHIVED` |
| `transitionTo(String, ScriptStatus)` | Internal helper driving `archive` and `restore` status transitions |

## Usage Example

```java
// Create a new script
CreateScriptInput input = CreateScriptInput.builder()
        .name("Restart Service")
        .shell(ShellType.POWERSHELL)
        .tagIds(List.of("tag-1", "tag-2"))
        .build();

ScriptResponse created = scriptService.create(input, "user-123");

// Paginated listing with filter and sort
CursorPaginationCriteria pagination = CursorPaginationCriteria.builder()
        .limit(20)
        .build();

SortInput sort = SortInput.builder()
        .field("name")
        .direction(SortDirection.ASC)
        .build();

CountedGenericQueryResult<ScriptResponse> results =
        scriptService.list(filter, "restart", sort, pagination);

// Soft-delete a script
String deletedId = scriptService.delete("script-abc123");

// Archive then restore
ScriptResponse archived  = scriptService.archive("script-abc123");
ScriptResponse restored  = scriptService.restore("script-abc123");
```

> **Tenant scoping:** All operations resolve the tenant ID internally via `TenantIdProvider`. Callers never pass a tenant ID — see the class-level Javadoc for the security rationale.
