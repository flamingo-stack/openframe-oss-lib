Service responsible for querying `Organization` documents from MongoDB with support for filtering, cursor-based pagination, full-text search, and dynamic sorting.

## Key Components

| Method | Description |
|---|---|
| `findByOrganizationId(String)` | Looks up a single organization by its business ID, returning an `Optional`. |
| `queryOrganizations(...)` | Main query entry point; combines filter options, pagination, search, and sort into a `CountedGenericQueryResult`. |
| `fetchPageItems(...)` | Executes the paginated MongoDB query, requesting `limit + 1` items to detect next-page existence. |
| `buildPageInfo(...)` | Constructs `PageInfo` with encoded start/end cursors and pagination flags. |
| `rawCursor(...)` | Selects the correct cursor strategy — compound `(lastActivityAt, _id)` keyset for activity sort, plain ObjectId otherwise. |
| `buildQueryFilter(...)` | Maps `OrganizationFilterOptions` to the MongoDB-level `OrganizationQueryFilter`. |
| `validateSortField(...)` | Guards against invalid sort fields by falling back to the repository's default. |

## Usage Example

```java
@Autowired
OrganizationQueryService organizationQueryService;

// Build filter options
OrganizationFilterOptions filters = OrganizationFilterOptions.builder()
        .status("ACTIVE")
        .hasActiveContract(true)
        .build();

// Cursor-based pagination (first 20 results)
CursorPaginationCriteria pagination = CursorPaginationCriteria.builder()
        .limit(20)
        .build();

// Sort by last activity descending
SortInput sort = SortInput.builder()
        .field("lastActivityAt")
        .direction(SortDirection.DESC)
        .build();

CountedGenericQueryResult<Organization> result =
        organizationQueryService.queryOrganizations(filters, pagination, "Acme", sort);

List<Organization> orgs  = result.getItems();
int               total  = result.getFilteredCount();
PageInfo          paging = result.getPageInfo();
```

## Notes

- **Filter push-down** — all filtering is applied at the MongoDB query level before documents are fetched, avoiding in-memory post-processing.
- **Cursor integrity** — `filteredCount` is computed on the base query *before* `fetchPageItems` appends the keyset predicate and `LIMIT`, ensuring accurate totals across pages.
- Sort field validation falls back to the repository default and logs a `WARN` when an unrecognised field is supplied.
