Service layer class that manages retrieval of installed agents across machines, automatically filtering out agents with a `DISCONNECTED` connection status from all query results.

## Key Components

| Method | Description |
|---|---|
| `getInstalledAgentsForMachines(List<String>)` | Bulk lookup of agents for multiple machine IDs; returns a positionally-aligned list of lists |
| `getInstalledAgentsForMachine(String)` | Returns all active agents for a single machine |
| `getAllInstalledAgents()` | Returns all non-disconnected agents across the system |
| `getInstalledAgent(String)` | Looks up a single agent by its document ID |
| `getInstalledAgentByMachineIdAndType(String, String)` | Finds a specific agent by machine ID and agent type combination |
| `excludeDisconnected(List<InstalledAgent>)` | Private helper that filters out `DISCONNECTED` agents from any list |
| `isNotDisconnected(InstalledAgent)` | Predicate used by both stream and `Optional` filter operations |

## Usage Example

```java
// Single machine lookup
List<InstalledAgent> agents = installedAgentService.getInstalledAgentsForMachine("machine-123");

// Bulk lookup — result index matches machineIds index
List<String> machineIds = List.of("machine-1", "machine-2", "machine-3");
List<List<InstalledAgent>> agentsByMachine = installedAgentService.getInstalledAgentsForMachines(machineIds);

// Lookup by machine + agent type
Optional<InstalledAgent> agent = installedAgentService
    .getInstalledAgentByMachineIdAndType("machine-123", "RMM");
agent.ifPresent(a -> System.out.println(a.getStatus()));
```

> **Note:** All methods silently exclude `DISCONNECTED` agents. If you need to inspect disconnected agents, query `InstalledAgentRepository` directly.
