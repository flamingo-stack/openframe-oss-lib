Builds `ScriptFilterOption` lists from facet `value → count` maps, centralizing option construction and human-readable label resolution for both `ScriptFilterService` and `ScriptExecutionFilterService`.

## Key Components

| Method | Description |
|---|---|
| `selfLabeled(Map<String, Integer>)` | Maps enum-valued facets (shell, platform, status) where the raw key serves as both value and label |
| `userLabeled(Map<String, Integer>)` | Resolves user IDs to display names via a batch lookup; falls back through full name → email → raw ID |
| `machineLabeled(Map<String, Integer>)` | Resolves machine IDs to human-readable labels via a batch lookup; falls back through hostname → displayName → raw ID |
| `displayName(User)` | Private helper — assembles a user's full name, falling back to email then ID |
| `machineLabel(Machine)` | Private helper — returns hostname, then displayName, then raw machineId |

## Usage Example

```java
// Injected into a filter service
@Service
@RequiredArgsConstructor
public class ScriptFilterService {

    private final ScriptFilterOptionMapper mapper;

    public ScriptFilterOptions buildOptions(ScriptFacets facets) {
        return ScriptFilterOptions.builder()
            // Enum facets — value and label are identical
            .shells(mapper.selfLabeled(facets.getShellCounts()))
            .platforms(mapper.selfLabeled(facets.getPlatformCounts()))
            .statuses(mapper.selfLabeled(facets.getStatusCounts()))
            // ID facets — batch-resolved to human-readable labels
            .authors(mapper.userLabeled(facets.getAuthorCounts()))
            .devices(mapper.machineLabeled(facets.getDeviceCounts()))
            .build();
    }
}
```

## Notes

- **Batch loading** — both `userLabeled` and `machineLabeled` issue a single repository query per call, avoiding N+1 lookups.
- **Graceful fallback** — unknown IDs (deleted users/machines) silently fall back to the raw ID so filter options remain functional.
- The `value` field for machine options retains the raw `machineId`; the datafetcher layer is responsible for encoding it to a GraphQL global ID on the way out.
