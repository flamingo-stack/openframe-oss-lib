Defines the enumeration of all supported GraphQL node types in the OpenFrame relay layer, mapping Java enum constants to their corresponding GraphQL type name strings.

## Key Components

| Member | GraphQL Type Name | Description |
|---|---|---|
| `MACHINE` | `"Machine"` | Physical or virtual device node |
| `ORGANIZATION` | `"Organization"` | Org-level entity |
| `EVENT` | `"Event"` | System/platform event |
| `INTEGRATED_TOOL` | `"IntegratedTool"` | External tool integration |
| `TENANT` | `"Tenant"` | Multi-tenant identifier |
| `DIALOG` | `"Dialog"` | Conversation/dialog thread |
| `MESSAGE` | `"Message"` | Individual message node |
| `TAG` | `"Tag"` | Classification tag |
| `TOOL_CONNECTION` | `"ToolConnection"` | Connection to an integrated tool |
| `INSTALLED_AGENT` | `"InstalledAgent"` | Deployed agent on a machine |
| `LOG_EVENT` | `"LogEvent"` | Log entry event |
| `LOG_DETAILS` | `"LogDetails"` | Detailed log metadata |
| `SCRIPT` | `"Script"` | Automation script |
| `SCRIPT_EXECUTION` | `"ScriptExecution"` | Script run record |

**Methods:**
- `getGraphqlTypeName()` — returns the GraphQL schema type string for a given constant
- `fromTypeName(String)` — reverse-lookup; throws `IllegalArgumentException` for unknown type names

## Usage Example

```java
// Forward lookup: enum → GraphQL type name
String typeName = NodeType.MACHINE.getGraphqlTypeName(); // "Machine"

// Reverse lookup: GraphQL type name → enum
NodeType type = NodeType.fromTypeName("Script"); // NodeType.SCRIPT

// Safe usage with exception handling
try {
    NodeType unknown = NodeType.fromTypeName("UnknownType");
} catch (IllegalArgumentException e) {
    // "Unknown Node type: UnknownType"
}
```
