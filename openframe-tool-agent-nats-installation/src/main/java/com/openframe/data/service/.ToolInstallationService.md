Orchestrates the installation lifecycle of integrated tool agents by resolving command parameters and publishing installation events via NATS messaging. Active only when `spring.cloud.stream.enabled` is configured.

## Key Components

| Component | Description |
|---|---|
| `process(machineId, toolAgent)` | Triggers a standard installation for a given machine and tool agent |
| `process(machineId, toolAgent, reinstall)` | Extends the base process with an optional reinstall flag; resolves both installation and run command args before publishing |
| `getIntegratedToolData(toolId)` | Retrieves the associated `IntegratedTool` document; returns a stub with empty fields if `toolId` is blank |

**Dependencies injected:**

- `IntegratedToolService` — fetches tool metadata by key
- `ToolCommandParamsResolver` — resolves dynamic parameters in command argument lists
- `ToolInstallationNatsPublisher` — publishes the installation event to a NATS subject

## Usage Example

```java
// Standard install
toolInstallationService.process("machine-abc123", toolAgent);

// Force reinstall
toolInstallationService.process("machine-abc123", toolAgent, true);
```

## Notes

- The service is conditionally loaded via `@ConditionalOnProperty("spring.cloud.stream.enabled")` — it is inactive in environments where NATS/Spring Cloud Stream is disabled.
- Errors during publish are caught and logged but do not propagate — a fallback mechanism is noted as a pending TODO.
- When `toolId` is empty, an empty `IntegratedTool` stub is published rather than aborting, to support agents without a backing tool server.
