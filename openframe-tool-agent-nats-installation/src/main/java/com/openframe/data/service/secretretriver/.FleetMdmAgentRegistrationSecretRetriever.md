Retrieves the Fleet MDM agent enrollment secret for use in device registration workflows. Implements `ToolAgentRegistrationSecretRetriever` by fetching API credentials from the integrated tool configuration and querying the Fleet MDM API.

## Key Components

| Member | Type | Description |
|---|---|---|
| `TOOL_ID` | Constant | Fixed identifier `"fleetmdm-server"` used to look up the tool configuration |
| `validateTenantConfig()` | `@PostConstruct` method | Validates multi-tenancy configuration on startup via `FleetTenantHeader.validate()` |
| `getToolId()` | Override | Returns the `"fleetmdm-server"` tool identifier |
| `getSecret()` | Override | Resolves API URL/credentials, instantiates `FleetMdmClient`, and returns the enroll secret |
| `tenantId` | `@Value` field | Injected from `TENANT_ID` environment variable; used for multi-tenant Fleet MDM requests |
| `fleetMultiTenancyEnabled` | `@Value` field | Injected from `openframe.fleet.multi-tenancy.enabled`; gates tenant header validation |

**Activation:** Bean is only registered when `openframe.integration.tool.enabled=true`.

## Usage Example

```java
// Injected automatically by Spring when integration is enabled.
// Typical use via the ToolAgentRegistrationSecretRetriever interface:

@Autowired
private List<ToolAgentRegistrationSecretRetriever> retrievers;

String secret = retrievers.stream()
    .filter(r -> r.getToolId().equals("fleetmdm-server"))
    .findFirst()
    .orElseThrow()
    .getSecret();
```

**Required configuration:**

```text
openframe.integration.tool.enabled=true
openframe.fleet.multi-tenancy.enabled=true   # optional
TENANT_ID=your-tenant-id                     # optional, for multi-tenancy
```

The tool's API URL and credentials are resolved at runtime from the `IntegratedTool` and `ToolUrl` records, so no static endpoint configuration is needed in application properties.
