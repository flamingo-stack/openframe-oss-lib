Enum defining standardized error codes and their corresponding HTTP status codes for the OpenFrame core exception handling system.

## Key Components

| Member | Type | Description |
|---|---|---|
| `code` | `String` | Machine-readable error identifier (e.g., `"NOT_FOUND"`) |
| `httpStatus` | `int` | Associated HTTP status code (e.g., `404`, `500`) |
| `getCode()` | Method | Returns the string error code |
| `getHttpStatus()` | Method | Returns the integer HTTP status |

**Error categories covered:**

- **Generic HTTP** — `NOT_FOUND`, `BAD_REQUEST`, `UNAUTHORIZED`, `FORBIDDEN`, `CONFLICT`, `INTERNAL_ERROR`, etc.
- **Domain-specific** — `USER_NOT_FOUND`, `DEVICE_NOT_FOUND`, `ENCRYPTION_FAILED`, `CLIENT_SECRET_INVALID`, etc.
- **Ticket / Time tracking** — `TICKET_INVALID_TRANSITION`, `TIME_ENTRY_ACTIVE_EXISTS`, `TICKET_STATUS_SYSTEM_PROTECTED`, etc.
- **Authorization** — `USER_ACTIVE_IN_ANOTHER_TENANT`, `OWNER_CANNOT_SWITCH_TENANT`
- **Infrastructure** — `PINOT_QUERY_ERROR`, `DATABASE_ERROR` (both `503`)

## Usage Example

```java
// Throwing a domain exception with an ErrorCode
throw new OpenFrameException(ErrorCode.TICKET_NOT_FOUND);

// Accessing code and status directly
ErrorCode error = ErrorCode.VALIDATION_ERROR;
System.out.println(error.getCode());       // "VALIDATION_ERROR"
System.out.println(error.getHttpStatus()); // 400

// Mapping to an HTTP response
ResponseEntity<ErrorResponse> response = ResponseEntity
    .status(error.getHttpStatus())
    .body(new ErrorResponse(error.getCode()));
```
