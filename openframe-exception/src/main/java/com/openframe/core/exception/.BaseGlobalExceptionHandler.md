A `@RestControllerAdvice` base class that centralizes HTTP exception handling across Spring REST controllers, mapping both framework and application exceptions to structured `ErrorResponse` payloads.

## Key Components

| Method | Exception Handled | HTTP Status |
|---|---|---|
| `handleBaseException` | `BaseException` (includes `ValidationException`) | Determined by exception |
| `handleMethodArgumentNotValid` | `MethodArgumentNotValidException` | `400 Bad Request` |
| `handleConstraintViolation` | `ConstraintViolationException` | `400 Bad Request` |
| `handleHandlerMethodValidation` | `HandlerMethodValidationException` (Spring 6.1+) | `400 Bad Request` |
| `handleMissingRequestHeader` | `MissingRequestHeaderException` | `400 Bad Request` |
| `handleMissingServletRequestParameter` | `MissingServletRequestParameterException` | `400 Bad Request` |
| `handleIllegalArgument` | `IllegalArgumentException` | `400 Bad Request` |
| `handleIllegalState` | `IllegalStateException` | `409 Conflict` |
| `handleMethodNotSupported` | `HttpRequestMethodNotSupportedException` | `405 Method Not Allowed` |
| `handleMediaTypeNotSupported` | `HttpMediaTypeNotSupportedException` | `415 Unsupported Media Type` |
| `handleResponseStatusException` | `ResponseStatusException` | Determined by exception |
| `handleException` | `Exception` (catch-all) | `500 Internal Server Error` |

**Private helpers:**
- `resolveFieldName` — resolves parameter name or falls back to positional index (`arg0`, `arg1`) when compiled without `-parameters`
- `buildValidationResponse` — constructs an `ErrorResponse` with field-level errors
- `toMessage` — formats field errors as a comma-joined `field: message` string

## Usage Example

Extend this class in your service module to inherit all handlers, optionally overriding specific ones:

```java
@RestControllerAdvice
public class MyServiceExceptionHandler extends BaseGlobalExceptionHandler {

    // Override to add custom handling for a domain-specific exception
    @ExceptionHandler(OrderNotFoundException.class)
    @ResponseStatus(HttpStatus.NOT_FOUND)
    public ErrorResponse handleOrderNotFound(OrderNotFoundException ex) {
        return ErrorResponse.of(ErrorCode.NOT_FOUND, ex.getMessage());
    }
}
```

Validation errors on `@RequestBody` fields are automatically collected and returned as structured field errors:

```json
{
  "code": "VALIDATION_ERROR",
  "message": "email: must not be blank, age: must be positive",
  "fieldErrors": [
    { "field": "email", "message": "must not be blank" },
    { "field": "age",   "message": "must be positive"  }
  ]
}
```

> **Note:** `HandlerMethodValidationException` handling (Spring 6.1+) prevents `@RequestParam` / `@PathVariable` constraint failures from being mislabeled as `INTERNAL_ERROR`.
