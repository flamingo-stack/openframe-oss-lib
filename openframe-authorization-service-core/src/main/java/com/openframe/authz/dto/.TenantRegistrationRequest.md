Data Transfer Object (DTO) for capturing tenant registration input in OpenFrame's multi-tenant authorization system. Extends `CoreUserRequest` with organization-specific fields and validation constraints.

## Key Components

| Field | Type | Description |
|---|---|---|
| `email` | `String` | Validated via `@ValidEmail` custom constraint |
| `tenantName` | `String` | Organization name; 2–100 chars, alphanumeric + common punctuation |
| `tenantDomain` | `String` | Validated via `@TenantDomain` custom constraint |
| `accessCode` | `String` | Optional invite/access code for registration gating |
| `prNumber` | `Integer` | Optional PR number binding registration to a preview environment namespace |

## Usage Example

```java
TenantRegistrationRequest request = TenantRegistrationRequest.builder()
    .email("admin@acme.com")
    .tenantName("Acme Corporation")
    .tenantDomain("acme.openframe.ai")
    .accessCode("INVITE-2024")
    .prNumber(42)          // optional: binds to tenant-42 preview namespace
    .build();
```

When `prNumber` is provided and PR-number registration is enabled, the tenant is bound to the pre-provisioned `tenant-<prNumber>` namespace rather than claiming an arbitrary `READY` slot. If the feature is disabled, `prNumber` is silently ignored.

## Validation Rules

- `tenantName` must match `^[\p{L}\p{M}0-9&.,''"()\- ]{2,100}$` — supports Unicode letters, digits, and common punctuation
- `prNumber` must be a positive integer when supplied
- `email` and `tenantDomain` use custom validators defined in `com.openframe.core.validation`
