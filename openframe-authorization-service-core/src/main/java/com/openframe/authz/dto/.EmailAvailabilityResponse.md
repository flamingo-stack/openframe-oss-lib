Response DTO returned by the email availability check endpoint, indicating whether an email address is free to register and, if not, why it is unavailable.

## Key Components

| Member | Type | Description |
|---|---|---|
| `available` | `boolean` | `true` if the email may be used for registration |
| `reason` | `Reason` (nullable) | Populated only when `available` is `false`; omitted from JSON when `null` |
| `Reason.TAKEN` | enum constant | An active account already owns this address |
| `Reason.BLOCKED_DOMAIN` | enum constant | Domain is rejected (disposable or privacy-focused provider) |

## Usage Example

```java
// Positive case — address is free
EmailAvailabilityResponse free = EmailAvailabilityResponse.builder()
        .available(true)
        .build();

// Negative case — address already registered
EmailAvailabilityResponse taken = EmailAvailabilityResponse.builder()
        .available(false)
        .reason(EmailAvailabilityResponse.Reason.TAKEN)
        .build();

// Negative case — domain is blocked
EmailAvailabilityResponse blocked = EmailAvailabilityResponse.builder()
        .available(false)
        .reason(EmailAvailabilityResponse.Reason.BLOCKED_DOMAIN)
        .build();
```

**JSON output when unavailable:**
```json
{ "available": false, "reason": "BLOCKED_DOMAIN" }
```

**JSON output when available** (`reason` suppressed via `@JsonInclude(NON_NULL)`):
```json
{ "available": true }
```
