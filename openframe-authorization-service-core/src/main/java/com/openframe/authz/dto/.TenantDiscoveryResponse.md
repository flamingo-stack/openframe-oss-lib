Response DTO for tenant discovery, encapsulating tenant and authentication provider information associated with a given email address.

## Key Components

| Field | Type | JSON Key | Description |
|---|---|---|---|
| `email` | `String` | `email` | The queried email address |
| `hasExistingAccounts` | `boolean` | `has_existing_accounts` | Whether the email has existing accounts |
| `tenantId` | `String` | `tenant_id` | Associated tenant identifier |
| `domain` | `String` | `domain` | Tenant domain |
| `authProviders` | `List<String>` | `auth_providers` | Available authentication providers |

## Usage Example

```java
// Building a discovery response
TenantDiscoveryResponse response = TenantDiscoveryResponse.builder()
    .email("user@example.com")
    .hasExistingAccounts(true)
    .tenantId("tenant-abc-123")
    .domain("example.com")
    .authProviders(List.of("google", "microsoft", "local"))
    .build();

// Accessing fields
if (response.isHasExistingAccounts()) {
    String tenant = response.getTenantId();
    List<String> providers = response.getAuthProviders();
}
```

## Notes

- Lombok annotations (`@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor`) auto-generate getters, setters, constructors, and builder.
- Jackson `@JsonProperty` annotations ensure snake_case serialization for API compatibility.
- Typically returned by a tenant discovery endpoint to guide client-side login flow based on available SSO or local auth options.
