Response DTO returned by the domain-policy-only check endpoint, indicating whether an email domain is permitted by the current allowlist/blocklist policy — without revealing registration status.

## Key Components

| Member | Type | Description |
|--------|------|-------------|
| `allowed` | `boolean` | `true` if the email domain passes the configured domain policy; `false` otherwise |

Lombok annotations (`@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor`) generate getters/setters, a fluent builder, and both default and all-args constructors.

## Usage Example

```java
// Build via Lombok builder
EmailDomainAllowedResponse response = EmailDomainAllowedResponse.builder()
        .allowed(true)
        .build();

// Or via all-args constructor
EmailDomainAllowedResponse response = new EmailDomainAllowedResponse(false);

// Consume in a controller
if (response.isAllowed()) {
    // proceed with registration flow
}
```

## Notes

- This DTO is intentionally minimal — it exposes only the domain policy result, keeping registration-state information out of the response to avoid user enumeration.
- Serializes to `{"allowed": true}` / `{"allowed": false}` in JSON responses.
