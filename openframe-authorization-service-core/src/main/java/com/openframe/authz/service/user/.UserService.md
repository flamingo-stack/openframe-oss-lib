Core user management service for the OpenFrame authorization server, handling user registration, authentication lookups, SSO integration, and lifecycle operations (activation, deactivation, password updates) scoped to tenants.

## Key Components

| Method | Description |
|---|---|
| `findActiveByEmail` | Looks up an active user by email (tenant-agnostic) |
| `findActiveByEmailAndTenant` | Looks up an active user scoped to a specific tenant |
| `existsByEmailAndTenant` | Checks for user existence within a tenant |
| `registerUser` | Registers a new local user or reactivates a deleted one; throws on active duplicate |
| `registerUserFromInvitation` | Same as `registerUser` but auto-marks email as verified |
| `registerOrReactivateFromSso` | Creates or reactivates a user from an SSO provider, setting `emailVerified=true` |
| `deactivateUser` | Soft-deletes a user by setting status to `DELETED` |
| `reactivateUser` | Restores a deleted user with updated credentials and roles |
| `updatePassword` | Re-encodes and persists a new password by user ID |
| `touchLastLogin` | Updates the `lastLogin` timestamp on successful authentication |
| `markEmailVerified` | Marks a user's email as verified and triggers post-processing via `UserEmailVerifiedProcessor` |

## Usage Example

```java
// Register a new local user in a tenant
AuthUser user = userService.registerUser(
    "tenant-abc",
    "jane@example.com",
    "Jane",
    "Doe",
    "s3cur3P@ss",
    List.of(UserRole.TECHNICIAN)
);

// Register or reactivate via SSO (e.g., Google OAuth2)
AuthUser ssoUser = userService.registerOrReactivateFromSso(
    "tenant-abc",
    "jane@example.com",
    "Jane",
    "Doe",
    List.of(UserRole.TECHNICIAN),
    "google"
);

// Record a successful login
userService.touchLastLogin("jane@example.com", "tenant-abc");

// Verify email after token confirmation
userService.markEmailVerified(user.getId());
```

## Notes

- All email lookups normalize input via `trim().toLowerCase()` to prevent duplicates.
- SSO-created users receive a random UUID password hash since authentication is provider-managed.
- `backfillNameIfBlank` ensures SSO logins populate missing names without overwriting manual edits.
- `markEmailVerified` is idempotent and delegates post-verification side effects to `UserEmailVerifiedProcessor`.
