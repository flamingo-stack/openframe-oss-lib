Handles the full lifecycle of registering a new user via an invitation token, including tenant resolution, existing-user conflict detection, and post-registration processing.

## Key Components

| Member | Type | Description |
|---|---|---|
| `registerByInvitation` | `public` | Entry point — validates the invitation, resolves the target tenant, handles existing users, creates or reuses an `AuthUser`, and marks the invitation `ACCEPTED` |
| `resolveTargetTenantId` | `private` | Returns the first available tenant when `openframe.tenancy.local-tenant=true`, otherwise uses the tenant embedded in the invitation |
| `handleExistingActiveUser` | `private` | Returns the existing user if already in the target tenant; deactivates them if `switchTenant=true` (blocking `OWNER` role); throws `UserActiveInAnotherTenantException` otherwise |
| `createUserForInvitation` | `private` | Delegates to `UserService.registerUserFromInvitation` with credentials and roles from the invitation |
| `acceptInvitation` | `private` | Marks invitation status `ACCEPTED`, persists it, and triggers `RegistrationProcessor.postProcessInvitationRegistration` |
| `markVerifiedQuietly` | `private` | Silently marks email as verified for reused users — failures are swallowed to avoid blocking acceptance |

## Usage Example

```java
// Injected via Spring — not instantiated directly
@Autowired
private InvitationRegistrationService invitationRegistrationService;

InvitationRegistrationRequest request = InvitationRegistrationRequest.builder()
    .invitationId("inv_abc123")
    .firstName("Jane")
    .lastName("Doe")
    .password("s3cur3P@ss!")
    .switchTenant(false)
    .build();

AuthUser newUser = invitationRegistrationService.registerByInvitation(request);
// newUser is persisted, invitation marked ACCEPTED, post-processors fired
```

## Error Conditions

| Exception | Trigger |
|---|---|
| `OwnerCannotSwitchTenantException` | Active user holds `OWNER` role and `switchTenant=true` |
| `UserActiveInAnotherTenantException` | Active user belongs to a different tenant and `switchTenant` is not set |

> **Config flag:** Set `openframe.tenancy.local-tenant=true` in local/dev environments to bypass invitation tenant resolution and always register against the first tenant in the database.
