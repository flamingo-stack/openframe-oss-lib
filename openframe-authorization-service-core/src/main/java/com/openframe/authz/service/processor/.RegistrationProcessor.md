Defines the `RegistrationProcessor` interface, providing lifecycle hooks for tenant, invitation-based, and SSO auto-provisioned user registration flows. All methods have default no-op implementations, enabling selective override.

## Key Components

| Method | Trigger Point |
|---|---|
| `preProcessTenantRegistration` | Before tenant registration logic executes |
| `postProcessTenantRegistration` | After a tenant and user are successfully created |
| `postProcessInvitationRegistration` | After a user registers via an invitation link |
| `postProcessAutoProvision` | After SSO first-login provisioning or subsequent SSO profile refresh |
| `reserveTenantIdForRegistration` | During tenant creation; returns the tenant ID to assign (defaults to a fresh UUID) |

## Usage Example

```java
@Component
public class CustomRegistrationProcessor implements RegistrationProcessor {

    @Override
    public void postProcessTenantRegistration(
            Tenant tenant, AuthUser user, TenantRegistrationRequest request) {
        // Send welcome email, seed default data, etc.
        welcomeEmailService.send(user.getEmail(), tenant.getId());
    }

    @Override
    public void postProcessAutoProvision(AuthUser user, String pictureUrl) {
        // Sync SSO profile picture to user record
        if (pictureUrl != null) {
            userProfileService.updateAvatar(user.getId(), pictureUrl);
        }
    }

    @Override
    public String reserveTenantIdForRegistration(TenantRegistrationRequest request) {
        // SaaS: claim a pre-provisioned cluster ID; OSS: falls back to UUID
        return clusterPool.claimNextReadyTenantId();
    }
}
```

> **OSS note:** The default `reserveTenantIdForRegistration` delegates to `Tenant.generateTenantId()` (UUID). SaaS implementations override this to atomically claim a pre-generated tenant ID from a ready cluster pool.
