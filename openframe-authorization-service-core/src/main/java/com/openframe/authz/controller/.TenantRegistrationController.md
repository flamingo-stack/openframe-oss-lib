Handles credential-based tenant registration in the OpenFrame authorization service. SSO signup is not handled here: it is the unknown-identity branch of `GET /oauth/login/sso` in `SsoLoginController`.

## Key Components

| Element | Description |
|---|---|
| `POST /oauth/register` | Registers a new tenant from a JSON `TenantRegistrationRequest` and signs its owner into the auth-server session |

## Usage Example

```java
POST /oauth/register
Content-Type: application/json

{
  "email": "admin@acme.com",
  "firstName": "Ada",
  "lastName": "Admin",
  "password": "s3cur3!",
  "tenantName": "Acme",
  "tenantDomain": "acme"
}
// Returns: Tenant object (HTTP 200); the client continues via /oauth/continue?tenantId=...
```
