Defines the `SsoFlowHandler` interface, which provides a contract and default helper methods for implementing SSO authentication flows within the OpenFrame authorization service.

## Key Components

| Member | Type | Description |
|---|---|---|
| `cookieName()` | Abstract method | Returns the SSO flow-specific cookie name |
| `resolveCookie()` | Default method | Finds and returns the flow cookie from the request, or `null` |
| `requireCookie()` | Default method | Returns the flow cookie or throws if absent (session expired) |
| `isActivated()` | Default method | Returns `true` if the flow cookie is present on the request |
| `handle()` | Abstract method | Core handler invoked after successful OAuth2/OIDC authentication |
| `requireOidcUser()` | Default method | Extracts `OidcUser` from `Authentication` or throws on type mismatch |
| `requireEmail()` | Default method | Resolves and validates the OIDC user's email, normalized to lowercase |
| `resolveNames()` | Default method | Delegates to `OidcUserUtils` to extract first/last name from the OIDC user |
| `clearFlowCookieAndRedirect()` | Default method | Clears the flow cookie and redirects to `/oauth/continue?tenantId=...` |

## Usage Example

```java
public class ProvisioningFlowHandler implements SsoFlowHandler {

    @Override
    public String cookieName() {
        return "sso_provision_flow";
    }

    @Override
    public void handle(HttpServletRequest request,
                       HttpServletResponse response,
                       Authentication authentication) throws Exception {
        Cookie flowCookie = requireCookie(request);
        OidcUser oidcUser = requireOidcUser(authentication);
        String email = requireEmail(oidcUser);
        String[] names = resolveNames(oidcUser);

        // ... perform provisioning logic ...

        clearFlowCookieAndRedirect(response, flowCookie, "tenant-123", null);
    }
}
```

> **Note:** The `redirectTo` parameter in `clearFlowCookieAndRedirect` is not yet wired — a TODO marks it for local debugging support.
