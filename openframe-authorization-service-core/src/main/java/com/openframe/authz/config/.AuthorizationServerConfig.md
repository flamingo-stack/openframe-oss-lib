Configures the Spring Authorization Server for OpenFrame's multi-tenant OAuth2/OIDC infrastructure, wiring together JWT encoding/decoding, tenant-aware JWK key resolution, user authentication, and custom token claims.

## Key Components

| Bean | Purpose |
|---|---|
| `authorizationServerSecurityFilterChain` | Primary security filter chain (Order 1) enabling OIDC, multi-issuer support, and JWT resource server |
| `jwkSource` | Tenant-aware JWK source — resolves the active RSA key for the current tenant via `TenantKeyService` |
| `jwtDecoder` / `jwtEncoder` | Standard Nimbus-backed JWT codec wired to the tenant JWK source |
| `tokenCustomizer` | Injects `tenant_id`, `userId`, and `roles` claims into access tokens; updates `lastLogin` on refresh |
| `userDetailsService` | Tenant-scoped user lookup by email, mapping `UserRole` to Spring `GrantedAuthority` |
| `passwordEncoder` | BCrypt password hashing |
| `authenticationManager` | `DaoAuthenticationProvider`-backed manager for programmatic auth (e.g., registration flows) |
| `forwardedHeaderFilter` | Processes `X-Forwarded-*` headers for correct scheme/host resolution behind proxies |
| `tenantForwardedPrefixFilter` | Resolves tenant context from forwarded prefix headers (runs before forwarded header filter) |

## Usage Example

```java
// Custom claims are automatically added to every access token:
// {
//   "sub": "user@example.com",
//   "tenant_id": "acme-corp",
//   "userId": "usr_abc123",
//   "roles": ["TECHNICIAN", "ADMIN"]
// }

// Programmatic authentication in a controller:
@RestController
public class RegistrationController {

    private final AuthenticationManager authenticationManager;

    public void loginAfterRegister(String email, String password) {
        var token = new UsernamePasswordAuthenticationToken(email, password);
        Authentication auth = authenticationManager.authenticate(token);
        SecurityContextHolder.getContext().setAuthentication(auth);
    }
}
```

> **Multi-tenant note:** Both `jwkSource` and `userDetailsService` rely on `TenantContext.getTenantId()` being populated by the `TenantForwardedPrefixFilter` before the security chain executes. A missing or blank tenant ID throws `IllegalStateException` at the JWKS endpoint.
