Configures Spring Security for all non-Authorization Server HTTP requests, wiring together OAuth2/OIDC login flows, SSO provider support, form login, and automatic user provisioning for multi-tenant environments.

## Key Components

| Component | Description |
|---|---|
| `defaultSecurityFilterChain` | `@Order(2)` filter chain defining public/protected route rules, form login, and OAuth2 login with custom handlers |
| `oidcUserService` | Custom OIDC user service that delegates to Spring's default, then auto-provisions users and resolves principal claims |
| `microsoftAwareJwtDecoderFactory` | `JwtDecoderFactory` with special handling for Microsoft multi-tenant OIDC issuers using regex pattern validation |
| `oauth2LoginFailureHandler` | Redirects failed OAuth2 logins to a configurable error URL with a URL-encoded error message |
| `autoProvisionIfNeeded` | Internal helper that checks SSO config, domain allowlists, and triggers `RegistrationProcessor` for new users |
| `MS_ISSUER_PATTERN` | Compiled regex matching `https://login.microsoftonline.com/{tenant}/v2.0` issuer URLs |

## Usage Example

```java
// Spring auto-wires SecurityConfig via @Configuration + @EnableWebSecurity.
// The filter chain permits public paths and secures everything else:

// Publicly accessible (no auth required):
// GET /login, /oauth/**, /sso/providers/**, /.well-known/**, /tenant/**

// All other requests require an authenticated session.
// On successful OAuth2/OIDC login, AuthSuccessHandler is invoked.
// On failure, the user is redirected to:
//   ${openframe.auth.error-url}?error=<url-encoded-message>

// Microsoft SSO receives a custom JWT decoder that validates
// multi-tenant issuers against the pattern:
// ^https://login\.microsoftonline\.com/[^/]+/v2\.0/?$
```

## Configuration Property

```yaml
openframe:
  auth:
    error-url: https://your-app/auth-error
```

## Notes

- CSRF and CORS are **disabled** — ensure upstream gateway or reverse proxy handles these.
- `SsoAuthorizationRequestResolver` customizes the OAuth2 authorization request (e.g., injects SSO cookie state).
- Auto-provisioning respects per-tenant `SSOPerTenantConfig.isAutoProvisionUsers()` and `allowedDomains` allowlists.
