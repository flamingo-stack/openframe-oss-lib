Thrown when a tenant owner attempts to switch to a different tenant, which is a prohibited operation.

## Key Components

- **`OwnerCannotSwitchTenantException`** — Extends `ConflictException`, signaling an HTTP 409 Conflict when a tenant owner tries to switch tenants.
- **`ErrorCode.OWNER_CANNOT_SWITCH_TENANT`** — Structured error code passed to the parent for consistent API error responses.

## Usage Example

```java
if (user.isOwner() && !user.getTenantId().equals(targetTenantId)) {
    throw new OwnerCannotSwitchTenantException(user.getEmail());
}
```

The exception message includes the owner's email for traceability (e.g., `"Tenant owner cannot switch tenant: owner@example.com"`).
