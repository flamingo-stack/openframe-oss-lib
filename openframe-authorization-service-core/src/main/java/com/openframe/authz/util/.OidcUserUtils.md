Utility class for extracting and normalizing user identity data from OIDC claims, with special handling for cross-provider compatibility (Google, Microsoft AAD, and standard OIDC providers).

## Key Components

| Method | Description |
|---|---|
| `resolveEmail(OidcUser)` | Resolves an email identifier using a fallback chain: `email` → `preferred_username` → `upn` → `unique_name` |
| `resolveNames(OidcUser)` | Returns `[firstName, lastName]` using `given_name`/`family_name`, falling back to splitting the `name` claim, then the email local-part |
| `resolvePictureUrl(OidcUser)` | Reads the standard `picture` claim (Google); returns `null` for Microsoft AAD (requires Graph API) |
| `stringClaim(Object)` | Normalizes a raw claim value — returns the string if non-blank, otherwise `null` |

## Usage Example

```java
@Service
public class UserProvisioningService {

    public UserProfile buildProfile(OidcUser oidcUser) {
        String email = OidcUserUtils.resolveEmail(oidcUser);
        String[] names = OidcUserUtils.resolveNames(oidcUser);
        String picture = OidcUserUtils.resolvePictureUrl(oidcUser);

        return UserProfile.builder()
            .email(email)
            .firstName(names[0])
            .lastName(names[1])
            .avatarUrl(picture)
            .build();
    }
}
```

## Provider Compatibility

```text
Claim           Google    Microsoft AAD    Standard OIDC
─────────────────────────────────────────────────────────
email           ✓         ✗                ✓
preferred_username ✗      ✓                ✓
upn             ✗         ✓ (AAD v1)       ✗
unique_name     ✗         ✓ (AAD v1)       ✗
given_name      ✓         ✗ (often)        ✓
family_name     ✓         ✗ (often)        ✓
name            ✓         ✓                ✓
picture         ✓         ✗ (Graph only)   ✓
```

> **Note:** `resolveNames` guarantees no `null` entries in the returned array — safe to persist directly without null checks.
