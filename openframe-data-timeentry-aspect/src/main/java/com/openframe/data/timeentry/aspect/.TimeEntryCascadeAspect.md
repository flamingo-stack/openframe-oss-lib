An AOP aspect that intercepts `TicketRepository.save()` and `saveAll()` calls to detect ticket title changes and cascade those updates to associated time entries.

## Key Components

| Member | Description |
|---|---|
| `aroundTicketSave` | `@Around` advice wrapping single `TicketRepository.save()` — captures the pre-save title, proceeds, then triggers a cascade if the title changed |
| `aroundTicketSaveAll` | `@Around` advice wrapping `TicketRepository.saveAll()` — performs the same diff logic across a batch of tickets |
| `captureTicketTitle` | Fetches the current persisted title for a single ticket before the save proceeds (returns `null` for new tickets) |
| `captureTicketTitles` | Builds a `Map<ticketId, oldTitle>` snapshot for a batch of tickets before the save proceeds |
| `cascadeTicketTitleChange` | Delegates to `TimeEntryCascadeService.updateTimeEntriesForTicketTitleChange()`, logging failures without re-throwing to avoid disrupting the original save |

## Usage Example

This aspect is applied automatically via Spring AOP — no call-site changes are required. Register it as a Spring bean alongside its dependencies:

```java
@Configuration
public class AspectConfig {

    @Bean
    public TimeEntryCascadeAspect timeEntryCascadeAspect(
            TimeEntryCascadeService cascadeService,
            TicketRepository ticketRepository) {
        return new TimeEntryCascadeAspect(cascadeService, ticketRepository);
    }
}
```

Once registered, any `TicketRepository.save()` call that changes a ticket's title will automatically propagate the new title to all linked time entries:

```java
// Title change detected automatically — no extra code needed
ticket.setTitle("Updated Ticket Title");
ticketRepository.save(ticket); // aspect intercepts, cascades title to time entries
```

> **Note:** Cascade failures are caught and logged at `ERROR` level but do not roll back or interrupt the originating save operation.
