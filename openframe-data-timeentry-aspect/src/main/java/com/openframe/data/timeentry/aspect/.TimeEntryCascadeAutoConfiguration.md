Auto-configuration class that conditionally registers Spring beans for TimeEntry cascade update functionality, activating when the `openframe.timeentry.cascade.enabled` property is `true` (enabled by default).

## Key Components

| Bean | Type | Description |
|------|------|-------------|
| `timeEntryCascadeService` | `TimeEntryCascadeService` | Core service handling cascade update logic, depends on `TimeEntryRepository` |
| `timeEntryCascadeAspect` | `TimeEntryCascadeAspect` | AOP aspect that intercepts relevant operations and triggers cascade updates, depends on `TimeEntryCascadeService` and `TicketRepository` |

**Activation condition:** `@ConditionalOnProperty(name = "openframe.timeentry.cascade.enabled", havingValue = "true", matchIfMissing = true)` — enabled by default unless explicitly disabled.

## Usage Example

**Enable or disable via `application.yml`:**

```yaml
openframe:
  timeentry:
    cascade:
      enabled: true   # default; omit to keep enabled
```

**Disable cascade updates:**

```yaml
openframe:
  timeentry:
    cascade:
      enabled: false
```

**Manual bean wiring (if auto-configuration is excluded):**

```java
@Bean
public TimeEntryCascadeService timeEntryCascadeService(TimeEntryRepository repo) {
    return new TimeEntryCascadeService(repo);
}

@Bean
public TimeEntryCascadeAspect timeEntryCascadeAspect(
        TimeEntryCascadeService service,
        TicketRepository ticketRepository) {
    return new TimeEntryCascadeAspect(service, ticketRepository);
}
```

> **Note:** This class follows Spring Boot's `@AutoConfiguration` pattern and is discovered automatically via `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports`. No explicit `@Import` is needed in consuming modules.
