Handles cascade updates to `TimeEntry` records when a ticket's title changes, ensuring denormalized ticket title data stays consistent across all related time entries.

## Key Components

| Member | Type | Description |
|---|---|---|
| `timeEntryRepository` | `TimeEntryRepository` | Repository for fetching and persisting `TimeEntry` documents |
| `updateTimeEntriesForTicketTitleChange` | Method | Finds all time entries by ticket ID and updates those with a stale title |

## Usage Example

```java
@Service
@RequiredArgsConstructor
public class TicketUpdateHandler {

    private final TimeEntryCascadeService timeEntryCascadeService;

    public void onTicketTitleUpdated(String ticketId, String newTitle) {
        // Propagate the new title to all linked time entries
        timeEntryCascadeService.updateTimeEntriesForTicketTitleChange(ticketId, newTitle);
    }
}
```

## Behavior Notes

- **No-op on empty result:** Logs a `DEBUG` message and returns early if no entries exist for the given `ticketId`.
- **Selective update:** Only entries where `ticketTitle` differs from `newTitle` are modified, avoiding unnecessary writes.
- **Bulk save:** All stale entries are updated in a single `saveAll` call for efficiency.
- **Audit logging:** Logs an `INFO` message with the count of updated entries, the ticket ID, and the new title on every successful cascade.
