Unit test suite for `FcmPushSender`, verifying FCM multicast delivery behavior including device token lifecycle management, payload construction, chunking, and error handling edge cases.

## Key Components

| Test Method | What It Verifies |
|---|---|
| `user_without_devices_is_a_noop` | No FCM call is made when a user has no registered devices |
| `devices_are_multicast_in_one_call` | Multiple devices are batched into a single multicast call |
| `unregistered_token_is_pruned` | Tokens with `UNREGISTERED` error code are deleted from the repository |
| `invalid_argument_never_prunes_tokens` | `INVALID_ARGUMENT` errors never trigger token deletion (bad payload ≠ dead token) |
| `transient_error_does_not_prune_the_token` | Transient `UNAVAILABLE` errors preserve device registrations |
| `tokens_beyond_the_cap_are_chunked_and_dead_tokens_map_to_the_right_chunk` | 500-token FCM cap triggers chunking; dead token indices map correctly per chunk |
| `whole_batch_failure_is_swallowed_and_prunes_nothing` | `FirebaseMessagingException` is silently absorbed without pruning tokens |
| `data_payload_carries_the_context_fields_the_client_routes_on` | Payload includes `id`, `type`, `category`, `severity`, and serialized context |
| `oversized_context_is_dropped_but_the_push_still_goes` | Context is dropped when it exceeds `maxContextBytes`, but core fields survive |
| `ios_push_carries_default_sound` | APNs config sets `aps.sound=default` for iOS devices |

## Usage Example

```java
// Typical test setup pattern used in this suite
@BeforeEach
void setUp() {
    firebaseMessaging = mock(FirebaseMessaging.class);
    deviceRepository = mock(PushDeviceRepository.class);
    properties = new FcmProperties();
    properties.setProjectId("flamingo-271f8");
    sender = new FcmPushSender(firebaseMessaging, deviceRepository, new ObjectMapper(), properties);
}

// Verify a dead token is pruned after UNREGISTERED response
BatchResponse oneDead = batch(1, List.of(
    failure(MessagingErrorCode.UNREGISTERED),
    success()
));
when(firebaseMessaging.sendEachForMulticast(any())).thenReturn(oneDead);
sender.deliver("u1", notification(), NotificationCategory.TICKETS);

ArgumentCaptor<List<String>> captor = ArgumentCaptor.forClass(List.class);
verify(deviceRepository).deleteByTokenIn(captor.capture());
assertThat(captor.getValue()).containsExactly("dead");
```

> **Note:** The `apsSound` helper accesses private fields on `ApnsConfig` via reflection since `firebase-admin` 9.9.0 exposes no public getters — this is intentional and pinned to that version.
