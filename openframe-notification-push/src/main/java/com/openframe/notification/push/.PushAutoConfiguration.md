Spring Boot auto-configuration that bootstraps Firebase Cloud Messaging (FCM) for push notifications, activated only when `openframe.features.push.enabled=true`.

## Key Components

| Bean / Element | Description |
|---|---|
| `firebaseMessaging()` | Initializes `FirebaseApp` using Application Default Credentials and project settings from `FcmProperties`, returning a `FirebaseMessaging` instance. Skips re-initialization if an app already exists. |
| `fcmPushChannel()` | Exposes an `FcmPushSender` as a `NotificationChannel` bean, wiring together FCM messaging, device repository, JSON mapping, and FCM properties. |
| `@ConditionalOnProperty` | Guards the entire configuration behind `openframe.features.push.enabled=true`. |
| `@ConditionalOnMissingBean` | Allows downstream services to override the default `FirebaseMessaging` bean. |

## Usage Example

```java
// application.yml
openframe:
  features:
    push:
      enabled: true
  fcm:
    project-id: my-firebase-project
    connect-timeout: 5s
    read-timeout: 10s
```

```java
// Inject the registered NotificationChannel in your service
@Service
public class AlertService {

    private final NotificationChannel pushChannel;

    public AlertService(NotificationChannel fcmPushChannel) {
        this.pushChannel = fcmPushChannel;
    }

    public void sendAlert(String userId, String message) {
        pushChannel.send(userId, message);
    }
}
```

> **Note:** This class is registered via `AutoConfiguration.imports`. Do **not** rely on component scanning to pick it up — the consuming application does not scan the `com.openframe.notification.push` package.
