Implements Firebase Cloud Messaging (FCM) push notification delivery for OpenFrame, handling multicast batching, payload size enforcement, and automatic cleanup of dead device tokens.

## Key Components

| Member | Description |
|---|---|
| `deliver()` | Entry point — loads user devices, batches tokens into ≤500-token chunks, dispatches FCM multicasts, and purges dead tokens |
| `sendChunk()` | Builds and sends a single `MulticastMessage` with title/body truncation and APNS sound config; logs delivery ratio |
| `buildData()` | Constructs the FCM data payload map (`notificationId`, `type`, `category`, `severity`, `context`); omits context when it exceeds `maxContextBytes` |
| `collectDeadTokens()` | Scans `BatchResponse` for `UNREGISTERED` / `SENDER_ID_MISMATCH` errors and accumulates stale tokens for deletion |
| `truncateToBytes()` | UTF-8–aware string truncation that respects multi-byte/supplementary codepoints without splitting them |
| `DEAD_TOKEN_ERRORS` | `EnumSet` of FCM error codes that indicate a permanently invalid token (`INVALID_ARGUMENT` intentionally excluded) |
| `FCM_PAYLOAD_LIMIT_BYTES` | FCM hard cap (4 096 bytes); paired with `ENVELOPE_HEADROOM_BYTES` (512) to size context serialization checks |

## Usage Example

```java
// Wired via dependency injection (Spring / Micronaut)
FcmPushSender sender = new FcmPushSender(
    FirebaseMessaging.getInstance(),
    pushDeviceRepository,
    objectMapper,
    fcmProperties          // configures maxTitleBytes, maxBodyBytes, maxContextBytes
);

// Called by the notification dispatch layer
sender.deliver(
    "user-42",
    notification,          // carries id, title, description, severity, context
    NotificationCategory.ALERT
);
// → sends up to 500 tokens/multicast, prunes dead tokens automatically
```

> **Payload safety:** `buildData()` serializes `NotificationContext` to JSON and drops it silently when the byte length exceeds `FcmProperties.maxContextBytes`, keeping the total payload under `FCM_PAYLOAD_LIMIT_BYTES` (4 096 bytes). Clients can retrieve the full context by notification ID.
