Defines a secondary lookup interface for identifying disposable email domains not covered by the built-in blocklist.

## Key Components

| Component | Description |
|---|---|
| `DisposableDomainChecker` | Interface for runtime disposable-domain lookups |
| `isDisposable(String domain)` | Returns `true` only when a domain is positively known to be disposable |

## Behavior Contract

Implementations **must fail open**: if the external service is unreachable (timeout, bad response, service down), return `false`. An unavailable third-party checker must never block a legitimate registration or invitation flow.

## Usage Example

```java
// Custom implementation backed by an external API
public class ExternalDisposableDomainChecker implements DisposableDomainChecker {

    @Override
    public boolean isDisposable(String domain) {
        try {
            return externalApiClient.check(domain).isDisposable();
        } catch (Exception e) {
            // Fail open — external service unreachable
            return false;
        }
    }
}

// Usage in email validation
if (disposableDomainChecker.isDisposable("mailinator.com")) {
    throw new DisposableDomainException("Disposable email addresses are not allowed.");
}
```

## Notes

- `domain` must be lowercase and must not include the local part (e.g., `"mailinator.com"`, not `"user@mailinator.com"`)
- Acts as a secondary lookup; the primary built-in blocklist is checked first
- Designed to be injected as a dependency, allowing no-op or stub implementations in tests
