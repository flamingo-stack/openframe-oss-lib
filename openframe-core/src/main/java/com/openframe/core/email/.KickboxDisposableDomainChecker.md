Implements the `DisposableDomainChecker` interface by delegating to an external HTTP service (Kickbox by default) to determine whether a given email domain is disposable.

## Key Components

- **`KickboxDisposableDomainChecker`** — Spring `@Component` conditionally registered when `openframe.email-domain-policy.disposable-check.enabled=true` (active by default via `matchIfMissing = true`).
- **`isDisposable(String domain)`** — Calls `DisposableDomainHttpClient.check(domain)`, returns `true` only if the response is non-null and `disposable()` is `true`.
- **Fail-open behavior** — Any exception (timeout, non-2xx, DNS failure, parse error) is caught, logged as a warning, and treated as `false` (not disposable). Signup is never blocked due to checker failures.
- **`DisposableDomainClientConfig`** — Timeout configuration lives separately on the HTTP client; see that class for tuning connection/read timeouts.

## Usage Example

```java
// Autowired by Spring — no manual instantiation needed.
// Activated when the following property is set (or absent, since matchIfMissing = true):
// openframe.email-domain-policy.disposable-check.enabled=true

@Autowired
private DisposableDomainChecker checker;

boolean blocked = checker.isDisposable("mailinator.com"); // true
boolean allowed = checker.isDisposable("gmail.com");      // false

// On network failure:
boolean failOpen = checker.isDisposable("unreachable.example"); // false — fail-open
```

> **Note:** This checker only ever *adds* blocks on top of the built-in domain list. It cannot be the sole reason a signup is rejected.
