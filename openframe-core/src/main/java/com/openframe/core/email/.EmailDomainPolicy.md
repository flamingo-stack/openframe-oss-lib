Enforces email domain policies for registration, invitation, and SSO auto-provisioning flows by checking against a configured blocklist and an optional disposable-domain service.

## Key Components

| Member | Description |
|---|---|
| `ensureEmailAllowed(String email)` | Throws `IllegalArgumentException` if the email's domain is blocked; use in registration/invite flows |
| `ensureDomainsAllowed(Collection<String> domains)` | Throws `IllegalArgumentException` if any domain in a collection is blocked; use when configuring SSO auto-provisioning |
| `isEmailAllowed(String email)` | Non-throwing form of `ensureEmailAllowed`; returns `false` if blocked, safe for conditional logic |
| `isDomainBlocked(String domain)` | Core check: evaluates the enabled flag, allowed-domains whitelist, blocked-domains list, then the disposable-domain checker in order |
| `EmailDomainPolicyProperties` | Injected config holding `blockedDomains`, `allowedDomains`, enabled flags, and disposable-check settings |
| `DisposableDomainChecker` | Injected third-party disposable-domain lookup; **fails open** — an unreachable service never blocks a legitimate flow |

**Evaluation order inside `isDomainBlocked`:**
1. Policy disabled → `false`
2. Domain on allowlist → `false`
3. Domain on blocklist → `true`
4. Disposable check disabled → `false`
5. Disposable check result → `true/false`

## Usage Example

```java
// Registration / invite (throws on violation)
emailDomainPolicy.ensureEmailAllowed("alice@gmail.com");

// SSO configuration (validate multiple domains at once)
emailDomainPolicy.ensureDomainsAllowed(List.of("acme.com", "acme.io"));

// Silent check during SSO login auto-provisioning
if (!emailDomainPolicy.isEmailAllowed(userEmail)) {
    log.warn("Skipping auto-provisioning for blocked domain: {}", userEmail);
    return;
}

// Low-level domain check (after normalization)
boolean blocked = emailDomainPolicy.isDomainBlocked("mailinator.com"); // true
```

> **Note:** Domain comparisons are always case-insensitive and trimmed via an internal `normalize()` helper, so `"ACME.COM"`, `" acme.com "`, and `"acme.com"` are treated as identical.
