Configures and registers the `DisposableDomainHttpClient` bean used to check whether an email domain is disposable. Active by default, this config is conditionally enabled via the `openframe.email-domain-policy.disposable-check.enabled` property.

## Key Components

- **`DisposableDomainClientConfig`** — Spring `@Configuration` class conditionally activated via `ConditionalOnProperty`
- **`disposableDomainHttpClient()`** — `@Bean` factory method that builds a timeout-bounded declarative HTTP client using Spring's `HttpServiceProxyFactory`
- **Timeout enforcement** — Both connect and read timeouts are sourced from `EmailDomainPolicyProperties.getDisposableCheck().getTimeoutMs()` to prevent third-party slowness from stalling registration or invitation flows

## Usage Example

```java
// application.yml configuration
openframe:
  email-domain-policy:
    disposable-check:
      enabled: true
      url: https://disposable-domain-api.example.com
      timeout-ms: 3000
```

```java
// Injecting the auto-configured client
@Service
public class RegistrationService {

    private final DisposableDomainHttpClient disposableDomainClient;

    public RegistrationService(DisposableDomainHttpClient disposableDomainClient) {
        this.disposableDomainClient = disposableDomainClient;
    }

    public void register(String email) {
        String domain = extractDomain(email);
        if (disposableDomainClient.isDisposable(domain)) {
            throw new DisposableDomainException("Disposable email domains are not allowed.");
        }
        // proceed with registration...
    }
}
```

## Notes

- To disable disposable domain checking entirely, set `openframe.email-domain-policy.disposable-check.enabled=false`
- `matchIfMissing = true` means the bean is active even when the property is absent
- Uses `SimpleClientHttpRequestFactory` for straightforward connect/read timeout control without additional HTTP client dependencies
