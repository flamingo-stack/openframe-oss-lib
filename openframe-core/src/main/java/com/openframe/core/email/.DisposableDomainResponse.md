Response body returned by the disposable-domain endpoint, representing whether a given email domain is classified as disposable (e.g. `{"disposable": true}`).

## Key Components

- **`disposable`** (`boolean`) — The single record component indicating whether the domain is a disposable/temporary email provider.

## Usage Example

```java
// Deserializing a response from the disposable-domain endpoint
DisposableDomainResponse response = objectMapper.readValue(
    "{\"disposable\": true}",
    DisposableDomainResponse.class
);

if (response.disposable()) {
    throw new IllegalArgumentException("Disposable email domains are not allowed.");
}
```

## Notes

- Implemented as a Java `record`, providing an immutable, concise DTO with a generated constructor, accessor (`disposable()`), `equals`, `hashCode`, and `toString`.
- Intended for use within the `com.openframe.core.email` package as part of email validation flows in the [OpenFrame](https://openframe.ai) platform.
