Fallback implementation of `DisposableDomainChecker` that unconditionally returns `false` for all domains, effectively disabling the external disposable-domain check while still allowing the built-in blocklist to function.

## Key Components

| Element | Description |
|---|---|
| `NoopDisposableDomainChecker` | Spring `@Component` active when `openframe.email-domain-policy.disposable-check.enabled=false` |
| `isDisposable(String domain)` | Always returns `false`; no external API calls are made |

## Configuration

This bean is conditionally registered via `@ConditionalOnProperty` and is mutually exclusive with [`KickboxDisposableDomainChecker`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/core/email/KickboxDisposableDomainChecker.java). Exactly one of the two will exist in the application context at runtime.

```yaml
# application.yml — disable external disposable-domain check
openframe:
  email-domain-policy:
    disposable-check:
      enabled: false   # activates NoopDisposableDomainChecker
```

## Usage Example

```java
// Injected automatically when the property above is false
@Service
public class EmailValidationService {

    private final DisposableDomainChecker disposableDomainChecker;

    public EmailValidationService(DisposableDomainChecker disposableDomainChecker) {
        this.disposableDomainChecker = disposableDomainChecker;
    }

    public boolean isAllowed(String domain) {
        // With Noop active, isDisposable always returns false —
        // only the built-in blocklist drives rejections.
        return !disposableDomainChecker.isDisposable(domain);
    }
}
```

> **Note:** Use this implementation in local development or test environments where external API calls to Kickbox are undesirable. For production, set `enabled: true` to activate the full `KickboxDisposableDomainChecker`.
