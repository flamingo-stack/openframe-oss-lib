Declarative HTTP interface for querying an external disposable email domain lookup service. The base URL is configured via `openframe.email-domain-policy.disposable-check.url`, with the path resolving to the target domain.

## Key Components

| Element | Description |
|---|---|
| `DisposableDomainHttpClient` | Spring 6 declarative HTTP interface (`@HttpExchange`) for disposable domain checks |
| `check(String domain)` | `GET /{domain}` — performs a lookup for the given domain and returns a `DisposableDomainResponse` |

## Configuration

Set the base URL in your application properties:

```yaml
openframe:
  email-domain-policy:
    disposable-check:
      url: https://your-disposable-check-api.example.com
```

## Usage Example

```java
// Register the client as a Spring bean
@Bean
public DisposableDomainHttpClient disposableDomainHttpClient(HttpServiceProxyFactory factory) {
    return factory.createClient(DisposableDomainHttpClient.class);
}

// Inject and use in a service
@Service
public class EmailValidationService {

    private final DisposableDomainHttpClient disposableDomainHttpClient;

    public boolean isDisposable(String email) {
        String domain = email.substring(email.indexOf('@') + 1);
        DisposableDomainResponse response = disposableDomainHttpClient.check(domain);
        return response.isDisposable();
    }
}
```

## Notes

- Accepts `application/json` responses by default (set via `@HttpExchange`)
- Relies on Spring 6's `HttpServiceProxyFactory` for runtime proxy generation
- Pair with `DisposableDomainResponse` for full deserialization of the API response
