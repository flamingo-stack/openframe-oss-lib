Spring Boot `@ConfigurationProperties` bean that exposes tuning knobs for `EmailDomainPolicy` under the `openframe.email-domain-policy` namespace. All fields carry safe defaults so the policy works out of the box without any explicit configuration.

## Key Components

| Member | Type | Default | Description |
|---|---|---|---|
| `enabled` | `boolean` | `true` | Master switch — set to `false` to disable all domain blocking (e.g., self-hosted deployments) |
| `blockedDomains` | `Set<String>` | `{}` | Domains to reject; seeded from the bundled `config/email-domain-policy-defaults.yml` |
| `allowedDomains` | `Set<String>` | `{}` | Per-deployment carve-outs that override entries in `blockedDomains` |
| `disposableCheck` | `DisposableCheck` | see below | Nested config for the external disposable-domain API call |

### Nested: `DisposableCheck`

| Member | Type | Default | Description |
|---|---|---|---|
| `enabled` | `boolean` | `true` | Toggle the external API lookup |
| `url` | `String` | `https://open.kickbox.com/v1/disposable/` | Base URL; domain is appended as a path segment |
| `timeoutMs` | `long` | `1500` | Hard call timeout — kept short to avoid stalling registration/invitation flows |

## Usage Example

```yaml
# application.yml
openframe:
  email-domain-policy:
    enabled: true
    blocked-domains:
      - mailinator.com
      - guerrillamail.com
    allowed-domains:
      - trusted-partner.com
    disposable-check:
      enabled: true
      url: https://open.kickbox.com/v1/disposable/
      timeout-ms: 1000
```

```java
@Component
public class RegistrationService {

    private final EmailDomainPolicyProperties props;

    public RegistrationService(EmailDomainPolicyProperties props) {
        this.props = props;
    }

    public void register(String email) {
        if (!props.isEnabled()) {
            // policy disabled — skip all checks
        }
        // use props.getBlockedDomains(), props.getAllowedDomains(), etc.
    }
}
```
