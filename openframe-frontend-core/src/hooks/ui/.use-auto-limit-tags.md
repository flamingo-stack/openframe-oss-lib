Calculates how many tag chips fit in a single-line container using real DOM measurements, supporting both fixed and automatic (`"auto"`) limits with `ResizeObserver`-driven updates.

## Key Components

### `useAutoLimitTags(options)`
Main hook that returns refs and a `visibleCount` to drive tag overflow rendering.

**Options (`UseAutoLimitTagsOptions`):**

| Option | Type | Default | Description |
|---|---|---|---|
| `count` | `number` | — | Total number of tags |
| `limitTags` | `number \| "auto"` | `"auto"` | Fixed limit or DOM-based measurement |
| `placeholder` | `string` | `""` | Input placeholder used to reserve input width |
| `reserveInputWidth` | `boolean` | `true` | Reserve trailing space for a combobox input |

**Returns (`UseAutoLimitTagsReturn`):**

| Ref / Value | Attach to | Purpose |
|---|---|---|
| `visibleCount` | — | Number of tags to render visibly |
| `middleRef` | `<div>` (tag + input zone) | Source of CSS metrics (padding, gap, width) |
| `measureRef` | `<div>` (off-screen) | Holds hidden copies of all tags for width measurement |
| `textMeasureRef` | `<span>` (off-screen) | Measures placeholder text width |
| `badgeRef` | `<button>` (+N badge) | Measures overflow badge width |
| `inputRef` | `<input>` | Reads `min-width` for input reservation |

## Usage Example

```typescript
import { useAutoLimitTags } from "./use-auto-limit-tags"

function TagRow({ tags }: { tags: string[] }) {
  const {
    visibleCount,
    middleRef,
    measureRef,
    textMeasureRef,
    badgeRef,
    inputRef,
  } = useAutoLimitTags({ count: tags.length, placeholder: "Search..." })

  const overflowCount = tags.length - visibleCount

  return (
    <>
      {/* Visible tag zone */}
      <div ref={middleRef} style={{ overflow: "hidden", display: "flex", gap: 8 }}>
        {tags.slice(0, visibleCount).map((tag) => (
          <span key={tag}>{tag}</span>
        ))}
        {overflowCount > 0 && (
          <button ref={badgeRef}>+{overflowCount}</button>
        )}
        <input ref={inputRef} placeholder="Search..." />
      </div>

      {/* Off-screen measurement elements */}
      <div ref={measureRef} style={{ visibility: "hidden", position: "absolute" }}>
        {tags.map((tag) => <span key={tag}>{tag}</span>)}
      </div>
      <span ref={textMeasureRef} style={{ visibility: "hidden", position: "absolute" }}>
        Search...
      </span>
    </>
  )
}
```

> **Note:** The `measureRef` container must render a hidden copy of **all** tags off-screen so the hook can measure each chip's true rendered width regardless of which tags are currently visible.
