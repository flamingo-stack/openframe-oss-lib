Stub React hooks providing placeholder API data-fetching interfaces for categories, vendors, and subcategory counts — returning empty state without making actual network requests.

## Key Components

| Hook | Returns | Description |
|------|---------|-------------|
| `useCategories` | `{ categories, loading, error }` | Fetches category list |
| `useVendors` | `{ vendors, loading, error }` | Fetches vendor list |
| `useSubcategoryCountByCategory` | `{ data, loading }` | Returns subcategory counts keyed by category |

## Usage Example

```typescript
import {
  useCategories,
  useVendors,
  useSubcategoryCountByCategory,
} from './api-hooks';

function CatalogView() {
  const { categories, loading, error } = useCategories();
  const { vendors } = useVendors();
  const { data: subcategoryCounts } = useSubcategoryCountByCategory();

  if (loading) return <span>Loading...</span>;
  if (error) return <span>Error loading data</span>;

  return (
    <ul>
      {categories.map((cat) => (
        <li key={cat.id}>{cat.name}</li>
      ))}
    </ul>
  );
}
```

> **Note:** These are stub implementations — all hooks return empty/static state and no network calls are made. They are intended as placeholders until real API endpoints are wired in.
