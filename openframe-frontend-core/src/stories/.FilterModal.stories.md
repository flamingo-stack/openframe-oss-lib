Storybook stories file for the `FilterModal` component, demonstrating all supported configurations including filter groups, sorting, tag key:value filtering, and interactive state management.

## Key Components

**Exported Stories**

| Story | Description |
|---|---|
| `Default` | Basic modal with status filter group and pre-selected filters |
| `Interactive` | Stateful example with open/close toggle and live filter count |
| `MultipleGroups` | Multiple filter group categories (statuses, device types, OS) |
| `WithoutCounts` | Filter options without item counts |
| `WithSorting` | Combined sort columns and filter groups |
| `SortingOnly` | Sort configuration with no filter groups |
| `InteractiveWithSorting` | Stateful sort + filter with live sort indicator |
| `EmptyFilters` | Filter groups present but nothing selected |
| `NoFiltersAvailable` | Modal open with no filter options |
| `FullyEmpty` | All optional props omitted |
| `Loading` | Skeleton loading state via `isLoading: true` |
| `WithTagFilter` | Tag key:value filter section alongside standard filters |
| `TagFilterOnly` | Tag filter without regular filter groups |
| `FullFeatured` | All features combined: sort + filters + tag filters |
| `InteractiveWithTags` | Fully stateful with tags, sort, and filters |

**Key Types Used**

- `FilterGroup` — filter section with options, labels, and optional counts
- `SortConfig` — sort column list plus active sort key and direction
- `TagKeyConfig` — tag key with filterable values (e.g. `site:chicago`)
- `TableFilters` — active filter state as `Record<string, string[]>`

## Usage Example

```typescript
import { FilterModal, type FilterGroup, type SortConfig } from '../components/ui/filter-modal'
import type { TableFilters } from '../components/ui/table/types'

const filterGroups: FilterGroup[] = [
  {
    id: 'statuses',
    title: 'Statuses',
    options: [
      { id: 'active', label: 'Active', count: 2975 },
      { id: 'inactive', label: 'Inactive', count: 245 },
    ],
  },
]

const sortConfig: SortConfig = {
  columns: [
    { key: 'name', label: 'Name' },
    { key: 'date', label: 'Date' },
  ],
  sortBy: 'name',
  sortDirection: 'asc',
}

function MyPage() {
  const [isOpen, setIsOpen] = useState(false)
  const [filters, setFilters] = useState<TableFilters>({})

  return (
    <FilterModal
      isOpen={isOpen}
      onClose={() => setIsOpen(false)}
      filterGroups={filterGroups}
      currentFilters={filters}
      onFilterChange={setFilters}
      sortConfig={sortConfig}
      onSort={(col, dir) => console.log(col, dir)}
      isLoading={false}
    />
  )
}
```
