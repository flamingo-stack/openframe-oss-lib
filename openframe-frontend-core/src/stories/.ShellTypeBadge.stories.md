Storybook stories for the `ShellTypeBadge` component, providing interactive documentation and visual testing for all supported OpenFrame RMM shell/script type badges.

## Key Components

| Export | Type | Description |
|---|---|---|
| `meta` | `Meta<ShellTypeBadge>` | Storybook metadata with `select` control for `shellType` and autodocs enabled |
| `Default` | `Story` | Default story using `POWERSHELL` |
| `PowerShell` | `Story` | PowerShell badge variant |
| `Cmd` | `Story` | CMD/Batch badge variant |
| `Bash` | `Story` | Bash badge variant |
| `Python` | `Story` | Python badge variant |
| `Nushell` | `Story` | Nushell badge variant |
| `Deno` | `Story` | Deno badge variant |
| `Shell` | `Story` | Generic shell badge variant |
| `AllShellTypes` | `Story` | Composite story rendering all seven variants stacked for side-by-side comparison |

## Usage Example

```typescript
// Render a single badge in your component
import { ShellTypeBadge } from '../components/platform/ShellTypeBadge';

<ShellTypeBadge shellType="PYTHON" />

// Supported shellType values
const shellTypes = [
  'POWERSHELL',
  'CMD',
  'BASH',
  'PYTHON',
  'NUSHELL',
  'DENO',
  'SHELL',
] as const;
```

## Supported Shell Types

| `shellType` | Description |
|---|---|
| `POWERSHELL` | Windows PowerShell / PowerShell Core |
| `CMD` | Windows CMD / Batch scripts |
| `BASH` | Unix/Linux Bash shell |
| `PYTHON` | Python scripts |
| `NUSHELL` | Nushell modern shell |
| `DENO` | Deno TypeScript runtime |
| `SHELL` | Generic shell fallback |
