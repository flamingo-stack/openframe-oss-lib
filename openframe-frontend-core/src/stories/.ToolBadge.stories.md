Storybook stories for the `ToolBadge` component, covering all supported OpenFrame tool type variants with individual and combined display stories.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Default` | `Story` | `OPENFRAME_RMM` badge |
| `Fleet` | `Story` | `FLEET_MDM` badge |
| `MeshCentral` | `Story` | `MESHCENTRAL` badge |
| `Authentik` | `Story` | `AUTHENTIK` badge |
| `OpenFrame` | `Story` | `OPENFRAME` badge |
| `OpenFrameChat` | `Story` | `OPENFRAME_CHAT` badge |
| `OpenFrameClient` | `Story` | `OPENFRAME_CLIENT` badge |
| `System` | `Story` | `SYSTEM` badge |
| `AllTools` | `Story` | Side-by-side comparison of all badges |

**Supported `toolType` values:** `OPENFRAME_RMM` · `FLEET_MDM` · `MESHCENTRAL` · `AUTHENTIK` · `OPENFRAME` · `OPENFRAME_CHAT` · `OPENFRAME_CLIENT` · `SYSTEM`

## Usage Example

```typescript
import { ToolBadge } from '../components/platform/ToolBadge';

// Single badge
<ToolBadge toolType="OPENFRAME_RMM" />

// With optional class override
<ToolBadge toolType="FLEET_MDM" className="my-custom-class" />

// Inline comparison (mirrors AllTools story)
<div style={{ display: 'flex', flexDirection: 'column', gap: '1rem' }}>
  <ToolBadge toolType="OPENFRAME" />
  <ToolBadge toolType="OPENFRAME_CHAT" />
  <ToolBadge toolType="OPENFRAME_CLIENT" />
</div>
```

## Notes

- Stories live under the **Platform/ToolBadge** Storybook path with `autodocs` enabled.
- The `toolType` arg is exposed as a `select` control in the Storybook UI, making it easy to cycle through all tool types interactively.
- See [`ToolBadge`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/components/platform/ToolBadge.tsx) and [`ToolType`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/types/tool.types.ts) for implementation details.
