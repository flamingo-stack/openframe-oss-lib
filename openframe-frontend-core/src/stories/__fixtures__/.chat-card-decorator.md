Shared Storybook utilities for rendering chat entity-card stories in an isolated, realistic chat-column context.

## Key Components

- **`ChatColumnDecorator`** — React wrapper component that reproduces the assistant message column layout (constrained `max-w-[420px]`, ODS background, padding) so entity-card stories render at their real dimensions without the full chat runtime.
- **`makeAnchorProps`** — Factory that returns a `{ href, onClick }` pair satisfying card `*AnchorProps` interfaces. The `onClick` calls `preventDefault` to prevent iframe navigation in Storybook while preserving anchor semantics (hover, copy-link).

## Usage Example

```typescript
import { ChatColumnDecorator, makeAnchorProps } from './chat-card-decorator'
import type { Meta, StoryObj } from '@storybook/react'
import { TicketCard } from './ticket-card'

const meta: Meta<typeof TicketCard> = {
  component: TicketCard,
  decorators: [
    (Story) => (
      <ChatColumnDecorator>
        <Story />
      </ChatColumnDecorator>
    ),
  ],
}
export default meta

export const Default: StoryObj<typeof TicketCard> = {
  args: {
    title: 'Printer not working',
    anchorProps: makeAnchorProps('https://app.example.com/tickets/42'),
  },
}
```

## Notes

- `ChatColumnDecorator` is a layout-only wrapper; it carries no runtime dependencies, making it safe to import in any `.stories.tsx` file.
- `makeAnchorProps` is intentionally router-agnostic — swap `href` for any valid URL; the `onClick` stub is Storybook-only and should not be used in production card components.
