Storybook stories for the `Tag` UI component, covering all variants, icon/close button combinations, disabled states, and composite showcase renders.

## Key Components

| Export | Description |
|---|---|
| `Primary` | Tag with `primary` variant |
| `Outline` | Tag with `outline` variant |
| `Success` / `Warning` / `Error` / `Critical` / `Grey` | Semantic variant stories |
| `WithIcon` | Tag with a leading lucide icon |
| `WithCloseButton` | Tag with an `onClose` dismiss handler |
| `WithIconAndClose` | Tag combining icon and close button |
| `AllVariants` | Side-by-side showcase of all 7 variants |
| `AllWithIcons` | All variants rendered with icons |
| `AllWithClose` | All variants rendered with close buttons |
| `Disabled` | Single disabled tag |
| `DisabledWithIconAndClose` | Disabled tag with icon and close |
| `AllDisabled` | All variants in disabled state |
| `AllWithIconAndClose` | All variants with both icon and close |

## Usage Example

```typescript
import { Tag } from '../components/ui/tag';
import { Smile } from 'lucide-react';

// Basic variant
<Tag variant="success" label="Active" />

// With icon and dismissible close button
<Tag
  variant="primary"
  label="Assigned"
  icon={<Smile className="size-5" />}
  onClose={() => handleRemove()}
/>

// Disabled state
<Tag variant="warning" label="Pending" disabled />
```

## Variants

| Variant | Typical Use |
|---|---|
| `primary` | Default / general purpose |
| `outline` | Subtle / secondary |
| `success` | Positive status |
| `warning` | Cautionary status |
| `error` | Failure / invalid |
| `critical` | High-severity alert |
| `grey` | Neutral / inactive |
