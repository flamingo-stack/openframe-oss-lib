Storybook stories for the `OSTypeBadge`, `OSTypeIcon`, and `OSTypeLabel` components, covering OS type rendering, alias normalization, display modes, and sizing variants.

## Key Components

| Export | Type | Description |
|---|---|---|
| `Default` / `Windows` / `MacOS` / `Linux` | `Story` | Basic OS badge rendering per platform |
| `Darwin` / `Ubuntu` | `Story` | Alias normalization (e.g. `"Darwin"` → macOS, `"Ubuntu"` → Linux) |
| `IconOnly` / `LabelOnly` | `Story` | Display mode variants |
| `LargeIcon` | `Story` | Custom icon sizing via Tailwind class |
| `Unknown` | `Story` | Graceful fallback for undefined OS type |
| `AllOSTypes` | `Story` | Side-by-side comparison of all three platforms |
| `Aliases` | `Story` | Normalization showcase for `Darwin`, `win32`, `Ubuntu`, `Fedora` |
| `Icons` / `IconSizes` | `IconStory` | `OSTypeIcon` standalone stories with size variants |
| `Labels` | `LabelStory` | `OSTypeLabel` standalone story |

## Usage Example

```typescript
// Full badge (icon + label)
<OSTypeBadge osType="Darwin" />          // normalizes → macOS
<OSTypeBadge osType="win32" />           // normalizes → Windows

// Icon only
<OSTypeBadge osType="linux" iconOnly />
<OSTypeIcon  osType="linux" size="w-6 h-6" />

// Label only
<OSTypeBadge osType="macos" labelOnly />
<OSTypeLabel osType="macos" />

// Unknown / missing type (renders fallback)
<OSTypeBadge osType={undefined} labelOnly />
```

## Notes

- The `meta` object configures three separate Storybook entries: `Features/OSTypeBadge`, `Features/OSTypeIcon`, and `Features/OSTypeLabel`.
- `osType` accepts case-insensitive strings and platform aliases sourced from Fleet MDM, OpenFrame RMM, and similar integrations.
- `iconSize` / `size` accept Tailwind width/height classes (e.g. `"w-6 h-6"`).
