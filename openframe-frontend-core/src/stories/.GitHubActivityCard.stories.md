Storybook stories for the `GitHubActivityCard` component, covering the three GitHub doc types (`github_commit`, `github_pull_request`, `github_pr_review`) in both `compact` and `row` display variants.

## Key Components

| Export | Description |
|---|---|
| `Commit` | Story rendering a GitHub commit card in `compact` variant |
| `PullRequest` | Story rendering a pull request card in `compact` variant |
| `PullRequestReview` | Story rendering a PR review card with `[review:STATE]` badge parsing in `compact` variant |
| `RowVariant` | Story rendering a pull request card in `row` variant |

**Decorators & Fixtures:**
- `ChatColumnDecorator` — wraps each story in a chat column layout
- `makeAnchorProps` — generates resolved anchor props from an item URL
- `githubCommitItem`, `githubPullRequestItem`, `githubPrReviewItem` — pre-built fixture data for each GitHub doc type

## Usage Example

```typescript
// Rendering GitHubActivityCard directly (as used in stories)
import { GitHubActivityCard } from '../components/chat/entity-cards'
import { makeAnchorProps } from './__fixtures__/chat-card-decorator'
import { githubPullRequestItem } from './__fixtures__/chat-cards'

<GitHubActivityCard
  item={githubPullRequestItem}
  variant="compact"           // or "row"
  anchorProps={makeAnchorProps(githubPullRequestItem.url ?? '#')}
/>
```

## Notes

- The component is **pure presentation** — callers are responsible for passing resolved `anchorProps`
- `owner/repo` is derived from the item URL when `item.repo` is omitted
- Long commit SHAs are automatically shortened
- PR review titles containing `[review:STATE]` markers drive the state badge color
- Stories are scoped under `Chat/EntityCards/GitHubActivityCard` in the Storybook sidebar
