Storybook stories file for the `InviteLinkInvalidModal` component, rendering the UI state displayed when an invitation link is expired or invalid.

## Key Components

- **`meta`** — Storybook metadata configuring the story under the `Auth/Invite Link Invalid` title with fullscreen layout and autodocs enabled
- **`Default`** — Single story rendering `InviteLinkInvalidModal` with a no-op `onBackToLogin` callback

## Usage Example

```typescript
// Render the modal in isolation with a real navigation handler
import { InviteLinkInvalidModal } from '../../components/features/auth'

<InviteLinkInvalidModal onBackToLogin={() => router.push('/login')} />
```

## Notes

- Both the close (`X`) button and the primary action button invoke `onBackToLogin`, redirecting users back to the login screen
