Unified content-href authority for all embeddable surfaces: resolves content links consistently across page views and chat surfaces through one seam, `ChatRuntime.composeContentUrl`.

## Key Components

### Types

- **`ComposeContentUrlInput`** — Unified input for both page views (slug-based) and chat rows (ID + `externalUrl`, the server's address).
- **`EmbedderContentRoutes`** — The pages a host serves the hub's content on; each one it has is named.
- **`ComposeContentUrl`** — The seam function signature on `ChatRuntime`; always returns `{ href, targetPlatform }`, never null.

### Functions

- **`makeEmbedderComposeContentUrl({ contentOrigin, routes })`** — THE composer of a host that embeds the hub's content. A record the host has a page for opens there (a relative route); every other record opens the address the server answers. A record with no address opens the hub (`contentOrigin`), never a guessed path.
- **`buildDefaultHref(basePath, slug)`** — Fallback href when no `composeContentUrl` is wired (single-platform embedders).
- **`resolveContentHref(composeContentUrl, args)`** — Helper used by catalog/detail views: delegates to `composeContentUrl` when wired, otherwise calls `buildDefaultHref`.

## Usage Example

```typescript
import { makeEmbedderComposeContentUrl, resolveContentHref } from './content-href'

const composeContentUrl = makeEmbedderComposeContentUrl({
  contentOrigin: 'https://www.flamingo.run',
  routes: { release: slug => `/releases/${slug}`, knowledgeBase: '/docs' },
})

// Chat row: id as identifier, slug read off the server's address
composeContentUrl({ type: 'product_release', identifier: 'abc123', externalUrl: 'https://www.flamingo.run/releases/v2' })
// → { href: '/releases/v2', targetPlatform: null }

// A record the host has no page for: the server's address
composeContentUrl({ type: 'blog_post', identifier: '1108', externalUrl: 'https://www.flamingo.run/blog/my-post' })
// → { href: 'https://www.flamingo.run/blog/my-post', targetPlatform: null }

// Catalog/detail view helper
resolveContentHref(composeContentUrl, { type: 'product_release', slug: 'v2', basePath: '/releases' })
// → { href: '/releases/v2', targetPlatform: null }
```
