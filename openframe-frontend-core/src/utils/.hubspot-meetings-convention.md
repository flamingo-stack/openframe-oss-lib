The single EXECUTABLE home of the meeting-link naming convention (`call-<purpose>[--<descriptor>]` on the LAST slug segment). Server-safe, React-free, zero API knowledge. Team-process documentation (the convention tables) lives in [`docs/EMBEDDING_HUBSPOT_MEETINGS.md`](../../docs/EMBEDDING_HUBSPOT_MEETINGS.md) — do not restate tables here.

## Exports
| Export | Description |
|---|---|
| `SCHEDULING_SLUG_MARKER` | `'call-'` opt-in marker |
| `SCHEDULING_SLUG_SHAPE` / `isValidSchedulingSlug()` | Full-slug shape (N kebab segments) |
| `parseSchedulingSlug()` | → `{ purpose, descriptor } \| null`; normalizes trim+lowercase ONCE (authoritative surface) |
| `isSchedulingNearMiss()` | `call-`-prefixed but unparseable — log these at ingest |
| `schedulingPurposeLabel()` | Kebab token → "Title Case" (wraps `titleCaseFromSlug`) |
| `parseSchedulingLinkName()` | `"Title \| Description"` name split |
| `MAX_MONTH_OFFSET` | Availability paging bound (widget nav, route 400, DAL clamp) |
