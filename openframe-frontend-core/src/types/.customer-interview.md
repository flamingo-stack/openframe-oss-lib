Customer interview domain types defining the full data model for video-based customer testimonial interviews, including AI processing pipelines, video content management, and publishing workflows.

## Key Components

### Interfaces

- **`CustomerInterview`** — Core entity with fields for video content, AI processing status/results, SEO metadata, speaker identification, and relational joins to users, MSPs, platforms, and case studies
- **`CreateCustomerInterviewData`** — Input shape for creating new interviews; requires `title`, `slug`, `status`, `author_id`, and `platforms`
- **`UpdateCustomerInterviewData`** — Partial of `CreateCustomerInterviewData` for patch operations
- **`CustomerInterviewFilters`** — Query filter parameters including platform, industry, company size, search, status, and pagination
- **`CustomerInterviewListResponse`** — Paginated list wrapper with `data` array and `count`

### Re-exports

Re-exports `VideoTeaser`, `Speaker`, `VideoClip`, `TranscriptWord`, `SpeakerMapping`, and `ExcludedRange` from `./video-processing` for backwards compatibility.

### Status Enums

- **Publishing:** `'draft' | 'completed'`
- **AI pipeline stages** (`ai_transcript_status`, `ai_summary_status`, `ai_clips_status`): `'pending' | 'processing' | 'completed' | 'failed'`
- **Highlight video source:** `'manual' | 'ai_generated'`

## Usage Example

```typescript
import type {
  CustomerInterview,
  CreateCustomerInterviewData,
  CustomerInterviewFilters,
} from './customer-interview'

// Create a new interview record
const payload: CreateCustomerInterviewData = {
  title: 'How Acme IT Reduced Ticket Volume by 40%',
  slug: 'acme-it-ticket-reduction',
  status: 'draft',
  author_id: 'usr_abc123',
  platforms: ['plt_uuid_1', 'plt_uuid_2'],
  main_video_url: 'https://cdn.example.com/interviews/acme.mp4',
  config: {
    highlight_target_duration_seconds: 120,
  },
}

// Filter published interviews by platform
const filters: CustomerInterviewFilters = {
  platform: 'plt_uuid_1',
  status: 'completed',
  limit: 10,
  offset: 0,
}

// Access AI pipeline status on a fetched record
function isReadyToPublish(interview: CustomerInterview): boolean {
  return (
    interview.ai_transcript_status === 'completed' &&
    interview.ai_summary_status === 'completed' &&
    interview.status === 'draft'
  )
}
```

## Notes

- External transcript/video APIs are tracked via `assemblyai_transcript_id` and `twelvelabs_video_id`
- `incentive_excluded_ranges` and `speaker_mapping` are computed during transcription and stored as JSONB
- `custom_instructions` steers AI prompts for both case study generation and video processing
