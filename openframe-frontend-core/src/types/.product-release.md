Defines TypeScript types, interfaces, and constants for the product release domain, covering the full lifecycle of a release record from creation to publishing with support for changelogs, media, external integrations, and AI-generated content.

## Key Components

### Core Interfaces

| Interface | Purpose |
|---|---|
| `ProductRelease` | Primary record shape with all release fields including changelog arrays, video processing, SEO, HubSpot email, and populated relations |
| `ChangelogEntry` | Single changelog item with optional per-entry visibility (`public` \| `internal`) for compatibility with investor-update flows |
| `ReleaseMedia` | Attached media asset (image, video, screenshot, demo) with ordering metadata |
| `CreateProductReleaseData` | Input shape for creating a release; platform IDs and tag IDs passed as flat arrays |
| `UpdateProductReleaseData` | Partial of `CreateProductReleaseData` for PATCH operations |
| `ProductReleaseFilters` | Query filter bag used by list endpoints (platform, tags, version, type, status, pagination) |
| `ProductReleaseListResponse` | Paginated list envelope: `data` array + total `count` |

### External Link Interfaces

- **`ProductReleaseGitHubLink`** — full GitHub release URL with ordering
- **`KnowledgeBaseLink`** — relative KB article path
- **`ClickUpRoadmapTask`** / **`ClickUpDeliveryTask`** — ClickUp task IDs for roadmap and delivery lists
- **`GitHubRelease`** — GitHub API release shape used in the creation wizard

### Constants

| Export | Purpose |
|---|---|
| `releaseTypeOptions` | Dropdown options for `major`, `minor`, `patch`, `beta`, `alpha` with colors |
| `releaseStatusOptions` | Dropdown options for `alpha`, `beta`, `stable`, `deprecated` with colors |
| `changelogLabels` | Human-readable labels for the four changelog JSONB categories |
| `SEMVER_REGEX` | Validates semantic version strings including pre-release and build metadata |

## Usage Example

```typescript
import type {
  ProductRelease,
  CreateProductReleaseData,
  ChangelogEntry,
  ProductReleaseFilters,
} from './product-release'
import { releaseTypeOptions, SEMVER_REGEX } from './product-release'

// Validate a version string before submitting
const version = '2.1.0-beta.1'
if (!SEMVER_REGEX.test(version)) {
  throw new Error(`Invalid semver: ${version}`)
}

// Build a changelog entry with visibility control
const entry: ChangelogEntry = {
  title: 'New AI-powered ticket routing',
  description: 'Mingo AI now auto-assigns tickets based on technician skill sets.',
  visibility: 'public',
}

// Compose a create payload
const payload: CreateProductReleaseData = {
  title: 'OpenFrame 2.1.0 Beta',
  slug: 'openframe-2-1-0-beta',
  version,
  release_type: 'beta',
  release_status: 'beta',
  release_date: '2025-08-01',
  features_added: [entry],
  bugs_fixed: [],
  improvements: [],
  breaking_changes: [],
  status: 'draft',
  author_id: 'usr_abc123',
  platforms: ['platform-uuid-1'],
  tags: [4, 12],
}

// Filter releases for the public changelog page
const filters: ProductReleaseFilters = {
  release_status: ['stable'],
  release_type: ['major', 'minor'],
  has_breaking_changes: false,
  limit: 20,
  offset: 0,
}

// Use dropdown metadata for a release type selector
const options = releaseTypeOptions.map(({ value, label, color }) => ({
  id: value,
  display: label,
  badge: color,
}))
```
