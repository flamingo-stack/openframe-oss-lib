Defines shared TypeScript interfaces for all navigation-related components in the OpenFrame UI library, providing a consistent contract for headers, sidebars, and mobile navigation panels.

## Key Components

| Interface | Purpose |
|---|---|
| `NavigationItem` | Base interface for any nav item — supports links, dropdowns, badges, icons, and custom elements |
| `HeaderConfig` | Full configuration for the top header bar, including logo, nav items, actions, mobile menu, and Mingo AI integration |
| `MobileNavConfig` | Sectioned navigation panel for mobile viewports |
| `SlidingSidebarConfig` | Slide-in sidebar overlay with left/right positioning |
| `NavigationSidebarConfig` | Collapsible vertical sidebar with minimized state support |
| `NavigationSidebarItem` | Sidebar-specific nav item with unread counts and primary/secondary section grouping |
| `UnifiedSidebarUser` | User identity data (name, email, avatar, role) surfaced in sidebar footers |

## Usage Example

```typescript
import {
  NavigationItem,
  HeaderConfig,
  NavigationSidebarItem,
} from '@openframe/oss-lib'

const navItems: NavigationItem[] = [
  {
    id: 'dashboard',
    label: 'Dashboard',
    href: '/dashboard',
    type: 'single',
    isActive: true,
  },
  {
    id: 'tools',
    label: 'Tools',
    type: 'dropdown',
    children: [
      { id: 'tickets', label: 'Tickets', href: '/tickets' },
      { id: 'assets', label: 'Assets', href: '/assets' },
    ],
  },
]

const headerConfig: HeaderConfig = {
  logo: { element: <MyLogo />, href: '/' },
  navigation: { items: navItems, position: 'center' },
  mingo: { enabled: true, label: 'Mingo AI' },
  autoHide: true,
  backgroundColor: 'bg-ods-card',
}

const sidebarItem: NavigationSidebarItem = {
  id: 'inbox',
  label: 'Inbox',
  icon: <InboxIcon />,
  path: '/inbox',
  unreadCount: 5,
  section: 'primary',
}
```
