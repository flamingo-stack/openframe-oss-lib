Defines the centralized type system for all MSP tool integrations in the OpenFrame platform, serving as the single source of truth for tool type identifiers and display labels.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `ToolTypeValues` | `const object` | Enum-like constant map of all supported tool type string literals |
| `ToolType` | `type` | Union type derived from `ToolTypeValues` values |
| `toolLabels` | `Record<ToolType, string>` | Maps each `ToolType` to its human-readable display label |

### Supported Tool Types

| Key | Value | Label |
|-----|-------|-------|
| `FLEET_MDM` | `'FLEET_MDM'` | Fleet |
| `MESHCENTRAL` | `'MESHCENTRAL'` | MeshCentral |
| `AUTHENTIK` | `'AUTHENTIK'` | Authentik |
| `OPENFRAME` | `'OPENFRAME'` | OpenFrame |
| `OPENFRAME_CHAT` | `'OPENFRAME_CHAT'` | OpenFrame Chat |
| `OPENFRAME_CLIENT` | `'OPENFRAME_CLIENT'` | OpenFrame Client |
| `OPENFRAME_RMM` | `'OPENFRAME_RMM'` | RMM |
| `OSQUERY` | `'OSQUERY'` | Osquery |
| `SYSTEM` | `'SYSTEM'` | System |

## Usage Example

```typescript
import { ToolType, ToolTypeValues, toolLabels } from './tool.types'

// Type-safe tool type reference
const currentTool: ToolType = ToolTypeValues.FLEET_MDM

// Resolve display label for UI rendering (e.g. ToolBadge, ToolIcon)
const label = toolLabels[currentTool] // → 'Fleet'

// Narrow by tool type in a switch
function handleTool(tool: ToolType) {
  switch (tool) {
    case ToolTypeValues.MESHCENTRAL:
      // handle MeshCentral
      break
    case ToolTypeValues.OPENFRAME_RMM:
      // handle RMM
      break
  }
}
```

## Notes

- Prefer `ToolTypeValues.X` over raw string literals to ensure compile-time safety.
- `ToolType` is a strict union — TypeScript will error on unrecognized values.
- Consumed by `ToolBadge`, `ToolIcon`, and any component requiring tool metadata.
