Defines the centralized source of truth for operating system type metadata across the platform, normalizing OS values from Fleet MDM, OpenFrame RMM, and GraphQL sources into a unified structure.

## Key Components

| Export | Type | Description |
|---|---|---|
| `OSTypeValues` | `const` | Enum-like object with `WINDOWS`, `MACOS`, `LINUX` string constants |
| `OSType` | `type` | Union type derived from `OSTypeValues` keys |
| `OSTypeDefinition` | `interface` | Full OS metadata shape including id, label, icon, platformId, and aliases |
| `OS_TYPES` | `OSTypeDefinition[]` | Master array of all OS definitions — primary source of truth |
| `osLabels` | `Record<OSType, string>` | Simple lookup map from OS type to display label |

## Usage Example

```typescript
import { OS_TYPES, OSTypeValues, osLabels } from './os.types'

// Render OS list with icons
OS_TYPES.forEach(({ label, icon: Icon, platformId }) => {
  console.log(label, platformId) // 'macOS', 'darwin'
  // <Icon /> → renders Apple/Windows/Linux logo
})

// Normalize an incoming OS string via aliases
const raw = 'darwin'
const matched = OS_TYPES.find(os =>
  os.aliases.includes(raw.toLowerCase())
)
console.log(matched?.id) // 'MACOS'

// Display label lookup
console.log(osLabels[OSTypeValues.LINUX]) // 'Linux'
```

## Alias Ordering

Aliases within each OS entry are ordered from most-specific to least-specific (e.g., `'darwin'` before `'mac'`, `'win32'` before `'win'`) to prevent false-positive matches during normalization lookups.
