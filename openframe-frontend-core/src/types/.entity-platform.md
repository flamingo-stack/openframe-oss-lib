Defines the shared `EntityPlatformAssoc` interface representing a hydrated `entity_platforms` junction row, used by all per-entity platform association types to ensure a consistent shape across the codebase.

## Key Components

### `EntityPlatformAssoc`
A single interface describing the shape that `attachPlatformsToRows` places on every `<entity>_platforms[]` array (e.g. `case_study_platforms`, `blog_post_platforms`, `customer_interview_platforms`).

| Field | Type | Description |
|---|---|---|
| `platform_id` | `string` | Required platform identifier |
| `is_featured` | `boolean` | Whether the platform is featured |
| `featured_order` | `number \| null` | Optional ordering for featured platforms |
| `name` | `string` | Platform name, spread from the platform record; used by `composeContentUrlFromPlatforms` |
| `display_name` | `string` | Optional display-friendly name |
| `platform_name` | `string` | Alias added by some admin fetches (e.g. `getCaseStudyForAdmin`) |
| `id` | `string` | Optional platform record ID |
| `created_at` | `string` | Optional creation timestamp |

## Usage Example

```typescript
import type { EntityPlatformAssoc } from './entity-platform'

// Typed per-entity association reusing the shared interface
type CaseStudyPlatform = EntityPlatformAssoc

function getFeaturedPlatforms(platforms: EntityPlatformAssoc[]): EntityPlatformAssoc[] {
  return platforms
    .filter(p => p.is_featured)
    .sort((a, b) => (a.featured_order ?? 0) - (b.featured_order ?? 0))
}
```

## Notes

- All per-entity platform types reference this single interface, preventing shape drift across entity types.
- Fields spread from the platform record (via `PLATFORM_EMBED`) allow URL composition without casting.
