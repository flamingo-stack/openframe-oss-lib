Type definitions for the blog domain, covering database models, API contracts, form data, query options, SEO analysis, and UI filtering structures for blog posts.

## Key Components

### Core Types
- **`BlogStatus`** — Union literal type for post lifecycle states: `'draft'`, `'ai_drafted'`, `'published'`, `'ai_published'`, `'scheduled'`, `'archived'`
- **`Platform`** — String alias for platform identifiers (fetched dynamically from the database)

### Database Models
- **`BlogPost`** — Full post shape including raw API response fields (`profiles`, `blog_post_platforms`, `blog_post_tags`) and normalized client-side relationships (`author`, `categories`, `tags`)
- **`BlogAuthor`** — Author shape for blog posts; distinct from shared `EntityAuthor`; includes optional `slug` and `linkedinUrl` for SEO/schema usage
- **`BlogPostPlatform`** — Aliased to `EntityPlatformAssoc` from `entity-platform.ts`; replaces the legacy flat junction shape
- **`TagAssoc`** — Flat unified tag association shape; replaces the legacy nested `{ blog_tags: {...} }` pattern
- **`BlogMediaAsset`**, **`BlogCategory`**, **`BlogTag`** — Supporting entity models

### Form & Mutation Types
- **`CreateBlogPostData`** — Required fields for creating a post, including `platforms`, `categories`, and `tags` arrays
- **`UpdateBlogPostData`** — Partial version of create data for PATCH-style updates

### Query & Stats
- **`GetBlogPostsOptions`** — Filtering, pagination, and sorting parameters for list queries
- **`BlogPostStats`** — Dashboard aggregate counts and `posts_by_platform` breakdown
- **`BlogPagination`** / **`BlogPostSummary`** — Public-facing list and summary shapes

### SEO
- **`SEOAnalysisResult`** — Scored analysis output with `suggestions`, `errors`, and `warnings`
- **`SEOAnalysisOptions`** — Optional keywords and flags for analysis configuration
- **`BlogSEOAnalytics`** — Database row shape for persisted SEO analysis results

### UI / Filtering
- **`BlogFilterSidebarProps`**, **`BlogFilters`**, **`BlogFilterOption`** — Props and data shapes for the filter sidebar component
- **`BlogCategoryForSidebar`** — Adapter type bridging `BlogCategory` to the `CategorySidebar` interface

## Usage Example

```typescript
import type {
  BlogPost,
  CreateBlogPostData,
  GetBlogPostsOptions,
  BlogStatus,
} from './blog';

// Querying posts with filters
const options: GetBlogPostsOptions = {
  platform: 'openframe',
  status: 'published',
  page: 1,
  pageSize: 10,
  sortBy: 'published_at',
  sortOrder: 'desc',
};

// Creating a new post
const newPost: CreateBlogPostData = {
  title: 'Getting Started with OpenFrame',
  slug: 'getting-started-openframe',
  content: '...',
  author_id: 'user-uuid',
  status: 'draft' as BlogStatus,
  platforms: ['platform-uuid-1'],
  categories: [3],
  tags: [7, 12],
};
```
