Auto-generated Supabase database type definitions for the OpenFrame OSS library, providing strongly-typed interfaces for all public schema tables including announcements, Slack data, podcast episodes, webinars, and Luma events.

## Key Components

### `Json` Type

A recursive union type representing any valid JSON value — primitives, objects, arrays, or `null`.

### `Database` Type

The root type describing the full Supabase public schema. Each table is represented with three operation shapes:

| Shape | Purpose |
|-------|---------|
| `Row` | Full record returned from `SELECT` queries |
| `Insert` | Required + optional fields for `INSERT` |
| `Update` | All fields optional for `PATCH`/`UPDATE` |

### Tables

| Table | Description |
|-------|-------------|
| `announcement_assets` | File attachments linked to announcements |
| `announcements` | Platform announcements with icons and styling |
| `slack_channels` | Synced Slack workspace channels |
| `slack_messages` | Slack messages with threading and metadata |
| `slack_users` | Slack workspace member profiles |
| `podcast_episodes` | Podbean-synced podcast episode records |
| `webinars` | Livestorm-synced webinar events |
| `luma_events` | Luma-synced community events |

### Relationships

- `announcement_assets.announcement_id` → `announcements.id`
- `slack_messages.channel_id` → `slack_channels.channel_id`
- `slack_messages.user_id` → `slack_users.user_id`

## Usage Example

Pass the `Database` type to the Supabase client for full end-to-end type safety:

```typescript
import { createClient } from '@supabase/supabase-js'
import type { Database } from './supabase'

const supabase = createClient<Database>(
  process.env.SUPABASE_URL!,
  process.env.SUPABASE_ANON_KEY!
)

// Fully typed — Row shape inferred automatically
const { data: announcements } = await supabase
  .from('announcements')
  .select('id, title, description, is_active')
  .eq('is_active', true)

// Type-safe insert — Insert shape enforced
await supabase.from('slack_users').insert({
  user_id: 'U12345',
  username: 'jane.doe',
  display_name: 'Jane Doe',
})
```
