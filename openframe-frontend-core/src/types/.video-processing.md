Shared TypeScript type definitions for video processing functionality, providing the canonical data shapes used across video-enabled entities such as customer interviews, product releases, and marketing campaigns.

## Key Components

| Export | Kind | Description |
|---|---|---|
| `VideoTeaser` | Interface | Canonical persistence shape for short video clips/bites stored in `video_bites`/`teasers` JSONB columns |
| `Speaker` | Interface | Speaker identification metadata for transcription workflows |
| `VideoClip` | Interface | AI-identified video segment from Twelve Labs analysis |
| `TranscriptWord` | Interface | Word-level transcript data with millisecond-precision timing |
| `SpeakerMapping` | Interface | Maps AssemblyAI speaker labels (`"A"`, `"B"`) to named participant info |
| `ExcludedRange` | Interface | Time range exclusions (e.g., incentive mentions) in seconds |
| `VideoProcessingFields` | Interface | Base set of video fields shared across all video-capable entities |
| `VideoProcessingEntityType` | Type Union | Discriminator for agent routing across all supported entity types |

## Usage Example

```typescript
import type {
  VideoTeaser,
  VideoProcessingFields,
  SpeakerMapping,
  VideoProcessingEntityType,
} from './video-processing'

// Composing a video-enabled entity record
const speakerMap: SpeakerMapping = {
  A: { name: 'Jane Doe', role: 'interviewer' },
  B: { name: 'John Smith', role: 'interviewee', userId: 'usr_abc123' },
}

const fields: VideoProcessingFields = {
  main_video_url: 'https://stream.mux.com/abc123.m3u8',
  transcript: 'Full transcript text...',
  speaker_mapping: speakerMap,
  ai_confidence_transcript: 0.94,
  ai_confidence_summary: 0.87,
}

const entityType: VideoProcessingEntityType = 'customer_interview'

// Constructing a teaser bite (canonical shape)
const teaser: VideoTeaser = {
  id: 'a1b2c3d4',
  url: 'https://stream.mux.com/bite_xyz.m3u8',
  title: 'Key product insight moment',
  start_time_ms: 134000,
  end_time_ms: 162000,
  published: true,
  featured: false,
  source: 'ai_generated',
  confidence: 87,
}
```

## Notes

- `VideoTeaser` is the **true superset** for persistence — downstream display types (e.g., `VideoTeaserWithRatio`) extend it rather than diverging from it.
- `VideoClip` intentionally remains a separate shape from `VideoTeaser`; it represents AI extraction candidates, not persisted bites.
- `id` on `VideoTeaser` is a stable 8-char lowercase-hex identity key used by the Mux transcode pipeline — never derived from `url`.
