Defines TypeScript types, interfaces, and constants for the OpenFrame announcement system, covering database models, API request/response shapes, form data, component props, and utility types.

## Key Components

### Core Interfaces

| Interface | Purpose |
|---|---|
| `Announcement` | Full database model including CTA fields, icon props, and hydrated platform associations |
| `AnnouncementAsset` | File attachment metadata linked to an announcement |
| `AnnouncementResponse` | Wire shape for `GET /api/announcements/active` — nullable envelope |
| `AnnouncementListResponse` | Paginated list response with optional platform/active filters |

### CRUD Data Shapes

| Interface | Purpose |
|---|---|
| `CreateAnnouncementData` | Payload for creating a new announcement |
| `UpdateAnnouncementData` | Partial payload for updating an existing announcement |
| `AnnouncementFormData` | Form state, including `icon_props` and `cta_icon_props` as JSON strings |
| `GetAnnouncementsOptions` | Query parameters for listing announcements |

### Component Props

| Interface | Purpose |
|---|---|
| `AnnouncementBarProps` | Controls SSR seeding, preview mode, dismissibility, and CSS class |
| `AnnouncementFormProps` | Admin create/edit form callbacks and available icon list |
| `AnnouncementListProps` | List view with edit, delete, and toggle-active handlers |

### Constants

- **`ANNOUNCEMENT_CTA_DEFAULTS`** — Default CTA button colors (`#1A1A1A` background, `#FAFAFA` text), shared between the DAL and admin form.
- **`AVAILABLE_SVG_ICONS`** — Registry of supported icon names (OpenFrame/platform logos + Lucide icons); `component` is resolved at runtime.

## Usage Example

```typescript
import type {
  Announcement,
  CreateAnnouncementData,
  AnnouncementBarProps,
  AnnouncementResponse,
} from './announcement';
import { ANNOUNCEMENT_CTA_DEFAULTS } from './announcement';

// Creating an announcement payload
const newAnnouncement: CreateAnnouncementData = {
  title: 'New Feature Released',
  description: 'Check out the latest OpenFrame update.',
  background_color: '#1A1A1A',
  icon_name: 'rocket',
  platforms: ['platform-uuid-1', 'platform-uuid-2'],
  is_active: true,
  cta_enabled: true,
  cta_text: 'Learn More',
  cta_url: 'https://openframe.ai/changelog',
  cta_target: '_blank',
  cta_button_background_color: ANNOUNCEMENT_CTA_DEFAULTS.background,
  cta_button_text_color: ANNOUNCEMENT_CTA_DEFAULTS.text,
  created_by: 'user-uuid',
};

// Consuming the active announcement API response
const response: AnnouncementResponse = await fetch('/api/announcements/active')
  .then(r => r.json());

if (response.announcement) {
  console.log(response.announcement.title);
}

// AnnouncementBar in SSR mode — null signals "nothing to show"
const barProps: AnnouncementBarProps = {
  initialAnnouncement: response.announcement,
  dismissible: true,
  previewMode: false,
};
```
