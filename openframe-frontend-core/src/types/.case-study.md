Defines TypeScript interfaces for case study content entities in the OpenFrame platform, covering the full lifecycle from creation to publishing with video processing, SEO, and relational data support.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `CaseStudy` | `interface` | Full case study record with all fields, relations, and video pipeline data |
| `CreateCaseStudyData` | `interface` | Payload shape for creating a new case study |
| `UpdateCaseStudyData` | `type` | Partial version of `CreateCaseStudyData` for PATCH operations |
| `CaseStudyFilters` | `interface` | Query filter options for listing/searching case studies |
| `CaseStudyListResponse` | `interface` | Paginated response wrapper for case study arrays |

## Field Groups (CaseStudy)

- **Story structure** — `challenge`, `solution`, `results`
- **Video** — `testimonial_video_url` (YouTube preferred), `main_video_url` (uploaded fallback), `video_bites`, `main_video_thumbnail`
- **Video processing pipeline** — `transcript`, `srt_content`, `video_summary`, `highlight_video_url`, `config` (full parity with `customer_interviews`)
- **SEO** — `seo_title`, `seo_description`, `seo_keywords`, `og_image_url`
- **Publishing** — `status` (`draft` | `ai_drafted` | `published` | `scheduled` | `archived`), `published_at`
- **Relations** — `msp`, `user`, `platforms`, `tags`, `customer_interview`

## Usage Example

```typescript
import type {
  CaseStudy,
  CreateCaseStudyData,
  CaseStudyFilters,
  CaseStudyListResponse
} from './case-study'

// Create a new case study
const payload: CreateCaseStudyData = {
  title: 'How Acme MSP Cut Ticket Resolution by 40%',
  slug: 'acme-msp-ticket-resolution',
  status: 'draft',
  author_id: 'uuid-author',
  platforms: ['uuid-platform-1'],
  tags: [12, 34],
  challenge: 'High volume of repetitive L1 tickets...',
  solution: 'Deployed Mingo AI triage automation...',
  results: '40% reduction in mean time to resolve...',
  testimonial_video_url: 'https://www.youtube.com/watch?v=example',
}

// Filter for published case studies by industry
const filters: CaseStudyFilters = {
  status: 'published',
  industry: 'healthcare',
  limit: 10,
  offset: 0,
}

// Typed response
const response: CaseStudyListResponse = await fetchCaseStudies(filters)
response.data.forEach((cs: CaseStudy) => console.log(cs.title))
```

## Notes

- `video_source_type` is **deprecated**; prefer URL-based detection via `testimonial_video_url` vs `main_video_url`
- `transcript_words_data` is intentionally omitted — server-only field
- `main_video_thumbnail` is optional for backward compatibility with existing consumers
- MSP company/industry/testimonial data is accessed through the `msp` relation, resolved via `user.msp_id`
