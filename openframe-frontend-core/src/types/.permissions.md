Defines TypeScript types and interfaces for the permission policy configuration system used in OpenFrame's AI tool authorization layer.

## Key Components

| Export | Kind | Description |
|--------|------|-------------|
| `ApprovalLevel` | Type | Union of four authorization levels: `'ALLOW'`, `'ASK_USER'`, `'ASK_TECHNICIAN'`, `'DENY'` |
| `PermissionPolicy` | Interface | A single policy rule binding a command pattern and tool to an approval level |
| `PermissionCategory` | Interface | Logical grouping of related `PermissionPolicy` entries, optionally with a React icon node |
| `PolicyConfigurationPanelProps` | Interface | Props contract for the panel component that renders and edits permission categories |

## Usage Example

```typescript
import {
  ApprovalLevel,
  PermissionCategory,
  PolicyConfigurationPanelProps,
} from "./permissions";

const category: PermissionCategory = {
  id: "file-ops",
  name: "File Operations",
  policies: [
    {
      id: "policy-delete",
      name: "Delete Files",
      naturalKey: "file.delete",
      commandPattern: "rm *",
      toolName: "shell",
      approvalLevel: "ASK_TECHNICIAN",
    },
    {
      id: "policy-read",
      name: "Read Files",
      naturalKey: "file.read",
      commandPattern: "cat *",
      toolName: "shell",
      approvalLevel: "ALLOW",
    },
  ],
};

const panelProps: PolicyConfigurationPanelProps = {
  categories: [category],
  editMode: true,
  onPolicyPermissionChange: (categoryId, policyId, level: ApprovalLevel) => {
    console.log(`Policy ${policyId} in ${categoryId} → ${level}`);
  },
  onCategoryPermissionChange: (categoryId, level: ApprovalLevel) => {
    console.log(`All policies in ${categoryId} → ${level}`);
  },
};
```

## Notes

- `PermissionCategory` is **pure data** — expansion and bulk-selection UI state belongs to the consuming panel component.
- The optional `icon` field accepts a `React.ReactNode`; the panel falls back to a shield icon when omitted.
- `PermissionPolicy.toolName` is typed as `ToolType` (imported from [`tool.types`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/tool.types.ts)), ensuring only known tool identifiers are accepted.
