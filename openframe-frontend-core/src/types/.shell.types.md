Centralized type definitions and metadata registry for all supported shell/script types used across the OpenFrame platform.

## Key Components

| Export | Kind | Description |
|---|---|---|
| `ShellTypeValues` | `const` | Enum-like object of all supported shell type identifiers |
| `ShellType` | `type` | Union type derived from `ShellTypeValues` values |
| `ShellTypeDefinition` | `interface` | Full metadata shape for a shell type (id, label, value, icon) |
| `SHELL_TYPES` | `ShellTypeDefinition[]` | **Single source of truth** — ordered list of all shell types with icons and labels |
| `shellLabels` | `Record<ShellType, string>` | Convenience map from shell type key to display label |

**Supported shells:** PowerShell, Batch (CMD), Bash, Python, Nu (Nushell), Deno, Shell

## Usage Example

```typescript
import {
  SHELL_TYPES,
  ShellTypeValues,
  shellLabels,
  type ShellType,
  type ShellTypeDefinition
} from '@/types/shell.types'

// Render a dropdown of all supported shells
const options = SHELL_TYPES.map(({ id, label, icon: Icon }) => (
  <option key={id} value={id}>
    <Icon size={16} /> {label}
  </option>
))

// Resolve a display label from a stored shell type
const stored: ShellType = ShellTypeValues.POWERSHELL
console.log(shellLabels[stored]) // → "PowerShell"

// Type-safe shell type check
function runScript(shell: ShellType, script: string) {
  if (shell === ShellTypeValues.PYTHON) {
    // handle Python-specific execution
  }
}

// Look up a full definition by id
const def: ShellTypeDefinition | undefined = SHELL_TYPES.find(
  (s) => s.id === ShellTypeValues.BASH
)
```

## Notes

- Always import from this file rather than defining local shell constants — `SHELL_TYPES` is the designated single source of truth across the platform.
- The `value` field (e.g. `'powershell'`, `'bash'`) is intended for RMM API payloads; `id` is for internal logic; `label` is for UI display.
- Icons are React components typed via `IconProps` from `./icons`.
