Defines the complete TypeScript type system for the Marketing AI module, covering campaigns, AI-generated content and media, social accounts, scheduled posts, approvals, and usage tracking.

## Key Components

### Campaign Types
- **`MarketingCampaign`** — Core campaign entity with content seed fields (`content_source_type`, `content_source_id`, `custom_instructions`)
- **`CreateCampaignInput`** / **`UpdateCampaignInput`** — Mutation payloads for campaign management
- **`CampaignWithDetails`** — Aggregate type combining campaign, content, and media
- **`CampaignStats`** — Counters for draft, active, and completed campaigns

### AI Content & Media Types
- **`AIContent`** — Generated text assets (`blog_post`, `social_post`, `ad_copy`, `email`) with approval workflow and URL injection fields
- **`AIMedia`** — Generated image/video assets with provider tracking (`dalle-3`, `flux-pro`, `kling-v2.5`, etc.) and Figma export support
- **`MediaDimensions`** — Width, height, and aspect ratio descriptor
- **`ContentStatus`** / **`MediaStatus`** — Lifecycle enums from `draft` through `published`

### Social & Scheduling Types
- **`SocialAccount`** — OAuth-connected social channel (`slack`, `linkedin`, `facebook`, `instagram`, `twitter`, `youtube`)
- **`ScheduledPost`** — Post scheduling with retry tracking and external post URL reference
- **`SocialChannel`** / **`SocialAccountType`** — Channel and account classification enums

### Approval & Usage Tracking
- **`ContentApproval`** — Review workflow for content and media items
- **`AIUsage`** / **`TrackAIUsageInput`** — Token and cost tracking per service (`anthropic`, `openai`, `replicate`, `figma`, `google`)
- **`AIUsageSummary`** — Aggregated cost and token totals broken down by service

### Content Source Types
- **`ContentSourceType`** — Union type covering 13 content origin strategies (`product_release`, `blog_post_seed`, `event`, `podcast`, `faq`, etc.)

## Usage Example

```typescript
import type {
  CreateCampaignInput,
  AIContent,
  ContentSourceType,
  MediaProvider,
} from './marketing';

const newCampaign: CreateCampaignInput = {
  name: 'Q3 Product Launch',
  content_source_type: 'product_release',
  content_source_id: 42,
  custom_instructions: 'Emphasize enterprise features and security compliance.',
  start_date: '2025-08-01',
};

const generatedPost: Partial<AIContent> = {
  content_type: 'social_post',
  status: 'draft',
  social_account_id: 7,
  url_injection_preference: 'as_comment',
  selected_for_publish: false,
};

const provider: MediaProvider = 'flux-pro';
```
