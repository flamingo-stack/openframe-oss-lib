The rows of the marketing tables as the database holds them, column for column: `marketing_campaigns`, `ai_content` and `ai_media`, and the vocabularies their check constraints allow. A type here names no column its table does not have.

## Key Components

### Campaign Types
- **`MarketingCampaign`** — A `marketing_campaigns` row: status, what the campaign is about (`content_source`), the accounts it writes for (`selected_accounts`), the per-agent settings and feedback, `custom_instructions`
- **`CampaignStatus`** — `draft`, `active` or `completed`
- **`CampaignContentSource`** — The content a campaign is about: its type, id, link and, for a seed-blog campaign, the blog it writes for

### AI Content & Media Types
- **`AIContent`** — An `ai_content` row: a generated post or article for one distribution channel, with its link placement (`url_injection_preference`) and what publishing it recorded
- **`AIMedia`** — An `ai_media` row: a generated or uploaded image or video for one distribution channel
- **`ContentType`**, **`ContentStatus`**, **`MediaStatus`**, **`MediaProvider`** — The values the tables' check constraints allow
- **`MediaDimensions`** — Width, height and aspect ratio

### Content Source Types
- **`ContentSourceType`** — What a campaign can be about (`product_release`, `blog_post_seed`, `event`, `podcast`, `faq`, etc.)
- **`ContentSourceOption`** — One row of the content source picker
- **`URLInjectionPreference`** — Where a post's link goes

## Usage Example

```typescript
import type { AIContent, MarketingCampaign } from './marketing';

function linkOf(campaign: MarketingCampaign, post: AIContent): string | null {
  return post.url_injection_preference === 'none' ? null : campaign.content_source?.url ?? null;
}
```
