Defines unified platform types used across announcements, blog posts, and platform configuration throughout the Flamingo Stack ecosystem.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `PlatformName` | `type` | Union of all valid platform identifiers (e.g. `'flamingo'`, `'openframe'`, `'openmsp'`) |
| `PlatformRecord` | `interface` | Full database model from the `platforms` table, including chat wiring, activity tracking, and content scoping flags |
| `PlatformConfig` | `interface` | API-facing configuration shape with display metadata (color, icon, label) |
| `PlatformOption` | `interface` | Lightweight `{ value, label }` shape for dropdowns and filter UIs |
| `PlatformFilter` | `type` | Extends `PlatformName` with `'all'` for filter contexts |
| `LegacyPlatform` | `type` | Backward-compatible alias for the original three platforms |
| `PlatformStats` | `interface` | Aggregated content counts per platform for reporting |

## Usage Example

```typescript
import type {
  PlatformName,
  PlatformRecord,
  PlatformFilter,
  PlatformOption,
} from './platform';

// Narrow to a valid platform
const platform: PlatformName = 'openframe';

// Filter UI options
const options: PlatformOption[] = [
  { value: 'all', label: 'All Platforms' },
  { value: 'flamingo', label: 'Flamingo' },
  { value: 'openframe', label: 'OpenFrame' },
];

// Type-safe filter handler
function handleFilter(filter: PlatformFilter) {
  if (filter === 'all') {
    // return all records
  } else {
    // return records for `filter` platform
  }
}

// Check platform content scoping from a DB record
function isUniversalViewer(record: PlatformRecord): boolean {
  return record.serves_all_content;
}
```

> **Note on `PlatformRecord` flags:**
> - `serves_all_content` — when `true`, content DALs return rows for all platforms (read by `getPlatformContentScopeMode`)
> - `tracks_activity` — when `false`, skips activity tracking and HubSpot sync for that platform's principals
> - `chat_enabled` — platform-wide kill switch for the Ask AI / chat surface
