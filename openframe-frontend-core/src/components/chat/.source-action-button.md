Draws a record's "Ask Mingo" or "Display" action as a button beside the record (a card's footer, a row of the sources strip). It never decides the action: `recordDiscussAction` (entity-cards/dispatch.tsx) builds it, the same that builds the record's "⋯" menu row, so the button and the menu always offer the same thing.

## Key Components

- **`CardDiscussAction`**: `{ label, icon, run, disabled? }`, the record's action.
- **`SourceActionDensity`**: `'inline' | 'card' | 'list-row'`, the look.
- **`SourceActionButton`**: `{ action, title, density?, className?, loading? }`. Draws nothing without an action; a held action is drawn inert.
- **`FooterAction`**: the one footer button look (also the card's "Watch video").

## Usage Example

```tsx
import { recordDiscussAction } from './entity-cards/dispatch'
import { useRecordActions } from './record-actions'
import { SourceActionButton } from './source-action-button'

const action = recordDiscussAction(ref, useRecordActions())
<SourceActionButton action={action} title={ref.title} density="card" />
```
