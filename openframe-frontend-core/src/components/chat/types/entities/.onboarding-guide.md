Wire-shape type definitions for the chat onboarding-guide card and `/api/onboarding-guides` API responses, including entity structure, filter parameters, and list/section summary response shapes.

## Key Components

| Export | Kind | Description |
|---|---|---|
| `OnboardingGuide` | `interface` | Full entity row shape with content, video pipeline, SEO, workflow, and audit fields |
| `OnboardingGuideFilters` | `interface` | Query filter parameters for listing/searching guides |
| `OnboardingGuideListResponse` | `interface` | Paginated list response wrapping `OnboardingGuide[]` with a total count |
| `OnboardingGuideSectionSummary` | `interface` | Aggregated section metadata — section name, order, and guide count |

## Usage Example

```typescript
import type {
  OnboardingGuide,
  OnboardingGuideFilters,
  OnboardingGuideListResponse,
  OnboardingGuideSectionSummary,
} from './onboarding-guide';

// Fetch guides with filters
const filters: OnboardingGuideFilters = {
  status: 'published',
  section: 'getting-started',
  platform: 'openframe',
  limit: 10,
  offset: 0,
};

const response: OnboardingGuideListResponse = await fetch(
  `/api/onboarding-guides?${new URLSearchParams(filters as Record<string, string>)}`
).then((r) => r.json());

// Access guide fields
const guide: OnboardingGuide = response.data[0];
const videoUrl = guide.main_video_url ?? guide.youtube_url;
const platforms = guide.onboarding_guide_platforms?.filter((p) => p.is_featured);

// Section summary
const summary: OnboardingGuideSectionSummary = {
  section: guide.section,
  section_order: guide.section_order,
  count: response.count,
};
```

> **Note:** Server-side DAL methods (`createOnboardingGuide`, `updateOnboardingGuide`, `resolvePublicPlatformScope`) remain hub-side. Only the row type and filter/response shapes are exported from this module.
