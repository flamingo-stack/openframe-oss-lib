Defines the core TypeScript types and interfaces for the Unified Program System, which provides a single generic abstraction layer for handling events, podcasts, and webinars across public and admin surfaces.

## Key Components

### Host & Author Types
- **`ProgramHost`** — Host/speaker info (name, avatar, role) sourced from provider sync (Luma, Podbean, Livestorm)
- **`ProgramAuthorRef`** — Client-safe author subset from `profiles` FK join; excludes email for public payloads
- **`programItemToStripProfile()`** — Resolves a `VideoBiteStripProfile` from an item's author or first host; routes through `toStripProfile` as SSoT

### Database Row Types
- **`LumaEventRow`** — Raw row from `luma_events`
- **`PodcastEpisodeRow`** — Raw row from `podcast_episodes` (includes video/audio override fields)
- **`WebinarRow`** — Raw row from `webinars` (includes Livestorm recording and override fields)

### Program Item Interfaces
- **`BaseProgramItem`** — Common shape all program items implement (`id`, `title`, `cover_url`, `date`, `hosts`, etc.)
- **`EventItem`** — Extends base with location, geo, and Luma-specific fields
- **`PodcastItem`** — Extends base with audio/video URLs, AI processing, and SEO fields
- **`WebinarItem`** — Extends base with Livestorm recording, AI processing, and SEO fields

### Configuration Types
- **`ProgramType`** — `'event' | 'podcast' | 'webinar'`
- **`ProgramLabels`** — Display strings (singular, plural, section headers, empty states)
- **`ProgramConfig<T>`** — Core configuration object driving generic component behavior (table name, API endpoint, routing, icons, sort order)

### Response Types
- **`ProgramListResponse<T>`** — Paginated list result
- **`ProgramItemResponse<T>`** — Single item with optional media
- **`ProgramMedia`** — Associated media records (image/video/audio)

## Usage Example

```typescript
import type {
  ProgramConfig,
  PodcastItem,
  ProgramLabels,
} from './program-types';
import { MicIcon } from 'lucide-react';

const podcastLabels: ProgramLabels = {
  singular: 'Episode',
  plural: 'Episodes',
  upcoming: 'Latest Episode',
  upcomingSection: 'Latest Episodes',
  archive: 'All Episodes',
  empty: 'No episodes yet',
};

const podcastConfig: ProgramConfig<PodcastItem> = {
  type: 'podcast',
  labels: podcastLabels,
  dateField: 'published_at',
  table: 'podcast_episodes',
  apiEndpoint: '/api/podcasts',
  icon: <MicIcon />,
  externalLinkLabel: 'Listen on Podbean',
  detailRoute: '/podcasts',
  sortOrder: 'desc',
};

// Resolve a strip profile for video-bites overlay
const profile = programItemToStripProfile({
  author: { full_name: 'Jane Doe', avatar_url: '/jane.png' },
  hosts: [{ name: 'Fallback Host', role: 'team_member' }],
});
// → resolves from author first; falls back to first host
```
