Defines the wire-shape types for investor update entities used in chat cards and `/api/investor-updates` API responses, plus a pure date-range formatter utility.

## Key Components

### Interfaces

- **`MetricEntry`** — A single financial or operational metric with current/previous values, optional percentage change, and a `public | internal` visibility flag
- **`HighlightEntry`** — A titled highlight item (e.g. product milestone, community update) with visibility control
- **`InvestorUpdateHighlights`** — Groups highlight entries by category: `key_highlights`, `product_milestones`, `community_updates`, `upcoming_priorities`, and `financial_notes`
- **`InvestorUpdate`** — The primary entity shape covering all update fields: content, video assets, financials, metrics, SEO metadata, HubSpot integration IDs, and audit timestamps

### Functions

- **`formatInvestorUpdatePeriod(start, end, options?)`** — Formats a date range as a human-readable string (e.g. `Mar 2025 - May 2025`). Renders `?` for missing endpoints. Pins to UTC to ensure SSR/client hydration consistency.

## Usage Example

```typescript
import type { InvestorUpdate, MetricEntry } from '@openframe-oss-lib/investor-update';
import { formatInvestorUpdatePeriod } from '@openframe-oss-lib/investor-update';

// Format a period label for display
const label = formatInvestorUpdatePeriod('2025-03-01', '2025-05-31');
// → "Mar 2025 - May 2025"

const labelLong = formatInvestorUpdatePeriod('2025-03-01', null, { monthFormat: 'long' });
// → "March 2025 - ?"

// Typing a metric entry
const mrr: MetricEntry = {
  current: 42000,
  previous: 38000,
  change_pct: 10.5,
  visibility: 'internal',
};
```

## Notes

- Only **types** and the pure `formatInvestorUpdatePeriod` formatter are exported here. Server-side data utilities and visibility filters remain hub-side.
- `section_visibility` allows per-section `public | internal` gating on the `InvestorUpdate` object independent of field-level `MetricEntry` / `HighlightEntry` visibility.
