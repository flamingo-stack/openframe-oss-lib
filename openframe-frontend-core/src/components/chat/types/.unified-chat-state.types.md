Unified contract type definitions for the `useChat` hook's transport-agnostic return shape, shared by both the SSE (Guide mode) and NATS (Mingo mode) transport adapters.

## Key Components

| Export | Kind | Description |
|---|---|---|
| `DialogTokenUsage` | Interface | Per-dialog token usage snapshot from the Mingo backend's GraphQL `dialogs` endpoint |
| `ChatConnectionState` | Type | Transport-level connection status: `'connected' \| 'connecting' \| 'disconnected'` |
| `StreamingPhase` | Type | Granular streaming indicator: `'idle' \| 'thinking' \| 'streaming'` |
| `UnifiedUsageBreakdown` | Interface | SSE-only sub-call token costs for the Haiku rewriter/classifier/summarizer pipeline |
| `UnifiedChatMessage` | Interface | Transport-agnostic message shape; Guide-only fields (`sources`, `chatRefs`) are optional. `streamSeq` is not render input — it is the per-message coverage signal `mergeHistoryWithRealtime` decides with, and omitting it makes a mid-stream history refetch drop live bubbles |
| `UnifiedSendMessageOptions` | Interface | Options accepted by `sendMessage` honoured by both transports |
| `UnifiedChatState` | Interface | **Primary contract** — the full return shape both transport hooks must satisfy |

## Usage Example

```typescript
import type {
  UnifiedChatState,
  UnifiedChatMessage,
  UnifiedSendMessageOptions,
  StreamingPhase,
} from './unified-chat-state.types'

// Consuming the contract without branching on transport mode
function MyChatShell({ chat }: { chat: UnifiedChatState }) {
  const { messages, isLoading, streamingPhase, sendMessage, stopMessage } = chat

  const handleSend = async (text: string, opts?: UnifiedSendMessageOptions) => {
    await sendMessage(text, {
      hidden: false,
      attachments: opts?.attachments,
      contextItems: opts?.contextItems,
    })
  }

  // SSE-only fields are null in Mingo mode — guard before rendering
  const modelLabel = chat.currentModelLabel ?? 'AI'
  const phase: StreamingPhase = streamingPhase

  return { messages, isLoading, phase, modelLabel, handleSend, stopMessage }
}
```

## Transport Compatibility

| Field | SSE (Guide) | NATS (Mingo) |
|---|---|---|
| `sources`, `chatRefs` | ✅ Populated | `undefined` |
| `currentProvider` / `currentModelLabel` | ✅ Populated | `null` |
| `currentUsageBreakdown` | ✅ After trailing frame | `null` |
| `DialogTokenUsage` (separate) | `null` | ✅ From GraphQL |
| `discussRef` / `displayRef` | ✅ Active | no-op |
