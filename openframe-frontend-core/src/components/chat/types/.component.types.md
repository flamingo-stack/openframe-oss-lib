Defines all TypeScript prop interfaces and component types used across the chat UI library, covering containers, headers, messages, and inline rendering extension points.

## Key Components

| Export | Kind | Description |
|---|---|---|
| `NavLinkAnchorComponent` | Type | Host-supplied anchor component for markdown link routing inside messages |
| `ChatContainerProps` | Interface | Props for the root chat wrapper `<div>` |
| `ChatHeaderProps` | Interface | Full header configuration: identity, connection status, ticket info, MSP branding, skeleton states |
| `ChatHeaderTicketInfo` | Interface | Ticket title, meta, status, lifecycle color/kind displayed in the header |
| `ConnectionIndicatorProps` | Interface | Single `status` prop for the connection badge |
| `ChatMessageEnhancedProps` | Interface | Rich message bubble: role, content segments, approval handling, entity cards, mentions, context chips, anchor override |
| `ChatMessageListProps` | Interface | Scrollable thread list: messages, auto/pin scroll, pagination, approval footer, avatar display |

## Usage Example

```typescript
import type {
  ChatHeaderProps,
  ChatMessageEnhancedProps,
  NavLinkAnchorComponent,
} from './component.types'

// Host-supplied router-aware anchor
const NavLinkAnchor: NavLinkAnchorComponent = ({ href, className, children }) => (
  <a href={href} className={className}>{children}</a>
)

const headerProps: ChatHeaderProps = {
  userName: 'Mingo AI',
  connectionStatus: 'connected',
  fullWidth: true,
  bare: false,
  isLoading: false,
  ticketInfo: {
    title: 'Laptop won't boot',
    statusName: 'In Progress',
    statusKind: 'in_progress',
  },
}

const messageProps: ChatMessageEnhancedProps = {
  role: 'assistant',
  content: 'Checking diagnostics…',
  assistantType: 'mingo',
  approvalVariant: 'admin',
  NavLinkAnchor,
  renderMention: ({ marker, id }) => <EntityChip marker={marker} id={id} />,
  onApprove: async (requestId) => { await approveRequest(requestId) },
}
```

## Notes

- `ChatMessageEnhancedProps.renderEntityCard` enables inline `[card://<type>:<id>]` expansion without the library holding any entity-specific knowledge — the host's renderer hydrates each card by id.
- `ChatHeaderProps.fullWidth` / `bare` decouple layout from legacy centered-narrow defaults — set both when embedding in a narrow side panel.
- `NavLinkAnchorComponent` is intentionally loose (`any` spread at the call site) so host implementations can declare extra routing props (`path`, `targetPlatform`) without TypeScript friction.
