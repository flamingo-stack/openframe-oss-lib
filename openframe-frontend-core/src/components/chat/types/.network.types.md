Defines TypeScript types and constants for network and communication infrastructure, covering NATS messaging, WebSocket connections, streaming chunk data, and generic API response shapes.

## Key Components

### Constants
- **`NETWORK_CONFIG`** — Frozen configuration object with tunable network parameters (timeouts, retry backoff, message limits, ping intervals)

### NATS Types
- **`NatsMessageType`** — Discriminates between `'message'` and `'admin-message'` NATS payloads
- **`NatsConnectionStatus`** — Union of NATS lifecycle states (`connecting`, `connected`, `disconnected`, `reconnecting`, `closed`, `error`)
- **`NatsConnectionSource`** — Identifies the actor initiating a connection (`client`, `agent`, `dashboard`)

### Chunk / Streaming Types
- **`ChunkData`** — Core streaming payload; carries sequence IDs, stream state, tool execution metadata, approval workflow fields, and model/provider info. Supports an open index signature for extension
- **`BufferedChunk`** — Wraps a `ChunkData` with its `NatsMessageType` for buffered delivery

### WebSocket Types
- **`WebSocketMessage`** — Generic typed message envelope with optional timestamp and ID
- **`WebSocketConfig`** — Full WebSocket client configuration including reconnect strategy and lifecycle callbacks

### Function Types
- **`FetchChunksFunction`** — Typed async fetcher for polling `ChunkData[]` by dialog ID and chat type

### Response Types
- **`NetworkResponse<T>`** — Generic success/error API envelope
- **`PaginatedResponse<T>`** — Extends `NetworkResponse` with page, pageSize, totalCount, and totalPages
- **`NetworkError`** — Structured error with code, message, optional details, and ISO timestamp

## Usage Example

```typescript
import {
  NETWORK_CONFIG,
  type ChunkData,
  type FetchChunksFunction,
  type NetworkResponse,
  type PaginatedResponse,
  type NatsConnectionStatus,
} from './network.types'

// Use frozen config values
const timeout = NETWORK_CONFIG.CONNECT_TIMEOUT_MS // 10_000

// Type a NATS connection status handler
function handleStatus(status: NatsConnectionStatus): void {
  if (status === 'error') {
    scheduleReconnect(NETWORK_CONFIG.RECONNECT_TIME_WAIT_MS)
  }
}

// Type a chunk fetcher implementation
const fetchChunks: FetchChunksFunction = async (dialogId, chatType, fromSequenceId) => {
  const res = await api.get<ChunkData[]>(`/dialogs/${dialogId}/chunks`, {
    params: { chatType, from: fromSequenceId },
  })
  return res.data
}

// Consume a paginated API response
async function loadHistory(): Promise<void> {
  const response: PaginatedResponse<ChunkData[]> = await api.getHistory()
  if (response.success) {
    console.log(`Page ${response.page} of ${response.totalPages}`)
  }
}
```
