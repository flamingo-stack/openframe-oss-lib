Defines core enumerations, constants, interfaces, and utility functions for the OpenFrame chat system, covering chat types, message roles, approval workflows, connection states, and SSE event shapes.

## Key Components

### Constants & Types

| Export | Values | Description |
|---|---|---|
| `CHAT_TYPE` | `CLIENT_CHAT`, `ADMIN_AI_CHAT` | Distinguishes client vs. admin chat sessions |
| `OWNER_TYPE` | `CLIENT`, `ADMIN`, `ASSISTANT` | Identifies who owns a message |
| `MESSAGE_ROLE` | `user`, `assistant`, `error`, `system` | Standard LLM-style message roles |
| `ASSISTANT_TYPE` | `fae`, `mingo` | Flamingo AI assistants (Fae = client, Mingo = technician) |
| `AUTHOR_TYPE` | `user`, `admin`, `fae`, `mingo`, `system` | Granular message authorship |
| `APPROVAL_STATUS` | `pending`, `approved`, `rejected`, `cancelled` | Lifecycle states for approval workflows |
| `APPROVAL_BLOCK_VARIANT` | `admin`, `client` | Controls approval block rendering — `admin` shows full command/script preview; `client` shows only title and status pill |
| `CONNECTION_STATUS` | `connecting`, `connected`, `disconnected`, `reconnecting`, `closed`, `error` | Real-time connection lifecycle states |

### Interfaces

- **`MessageOwner`** — Typed owner identity including `OwnerType`, optional `machineId`, `userId`, AI model, and user profile (with avatar resolution delegated to the host)
- **`TextEventData`** / **`ToolExecutionEventData`** / **`SSEEventData`** — Wire-shape types for server-sent events carrying streamed text or tool execution state
- **`QuickAction`** — Shape for quick-action chips (`id` + `text`)

### Utility Functions

- **`buildChatRefKey(docType, externalId)`** — Constructs canonical `${docType}:${externalId}` keys for the `chatRefs` map, keeping writer and reader logic consistent
- **`isStructuredContent(content)`** — Type guard distinguishing segment arrays from plain strings
- **`normalizeContent(content)`** — Coerces `string | MessageSegment[]` into a uniform `MessageSegment[]`

## Usage Example

```typescript
import {
  CHAT_TYPE,
  MESSAGE_ROLE,
  APPROVAL_STATUS,
  APPROVAL_BLOCK_VARIANT,
  buildChatRefKey,
  isStructuredContent,
  normalizeContent,
  type MessageOwner,
  type SSEEventData,
} from './chat.types'

// Route a message to the correct chat surface
const chatType = CHAT_TYPE.ADMIN // 'ADMIN_AI_CHAT'

// Build a chatRef lookup key for an inline card marker
const refKey = buildChatRefKey('ticket', 'TKT-1042') // 'ticket:TKT-1042'

// Normalize mixed content for rendering
const segments = normalizeContent('Hello, how can I help?')
// [{ type: 'text', text: 'Hello, how can I help?' }]

// Type-safe approval state check
const status = APPROVAL_STATUS.PENDING // 'pending'

// Render the correct approval block for the viewer
const variant = APPROVAL_BLOCK_VARIANT.CLIENT // hides raw commands from end user

// Typed SSE handler
function handleSSEEvent(event: SSEEventData) {
  if (event.type === 'TEXT') {
    console.log(event.text)
  } else if (event.type === 'EXECUTED_TOOL') {
    console.log(event.toolFunction, event.success)
  }
}

// Typed message owner
const owner: MessageOwner = {
  type: 'ASSISTANT',
  model: 'gpt-4o',
}
```
