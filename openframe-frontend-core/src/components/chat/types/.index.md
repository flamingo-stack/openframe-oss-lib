Central barrel export file that re-exports all TypeScript type definitions for the OpenFrame chat system, providing a single import entry point for consumers.

## Key Components

All exports are sourced from the following modules:

| Module | Description |
|---|---|
| `chat.types` | Core chat domain types |
| `message.types` | Message structure and payload types |
| `component.types` | UI component prop/state types |
| `network.types` | Network request/response types |
| `processing.types` | Message processing pipeline types |
| `api.types` | External API contract types |
| `entities` | Shared domain entity definitions |
| `context-item.types` | Context item types for AI/chat context |
| `unified-chat-state.types` | Unified state management types |

## Usage Example

```typescript
// Import any type directly from the package root — no need to reach into submodules
import type {
  ChatMessage,
  NetworkRequest,
  UnifiedChatState,
  ContextItem,
} from '@openframe/chat-types'
```

Instead of:

```typescript
// ❌ Avoid deep imports
import type { ChatMessage } from '@openframe/chat-types/message.types'
import type { UnifiedChatState } from '@openframe/chat-types/unified-chat-state.types'
```

## Notes

- This file contains **no runtime logic** — it is purely a type re-export barrel.
- Adding a new type module requires a corresponding `export *` line here to expose it to consumers.
- See the [source file](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/index.ts) for the full export list.
