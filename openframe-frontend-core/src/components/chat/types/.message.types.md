Defines all TypeScript types, interfaces, and constants for the chat message system, covering message lifecycle events, content structures, tool execution states, approval workflows, and historical/processed message representations.

## Key Components

### Constants
- **`MESSAGE_TYPE`** — Enum-style const object with 16 message types (`TEXT`, `THINKING`, `EXECUTING_TOOL`, `APPROVAL_REQUEST`, `CONTEXT_COMPACTION_START`, etc.)
- **`SCROLL_ANCHOR`** — Per-message viewport hint (`top` | `bottom`) controlling chat scroll behavior on long assistant responses

### Tool Execution
- **`ToolExecutionData`** — Wire payload for `EXECUTING_TOOL` / `EXECUTED_TOOL` events, including optional `toolExecutionRequestId` for merging into approval batches
- **`ExecutingToolState`** — In-flight snapshot carried between executing/executed events to preserve `toolTitle` and `toolExplanation`

### Approval Workflow
- **`ApprovalRequestData`** / **`ApprovalResultData`** — Single-command approval request/result payloads
- **`PendingToolCallData`** — Individual tool call within a batch approval request
- **`ApprovalBatchData`** — Batch of tool calls requiring approval, keyed by `toolExecutionRequestId`
- **`ApprovalBatchExecutionState`** — Per-tool execution progress (`executing` | `done`) within a resolved batch

### Message Segments
- **`MessageSegment`** — Union of `TextSegment`, `ThinkingSegment`, `ToolExecutionSegment`, `ApprovalRequestSegment`, `ApprovalBatchSegment`, `ErrorSegment`, `ContextCompactionSegment`
- **`MessageContent`** — `string | MessageSegment[]`

### API Data Types
- **`MessageData`** — Discriminated union of all wire-format message data types from GraphQL/API
- **`HistoricalMessage`** — Persisted message row with `lastChunkStreamSeq` for realtime merge coverage
- **`ProcessedMessage`** / **`Message`** — Normalized display-ready message with role, content, timestamps, and `streamSeq`

## Usage Example

```typescript
import {
  MESSAGE_TYPE,
  SCROLL_ANCHOR,
  type MessageData,
  type MessageSegment,
  type ApprovalBatchData,
  type ProcessedMessage,
} from './message.types'

// Check incoming message type
function handleChunk(data: MessageData) {
  if (data.type === MESSAGE_TYPE.EXECUTING_TOOL) {
    console.log('Tool running:', data.toolFunction)
  }
  if (data.type === MESSAGE_TYPE.APPROVAL_REQUEST) {
    console.log('Batch calls:', data.toolCalls?.length)
  }
}

// Build a processed message for rendering
const msg: ProcessedMessage = {
  id: 'msg-1',
  role: 'assistant',
  content: [
    { type: 'text', text: 'Done! Here is the result.' },
    { type: 'tool_execution', data: {
        type: 'EXECUTED_TOOL',
        integratedToolType: 'ticketing',
        toolFunction: 'createTicket',
        success: true,
        result: '{"ticketId":"T-42"}',
    }},
  ],
  timestamp: new Date(),
  streamSeq: 14,
}

// Scroll hint for long article responses
const anchor = SCROLL_ANCHOR.TOP
```
