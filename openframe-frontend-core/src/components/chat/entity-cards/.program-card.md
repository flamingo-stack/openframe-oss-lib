Presentation-only card component for programs (podcasts, webinars, events) supporting three density modes: `default`, `sm` (compact), and `portrait` (vertical rail).

## Key Components

### Exports

- **`ProgramCard<T>`** — Generic card component accepting any `BaseProgramItem` subtype; delegates to density-specific render branches
- **`ProgramCardSkeleton`** — The card's own loading form (drawn by `ProgramCard` in a loading scope), matching each size; the `default` size's tags, host avatars and gallery thumbnails carry `data-loading-item` in both forms. In a scope the rows are decided by the type's CONFIG, never by the placeholder record: the hosts row when `cardShowsHosts` (`PROGRAM_CARD_SKELETON_HOSTS`), the gallery when `cardShowsGallery` (`PROGRAM_CARD_SKELETON_MEDIA`); the tag row is a record's optional part (`data-loading-optional`), as is the gallery of a type without `cardShowsGallery`
- **`ProgramCardProps<T>`** — Interface defining all card inputs

### Internal Utilities

- **Dates** — resolved by `programDateInstant` and rendered by `formatProgramDate` / `formatWebinarTimeMeta` (`../../../utils`), shared with the public page header. A local `formatUtc` twin used to live here; the UTC pin that prevents React #418 is already inside `formatDateWithTimezone` when it is given no zone.
- **`getHosts(hosts)`** — Normalizes `ProgramHost[]` or raw JSON string into `{ name, avatar }[]`
- **`MediaGallery`** — Horizontally scrollable thumbnail strip with `ImageGalleryModal` lightbox on click

### Density Modes

| Size | Layout | Use Case |
|---|---|---|
| `default` | Wide horizontal with full detail | Archive/listing pages |
| `sm` | Compact horizontal row | Chat-inline cards |
| `portrait` | Vertical via `EntityPortraitCard` | Mixed-content rails |

## Usage Example

```typescript
import { ProgramCard, ProgramCardSkeleton } from './program-card'
import { podcastConfig } from '../config/podcast-config'

// Loading state: the card in a loading scope draws its own skeleton
<LoadingWhen loading={isLoading}><ProgramCard config={config} item={item} size="sm" /></LoadingWhen>

// Default density
<ProgramCard
  config={podcastConfig}
  item={episode}
  media={episode.media}
  href={`/podcasts/${episode.slug}`}
  size="default"
/>

// Portrait for mixed-content rail
<ProgramCard
  config={webinarConfig}
  item={webinar}
  href={`/webinars/${webinar.slug}`}
  size="portrait"
  showTypeBadge={true}
  target="_blank"
  rel="noopener noreferrer"
/>
```

> The card writes no click logic — callers wrap or pass `href` directly. Use `target="_blank"` with `rel="noopener noreferrer"` for cross-platform or embed contexts.
