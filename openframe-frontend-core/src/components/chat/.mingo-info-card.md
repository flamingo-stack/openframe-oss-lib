A React component that renders an inline-safe information card designed for use inside chat message paragraphs, using only phrasing-content elements (`<span>`, `<a>`, `<button>`, `<img>`) to remain valid within `<p>` tags.

## Key Components

### Exports

- **`MingoInfoCard`** — Primary card component rendering title, optional description, leading media, status pill, and overflow menu
- **`CardMedia`** *(internal)* — 40px leading media slot supporting avatar images (with initials fallback) or icon glyphs
- **`MingoInfoCardProps`** — Full prop interface for the card
- **`MingoInfoCardStatus`** — Shape for the status pill (`label` + `variant`)
- **`MingoInfoCardAnchorProps`** — Anchor-prop bundle (`href`, `target`, `rel`, `onClick`) for navigation mode

### Content Region Modes

| Condition | Rendered as |
|---|---|
| `anchorProps` supplied | `<a>` (takes precedence) |
| `onClick` supplied | `<button type="button">` |
| Neither | `<span>` (static) |

## Usage Example

```typescript
import { MingoInfoCard } from '@openframe/ui'

// Static card with avatar and status pill
<MingoInfoCard
  imageSrc="https://cdn.example.com/avatar.png"
  imageAlt="Jane Doe"
  title="Jane Doe"
  description="Senior Technician"
  status={{ label: 'Online', variant: 'success' }}
/>

// Navigable card with icon and overflow menu
<MingoInfoCard
  icon={<ServerIcon size={24} />}
  title="Prod Server"
  description="192.168.1.1"
  anchorProps={{ href: '/devices/42', target: '_blank' }}
  menuGroups={[
    {
      items: [
        { label: 'View details', onClick: handleView },
        { label: 'Restart', onClick: handleRestart },
      ],
    },
  ]}
/>
```

## Notes

- The `imageSrc` avatar gracefully degrades to initials (via `getFirstLastInitials`) on image load failure
- The `⋯` menu button is always a sibling of the content anchor — never nested — preserving valid HTML
- Status pill reuses `tagVariants` for colour consistency without introducing block-level `<div>` elements
