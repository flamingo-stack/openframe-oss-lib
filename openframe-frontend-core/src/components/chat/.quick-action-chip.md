Renders a compact, themed quick-action chip button with icon resolution, loading skeleton, and support for agent-branded accents, lozenges, and selection states.

## Key Components

### Types & Utilities

- **`QuickActionAccent`** — Union type for icon tint: `'pink'` | `'cyan'` | any CSS color string
- **`QuickActionIconSpec`** — Extends `EntityIconValue` with `accent` and `size`; declarative icon descriptor resolved by `<EntityIcon>`
- **`QuickActionThemeSpec`** — Caller-supplied chip theme with `accent` and optional `lozenge`
- **`QuickActionChipLozenge`** — Leading category/status affix rendered inside the chip label
- **`getAgentAccent(slug)`** — Maps built-in agent slugs (`'fae'`, `'mingo'`) to brand accent tokens
- **`accentFromIdentityIcon(icon)`** — Extracts `icon_props.color` from an admin-configured identity
- **`isQuickActionIconSpec(icon)`** — Type guard distinguishing a spec object from a `ReactNode`
- **`renderQuickActionIcon(icon)`** — Resolves a chip `icon` prop to a renderable node via `<EntityIcon>`

### Components

- **`QuickActionChipButton`** — Primary chip component with full theming, icon, lozenge, selection, and interactivity support
- **`QuickActionChipSkeleton`** — Loading placeholder that mirrors the real chip's exact dimensions using pulse bars

## Usage Example

```typescript
import {
  QuickActionChipButton,
  QuickActionChipSkeleton,
  getAgentAccent,
  accentFromIdentityIcon,
} from './quick-action-chip'

// Basic chip with a built-in agent accent
<QuickActionChipButton
  label="Summarize Ticket"
  icon={{ name: 'mingo', size: 16 }}
  theme={{ accent: getAgentAccent('mingo') ?? 'cyan' }}
  onSelect={() => console.log('selected')}
/>

// Chip with admin-configured icon color and a category lozenge
<QuickActionChipButton
  label="Patch Servers"
  icon={{ name: 'server', accent: accentFromIdentityIcon(agentRow.icon) }}
  lozenge={{ label: 'SEC', className: 'text-ods-warning' }}
  selected
  selectedAccent="cyan"
  size="large"
/>

// Loading state — matches loaded chip dimensions 1:1
<QuickActionChipSkeleton labelCh={12} icon lozenge size="large" />
```

## Notes

- Theme accent fills only when the icon spec carries no `accent` of its own — per-action config always wins.
- Named brand tokens (`pink`, `cyan`) apply a `text-ods-flamingo-*` class; arbitrary CSS colors are passed as an explicit `color` prop to `<EntityIcon>`.
- Set `interactive={false}` for decorative chips (marquee strips, table cells) to suppress focus and keyboard handling.
