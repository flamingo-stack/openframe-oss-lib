The bubble's markdown for a user row's `file` part, and the escape every server that writes a file name into markdown applies. The attachment itself (its constants, its `ChatAttachment` shape, its view url and its `file` part) is the chat protocol's: `chat-protocol/attachment.ts`.

## Key Components

| Export | Purpose |
|--------|---------|
| `escapeMarkdownInline` | Escapes a file name's markdown characters (`[ ] ( ) \ < > "`, line breaks) so it cannot end a link early |
| `chatFilePartMarkdown` | A `file` part as the bubble draws it: `![name](url)` for an image, `[Attached: name](url)` for anything else, through the host's view prefix |
| `CHAT_ATTACHMENT_VIEW_URL_PREFIX_REGEX_ESCAPED` | The hub's view prefix escaped for a pattern |
