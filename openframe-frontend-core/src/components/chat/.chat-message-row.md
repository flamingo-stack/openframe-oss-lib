Renders a single Slack-channel-style message row used across both the OpenMSP community feed and ticket conversation surfaces, ensuring pixel-identical layout on both.

## Key Components

### `ChatMessageRow`
The primary message row component with avatar, display name, relative timestamp, body text, and an optional footer slot. Handles avatar proxying via `useProxiedImageUrl` and gracefully falls back to an initials box on image load failure, keyed by URL to allow retry on src change.

ONE switch (`useLoadingScope() || loading`): with `loading` (or in a loading scope) the row draws its loading form from its own class constants: the same wrapper and avatar box (a skeleton box), the name bar at the name's own line height (`TextLineSkeleton` `inherit` inside the name's type), the time bar at `text-h6`, and the body a typical run of `text-h6` lines (`CHAT_MESSAGE_ROW_BODY_LINES`, 2). List markers (`data-loading-item`) are forwarded in both forms.

### `ChatMessageRowSkeleton` (deprecated)
Renders `<ChatMessageRow loading displayName="" body="" />` with the markers it is given. Render the row with `loading` instead.

### `ChatMessageRowProps`
```typescript
interface ChatMessageRowProps {
  displayName: string       // Bold name in header
  avatarUrl?: string | null // Proxied; falls back to initials
  timeLabel?: string | null // Pre-formatted (e.g. "2h ago"); hidden if empty
  body: string              // whitespace-pre-wrap message text
  footer?: ReactNode        // Surface-specific slot (reply badge / attachments)
  loading?: boolean         // The row's own loading form (pass displayName="" body="")
  [key: `data-${string}`]: unknown // List markers, both forms
}
```

## Usage Example

```typescript
import { ChatMessageRow } from './chat-message-row'

// Slack community feed
<ChatMessageRow
  displayName="Jane Smith"
  avatarUrl="https://cdn.example.com/avatars/jane.jpg"
  timeLabel="2h ago"
  body="Hey team, deployment looks good!"
  footer={<ReplyBadge count={3} />}
/>

// Ticket conversation feed
<ChatMessageRow
  displayName="Support Bot"
  avatarUrl={null}          // Renders initials fallback "SB"
  timeLabel={formatRelativeTime(message.createdAt)}
  body={message.text}
  footer={<TicketAttachmentsList attachments={message.attachments} />}
/>

// While loading
<LoadingItems count={TICKET_FEED_SKELETON_ROWS}>
  {() => <ChatMessageRow loading displayName="" body="" data-loading-item />}
</LoadingItems>
```

## Notes

- Colors use ODS theme tokens exclusively (`text-ods-text-primary`, `text-ods-text-secondary`, `bg-ods-border`) — no raw color values.
- Avatar sizing mirrors Slack's layout: `w-8 h-8` (32px) on mobile, `md:w-10 md:h-10` (40px) on desktop, `rounded-lg`, `object-cover`.
- The `footer` prop is the **only** intentional surface-level variation point; all other markup is shared verbatim.
