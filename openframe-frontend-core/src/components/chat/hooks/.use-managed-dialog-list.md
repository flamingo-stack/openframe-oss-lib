The ONE dialog-list state machine shared by both transport adapters — NATS/Mingo managed-dialog mode and the SSE/Guide adapter when `ChatRuntime.endpoints.chatConversationsUrl` is set. Extracted from `useNatsChatAdapter` so Guide mode reuses the exact list/paging/mutation semantics openframe-frontend already relies on.

## Key Components

### `useManagedDialogList(args)`
Owns the loaded `DialogItem[]` page, the server cursor, first-page loading/error state (with the retry re-arm), cursor pagination, an optional server-side `search` term (a change re-runs page 1) and the optimistic rename / archive / delete mutations. Does NOT own the active dialog id, message history or the transport — the adapters layer those on top via `onDialogRemoved`.

### `UseManagedDialogListArgs`
- `active` — mirrors the adapter's gate; the initial load waits for it
- `fetchDialogs` / `renameDialog` / `archiveDialog` / `deleteDialog` — host callbacks; presence IS the capability (absent = inert / no-op)
- `pageSize` — sent as `limit`
- `search` — `undefined` = no search support (NATS keeps `{cursor, limit}` wire params); any string change reloads page 1 with `search`
- `onDialogRemoved(id, 'archived' | 'deleted')` — fires AFTER the local removal, read through a latest-ref
- `logTag` — console prefix for failure logs

### `UseManagedDialogListResult`
`dialogs`, `dialogsNextCursor`, `isDialogsLoading`, `dialogsError`, `hasMoreDialogs`, `loadDialogsPage`, `reloadDialogs`, `loadMoreDialogs`, `renameDialog`, `archiveDialog`, `deleteDialog`, plus `upsertDialogTop(item)` (prepend + dedupe) and `patchDialog(id, patch)`.

## Behavioural contracts

- Only the FIRST page failing sets `dialogsError`; a pagination failure keeps the loaded rows.
- Rename is optimistic; the rollback title is read synchronously from a live ref at call time (capturing it inside a `setState` updater was unreliable — the updater may run after an immediately-rejecting callback reaches the catch).
- Archive/delete failures are logged and swallowed (row stays), matching the pre-extraction NATS adapter.
