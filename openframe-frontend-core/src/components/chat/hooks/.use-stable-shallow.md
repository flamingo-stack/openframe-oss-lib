Reference latch for a value whose contents did not change, so a host's INLINE object prop can be used as a memo dependency without invalidating everything downstream of it on every render.

## Key Components

### `useStableShallow(value)`
Returns the PREVIOUS reference while a shallow comparison of the own enumerable keys matches, and the new one the moment anything differs. `undefined` round-trips in both directions.

Used by `useUnifiedChat` for the `injectedDialogCapabilities` companion option: hosts write it inline (`mingoDialogCapabilities={{ canRename: true, … }}`), and without the latch that fresh object would break the unified-state memo — and any memo a consumer hangs off its identity — on every render.

## Behavioural contracts

- Shallow BY DESIGN: values are compared with `Object.is`, so a host whose callbacks are themselves recreated each render still churns. That is the host's own instability, visible to it, and not something this hook should paper over by comparing more deeply.
- An explicitly-`undefined` key and a missing key are NOT equal — the key sets are compared with `in`, not by counting.
- Adjusts state during render (the documented React pattern for deriving from a prop) rather than writing a ref, which would be unsafe under concurrent rendering. The pass that stores a new value also returns it, so a caller never sees a stale object for a render.
