A multi-select tag picker rendered as a button-triggered Radix UI popover, featuring inline search/filter, checkable tag rows, optional inline tag creation, and per-row delete actions.

## Key Components

### `TagSelectDropdown`
The main exported component. Opens a popover containing:
- **Search input** — filters options in real time; `Enter` triggers creation when applicable
- **Option list** — selected tags float to the top, each row shows a check icon when active and a hover-revealed trash icon when `onDelete` is provided
- **Create row** — appears when the search query doesn't match any existing tag; enforces `maxCreateLength` with an inline error

### Interfaces

| Export | Purpose |
|---|---|
| `TagSelectOption` | `{ id: string; label: string }` — shape of each selectable tag |
| `TagSelectDropdownProps` | Full prop surface for the dropdown |

### Key Props

| Prop | Type | Description |
|---|---|---|
| `options` | `TagSelectOption[]` | All available tags |
| `selectedIds` | `string[]` | IDs of currently selected tags |
| `onChange` | `(ids: string[]) => void` | Called with next full selection on toggle |
| `onCreate` | `(name: string) => void` | Enables inline creation row when provided |
| `onDelete` | `(id: string) => void` | Enables per-row trash button when provided |
| `maxCreateLength` | `number` | Optional character cap for new tag names |
| `isCreating` / `isDeleting` | `boolean` | Disables create/delete buttons during async ops |

## Usage Example

```typescript
import { TagSelectDropdown, TagSelectOption } from './tag-select-dropdown'

const ALL_TAGS: TagSelectOption[] = [
  { id: '1', label: 'Urgent' },
  { id: '2', label: 'Billing' },
  { id: '3', label: 'Hardware' },
]

function TagPicker() {
  const [selected, setSelected] = React.useState<string[]>(['1'])

  return (
    <TagSelectDropdown
      options={ALL_TAGS}
      selectedIds={selected}
      onChange={setSelected}
      onCreate={(name) => console.log('Create tag:', name)}
      onDelete={(id) => console.log('Delete tag:', id)}
      maxCreateLength={30}
      triggerLabel="Add Tags"
    />
  )
}
```

> Selected tag chips are rendered by the caller — this component only manages the picker UI and fires `onChange` with the updated ID array.
