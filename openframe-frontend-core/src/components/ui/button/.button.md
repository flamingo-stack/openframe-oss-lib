Flexible, multi-variant button component supporting standard buttons, links, split-icon layouts, and loading states via a unified `Button` interface.

## Key Components

- **`buttonVariants`** — CVA variant map defining styles for `variant` (`accent`, `outline`, `transparent`, `destructive`, `warning`, `inverted`, `glyph`, `overlay`, `link`) and the kinds (`field`, `row`, `tab`, `chip`, `card`, `cell`), `size` (`default`, `small`, `small-legacy`, `compact`, `icon`, `icon-sm`), `fullWidth`, and `noPaddingX`.
- **`splitShellVariants` / `splitSlotVariants`** — CVA helpers for the split-icon layout, where a vertical divider separates main content from a trailing icon area within a single click target.
- **`Spinner`** — Internal SVG spinner rendered absolutely during `loading` state, preserving button dimensions.
- **`Button`** — Primary export. A `forwardRef` component that auto-selects rendering strategy: `<Slot>` (`asChild`), `<Link>` (`href` / `linkProps`), split layout (`splitIcon`), or a plain `<button>`.

## Props

| Prop | Type | Notes |
|---|---|---|
| `variant` | `accent` \| `outline` \| `transparent` \| `destructive` \| `warning` \| `inverted` \| `glyph` \| `overlay` \| `link` \| a kind (`field` \| `row` \| `tab` \| `chip` \| `card` \| `cell`) | Defaults to `accent`. Kinds: see below |
| `size` | `default` \| `small` \| `compact` \| `icon` \| `icon-sm` | `small-legacy` deprecated |
| `href` / `linkProps` | `string` / object | Renders as `<Link>`; `linkProps` wins over `href` |
| `splitIcon` | `ReactNode` | Triggers split layout (default/small sizes only) |
| `loading` | `boolean` | Hides content, shows spinner; implies `disabled` |
| `asChild` | `boolean` | Delegates rendering to child via Radix `Slot` |

## Kinds (`field`, `row`, `tab`, `chip`, `card`, `cell`)

Every clickable element in the lib is a `Button`: there is no raw `<button>` in a component. A push button is a
`variant` + `size`. A control that is not a plain push button is one of the Button's KINDS (`BUTTON_KIND_CLASS` in
`button-styles.ts`), each with its whole design-system look in Button itself and reused by every control of its kind:

| Kind | For | State attributes |
|---|---|---|
| `field` | a control drawn as a form field that opens a popup (date picker, searchable select, `InputTrigger`) | `data-state="open"` / `aria-expanded`, `data-invalid` |
| `row` | a clickable row of a list, menu, dropdown, navigation, or an expandable summary | `data-state="active"` |
| `tab` | a tab of a tab strip or tab list; `data-emphasis="fade"` adds the admin strip's accent fade | `data-state="active"` |
| `chip` | a pill choice (filter, quick question, vendor pill) | `aria-pressed`, `data-state="active"` |
| `card` | a whole card / tile / media facade that is one click target, or a contentless hit layer | — |
| `cell` | a cell of a top bar (header cells, the chat bars' edge buttons); the bar draws the dividers (`divide-x`) | `aria-pressed`, `aria-expanded`, `data-state="active"` |

`size` does not apply to a kind. A call site's `className` on ANY Button is layout only (width, flex, position,
margin); state goes through the attributes above, never a conditional class. A loading form that must land in the same
box reads the same constant (`cn(BUTTON_KIND_CLASS.row, layout)`, or `buttonVariants({ variant, size })`).

`attach="start"` / `"end"` draws two Buttons as one surface with a seam (`DropdownButton`, `SplitButton`); a filled
variant's trailing half carries the darker seam.

## Usage Example

```typescript
// Standard accent button with loading state
<Button variant="accent" loading={isSubmitting} onClick={handleSubmit}>
  Save Changes
</Button>

// Link button with split icon
<Button href="/dashboard" splitIcon={<ChevronDownIcon />} variant="outline">
  Dashboard
</Button>

// Icon-only ghost button
<Button variant="transparent" size="icon-sm" aria-label="Share">
  <ShareIcon />
</Button>

// A list row, selected
<Button variant="row" type="button" data-state={selected ? 'active' : undefined} onClick={open}>
  {row}
</Button>

// Render as child (asChild)
<Button asChild variant="outline">
  <a href="https://openframe.ai">Learn More</a>
</Button>
```
