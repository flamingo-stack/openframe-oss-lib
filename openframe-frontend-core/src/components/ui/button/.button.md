Flexible, multi-variant button component supporting standard buttons, links, split-icon layouts, and loading states via a unified `Button` interface.

## Key Components

- **`buttonVariants`** — CVA variant map defining styles for `variant` (`accent`, `outline`, `transparent`, `destructive`, `warning`, `inverted`, `glyph`, `overlay`, `link`, `bare`) and the kinds (`field`, `row`, `rail`, `tab`, `segment`, `chip`, `card`, `cell`, `stepper`), `size` (`default`, `small`, `small-legacy`, `compact`, `icon`, `icon-sm`), `fullWidth`, and `noPaddingX`.
- **`splitShellVariants` / `splitSlotVariants`** — CVA helpers for the split-icon layout, where a vertical divider separates main content from a trailing icon area within a single click target.
- **`Spinner`** — Internal SVG spinner rendered absolutely during `loading` state, preserving button dimensions.
- **`Button`** — Primary export. A `forwardRef` component that auto-selects rendering strategy: `<Slot>` (`asChild`), `<Link>` (`href` / `linkProps`), split layout (`splitIcon`), or a plain `<button>`.

## Props

| Prop | Type | Notes |
|---|---|---|
| `variant` | `accent` \| `outline` \| `transparent` \| `destructive` \| `warning` \| `inverted` \| `glyph` \| `overlay` \| `link` \| `bare` \| a kind (`field` \| `row` \| `rail` \| `tab` \| `segment` \| `chip` \| `card` \| `cell` \| `stepper`) | Defaults to `accent`. Kinds and states: see below |
| `size` | `default` \| `small` \| `compact` \| `icon` \| `icon-sm` | `small-legacy` deprecated |
| `href` / `linkProps` | `string` / object | Renders as `<Link>`; `linkProps` wins over `href` |
| `splitIcon` | `ReactNode` | Triggers split layout (default/small sizes only) |
| `loading` | `boolean` | Hides content, shows spinner; implies `disabled` |
| `asChild` | `boolean` | Delegates rendering to child via Radix `Slot` |

## States on the push-button variants

A push button's state also comes from its attributes, never a site class:

| Variant | Attribute | Look |
|---|---|---|
| `link` | `data-state="active"` | holds the accent (a filter trigger with filters applied) |
| `link` | `data-tone="neutral"` | the primary text on hover instead of the accent (a secondary text action) |
| `link` | `data-tone="primary"` | the primary text, the accent on hover (a value that opens something) |
| `bare` | — | a glyph with no surface: secondary, primary on hover and keyboard focus, faded when disabled |
| `bare` | `aria-expanded="true"` | stays lit (primary) while its popup is open |
| `bare` | `data-state="active"` | armed, in the accent (the composer's send while the editor has focus) |
| `bare` | `data-tone="accent"` | opens and presses in the accent (the composer's add-context) |
| `bare` | `data-tone="danger"` / `"error"` / `"success"` | the error colour on hover / a glyph drawn in the error or success colour |
| `bare` | `data-tone="field"` | a field adornment: the accent while the field (`group`) has focus, the error colour while it is invalid |
| `outline` | `data-tone="accent"` | the accent fill on hover |

## Kinds (`field`, `row`, `rail`, `tab`, `segment`, `chip`, `card`, `cell`, `stepper`)

Every clickable element in the lib is a `Button`: there is no raw `<button>` in a component. A push button is a
`variant` + `size`. A control that is not a plain push button is one of the Button's KINDS (`BUTTON_KIND_CLASS` in
`button-styles.ts`), each with its whole design-system look in Button itself and reused by every control of its kind:

| Kind | For | State attributes |
|---|---|---|
| `field` | a control drawn as a form field that opens a popup (date picker, searchable select, `InputTrigger`), or a choice drawn as a field (`SelectButton`) | `data-state="open"` / `aria-expanded` (the accent border, held on hover), `aria-selected` (the accent border on the accent's light fill), `data-invalid` (wins over open) |
| `row` | a clickable row of a list, menu, dropdown, navigation, or an expandable summary | `data-state="active"` (the hover surface); `data-tone`: `accent` (the accent's secondary fill, no hover), `link` (the accent text, no surface), `surface` (the raised surface), `muted` (the border-grey fill, held on hover), `card` (a bordered card), `framed` (every row a bordered card, the selected one's border the accent) |
| `rail` | an entry of the app's navigation rail: the hover wash on its own layer, so the current page switches in one frame | `data-state="active"` (the accent's light fill, accent text and glyph, the accent bar), `aria-busy` (the hover wash) |
| `tab` | a tab of a tab strip or tab list; `data-emphasis="fade"` adds the admin strip's accent fade | `data-state="active"` |
| `segment` | a segment of a segmented control (`TabSelector`) | `data-state="active"` (the raised surface; `data-tone="accent"`: the accent), `disabled` (a selected one keeps the surface, secondary text) |
| `chip` | a pill choice (filter, quick question, vendor pill) | `aria-pressed`, `data-state="active"`; `data-tone="accent"`: the accent border on hover |
| `card` | a whole card / tile / media facade that is one click target, or a contentless hit layer | — |
| `cell` | a cell of a top bar (header cells, the chat bars' edge buttons); the bar draws the dividers (`divide-x`) | `aria-expanded` (the primary text), `data-state="active"` (the pressed surface, the primary text) |
| `stepper` | a carousel's previous / next arrow under its track: a round outline with no fill; drawn only through `CarouselStepButton` | `disabled` (faded, at either end of the track) |

`size` does not apply to a kind. A call site's `className` on ANY Button is layout only (width, flex, position,
margin), never a colour; state goes through the attributes above, never a conditional class. A second look for the
same state is a `data-tone` the kind declares, set on the control and on its loading form. A loading form that must land in the same
box reads the same constant (`cn(BUTTON_KIND_CLASS.row, layout)`, or `buttonVariants({ variant, size })`).

`attach="start"` / `"end"` draws two Buttons as one surface with a seam (`DropdownButton`, `SplitButton`); a filled
variant's trailing half carries the darker seam.

## Usage Example

```typescript
// Standard accent button with loading state
<Button variant="accent" loading={isSubmitting} onClick={handleSubmit}>
  Save Changes
</Button>

// Link button with split icon
<Button href="/dashboard" splitIcon={<ChevronDownIcon />} variant="outline">
  Dashboard
</Button>

// Icon-only ghost button
<Button variant="transparent" size="icon-sm" aria-label="Share">
  <ShareIcon />
</Button>

// A list row, selected
<Button variant="row" type="button" data-state={selected ? 'active' : undefined} onClick={open}>
  {row}
</Button>

// Render as child (asChild)
<Button asChild variant="outline">
  <a href="https://openframe.ai">Learn More</a>
</Button>
```
