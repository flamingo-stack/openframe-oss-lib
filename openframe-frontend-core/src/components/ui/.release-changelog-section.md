Renders a collapsible/expandable changelog section for product releases, displaying a titled list of `ChangelogEntry` items with optional progressive disclosure and rich markdown support.

## Key Components

**`ReleaseChangelogSection`** — Primary export. Accepts a `title`, array of `ChangelogEntry` items, and several display-mode flags:

| Prop | Type | Description |
|---|---|---|
| `collapsible` | `boolean` | Toggle section open/closed via title row button |
| `defaultCollapsed` | `boolean` | Initial collapsed state (default: `true`) |
| `previewFirst` | `boolean` | Shows first entry in full, fades remaining entries behind a "Show N more" toggle |
| `isBreaking` | `boolean` | Renders title in error color for breaking changes |
| `icon` | `ReactNode` | Lucide icon rendered inline before the title |
| `MarkdownRenderer` | `ComponentType` | Defaults to `RichMarkdownRenderer`; swap for custom implementations |
| `hideTitle` | `boolean` | Suppresses the title row entirely |

> **Note:** When both `collapsible` and `previewFirst` are passed, `collapsible` takes precedence.

**`ChangelogEntryList`** *(internal)* — Renders a `<ul>` of bordered entries, each with a bold markdown-rendered `title` and optional `description` body. Typography is pinned via Tailwind `[&_p]:!` overrides to ODS token scales (`text-h3`/`text-h4`) so the `MarkdownRenderer`'s default paragraph styles don't override responsive breakpoints.

## Usage Example

```typescript
import { ReleaseChangelogSection } from './release-changelog-section';
import { Sparkles } from 'lucide-react';

// Default collapsible section
<ReleaseChangelogSection
  title="New Features"
  entries={[
    { title: "AI-powered ticket routing", description: "Routes tickets to the right queue automatically." },
    { title: "[Dashboard redesign](https://example.com)", description: "Faster load times and improved layout." },
  ]}
  icon={<Sparkles className="h-4 w-4" />}
  collapsible
  defaultCollapsed={false}
/>

// Preview-first mode (fades entries after the first)
<ReleaseChangelogSection
  title="Bug Fixes"
  entries={fixes}
  previewFirst
/>

// Breaking changes section
<ReleaseChangelogSection
  title="Breaking Changes"
  entries={breaking}
  isBreaking
/>
```
