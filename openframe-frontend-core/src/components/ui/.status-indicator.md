A client-side React component that renders a colored status dot paired with a label, optionally wrapped in an external link.

## Key Components

### `StatusIndicatorProps`

| Prop | Type | Required | Description |
|------|------|----------|-------------|
| `status` | `'success' \| 'pending' \| 'error' \| 'missing'` | ✅ | Determines dot and text color |
| `label` | `string` | ✅ | Display text next to the dot |
| `href` | `string` | ❌ | If provided, wraps the indicator in an external `<a>` tag |

### `StatusIndicator`

Maps each status to ODS design token classes:

| Status | Color Token |
|--------|-------------|
| `success` | `ods-success` (green) |
| `pending` | `ods-warning` (yellow) |
| `error` | `ods-error` (red) |
| `missing` | `ods-warning` (yellow) |

## Usage Example

```typescript
// Static status display
<StatusIndicator status="success" label="Connected" />

// Error state
<StatusIndicator status="error" label="Service Unavailable" />

// Clickable indicator linking to an external resource
<StatusIndicator
  status="pending"
  label="Awaiting Approval"
  href="https://dashboard.example.com/approvals/123"
/>

// Missing configuration
<StatusIndicator status="missing" label="API Key Not Set" />
```

## Notes

- Uses `"use client"` — must run in a browser context (Next.js App Router).
- The `href` variant opens in a new tab with `rel="noopener noreferrer"` for security.
- Color tokens (`ods-success`, `ods-warning`, `ods-error`) are defined in the ODS (OpenFrame Design System) Tailwind config. Ensure the theme is loaded in your Tailwind setup.
