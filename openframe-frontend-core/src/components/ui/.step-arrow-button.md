A client-side React button: THE previous / next arrow that steps through slides.

## Key Components

### `StepArrowButton`

A `forwardRef` wrapper over the lib's `Button` with `variant="stepper"` (a round 36px control: the card surface with a border, the accent border and glyph on hover, faded when disabled) and the chevron that points the way it moves. `SnapCarouselControls` draws its two arrows with it, and so does a presentation's navbar (the company-hub deck). The navbar's other round controls (pause, fullscreen) are `Button variant="stepper"` directly. A `CardsStrip`'s floating arrows are a different control (the outline icon button over the cards).

| Prop | Type | Default | Description |
|---|---|---|---|
| `direction` | `'previous' \| 'next'` | — | Which way it moves; the chevron points that way |
| `aria-label` | `string` | — | Required: the button is a glyph only |
| `glyph` | `ReactNode` | the chevron | A glyph for a step that does something else (a deck's "skip to end" at its start) |
| `className` | `string` | — | Layout only |

Every other `<button>` attribute (`onClick`, `disabled`, …) passes through.

## Usage Example

```tsx
<StepArrowButton direction="previous" aria-label="Previous" disabled={index === 0} onClick={goBack} />
<StepArrowButton direction="next" aria-label="Next" disabled={index === count - 1} onClick={goNext} />
```
