A polymorphic chip/tag UI component with multiple visual variants, sizes, and optional icon/close button support.

## Key Components

- **`tagVariants`** — `cva` variant config defining two sizes (`default` 32px, `large` 48px) and nine visual variants: `primary`, `outline`, `success`, `warning`, `error`, `critical`, `grey`, `selected`, `selectedCyan`, and `badge`.
- **`TagProps`** — Interface extending `HTMLAttributes<HTMLDivElement>` with `label`, optional `icon`, `onClose`, `disabled`, `labelClassName`, and `as` (root element override).
- **`Tag`** — The main component. Renders an icon slot, a truncating label, and an optional close button with `XmarkCircleIcon`.

## Usage Example

```typescript
import { Tag } from "./tag"

// Basic tag
<Tag label="Active" variant="success" />

// With icon and close handler
<Tag
  label="Billing"
  variant="outline"
  icon={<BillingIcon />}
  onClose={() => handleRemove("billing")}
/>

// Large selected chip (e.g. tab group)
<Tag label="Monitoring" variant="selected" size="large" />

// Inline tag inside paragraph content (avoids invalid div-in-p hydration)
<Tag label="Beta" variant="badge" as="span" />

// Disabled state
<Tag label="Archived" variant="grey" disabled />
```

## Notes

- The `as` prop accepts `'div'` (default) or `'span'` — use `'span'` when the tag appears inside phrasing content (e.g. `<p>`) to avoid invalid HTML and hydration errors.
- `disabled` applies pointer-events-none and muted styling via `disabledTagClasses` and sets `aria-disabled`.
- The close `<button>` calls `e.stopPropagation()` before invoking `onClose`, preventing unintended parent click handlers from firing.
