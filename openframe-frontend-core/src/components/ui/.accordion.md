Accessible accordion component built on Radix UI primitives, providing collapsible content sections with animated expand/collapse transitions and a rotating chevron indicator.

## Key Components

| Export | Description |
|--------|-------------|
| `Accordion` | Root container (re-export of `AccordionPrimitive.Root`); accepts `type="single"` or `type="multiple"` |
| `AccordionItem` | Individual collapsible section with a bottom border |
| `AccordionTrigger` | Clickable header with a `ChevronDown` icon that rotates 180° when open |
| `AccordionContent` | Animated content panel using `animate-accordion-up/down` Tailwind keyframes |

## Usage Example

```typescript
import {
  Accordion,
  AccordionItem,
  AccordionTrigger,
  AccordionContent,
} from "@/components/ui/accordion"

export function FAQAccordion() {
  return (
    <Accordion type="single" collapsible defaultValue="item-1">
      <AccordionItem value="item-1">
        <AccordionTrigger>What is OpenFrame?</AccordionTrigger>
        <AccordionContent>
          OpenFrame is a unified AI-driven platform for MSP operations.
        </AccordionContent>
      </AccordionItem>

      <AccordionItem value="item-2">
        <AccordionTrigger>How does Mingo AI work?</AccordionTrigger>
        <AccordionContent>
          Mingo AI automates IT support tasks for technicians.
        </AccordionContent>
      </AccordionItem>
    </Accordion>
  )
}
```

## Notes

- **`type="single"`** allows only one open item at a time; **`type="multiple"`** allows several.
- Pass `collapsible` on a `single` accordion to allow closing the active item.
- All components forward refs and accept standard Radix UI props alongside `className` for Tailwind customization.
