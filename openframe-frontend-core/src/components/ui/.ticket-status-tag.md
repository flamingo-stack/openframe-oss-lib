Renders a styled ticket status badge that maps any status string variant (backend enum, chat lowercase, dialog alias) to a canonical display with correct color, label, and icon.

## Key Components

### Types & Exports
- **`TicketStatus`** — Union type of canonical status values: `ACTIVE | AI_ASSISTANCE | TECH_REQUIRED | ON_HOLD | RESOLVED | ARCHIVED`
- **`TicketStatusKind`** — Backend kind enum including `CUSTOM`
- **`TicketStatusInput`** — Shape for raw ticket status fields from the backend (status, statusKind, statusName, statusColor)
- **`TicketStatusTagProps`** — Full props interface for the tag component

### Utility Functions
- **`resolveTicketStatus(status)`** — Normalizes any alias (e.g. `ACTION_REQUIRED`, `open`, `active`) to a canonical `TicketStatus` or `null`
- **`getTicketStatusConfig(status)`** — Returns label, variant, and optional icon for any status string
- **`getTicketStatusTag(status)`** — Drop-in replacement for legacy `getTicketStatusTag` utility
- **`kindToCanonicalStatus(kind)`** — Maps a backend kind to its canonical status
- **`usesCanonicalStatusStyle(kind)`** — Returns `true` for kinds that use system styling over backend color
- **`resolveStatusTagProps(input)`** — Resolves a `TicketStatusInput` into `TicketStatusTag` props

### Component
- **`TicketStatusTag`** — Renders a `Tag` with optional icon, custom hex color with derived hover/active states, and an optional inline dropdown (via `ActionsMenuDropdown`) for in-place status changes

## Usage Example

```typescript
// Basic display
<TicketStatusTag status="RESOLVED" />

// With custom backend color and label override
<TicketStatusTag
  status="TECH_REQUIRED"
  label="Waiting on Client"
  color="#F59E0B"
/>

// Inline status changer with dropdown
<TicketStatusTag
  status={ticket.status}
  options={statusOptions}
  onSelect={(id) => updateStatus(ticket.id, id)}
  isPending={isUpdating}
/>

// Resolve from raw backend fields
const props = resolveStatusTagProps({
  statusKind: 'CUSTOM',
  statusName: 'Escalated',
  statusColor: '#DC2626',
})
<TicketStatusTag {...props} />
```
