Accessible label component built on Radix UI's `LabelPrimitive`, styled with `class-variance-authority` (CVA) to support multiple size and spacing variants.

## Key Components

### `labelVariants`
CVA configuration defining two variant axes:

| Axis | Options | Default |
|------|---------|---------|
| `variant` | `default`, `small` (deprecated alias), `medium` (deprecated alias), `large`, `surface` | `default` |
| `spacing` | `none`, `tight`, `normal`, `loose` | `none` |

### `Label`
A `forwardRef` wrapper around `LabelPrimitive.Root` that merges CVA-generated classes with any additional `className` passed by the consumer.

### `surface`
Every label in the lib is a `Label`: there is no raw `<label>` in a component. A CLICK SURFACE that labels its
control (an adorned field's chrome in `Input` / `Textarea`, a `CheckboxBlock` or `RadioGroup` row, the `TagsManager`
field, a slider's caption row) uses `variant="surface"`: the label element and its control association with no
typography of its own; the call site's `className` draws the surface.

## Usage Example

```typescript
import { Label } from "./label"

// Default label
<Label htmlFor="email">Email address</Label>

// Small label with tight spacing
<Label htmlFor="username" variant="small" spacing="tight">
  Username
</Label>

// Large label with loose spacing
<Label htmlFor="bio" variant="large" spacing="loose">
  Biography
</Label>

// A click surface wrapping its control
<Label variant="surface" htmlFor={id} className="flex w-full items-center gap-3 rounded-md p-3">
  <Checkbox id={id} /> Remember me
</Label>

// With custom class override
<Label htmlFor="name" className="text-red-500">
  Required Field
</Label>
```

## Notes

- Rendered as a client component (`"use client"`).
- Inherits all native `<label>` accessibility behaviours from Radix UI, including automatic association with form controls via `htmlFor`.
- Extend or override styles via the `className` prop; CVA classes are merged using the `cn` utility.
