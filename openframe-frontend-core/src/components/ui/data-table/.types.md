Extends TanStack Table's `ColumnMeta` interface with Flamingo-specific column configuration options, and exports shared filter/breakpoint types used across the data table system.

## Key Components

### Types & Interfaces

- **`TailwindBreakpoint`** — Union type of supported responsive breakpoints: `'md' | 'lg' | 'xl' | '2xl'`
- **`DataTableFilterOption`** — Shape for individual filter dropdown options, containing `id`, `label`, `value` and an optional `count` (rows the option would match, rendered beside the label; expects a self-excluding facet)

### `ColumnMeta` Module Augmentation

Extends `@tanstack/react-table`'s `ColumnMeta` with:

| Property | Type | Description |
|---|---|---|
| `width` | `string` | Tailwind width class (e.g. `'w-40'`, `'flex-1 min-w-0'`) |
| `align` | `'left' \| 'center' \| 'right'` | Cell/header horizontal alignment |
| `hideAt` | `TailwindBreakpoint \| TailwindBreakpoint[]` | Hide column at/below specified breakpoints |
| `alwaysShowHeader` | `boolean` | Keep header visible on tablet even without a filter |
| `filter` | `{ options, placement? }` | Renders a filter dropdown with provided options |
| `sortable` | `boolean` | Opt-in sort indicator on header (default `false`) |
| `cellClassName` | `string` | Extra classes on the body cell wrapper |
| `headerClassName` | `string` | Extra classes on the header cell wrapper |

## Usage Example

```typescript
import type { ColumnDef } from '@tanstack/react-table'
import type { DataTableFilterOption } from './types'

const statusOptions: DataTableFilterOption[] = [
  { id: 'active', label: 'Active', value: 'active' },
  { id: 'inactive', label: 'Inactive', value: 'inactive' },
]

const columns: ColumnDef<MyRow>[] = [
  {
    accessorKey: 'status',
    meta: {
      width: 'w-32',
      align: 'center',
      hideAt: 'md',
      sortable: true,
      filter: { options: statusOptions, placement: 'bottom-start' },
    },
  },
]
```
