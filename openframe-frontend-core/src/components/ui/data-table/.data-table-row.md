Renders a single data table row as a styled card, supporting click handlers, link navigation, compact/auto-height sizing, and optional expandable sub-row content.

## Key Components

- **`DataTableRow`** — Memoized row component (wraps `DataTableRowImpl`) that renders TanStack Table cells inside a rounded card. Exported as `memo`-wrapped but typed as the original generic function.
- **`DataTableRowProps<T>`** — Props interface supporting `row`, `onClick`, `href`, `compact`, `autoHeight`, `className`, and `subRow`.
- **`CellContent`** — Internal helper that wraps primitive (`string` | `number`) cell values in truncated, styled `<span>` elements; passes React node children through unchanged.
- **`handleClick`** — Memoized click handler implementing the click-bubbling protocol: ignores events from portaled descendants outside the row DOM subtree and short-circuits on `[data-no-row-click]` elements.

## Click-Bubbling Protocol

Any interactive element inside a cell that should not trigger row navigation or `onClick` must carry the `data-no-row-click` attribute.

## Usage Example

```typescript
import { DataTableRow } from './data-table-row'

// Basic click handler
<DataTableRow row={row} onClick={(item) => console.log(item)} />

// Link mode (full-card anchor)
<DataTableRow row={row} href={`/items/${row.original.id}`} />

// Link mode with sub-row (link wraps cells only)
<DataTableRow
  row={row}
  href={`/items/${row.original.id}`}
  subRow={<ExpandedDetail item={row.original} />}
/>

// Column with action buttons (opt out of row click)
const columns = [{
  id: 'actions',
  cell: ({ row }) => (
    <div data-no-row-click className="flex gap-2 justify-end">
      <Button onClick={() => edit(row.original)}>Edit</Button>
    </div>
  ),
  meta: { width: 'w-[160px] shrink-0', align: 'right' },
}]
```

## Loading

`row={null}` (or a loading scope) draws the row's own private loading form: the row's card and shells, each visible column a `text-h4` bar, every other row (`loadingIndex`) a secondary line under the first cell, honouring `compact` and `rowHeightClassName`; `cellsClassName` styles its cell shell. `data-*` markers (`data-loading-item`, which the body passes) land on the row's root in both forms.
