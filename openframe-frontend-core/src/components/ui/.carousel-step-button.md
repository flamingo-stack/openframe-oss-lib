A client-side React button: THE previous / next arrow of a carousel's controls row.

## Key Components

### `CarouselStepButton`

A `forwardRef` wrapper over the lib's `Button` with `variant="stepper"` (a round outline with no fill, the card fill on hover, faded when disabled) and the chevron that points the way the carousel moves. `SnapCarouselControls` draws its two arrows with it; any carousel that steps one slide at a time under its track uses it too. A `CardsStrip`'s floating arrows are a different control (the outline icon button over the cards).

| Prop | Type | Default | Description |
|---|---|---|---|
| `direction` | `'previous' \| 'next'` | — | Which way the carousel moves; the chevron points that way |
| `aria-label` | `string` | — | Required: the button is a glyph only |
| `className` | `string` | — | Layout only |

Every other `<button>` attribute (`onClick`, `disabled`, …) passes through.

## Usage Example

```tsx
<CarouselStepButton direction="previous" aria-label="Previous" disabled={index === 0} onClick={goBack} />
<CarouselStepButton direction="next" aria-label="Next" disabled={index === count - 1} onClick={goNext} />
```
