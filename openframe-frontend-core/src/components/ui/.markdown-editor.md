A full-featured Markdown editor component built on top of `@uiw/react-md-editor`, providing theme-aware styling, file/image upload support, paste handling, and auto-scroll during resize drag.

## Key Components

### `MarkdownEditor` (default export)
The primary editor component. Lazily loads `@uiw/react-md-editor` (SSR-safe) and injects scoped CSS overrides that map to ODS design tokens.

### `MarkdownEditorStyles`
Internal component that injects `mdEditorCSS` into `<head>` as a `<style>` tag on mount (idempotent — uses a stable element ID to avoid duplicates).

### `MarkdownEditorProps`
| Prop | Type | Description |
|---|---|---|
| `value` | `string` | Controlled markdown content |
| `onChange` | `(markdown: string) => void` | Called on every edit |
| `placeholder` | `string` | Empty-state hint text |
| `disabled` | `boolean` | Disables the editor |
| `height` | `number` | Initial height in px (default `600`) |
| `minHeight` | `number` | Minimum height in px (default `100`) |
| `onUploadFile` | `(file: File) => Promise<string>` | Upload handler; reveals upload button when provided |
| `onFileUploaded` | `(url, filename) => void` | Post-upload callback |
| `renderPreview` | `(source: string) => React.ReactNode` | Custom preview renderer |

## Usage Example

```typescript
import { MarkdownEditor } from "@/components/markdown-editor"

function MyForm() {
  const [body, setBody] = useState("# Hello\n\nStart writing...")

  const uploadFile = async (file: File): Promise<string> => {
    const form = new FormData()
    form.append("file", file)
    const res = await fetch("/api/upload", { method: "POST", body: form })
    const { url } = await res.json()
    return url
  }

  return (
    <MarkdownEditor
      value={body}
      onChange={setBody}
      placeholder="Write something..."
      height={400}
      onUploadFile={uploadFile}
      onFileUploaded={(url, name) => console.log("Uploaded:", name, url)}
    />
  )
}
```

## Notable Behaviors

- **Paste-to-upload**: Pasting an image from the clipboard triggers `onUploadFile` automatically and inserts the resulting Markdown image link at the cursor.
- **Auto-scroll on resize**: A `requestAnimationFrame` loop detects when the user drags the resize bar near the viewport bottom and scrolls the nearest scrollable ancestor, preventing the handle from going offscreen.
- **Theme tokens**: All CSS overrides use `var(--color-*)` and `var(--ods-*)` CSS custom properties so the editor adapts to light/dark themes without re-mounting.
