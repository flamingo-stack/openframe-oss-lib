A controlled search input component that combines inline tag display with a text search field, supporting overflow handling for tags that exceed available width.

## Key Components

### `TagSearchOption<T>`
Generic interface representing a selectable tag with a `label` (display string) and `value` (typed payload, defaults to `string`).

### `TagSearchInputProps<T>`
Full prop interface for the component, including:
- `tags` / `searchValue` — controlled state for active tags and input text
- `onTagRemove` / `onSearchChange` / `onClearAll` — mutation callbacks
- `limitTags` — `number | "auto"` controlling visible tag count (defaults to `"auto"` for width-based calculation)
- `renderTag` / `getLimitTagsText` — render customization slots

### `TagSearchInput<T>`
The main generic component. Renders a styled input row with:
- A pinned **search icon** (left)
- A **middle zone** containing visible tags, an overflow `+N` badge, and the text input
- A pinned **clear-all button** (right, conditional)
- A **`HiddenTagsPopup`** anchored below the `+N` badge for overflow tags
- Off-screen **measurement containers** used by `useAutoLimitTags` to compute visible tag count

## Usage Example

```typescript
import { TagSearchInput, TagSearchOption } from "./tag-search-input"

const options: TagSearchOption<number>[] = [
  { label: "Billing", value: 1 },
  { label: "Networking", value: 2 },
  { label: "Security", value: 3 },
]

function FilterBar() {
  const [tags, setTags] = useState(options)
  const [search, setSearch] = useState("")

  return (
    <TagSearchInput<number>
      tags={tags}
      searchValue={search}
      onSearchChange={setSearch}
      onTagRemove={(id) => setTags((prev) => prev.filter((t) => t.value !== id))}
      onClearAll={() => { setTags([]); setSearch("") }}
      onSubmit={(val) => console.log("submitted:", val)}
      limitTags="auto"
    />
  )
}
```
