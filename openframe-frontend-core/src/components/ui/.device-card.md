A client-side React card component for displaying device information including OS type, status, last-seen timestamp, and configurable action buttons.

## Key Components

### Interfaces

- **`Device`** — Shape of a device record, including optional `id`, `machineId`, `name`, `type`, `operatingSystem`, `organization`, `status`, `lastSeen`, `tags`, `ipAddress`, `macAddress`, `version`, and `location`.
- **`ActionButton`** — Configuration for a custom action button: `label`, `onClick`, `variant`, and `visible` flag.
- **`DeviceCardProps`** — Extends `React.HTMLAttributes<HTMLDivElement>` with `device`, `actions`, `statusTag`, `onDeviceClick` and `loading`.
- **Class constants** (module-private) — `DEVICE_CARD_FRAME_CLASS`, `DEVICE_CARD_HEAD_ROW_CLASS`, `DEVICE_CARD_NAME_STACK_CLASS`, `DEVICE_CARD_NAME_LINE_CLASS`, `DEVICE_CARD_STATUS_ROW_CLASS`, `DEVICE_CARD_ICON_BOX_CLASS`, `DEVICE_CARD_MORE_BUTTON_CLASS`: the card's boxes, shared by its two forms.

### Component

- **`DeviceCard`** — Renders a bordered card with three rows:
  1. Device type icon, OS icon, device name/organization, and optional action buttons (more, details, custom).
  2. Status tag and the last-seen time in the viewer's zone and locale.
  3. Device tags rendered as outline `Tag` pills.

## Usage Example

```typescript
import { DeviceCard } from './device-card'

export function Example() {
  return (
    <DeviceCard
      device={{
        id: 'dev-001',
        name: 'MacBook Pro',
        operatingSystem: 'macos',
        organization: 'Acme Corp',
        status: 'active',
        lastSeen: new Date(),
        tags: ['managed', 'engineering'],
      }}
      statusTag={{ variant: 'success', label: 'Active' }}
      actions={{
        moreButton: {
          visible: true,
          onClick: () => console.log('More clicked'),
        },
        customActions: [
          { label: 'Connect', onClick: () => console.log('Connect'), visible: true },
        ],
      }}
      onDeviceClick={(device) => console.log('Selected:', device.id)}
    />
  )
}
```

## Loading

`loading` (or a loading scope) keeps the card's ONE structure, inert and `aria-hidden`: the device-type icon, the "more" button, the details button and any custom action are drawn for real; the OS icon, the name, the organization, the status tag (its own `Tag loading`) and the "Last Seen:" time (its label real) are skeletons in the same boxes; the tags row is drawn with one tag (a typical device's), since the card sits in a grid's first screen; each tag carries `data-loading-item` in both forms. The card's `data-*` markers (`data-loading-item`) ride on its root in both forms.
