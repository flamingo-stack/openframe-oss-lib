Accessible alert component with three style variants (`default`, `destructive`, `warning`) built using `class-variance-authority` and React's `forwardRef`.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Alert` | `React.forwardRef` | Root container with `role="alert"`, accepts `variant` prop and optional SVG icon child |
| `AlertTitle` | `React.forwardRef` | Renders as `<h5>` for the alert heading |
| `AlertDescription` | `React.forwardRef` | Body text container with relaxed line-height for paragraph children |
| `alertVariants` | `cva` config | CVA variant map driving Tailwind classes for each alert style |

### Variants

| Variant | Use Case |
|---------|----------|
| `default` | General informational messages |
| `destructive` | Errors or dangerous actions |
| `warning` | Cautionary notices (uses ODS warning tokens) |

## Usage Example

```typescript
import { Alert, AlertTitle, AlertDescription } from "./components/ui/alert"
import { AlertTriangle } from "lucide-react"

// Default
<Alert>
  <AlertTitle>Heads up</AlertTitle>
  <AlertDescription>Your session will expire in 5 minutes.</AlertDescription>
</Alert>

// Destructive with icon
<Alert variant="destructive">
  <AlertTriangle className="h-4 w-4" />
  <AlertTitle>Error</AlertTitle>
  <AlertDescription>Failed to sync device inventory.</AlertDescription>
</Alert>

// Warning
<Alert variant="warning">
  <AlertTitle>License expiring</AlertTitle>
  <AlertDescription>Renew within 7 days to avoid service interruption.</AlertDescription>
</Alert>
```

> **Icon support:** Placing an SVG/icon as a direct child of `Alert` automatically positions it absolutely at top-left and offsets sibling content via the `[&>svg~*]:pl-7` selector — no extra wrapper needed.
