Deprecated legacy table type definitions for the OpenFrame component library. All exports have been superseded by the `data-table` package and are retained only for backward compatibility.

> ⚠️ **All types in this file are deprecated.** Migrate to the equivalent types exported from `data-table`.

## Key Components

| Type | Description |
|---|---|
| `TailwindBreakpoint` | Union of responsive breakpoints (`'md' \| 'lg' \| 'xl' \| '2xl'`) |
| `TableColumn<T>` | Column definition with sorting, filtering, responsive hiding, and custom cell/header renderers |
| `FilterOption` | Single filter choice with `id`, `label`, and `value` |
| `FilterSection` | Groups filter options by UI type (`checkbox`, `radio`, `select`) |
| `TableFilters` | Map of column keys to arrays of active filter values |
| `CursorPagination` | Cursor-based pagination config with navigation callbacks |
| `PagePagination` | Page-number pagination config |
| `InfiniteScrollConfig` | Infinite scroll trigger config with load-more callback |
| `TableProps<T>` | Root table configuration — data, columns, sorting, filtering, selection, pagination, and animation |
| `BulkAction<T>` | Action applied to all selected rows |
| `RowAction<T>` | Per-row action with variant and mobile visibility control |
| `TableHeaderProps<T>` | Props for the table header sub-component |
| `TableRowProps<T>` | Props for individual row rendering, including optional FLIP reorder animation |
| `TableCellProps` | Props for a single table cell |
| `TableCardSkeletonProps` | Loading skeleton configuration |
| `TableEmptyStateProps` | Empty state configuration with optional action |

## Usage Example

```typescript
import type {
  TableColumn,
  TableProps,
  CursorPagination,
} from './types'

// ⚠️ Deprecated — prefer imports from `data-table`
interface Device {
  id: string
  name: string
  status: 'online' | 'offline'
}

const columns: TableColumn<Device>[] = [
  {
    key: 'name',
    label: 'Device Name',
    sortable: true,
    width: 'flex-1',
  },
  {
    key: 'status',
    label: 'Status',
    align: 'center',
    hideAt: 'md',
    renderCell: (item) => <StatusBadge status={item.status} />,
  },
]

const pagination: CursorPagination = {
  hasNextPage: true,
  endCursor: 'cursor_abc123',
  onNext: (cursor) => fetchDevices({ after: cursor }),
  itemName: 'devices',
}

const tableProps: TableProps<Device> = {
  data: devices,
  columns,
  rowKey: 'id',
  cursorPagination: pagination,
  onRowClick: (device) => router.push(`/devices/${device.id}`),
  animateRowReorder: !prefersReducedMotion,
}
```
