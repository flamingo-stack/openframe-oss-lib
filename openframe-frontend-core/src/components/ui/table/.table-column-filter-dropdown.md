Renders a deprecated column-level filter dropdown for tables, wrapping `FiltersDropdown` with a labeled trigger button and checkbox-based filter sections.

## Key Components

### `TableColumnFilterDropdownProps`
| Prop | Type | Description |
|---|---|---|
| `columnKey` | `string` | Key used to read/write filter state |
| `columnLabel` | `string` | Display label and accessibility text |
| `filterOptions` | `FilterOption[]` | Available checkbox options for the column |
| `filters` | `TableFilters` | Current filter state across all columns |
| `onFilterChange` | `(filters: TableFilters) => void` | Callback when filters are applied or reset |
| `placement` | `'bottom-start' \| 'bottom-end' \| 'bottom'` | Dropdown anchor position (default: `'bottom-start'`) |
| `dropdownClassName` | `string` | Extra class on the dropdown (default: `'min-w-[240px]'`) |

### `TableColumnFilterDropdown`
Renders a clickable label + `Filter02Icon` trigger. The icon turns accent-colored when one or more filters are active (`activeCount > 0`). Applies or resets filters scoped to the given `columnKey` without mutating other column filter state.

> **Deprecated:** Use `DataTableColumnFilter` from `data-table` instead.

## Usage Example

```typescript
import { TableColumnFilterDropdown } from './table-column-filter-dropdown'

const [filters, setFilters] = useState<TableFilters>({})

<TableColumnFilterDropdown
  columnKey="status"
  columnLabel="Status"
  filterOptions={[
    { label: 'Active', value: 'active' },
    { label: 'Inactive', value: 'inactive' },
  ]}
  filters={filters}
  onFilterChange={setFilters}
  placement="bottom-start"
/>
```

## Notes

- Both the interface and the component are marked `@deprecated`. Migrate to `DataTableColumnFilter` from the `data-table` package.
- Filter state is immutable per column: applying updates only `columnKey`'s values; resetting deletes the key without affecting sibling columns.
