The loading rows of `Table`, laid out exactly as `TableRow` lays out a loaded row. Internal to the table: `Table` draws them itself while `loading` (one full page), and the `table` barrel does not export `TableCardSkeleton`. New tables use `DataTable.Body loading` from `data-table`.

## Key Components

### `TableCardSkeleton` *(internal)*
Renders `n` skeleton card rows (through `LoadingItems`, each marked `data-loading-item`) in `TableRow`'s own frame, each column at its own width: the synthetic actions column (`__actions__`) as one button per row action (icon buttons for icon-only actions) and the chevron column (`__chevron__`) as an icon button.

**Props** (`TableCardSkeletonProps`):

| Prop | Type | Default | Description |
|---|---|---|---|
| `columns` | `Column[]` | — | The rows' columns with `key`, optional `width` and `hideAt`, synthetic columns included |
| `rows` | `number` | `10` | Number of skeleton rows to render |
| `compact` | `boolean` | `false` | A compact table's row height |
| `actions` | `{ iconOnly: boolean }[]` | — | The actions column's buttons; absent: one icon button (`renderRowActions`) |
| `selectable` | `boolean` | `false` | The selection checkbox column |
| `className` | `string` | — | Extra classes on the row wrapper |
| `rowClassName` | `string` | — | Extra classes on the inner flex row |

### Constants *(deprecated)*
- `ROW_HEIGHT_DESKTOP` / `ROW_HEIGHT_MOBILE` — read from the data table's row class set (`data-table/data-table-row-classes`), re-exported by the `table` barrel

### Row classes (module exports, read by `TableRow` too)
- `TABLE_ROW_FRAME_CLASS` — the row card (frame and surface), one box in both forms
- `TABLE_ROW_CELLS_CLASS` — the cells' row inside the card (inset and column gap)
- `tableRowHeightClass(compact)` — the cells' height in both forms: a compact row's padding and `COMPACT_ROW_MIN_HEIGHT` floor, else the design height; read by `TableRow` and this skeleton
- `TABLE_SKELETON_ROWS` — rows drawn when the table knows no page size (a typical count for an unpaged table)

**Primary column detection:** The component automatically identifies the widest (`flex-1` or `flex-[n]`) column as "primary" and renders a second skeleton line on every other row to simulate multi-line content.

## Usage Example

```typescript
// Hosts render the table itself; it draws these rows while loading
<Table columns={columns} data={[]} loading />

// Inside table.tsx only
const columns = [
  { key: 'avatar', width: 'w-10' },
  { key: 'name',   width: 'flex-1' },
  { key: 'status', width: 'w-24' },
  { key: '__actions__', width: 'w-32 shrink-0 flex-none' },
  { key: '__chevron__', width: 'w-12 shrink-0 flex-none' },
]

<TableCardSkeleton
  columns={columns}
  rows={5}
  actions={[{ iconOnly: false }]}
/>
```

> New tables: use `DataTable.Body loading` from the `data-table` package.
