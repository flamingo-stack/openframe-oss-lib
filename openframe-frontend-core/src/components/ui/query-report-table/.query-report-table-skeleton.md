The loading form of `QueryReportTable`, rendering animated placeholder rows and columns while data is being fetched. Internal to the table: `QueryReportTable` draws it itself (with `loading`, or in a `LoadingScope`), and the query-report-table barrel does not export it.

## Key Components

**`QueryReportTableSkeleton`** — The module's component (used by `QueryReportTable` only). Renders a configurable grid of pulsing skeleton cells mimicking the table's header and row structure.

**Props (`QueryReportTableSkeletonProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `rows` | `number` | Number of skeleton rows to render |
| `columns` | `number` | Number of skeleton columns per row |
| `columnWidth` | `number \| string` | Fixed width applied to each column cell |
| `variant` | `'default' \| 'compact'` | Controls row height, spacing, and border style |
| `className` | `string` | Optional additional CSS classes |

**Variants:**
- **`default`** — Taller rows (`80px`), card-style bordered containers with rounded corners
- **`compact`** — Shorter rows (`56px`), flat bottom-border separators with tighter spacing

## Usage Example

```typescript
// Hosts render the table itself: it draws this form while loading
<QueryReportTable data={[]} loading />

// Inside query-report-table.tsx only
<QueryReportTableSkeleton rows={5} columns={4} columnWidth={180} variant="compact" />
```

> The header sits directly on the rows (as the loaded table's does), and the rows share the loaded row's boxes (`queryReportRowFrameClass`, `queryReportRowCellsClass`, `queryReportHeaderClass`, `queryReportRowsClass`, `QUERY_REPORT_CELL_CLASS`, `QUERY_REPORT_HEADER_CELL_CLASS` from `query-report-table-row`, built on the data table's row class set). Bars are `TextLineSkeleton`s of each cell's type step.

> **Note:** Cell placeholder widths vary pseudo-randomly per row/column using `(rowIndex * colIndex * 7) % 35` to produce a more natural-looking skeleton rather than uniform bars.
