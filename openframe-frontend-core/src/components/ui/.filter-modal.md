A modal dialog component for sorting and filtering table data, supporting checkbox filter groups, column sorting, tag key-value filters, and date range filtering with draft state management.

## Key Components

### Interfaces

| Interface | Description |
|---|---|
| `FilterModalOption` | Single filter option with `id`, `label`, and optional `count` |
| `FilterGroup` | Named group of `FilterModalOption` items |
| `FilterModalProps` | Full props definition for the modal |

### Exported Types (re-exported)

- `SortableColumn`, `SortConfig`, `SortDirection` — from `sort-column-item`
- `TagKeyConfig`, `TagValueOption` — from `tag-key-value-filter`

### Behavior

- **Draft state**: All selections are held locally and only committed on **Apply**; **Reset** clears all filters to defaults and closes the modal.
- **Scroll shadows**: `useScrollFade` adds top/bottom fade overlays as the filter list scrolls.
- **Loading state**: When `isLoading` is true, renders skeleton rows instead of filter content.
- **Empty state**: Renders an icon + message when no sort columns, filter groups, tag filters, or date filter are provided.

## Usage Example

```typescript
<FilterModal
  isOpen={isFilterOpen}
  onClose={() => setFilterOpen(false)}
  filterGroups={[
    {
      id: 'status',
      title: 'Status',
      options: [
        { id: 'active', label: 'Active', count: 12 },
        { id: 'inactive', label: 'Inactive', count: 4 },
      ],
    },
  ]}
  currentFilters={activeFilters}
  onFilterChange={(filters) => setActiveFilters(filters)}
  sortConfig={{
    title: 'Sort By',
    sortBy: 'createdAt',
    sortDirection: 'desc',
    columns: [{ key: 'createdAt', label: 'Created Date' }],
  }}
  onSort={(column, direction) => handleSort(column, direction)}
  dateFilter={{
    title: 'Created Date',
    sort: 'desc',
    onChange: ({ sort, range }) => handleDateFilter(sort, range),
  }}
/>
```
