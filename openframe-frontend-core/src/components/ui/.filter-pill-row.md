A responsive filter pill row component that renders a labeled set of toggle buttons inside a card container, used to filter catalog views by status, platform, section, or other dimensions.

## Key Components

### Interfaces

| Interface | Description |
|---|---|
| `FilterPillRowOption` | Shape for each filter option: `value` (key) and `label` (display text) |
| `FilterPillRowProps` | Full props contract for `FilterPillRow` |

### `FilterPillRow` (named export)

Renders a flex-wrap card containing:
- A `Filter` icon + label on the left
- A pill button per option (active pill uses `accent` variant, inactive uses `outline`)
- An optional `countLabel` right-aligned (e.g. `"Showing 1-10 of 42 items"`)
- Optional `children` to replace the default pill buttons with custom filter content

## Usage Example

```typescript
import { FilterPillRow } from '@openframe-oss-lib/ui'

const PLATFORM_OPTIONS = [
  { value: 'all',     label: 'All'     },
  { value: 'windows', label: 'Windows' },
  { value: 'mac',     label: 'macOS'   },
  { value: 'linux',   label: 'Linux'   },
]

export function ToolCatalogFilters() {
  const [platform, setPlatform] = useState('all')

  return (
    <FilterPillRow
      label="Platform"
      selectedValue={platform}
      onValueChange={setPlatform}
      options={PLATFORM_OPTIONS}
      countLabel="Showing 12 of 48 tools"
    />
  )
}
```

**Custom content via `children`:**

```typescript
<FilterPillRow label="Status" selectedValue="" onValueChange={() => {}}>
  <MyCustomToggleGroup />
</FilterPillRow>
```

> **Note:** When `children` is provided it replaces the auto-generated pill buttons entirely; `options` is ignored.
