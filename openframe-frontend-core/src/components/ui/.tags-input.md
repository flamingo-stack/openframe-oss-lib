A client-side React component for managing a list of string tags with add/remove functionality, keyboard support, and optional tag limits.

## Key Components

### `TagsInput` (exported function)

A controlled input component that renders a text field with an "Add" button, a collection of removable badge tags, and an optional tag counter.

**Props (`TagsInputProps`):**

| Prop | Type | Default | Description |
|---|---|---|---|
| `value` | `string[]` | `[]` | Current list of tags (controlled) |
| `onChange` | `(tags: string[]) => void` | — | Callback fired when tags change |
| `placeholder` | `string` | `"Add a tag..."` | Input placeholder text |
| `className` | `string` | — | Wrapper `div` class override |
| `disabled` | `boolean` | `false` | Disables input and remove buttons |
| `maxTags` | `number` | — | Maximum number of allowed tags |
| `inputClassName` | `string` | — | Additional classes for the `Input` |
| `badgeClassName` | `string` | — | Additional classes for each `Badge` |
| `label` | `string` | — | Optional label rendered above the input |

**Behaviors:**
- Duplicate tags are silently rejected
- Tags are added via the **Add** button or by pressing `Enter`
- Input and Add button are automatically disabled when `maxTags` is reached
- A `{current}/{max} tags` counter is shown when `maxTags` is set

## Usage Example

```typescript
import { TagsInput } from "@/components/ui/tags-input"
import { useState } from "react"

export function MyForm() {
  const [tags, setTags] = useState<string[]>(["typescript", "react"])

  return (
    <TagsInput
      label="Technologies"
      value={tags}
      onChange={setTags}
      placeholder="Add a technology..."
      maxTags={5}
    />
  )
}
```
