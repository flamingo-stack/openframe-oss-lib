A layout wrapper component that adds an optional label above and a status message below any form field, handling the visual chrome (label + feedback text) while letting the field itself remain unstyled.

## Key Components

### `FieldWrapper`
A `forwardRef` component that wraps form fields with consistent label and feedback message rendering.

**Props (`FieldWrapperProps`)**

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `label` | `string` | — | Label text rendered above the field |
| `error` | `string` | — | Status/feedback message rendered below the field |
| `errorVariant` | `"error" \| "warning" \| "success" \| "muted"` | `"error"` | Color variant for the feedback message |
| `className` | `string` | — | Additional class applied to the outer wrapper |
| `children` | `React.ReactNode` | — | The field element(s) to wrap |

**Behavior:**
- When neither `label` nor `error` is present, the wrapper renders as `contents` (no layout box introduced).
- When either exists, it renders as a full-width flex column.
- The feedback message clamps to 2 lines with ellipsis; the full text is accessible via the native `title` tooltip.

**Color Variants:**

| Variant | Color token |
|---------|------------|
| `error` | `text-ods-error` |
| `warning` | `text-ods-warning` |
| `success` | `text-ods-success` |
| `muted` | `text-ods-text-secondary` |

## Usage Example

```typescript
import { FieldWrapper } from "@openframe-oss-lib/components"

// Basic usage with label and error feedback
<FieldWrapper label="Email address" error="Invalid email format">
  <input type="email" className="..." />
</FieldWrapper>

// Success state after validation
<FieldWrapper
  label="Username"
  error="Username is available!"
  errorVariant="success"
>
  <input type="text" className="..." />
</FieldWrapper>

// Passthrough — no wrapper box introduced in the DOM
<FieldWrapper>
  <input type="text" className="..." />
</FieldWrapper>
```
