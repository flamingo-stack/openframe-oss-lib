A client-side React component that renders a single row in a ticket status configuration UI, supporting both system-defined and custom ticket statuses with reordering, color picking, and delete controls.

## Key Components

### `TicketStatusConfigRow`
The primary exported component. Renders a row containing:
- **Drag handle** — interactive for custom rows, decorative/disabled for system rows. The whole rail is rendered only while `useDragAndDropEnabled()` holds; on touch/narrow viewports it disappears and the `moveButtons` node (an up/down `SortableMoveButtons` pair handed in by `TicketStatusConfigList`) renders beside the delete button instead
- **Name input** — editable for custom, read-only for system rows; carries a visible "Status Name" label (the rail, chip and controls offset below the label line to align with the field)
- **Color controls** — `ColorPresetSelect` (labelled "Color") and `ColorPickerInput` shown only for custom rows with color support
- **Live preview** — `TicketStatusTag` reflecting current name and color. Inline right on desktop (lg+); below the fields on tablet (own row, right-aligned) and mobile (beside the color select). System rows keep it beside the name everywhere
- **Transparent background** — only the border outlines the row; the dragged row gets an opaque `bg-ods-bg` so it can travel over siblings
- **Action button** — info tooltip icon for system rows; delete button (with optional disabled state tooltip) for custom rows

### `WithLeftTooltip` (internal)
A touch-aware tooltip wrapper that ensures only one tooltip is open at a time via a module-level `dismissOpenTooltip` ref. Renders children unchanged when no `content` is provided.

### `TicketStatusConfigRowProps`
The full props interface, key fields:

| Prop | Description |
|---|---|
| `variant` | `'system'` or `'custom'` — controls editability and available actions |
| `statusKey` | Canonical key forwarded to `TicketStatusTag` |
| `onColorChange` | Callback receiving `{ color, preset? }` |
| `dragHandleProps` | `SortableDragHandleProps` from `useSortableItem` (spread whole onto the grip) |
| `moveButtons` | Touch fallback node (`SortableRowRenderArgs.moveButtons`), rendered beside delete |
| `deleteDisabledReason` | Shown as tooltip when delete is disabled |
| `isDragging` | Applies visual feedback during drag |

## Usage Example

```typescript
import { TicketStatusConfigRow } from './ticket-status-config-row'

// Custom row with color picker and delete
<TicketStatusConfigRow
  variant="custom"
  statusKey="row-uuid-123"
  name={statusName}
  onNameChange={setStatusName}
  color={color}
  presetKey={preset}
  onColorChange={({ color, preset }) => {
    setColor(color)
    setPreset(preset)
  }}
  onDelete={handleDelete}
  deleteDisabled={isOnlyStatus}
  deleteDisabledReason="At least one status is required"
  dragHandleProps={dragHandleProps}
  isDragging={isDragging}
  moveButtons={moveButtons}
/>

// System row (read-only, no delete)
<TicketStatusConfigRow
  variant="system"
  statusKey="RESOLVED"
  name="Resolved"
  systemTooltip="Built-in status — cannot be removed"
  systemTagVariant="outline"
/>
```
