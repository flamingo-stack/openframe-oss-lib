Client-side color selection components providing both a preset-based dropdown selector and a full-featured color picker with HEX/RGB/HSL input support.

## Key Components

### Exports & Constants

| Name | Type | Description |
|---|---|---|
| `ColorPreset` | Interface | Shape for a color preset entry (`key`, `label`, `color`) |
| `TICKET_STATUS_COLOR_PRESETS` | `readonly ColorPreset[]` | 12-color palette for ticket status use |
| `CUSTOM_PRESET_KEY` | `string` | Sentinel key `'custom'` for user-defined colors |
| `DEFAULT_CUSTOM_STATUS_COLOR` | `string` | Fallback hex `#888888` for custom presets |
| `ColorPresetSelect` | Component | Dropdown to pick from named presets or switch to custom |
| `ColorPickerInput` | Component | Popover with a saturation/hue canvas and HEX/RGB/HSL text inputs |

### Internal Helpers

- **`HexInputs`** — controlled text input with draft state; validates against `HEX_PATTERN` on blur/Enter
- **`ChannelInput`** — numeric-only input clamped to `[min, max]`; used by RGB and HSL rows
- **`RgbInputs`** / **`HslInputs`** — three-channel rows converting to/from hex via `ods-color-utils`

## Usage Example

```typescript
import {
  ColorPresetSelect,
  ColorPickerInput,
  TICKET_STATUS_COLOR_PRESETS,
} from './color-preset-select'

// Preset selector (e.g. ticket status badge color)
<ColorPresetSelect
  value={color}
  presetKey={presetKey}
  presets={TICKET_STATUS_COLOR_PRESETS}
  onChange={({ color, preset }) => {
    setColor(color)
    setPresetKey(preset)
  }}
/>

// Free-form color picker (always works in hex)
<ColorPickerInput
  value={color}          // "#5ea62e"
  onChange={setColor}    // receives hex string
/>
```

> **Note:** Both components use `value`/`onChange` in hex (`#rrggbb`). Color space conversions (RGB ↔ HSL ↔ hex) are handled internally via `utils/ods-color-utils`.
