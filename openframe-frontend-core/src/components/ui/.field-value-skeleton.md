The bar a field draws for its value (or placeholder) while it loads: a `text-h4` `TextLineSkeleton` sized by `FIELD_VALUE_SKELETON_CLASS`.

## Key Components

### `FieldValueSkeleton`
No props. Drawn in the value slot of `Input`, `SelectTrigger` and `InputTrigger` when they are in a loading scope; their box, label and adornments stay real. Every field therefore draws the same bar in the same place.

## Usage Example

```tsx
import { FieldValueSkeleton } from './field-value-skeleton';

{inScope ? <FieldValueSkeleton /> : value}
```
