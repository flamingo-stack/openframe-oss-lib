Accessible breadcrumb navigation component built on native HTML elements with Radix UI's `Slot` primitive for flexible rendering.

## Key Components

| Export | Element | Purpose |
|---|---|---|
| `Breadcrumb` | `<nav>` | Root wrapper with `aria-label="breadcrumb"` |
| `BreadcrumbList` | `<ol>` | Ordered list of breadcrumb items |
| `BreadcrumbItem` | `<li>` | Individual breadcrumb entry |
| `BreadcrumbLink` | `<a>` / Slot | Clickable navigation link; supports `asChild` for custom renderers |
| `BreadcrumbPage` | `<span>` | Current page indicator (`aria-current="page"`, non-interactive) |
| `BreadcrumbSeparator` | `<li>` | Decorative divider; defaults to `ChevronRight`, accepts custom children |
| `BreadcrumbEllipsis` | `<span>` | Collapsed items indicator using `MoreHorizontal` icon |

## Usage Example

```typescript
import {
  Breadcrumb,
  BreadcrumbList,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbPage,
  BreadcrumbSeparator,
  BreadcrumbEllipsis,
} from "@openframe-oss-lib/ui"

export function Nav() {
  return (
    <Breadcrumb>
      <BreadcrumbList>
        <BreadcrumbItem>
          <BreadcrumbLink href="/">Home</BreadcrumbLink>
        </BreadcrumbItem>
        <BreadcrumbSeparator />
        <BreadcrumbItem>
          <BreadcrumbEllipsis />
        </BreadcrumbItem>
        <BreadcrumbSeparator />
        <BreadcrumbItem>
          <BreadcrumbLink href="/settings">Settings</BreadcrumbLink>
        </BreadcrumbItem>
        <BreadcrumbSeparator />
        <BreadcrumbItem>
          <BreadcrumbPage>Profile</BreadcrumbPage>
        </BreadcrumbItem>
      </BreadcrumbList>
    </Breadcrumb>
  )
}
```

**Notes:**
- `BreadcrumbLink` accepts `asChild` to delegate rendering to a child component (e.g., Next.js `<Link>`).
- `BreadcrumbSeparator` renders a custom separator when provided children.
- All components forward refs and accept standard HTML element props.
