A label and its value joined by a leader line (Figma `info-card` row): the quiet label, a hairline that takes the free space, the value, and a status mark at the end. One line, always: a long value clips.

## Key Components

### `LeaderRow`
| Prop | Type | Description |
|------|------|-------------|
| `label` | `ReactNode` | The quiet label |
| `value` | `ReactNode` | The value |
| `status` | `ReactNode` | A 16px mark after the value |
| `as` | `'div' \| 'li'` | The row's element (default `div`) |
| `labelTone` | `'secondary' \| 'primary'` | The label's tone |
| `valueTone` | `'primary' \| 'secondary' \| 'warning'` | The value's tone |
| `loading` | `boolean` | The value is still being read |

### `LeaderRowSkeleton` (deprecated)
Renders `<LeaderRow loading />`.

## Loading

`loading` (or a loading scope when the value is empty): ONE structure. The label is drawn for real (a bar when empty), the hairline real, the value a bar of the row's type step, the status a 16px box when the row has one.

## Usage Example

```tsx
<LeaderRow label="Plan" value={plan?.name} status={<CheckIcon size={16} />} loading={!plan} />
```
