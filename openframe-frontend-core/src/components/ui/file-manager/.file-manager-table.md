A client-side React component that renders a file manager table with selection, its own loading state, and the height its parent gives it.

## Key Components

- **`FileManagerTable`** — Main exported component that handles file listing, multi-select, and adaptive layout
- **`allSelected` / `someSelected`** — Memoized booleans driving the header checkbox's checked/indeterminate state
- **Height** — `h-full`: the table takes its parent's height in both forms and its rows scroll inside, under the header. It never measures the window, so a docked composer or padding below the parent does not hide the last rows; a parent of no definite height lets it grow with its rows
- **Corners**: the frame clips (`overflow-hidden`), so the header and the rows meet the border's inner curve; neither carries its own rounding, which at the frame's radius would leave a sliver of the frame's fill at each corner. The row menu is portalled, so nothing needs to float out
- **Loading state** — ONE switch (`useLoadingScope() || loading`): the same container and ONE header (column labels real, the select-all checkbox real and inert), then `FILE_MANAGER_SKELETON_ROWS` rows (a typical folder: a folder listing has no page size) drawn through `LoadingItems` as `<FileManagerTableRow loading data-loading-item />`
- **`FILE_MANAGER_SKELETON_ROWS`** — The typical row count above (module-private)
- **`FileManagerEmpty`** — Rendered when not loading and `files.length === 0`
- **`FileManagerTableRow`** — Per-row component receiving selection, click, double-click, and action handlers

## Props (`FileManagerTableProps`)

| Prop | Description |
|---|---|
| `files` | Array of file/folder items to display |
| `selectedFiles` | Array of selected file IDs |
| `showCheckboxes` | Toggle selection checkboxes (default: `true`) |
| `loading` | The folder is being read: draws the loading rows (default: `false`; a loading scope does the same) |
| `isSearchResult` | Renders file path subtitles and changes click behavior |
| `onSelectFile` | Called with `(id, selected)` on row checkbox change |
| `onSelectAll` | Called with `(checked)` on header checkbox change |
| `onFileClick` | Called on single-click (search result mode) |
| `onFolderOpen` | Called when a folder row is clicked or double-clicked |
| `onFileAction` | Called with `(action, fileId)` on action button interaction |

## Usage Example

```typescript
import { FileManagerTable } from './file-manager-table'

function MyFileManager() {
  const [selectedFiles, setSelectedFiles] = useState<string[]>([])

  const handleSelectFile = (id: string, selected: boolean) => {
    setSelectedFiles(prev =>
      selected ? [...prev, id] : prev.filter(f => f !== id)
    )
  }

  const handleSelectAll = (checked: boolean) => {
    setSelectedFiles(checked ? files.map(f => f.id) : [])
  }

  return (
    <FileManagerTable
      files={files}
      selectedFiles={selectedFiles}
      loading={false}
      isSearchResult={false}
      onSelectFile={handleSelectFile}
      onSelectAll={handleSelectAll}
      onFolderOpen={(folder) => console.log('Open folder', folder.id)}
      onFileAction={(action, id) => console.log(action, id)}
    />
  )
}
```
