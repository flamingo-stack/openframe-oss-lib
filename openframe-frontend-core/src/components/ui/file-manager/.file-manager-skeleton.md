**Deprecated.** `FileManagerSkeleton` is an alias of `<FileManager loading … />` with nothing read yet: the file manager draws its own loading state (one tree, so nothing remounts when the folder answers).

## Key Components

### `FileManagerSkeleton` (deprecated)

Renders `<FileManager loading region={region} files={[]} currentPath="" selectedFiles={[]} showSearch={showSearch} showActions={showActions} />`.

**Props (`FileManagerSkeletonProps`):**

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `region` | `boolean` | `true` | The loading state announces itself ("Loading files"); `false` inside another loading region |
| `showSearch` | `boolean` | `true` | Draws the search field (real, inert) |
| `showActions` | `boolean` | `true` | Draws the action bar (real, inert) |

The former `rows` prop is gone: a loading folder draws `FILE_MANAGER_SKELETON_ROWS` (a typical folder, declared in `file-manager-table.tsx`), since a folder listing has no page size.

## Usage Example

```tsx
import { FileManager } from '@flamingo-stack/openframe-frontend-core/components/ui'

// Instead of <FileManagerSkeleton />, render the file manager itself while the folder is read:
<FileManager loading={isLoading} files={files} currentPath={path} selectedFiles={selected} />
```
