Renders a navigable breadcrumb trail for the file manager, displaying hierarchical path segments as clickable buttons separated by chevron icons.

## Key Components

- **`FileManagerBreadcrumb`** — Main export; a `<nav>`-based breadcrumb component that maps over `items` to render path segments with `ChevronRight` separators.
- **`FileManagerBreadcrumbProps`** — Type contract imported from `./types`, defining `items`, `onItemClick`, and `className` props.

## Usage Example

```typescript
import { FileManagerBreadcrumb } from './file-manager-breadcrumb'

const breadcrumbItems = [
  { label: 'Root', path: '/' },
  { label: 'Documents', path: '/documents' },
  { label: 'Reports', path: '/documents/reports' },
]

<FileManagerBreadcrumb
  items={breadcrumbItems}
  onItemClick={(path) => console.log('Navigate to:', path)}
  className="my-2"
/>
```

## Behavior Notes

- The **last item** receives `font-medium` styling to visually indicate the current location.
- `onItemClick` is optional (`?.`), so the component renders safely without a click handler.
- Chevron separators are suppressed for the first item (`index > 0` guard).
- Layout uses `flex-wrap` with `break-words`/`break-all` to handle long paths gracefully on narrow viewports.
