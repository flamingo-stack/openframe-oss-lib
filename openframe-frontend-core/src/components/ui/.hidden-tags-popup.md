A floating popup component that displays a list of hidden/overflow tags with optional removal capability, typically used when tag inputs have more items than visible space allows.

## Key Components

### Interfaces

- **`HiddenTagItem`** — Describes a single tag entry with a `label` (`ReactNode`) and `value` (`unknown`)
- **`HiddenTagsPopupProps`** — Props for the popup component:
  - `items` — Array of `HiddenTagItem` to render
  - `onRemove` — Optional callback fired with the item's `value` when the remove button is clicked
  - `disabled` — Hides remove buttons when `true`
  - `className` / `style` — For positioning overrides (consumers set `style.left` or `className` for alignment)

### Component

- **`HiddenTagsPopup`** — A `forwardRef` div that renders absolutely below its anchor (`top-full`), with an animated entrance (`animate-in fade-in-0 zoom-in-95`). Each item row shows a truncated, uppercase label and an `XmarkCircleIcon` remove button (when not disabled).

## Usage Example

```typescript
import { HiddenTagsPopup } from "./hidden-tags-popup"

const overflowTags = [
  { label: "Engineering", value: "engineering" },
  { label: "Design", value: "design" },
]

function TagInput() {
  const handleRemove = (value: unknown) => {
    console.log("Removing tag:", value)
  }

  return (
    <div className="relative">
      {/* anchor element */}
      <HiddenTagsPopup
        items={overflowTags}
        onRemove={handleRemove}
        style={{ left: 0 }}
      />
    </div>
  )
}
```

> **Note:** Wrap the popup in a relatively positioned container. Use `style.left` or a `className` override to control horizontal alignment.
