A small presentational component that renders a square color preview swatch, used as a shared building block across color and status selector UIs.

## Key Components

**`ColorSwatch`** — Default export function component.

**`ColorSwatchProps`** — Interface defining the component's props:

| Prop | Type | Required | Description |
|---|---|---|---|
| `color` | `string` | ✅ | Any valid CSS color value applied as `backgroundColor` |
| `className` | `string` | ❌ | Optional additional Tailwind/CSS classes |

## Usage Example

```typescript
import { ColorSwatch } from './color-swatch'

// Basic usage
<ColorSwatch color="#3B82F6" />

// With custom sizing override
<ColorSwatch color="rgb(239, 68, 68)" className="size-6" />

// Composed inside a status selector
<div className="flex items-center gap-2">
  <ColorSwatch color={selectedStatus.color} />
  <span>{selectedStatus.label}</span>
</div>
```

## Notes

- Renders as an `aria-hidden` `<span>` — purely decorative; excluded from the accessibility tree.
- Default styles: `inline-block`, `16×16px` (`size-4`), `shrink-0`, `rounded-sm`.
- Uses the shared [`cn`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/utils/cn.ts) utility for class merging, so `className` overrides compose cleanly with Tailwind.
