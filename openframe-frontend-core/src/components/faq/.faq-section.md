Renders a grouped, deep-linkable FAQ section with category jump-navigation, scroll-spy active states, hash-based accordion expansion, and optional JSON-LD schema emission.

## Key Components

### `FaqSection` (default export)
The top-level client component that fetches FAQ data via `useSelfFetch`, groups results by section, and renders either a flat or grouped accordion layout depending on whether multiple categories exist.

**Props (`FaqSectionProps`):**

| Prop | Type | Description |
|---|---|---|
| `initialFaqs` | `Faq[]` | SSR hydration seed — skips first client fetch |
| `entityType` / `entityId` | `string` / `number\|string` | Scopes the `/api/faqs` request to a specific entity |
| `heading` | `ReactNode \| null` | Custom heading; `null` = no heading (host owns `<h1>`) |
| `emitJsonLd` | `boolean` | Injects FAQPage `schema.org` JSON-LD `<script>` |
| `jsonLd` | `FaqSchemaOptions` | Overrides for JSON-LD `name`/`description`/`url` |
| `minResults` | `number` | Maps to `?count=` query param |
| `apiBaseUrl` | `string` | Fetch-URL prefix for third-party embeds/proxies |

### `GroupedFaqList` (internal)
Renders category jump-nav pills (`<a href="#slug">`) above stacked accordion sections. Includes:
- **Scroll-spy** via `IntersectionObserver` — highlights the pill for the section in view
- **Hash dispatch** — item hashes (`#faq-item-<id>`) auto-expand the cited accordion row; section hashes (`#faq-<slug>`) activate the matching pill
- `useScrollToHash` with sticky-header offset compensation

### `groupFaqsBySection` (internal)
Pure function that groups `Faq[]` into `FaqGroup[]` ordered by first-seen display order. Uncategorized items (blank/missing `section`) sink to the end.

### `buildFaqsUrl` (internal)
Composes the `/api/faqs` fetch URL via `buildSuggestionUrl`, compatible with `apiBaseUrl`, `entityType`, `entityId`, and `minResults`.

## Usage Example

```typescript
// Server component passes SSR-fetched FAQs; client skips re-fetch
import { FaqSection } from '@openframe-oss-lib/components'

export default async function SupportPage() {
  const faqs = await fetchFaqsForEntity('product', 42)

  return (
    <FaqSection
      initialFaqs={faqs}
      entityType="product"
      entityId={42}
      emitJsonLd
      jsonLd={{ name: 'Product FAQs', url: 'https://example.com/support' }}
      minResults={10}
    />
  )
}
```
