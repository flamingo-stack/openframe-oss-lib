Shared type contracts, constants, and utilities for the OpenFrame ticket system — consumed by both client-side hooks and UI components to describe ticket wire shapes, cache structure, error codes, and UX constants.

## Key Components

### Interfaces

| Name | Purpose |
|---|---|
| `TicketData` | Wire shape of a row from `POST /api/chat/agent/find-ticket`. Mirrors the server's `FindTicketResult` projection intentionally. |
| `TicketAssignedOwner` | Resolved agent profile (name, email, avatar) joined from `hubspot_owners` → `profiles`. |
| `TicketClickupSummary` | Compact projection of a linked ClickUp task for the "Linked delivery" drawer card. |
| `OptimisticTicket` | Extends `TicketData` with `_optimistic: true` for pre-flight list entries before server confirmation. |
| `TicketsCacheSlot` | Shape of a `['tickets', …]` TanStack Query cache slot — prevents the `t.map is not a function` class of cache mutation bugs. |
| `MappedTicketActionError` | Structured error envelope with a typed code, toast copy, and retry/cache-eviction hints. |

### Types & Union

- **`AnyTicket`** — `TicketData | OptimisticTicket`
- **`TicketActionErrorCode`** — discriminated union of 11 server-side error codes routed through `mapTicketActionError`

### Functions

- **`isOptimistic(t)`** — type guard narrowing `AnyTicket` to `OptimisticTicket`

### Constants

| Name | Value | Purpose |
|---|---|---|
| `TICKET_TEXT_MAX_CHARS` | `5000` | Client-side cap on ticket/comment text length |
| `TICKET_LIVE_POLL_MS` | `8000` | Shared refetch interval (ms) for list + conversation polls on open drawers |
| `TOAST_COPY` | `as const` object | Centralized, QA-auditable toast strings for all ticket actions |

## Usage Example

```typescript
import {
  AnyTicket,
  isOptimistic,
  TicketsCacheSlot,
  TICKET_LIVE_POLL_MS,
  TICKET_TEXT_MAX_CHARS,
  TOAST_COPY,
} from '@openframe/oss-lib'

// Type-guard before rendering optimistic rows
function renderTicket(t: AnyTicket) {
  if (isOptimistic(t)) return <SkeletonRow />
  return <TicketRow data={t} />
}

// Safe cache mutation — always project through TicketsCacheSlot
queryClient.setQueriesData<TicketsCacheSlot>(
  { queryKey: ['tickets'] },
  (old) => ({
    ...old,
    tickets: old?.tickets?.map((t) =>
      t.id === updatedId ? { ...t, status: 'CLOSED' } : t
    ),
  })
)

// Enforce text cap before submitting
if (body.length > TICKET_TEXT_MAX_CHARS) {
  showError(`Max ${TICKET_TEXT_MAX_CHARS} characters`)
}

// Consistent poll cadence across list + conversation hooks
useQuery({ queryKey: ['tickets'], refetchInterval: TICKET_LIVE_POLL_MS })

// Centralized toast copy
toast(TOAST_COPY.close_success)
```
