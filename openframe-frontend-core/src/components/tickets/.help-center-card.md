Renders a single ticket row in the Help Center list, combining a toggleable summary button with an expandable detail drawer (`TicketDetailDrawer`) that provides full ticket interaction (compose, close, reopen).

## Key Components

### `HelpCenterCard` (default export)
The primary component. Renders a `<button>` summary row using `DevCardRowContent` (shared with the delivery list for visual consistency). When expanded, mounts a sibling `TicketDetailDrawer` beneath the row. Optimistic (locally-created, not yet server-confirmed) tickets render as non-expandable, dimmed rows.

**Notable behaviors:**
- Smooth-scroll via `scrollElementIntoView` (rAF-driven, immune to browser scroll-anchor cancellation) on expand — runs in a `useEffect`, not the click handler, so the drawer height is committed before measurement
- Deep-link support: accepts an `id` prop (`ticket-<external_id>`) for `useScrollToHash` hash navigation from chat cards
- Drawer is a DOM sibling of the toggle button — click events inside the drawer do not bubble to the row's toggle handler

### `mapPriorityScheme` (local helper)
Maps ticket priority strings to `StatusBadge` color schemes:

| Priority | Scheme |
|---|---|
| `HIGH` / `URGENT` | `error` (red) |
| `MEDIUM` | `warning` (yellow) |
| `LOW` / unknown | `default` |

Kept local to avoid conflating workflow status colors (from `getStatusColorScheme`) with severity colors.

## Key Props (`HelpCenterCardProps`)

| Prop | Type | Description |
|---|---|---|
| `ticket` | `AnyTicket` | Ticket data (real or optimistic) |
| `expanded` | `boolean` | Controlled open/closed state |
| `onToggle` | `(id: string) => void` | Called on row click |
| `busy` | `boolean` | Forwarded to drawer for loading state |
| `replyError` | `TicketDetailDrawerProps['replyError']` | Persisted reply-failure banner |
| `id` | `string?` | DOM `id` for hash-based deep linking |

## Usage Example

```typescript
<HelpCenterCard
  ticket={ticket}
  expanded={expandedId === ticket.id}
  onToggle={(id) => setExpandedId(prev => prev === id ? null : id)}
  busy={isBusy}
  supportSystemDown={false}
  onSendMessage={handleSendMessage}
  onClose={handleClose}
  onReopen={handleReopen}
  onActionCollapsed={() => setExpandedId(null)}
  replyError={replyErrors[ticket.external_id]}
  onClearReplyError={() => clearReplyError(ticket.external_id)}
  id={`ticket-${ticket.external_id}`}
/>
```
