Wrapper components that keep filter controls visible but visually disabled during loading states, with smooth transitions and full accessibility support.

## Key Components

| Export | Description |
|---|---|
| `PersistentFilterControls` | Base wrapper; handles opacity, pointer-events, ARIA attributes, and a spinning loader indicator |
| `PersistentSearchContainer` | Wraps search inputs; keeps interaction enabled (`preventInteraction=false`) during loading |
| `PersistentSidebar` | Wraps desktop sidebar filters; sticky-positioned, `0.5` disabled opacity |
| `PersistentMobileDropdown` | Wraps mobile dropdown filters; hidden on `lg+`, `0.7` disabled opacity |

## Props — `PersistentFilterControls`

| Prop | Type | Default | Description |
|---|---|---|---|
| `isLoading` | `boolean` | — | Triggers the disabled visual state |
| `children` | `ReactNode` | — | Filter control components to wrap |
| `className` | `string` | — | Additional Tailwind/CSS classes |
| `disabledOpacity` | `number` | `0.6` | Opacity when loading (0–1) |
| `transitionDuration` | `number` | `300` | Transition duration in milliseconds |
| `preventInteraction` | `boolean` | `true` | Applies `pointer-events-none` during loading |

## Usage Example

```typescript
import {
  PersistentFilterControls,
  PersistentSearchContainer,
  PersistentSidebar,
  PersistentMobileDropdown,
} from "./persistent-filter-controls"

// Granular per-control usage
function FilterLayout({ isLoading }: { isLoading: boolean }) {
  return (
    <>
      {/* Search stays interactive during loading */}
      <PersistentSearchContainer isLoading={isLoading}>
        <SearchInput />
      </PersistentSearchContainer>

      {/* Sidebar fully disabled at 50% opacity */}
      <PersistentSidebar isLoading={isLoading}>
        <CategoryFilterSidebar />
      </PersistentSidebar>

      {/* Mobile dropdown, hidden on desktop */}
      <PersistentMobileDropdown isLoading={isLoading}>
        <MobileFilterDropdown />
      </PersistentMobileDropdown>
    </>
  )
}

// Or use the base component with custom settings
<PersistentFilterControls
  isLoading={isLoading}
  disabledOpacity={0.4}
  transitionDuration={200}
  preventInteraction
>
  <CustomFilterPanel />
</PersistentFilterControls>
```

## Accessibility

- `role="region"` with `aria-label="Filter controls"` and `aria-busy` on the outer wrapper
- `role="status"` with `aria-live="polite"` on a visually hidden (`sr-only`) element announces loading to screen readers
- A visible spinning indicator (`animate-spin`) is rendered at `top-2 right-2` during loading
- Keyboard navigation and screen reader access are preserved even when `pointer-events-none` is applied
