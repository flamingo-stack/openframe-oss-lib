A reusable, accessible filter chip UI component for displaying and interacting with filter tags, supporting multiple visual variants, optional removal, and responsive sizing.

## Key Components

### `FilterChipProps`

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `id` | `string` | — | Unique identifier for the chip |
| `label` | `string` | — | Display text, truncated with tooltip on overflow |
| `variant` | `'selected' \| 'unselected' \| 'category' \| 'subcategory' \| 'tag' \| 'info'` | `'unselected'` | Visual style preset |
| `size` | `'sm' \| 'md'` | `'md'` | Controls padding and text size |
| `removable` | `boolean` | `false` | Shows an `X` button when `true` |
| `onRemove` | `() => void` | — | Callback fired when the remove button is clicked |
| `onClick` | `() => void` | — | Callback fired when the chip itself is clicked |
| `disabled` | `boolean` | `false` | Disables all interactions and reduces opacity |
| `className` | `string` | — | Additional Tailwind classes for overrides |

### `FilterChip`

The exported component renders a styled pill-shaped chip. Variant classes use ODS (OpenFrame Design System) tokens for consistent theming. The `category`, `subcategory`, and `tag` variants use accent color borders at varying opacity levels to signal hierarchy subtly.

## Usage Example

```typescript
import { FilterChip } from "@/components/filter-chip"

// Basic interactive chip
<FilterChip
  id="filter-os"
  label="Windows"
  variant="selected"
  onClick={() => toggleFilter("windows")}
/>

// Removable category chip
<FilterChip
  id="filter-category-network"
  label="Networking"
  variant="category"
  removable
  onRemove={() => removeCategory("network")}
/>

// Small info chip (non-interactive)
<FilterChip
  id="chip-count"
  label="42 results"
  variant="info"
  size="sm"
/>
```

## Notes

- Keyboard accessible: chips with `onClick` receive `tabIndex={0}` and `role="button"`; the remove button includes `aria-label` for screen readers.
- Click events call `stopPropagation` to prevent conflicts when chips are nested inside other interactive elements.
- Label text truncates at `120px` (`md`) or `100px` (`sm`) with a native `title` tooltip for full text on hover.
