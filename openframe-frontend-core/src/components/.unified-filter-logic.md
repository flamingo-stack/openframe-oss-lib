Provides unified AND-based filter logic for URL-driven filtering across different content types (vendors, blog, etc.), managing filter state via search parameters.

## Key Components

### Interfaces

- **`FilterState`** — Shape of the active filter state: `search`, `categories`, `subcategories`, `tags`, `filters`, `pricing`, `page`
- **`FilterConfig`** — Per-route configuration declaring `basePath` and which filter types are supported

### Hook

**`useUnifiedFiltering(config: FilterConfig)`** — Core hook that reads/writes filter state from URL search params. Returns:

| Method | Description |
|---|---|
| `getCurrentFilterState()` | Parses current URL params into a `FilterState` object |
| `updateFilters(partial, preserveScroll?)` | Merges new filters into state and pushes updated URL |
| `addFilter(type, value, preserveScroll?)` | Appends a value to a multi-select filter |
| `removeFilter(type, value?, preserveScroll?)` | Removes a specific value or clears a filter type |
| `toggleFilter(type, value, preserveScroll?)` | Adds if absent, removes if present |
| `clearAllFilters()` | Navigates to `basePath` with no params |
| `getFilterChips(categories?, tags?)` | Returns display-ready chip objects for active filters |
| `handleFilterChipRemove(chipId)` | Parses chip ID and dispatches the correct `removeFilter` call |
| `isPending` | React transition pending state |

### Pre-built Configs

- **`vendorFilterConfig`** — `/vendors` route; enables categories, subcategories, filters, pricing, and search
- **`blogFilterConfig`** — `/blog` route; enables categories, tags, and search

## Usage Example

```typescript
import { useUnifiedFiltering, vendorFilterConfig } from './unified-filter-logic'

function VendorFilters() {
  const { getCurrentFilterState, toggleFilter, clearAllFilters, isPending } =
    useUnifiedFiltering(vendorFilterConfig)

  const state = getCurrentFilterState()

  return (
    <div>
      <button onClick={() => toggleFilter('categories', 'security')}>
        Security
      </button>
      <button onClick={() => toggleFilter('pricing', 'free')}>
        Free
      </button>
      <button onClick={clearAllFilters} disabled={isPending}>
        Clear All
      </button>
    </div>
  )
}
```

> **AND semantics:** All active filters must match simultaneously. Selecting two categories returns only items that belong to both.
