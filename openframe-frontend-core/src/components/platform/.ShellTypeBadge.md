Displays a badge for RMM shell/script types, pairing an appropriate icon with a human-readable label for all supported shell environments.

## Key Components

### `ShellTypeBadge` (React.FC)
The primary export. Renders an icon + label pair for a given `ShellType`.

### `ShellTypeBadgeProps`
| Prop | Type | Description |
|---|---|---|
| `shellType` | `ShellType` | The shell/script type to display |
| `className` | `string?` | Additional classes for the wrapper `div` |
| `iconClassName` | `string?` | Additional classes applied to the icon |

### `shellIconMap`
A fully-typed `Record<ShellType, ShellIconConfig>` ensuring exhaustive coverage of all supported shell types: `POWERSHELL`, `CMD`, `BASH`, `PYTHON`, `NUSHELL`, `DENO`, and `SHELL`.

**Supported shell types and their icons:**

| Shell | Icon Component |
|---|---|
| PowerShell | `PowershellLogoGreyIcon` |
| CMD | `CmdIcon` |
| Bash | `BashIcon` |
| Python | `PythonLogoIcon` |
| Nushell | `NushellIcon` |
| Deno | `DenoIcon` |
| Shell | `ShellIcon` (default fallback) |

## Usage Example

```typescript
import { ShellTypeBadge } from './ShellTypeBadge'
import { ShellTypeValues } from '../../types/shell.types'

// Basic usage
<ShellTypeBadge shellType={ShellTypeValues.POWERSHELL} />

// With custom wrapper and icon classes
<ShellTypeBadge
  shellType={ShellTypeValues.PYTHON}
  className="bg-surface-secondary px-2 py-1 rounded"
  iconClassName="opacity-80"
/>

// Case-insensitive — input is normalized to uppercase internally
<ShellTypeBadge shellType={"bash" as ShellType} />
```

> **Note:** Unknown or unrecognized `shellType` values fall back to `ShellIcon` via `defaultIconConfig`, preventing render errors.
