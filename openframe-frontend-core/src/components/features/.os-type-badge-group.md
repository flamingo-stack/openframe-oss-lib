Renders a horizontal group of OS type icons, optionally truncating to a maximum count with a "+N more" overflow indicator.

## Key Components

### `OSTypeBadgeGroup`

The primary export. Iterates over an array of OS type strings and renders an [`OSTypeBadge`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/components/os-type-badge/os-type-badge.tsx) (icon-only mode) for each entry. Returns `null` when `osTypes` is empty or undefined.

### `OSTypeBadgeGroupProps`

| Prop | Type | Default | Description |
|---|---|---|---|
| `osTypes` | `string[]` | — | OS type strings (case-insensitive, alias-aware) |
| `className` | `string` | `''` | Additional CSS classes for the wrapper |
| `iconSize` | `string` | `'w-5 h-5'` | Tailwind size classes applied to each icon |
| `maxDisplay` | `number` | — | Cap on visible badges; excess shown as `+N more` |

## Usage Example

```typescript
import { OSTypeBadgeGroup } from './os-type-badge-group'

// Show all three platform icons
<OSTypeBadgeGroup osTypes={['windows', 'darwin', 'linux']} />

// Cap at 2, renders "+1 more" for the third
<OSTypeBadgeGroup
  osTypes={['windows', 'macos', 'linux']}
  maxDisplay={2}
  iconSize="w-4 h-4"
/>

// Custom wrapper styling
<OSTypeBadgeGroup
  osTypes={['linux']}
  className="mt-2"
/>
```
