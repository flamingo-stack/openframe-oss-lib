Renders a row of OpenFrame-styled tag badges from a flat entity-tags association array, with optional click-through filtering and overflow collapsing.

## Key Components

### `EntityTagBadges` (exported component)
The single canonical tag-badge renderer for the entire product. Accepts a `TagAssoc[]` array and maps each entry to a `StatusBadge` chip. Returns `null` when the tag list is empty.

### `TAG_BADGE_CLASS` (exported constant)
The shared CSS class string (`bg-ods-card border border-ods-border`) that defines the OpenFrame tag chip skin. Exported so other components (e.g. `FaqAccordion` section badges) can reuse the identical appearance without duplicating styles.

### Props

| Prop | Type | Description |
|---|---|---|
| `tags` | `TagAssoc[] \| null` | Flat association array from entity hydration |
| `basePath` | `string` | When set, wraps each slugged badge in a `next/link` to `${basePath}?tags=${slug}` |
| `max` | `number` | Cap on visible badges; extras collapse into a `+N` overflow badge |
| `className` | `string` | Extra classes on the wrapper `div` |

## Usage Example

```typescript
// Non-interactive display
<EntityTagBadges tags={article.article_tags} />

// Clickable badges linking to filtered list
<EntityTagBadges
  tags={article.article_tags}
  basePath="/blog"
  max={5}
  className="mt-2"
/>

// Reuse the tag skin on a custom chip
import { TAG_BADGE_CLASS } from './entity-tag-badges'

<StatusBadge text="SECTION" variant="card" className={TAG_BADGE_CLASS} />
```

**Overflow behavior:** `max={0}` shows no badges; `max={null | undefined}` shows all. Tags without a `slug` render as non-interactive even when `basePath` is provided.
