Core type definitions and utility functions for the notification system, including approval-request notifications used by the Mingo AI approval workflow.

## Key Components

### Types & Interfaces

| Name | Description |
|---|---|
| `Notification` | Core notification shape with display, metadata, and interaction fields |
| `AddNotificationInput` | Omits auto-generated fields (`id`, `createdAt`) for consumer-facing `addNotification` calls |
| `NotificationVariant` | Visual style: `default` · `success` · `warning` · `error` · `info` |
| `NotificationSeverity` | Backend severity level: `INFO` · `SUCCESS` · `WARNING` · `DANGER` |
| `RenderNotificationTile` | Override callback to replace the default tile renderer per notification |
| `ApprovalNotificationMeta` | Approval payload stored in `notification.meta` for `ADMIN_APPROVAL_REQUEST` notifications |
| `ApprovalToolCallMeta` | Single planned tool invocation awaiting admin approval |

### Utility Functions

| Name | Description |
|---|---|
| `isApprovalNotification` | Guards whether a notification carries an approval request via `meta.contextType` |
| `getApprovalMeta` | Safely extracts and validates `ApprovalNotificationMeta` from a notification; returns `null` on mismatch |
| `resolutionToStatus` | Maps backend `ApprovalResolution` strings (`PENDING`, `APPROVED`, `REJECTED`, `CANCELLED`) to `ChatApprovalStatus` |
| `approvalMetaToBatchData` | Converts `ApprovalNotificationMeta` to an `ApprovalBatchData` payload for chat approval batches |

### Constants

- **`ADMIN_APPROVAL_REQUEST_CONTEXT_TYPE`** — discriminator string (`"ADMIN_APPROVAL_REQUEST"`) matched against `notification.meta.contextType`

## Usage Example

```typescript
import {
  isApprovalNotification,
  getApprovalMeta,
  resolutionToStatus,
  approvalMetaToBatchData,
} from './types'

// Check and extract approval metadata
if (isApprovalNotification(notification)) {
  const approval = getApprovalMeta(notification)

  if (approval) {
    // Map resolution to a UI status
    const status = resolutionToStatus(approval.resolution)

    // Build the batch payload for the chat approval component
    const batchData = approvalMetaToBatchData(approval)
  }
}

// Add a basic notification (id and createdAt are optional)
const input: AddNotificationInput = {
  title: 'Ticket #1042 Updated',
  variant: 'success',
  severity: 'SUCCESS',
  onClick: () => router.push('/tickets/1042'),
}
```
