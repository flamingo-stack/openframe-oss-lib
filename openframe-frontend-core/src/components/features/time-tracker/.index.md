Public API barrel file for the Time Tracker feature module, re-exporting all components, hooks, context utilities, and TypeScript types from their respective source files.

## Key Components

| Export | Source | Description |
|---|---|---|
| `TimeTrackerProvider` | `time-tracker-context` | Context provider for time tracker state |
| `useTimeTracker` | `time-tracker-context` | Hook to consume time tracker context (throws if missing) |
| `useOptionalTimeTracker` | `time-tracker-context` | Hook to consume time tracker context (returns `undefined` if missing) |
| `TimeTrackerPanel` | `time-tracker-panel` | UI panel component for the tracker interface |
| `TimeTrackerHeaderButton` | `time-tracker-header-button` | Header button component to open/control the tracker |
| `useTrackerClock` | `use-tracker-clock` | Hook managing the running clock/tick logic |

## Types

- `TimeTrackerProviderProps`, `TimeTrackerPanelProps`, `TimeTrackerHeaderButtonProps`, `UseTrackerClockArgs` — component and hook prop shapes
- `TimeTrackerStatus`, `TimeTrackerEntry`, `TimeTrackerData` — core tracker state types
- `TimeTrackerTicketOption`, `TimeTrackerCustomerOption` — dropdown option types for ticket and customer selectors

## Usage Example

```typescript
import {
  TimeTrackerProvider,
  TimeTrackerPanel,
  TimeTrackerHeaderButton,
  useTimeTracker,
} from '@openframe-oss-lib/time-tracker'

function App() {
  return (
    <TimeTrackerProvider>
      <TimeTrackerHeaderButton />
      <TimeTrackerPanel />
    </TimeTrackerProvider>
  )
}

function TrackerStatus() {
  const tracker = useTimeTracker()
  return <span>Status: {tracker.status}</span>
}
```
