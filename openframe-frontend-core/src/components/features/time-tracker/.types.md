Defines the complete TypeScript contract for the OpenFrame time tracker UI component, including status states, option shapes, entry records, and the full host-provided data interface.

## Key Components

| Export | Kind | Description |
|---|---|---|
| `TimeTrackerStatus` | Type | Union of tracker states: `'ready'`, `'tracking'`, `'paused'` |
| `TimeTrackerTicketOption` | Interface | `id` + `label` pair for ticket autocomplete options |
| `TimeTrackerCustomerOption` | Interface | `id` + `label` + optional `imageUrl` for customer autocomplete |
| `TimeTrackerEntry` | Interface | A previous session record with pre-formatted `durationLabel` and `dateLabel` |
| `TimeTrackerData` | Interface | The complete prop contract fed by the host into the UI component |

### `TimeTrackerData` Notable Fields

- **`status` / `runningSince` / `accumulatedMs`** — Drives the live timer; UI ticks locally from `runningSince`, backend stays source of truth
- **`ticketOptions` / `selectedTicketId` / `onTicketSearch`** — Ticket autocomplete wiring (host handles search)
- **`customerOptions` / `onSelectedCustomerChange`** — Optional customer panel; rendered only when `onSelectedCustomerChange` is provided
- **`customerLocked`** — Prevents customer edits when derived from the selected ticket
- **`lastEntries`** — Up to three recent sessions displayed in the panel
- **`isStarting` / `isSubmitting`** — Loading guards for async host actions

## Usage Example

```typescript
const data: TimeTrackerData = {
  status: 'ready',
  accumulatedMs: 0,
  ticketOptions: [{ id: 'TKT-42', label: '#42 – Replace firewall' }],
  selectedTicketId: null,
  onSelectedTicketChange: (id) => dispatch(selectTicket(id)),
  onTicketSearch: (query) => dispatch(searchTickets(query)),
  customerOptions: [{ id: 'cust-1', label: 'Acme Corp', imageUrl: 'https://cdn.example.com/acme.png' }],
  selectedCustomerId: null,
  onSelectedCustomerChange: (id) => dispatch(selectCustomer(id)),
  notes: '',
  onNotesChange: (value) => dispatch(setNotes(value)),
  lastEntries: [
    { id: 'e1', durationLabel: '00:08:17', dateLabel: '07/12/25', title: 'Network audit' },
  ],
  onStart: () => dispatch(startTimer()),
  onPause: () => dispatch(pauseTimer()),
  onResume: () => dispatch(resumeTimer()),
  onCancel: () => dispatch(cancelTimer()),
  onSubmit: () => dispatch(submitTimer()),
};
```
