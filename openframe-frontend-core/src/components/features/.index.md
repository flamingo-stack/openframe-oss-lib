Central barrel export file for the OpenFrame OSS library's feature components, re-exporting all public UI components, hooks, providers, and utilities from their respective module directories.

## Key Components

### Theme System
- **`DynamicThemeProvider`** / **`useDynamicTheme`** — Dynamic runtime theming
- **`ThemeProvider`** / **`useTheme`** / **`useThemeToggle`** — Canonical ODS theme system (thin wrapper over `next-themes`), headless by design with constants `THEME_STORAGE_KEY`, `THEME_ATTRIBUTE`, `DEFAULT_THEME` and types `Theme`, `ThemeProviderProps`, `UseThemeToggleResult`

### Video Primitives
- **`<Video>`** — Unified video component replacing legacy `<VideoPlayer>` + `<YouTubeEmbed>`
- **`<CardsStrip>`** — Horizontal card-strip engine (render-prop or organic `children` mode)
- **`<EntityVideoSection>`** / **`<VideoBitesStrip>`** — Public detail-page wrappers
- **`<VideoBitesDisplay>`** — Deprecated shim over the strip
- **`video-bites-shared`** — Server-safe leaf, also published as its own subpath

### Feature Components (selected)
- `auth`, `auth-providers-list`, `command-box`, `error-boundary`
- `filters-dropdown`, `loading-provider`, `media-gallery-manager`
- `ai-enrich`, `board`, `notifications`, `time-tracker`
- `seo-editor-preview`, `tags-selector`, `social-links-manager`
- `changelog-manager`, `github-releases-manager`, `knowledge-base-links-manager`

## Usage Example

```typescript
import {
  ThemeProvider,
  useThemeToggle,
  Video,
  CardsStrip,
  CommandBox,
  ErrorBoundary,
} from '@openframe-oss-lib/features'

function App() {
  const { toggle, theme } = useThemeToggle()

  return (
    <ThemeProvider>
      <ErrorBoundary>
        <Video src="https://example.com/video.mp4" />
        <button onClick={toggle}>Current: {theme}</button>
      </ErrorBoundary>
    </ThemeProvider>
  )
}
```
