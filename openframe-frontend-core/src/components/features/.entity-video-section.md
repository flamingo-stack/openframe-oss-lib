Renders the video block for a public entity detail page, combining a full video, AI-generated highlights, markdown summary, and video bites strip into a single composable section.

## Key Components

**`EntityVideoSection`** — Primary export. Orchestrates three sub-sections:
- **Tabbed video player** — shows "Full Video" / "Highlights" tabs when both exist; falls back to a single `<Video>` if only one is available. YouTube URL takes precedence over `mainVideoUrl` when both are provided.
- **Markdown summary** — Rendered via an injected `MarkdownRenderer` component when `videoSummary` is present.
- **Video bites strip** — Scrollable `<VideoBitesStrip>` rendered when `videoBites` array is non-empty.

Returns `null` when no video, summary, or bites are available.

**`EntityVideoSectionProps`** — Full prop interface covering video URLs, captions, poster images, bites configuration, and the injected markdown renderer.

## Usage Example

```typescript
import { EntityVideoSection } from './entity-video-section';
import { MarkdownRenderer } from '@/components/markdown-renderer';

<EntityVideoSection
  youtubeUrl="https://www.youtube.com/watch?v=abc123"
  highlightVideoUrl="https://cdn.example.com/highlight.mp4"
  highlightVideoThumbnail="https://cdn.example.com/thumb.jpg"
  title="Product Demo"
  videoSummary="**Overview:** This video covers..."
  videoBites={bites}
  bitesTitle="Key Moments"
  bitesProfile={speakerProfile}
  bitesHref="/events/product-demo"
  filterPublishedBites
  priority
  MarkdownRenderer={MarkdownRenderer}
/>
```

## Notes

- `youtubeUrl` always wins over `mainVideoUrl` when both are set — resolved at the section level to keep `<Video>` single-source-per-render.
- `srtContent` is deprecated; use `captionsUrl` (VTT) instead.
- `priority` forwards an LCP hint to the full-video tab's poster image.
