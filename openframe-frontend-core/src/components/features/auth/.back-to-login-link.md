A client-side React component that renders a styled "Back to Login" text link used across authentication screens.

## Key Components

### `BackToLoginLink`

A button styled as an underlined text link, designed for auth flow navigation.

**Props (`BackToLoginLinkProps`):**

| Prop | Type | Default | Description |
|---|---|---|---|
| `onClick` | `() => void` | — | Callback fired when the link is clicked |
| `label` | `string` | `'Back to Login'` | Customizable link text |
| `className` | `string` | — | Optional class overrides via `cn` utility |

## Usage Example

```typescript
import { BackToLoginLink } from './back-to-login-link'

function ForgotPasswordScreen() {
  const handleBack = () => {
    router.push('/login')
  }

  return (
    <div>
      <h1>Forgot Password</h1>
      <BackToLoginLink onClick={handleBack} />

      {/* With custom label and class */}
      <BackToLoginLink
        onClick={handleBack}
        label="Return to Sign In"
        className="text-ods-brand-primary"
      />
    </div>
  )
}
```

## Notes

- Rendered as a `<button type="button">` to avoid unintended form submissions.
- Applies `text-h4` and `text-ods-text-secondary` design tokens by default; fully overridable via `className`.
