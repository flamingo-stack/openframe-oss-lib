Renders an interactive Figma prototype viewer with responsive scaling, section navigation, and multi-device support (desktop, mobile, touch). Integrates directly with the Figma Embed API and manages iframe lifecycle states.

## Key Components

### Exported Interfaces
- **`FigmaPrototypeSection`** — Defines a navigable section with `id`, `number`, `title`, optional `description`, and per-device starting node IDs
- **`FigmaPrototypeViewerConfig`** — Full viewer configuration including file keys (mobile/desktop/legacy), section list, dimension overrides, and CSS class customization
- **`FigmaPrototypeViewerProps`** — Component props wrapping config with optional external section control

### Internal Types
- **`ViewMode`** — `'DESKTOP' | 'MOBILE' | 'MOBILE_TOUCH'` — determined by screen width and touch capability
- **`IframeState`** — Lifecycle states: `INITIAL → LOADING → READY`, plus `RELOADING` and `SLEEP_RECOVERY`
- **`UnifiedState`** — Single source of truth for all rendering decisions (scaling, visibility flags, navigation)

### Core Utility Functions

| Function | Purpose |
|---|---|
| `getViewMode` | Classifies device based on screen width and touch support |
| `calculateScaling` | Computes `scale`, `marginX`, `marginY` to fit content without upscaling |
| `resolveFileKey` | Priority chain: env var → config field → legacy `fileKey` |
| `resolveStartingPoint` | Priority chain: section node → env var → config → first section |
| `generateEmbedUrl` | Builds Figma embed URL with correct params for device mode |
| `renderUnifiedUI` | Renders full UI from declarative `UnifiedState` (section selector + iframe container) |

### Configuration Priority (highest → lowest)
```text
NEXT_PUBLIC_FIGMA_* env vars → config props → defaults
```

## Usage Example

```typescript
import { FigmaPrototypeViewer } from './figma-prototype-viewer'
import type { FigmaPrototypeViewerConfig } from './figma-prototype-viewer'

const config: FigmaPrototypeViewerConfig = {
  title: 'Onboarding Flow',
  desktopFileKey: 'abc123desktop',
  mobileFileKey: 'abc123mobile',
  desktopContentDimensions: { width: 1280, height: 720 },
  mobileContentDimensions: { width: 390, height: 844 },
  sections: [
    {
      id: 'welcome',
      number: '01',
      title: 'Welcome Screen',
      startingNodeId: '1:23',
      mobileStartingNodeId: '1:45'
    },
    {
      id: 'setup',
      number: '02',
      title: 'Account Setup',
      startingNodeId: '2:10'
    }
  ],
  defaultSectionId: 'welcome'
}

export default function PrototypePage() {
  return (
    <FigmaPrototypeViewer
      config={config}
      onSectionClick={(id) => console.log('Navigated to:', id)}
    />
  )
}
```

**Environment variable overrides** (`.env.local`):
```bash
NEXT_PUBLIC_FIGMA_DESKTOP_FILE_KEY=your_desktop_key
NEXT_PUBLIC_FIGMA_MOBILE_FILE_KEY=your_mobile_key
NEXT_PUBLIC_FIGMA_DESKTOP_STARTING_POINT=1:23
NEXT_PUBLIC_FIGMA_MOBILE_STARTING_POINT=1:45
NEXT_PUBLIC_FIGMA_DESKTOP_WIDTH=1280
NEXT_PUBLIC_FIGMA_DESKTOP_HEIGHT=720
```
