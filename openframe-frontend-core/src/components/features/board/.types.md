Defines the core types, interfaces, and utility functions for the Kanban-style ticket board, including column definitions, ticket shapes, and helpers for mapping tickets to board columns.

## Key Components

### Types & Interfaces

| Export | Description |
|---|---|
| `BoardPriority` | Union type: `'low' \| 'medium' \| 'high' \| 'urgent'` |
| `BoardTicket` | Core ticket shape with status, priority, assignees, tags, and pending approval |
| `BoardTicketAssignee` | Assignee identity with optional avatar and initials |
| `BoardTicketPendingApproval` | Latest pending tool-call approval attached to a ticket |
| `BoardColumnDef` | Board column config including tickets, color, drag/drop rules, and pagination state |
| `BoardChange` | Describes a ticket move: source/target column and surrounding ticket IDs |

### Functions

| Export | Description |
|---|---|
| `columnFromTicketStatus` | Builds a `BoardColumnDef` from a canonical `TicketStatus`, applying default label/color with optional overrides |
| `groupTicketsByStatus` | Buckets a flat list of `BoardTicket[]` into ordered `BoardColumnDef[]` for a given set of statuses |

### Internal

- `STATUS_DEFAULTS` — default label and hex color for each of the six canonical statuses (`ACTIVE`, `AI_ASSISTANCE`, `TECH_REQUIRED`, `ON_HOLD`, `RESOLVED`, `ARCHIVED`)
- `canonicalize()` — normalizes raw status strings to `TicketStatus`, including the legacy alias `ACTION_REQUIRED → TECH_REQUIRED`

## Usage Example

```typescript
import {
  columnFromTicketStatus,
  groupTicketsByStatus,
  type BoardTicket,
} from './types'

const tickets: BoardTicket[] = [
  { id: '1', title: 'Printer offline', ticketNumber: 'T-001', status: 'ACTIVE' },
  { id: '2', title: 'VPN issue', ticketNumber: 'T-002', status: 'on hold' },
]

// Group flat tickets into board columns
const columns = groupTicketsByStatus(tickets, ['ACTIVE', 'ON_HOLD', 'RESOLVED'])

// Build a single column with overrides
const activeColumn = columnFromTicketStatus('ACTIVE', tickets, {
  label: 'In Progress',
  total: 42,
  hasMore: true,
})
```
- `BoardTicketAssignee.deleted` — deleted account: `TicketCardBody` renders `DeletedUserAvatar` (red user-x) instead of `SquareAvatar` for that assignee.
