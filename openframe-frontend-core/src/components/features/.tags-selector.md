Reusable React component for selecting and managing tags with search autocomplete, chip display, and optional tag creation.

## Key Components

### Interfaces

- **`Tag`** — Shape of a tag object: `id`, `name`, `slug`
- **`TagsSelectorProps`** — Component props:

| Prop | Type | Default | Description |
|---|---|---|---|
| `availableTags` | `Tag[]` | — | Pool of selectable tags |
| `selectedTagIds` | `number[]` | — | Controlled list of selected tag IDs |
| `onTagsChange` | `(ids: number[]) => void` | — | Fires when selection changes |
| `onCreateTag` | `(name: string) => Promise<Tag \| null>` | — | Async handler to create a new tag |
| `maxTags` | `number` | `10` | Maximum selectable tags |
| `allowCreate` | `boolean` | `true` | Show "Create tag" option in dropdown |
| `disabled` | `boolean` | `false` | Disables all interaction |

### Exported Component

- **`TagsSelector`** — Main component rendering the search input, tag chips, autocomplete dropdown, and tag counter

## Usage Example

```typescript
import { TagsSelector } from './tags-selector';

function MyForm() {
  const [selectedIds, setSelectedIds] = useState<number[]>([]);

  const handleCreate = async (name: string) => {
    const res = await fetch('/api/tags', {
      method: 'POST',
      body: JSON.stringify({ name }),
    });
    return res.json(); // returns Tag | null
  };

  return (
    <TagsSelector
      availableTags={[
        { id: 1, name: 'TypeScript', slug: 'typescript' },
        { id: 2, name: 'React', slug: 'react' },
      ]}
      selectedTagIds={selectedIds}
      onTagsChange={setSelectedIds}
      onCreateTag={handleCreate}
      maxTags={5}
      placeholder="Search or create tags..."
    />
  );
}
```
