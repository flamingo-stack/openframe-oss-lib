A reusable React client component that renders a row of status filter buttons for admin dashboards, supporting role-based selective disabling of individual status options.

## Key Components

### Interfaces

- **`StatusOption`** — Shape for each filter option: `{ value: string; label: string }`
- **`StatusFilterComponentProps`** — Full prop contract for the component:

| Prop | Type | Description |
|---|---|---|
| `selectedStatus` | `string` | Currently active filter value |
| `onStatusChange` | `(status: string) => void` | Callback fired on button click |
| `statusOptions` | `StatusOption[]` | List of available filter options |
| `showCount` | `boolean?` | Toggles item count display (default: `false`) |
| `count` | `number?` | Number to display when `showCount` is true |
| `className` | `string?` | Additional CSS classes for the wrapper |
| `disabledValues` | `string[]?` | Status values to render but disable (e.g. for role-gating) |

### Component

- **`StatusFilterComponent`** — Renders an "All" button followed by individual status buttons. Active status uses the `accent` variant; inactive uses `outline`. Disabled buttons remain visible but non-interactive — useful for exposing a full status set while restricting which values a viewer may select.

## Usage Example

```typescript
import { StatusFilterComponent, StatusOption } from './status-filter-component';

const statusOptions: StatusOption[] = [
  { value: 'published', label: 'Published' },
  { value: 'draft', label: 'Draft' },
  { value: 'archived', label: 'Archived' },
];

// Non-management users can only switch to 'published'
<StatusFilterComponent
  selectedStatus={currentStatus}
  onStatusChange={setCurrentStatus}
  statusOptions={statusOptions}
  showCount={true}
  count={42}
  disabledValues={['draft', 'archived']}
/>
```
