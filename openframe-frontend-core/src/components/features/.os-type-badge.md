Displays operating system type with an icon and label, automatically normalizing OS type strings from various formats and aliases. Exports three focused sub-components for flexible rendering.

## Key Components

| Export | Type | Description |
|---|---|---|
| `OSTypeBadge` | `React.FC` | Full badge with icon + label (default), icon-only, or label-only rendering |
| `OSTypeIcon` | `React.FC` | Convenience wrapper — renders only the OS icon |
| `OSTypeLabel` | `React.FC` | Convenience wrapper — renders only the OS label text |
| `OSTypeBadgeProps` | `interface` | Props interface for `OSTypeBadge` |

### `OSTypeBadgeProps`

| Prop | Type | Default | Description |
|---|---|---|---|
| `osType` | `string` | — | OS type string (case-insensitive, handles aliases) |
| `className` | `string` | `''` | Additional CSS classes |
| `iconOnly` | `boolean` | `false` | Render icon only, no label |
| `labelOnly` | `boolean` | `false` | Render label only, no icon |
| `iconSize` | `string` | `'w-4 h-4'` | Tailwind size classes for the icon |
| `iconColor` | `string` | `var(--color-text-secondary)` | Icon fill/stroke color |
| `rightIcon` | `React.ReactNode` | `null` | Optional trailing icon element |

## Usage Example

```typescript
import { OSTypeBadge, OSTypeIcon, OSTypeLabel } from './os-type-badge'

// Full badge: icon + label
<OSTypeBadge osType="windows" />
<OSTypeBadge osType="Darwin" />

// Icon only (e.g. compact table cell)
<OSTypeIcon osType="Ubuntu" size="w-5 h-5" />

// Label only (e.g. plain text context)
<OSTypeLabel osType="linux" className="font-medium" />

// Badge with trailing action icon
<OSTypeBadge
  osType="windows"
  rightIcon={<ChevronRightIcon className="w-3 h-3" />}
/>

// Unknown / missing OS type
<OSTypeBadge osType={undefined} labelOnly /> // renders "Unknown"
<OSTypeBadge osType={undefined} />            // renders null
```

## Notes

- OS type strings are normalized via `normalizeOSType` from [`os-utils`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/utils/os-utils.ts), so values like `"Darwin"`, `"ubuntu"`, or `"win32"` resolve correctly.
- When `osType` is missing and `labelOnly` is `false`, the component returns `null` (safe for conditional rendering).
- All three exports set a `displayName` for clear identification in React DevTools.
