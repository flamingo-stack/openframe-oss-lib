Renders video content from YouTube URLs, file URLs (HLS/MP4), or bare YouTube IDs with automatic source detection, three layout modes, and optional hover-play/muted-autoplay behavior.

## Key Components

### Exports

- **`extractYouTubeId(url: string): string | null`** — Parses any YouTube URL shape or bare 11-char ID into a video ID. Uses strict `URL` parsing with anchored regexes to prevent ReDoS attacks.
- **`VideoLayout`** — Union type: `'centered' | 'fill' | 'native'`
- **`<Video>`** (default export) — Single unified video component routing to lite-YouTube facade or `<MuxPlayer>` based on `kind` prop.

### Internal Utilities

- **`videoPerfDebugEnabled()`** — Gates hover-to-play latency instrumentation; always on in dev, opt-in via `localStorage.VIDEO_PERF_DEBUG` in production.
- **`isYouTubeUrl(url)`** — Hostname-based YouTube detection against a strict allowlist.
- **`extractYouTubeId(url)`** — Exported ID extractor usable by admin tooling without rendering the component.

### Key Behaviors

| Feature | Detail |
|---|---|
| `kind="auto"` | Bare 11-char ID → YouTube; YouTube hostname → YouTube; anything else → file |
| `layout="centered"` | `max-w-3xl` centered wrapper — detail pages |
| `layout="fill"` | `absolute inset-0` — carousel slides |
| `layout="native"` | Intrinsic aspect ratio — grid/card embeds |
| Cast suppression | Stubs `chrome.cast` to block MuxPlayer's CSP-violating Cast SDK injection |
| Autoplay policy | Module-level `pointerdown`/`keydown` tracker gates muted vs. sound-first hover play |

## Usage Example

```typescript
import { Video, extractYouTubeId } from '@/components/video';

// Auto-detect source from URL
<Video url="https://www.youtube.com/watch?v=dQw4w9WgXcQ" layout="centered" />

// Explicit file source with captions
<Video
  kind="file"
  url="https://cdn.example.com/clip.m3u8"
  captionsUrl="https://cdn.example.com/captions.vtt"
  layout="fill"
  autoPlay
  muted
  loop
/>

// Extract ID for thumbnail logic without rendering
const id = extractYouTubeId('https://youtu.be/dQw4w9WgXcQ'); // "dQw4w9WgXcQ"
```
