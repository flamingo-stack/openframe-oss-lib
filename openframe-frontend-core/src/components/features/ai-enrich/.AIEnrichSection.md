Reusable React section component that renders a complete AI enrichment UI panel, including a trigger button, optional custom instructions textarea, status feedback, warnings, confidence scoring, and result actions.

## Key Components

### Interfaces

- **`ConfidenceField`** — Describes a field with an optional confidence score (`label`, `key`, `confidence`).
- **`AIRequiredField`** — Describes a field required before enrichment can run (`key`, `label`, `isFilled`). Unfilled fields are displayed as badges when the button is disabled.
- **`AIEnrichSectionProps`** — Full prop surface for the section component, covering button state, status, warnings, layout variant, custom instructions, and action callbacks.

### Component

- **`AIEnrichSection`** — The primary export. Renders a card-style panel containing:
  - Icon + title + description header
  - Optional controlled `<Textarea>` for editor-supplied AI focus instructions
  - `AIEnrichButton` trigger (full-width)
  - Optional cancel button (visible only during loading)
  - Disabled state message with unfilled-field badges
  - Loading spinner + status message
  - Success/error result block with confidence badge, warnings (`AIWarningsSection`), slot for custom children, and a "Clear Results" button

## Usage Example

```typescript
import { AIEnrichSection } from './AIEnrichSection'

<AIEnrichSection
  title="AI Enrichment"
  description="Auto-fill fields using Claude."
  onEnrich={handleEnrich}
  loading={isLoading}
  canEnrich={!!formData.version}
  status={enrichStatus}
  statusMessage={enrichMessage}
  overallConfidence={87}
  warnings={enrichWarnings}
  requiredFields={[
    { key: 'version', label: 'Version', isFilled: !!formData.version },
  ]}
  showCustomInstructions
  customInstructions={instructions}
  onCustomInstructionsChange={setInstructions}
  onClear={handleClear}
  showCancel
  onCancel={handleCancel}
/>
```

## Notes

- `canEnrich` and `disabled` are OR'd together — both must be falsy for the button to be active.
- The custom instructions value is **fully controlled** by the parent; the component never owns it internally. The string is forwarded to the backend and injected into the Claude prompt via `buildEditorFocusBlock()`.
- Supports `variant="compact"` for tighter padding in space-constrained layouts.
