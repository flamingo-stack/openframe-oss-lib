A client-side React component that renders styled badge tags for categorizing vendors, tools, and platform capabilities within the OpenFrame design system.

## Key Components

### `VendorTagProps` Interface

| Prop | Type | Description |
|---|---|---|
| `type` | union (14 variants) | Determines icon, label, and color scheme |
| `text` | `string` | Optional override for the default display label |
| `className` | `string` | Additional CSS classes |
| `size` | `'sm' \| 'md'` | Controls padding; defaults to `'md'` |
| `hidden` | `boolean` | Applies `invisible` class when `true` |
| `accentColor` | `string` | Inline color override for the icon box (open-source type only) |

### `VendorTag` Function

Renders a pill-shaped tag with a small icon box and a label. The internal `getTagContent()` helper maps each `type` to its icon, default text, and text color using ODS design tokens (`ods-accent`, `ods-border`, `ods-text-primary`, etc.).

**Supported types:**

- **Licensing:** `open-source`, `commercial`, `free`, `freemium`, `paid`, `enterprise`
- **Platform capability:** `api`, `data`, `k8s`, `secured`
- **Selection state:** `ai`, `manual`, `openframe_selected`, `placeholder`
- **Meta:** `recommended`, `classification` (sub-dispatches on `text` value)

## Usage Example

```typescript
import { VendorTag } from "./vendor-tag"

// Basic licensing badge
<VendorTag type="open-source" />

// Custom label with accent color override
<VendorTag type="open-source" text="Apache 2.0" accentColor="#e07b39" />

// Small AI-selection badge
<VendorTag type="ai" size="sm" />

// Platform capability tags
<VendorTag type="k8s" />
<VendorTag type="secured" text="SOC 2" />

// Classification (text drives sub-type)
<VendorTag type="classification" text="open_source" />
<VendorTag type="classification" text="openframe_selected" />

// Hidden (preserves layout space)
<VendorTag type="recommended" hidden />
```
