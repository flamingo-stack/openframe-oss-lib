React component that renders product release cards in two density variants (`lg` and `sm`) for displaying software release information across OpenFrame and Flamingo MSP platform surfaces.

## Key Components

### Types & Interfaces

- **`ProductReleaseCardSize`** — Union type `'lg' | 'sm'` controlling card density
- **`ProductReleaseCardAnchorProps`** — Structural `<a>` prop bundle (`href`, `target`, `rel`, `onClick`) for consumer-composed navigation; shape-compatible with the hub's `useNavLink` hook
- **`ProductReleaseCardProps`** — Full prop surface including title, summary, version, changelog counts, author, cover image, and release metadata

### `ProductReleaseCard`

Main export. Renders one of two layouts based on the `size` prop (defaults to `'lg'`):

- **`lg`** — Three-zone layout: hero (16:9 cover image + version pill + title + summary), changelog stats strip (feature/fix/improvement/breaking counts), and a fixed 4-cell metadata grid (Type · Status · Released · Author). Renders as an `<InteractiveCard>` with hover/focus states.
- **`sm`** — Compact horizontal layout (~80px tall) for inline chat and tight surfaces. Uses `<span>` elements instead of block-level tags (safe inside markdown `<p>`), 56px icon, 1-line title, and condensed meta (version · date).

Navigation is handled via `anchorProps` (preferred) or legacy `onClick` for back-compat.

## Usage Example

```typescript
import { ProductReleaseCard } from '@openframe/ui'

// Large catalog card with full metadata
<ProductReleaseCard
  size="lg"
  title="OpenFrame 2.4.0"
  summary="Adds AI-powered ticket triage and bulk automation rules."
  version="2.4.0"
  formattedDate="Jun 12, 2025"
  coverImage="https://cdn.example.com/releases/2.4.0-cover.png"
  releaseType="minor"
  releaseStatus="stable"
  releaseTypeBadgeColor="success"
  changelogCounts={{ features: 8, fixes: 14, improvements: 5, breaking: 0 }}
  author={{ full_name: "Ada Lovelace", avatar_url: "/avatars/ada.png", job_title: "Staff Engineer" }}
  anchorProps={{
    href: "/releases/2.4.0",
    onClick: (e) => router.push("/releases/2.4.0"),
  }}
/>

// Compact inline card for chat surfaces
<ProductReleaseCard
  size="sm"
  title="OpenFrame 2.4.0"
  version="2.4.0"
  formattedDate="Jun 12, 2025"
  anchorProps={{ href: "/releases/2.4.0" }}
/>
```
