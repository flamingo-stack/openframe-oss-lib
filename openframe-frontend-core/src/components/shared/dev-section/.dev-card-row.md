Shared layout component for `DevSectionPage` list rows, providing a consistent two-column structure (title/subtitle/description left, badges right) with matching skeleton states to prevent layout shift during loading.

## Key Components

| Export | Type | Description |
|---|---|---|
| `DevCardRowContent` | Component | Main row layout with fixed min-height blocks for title, subtitle, and description columns; in a loading scope (or with `loading`) it draws its own skeleton (`DevCardRowContentSkeleton`, internal: bars for the text and ONE badge, every ticket row's status badge; NEW and priority are optional, so not drawn). Forwards its `data-*` props (`data-loading-item`) in both forms |
| `DevCardRowContentProps` | Interface | Props contract for `DevCardRowContent` (plus `data-*` markers) |

## Usage Example

```typescript
// Static row (e.g. delivery surface)
<div>
  <DevCardRowContent
    title="Deploy to production"
    subtitle="UPDATED today, #4271, Code review"
    description="Automated deployment pipeline triggered by merge to main."
    emptyDescription="No deployment notes available."
    rightBadges={
      <>
        <StatusBadge status="in-progress" />
        <EnvironmentBadge env="production" />
      </>
    }
  />
</div>

// Clickable row (e.g. tickets surface)
<button onClick={handleSelect}>
  <DevCardRowContent
    title="Login page broken on Safari"
    subtitle="OPEN, #1042, Bug"
    description="Users on Safari 17 cannot submit the login form."
    rightBadges={<PriorityBadge level="high" />}
  />
</button>

// Loading state of a list: its own row component draws itself, one full page of them
<LoadingItems count={pageSize}>{() => <HelpCenterCard ticket={null} data-loading-item />}</LoadingItems>
```

## Notes

- `rightBadges` accepts any `ReactNode` — the caller controls badge count and type; no badge logic is embedded here.
- Ticket conversation rows are intentionally excluded; they use the shared `<ChatMessageRow>` component (`components/chat/chat-message-row.tsx`).
- Skeleton min-heights mirror content min-heights exactly to prevent reflow on data load.
