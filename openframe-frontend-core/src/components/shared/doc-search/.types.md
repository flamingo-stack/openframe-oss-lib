Wire type for a single search result row returned by `/api/docs/search`, shared between the hub's RAG layer and the lib's search hook.

## Key Components

### `DocSearchResult` Interface

| Field | Type | Description |
|---|---|---|
| `path` | `string` | Document path identifier |
| `name` | `string` | Display name of the result |
| `type` | `'file' \| 'folder'` | Whether the result is a file or folder |
| `snippet` | `string` | Short excerpt from the matched content |
| `matchType` | `'title' \| 'content'` | Whether the match occurred in title or body |
| `documentType` | `string?` | Optional content type classification |
| `externalUrl` | `string?` | External URL when result links outside the hub |
| `targetPlatform` | `string \| null \| undefined` | Platform owning `externalUrl`; drives same-tab vs. new-tab logic via `decideNewTab` |
| `sourceRepo` | `string?` | Repository the document originates from |
| `entityId` | `string?` | Primary key value for RAG table rows; enables chat panel drill-in via `entityIdFilter` for entities with no public viewer |

## Usage Example

```typescript
import type { DocSearchResult } from '@openframe-oss-lib/types'

const result: DocSearchResult = {
  path: '/docs/billing/cap-table',
  name: 'Cap Table Overview',
  type: 'file',
  snippet: '...equity breakdown by shareholder...',
  matchType: 'content',
  documentType: 'financial',
  entityId: 'row_abc123',
}

// Use entityId to open chat panel instead of navigating to a URL
if (result.entityId && !result.externalUrl) {
  openChatPanel({ entityIdFilter: result.entityId })
} else {
  navigate(result.externalUrl, { newTab: decideNewTab(result.targetPlatform) })
}
```

## Notes

- Must remain **field-for-field identical** with `lib/data/doc-search-utils.ts:DocSearchResult` in the hub — changes to either side must be mirrored.
- `entityId` is specifically intended for RAG table rows (e.g. `cap_table`, `financial-kpis`) that have no public viewer URL; consumers should prefer chat-panel drill-in over synthesizing a potentially invalid path URL.
