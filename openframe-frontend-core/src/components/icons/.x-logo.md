Renders a 24×24 SVG icon representing the X (formerly Twitter) logo, accepting standard SVG props for flexible styling.

## Key Components

### `XLogo`
**@deprecated** — Use icons from `icons-v2-generated` instead.

A React functional component that renders the X social media logo as an inline SVG.

| Prop | Type | Default | Description |
|---|---|---|---|
| `className` | `string` | `''` | CSS class applied to the `<svg>` element |
| `color` | `string` | `'white'` | Fill color for both SVG paths |
| `...props` | `React.SVGProps<SVGSVGElement>` | — | Any valid SVG attribute (e.g. `onClick`, `aria-label`) |

## Usage Example

```typescript
import { XLogo } from './x-logo';

// Default white icon
<XLogo />

// Custom color and size override via SVG props
<XLogo color="#000000" className="my-icon" width={32} height={32} />

// With accessibility label
<XLogo color="currentColor" aria-label="X (Twitter)" role="img" />
```

> **Migration note:** This component is deprecated. Replace usages with the equivalent export from `icons-v2-generated`:
> ```typescript
> // Preferred
> import { XIcon } from '@/icons-v2-generated';
> ```
