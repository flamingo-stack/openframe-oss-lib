Renders a styled comment card that adapts its layout based on context — showing vendor information when viewing a user profile, or user information when viewing a vendor page — with optional delete functionality based on auth state.

## Key Components

### `CommentCard` (default export)

A context-aware card component for displaying user-submitted vendor comments.

**Props (`CommentCardProps`):**

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `comment` | `object` | — | Comment data including content, author, vendor, and metadata |
| `context` | `'profile' \| 'vendor'` | `'profile'` | Controls layout and delete permission logic |
| `onViewProduct` | `(slug: string) => void` | — | Callback when vendor button is clicked |
| `onDeleteComment` | `(id: string) => void` | — | Callback when delete is triggered |
| `showVendorInfo` | `boolean` | `true` | Toggles vendor info display |
| `compact` | `boolean` | `false` | Reduces content area height |

**Internal logic:**

- `canUserDeleteComment()` — Grants delete access to authenticated users; in `profile` context, respects the `canDelete` prop; in `vendor` context, compares `currentUser.id` against `comment.user.id`
- `formatActivityTime()` — Delegates to `formatRelativeTime` utility for human-readable timestamps

## Usage Example

```typescript
<CommentCard
  context="vendor"
  comment={{
    id: "abc123",
    content: "Solid RMM tool for small MSPs.",
    title: "Great value",
    createdAt: "2025-06-01T12:00:00Z",
    user: {
      id: "user-42",
      name: "Jane Smith",
      profilePicture: null,
    },
    canDelete: true,
  }}
  onDeleteComment={(id) => console.log("Delete", id)}
/>
```
