An accessible, animated accordion component for rendering FAQ items with smooth expand/collapse transitions and deep-link anchor support.

## Key Components

### Interfaces

- **`FaqItem`** — Data shape for a single FAQ entry with `id`, `question`, and `answer` fields
- **`FaqAccordionProps`** — Props accepting an array of `FaqItem` and optional `defaultOpenIds` for pre-expanded items, `loading` (the questions are still being read: draws the skeleton, as a loading scope does) and `skeletonCount` (rows the skeleton draws)

### Component

- **`FaqAccordionSkeleton`** — The accordion while its questions are read: `count` closed rows (default `FAQ_ACCORDION_SKELETON_ROWS`, a typical list) drawn through `LoadingItems`, each in the row's own frame (`ROW_FRAME_CLASS`, read by both forms) and marked `data-loading-item`
- **`FaqAccordion`** — Stateful accordion managing open/close state via a `Set`, rendering each item with a clickable header, animated content panel, and per-item anchor ID for hash-based deep linking (e.g. `/faqs#faq-item-<id>`).

## Usage Example

```typescript
import { FaqAccordion, FaqItem } from './faq-accordion'

const items: FaqItem[] = [
  { id: 1, question: 'What is OpenFrame?', answer: 'A unified MSP platform...' },
  { id: 2, question: 'How does Mingo AI work?', answer: 'It automates triage...' },
]

// Render with the second item open by default
<FaqAccordion items={items} defaultOpenIds={[2]} />
```

## Behavior Notes

- **Keyboard accessible** — `Enter` and `Space` toggle items; `aria-expanded` reflects open state
- **Scroll margin** — Each row has `scroll-mt-24` so sticky nav (96px) doesn't obscure the header on hash navigation
- **Animation** — a grid-rows (`1fr` / `0fr`) + `opacity` transition at 300ms `ease-in-out`; no measurement
- **Mobile safety** — `break-words` prevents long URLs or tokens from clipping inside the `overflow-hidden` panel
