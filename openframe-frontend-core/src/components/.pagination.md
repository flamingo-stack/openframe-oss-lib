Accessible, client-side pagination component that renders page navigation with smart ellipsis logic and a set of composable sub-components for building custom pagination UIs.

## Key Components

| Export | Type | Description |
|---|---|---|
| `Pagination` | Component | Full-featured pagination with built-in page number generation, ellipsis, and prev/next controls |
| `PaginationContent` | `forwardRef` | Flex container (`<ul>`) for pagination items |
| `PaginationItem` | `forwardRef` | Wrapper `<li>` for individual pagination elements |
| `PaginationLink` | `forwardRef` | Styled `<button>` for individual page links |
| `PaginationEllipsis` | `forwardRef` | `<span>` rendering a `MoreHorizontal` icon with screen-reader text |
| `PaginationPrevious` | `forwardRef` | Previous-page `<button>` with `ChevronLeft` icon |
| `PaginationNext` | `forwardRef` | Next-page `<button>` with `ChevronRight` icon |

**Page number algorithm:** Shows up to 5 pages. For larger sets it always renders the first and last page, up to 3 middle pages around the current page, and inserts ellipsis (`-1`/`-2` sentinel values) where gaps exist.

## Usage Example

**Simple controlled pagination:**

```typescript
import { Pagination } from "@/components/pagination"

export function MyList() {
  const [page, setPage] = React.useState(1)

  return (
    <>
      <ItemList page={page} />
      <Pagination
        currentPage={page}
        totalPages={20}
        onPageChange={setPage}
        className="mt-4"
      />
    </>
  )
}
```

**Composable low-level API:**

```typescript
import {
  PaginationContent,
  PaginationItem,
  PaginationLink,
  PaginationPrevious,
  PaginationNext,
  PaginationEllipsis,
} from "@/components/pagination"

export function CustomPagination() {
  return (
    <nav aria-label="pagination">
      <PaginationContent>
        <PaginationItem><PaginationPrevious onClick={() => {}} /></PaginationItem>
        <PaginationItem><PaginationLink>1</PaginationLink></PaginationItem>
        <PaginationItem><PaginationEllipsis /></PaginationItem>
        <PaginationItem><PaginationNext onClick={() => {}} /></PaginationItem>
      </PaginationContent>
    </nav>
  )
}
```
