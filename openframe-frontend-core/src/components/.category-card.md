A client-side React card component for displaying a product category with its metadata, icon grid, and a navigation button.

## Key Components

### `CategoryCard`

A presentational card component that renders category information in a structured layout.

**Props (`CategoryCardProps`):**

| Prop | Type | Description |
|---|---|---|
| `name` | `string` | Category display name |
| `description` | `string` | Short description text |
| `categoryCount` | `number` | Number of subcategories |
| `productCount` | `number` | Number of products in the category |
| `icons` | `React.ReactNode[]` | Optional array of icon nodes; an empty row one tile high if empty |

## Usage Example

```typescript
import { CategoryCard } from "./category-card";
import { ServerIcon, DatabaseIcon } from "lucide-react";

export default function Page() {
  return (
    <CategoryCard
      name="Infrastructure"
      description="Tools for managing servers, networking, and cloud resources."
      categoryCount={5}
      productCount={42}
      icons={[<ServerIcon />, <DatabaseIcon />]}
    />
  );
}
```

## Notes

- **Client Component** — marked with `"use client"` for React interactivity.
- **Icon grid** — renders the provided icons; with none the row stays one tile high and empty (no placeholder tiles).
- **Loading** — in a loading scope the card draws `CategoryCardSkeleton` (`CATEGORY_CARD_SKELETON_ICONS` icon tiles, a typical card); both read their boxes from the constants exported beside the skeleton (`CATEGORY_CARD_FRAME_CLASS`, `CATEGORY_CARD_ICON_ROW_CLASS`, `CATEGORY_CARD_ICON_TILE_CLASS`, `CATEGORY_CARD_TEXT_BLOCK_CLASS`, `CATEGORY_CARD_TITLE_CLASS`, `CATEGORY_CARD_COUNTS_CLASS`, `CATEGORY_CARD_DESCRIPTION_ROW_CLASS`, `CATEGORY_CARD_DESCRIPTION_CLASS`, `CATEGORY_CARD_ACTION_BOX_CLASS`). The counts line's copy ("Categories", "Products") is drawn for real, each number a bar.
- **Navigation button** — includes an accessible `aria-label` using the category `name`; intended to trigger navigation to a category detail view (wire up an `onClick` or wrap in a link as needed).
- Styled with OpenDS design tokens (`ods-*`) for consistent theming across the OpenFrame UI.
