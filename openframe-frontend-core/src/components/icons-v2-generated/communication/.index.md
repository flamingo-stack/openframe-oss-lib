Barrel export file that re-exports all communication-related icon components from their individual modules, providing a single import point for the icon library's communication category.

## Key Components

This file exports **80 icon components** organized into logical groups:

| Group | Icons |
|---|---|
| **Call** | `CallIcon`, `CallHangupIcon`, `CallInboundIcon`, `CallOutboundIcon`, `CallMissed01Icon`, `CallMissed02Icon`, `CallRingingIcon`, `CallSignalIcon`, `CallLockIcon`, `CallUnlockIcon`, `CallPauseIcon`, `CallPlusIcon`, `CallMinusIcon`, `CallOffIcon`, `CallXmarkIcon` |
| **Chat** | `ChatBlankIcon`, `ChatCheckIcon`, `ChatEllipsisIcon`, `ChatExclamationIcon`, `ChatFaceIcon`, `ChatHeartIcon`, `ChatIndicatorIcon`, `ChatLanguageIcon`, `ChatMinusIcon`, `ChatOffIcon`, `ChatPlusIcon`, `ChatQuestionIcon`, `ChatQuoteIcon`, `ChatStarIcon`, `ChatTextIcon`, `ChatVoicemailIcon`, `ChatXmarkIcon`, `ChatsIcon` |
| **Email** | `EmailIcon`, `EmailArrowDownIcon`, `EmailArrowUpIcon`, `EmailBannedIcon`, `EmailCheckIcon`, `EmailHeartIcon`, `EmailLockIcon`, `EmailOpenIcon`, `EmailReadingIcon`, `EmailReadingHeartIcon`, `EmailSearchIcon`, `EmailShieldIcon`, `EmailsIcon` |
| **Message** | `MessageBlankIcon`, `MessageCheckIcon`, `MessageEllipsisIcon`, `MessageExclamationIcon`, `MessageFaceIcon`, `MessageHeartIcon`, `MessageIndicatorIcon`, `MessageLanguageIcon`, `MessageMinusIcon`, `MessageOffIcon`, `MessagePlusIcon`, `MessageQuestionIcon`, `MessageQuoteIcon`, `MessageRobotIcon`, `MessageStarIcon`, `MessageTextIcon`, `MessageVoicemailIcon`, `MessageXmarkIcon`, `MessagesIcon` |
| **Inbox** | `InboxIcon`, `InboxArrowDownIcon`, `InboxArrowUpIcon`, `InboxContentIcon`, `MailboxIcon` |
| **Misc** | `AtSignIcon`, `DeleteIcon`, `DialpadIcon`, `Send01Icon`, `Send02Icon`, `Send03Icon`, `StoryAddIcon`, `TelephoneRetroIcon`, `VoicemailIcon`, `MingoMonochromeIcon` |

## Usage Example

```typescript
// Import individual icons as needed
import { CallIcon, MessageTextIcon, EmailIcon } from '@openframe/icons/communication';

// Or import multiple icons
import {
  CallRingingIcon,
  ChatCheckIcon,
  EmailOpenIcon,
  InboxIcon,
  Send01Icon
} from '@openframe/icons/communication';
```
