A client-side dropdown component for filtering content by organization in the OpenFrame header, displaying the selected organization name and device count.

## Key Components

### Interfaces

- **`HeaderOrganizationFilterOrganization`** — Shape for each organization entry (`id`, `name`, optional `deviceCount`)
- **`HeaderOrganizationFilterProps`** — Props for the filter component

### Component

- **`HeaderOrganizationFilter`** — Renders a styled trigger button with a filter icon, organization name, and device count, backed by a dropdown menu of selectable organizations

### Behavior

- Defaults to `"All Organizations"` when no `selectedOrgId` matches
- Shows `totalDeviceCount` when no specific org is selected; shows org-level `deviceCount` when one is selected
- Calls `onOrgChange('')` to reset to all organizations; calls `onOrgChange(org.id)` on selection

## Usage Example

```typescript
import {
  HeaderOrganizationFilter,
  HeaderOrganizationFilterOrganization
} from './header-organization-filter'

const orgs: HeaderOrganizationFilterOrganization[] = [
  { id: 'org-1', name: 'Acme Corp', deviceCount: 42 },
  { id: 'org-2', name: 'Globex Inc', deviceCount: 17 },
]

function Header() {
  const [selectedOrgId, setSelectedOrgId] = useState('')

  return (
    <HeaderOrganizationFilter
      organizations={orgs}
      selectedOrgId={selectedOrgId}
      onOrgChange={setSelectedOrgId}
      totalDeviceCount={59}
    />
  )
}
```
