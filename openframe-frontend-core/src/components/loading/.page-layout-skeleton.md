Skeletons of shared page layout parts (header, search, category sidebar, breadcrumb, results header, vendor grid), composed only from the lib's skeleton components (`UnifiedSkeleton`, `TextLineSkeleton`, …) so they pulse with the one skeleton surface.

## Key Components

| Export | Description |
|---|---|
| `HeaderSkeleton` | Sticky header skeleton with logo, nav links, and action buttons (responsive) |
| `SearchContainerSkeleton` | Search input with optional filter chip row |
| `CategorySidebarSkeleton` | File-tree sidebar skeleton mimicking `MultiLevelNavigation` |
| `BreadcrumbSkeleton` / `BreadcrumbLinkSkeleton` | Breadcrumb trail, and one breadcrumb link |
| `ResultsHeaderSkeleton` | Results count / sort bar skeleton |
| `VendorGridSkeleton` | A grid of vendor card skeletons |

## Notes

- A component that shows read data draws its OWN `<Name>Skeleton` (beside it, sharing its class constants) in a `LoadingScope`; these are only for layout parts that have no component of their own.
