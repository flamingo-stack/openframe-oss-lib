The loading barrel: the skeleton PARTS a component builds its own loading form from, the loading region and Suspense
helpers, and a few deprecated whole-view skeletons kept for hosts on an older release.

THE RULE: a page's loading state is the page, drawn by its components. Every component switches itself
(`useLoadingScope() || props.loading`) and draws its own `<Name>Skeleton` from the parts below; a page never picks a
child's skeleton and draws no whole-view skeleton. `LoadingScope`, `LoadingWhen`, `LoadingItems` and `loadingItemProps`
live in `components/ui/loading-scope`.

## Key Components

### Skeleton parts
| Export | Source | Description |
|--------|--------|-------------|
| `UnifiedSkeleton` | `./unified-skeleton` | The one pulse: a box of the given class |
| `TextLineSkeleton` | `./unified-skeleton` | One or more text lines of a type step (`type`, `lines`) |
| `TextSkeleton`, `MediaSkeleton`, `InteractiveSkeleton` | `./unified-skeleton` | Composable text, media and control shapes |
| `CardSkeleton`, `CardSkeletonGrid` | `./card-skeleton` | Generic card |
| `CategoryCardSkeleton` | `./category-card-skeleton` | A category card |
| `OrganizationIconSkeleton` | `./organization-icon-skeleton` | An organization's icon box |
| `OrganizationCardSkeleton`, `OrganizationCardSkeletonGrid` | `./organization-card-skeleton` | An organization card |
| `SearchContainerSkeleton`, `CategorySidebarSkeleton`, `BreadcrumbSkeleton`, `BreadcrumbLinkSkeleton`, `ResultsHeaderSkeleton`, `VendorGridSkeleton` | `./page-layout-skeleton` | Parts of the catalog layouts |

### Loading region and Suspense
| Export | Source | Description |
|--------|--------|-------------|
| `LoadingRegion` | `./loading-region` | The region that announces a loading state once |
| `LoadingStatus` | `../ui/loading-scope` | The one polite status a loading state is read as |
| `LoadingFallback` | `./loading-fallback` | A Suspense fallback: the same component in a loading scope (`AnnouncedLoadingScope`). `status={false}`: no announcement (an inline part) |

A client read that must announce itself is `<LoadingWhen loading={…} label="…" as? className?>`: one always-mounted region (`AnnouncedLoadingScope`, the region `LoadingFallback` draws) whose status reads the label while loading. Never a `LoadingRegion` wrapped around a `LoadingWhen`.
| `LoadingSuspense` | `./loading-fallback` | A Suspense boundary whose fallback is its children (or `fallback`) in a loading scope; takes `status` too |
| `ContentLoadingContainer`, `useContentLoading` | `../content-loading-container` | Loading state container and hook |

### Deprecated (whole-view skeletons, kept for older hosts)
`MspProfileFormSkeleton`, `SettingsFormSkeleton`, `CategoryVendorSelectorSkeleton`, `BlogCardGridSkeleton`,
`SlackCommunitySkeleton`, `MarginReportSkeleton`. Render the component in a loading scope instead.

## Usage Example

```tsx
import { LoadingSuspense } from '@flamingo-stack/openframe-frontend-core/components';

<LoadingSuspense label="Loading the script" fallback={<ScriptView script={null} />}>
  <ScriptReader />
</LoadingSuspense>
```

> ⚠️ **Important:** `OpenmspHeartbeatLoader` is intentionally **excluded** from this barrel: it is client-only and must
> be imported directly from `./openmsp-heartbeat`.
