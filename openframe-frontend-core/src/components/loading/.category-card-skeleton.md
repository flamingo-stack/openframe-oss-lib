The category card while its category is read, built from `CategoryCard`'s own boxes, so the loading and the loaded card are one size.

## Key Components

- **`CategoryCardSkeleton`** — The card's frame, its icon row (`CATEGORY_CARD_SKELETON_ICONS` circular tiles, a typical card, each `data-loading-item`), the title as an `h2` bar, the counts line with its copy drawn for real ("Categories", "Products") and each number a bar, and the description as an `h6` bar beside the action's box.
- **Class constants** — `CATEGORY_CARD_FRAME_CLASS`, `CATEGORY_CARD_ICON_ROW_CLASS`, `CATEGORY_CARD_ICON_TILE_CLASS`, `CATEGORY_CARD_TEXT_BLOCK_CLASS`, `CATEGORY_CARD_TITLE_CLASS`, `CATEGORY_CARD_COUNTS_CLASS`, `CATEGORY_CARD_DESCRIPTION_ROW_CLASS`, `CATEGORY_CARD_DESCRIPTION_CLASS`, `CATEGORY_CARD_ACTION_BOX_CLASS`: read by `CategoryCard` and by this skeleton.

## Usage Example

A host never draws the skeleton itself: `CategoryCard` draws it in a loading scope.

```typescript
<LoadingScope>
  <CategoryCard name="" description="" categoryCount={0} productCount={0} />
</LoadingScope>
```
