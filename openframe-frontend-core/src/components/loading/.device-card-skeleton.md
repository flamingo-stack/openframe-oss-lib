The loading box of `DeviceCard`, box for box, and the class constants the card and its skeleton share.

## Key Components

### `DeviceCardSkeleton`
`DeviceCard` draws it itself (its `loading` prop, or a loading scope); hosts do not pick it.
- **Row 1:** the device-type icon (static, drawn for real), the OS icon box and the name line (`text-h4`) over the organization line (`text-h6`), the "more" button drawn for real (`moreButton`), the details button's box (`detailsButton`)
- **Row 2:** the status tag's own skeleton and the "Last Seen:" line (its label drawn for real)

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `moreButton` | `boolean` | `true` | The card shows its "more" button |
| `detailsButton` | `boolean` | `false` | The card shows a details button: a default-size button box |
| `className`, `data-*` | | | Applied to the root, as on the loaded card (`data-loading-item` for a list item) |

### Shared class constants
`DEVICE_CARD_FRAME_CLASS`, `DEVICE_CARD_HEAD_ROW_CLASS`, `DEVICE_CARD_NAME_STACK_CLASS`, `DEVICE_CARD_NAME_LINE_CLASS`, `DEVICE_CARD_STATUS_ROW_CLASS`, `DEVICE_CARD_ICON_BOX_CLASS`, `DEVICE_CARD_MORE_BUTTON_CLASS`, and `DEVICES_GRID_CLASS` (the grid `DevicesGrid` lays its cards in).

## Usage Example

```tsx
<DeviceCard device={device} loading={!device.name} data-loading-item />
```
