The devices grid's class and a deprecated alias of the device card's loading form.

## Key Components

### `DEVICES_GRID_CLASS`
The grid `DevicesGrid` lays its cards (and its next page) in: one column, two from `content-md`, three from `content-lg`.

### `DeviceCardSkeleton` (deprecated)
Renders `<DeviceCard loading />`: the card draws its own loading form from its one structure. Not re-exported from the loading barrel; render `DeviceCard` with `loading` (or in a loading scope) instead.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `moreButton` | `boolean` | `true` | The card shows its "more" button |
| `className`, `data-*` | | | Applied to the card's root |

## Usage Example

```tsx
<DeviceCard device={device} loading={!device.name} data-loading-item />
```
