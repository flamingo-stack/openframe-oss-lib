Tailwind CSS configuration for the OpenFrame OSS design system, extending the default theme with ODS (Open Design System) color tokens, custom typography utilities, and plugin integrations.

## Key Components

- **`odsTypographyPlugin`** — Custom Tailwind plugin registering `.text-h1` through `.text-h6`, `.text-code`, and `.text-badge` utility classes, each bound to CSS custom properties for font family, weight, size, and line height.
- **`withAlphaValue`** / **`withAlphaSupport`** — Utility functions that wrap `var()`-based color tokens with `color-mix()` so Tailwind's opacity modifier syntax (e.g., `bg-ods-error/10`) works correctly with CSS variable colors.
- **ODS color scale** (`ods.*`) — Nested color map covering backgrounds, borders, text, accent, status (`success`, `error`, `warning`, `info`), brand (`flamingo`, `open-yellow`), and attention tokens, all wrapped with alpha support.
- **Shadcn/ui base colors** — Retained `border`, `input`, `ring`, `background`, `foreground`, `primary`, `secondary`, `destructive`, `muted`, `accent`, `popover`, and `card` mappings for component library compatibility.
- **Plugins** — `tailwindcss-animate`, `@tailwindcss/container-queries`, and the local `odsTypographyPlugin`.

## Usage Example

```typescript
// tailwind.config.ts is consumed automatically by Tailwind CLI / PostCSS.
// Reference ODS tokens in component class strings:

// Typography
<h1 className="text-h1">Page Title</h1>
<code className="text-code">path/to/file</code>
<span className="text-badge">Active</span>

// ODS colors with opacity modifier
<div className="bg-ods-bg text-ods-text-primary border-ods-border" />
<div className="bg-ods-error/10 text-ods-error" />          // alpha modifier works
<div className="bg-ods-accent hover:bg-ods-accent-hover" />

// Brand colors
<div className="bg-ods-flamingo-pink text-ods-open-yellow" />

// Status / attention
<div className="border-ods-attention-red-error bg-ods-attention-red-error-secondary" />
```

> **Note:** All `ods-*` color classes require the corresponding CSS custom properties (e.g., `--color-bg`, `--color-accent-primary`) to be declared in a global stylesheet. The `withAlphaSupport` wrapper is transparent at full opacity — un-suffixed classes render identically to a direct `var()` reference.
