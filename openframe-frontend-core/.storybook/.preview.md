Storybook global preview configuration for the OpenFrame component library. Sets up theme toggling, decorators, and viewport presets used across all stories.

## Key Components

- **`globalTypes.theme`** — Toolbar toggle that switches between `dark` (default) and `light` ODS token themes by setting `data-theme` on `<html>`
- **`decorators`** — Array with a single decorator that reads the active theme from `context.globals` and applies it to `document.documentElement` before rendering each story
- **`parameters.controls.matchers`** — Auto-detects color and date props in the Storybook controls panel
- **`parameters.nextjs`** — Enables Next.js App Router compatibility (`appDirectory: true`)
- **`parameters.viewport`** — Restricts the viewport picker to three breakpoints that match ODS auth breakpoints: Mobile (430px), Tablet (800px), Desktop (1280px)
- **`initialGlobals`** — Starts stories with no viewport constraint (unconstrained/reset)

## Usage Example

Stories automatically inherit these globals. Override theme or viewport per-story:

```typescript
// stories/Button.stories.ts
import type { Meta, StoryObj } from '@storybook/nextjs-vite';
import { Button } from '../src/components/Button';

const meta: Meta<typeof Button> = {
  component: Button,
  // Force light theme for this story
  globals: {
    theme: 'light',
    viewport: { value: 'mobile' },
  },
};

export default meta;
```

Font styles are loaded via `storybook-fonts.css` (a Storybook-specific workaround since `next/font/google` is not available outside the Next.js runtime).
