Bootstraps `IntegratedToolAgentConfiguration` records on application startup by loading agent configuration JSON files from the classpath and persisting them via `IntegratedToolAgentService`, with version values injected from deployment-provided environment properties.

## Key Components

| Component | Description |
|---|---|
| `IntegratedToolAgentInitializer` | `ApplicationRunner` (`@Order(20)`) that drives the initialization sequence |
| `run()` | Entry point; reads configuration file paths from `AgentConfigurationProperties` and delegates to `processAgentConfiguration()` |
| `processAgentConfiguration()` | Loads a single JSON config from the classpath, deserializes it, applies version overrides, and calls `integratedToolAgentService.updateConfigurationFields()` |
| `applyVersionFromProperties()` | Dispatches to the matching `AgentVersionOverride` strategy to inject runtime versions |
| `AgentVersionOverride` (enum) | Strategy enum with two entries — `MESHCENTRAL` and `FLEETMDM` — each defining how versions from `ClientVersionsProperties` are applied to the configuration and its assets |
| `applyAssetVersion()` | Helper that sets a version on a named `ToolAgentAsset` within a configuration (used by `FLEETMDM` to patch the nested `osqueryd` asset) |

## Usage Example

```java
# application.yml (or env-equivalent)
openframe:
  agent:
    agent-configurations:
      - configs/meshcentral-agent.json
      - configs/fleetmdm-agent.json
  client-versions:
    mesh: "24.1.0"
    fleet: "4.50.0"
    osquery: "5.11.0"
```

```java
// The initializer runs automatically at startup via ApplicationRunner.
// No manual invocation required. Equivalent programmatic trigger:
IntegratedToolAgentInitializer initializer = new IntegratedToolAgentInitializer(
    objectMapper,
    integratedToolAgentService,
    agentConfigurationProperties,
    clientVersionsProperties
);
initializer.run(null); // loads, versions, and persists all configured agents
```

**Version override behaviour:**
- `meshcentral-agent` — top-level `version` set from `clientVersionsProperties.getMesh()`
- `fleetmdm-agent` — top-level `version` from `getFleet()`; nested `osqueryd` asset version from `getOsquery()`
- Any agent ID without a matching enum entry retains the version declared in its JSON file
