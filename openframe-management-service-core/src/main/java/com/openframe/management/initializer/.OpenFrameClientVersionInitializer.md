Initializes the `openframe-client` version from configuration at application startup by delegating to `ClientVersionService`, triggering full version propagation across related components.

## Key Components

| Component | Description |
|---|---|
| `OpenFrameClientVersionInitializer` | `ApplicationRunner` that runs at startup (Order 40) to sync the client version from config |
| `ClientVersionService#process(String)` | Delegate that updates the client config version and bumps all `releaseVersion=true` IntegratedToolAgents |
| `ClientVersionsProperties#getClient()` | Reads the version string from `openframe.client-versions.client` (sourced from the deployed platform image tag) |

**Startup Order:**

```text
Order 20 → IntegratedToolAgentInitializer
Order 30 → OpenFrameClientConfigurationInitializer
Order 40 → OpenFrameClientVersionInitializer  ← this class
```

This ordering guarantees target documents exist before version propagation runs.

## Usage Example

```java
// Configuration property (application.yml / platform image tag)
// openframe.client-versions.client: 1.4.2

// At startup, ApplicationRunner.run() is called automatically:
// 1. Reads clientVersionsProperties.getClient() → "1.4.2"
// 2. Calls clientVersionService.process("1.4.2")
//    - Updates openframe-client configuration version
//    - Bumps all IntegratedToolAgents with releaseVersion=true to "1.4.2"
//    - Marks those agents for republish
```

This class requires no manual invocation — Spring Boot calls `run()` automatically after the application context is fully loaded.
