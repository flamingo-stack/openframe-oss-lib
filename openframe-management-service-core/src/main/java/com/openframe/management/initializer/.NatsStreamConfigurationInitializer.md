Initializes NATS JetStream stream configurations at application startup by registering a set of predefined streams and any additional provider-supplied streams via `NatsStreamManagementService`.

## Key Components

| Element | Description |
|---|---|
| `CONFIGURATIONS` | Static list of five hardcoded `StreamConfiguration` definitions covering tool installation/uninstall, client updates, tool agent updates, tool connections, and installed agents |
| `NatsStreamManagementService` | Dependency used to persist/register each stream configuration |
| `AdditionalStreamConfigurationProvider` | Dependency that supplies supplementary stream configurations beyond the static defaults |
| `run(ApplicationArguments)` | `ApplicationRunner` hook that iterates both the static list and the additional provider list, calling `save` for each |

### Stream Subjects

| Stream Name | Subject Pattern(s) |
|---|---|
| `TOOL_INSTALLATION` | `machine.*.tool-installation`, `machine.*.tool-uninstall` |
| `CLIENT_UPDATE` | `machine.*.client-update` |
| `TOOL_UPDATE` | `machine.*.tool.*.update` |
| `TOOL_CONNECTIONS` | `machine.*.tool-connection` |
| `INSTALLED_AGENTS` | `machine.*.installed-agent` |

All streams use `StorageType.File` and `RetentionPolicy.Limits`.

## Usage Example

```java
// Automatic — triggered by Spring Boot on startup.
// To add streams without modifying CONFIGURATIONS, implement AdditionalStreamConfigurationProvider:

@Component
public class CustomStreamProvider implements AdditionalStreamConfigurationProvider {

    @Override
    public List<StreamConfiguration> provide() {
        return List.of(
            StreamConfiguration.builder()
                .name("CUSTOM_EVENTS")
                .subjects(List.of("machine.*.custom-event"))
                .storageType(StorageType.File)
                .retentionPolicy(RetentionPolicy.Limits)
                .build()
        );
    }
}
```
