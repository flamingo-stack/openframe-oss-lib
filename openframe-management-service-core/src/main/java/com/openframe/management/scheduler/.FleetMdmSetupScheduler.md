Scheduled component that periodically checks whether the FleetMDM server integration requires initial setup, triggering token provisioning if the tool is registered.

## Key Components

| Member | Type | Description |
|---|---|---|
| `FLEETMDM_SERVER` | `String` constant | Repository lookup key `"fleetmdm-server"` used to find the FleetMDM tool record |
| `toolRepository` | `IntegratedToolRepository` | Queries the data layer for registered integrations |
| `fleetMdmSetupService` | `FleetMdmSetupService` | Performs the actual setup and API token persistence |
| `runSetupIfNeeded()` | `@Scheduled` method | Polls at a configurable interval; calls `setupAndSaveApiToken` only when the FleetMDM tool record exists |

**Activation guard:** The entire scheduler is disabled unless `openframe.fleet-mdm.setup.enabled=true` is set (`@ConditionalOnProperty`).

## Configuration Properties

| Property | Default | Description |
|---|---|---|
| `openframe.fleet-mdm.setup.enabled` | *(absent = disabled)* | Must be `true` to activate the scheduler |
| `openframe.fleet-mdm.setup.scheduler-interval-ms` | `30000` | Fixed delay (ms) between polling cycles |

## Usage Example

```java
// application.yml
openframe:
  fleet-mdm:
    setup:
      enabled: true
      scheduler-interval-ms: 60000  # poll every 60 s
```

```java
// Scheduler fires automatically; no direct invocation needed.
// If the fleetmdm-server tool record is present, setup runs:
toolRepository.findByKey("fleetmdm-server")
    .ifPresent(fleetMdmSetupService::setupAndSaveApiToken);
```

Errors are caught and logged at `ERROR` level; the scheduler retries automatically on the next tick, making it safe for transient startup failures.
