Binds `openframe.client-versions.*` configuration properties to a typed Spring component, exposing version strings for the four OpenFrame client components.

## Key Components

| Field | Type | Description |
|---|---|---|
| `client` | `String` | Version string for the OpenFrame client |
| `mesh` | `String` | Version string for the mesh component |
| `fleet` | `String` | Version string for the fleet component |
| `osquery` | `String` | Version string for the osquery component |

## Usage Example

**`application.yml` configuration:**

```yaml
openframe:
  client-versions:
    client: "1.2.3"
    mesh: "2.0.1"
    fleet: "3.1.0"
    osquery: "5.10.2"
```

**Injecting and reading properties:**

```java
@Service
@RequiredArgsConstructor
public class ClientVersionService {

    private final ClientVersionsProperties clientVersionsProperties;

    public String getClientVersion() {
        return clientVersionsProperties.getClient();
    }

    public Map<String, String> getAllVersions() {
        return Map.of(
            "client",  clientVersionsProperties.getClient(),
            "mesh",    clientVersionsProperties.getMesh(),
            "fleet",   clientVersionsProperties.getFleet(),
            "osquery", clientVersionsProperties.getOsquery()
        );
    }
}
```

> All getters/setters are generated by Lombok `@Data`. The `@Component` annotation ensures the bean is registered automatically — no additional `@EnableConfigurationProperties` declaration is required.
