Mongock migration change unit that backfills the `quickActionsIsDefault` boolean field on existing `agent_llm_settings` MongoDB documents for a given tenant.

## Key Components

| Element | Description |
|---|---|
| `@ChangeUnit(id = "backfill-agent-llm-settings-quick-actions-is-default", order = "008")` | Registers this migration with Mongock; runs after the `seed-agent-llm-settings` step (order 006) |
| `execution()` | Applies an aggregation pipeline update to all tenant-scoped `agent_llm_settings` records that lack the `quickActionsIsDefault` field |
| `rollback()` | No-op rollback; the backfill is treated as safe to leave in place |

**Backfill logic:** Sets `quickActionsIsDefault = true` when the record's `quickActions` list is absent or empty (never customized → inherit Multi Platform Hub defaults), and `false` when a non-empty list is already stored (tenant has made explicit customizations).

**Idempotency:** The filter includes `{ quickActionsIsDefault: { $exists: false } }`, so re-running the migration only touches records that have not yet been updated.

## Usage Example

```java
// Mongock discovers and executes this change unit automatically during application startup.
// No manual invocation is needed. The dependency injection provides:
//   - MongoTemplate  → raw collection access (AgentLlmSettings is in the SaaS lib, not this module)
//   - TenantIdProvider → scopes the update to the current tenant

// Equivalent MongoDB aggregation pipeline update (for reference):
// db.agent_llm_settings.updateMany(
//   { tenantId: "<id>", quickActionsIsDefault: { $exists: false } },
//   [{ $set: { quickActionsIsDefault: { $eq: [{ $size: { $ifNull: ["$quickActions", []] } }, 0] } } }]
// )
```
