A Mongock `@ChangeUnit` (order `003`) that migrates the `tickets` collection from a flat legacy `status` string field to the structured `statusId`/`statusKind` model, and seeds required `TicketStatusDefinition` documents. Guarded by a feature flag (`openframe.features.tickets.lifecycle.enabled`) with `runAlways=true` pending full rollout.

## Key Components

| Member | Description |
|---|---|
| `LEGACY_TO_KIND` | Static map translating legacy status strings (`ACTIVE`, `TECH_REQUIRED`, `RESOLVED`, `ARCHIVED`) to `TicketStatusKind` enum values |
| `execution()` | Entry point: checks the lifecycle feature flag, seeds status definitions, then migrates all matching tickets |
| `seedStatuses()` | Upserts system statuses from `TicketStatusSeedCatalog`; conditionally seeds the custom `ON_HOLD` status if absent |
| `migrateTickets()` | Queries tickets missing `statusId` for the current tenant and drives per-ticket migration with counters |
| `resolveTarget()` | Maps a legacy status string to a `TicketStatusDefinition`; handles `ON_HOLD` separately with a `TECH_REQUIRED` fallback |
| `applyUpdate()` | Atomically sets `statusId`, `statusKind`, `updatedAt` and unsets the legacy `status` field on a single ticket |
| `rollback()` | No-op rollback (migration is additive; manual reversal required if needed) |

## Usage Example

```java
// Mongock discovers and runs this unit automatically at application startup.
// To enable the migration, set the feature flag in your environment:

// application.yml
openframe:
  features:
    tickets:
      lifecycle:
        enabled: true

// Legacy ticket document (before migration):
// { "_id": "abc123", "tenantId": "t1", "status": "ACTIVE", ... }

// Ticket document after migration:
// { "_id": "abc123", "tenantId": "t1",
//   "statusId": "<ObjectId of AI_ASSISTANCE status>",
//   "statusKind": "AI_ASSISTANCE",
//   "updatedAt": "2025-01-15T10:00:00Z" }
```

> **Note:** The `runAlways = true` flag is temporary. Once the lifecycle feature is permanently enabled and all tenants are migrated, the flag guard and `Environment` parameter should be removed and `runAlways` dropped per the inline `TODO(lifecycle-rollout)` comments.
