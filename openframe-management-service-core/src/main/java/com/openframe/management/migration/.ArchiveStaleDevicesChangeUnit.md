Mongock change unit that archives stale `OFFLINE` devices by transitioning them to `ARCHIVED` status when they haven't been seen for over one week, gated behind a feature flag.

## Key Components

| Member | Description |
|---|---|
| `ARCHIVE_STALE_FLAG` | Spring property `openframe.features.devices.archive-stale.enabled` that gates execution |
| `MANAGED_STATUSES` | Only `DeviceStatus.OFFLINE` devices are targeted; terminal states (`DECOMMISSIONED`, `DELETED`, etc.) are never touched |
| `STALE_THRESHOLD_WEEKS` | Devices not seen for more than **7 days** are considered stale |
| `execution()` | Mongock `@Execution` entry point; resolves the tenant, checks the flag, and delegates to `archiveStaleDevices()` |
| `archiveStaleWithStatus()` | Queries `Machine` documents by tenant, status, and `lastSeen < threshold`, then bulk-updates via `updateMulti` |
| `archiveUpdate()` | Builds the `Update` setting `status=ARCHIVED`, `updatedAt`, and a `migrationData` audit document recording `archivedBy`, `previousStatus`, and `archivedAt` |
| `rollback()` | No-op rollback — archived state is intentionally not reversed automatically |

## Usage Example

```java
// Triggered automatically by Mongock on application startup.
// Enable via Spring property (application.yml):
openframe:
  features:
    devices:
      archive-stale:
        enabled: true
```

```java
// The migration runs as change ID "archive-stale-devices" (order 005).
// runAlways=true means it executes on every startup while the flag is active.
// Once the flag is permanently enabled, remove runAlways and the flag guard
// to convert this into a standard one-shot migration.
@ChangeUnit(id = "archive-stale-devices", order = "005", author = "openframe", runAlways = true)
```

> **Note:** The `migrationData` audit field written to each archived `Machine` document preserves the `previousStatus` and timestamp for traceability. See the [source](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/management/migration/ArchiveStaleDevicesChangeUnit.java) for full field constants.
