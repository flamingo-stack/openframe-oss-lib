A deprecated no-op REST controller that accepts `POST /v1/cluster-registrations` requests and returns HTTP 2xx without performing any action, preserving backward compatibility for the cluster-registration DevOps job during migration.

## Key Components

- **`ReleaseVersionController`** — `@RestController` mapped to `/v1/cluster-registrations`; annotated with `@Deprecated(forRemoval = true)` pending deletion by 2026-07-11.
- **`updateReleaseVersion(String request)`** — Accepts an optional request body, logs a warning, and exits immediately. The openframe-client version is now set at startup via `OpenFrameClientVersionInitializer`.

## Usage Example

```java
// POST /v1/cluster-registrations
// Returns: 200 OK (empty body)
// Logs: WARN "Deprecated no-op endpoint POST /v1/cluster-registrations was called..."

// The version is now configured via application properties at startup:
// openframe.client-versions.client=<version>
// Handled by OpenFrameClientVersionInitializer — no HTTP call needed.
```

## Deprecation Notice

> **Remove by 2026-07-11.** This endpoint exists solely so the existing cluster-registration DevOps job continues to receive a `2xx` response while it is migrated off this endpoint. Once the caller is removed, delete this controller entirely.

See [`OpenFrameClientVersionInitializer`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/management/initializer/OpenFrameClientVersionInitializer.java) for the replacement startup-time version initialization logic.
