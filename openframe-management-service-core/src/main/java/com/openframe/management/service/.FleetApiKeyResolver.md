Resolves a Fleet MDM API key for an integrated tool by bootstrapping Fleet's initial setup (or falling back to login if already initialized) and ensuring an API-only service user exists, returning a valid authentication token.

## Key Components

| Member | Description |
|---|---|
| `API_USER_NAME` | Display name constant for the managed API service user (`"API Service User"`) |
| `API_USER_ROLE` | Role granted to the API user (`"admin"`) |
| `validateTenantConfig()` | `@PostConstruct` hook that validates multi-tenancy configuration on startup |
| `resolve(IntegratedTool)` | Entry point — extracts the Fleet API URL, runs setup/login, and returns a valid API token |
| `extractApiUrl(IntegratedTool)` | Finds the `ToolUrlType.API` URL from the tool's configured URLs, appending port if present |
| `setupOrLogin(...)` | Attempts Fleet initial setup; falls back to admin login on `4xx` (already initialized) |
| `createOrLoginApiUser(...)` | Creates an API-only user; falls back to login on `4xx` (user already exists) |

## Usage Example

```java
@Service
@RequiredArgsConstructor
public class FleetIntegrationService {

    private final FleetApiKeyResolver fleetApiKeyResolver;
    private final IntegratedToolRepository toolRepository;

    public String getFleetToken(String toolId) {
        IntegratedTool tool = toolRepository.findById(toolId)
            .orElseThrow(() -> new IllegalArgumentException("Tool not found: " + toolId));

        // Resolves or bootstraps a Fleet MDM API token for the given tool.
        // Handles first-run setup and idempotent re-runs transparently.
        return fleetApiKeyResolver.resolve(tool);
    }
}
```

> **Idempotency:** Both `setupOrLogin` and `createOrLoginApiUser` treat `4xx` responses as "already exists" signals and fall back gracefully to login, making `resolve()` safe to call on repeated invocations.

## Notes

- Multi-tenancy support is controlled via `openframe.fleet.multi-tenancy.enabled` and the `TENANT_ID` environment variable, validated eagerly at startup.
