Unit test suite for `SeedAgentLlmSettingsChangeUnit`, validating the Mongock migration that seeds `agent_llm_settings` documents for `CLIENT` and `ADMIN` agent types from the tenant's active AI model configuration.

## Key Components

| Component | Role |
|---|---|
| `SeedAgentLlmSettingsChangeUnit` | Subject under test — the Mongock change unit being validated |
| `activeConfigReturns(Document)` | Helper that stubs the `ai_model_configs` collection lookup chain |
| `anthropicConfig()` | Factory for a realistic Anthropic provider config document |
| `agentTypeIs(String)` | Custom `ArgumentMatcher` for filtering by `agentType` field in Bson queries |

## Test Coverage

| Test | Scenario |
|---|---|
| `seedsBothWhenMissing` | Inserts both `CLIENT` and `ADMIN` records when neither exists |
| `seedsOnlyMissingAgentType` | Inserts only the absent agent type when one already exists |
| `skipsWhenPresent` | No insert when both records already exist |
| `skipsWhenNoActiveConfig` | Skips entirely when no active model config is found |
| `skipsWhenNoProvider` | Skips when the active config has no `providerConfig` sub-document |
| `skipsWhenModelBlank` | Skips when `modelName` is blank/whitespace |
| `swallowsConcurrentDuplicateKey` | Duplicate-key error (code `11000`) on insert does not fail the migration |

## Usage Example

```java
// Run the full test class with JUnit 5
@ExtendWith(MockitoExtension.class)
class SeedAgentLlmSettingsChangeUnitTest {

    // Verify inserted documents carry correct shape
    assertThat(docs).allSatisfy(d -> {
        assertThat(d.getString("tenantId")).isEqualTo(TENANT);
        assertThat(d.getString("llmProvider")).isEqualTo("ANTHROPIC");
        assertThat(d.getString("providerModel")).isEqualTo("claude-opus-4-8");
        assertThat(d.get("createdAt")).isInstanceOf(Date.class);
        assertThat(d.getString("_class"))
            .isEqualTo("com.openframe.data.document.ai.AgentLlmSettings");
    });
}
```

> **Note:** The `anthropicConfig()` fixture mirrors the Spring Data MongoDB polymorphic discriminator pattern where a concrete subtype (`AnthropicConfig`) stores its type under the `"type"` key inside `providerConfig`, not as a top-level field.
