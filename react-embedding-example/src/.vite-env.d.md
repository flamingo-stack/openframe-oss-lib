Vite environment type declarations for the OpenFrame OSS library, extending the default `ImportMetaEnv` interface with project-specific environment variables.

## Key Components

| Name | Type | Description |
|---|---|---|
| `ImportMetaEnv` | Interface | Extends Vite's env interface with OpenFrame-specific variables |
| `VITE_HUB_ORIGIN` | `string \| undefined` | Public hub origin URL used for new-tab content links in embed mode |
| `ImportMeta` | Interface | Re-declares `import.meta.env` with the typed `ImportMetaEnv` shape |

## Usage Example

```typescript
// Access the typed env variable anywhere in the codebase
const hubOrigin = import.meta.env.VITE_HUB_ORIGIN ?? 'https://hub.openframe.ai'

// Example: construct a content link for embed mode
function getContentUrl(path: string): string {
  const origin = import.meta.env.VITE_HUB_ORIGIN
  if (!origin) return path
  return `${origin}${path}`
}
```

Set the variable in your `.env` file:

```bash
# .env
VITE_HUB_ORIGIN=https://hub.openframe.ai
```

> **Note:** The `VITE_` prefix is required by Vite to expose variables to client-side code. Variables without this prefix remain server-only and will be `undefined` at runtime.

## Notes

- The `/// <reference types="vite/client" />` directive pulls in Vite's built-in `ImportMeta` and `ImportMetaEnv` base types — this file augments rather than replaces them.
- `VITE_HUB_ORIGIN` is optional (`?`), so always guard against `undefined` before use.
- Source: [`vite-env.d.ts`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/vite-env.d.ts)
