Thin wrapper page component that renders the FAQ section by delegating all layout and data-fetching to `FaqDocumentPage` from the shared frontend core library.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `FaqsPage` | React component | Config-only page component; passes `apiBaseUrl` and `subtitle` to `FaqDocumentPage` |

**Dependencies:**

- `FaqDocumentPage` — from `@flamingo-stack/openframe-frontend-core/components`; owns the full page chrome (PageShell, hero, back button) and self-fetches FAQs via `${apiBaseUrl}/api/faqs`
- `CONTENT_PREFIX` — proxy prefix that rewrites `/content/api/faqs` to the hub, serving the platform-only active FAQ list

## Behavior Notes

- **No entity scope** → hub returns the platform-wide active FAQ list, matching the hub's SSR `/faqs` page output byte-for-byte
- **Back button** — uses the default `"Back to home" → /` affordance (do **not** pass `backButton={false}`; only `legal` pages opt out)
- **No local data-fetching** — all network calls are handled inside `FaqDocumentPage`

## Usage Example

```typescript
// Registered as a route in the app router, e.g.:
// { path: '/faqs', element: <FaqsPage /> }

import { FaqsPage } from './pages/faqs'

export const routes = [
  { path: '/faqs', element: <FaqsPage /> },
]
```
