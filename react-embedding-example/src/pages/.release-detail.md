Route component that renders a full product release detail page by composing injected section components and a host-supplied data hook into the library's `ReleaseDetailPage` shell.

## Key Components

| Export / Symbol | Description |
|---|---|
| `ReleaseDetailRoute` | Primary route component; reads `:slug` from the URL and delegates to `ReleaseDetailPage` |
| `useRelease` | Host-side React Query hook that fetches a single release by slug via `EP.productReleaseBySlug` |
| `RoadmapSection` | Injected section wrapping `RoadmapGrid` with hub-scoped voting/refresh endpoints |
| `VideoDisplaySection` | Injected section forwarding `VideoDisplaySectionProps` to `EntityVideoSection` for a tabbed Full Video / Highlights player |
| `DeliverySection` | Injected section rendering completed and in-progress `DeliveryTable`s from the library's fetched `DeliveryResponse` |

## Usage Example

Register the route in your router and let it handle the rest — all section components and API endpoints are wired internally:

```typescript
import { ReleaseDetailRoute } from './routes/release-detail'

// In your router definition
const routes = [
  {
    path: '/releases/:slug',
    element: <ReleaseDetailRoute />,
  },
]
```

The host-supplied `useRelease` hook feeds data through the app's `QueryClient`, so standard React Query caching and error boundaries apply automatically. A fetch failure surfaces the library's built-in error state rather than crashing the route.

## Notes

- **Injection pattern:** `ReleaseDetailPage` gates optional sections (`VideoDisplaySection`, `DeliverySection`, `RoadmapSection`) on prop presence — omitting any falls back to the library's default behavior (e.g., multiple separate video players instead of tabs).
- **Endpoint config:** All API paths come from [`EP`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/config/endpoints.ts) — swap endpoint constants there without touching this file.
- **Type safety:** `VideoDisplaySectionProps` is a structural subset of `EntityVideoSection`'s props, so props forward verbatim with no adapter needed.
