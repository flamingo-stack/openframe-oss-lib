Thin page component that wires the Delivery section UI to its API endpoints, delegating all chrome (hero, search, task-type filter) and table rendering to `DevSectionPage` and `DeliveryLists` from the shared component library.

## Key Components

| Export | Type | Description |
|---|---|---|
| `DeliveryPage` | React component | Composes `DevSectionPage` and `DeliveryLists`, injecting only the two API endpoint URLs |

### Props passed to child components

| Prop | Source | Description |
|---|---|---|
| `sectionKey="delivery"` | Hardcoded | Identifies the section for URL-param-wired chrome (hero, search, task-type filter) |
| `completedApiEndpoint` | `EP.deliveryCompleted` | Endpoint for the completed deliveries table |
| `inProgressApiEndpoint` | `EP.deliveryInProgress` | Endpoint for the active/in-progress deliveries table |

## Usage Example

```typescript
import { DeliveryPage } from './pages/delivery'

// In your router config:
{
  path: '/delivery',
  element: <DeliveryPage />,
}
```

> **Note:** All filtering and search state is managed via URL params inside `DevSectionPage`. `DeliveryPage` itself holds no local state — adding or changing query behaviour should be done at the `DeliveryLists` or `DevSectionPage` level in `@flamingo-stack/openframe-frontend-core`.
