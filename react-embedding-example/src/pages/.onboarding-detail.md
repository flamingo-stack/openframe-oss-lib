Thin route-level wrapper that connects React Router's URL slug to the `OnboardingGuideDetailView` component from the OpenFrame frontend core library.

## Key Components

- **`OnboardingDetailPage`** — Page component that extracts the `slug` param from the current route and passes it, along with the API endpoint and base path, to the core library's detail view. Contains no local data-fetching logic; all guide retrieval is handled internally by `OnboardingGuideDetailView`.

## Usage Example

```typescript
// routes.tsx
import { OnboardingDetailPage } from './pages/onboarding-detail'

const routes = [
  {
    path: '/onboarding-guides/:slug',
    element: <OnboardingDetailPage />,
  },
]
```

```typescript
// EP config (config/endpoints.ts)
export const EP = {
  onboardingBySlug: '/api/onboarding-guides/:slug',
  // ...
}
```

## Props Passed to Core View

| Prop | Source | Description |
|---|---|---|
| `slug` | `useParams()` | Guide identifier extracted from the URL |
| `guideEndpoint` | `EP.onboardingBySlug` | API route used by the core lib to fetch guide data |
| `basePath` | `"/onboarding-guides"` | Base navigation path for back-links and breadcrumbs |

## Notes

- Falls back to an empty string (`''`) if `slug` is undefined, guarding against optional param edge cases.
- No local state or side effects — purely a configuration bridge between the router and the core library.
- See [`OnboardingGuideDetailView`](https://github.com/flamingo-stack/openframe-oss-lib) for the full rendering and data-fetching implementation.
