Renders the OpenFrame contact page by mounting the self-contained `ContactForm` component from the frontend core library.

## Key Components

- **`ContactPage`** — Page-level wrapper that renders `ContactForm` inside a padded container. No local state or hooks required; the form reads its submission endpoint (`contactUrl`) from the ambient `EndpointsRuntime` provider automatically.

## Usage Example

```typescript
// Route this component directly from your router, e.g. React Router or TanStack Router
import { ContactPage } from './contact'

// In your route definition:
<Route path="/contact" element={<ContactPage />} />
```

> **Prerequisite:** An `EndpointsRuntime` provider must be mounted higher in the tree so `ContactForm` can resolve `EP.contact` internally. No additional props, hooks, or schema imports are needed at the host level.

## Notes

- Customize the visible copy by passing `title` and `subtitle` props directly to `ContactForm` if this page is reused in another context.
