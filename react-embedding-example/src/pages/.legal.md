Renders legal document pages (Privacy Policy and Terms of Service) by combining route parameters with per-document copy strings and delegating display to the shared `LegalDocumentPage` component.

## Key Components

- **`COPY`** — Static record mapping `docType` keys (`"privacy"` | `"terms"`) to their respective UI strings: title, fallback description, contact email, error/empty-state messaging.
- **`LegalPage`** — Route-level component that reads the `:docType` param, resolves the correct copy (defaulting to `"privacy"`), and renders `LegalDocumentPage` with the appropriate API endpoint.

## Usage Example

```typescript
// Register in your router
import { LegalPage } from './pages/legal'

// Route definition
{
  path: '/legal/:docType',
  element: <LegalPage />,
}

// Navigating to /legal/terms renders Terms of Service
// Navigating to /legal/privacy renders Privacy Policy
// Navigating to /legal/unknown falls back to Privacy Policy copy
```

## Notes

- The `:docType` param defaults to `"privacy"` if absent or unrecognised.
- API content is fetched via `EP.legal(docType)` — see [`src/config/endpoints`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/config/endpoints.ts) for the endpoint definition.
- `backButton={false}` suppresses the navigation back button, appropriate for standalone legal pages linked from footers.
- To add a new document type (e.g. `"cookies"`), add an entry to `COPY` and ensure `EP.legal` handles the new slug.
