Thin page-level wrapper that renders the Help Center ticket list for the OpenFrame dev shell.

## Key Components

- **`TicketsPage`** — Exported React component that mounts `HelpCenterList` from the `@flamingo-stack/openframe-frontend-core` package. Acts as a route-level entry point with no additional props or state.

## Usage Example

```typescript
// Route registration (e.g. in your router config)
import { TicketsPage } from './pages/tickets'

const routes = [
  { path: '/tickets', element: <TicketsPage /> },
]
```

## Notes

- `HelpCenterList` internally composes the `DevSectionPage` chrome, a ticket-creation form, and the ticket list. No additional configuration is required in this wrapper.
- Customer identity is resolved automatically via `ChatRuntime` (proxy-injected at runtime).
- API calls target `/api/chat/agent/*`, which are handled by the dev-only proxy fallback configured in `vite.config.ts`. Once the optional `agentBaseUrl` seam is available in the core lib, this proxy dependency will be removable.
