Renders a proof-of-embed page for the `<ShareExperienceSection>` component, validating that the case-studies "Share Your Experience" review-CTA block lifted from `multi-platform-hub` works correctly when consumed from the shared library.

## Key Components

- **`CaseStudiesPage`** — Exported page component that wraps `<ShareExperienceSection>` in a padded container, serving as a live embed verification surface
- **`ShareExperienceSection`** — Imported from `@flamingo-stack/openframe-frontend-core`, renders the review/CTA block including an inner `<ContactForm>`

## Runtime Wiring

The embedded `<ContactForm>` resolves its submission endpoint via the ambient `EndpointsRuntime.contactUrl`, set in `app-providers.tsx` as `${CONTENT_PREFIX}/api/contact`. The Vite dev proxy forwards this to the hub's `/api/contact`, giving the embed a fully functional form submission with zero per-call-site configuration — the same proxy seam used by the `/contact` page's `<ContactForm>`.

## Usage Example

```typescript
import { CaseStudiesPage } from './case-studies'

// Drop into any route that needs to validate the ShareExperienceSection embed
export const routes = [
  {
    path: '/case-studies',
    element: <CaseStudiesPage />,
  },
]
```

## Notes

- Copy is intentionally left at lib defaults (matching the hub's `/case-studies` UX) so returning case-study candidates see a consistent experience
- No additional props or context wiring required beyond what `app-providers.tsx` already establishes
