Renders the OpenFrame embedding demo home page, displaying a navigable grid of all available UI surfaces backed by `@flamingo-stack/openframe-frontend-core` components.

## Key Components

- **`SURFACES`** — Static array of route descriptors (`to`, `title`, `desc`) enumerating every embedded surface and its underlying API endpoint
- **`HomePage`** — Default page component; renders a header, a context paragraph explaining the `/content` reverse proxy + identity injection, and a responsive card grid linking to each surface

## Usage Example

```typescript
import { HomePage } from './home'
import { BrowserRouter } from 'react-router-dom'

// Typically mounted via a route definition:
// <Route path="/" element={<HomePage />} />

export function App() {
  return (
    <BrowserRouter>
      <HomePage />
    </BrowserRouter>
  )
}
```

## Surface Routes

| Path | Surface |
|---|---|
| `/knowledge-base` | Knowledge Hub (docs + RAG search) |
| `/onboarding-guides` | Onboarding catalog + detail |
| `/roadmap` | Voting grid |
| `/delivery` | Bug-fix & enhancement tables |
| `/releases` | Product releases list + detail |
| `/authors` | Author byline + related content rail |
| `/faqs` | Grouped accordion + JSON-LD |
| `/legal/privacy` | Privacy / terms |
| `/contact` | Contact form |
| `/case-studies` | Share Your Experience section |
| `/tickets` | Help center ticket list |

## Notes

- All surfaces proxy through `/content` which injects a chat secret and a fixed identity (`Michael Assraf`) for server-side AI greeting resolution
- Card styles use ODS design tokens (`ods-text-primary`, `ods-border`, `ods-card`) for theme consistency
- Source: [`src/home.tsx`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/home.tsx)
