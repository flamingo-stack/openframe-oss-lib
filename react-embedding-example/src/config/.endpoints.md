Centralized API endpoint registry for the OpenFrame hub. All backend route strings are derived from a single `CONTENT` base and exported as a frozen `EP` object, ensuring no endpoint literal is duplicated across the runtime factory, data layer, or pages.

## Key Components

### `EP` (const object)

The single source of truth for all hub API paths. Grouped by domain:

| Group | Members |
|---|---|
| **Chat** | `chatStream`, `commands`, `emptyState`, `aiAgent(slug)` |
| **Docs** | `docsSearch`, `docsStructure(sourceId)`, `docsContent(sourceId)`, `resolveLink` |
| **Agent** | `agentBase`, `approval`, `attachmentUpload`, `attachmentViewPrefix` |
| **Auth / Storage** | `identity`, `imageProxy`, `ogPlaceholder(title)` |
| **Roadmap** | `roadmap`, `roadmapVote`, `roadmapById(id)` |
| **Delivery** | `delivery`, `deliveryCompleted`, `deliveryInProgress` |
| **Onboarding** | `onboarding`, `onboardingBySlug(slug)`, `onboardingSections` |
| **Releases** | `productReleases`, `productReleaseBySlug(slug)` |
| **Misc** | `legal(docType)`, `contact`, `announcements`, `accessValidate`, `accessConsume` |
| **Proxy / OG** | `redditProxy`, `twitterProxy`, `ogScraper` |

### `HUB_PUBLIC_ORIGIN` (string)

Resolved from `VITE_HUB_ORIGIN` at build time; falls back to `http://localhost:3000`. Used for new-tab "open full content" links in embed mode.

### `AGENT_BASE` (internal)

Shared base path (`${CONTENT}/chat/agent`) from which `agentBase` and `approval` are derived, keeping the `/chat/agent` segment in one place.

## Usage Example

```typescript
import { EP, HUB_PUBLIC_ORIGIN } from './endpoints'

// Static path
const identity = EP.identity // e.g. "https://hub.example.com/content/auth/identity"

// Parameterized paths
const agentConfig = EP.aiAgent('fae')
// → "https://hub.example.com/content/ai-agents/fae"

const sourceStructure = EP.docsStructure('kb-123')
// → "https://hub.example.com/content/docs/sources/kb-123/structure"

const placeholderUrl = EP.ogPlaceholder('Getting Started')
// → "https://hub.example.com/content/og-placeholder?title=Getting%20Started"

// Embed-mode external link
const fullPageLink = `${HUB_PUBLIC_ORIGIN}/releases`
```

## Notes

- `EP` is cast `as const` — all values are readonly string literals or pure functions; nothing mutates at runtime.
- Parameterized entries (e.g. `aiAgent`, `docsStructure`) are inline arrow functions rather than template strings so callers always receive a correctly interpolated URL.
- The `delivery` endpoint accepts a `?task_ids=` query param at the call site; the base path is kept clean here.
