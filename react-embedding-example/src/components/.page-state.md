Shared error state component for route pages, rendered using ODS design tokens with no hardcoded colors.

## Key Components

- **`PageError`** — Displays a styled error heading and optional detail message using ODS semantic color tokens (`ods-text-primary`, `ods-text-secondary`).

## Usage Example

```typescript
// Minimal usage — title only
<PageError title="Something went wrong" />

// With optional detail message
<PageError
  title="Failed to load data"
  detail="The requested resource could not be found. Please try again."
/>
```

## Props

| Prop | Type | Required | Description |
|---|---|---|---|
| `title` | `string` | ✅ | Primary error heading displayed in `ods-text-primary` |
| `detail` | `string` | ❌ | Secondary descriptive message displayed below the title |

## Notes

- Uses ODS design tokens exclusively — safe for theme switching without style overrides.
- `detail` renders conditionally; no empty `<p>` tag is emitted when omitted.
- Intended for use within route-level page components to surface loading or fetch errors consistently across the app.
