The root layout shell component for the OpenFrame embed application, providing persistent navigation, announcement bar, and floating AI assistant across all routes.

## Key Components

- **`AppShell`** — Top-level layout component rendered at the router root; wraps all route content via `<Outlet />`
- **`NAV`** — Static navigation config array defining all top-level routes (Home, Onboarding, Knowledge Hub, Roadmap, Delivery, Releases, Authors, FAQ, Legal, Contact, Tickets)
- **`AnnouncementBar`** — Prop-less client-side component that auto-resolves its endpoint from `EndpointsRuntime.announcementsUrl`; fetches once on mount, refetches on tab refocus after 60s staleness, persists dismissal in a cookie
- **`AskAi`** — Floating AI assistant trigger rendered on every route
- **`<Outlet />`** — Unconstrained (`w-full`) to allow each route's component to manage its own max-width (e.g. `DocsHubPage` uses `max-w-[1920px]`)

## Usage Example

```typescript
// Registered as the root layout in your router config
import { AppShell } from './app-shell'

const router = createBrowserRouter([
  {
    path: '/',
    element: <AppShell />,
    children: [
      { index: true, element: <HomePage /> },
      { path: 'onboarding-guides', element: <OnboardingPage /> },
      // ...other routes
    ],
  },
])
```

## Notes

- Navigation uses React Router's `<NavLink>` with active-state styling via ODS design tokens (`ods-bg`, `ods-text-primary`, `ods-text-secondary`)
- No runtime navigation callbacks or document-click interceptors — soft-navigation is handled by the embed router bridge registered once in `providers/embed-router-bridge`
- The sticky header uses `backdrop-blur` with `bg-ods-card/95` for a frosted-glass effect at `z-40`
