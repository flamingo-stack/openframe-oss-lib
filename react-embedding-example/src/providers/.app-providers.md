Configures and composes the root React provider tree for the OpenFrame embed, wiring together React Query, chat/endpoints runtime contexts, identity resolution, and rich markdown proxy endpoints in a single memoized provider hierarchy.

## Key Components

| Export | Type | Description |
|---|---|---|
| `AppProviders` | React component | Root provider wrapper that composes all runtime contexts |
| `queryClient` | `QueryClient` | Module-level singleton React Query client shared across the app |

### Provider Hierarchy (outer → inner)

```text
QueryClientProvider
  └── ChatRuntimeContext.Provider      (memoized chat runtime)
        └── ChatIdentityProvider       (resolves /identity once for all subtrees)
              └── EndpointsRuntimeContext.Provider  (memoized endpoints runtime)
                    └── RichMarkdownRuntimeProvider (proxy URLs for reddit/twitter/OG)
                          └── {children}
```

**Design decisions:**
- `chatRuntime` and `endpointsRuntime` are `useMemo`-stabilized to satisfy the lib embedder warning against re-creating contexts on each render.
- `ChatIdentityProvider` sits inside `ChatRuntimeContext` (needs `identityUrl`) but above everything else, preventing duplicate `/identity` fetches across the app shell and `/tickets` page.
- No `ThemeProvider` is mounted — theming is handled via `data-theme="dark"` on `<html>` in `index.html`, since the lib's `ThemeProvider` is not publicly exported.
- `RichMarkdownRuntimeProvider` omits `transformImageSrc` because the embed environment lacks the Supabase image optimizer.

## Usage Example

```typescript
// main.tsx
import { AppProviders } from './providers/app-providers'
import { App } from './App'

createRoot(document.getElementById('root')!).render(
  <AppProviders>
    <App />
  </AppProviders>
)
```
