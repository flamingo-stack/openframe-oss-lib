Adapts React Router (react-router-dom) hooks and components into the shape expected by `@flamingo-stack/openframe-frontend-core`'s embed shim contract, enabling lib surfaces to navigate and re-render correctly within this SPA.

## Key Components

- **`LinkAdapter`** — A `forwardRef` component that maps the Next.js `<Link>` prop shape (`href`, `prefetch`, `scroll`) to react-router's `<Link>` (`to`, `replace`), dropping Next-only props that react-router doesn't support.
- **`registerEmbedRouterBridge()`** — One-time registration function (guarded by an `registered` flag) that wires three adapted hooks into `registerNavigation` and passes `LinkAdapter` to `registerLink`.
  - **`useRouter`** — Wraps `useNavigate()` in a memoized object matching the `RouterStub` contract (`push`, `replace`, `back`, `forward`, `refresh`, `prefetch`).
  - **`usePathname`** — Returns `useLocation().pathname` as a bare string.
  - **`useSearchParams`** — Unwraps react-router's `[params, setter]` tuple, returning only the `URLSearchParams` instance.

## Usage Example

Call `registerEmbedRouterBridge()` **once**, before any lib surface renders — typically in `main.tsx`:

```typescript
import { registerEmbedRouterBridge } from './embed-router-bridge'

registerEmbedRouterBridge() // must be called before first lib surface render

ReactDOM.createRoot(document.getElementById('root')!).render(
  <BrowserRouter>
    <App />
  </BrowserRouter>
)
```

> **Note:** The function is idempotent — calling it more than once is safe but has no effect after the first call. The file is `.tsx` (not `.ts`) because `LinkAdapter` contains JSX.
