Entry point for the OpenFrame OSS reference application. Bootstraps the React app by registering the embed router bridge, applying global styles, and mounting the component tree with routing and app-wide providers.

## Key Components

| Import | Role |
|---|---|
| `registerEmbedRouterBridge` | Wires react-router navigation into the embed-shims layer before first render |
| `AppProviders` | Wraps the app with all global context providers |
| `AppRoutes` | Defines top-level route configuration |
| `@flamingo-stack/openframe-frontend-core/styles` | Injects ODS design tokens, chat keyframes, and fonts |

## Usage Example

This file is the Vite entry point — it is not imported directly. It is referenced via `index.html`:

```typescript
// vite.config.ts (typical setup)
export default defineConfig({
  build: {
    rollupOptions: {
      input: 'src/main.tsx',
    },
  },
})
```

The render tree produced:

```typescript
<BrowserRouter>
  <AppProviders>
    <AppRoutes />
  </AppProviders>
</BrowserRouter>
```

## Notes

- **`registerEmbedRouterBridge()`** must be called before the first lib surface renders so embedded pages use react-router navigation rather than the `popstate`-only fallback.
- **`React.StrictMode` is intentionally omitted** to keep the dev network panel aligned with production output. The library itself is StrictMode-safe; coverage is handled by its Vitest suite.
- Styles are imported once here to ensure ODS tokens paint before any component renders.
