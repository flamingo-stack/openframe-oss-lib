Tailwind CSS configuration file for the `openframe-oss-lib` project, composing the shared OpenFrame Design System (ODS) preset from `@flamingo-stack/openframe-frontend-core` with local content paths.

## Key Components

- **`openframeCorePreset`** — Imported ODS Tailwind preset providing shared design tokens, fonts, and animations from `@flamingo-stack/openframe-frontend-core`.
- **`presets`** — Merges the ODS preset using Tailwind's `presets` array (not object spread) to correctly inherit all theme values.
- **`content`** — Purge-safe glob patterns covering local source files and pre-built dist artifacts from the core library.

## Usage Example

```typescript
// tailwind.config.ts
import type { Config } from 'tailwindcss'
import openframeCorePreset from '@flamingo-stack/openframe-frontend-core/tailwind.config.ts'

export default {
  presets: [openframeCorePreset as Config], // ✅ Use presets[], NOT { ...spread }
  content: [
    './index.html',
    './src/**/*.{ts,tsx}',
    // Required: prevents purging of classes used only in pre-built dist files
    './node_modules/@flamingo-stack/openframe-frontend-core/dist/**/*.{js,mjs,cjs}',
  ],
} satisfies Config
```

> **Note:** The core library's compiled output lives in `dist/`, not `src/`, so its path must be explicitly included in `content` — otherwise Tailwind's purge step will strip classes that are only referenced inside pre-built bundles.

## Notes

- Use `presets: [openframeCorePreset]` — never `{ ...openframeCorePreset }`. Tailwind's preset merging handles theme composition, plugin inheritance, and variant resolution correctly only through the `presets` array.
- View the source at [`tailwind.config.ts`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/tailwind.config.ts).
