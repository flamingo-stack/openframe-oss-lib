JUnit 5 test suite for `PinotClientDeviceRepository`, verifying query construction, tenant isolation, faceted filtering behavior, result mapping, and SQL injection protection against a mocked Apache Pinot connection.

## Key Components

| Class / Method | Purpose |
|---|---|
| `TenantIdValidation` | Asserts null/blank tenant IDs throw `PinotQueryException` and that all facet queries embed the `tenantId` filter |
| `FacetQueryStructure` | Validates generated SQL structure — correct `SELECT`, `GROUP BY`, `ORDER BY`, and exclusion of `DELETED` rows |
| `ExcludeFieldBehavior` | Verifies the "excludeField" contract: each facet query omits its own dimension's filter while applying all others |
| `CountAndMapping` | Confirms `getFilteredDeviceCount` reads the first cell as a `long`, and facet methods map rows to `Map<String, Integer>` |
| `SqlInjection` | Checks that single quotes in `tenantId` are escaped before interpolation into SQL |
| `whenQueryReturnsEmptyRows()` | Helper that stubs `pinotConnection → resultSetGroup → resultSet` with zero rows |
| `captureQuery()` | Helper that uses `ArgumentCaptor` to return the last SQL string passed to `pinotConnection.execute()` |

## Usage Example

```java
// Typical pattern used throughout the suite:
// 1. Stub Pinot to return empty results
when(pinotConnection.execute(anyString())).thenReturn(resultSetGroup);
when(resultSetGroup.getResultSet(0)).thenReturn(resultSet);
when(resultSet.getRowCount()).thenReturn(0);

// 2. Invoke the repository method under test
repository.getStatusFilterOptions(
    TENANT_ID,
    List.of("ACTIVE"),   // selectedStatuses  — excluded from this facet's WHERE
    List.of("LAPTOP"),   // selectedDeviceTypes — included in WHERE
    List.of(), List.of(), List.of(), List.of()
);

// 3. Capture and assert the generated SQL
ArgumentCaptor<String> captor = ArgumentCaptor.forClass(String.class);
verify(pinotConnection).execute(captor.capture());
String sql = captor.getValue();

assertTrue(sql.contains("tenantId = 'uuid-aaa'"));
assertTrue(sql.contains("deviceType = 'LAPTOP'"));
assertFalse(sql.contains("status = 'ACTIVE'")); // own field excluded
```

## Notes

- The suite uses **reflection** (`setField`) to inject the `devicesTable` value, bypassing Spring context startup.
- The excluded-field contract ensures facet counts remain accurate under cross-filter selections — a deliberate design choice tested explicitly in `ExcludeFieldBehavior`.
