Unit test suite for `PinotQueryBuilder`, validating SQL query generation, tenant isolation, input validation, and cursor-based pagination across all builder methods.

## Key Components

| Test Class | Coverage Area |
|---|---|
| `TenantIdValidation` | Null/empty/whitespace `tenantId` rejection |
| `TenantIdEscaping` | SQL injection prevention via single-quote escaping |
| `AutoAddedTenantFilter` | Tenant filter always prepended to `WHERE` clause |
| `FullQueryComposition` | `SELECT`, `COUNT`, `GROUP BY`, `ORDER BY`, `IN`, `OR`, `!=` clauses |
| `TableNameValidation` | Null/empty table name rejection and double-quote wrapping |
| `BuildStateValidation` | `build()` preconditions: requires at least one column, positive `LIMIT` |
| `WhereTimestampRange` | Millisecond-precision `Instant` bounds with partial/null handling |
| `WhereCursor` | Direction-aware keyset pagination (`ASC`/`DESC`) |

## Usage Example

```java
// Mirrors what the tests assert against PinotQueryBuilder
PinotQueryBuilder builder = new PinotQueryBuilder("logs", "uuid-aaa");

// Simple SELECT with equality and range filters
String query = builder
    .select("eventType", "severity")
    .whereEquals("status", "ACTIVE")
    .whereIn("severity", List.of("ERROR", "WARN"))
    .whereDateRange("eventTimestamp",
        LocalDate.of(2026, 1, 1), LocalDate.of(2026, 1, 31))
    .limit(100)
    .build();
// → SELECT eventType, severity FROM "logs"
//   WHERE tenantId = 'uuid-aaa'
//     AND status = 'ACTIVE'
//     AND severity IN ('ERROR','WARN')
//     AND eventTimestamp ...
//   LIMIT 100

// Keyset cursor pagination (DESC)
String cursorQuery = new PinotQueryBuilder("logs", "uuid-aaa")
    .select("id")
    .whereCursor("1700000000000_evt-1", "DESC")
    .build();
// Emits: (eventTimestamp < 1700000000000)
//     OR (eventTimestamp = 1700000000000 AND toolEventId < 'evt-1')
```

> **Note:** All builders enforce `tenantId` as the first `WHERE` predicate. Passing a null/blank `tenantId` or `tableName`, calling `build()` without a `select`, or using a non-positive `limit` throws `PinotQueryException`.
