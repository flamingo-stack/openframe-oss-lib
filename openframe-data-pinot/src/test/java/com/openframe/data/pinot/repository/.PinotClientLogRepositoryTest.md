Unit test suite for `PinotClientLogRepository`, verifying query construction, tenant ID propagation, sort field validation, and result-set-to-model mapping against a mocked Apache Pinot `Connection`.

## Key Components

| Class / Member | Purpose |
|---|---|
| `TenantIdPropagation` (nested) | Asserts every public repository method injects a `tenantId = '...'` WHERE clause; also validates that `null`/blank tenant IDs throw `PinotQueryException` |
| `SortValidation` (nested) | Checks `isSortableField()` allows known columns (`eventTimestamp`, `severity`), rejects unknown/null/blank values, and confirms the default sort field |
| `ResultMapping` (nested) | Exercises full row-to-`LogProjection` mapping across 12 columns and verifies `getOrganizationOptions` filters out rows with null or blank `organizationId` |
| `whenQueryReturnsEmptyRows()` | Helper that stubs `pinotConnection → resultSetGroup → resultSet` with zero rows |
| `captureExecutedQuery()` | Uses `ArgumentCaptor` to retrieve the exact SQL string passed to `pinotConnection.execute()` for assertion |

## Usage Example

```java
// Run the full suite with JUnit 5 + Mockito
// No real Pinot cluster required — Connection is fully mocked

@ExtendWith(MockitoExtension.class)
class PinotClientLogRepositoryTest {

    @Mock Connection pinotConnection;
    @Mock ResultSetGroup resultSetGroup;
    @Mock ResultSet resultSet;

    @BeforeEach
    void setUp() throws Exception {
        repository = new PinotClientLogRepository(pinotConnection);
        // Inject @Value field "logsTable" via reflection
        setField(repository, "logsTable", "logs");
    }

    @Test
    void findLogsIncludesTenantId() {
        whenQueryReturnsEmptyRows();
        repository.findLogs(TENANT_ID, START, END, ...);
        assertTrue(captureExecutedQuery().contains("tenantId = 'uuid-aaa'"));
    }
}
```
