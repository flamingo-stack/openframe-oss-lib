## Overview

Apache Pinot repository implementation for querying MSP event log data, supporting filtering, full-text search, cursor-based pagination, and faceted option lookups against a configurable Pinot logs table.

## Key Components

| Member | Description |
|---|---|
| `SORTABLE_COLUMNS` | Whitelist of fields permitted as sort targets |
| `DEFAULT_SORT_COLUMN` | Fallback sort field (`eventTimestamp`) |
| `PRIMARY_KEY_FIELD` | Tie-breaker key for cursor pagination (`toolEventId`) |
| `logsTable` | Configurable via `pinot.tables.logs.name` (default: `logs`) |
| `findLogs(...)` | Paginated log retrieval with multi-filter support |
| `searchLogs(...)` | Same as `findLogs` with an added relevance search term |
| `getEventTypeOptions(...)` | Returns distinct event type facet values |
| `getSeverityOptions(...)` | Returns distinct severity facet values |
| `getToolTypeOptions(...)` | Returns distinct tool type facet values |
| `getAvailableDateRanges(...)` | Returns distinct `ingestDay` values for date range UI |
| `getOrganizationOptions(...)` | Returns `OrganizationOption` pairs (id + name), filters nulls |
| `isSortableField(String)` | Validates a sort field against the allowed whitelist |
| `executeLogQuery(String)` | Private mapper — converts Pinot result rows into `LogProjection` |

## Usage Example

```java
// Inject repository
@Autowired
private PinotClientLogRepository logRepository;

// Paginated log fetch with filters
List<LogProjection> logs = logRepository.findLogs(
    "tenant-abc",
    LocalDate.of(2025, 1, 1),
    LocalDate.of(2025, 1, 31),
    null, null,
    List.of("ConnectWise"),
    List.of("ALERT"),
    List.of("HIGH"),
    List.of("org-001"),
    null,       // deviceId
    null,       // cursor
    25,
    "eventTimestamp",
    "DESC"
);

// Full-text search variant
List<LogProjection> results = logRepository.searchLogs(
    "tenant-abc", startDate, endDate,
    null, null,
    toolTypes, eventTypes, severities,
    orgIds, null, "disk full", null, 25, "eventTimestamp", "DESC"
);

// Validate a sort field before use
if (logRepository.isSortableField(requestedSort)) {
    // safe to pass to findLogs
}
```

## Configuration

```yaml
pinot:
  tables:
    logs:
      name: logs   # override default table name
```
