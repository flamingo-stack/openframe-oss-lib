Apache Pinot repository implementation for querying device data, providing faceted filter-option counts and filtered device totals for a given tenant.

## Key Components

| Component | Description |
|---|---|
| `PinotClientDeviceRepository` | Spring `@Repository` bean extending `AbstractPinotRepository` and implementing `PinotDeviceRepository` |
| `getStatusFilterOptions` | Returns a count-per-value map for the `status` facet |
| `getDeviceTypeFilterOptions` | Returns a count-per-value map for the `deviceType` facet |
| `getOsTypeFilterOptions` | Returns a count-per-value map for the `osType` facet |
| `getOrganizationFilterOptions` | Returns per-organization device counts, restricted to **ONLINE/OFFLINE** devices only |
| `getTagKeyFilterOptions` | Returns a count-per-value map for the `tagKeyValues` facet |
| `getFilteredDeviceCount` | Returns the total number of devices matching all supplied filters (excluding DELETED) |
| `executeFacetQuery` / `executeActiveFacetQuery` | Internal helpers that build and execute `GROUP BY` queries via `PinotQueryBuilder` |
| `applyDeviceFilters` / `applyActiveDeviceFilters` | Apply the shared filter set to a query builder, with an optional field exclusion for faceted queries |
| `MAX_FILTER_OPTIONS` | Constant (`10000`) overriding Pinot's default 10-group `GROUP BY` cap |
| `ACTIVE_STATUSES` | `[ONLINE, OFFLINE]` — the universe used by organization-level counts |

## Usage Example

```java
// Injected by Spring
@Autowired
private PinotDeviceRepository deviceRepository;

// Get device-type breakdown for current filters
Map<String, Integer> deviceTypeCounts = deviceRepository.getDeviceTypeFilterOptions(
    "tenant-abc",
    List.of("ONLINE"),           // statuses
    null,                        // deviceTypes — excluded (this is the faceted field)
    List.of("WINDOWS"),          // osTypes
    List.of("org-1", "org-2"),   // organizationIds
    null,                        // tagKeys
    null                         // tagKeyValues
);
// e.g. {"WORKSTATION": 142, "SERVER": 38, "LAPTOP": 210}

// Get total filtered device count
int total = deviceRepository.getFilteredDeviceCount(
    "tenant-abc",
    List.of("ONLINE"),
    List.of("WORKSTATION"),
    null, null, null, null
);
```
