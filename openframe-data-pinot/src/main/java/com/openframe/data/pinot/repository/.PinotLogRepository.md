Spring `@Repository` interface defining the contract for querying log data from Apache Pinot, supporting filtering, full-text search, faceted options, and cursor-based pagination.

## Key Components

| Method | Description |
|---|---|
| `findLogs(...)` | Retrieves paginated log entries filtered by tenant, date range, timestamps, tool types, event types, severities, organizations, and device |
| `searchLogs(...)` | Same as `findLogs` with an additional `searchTerm` parameter for full-text search |
| `getToolTypeOptions(...)` | Returns distinct tool type values matching the current filter context |
| `getEventTypeOptions(...)` | Returns distinct event type values matching the current filter context |
| `getSeverityOptions(...)` | Returns distinct severity values matching the current filter context |
| `getAvailableDateRanges(...)` | Returns available date ranges for a tenant given active filters |
| `getOrganizationOptions(...)` | Returns `OrganizationOption` objects (id + label) available under the current filters |
| `isSortableField(String field)` | Validates whether a given field name is sortable in the underlying Pinot store |
| `getDefaultSortField()` | Returns the default field name used for sorting results |

## Usage Example

```java
@Service
public class LogQueryService {

    private final PinotLogRepository logRepository;

    public LogQueryService(PinotLogRepository logRepository) {
        this.logRepository = logRepository;
    }

    public List<LogProjection> getFilteredLogs(String tenantId) {
        String sortField = logRepository.isSortableField("timestamp")
                ? "timestamp"
                : logRepository.getDefaultSortField();

        return logRepository.findLogs(
                tenantId,
                LocalDate.now().minusDays(7),
                LocalDate.now(),
                Instant.now().minusSeconds(604800),
                Instant.now(),
                List.of("RMM", "PSA"),
                List.of("ALERT"),
                List.of("HIGH", "CRITICAL"),
                List.of("org-123"),
                null,   // no device filter
                null,   // no cursor (first page)
                50,
                sortField,
                "DESC"
        );
    }
}
```

## Notes

- All query methods are scoped by `tenantId`, enforcing multi-tenant data isolation.
- Cursor-based pagination (`cursor`, `limit`) is used in both `findLogs` and `searchLogs` to support efficient deep pagination over Pinot's columnar store.
- The `get*Options` methods are designed to power dynamic filter dropdowns, returning only values present in the current filtered dataset.
