Fluent SQL query builder for Apache Pinot that constructs tenant-scoped SELECT statements with type-safe filters, ordering, pagination, and cursor-based navigation.

## Key Components

### Constructor
- **`PinotQueryBuilder(String tableName, String tenantId)`** — Initializes the builder with mandatory tenant scoping; throws `PinotQueryException` if `tenantId` is null or blank

### Select Clauses
- **`select(String... columns)`** — Adds specific columns to the SELECT list
- **`distinct()`** — Adds DISTINCT modifier
- **`selectCount()`** — Adds `COUNT(*) as count`
- **`selectCountAll()`** — Adds raw `COUNT(*)`

### WHERE Filters
- **`whereEquals / whereNotEquals / whereGreaterThan`** — Scalar comparisons
- **`whereIn(String field, List<String>)`** — IN list filter
- **`whereOr(String field, List<String>)`** — OR-joined equality conditions
- **`whereLike(String field, String value)`** — Wildcard LIKE (`%value%`)
- **`whereTimestampRange(String field, Instant from, Instant to)`** — Epoch-millis range on timestamp columns
- **`whereDateRange(String field, LocalDate, LocalDate)`** — Date range using formatted strings
- **`whereTextSearch(String searchTerm, String... columns)`** — Full-text `TEXT_MATCH` function
- **`whereFilterOptionsExcluding`** — Multi-field IN filters with one field excluded (for faceted filtering)

### Ordering & Grouping
- **`orderByTimestampDesc/Asc()`** — Sorts by `eventTimestamp` with secondary `toolEventId` tie-break
- **`orderBySortInput(String field, String direction, String primaryKey)`** — Dynamic sort with primary key fallback
- **`orderByCountDesc()`** — Sorts aggregation results
- **`groupBy / groupByWithCount`** — GROUP BY clauses

### Pagination
- **`limit(int)`** — Sets result limit (validated between `MIN_LIMIT` and `MAX_LIMIT = 10000`)

## Usage Example

```java
String sql = new PinotQueryBuilder("events_REALTIME", tenantId)
    .select("toolEventId", "eventTimestamp", "severity")
    .whereEquals("source", "crowdstrike")
    .whereTimestampRange("eventTimestamp", Instant.now().minus(1, HOURS), null)
    .whereIn("severity", List.of("HIGH", "CRITICAL"))
    .orderByTimestampDesc()
    .limit(500)
    .build();
```

## Notes

- All string values are automatically sanitized via `escapeSqlValue()` (single-quote escaping)
- The `tenantId` filter is always prepended as the first WHERE condition — cross-tenant queries are impossible by design
- Cursor-based pagination uses composite `(timestamp, toolEventId)` comparisons for stable keyset pagination
