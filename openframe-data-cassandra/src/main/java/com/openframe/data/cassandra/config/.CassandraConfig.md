Spring `@Configuration` class that bootstraps a Cassandra connection for the OpenFrame data layer, conditionally activated via `spring.data.cassandra.enabled=true`.

## Key Components

| Member | Description |
|---|---|
| `cassandraSession()` | Overrides the parent factory bean to inject a programmatic `DriverConfigLoader` with DC-aware load balancing and server-side timestamps |
| `ensureKeyspaceExists()` | Opens a temporary `CqlSession` (pre-keyspace) to run `CREATE KEYSPACE IF NOT EXISTS` and DDL for the `command_results` table with a configurable TTL |
| `getSchemaAction()` | Returns `CREATE_IF_NOT_EXISTS` so Spring Data Cassandra auto-creates mapped entity tables on startup |
| `cassandraSessionLogger()` | Registers a `CassandraSessionLogger` bean for diagnostic logging of the live session |

**Injected properties:**

| Property | Default | Purpose |
|---|---|---|
| `spring.data.cassandra.local-datacenter` | — | DC for load-balancing policy |
| `spring.data.cassandra.keyspace-name` | — | Target keyspace |
| `spring.data.cassandra.contact-points` | — | Seed node hostname/IP |
| `spring.data.cassandra.port` | `9042` | CQL native transport port |
| `spring.data.cassandra.replication-factor` | `1` | `SimpleStrategy` replication factor |
| `openframe.command-result.cassandra.ttl-seconds` | `3600` | `default_time_to_live` for `command_results` |

## Usage Example

```java
// application.yml
spring:
  data:
    cassandra:
      enabled: true
      local-datacenter: datacenter1
      keyspace-name: openframe
      contact-points: 127.0.0.1
      port: 9042
      replication-factor: 1

openframe:
  command-result:
    cassandra:
      ttl-seconds: 7200
```

```java
// Inject a repository backed by this configuration
@Service
public class CommandResultService {

    private final CommandResultRepository repository;

    public CommandResultService(CommandResultRepository repository) {
        this.repository = repository;
    }
}
```

> **Note:** `ensureKeyspaceExists()` runs before `CqlSessionFactoryBean` connects to the keyspace, so schema bootstrapping is safe on a clean cluster. The `command_results` table TTL is applied at the CQL level, not via Spring Data annotations, to allow runtime configurability.
