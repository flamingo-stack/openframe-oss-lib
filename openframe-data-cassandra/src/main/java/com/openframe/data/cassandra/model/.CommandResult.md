Cassandra entity representing a single machine's result for a batch command execution, stored in the `command_results` table.

## Key Components

| Component | Type | Description |
|---|---|---|
| `CommandResult` | `@Table` Entity | Root entity mapped to the `command_results` Cassandra table |
| `CommandResultKey` | `@PrimaryKeyClass` | Composite primary key combining `executionId` and `machineId` |
| `key` | `CommandResultKey` | Partition key by `execution_id`, clustered by `machine_id` |
| `result` | `String` | JSON string containing the agent's full command execution output |

## Key Schema Details

- **Partition key:** `execution_id` — groups all machine results for a given batch execution
- **Clustering key:** `machine_id` — uniquely identifies each machine's result within a partition
- **`result` column:** stores the full agent response as a raw JSON string

## Usage Example

```java
// Construct the composite key
CommandResult.CommandResultKey key = new CommandResult.CommandResultKey(
    "exec-abc-123",   // executionId
    "machine-007"     // machineId
);

// Build and persist the result
CommandResult commandResult = new CommandResult();
commandResult.setKey(key);
commandResult.setResult("{\"status\":\"success\",\"output\":\"Patch applied.\"}");

commandResultRepository.save(commandResult);

// Query all results for a given execution
List<CommandResult> results = commandResultRepository
    .findByKeyExecutionId("exec-abc-123");
```
