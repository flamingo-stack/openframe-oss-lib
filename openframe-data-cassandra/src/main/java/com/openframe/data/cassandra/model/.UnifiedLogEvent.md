Cassandra entity model representing a NIST-compliant unified log event for integrated MSP tools (Fleet, MeshCentral, etc.), mapped to the `unified_logs` table.

## Key Components

### `UnifiedLogEvent` (Table: `unified_logs`)
Top-level entity annotated with `@Table`. Uses Lombok `@Data` for boilerplate. Contains contextual log fields:

| Field | Column | Description |
|---|---|---|
| `userId` | `user_id` | Associated user, if available |
| `deviceId` | `device_id` | Device/machine identifier |
| `hostname` | `hostname` | Device hostname |
| `organizationId` | `organization_id` | Org identifier |
| `organizationName` | `organization_name` | Org display name |
| `severity` | `severity` | Level: `info`, `warning`, `error`, etc. |
| `message` | `message` | Human-readable event description |
| `debeziumMessage` | `debezium_message` | Raw CDC payload (JSON or plain text) |
| `details` | `details` | Flexible tool-specific JSON details |

### `UnifiedLogEventKey` (Composite Primary Key)
Nested `@PrimaryKeyClass` defining the Cassandra partition and clustering strategy:

| Column | Key Type | Ordinal | Notes |
|---|---|---|---|
| `ingest_day` | `PARTITIONED` | 0 | `YYYY-MM-DD` for time-series scalability |
| `tool_type` | `PARTITIONED` | 1 | e.g. `meshcentral`, `fleet-mdm` |
| `tenant_id` | `CLUSTERED` | 2 | Multi-tenant isolation |
| `event_type` | `CLUSTERED` | 3 | e.g. `login`, `logout`, `script` |
| `event_timestamp` | `CLUSTERED` | 4 | `DESCENDING` — recent-first queries |
| `tool_event_id` | `CLUSTERED` | 5 | Source tool event ID for uniqueness |

## Usage Example

```java
UnifiedLogEvent.UnifiedLogEventKey key = new UnifiedLogEvent.UnifiedLogEventKey();
key.setIngestDay("2025-07-15");
key.setToolType("fleet-mdm");
key.setTenantId("tenant-abc");
key.setEventType("login");
key.setEventTimestamp(Instant.now());
key.setToolEventId("fleet-evt-00123");

UnifiedLogEvent event = new UnifiedLogEvent();
event.setKey(key);
event.setHostname("workstation-01");
event.setOrganizationId("org-xyz");
event.setSeverity("info");
event.setMessage("User logged in via Fleet MDM");
event.setDetails("{\"ip\":\"192.168.1.10\"}");

cassandraTemplate.insert(event);
```

> **Partition design note:** Dual partitioning on `ingest_day` + `tool_type` bounds partition size to a single day per tool, enabling efficient range scans filtered by tenant, event type, and time without full-table scans.
