MongoDB document model for RMM (Remote Monitoring & Management) scripts, representing reusable scripts executable on agents ad-hoc, on a schedule, or as part of a check.

## Key Components

| Field | Type | Description |
|---|---|---|
| `id` | `String` | MongoDB document identifier |
| `tenantId` | `String` | Tenant owner — all queries must be scoped by this field |
| `name` | `String` | Human-readable name, unique per tenant |
| `shell` | `ScriptShell` | Interpreter (PowerShell, CMD, Bash, Python) |
| `privilegeLevel` | `PrivilegeLevel` | Execution privilege: `USER` or `ADMIN` |
| `scriptBody` | `String` | Raw source code executed by the agent |
| `supportedPlatforms` | `List<ScriptPlatform>` | Prevents dispatching to incompatible OS agents |
| `defaultTimeoutSeconds` | `Integer` | Agent kills process if exceeded; overridable per run |
| `defaultArgs` | `List<String>` | Default positional CLI arguments; overridable per run |
| `envVars` | `List<ScriptEnvVar>` | Default env vars; secret values require encryption |
| `status` | `ScriptStatus` | Lifecycle state — defaults to `ACTIVE`, supports soft-delete via `DELETED` |
| `createdBy` | `String` | User `sub` claim at creation time |

**Indexes:**
- Compound index on `(tenantId, name)` for tenant-scoped lookups
- Partial unique index on `(tenantId, name)` scoped to `{status: {$in: [ACTIVE, ARCHIVED]}}` enforced via `MongoIndexConfig`, allowing soft-deleted names to be reused
- Single-field index on `status`

## Usage Example

```java
Script script = Script.builder()
    .tenantId("tenant-abc")
    .name("Disk Cleanup")
    .description("Removes temp files older than 30 days")
    .shell(ScriptShell.POWERSHELL)
    .privilegeLevel(PrivilegeLevel.ADMIN)
    .scriptBody("Remove-Item $env:TEMP\\* -Recurse -Force")
    .supportedPlatforms(List.of(ScriptPlatform.WINDOWS))
    .defaultTimeoutSeconds(120)
    .defaultArgs(List.of("--verbose"))
    .envVars(List.of(new ScriptEnvVar("LOG_LEVEL", "debug", false)))
    .build();
```

> **Note:** Secret `envVars` encryption and delivery to agents is pending implementation. See the secret-management story for follow-up details.
