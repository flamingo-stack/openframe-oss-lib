A filter criteria data class used to build MongoDB queries for organization document lookups, supporting multi-dimensional filtering across categories, employee counts, contract status, activity timestamps, and status.

## Key Components

| Field | Type | Description |
|---|---|---|
| `category` | `String` | Filter by organization category |
| `minEmployees` | `Integer` | Lower bound for employee count range |
| `maxEmployees` | `Integer` | Upper bound for employee count range |
| `hasActiveContract` | `Boolean` | Filter organizations with an active contract |
| `status` | `String` | Filter by organization status value |
| `lastActivityFrom` | `Instant` | Start of last activity timestamp range |
| `lastActivityTo` | `Instant` | End of last activity timestamp range |

Lombok annotations (`@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor`) provide getters/setters, a fluent builder, and both default and full constructors automatically.

## Usage Example

```java
// Build a filter using the fluent builder
OrganizationQueryFilter filter = OrganizationQueryFilter.builder()
    .category("MSP")
    .minEmployees(10)
    .maxEmployees(500)
    .hasActiveContract(true)
    .status("ACTIVE")
    .lastActivityFrom(Instant.parse("2024-01-01T00:00:00Z"))
    .lastActivityTo(Instant.now())
    .build();

// Pass to a repository or query builder
List<OrganizationDocument> results = organizationRepository.findByFilter(filter);
```

All fields are optional — unset fields are typically ignored by the query builder, allowing partial or fully open-ended queries.
