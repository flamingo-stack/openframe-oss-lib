Defines the ordered set of steps in the per-user "Get Started" onboarding flow, used alongside `UserOnboardingProgress` to track completion state per `(userId, tenantId)` pair.

## Key Components

| Constant | Description |
|---|---|
| `CUSTOMERS_SETUP` | Initial customer configuration step |
| `DEVICE_MANAGEMENT` | Device inventory and management setup |
| `TICKETS` | Ticketing system onboarding |
| `SCRIPTING` | Script automation introduction |
| `MONITORING` | Infrastructure monitoring setup |
| `LOGGING` | Log management configuration |
| `KNOWLEDGE_MANAGEMENT` | Knowledge base onboarding |
| `MEET_MINGO` | Introduction to Mingo AI assistant |

> **Note:** Step order mirrors the Figma design. UI groupings ("Get set up" / "Run your operations" / "Work smarter with AI") are presentational only and are **not** persisted.

## Usage Example

```java
// Mark a specific step as completed for a user
UserOnboardingProgress progress = progressRepository
    .findByUserIdAndTenantId(userId, tenantId)
    .orElseGet(() -> new UserOnboardingProgress(userId, tenantId));

progress.markCompleted(UserOnboardingStep.CUSTOMERS_SETUP);
progressRepository.save(progress);

// Check if a step is done
boolean ticketsDone = progress.isCompleted(UserOnboardingStep.TICKETS);

// Iterate all steps in order
for (UserOnboardingStep step : UserOnboardingStep.values()) {
    System.out.println(step + ": " + progress.isCompleted(step));
}
```
