MongoDB document entity that tracks per-user "Get Started" onboarding progress, storing completed steps and flow state (skipped/completed) scoped to a `(userId, tenantId)` pair.

## Key Components

| Member | Type | Description |
|---|---|---|
| `id` | `String` | MongoDB document identifier (`@Id`) |
| `userId` | `String` | Owning user; part of the unique compound index |
| `tenantId` | `String` | Owning tenant; part of the unique compound index |
| `completedSteps` | `Set<UserOnboardingStep>` | Add-only, idempotent set of explicitly completed steps |
| `completed` | `boolean` | Set exclusively by the "Finish" action |
| `completedAt` | `Instant` | Timestamp when `completed` was set; `null` until then |
| `skipped` | `boolean` | Set by "Skip Onboarding"; cleared on reset |
| `skippedAt` | `Instant` | Timestamp when `skipped` was set; `null` until then |

**Compound index** `user_tenant_unique` enforces one record per `(userId, tenantId)`.

## Usage Example

```java
// Create a fresh progress record for a user
UserOnboardingProgress progress = UserOnboardingProgress.builder()
    .userId("user-123")
    .tenantId("tenant-abc")
    .build();

// Mark a step as completed (idempotent)
progress.getCompletedSteps().add(UserOnboardingStep.CONNECT_INTEGRATION);

// User explicitly finishes the flow
progress.setCompleted(true);
progress.setCompletedAt(Instant.now());

// User skips onboarding instead
progress.setSkipped(true);
progress.setSkippedAt(Instant.now());

// Reset to clean state
progress.setSkipped(false);
progress.setSkippedAt(null);
progress.setCompleted(false);
progress.setCompletedAt(null);
progress.getCompletedSteps().clear();
```

> **Note:** This document is independent of the tenant-wide Initial Setup flow — it tracks only the per-user "Get Started" experience. See the full collection at [`flamingo-stack/openframe-oss-lib`](https://github.com/flamingo-stack/openframe-oss-lib).
