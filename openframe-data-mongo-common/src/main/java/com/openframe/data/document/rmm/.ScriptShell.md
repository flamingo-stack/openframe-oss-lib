Enum defining the supported shell interpreters available for executing scripts within the OpenFrame RMM agent.

## Key Components

| Value | Description |
|---|---|
| `POWERSHELL` | Windows PowerShell interpreter |
| `CMD` | Windows Command Prompt interpreter |
| `BASH` | Unix/Linux Bash shell interpreter |
| `PYTHON` | Python script interpreter |
| `NUSHELL` | Nu shell interpreter |
| `SHELL` | Generic shell interpreter |

## Usage Example

```java
Script script = new Script();
script.setShell(ScriptShell.POWERSHELL);
script.setContent("Get-Process | Select-Object -First 10");

// Switch on interpreter type
switch (script.getShell()) {
    case POWERSHELL -> executeWithPowerShell(script);
    case BASH       -> executeWithBash(script);
    case PYTHON     -> executeWithPython(script);
    default         -> executeWithGenericShell(script);
}
```

## Notes

- New interpreters are added as agent-side support is implemented — check release notes for newly supported values before relying on them in production.
- Pairs with the `Script` document class in the same `com.openframe.data.document.rmm` package.
