MongoDB document entity representing a versioned release record scoped to a specific tenant, stored in the `release_versions` collection.

## Key Components

| Field | Type | Description |
|---|---|---|
| `id` | `String` | MongoDB document identifier (`@Id`) |
| `tenantId` | `String` | Indexed foreign key linking the release to a tenant |
| `documentVersion` | `Long` | Optimistic locking version field (`@Version`) |
| `version` | `String` | Indexed release version string (e.g. `1.0.0`) |
| `createdAt` | `Instant` | Auto-populated creation timestamp (`@CreatedDate`) |
| `updatedAt` | `Instant` | Auto-populated last-modified timestamp (`@LastModifiedDate`) |

Implements `TenantScoped` to enforce multi-tenancy patterns across the platform.

## Usage Example

```java
ReleaseVersion releaseVersion = new ReleaseVersion();
releaseVersion.setTenantId("tenant-abc");
releaseVersion.setVersion("2.1.0");

// Persist via Spring Data MongoDB repository
releaseVersionRepository.save(releaseVersion);

// Query by tenant and version
Optional<ReleaseVersion> found = releaseVersionRepository
    .findByTenantIdAndVersion("tenant-abc", "2.1.0");
```

> **Note:** The `@Version` annotation on `documentVersion` enables optimistic locking — concurrent updates to the same document will throw an `OptimisticLockingFailureException` if the version has changed since the record was read.
