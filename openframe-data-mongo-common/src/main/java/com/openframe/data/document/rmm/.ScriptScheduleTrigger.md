Brief enum defining the two trigger modes for scheduled script execution in the RMM (Remote Monitoring and Management) module.

## Key Components

| Value | Description |
|---|---|
| `DATE_TIME` | Script executes at a specific scheduled date and time |
| `DEVICE_ONLINE` | Script executes when the target device comes online |

## Usage Example

```java
ScriptScheduleTrigger trigger = ScriptScheduleTrigger.DEVICE_ONLINE;

switch (trigger) {
    case DATE_TIME:
        // Schedule execution at a specific timestamp
        break;
    case DEVICE_ONLINE:
        // Queue script to run when device reconnects
        break;
}
```

## Notes

- Part of the `com.openframe.data.document.rmm` package
- Used to control deferred or conditional script execution on managed devices
- Pair with a schedule document or job entity to define the full execution context
