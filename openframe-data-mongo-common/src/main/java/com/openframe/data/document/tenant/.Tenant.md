MongoDB document entity representing an organization/company in OpenFrame's multi-tenant architecture, mapped to the `tenants` collection.

## Key Components

| Member | Type | Description |
|--------|------|-------------|
| `id` | `String` | MongoDB document ID (`@Id`) |
| `name` | `String` | Organization display name (indexed) |
| `domain` | `String` | Unique subdomain for routing, e.g. `company.openframe.io` (unique index) |
| `website` | `String` | Free-form company URL, editable via tenant-info CRUD |
| `ownerId` | `String` | User ID of the first registered user (owner) |
| `status` | `TenantStatus` | Defaults to `TenantStatus.ACTIVE` |
| `createdAt` / `updatedAt` | `LocalDateTime` | Auto-managed audit timestamps |
| `generateTenantId()` | `static String` | Generates a random UUID string for a new tenant |
| `isActive()` | `boolean` | Returns `true` when `status == TenantStatus.ACTIVE` |

## Usage Example

```java
// Create a new tenant using the builder
Tenant tenant = Tenant.builder()
    .id(Tenant.generateTenantId())
    .name("Acme Corp")
    .domain("acme.openframe.io")
    .website("https://acme.com")
    .ownerId("user-uuid-123")
    .build();

// Check tenant status before processing
if (tenant.isActive()) {
    // proceed with tenant-scoped operations
}

// Update domain using toBuilder()
Tenant updated = tenant.toBuilder()
    .domain("acme-new.openframe.io")
    .build();
```

## Notes

- Lombok `@SuperBuilder(toBuilder = true)` enables immutable-style updates via `.toBuilder()`.
- `domain` carries a **unique index** — duplicate domain registration will throw a MongoDB `DuplicateKeyException`.
- Audit fields (`createdAt`, `updatedAt`) require Spring Data's `@EnableMongoAuditing` to populate automatically.
