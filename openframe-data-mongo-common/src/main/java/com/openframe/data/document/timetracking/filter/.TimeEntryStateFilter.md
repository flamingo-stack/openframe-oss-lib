Simple enum defining two mutually exclusive filter states for time entry queries — active (in-progress) or completed.

## Key Components

| Value | Description |
|---|---|
| `ACTIVE` | Filters for time entries that are currently in progress |
| `COMPLETED` | Filters for time entries that have been finished |

## Usage Example

```java
// Filter time entries by state
TimeEntryStateFilter filter = TimeEntryStateFilter.ACTIVE;

switch (filter) {
    case ACTIVE:
        // fetch in-progress entries
        break;
    case COMPLETED:
        // fetch finished entries
        break;
}
```

## Notes

- Used within the `com.openframe.data.document.timetracking.filter` package alongside other time tracking filter types
- Pair with query/repository methods that accept a `TimeEntryStateFilter` parameter to scope results
