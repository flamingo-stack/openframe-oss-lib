Data-layer filter criteria object for querying `ScriptExecution` records. Decouples repository queries from the API module by providing an independent filter model that the service layer maps from the API-layer `ScriptExecutionFilterInput`.

## Key Components

| Field | Type | Description |
|---|---|---|
| `statuses` | `List<ExecutionStatus>` | Filter by one or more execution statuses; `null`/empty applies no constraint |
| `initiatedByIds` | `List<String>` | Filter by initiator user IDs; `null`/empty applies no constraint |
| `machineIds` | `List<String>` | Filter by target machine IDs; `null`/empty applies no constraint |

Lombok annotations (`@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor`) generate boilerplate for getters/setters, builder pattern, and constructors.

## Usage Example

```java
// Build a filter using the fluent builder
ScriptExecutionQueryFilter filter = ScriptExecutionQueryFilter.builder()
    .statuses(List.of(ExecutionStatus.FAILED, ExecutionStatus.PENDING))
    .initiatedByIds(List.of("user-123", "user-456"))
    .machineIds(List.of("machine-789"))
    .build();

// Pass to the repository layer
List<ScriptExecution> results = scriptExecutionRepository.findAll(filter);

// Or construct with no constraints (fetch all)
ScriptExecutionQueryFilter noFilter = new ScriptExecutionQueryFilter();
```

> **Note:** Each field is independently optional — `null` or empty lists are treated as "no constraint" for that dimension, allowing partial filtering without requiring all criteria to be set.
