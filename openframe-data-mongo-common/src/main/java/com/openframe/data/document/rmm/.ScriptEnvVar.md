Represents a single environment variable to be exported on an RMM agent prior to script execution. This class is an embedded document within the [`Script`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/data/document/rmm/Script.java) MongoDB document — it is not persisted as a standalone collection.

## Key Components

| Field | Type | Description |
|---|---|---|
| `name` | `String` | The environment variable name as exported on the agent |
| `value` | `String` | The variable's value; intended to be ciphertext when `secret = true`, currently stored as plaintext |
| `secret` | `boolean` | Marks the variable as sensitive; encryption pipeline is not yet implemented |

> **⚠️ Known Limitation:** When `secret = true`, values are accepted without rejection but are currently stored in plaintext in MongoDB. Encryption at rest and secure agent delivery are pending a future secret-management story.

## Usage Example

```java
// Plain environment variable
ScriptEnvVar apiUrl = ScriptEnvVar.builder()
    .name("API_URL")
    .value("https://api.example.com")
    .secret(false)
    .build();

// Secret variable (stored plaintext until secret-management story lands)
ScriptEnvVar apiKey = ScriptEnvVar.builder()
    .name("API_KEY")
    .value("supersecret123")
    .secret(true)
    .build();

// Attach to a Script document
Script script = Script.builder()
    .envVars(List.of(apiUrl, apiKey))
    .build();
```
