Defines an enumeration of recognized integrated tool identifiers used to reference external tools within the OpenFrame platform.

## Key Components

- **`IntegratedToolId`** — Enum class annotated with Lombok's `@Getter`, providing a `getValue()` method for each constant.
- **`FLEET_SERVER_ID`** — Currently the sole enum constant, representing the Fleet MDM server with the identifier string `"fleetmdm-server"`.
- **`value`** — The string identifier associated with each enum constant, used for serialization or lookup against external tool configurations.

## Usage Example

```java
// Retrieve the string identifier for the Fleet MDM server
String toolId = IntegratedToolId.FLEET_SERVER_ID.getValue();
// toolId == "fleetmdm-server"

// Use in a switch or comparison against an integrated tool reference
if (tool.getId().equals(IntegratedToolId.FLEET_SERVER_ID.getValue())) {
    // handle Fleet MDM server logic
}
```

## Notes

- New integrated tools (e.g., additional MDM or RMM platforms) should be added as additional enum constants here, following the same `CONSTANT_NAME("string-id")` pattern.
