MongoDB document entity representing a tenant-scoped authentication invitation, combining `TenantScoped` and `Invitation` base class behavior with a compound index on `tenantId` and `email`.

## Key Components

- **`AuthInvitation`** — Extends `Invitation` to provide a concrete MongoDB-persisted invitation document with multi-tenant support.
- **Compound Index** — `{'tenantId': 1, 'email': 1}` ensures efficient lookup and uniqueness enforcement per tenant/email pair.
- **Lombok Annotations** — `@Data`, `@SuperBuilder`, `@NoArgsConstructor`, and `@EqualsAndHashCode(callSuper = true)` auto-generate boilerplate while preserving parent class fields.

## Usage Example

```java
// Creating a new AuthInvitation using the SuperBuilder
AuthInvitation invitation = AuthInvitation.builder()
    .tenantId("tenant-abc")
    .email("newuser@example.com")
    .build();

// Persisting via a Spring Data MongoDB repository
authInvitationRepository.save(invitation);

// Querying by tenant and email
Optional<AuthInvitation> found = authInvitationRepository
    .findByTenantIdAndEmail("tenant-abc", "newuser@example.com");
```

## Notes

- Inherits all fields and behavior from `Invitation` and `TenantScoped` — no additional fields are defined at this level.
- The compound index on `tenantId` + `email` supports efficient multi-tenant scoped lookups and can be used to enforce per-tenant invite uniqueness at the database level.
