MongoDB document entity representing a secret key used for agent registration, scoped to a specific tenant.

## Key Components

| Component | Description |
|---|---|
| `@Document` | Maps to the `agent_registration_secrets` MongoDB collection |
| `@CompoundIndex` | Enforces a unique index on `(tenantId, secretKey)` pairs |
| `TenantScoped` | Interface ensuring every record is isolated by tenant |
| `secretKey` | The registration secret presented by an agent during enrollment |
| `active` | Flag to enable/disable a secret without deletion |
| `createdAt` | Timestamp (`Instant`) recording when the secret was issued |

## Usage Example

```java
AgentRegistrationSecret secret = new AgentRegistrationSecret();
secret.setTenantId("tenant-abc");
secret.setSecretKey(UUID.randomUUID().toString());
secret.setCreatedAt(Instant.now());
secret.setActive(true);

agentRegistrationSecretRepository.save(secret);

// Validate an incoming agent registration request
Optional<AgentRegistrationSecret> valid = agentRegistrationSecretRepository
    .findByTenantIdAndSecretKeyAndActiveTrue("tenant-abc", incomingKey);
```

> **Note:** The compound unique index on `(tenantId, secretKey)` prevents duplicate secrets within the same tenant while allowing different tenants to share the same key value safely.
