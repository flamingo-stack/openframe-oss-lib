Abstract base class for notification context objects, providing polymorphic JSON deserialization via Jackson's `@JsonTypeInfo` with type discrimination based on the `"type"` property.

## Key Components

| Component | Description |
|---|---|
| `NotificationContext` | Abstract base class all notification context types must extend |
| `getType()` | Abstract method returning the discriminator string used for JSON polymorphism |
| `@JsonTypeInfo` | Configures Jackson to deserialize subclasses by the `"type"` field; falls back to `GenericContext` if type is unrecognized |
| `@SuperBuilder` | Lombok annotation enabling builder pattern inheritance across subclasses |
| `@NoArgsConstructor` | Lombok annotation generating a no-arg constructor required for deserialization |

## Usage Example

```java
// Concrete subclass implementation
@JsonTypeName("email")
@SuperBuilder
@NoArgsConstructor
public class EmailNotificationContext extends NotificationContext {

    private String recipientEmail;

    @Override
    public String getType() {
        return "email";
    }
}

// JSON deserialization — resolves to EmailNotificationContext
String json = """
    {
      "type": "email",
      "recipientEmail": "user@example.com"
    }
    """;

NotificationContext ctx = objectMapper.readValue(json, NotificationContext.class);
// ctx instanceof EmailNotificationContext → true
```

Unknown `"type"` values fall back to `GenericContext`, preventing deserialization failures when new notification types are introduced.

## Notes

- All subclasses must implement `getType()` and return the value matching their `@JsonTypeName`
