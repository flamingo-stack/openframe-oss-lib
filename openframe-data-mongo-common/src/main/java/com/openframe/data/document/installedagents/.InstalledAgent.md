Represents a MongoDB document model for an installed agent instance, storing metadata about an agent deployed on a specific machine within a tenant's environment.

## Key Components

| Member | Type | Description |
|---|---|---|
| `id` | `String` | MongoDB document identifier (`@Id`) |
| `tenantId` | `String` | Indexed tenant reference for multi-tenant scoping |
| `machineId` | `String` | Identifier of the machine where the agent is installed |
| `agentType` | `String` | Classifier for the type of agent |
| `version` | `String` | Installed agent version string |
| `status` | `ConnectionStatus` | Current connection state of the agent |
| `createdAt` / `updatedAt` | `String` | Audit timestamps |

**Interfaces implemented:**
- `TenantScoped` — enforces multi-tenant data isolation
- Stored in the `installed_agents` MongoDB collection

## Usage Example

```java
InstalledAgent agent = new InstalledAgent();
agent.setTenantId("tenant-abc");
agent.setMachineId("machine-001");
agent.setAgentType("monitoring");
agent.setVersion("1.4.2");
agent.setStatus(ConnectionStatus.CONNECTED);
agent.setCreatedAt(Instant.now().toString());
agent.setUpdatedAt(Instant.now().toString());

// Persist via repository
installedAgentRepository.save(agent);
```

## Notes

- The `@Indexed` annotation on `tenantId` optimizes multi-tenant queries against the `installed_agents` collection.
- Uses Lombok `@Data` for automatic generation of getters, setters, `equals`, `hashCode`, and `toString`.
