MongoDB document entity representing a single time-tracking record, mapping technician work sessions to tickets and organizations within a multi-tenant MSP environment.

## Key Components

| Field | Type | Description |
|---|---|---|
| `id` | `String` | MongoDB document identifier |
| `tenantId` | `String` | Tenant scope identifier (indexed) |
| `userId` | `String` | Technician who logged the time |
| `ticketId` / `ticketNumber` / `ticketTitle` | `String` / `Integer` / `String` | Associated ticket reference |
| `organizationId` | `String` | Client organization scope |
| `startedAt` / `endedAt` | `Instant` | Timer start/stop boundaries; `endedAt` is `null` while running |
| `pausedAt` | `Instant` | Non-null while paused; cleared on resume after accumulating into `breakSeconds` |
| `durationSeconds` / `breakSeconds` | `long` | Net work time and accumulated pause time |
| `source` | `TimeEntrySource` | Enum indicating how the entry was created |
| `createdBy` / `lastModifiedBy` | `String` | Audit trail fields |
| `createdAt` / `updatedAt` | `Instant` | Auto-managed by Spring Data (`@CreatedDate` / `@LastModifiedDate`) |

### Compound Indexes

| Index Name | Fields | Notes |
|---|---|---|
| `tenant_user_active` | `tenantId`, `userId` | Unique, partial filter on `endedAt: null` — enforces one active timer per user per tenant |
| `tenant_user_started` | `tenantId`, `userId`, `startedAt DESC` | History queries by user |
| `tenant_ticket_started` | `tenantId`, `ticketId`, `startedAt DESC` | History queries by ticket |
| `tenant_org_started` | `tenantId`, `organizationId`, `startedAt DESC` | History queries by organization |

## Usage Example

```java
// Start a new time entry
TimeEntry entry = TimeEntry.builder()
        .tenantId("tenant-abc")
        .userId("tech-001")
        .ticketId("ticket-xyz")
        .ticketNumber(1042)
        .ticketTitle("VPN connectivity issue")
        .organizationId("org-456")
        .startedAt(Instant.now())
        .source(TimeEntrySource.MANUAL)
        .createdBy("tech-001")
        .build();

// Pause the timer
entry.setPausedAt(Instant.now());

// Resume: accumulate break time and clear pause marker
long pauseDuration = Duration.between(entry.getPausedAt(), Instant.now()).getSeconds();
entry.setBreakSeconds(entry.getBreakSeconds() + pauseDuration);
entry.setPausedAt(null);

// Stop the timer
entry.setEndedAt(Instant.now());
entry.setDurationSeconds(
        Duration.between(entry.getStartedAt(), entry.getEndedAt()).getSeconds()
        - entry.getBreakSeconds()
);
```
