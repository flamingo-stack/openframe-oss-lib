MongoDB document entity representing a managed device (machine) within a tenant's infrastructure, storing hardware identity, network details, OS metadata, and security/compliance state.

## Key Components

| Field | Type | Description |
|---|---|---|
| `id` | `String` | MongoDB-generated primary key (`@Id`) |
| `machineId` | `String` | Device authentication identifier — mirrors `OAuthClient` ID |
| `tenantId` | `String` | Tenant scoping field (`@Indexed`, implements `TenantScoped`) |
| `organizationId` | `String` | Organization subdivision within a tenant (`@Indexed`) |
| `status` | `DeviceStatus` | Current device status enum (`@Indexed`) |
| `type` | `DeviceType` | Device classification enum (`@Indexed`) |
| `osType` | `String` | Operating system family (`@Indexed`) |
| `securityState` | `SecurityState` | Aggregated security posture |
| `complianceState` | `ComplianceState` | Aggregated compliance posture |
| `securityAlerts` | `List<SecurityAlert>` | Active security alerts on the device |
| `complianceRequirements` | `List<ComplianceRequirement>` | Evaluated compliance rules |
| `registeredAt` | `Instant` | First registration timestamp (`@CreatedDate`) |
| `updatedAt` | `Instant` | Last modification timestamp (`@LastModifiedDate`) |
| `stuckNotifiedAt` | `Instant` | Tracks when a `DEVICE_STUCK` event was last dispatched |

## Usage Example

```java
Machine machine = new Machine();
machine.setTenantId("tenant-abc");
machine.setMachineId("mach-001");
machine.setHostname("workstation-01");
machine.setDisplayName("Alice's MacBook");
machine.setIp("192.168.1.42");
machine.setOsType("macOS");
machine.setOsVersion("14.4");
machine.setType(DeviceType.LAPTOP);
machine.setStatus(DeviceStatus.ONLINE);
machine.setOrganizationId("org-xyz");

machineRepository.save(machine);
```

## Notes

- Stored in the `machines` MongoDB collection.
- `machineId` is **not** the MongoDB `_id` — it aligns with the corresponding `OAuthClient` for device authentication flows.
- `stuckNotifiedAt` enables idempotent stuck-device alerting; a `null` value indicates no notification has been sent yet.
