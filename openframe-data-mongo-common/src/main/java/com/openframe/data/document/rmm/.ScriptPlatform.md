Enum representing the supported operating-system platforms for RMM script execution targeting.

## Key Components

| Constant | Description |
|---|---|
| `WINDOWS` | Microsoft Windows platform |
| `LINUX` | Linux-based platform |
| `MACOS` | Apple macOS platform |

## Usage Example

```java
Script script = new Script();
script.setPlatform(ScriptPlatform.WINDOWS);

if (script.getPlatform() == ScriptPlatform.LINUX) {
    // handle Linux-specific execution logic
}
```

> **Note:** Platform granularity is intentionally minimal. Finer-grained distinctions (e.g. specific Windows versions or Linux distros) should be handled within the script body or via runtime arguments rather than additional enum values.
