Represents a header record for a single `ScriptSchedule` fire event, stored in MongoDB. One document is created per schedule run, acting as a coordination point that links all per-(script, machine) leaf `ScriptExecution` records produced by the same fire via a shared `executionId`.

## Key Components

| Member | Type | Description |
|---|---|---|
| `id` | `String` | MongoDB document identifier |
| `tenantId` | `String` | Tenant isolation field (via `TenantScoped`) |
| `executionId` | `String` | Correlation ID shared with all leaf `ScriptExecution` rows from this fire |
| `scheduleId` | `String` | Reference to the parent `ScriptSchedule` |
| `initiatedBy` | `String` | User or system that triggered the run |
| `scriptIds` | `List<String>` | Snapshot of runnable scripts at dispatch time |
| `machineIds` | `List<String>` | Snapshot of targeted machines at dispatch time |
| `status` | `ExecutionStatus` | `RUNNING` → `SUCCESS` or `FAILED` lifecycle state |
| `dispatchedAt` | `Instant` | Timestamp when the run was dispatched |
| `finishedAt` | `Instant` | Timestamp when all leaf executions completed |
| `createdAt` | `Instant` | Auto-populated by Spring Data (`@CreatedDate`) |

**Indexes:**
- Unique compound index on `(tenantId, executionId)`
- Compound index on `(tenantId, scheduleId, dispatchedAt DESC)` for schedule history queries
- Single-field indexes on `executionId`, `scheduleId`, and `status`

## Usage Example

```java
ScheduleScriptExecution header = ScheduleScriptExecution.builder()
    .tenantId("tenant-abc")
    .executionId(UUID.randomUUID().toString())
    .scheduleId("sched-123")
    .initiatedBy("system")
    .scriptIds(List.of("script-1", "script-2"))
    .machineIds(List.of("machine-a", "machine-b"))
    .status(ExecutionStatus.RUNNING)
    .dispatchedAt(Instant.now())
    .build();

repository.save(header);
```

> **Note:** `scriptIds` and `machineIds` are intentional snapshots — they preserve what was actually attempted even if the schedule or target set is later modified.
