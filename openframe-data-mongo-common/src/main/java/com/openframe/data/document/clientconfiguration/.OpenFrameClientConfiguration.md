MongoDB document entity representing the OpenFrame client configuration for a specific tenant, storing versioned download settings and publish state with automatic audit timestamps.

## Key Components

| Field | Type | Description |
|---|---|---|
| `id` | `String` | MongoDB document identifier (`@Id`) |
| `tenantId` | `String` | Unique tenant identifier (`@Indexed(unique = true)`) |
| `documentVersion` | `Long` | Optimistic locking version (`@Version`) |
| `version` | `String` | Client configuration version string |
| `downloadConfiguration` | `List<DownloadConfiguration>` | List of download config entries |
| `publishState` | `PublishState` | Current publish lifecycle state |
| `createdAt` / `updatedAt` | `LocalDateTime` | Auto-managed audit timestamps |

Implements `TenantScoped` to enforce multi-tenant data isolation across the platform.

## Usage Example

```java
OpenFrameClientConfiguration config = OpenFrameClientConfiguration.builder()
    .tenantId("tenant-abc-123")
    .version("1.4.0")
    .downloadConfiguration(List.of(
        DownloadConfiguration.builder()
            .platform("windows")
            .url("https://cdn.openframe.ai/releases/1.4.0/win")
            .build()
    ))
    .publishState(PublishState.DRAFT)
    .build();

repository.save(config);
```

## Notes

- Collection name: `openframe_client_configuration`
- `tenantId` has a unique index — one configuration document per tenant
- Optimistic locking via `@Version` prevents concurrent write conflicts
- Timestamps (`createdAt`, `updatedAt`) are managed automatically by Spring Data MongoDB
