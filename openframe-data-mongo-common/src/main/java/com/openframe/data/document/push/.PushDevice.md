Represents a MongoDB document for storing push notification device registrations, mapping a user's device token to a tenant and platform.

## Key Components

| Element | Description |
|---|---|
| `@Document("push_devices")` | Maps to the `push_devices` MongoDB collection |
| `TenantScoped` | Enforces tenant isolation across all push device records |
| `tenant_token_unique` | Compound index ensuring a token is unique per tenant |
| `tenant_user` | Compound index for efficient lookups by tenant and user |
| `platform` | Enum (`PushPlatform`) identifying the target OS/platform (e.g. iOS, Android) |

**Fields:**

| Field | Type | Description |
|---|---|---|
| `id` | `String` | MongoDB document ID |
| `tenantId` | `String` | Owning tenant identifier |
| `userId` | `String` | Associated user identifier |
| `token` | `String` | Device push notification token |
| `platform` | `PushPlatform` | Target platform |
| `createdAt` / `updatedAt` | `Instant` | Audit timestamps |

## Usage Example

```java
PushDevice device = PushDevice.builder()
    .tenantId("tenant-001")
    .userId("user-abc")
    .token("fcm-device-token-xyz")
    .platform(PushPlatform.ANDROID)
    .createdAt(Instant.now())
    .updatedAt(Instant.now())
    .build();

pushDeviceRepository.save(device);
```

## Notes

- The `tenant_token_unique` index prevents duplicate device registrations for the same token within a tenant.
- Lombok annotations (`@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor`) handle boilerplate generation.
