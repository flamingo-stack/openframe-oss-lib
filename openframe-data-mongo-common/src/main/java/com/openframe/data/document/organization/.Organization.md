Defines the MongoDB document model for an `Organization` entity, representing a company or managed client within a tenant's scope. Implements `TenantScoped` for multi-tenant data isolation.

## Key Components

| Member | Type | Description |
|---|---|---|
| `organizationId` | `String` | Immutable UUID assigned at creation; unique across all tenants |
| `tenantId` | `String` | Tenant isolation key (indexed) |
| `isDefault` | `Boolean` | Marks the tenant's default organization; defaults to `false` |
| `status` | `OrganizationStatus` | Lifecycle state (`ACTIVE`, `ARCHIVED`, `DELETED`); defaults to `ACTIVE` |
| `contactInformation` | `ContactInformation` | Nested object holding contacts and addresses |
| `monthlyRevenue` | `BigDecimal` | Revenue figure in the organization's currency |
| `contractStartDate` / `contractEndDate` | `LocalDate` | Contract validity window |
| `isContractActive()` | `boolean` | Returns `true` if today falls within the contract date range |
| `isDeleted()` | `boolean` | Returns `true` if status is `DELETED` (soft delete check) |
| `isArchived()` | `boolean` | Returns `true` if status is `ARCHIVED` |

> **Note on soft delete:** Organizations use `ARCHIVED`/`DELETED` statuses instead of hard deletion to preserve references for devices that may come back online.

## Usage Example

```java
// Build a new organization using the Lombok SuperBuilder
Organization org = Organization.builder()
    .tenantId("tenant-abc")
    .organizationId(UUID.randomUUID().toString())
    .name("Acme Corp")
    .category("Technology")
    .numberOfEmployees(150)
    .websiteUrl("https://acme.example.com")
    .monthlyRevenue(new BigDecimal("25000.00"))
    .contractStartDate(LocalDate.of(2024, 1, 1))
    .contractEndDate(LocalDate.of(2025, 12, 31))
    .isDefault(true)
    .build();

// Check contract and lifecycle status
if (org.isContractActive()) {
    System.out.println("Contract is currently active");
}

if (!org.isDeleted() && !org.isArchived()) {
    // Safe to include in normal queries
}
```
