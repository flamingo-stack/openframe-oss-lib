MongoDB document model representing a tenant-scoped event entity within the OpenFrame core event system.

## Key Components

| Member | Type | Description |
|---|---|---|
| `id` | `String` | MongoDB document identifier (`@Id`) |
| `tenantId` | `String` | Indexed tenant reference for multi-tenancy scoping |
| `type` | `String` | Event type classifier |
| `payload` | `String` | Serialized event data |
| `timestamp` | `Instant` | UTC time of event occurrence |
| `userId` | `String` | Originating user reference |
| `status` | `EventStatus` | Current processing state |
| `EventStatus` | `enum` | `CREATED`, `PROCESSING`, `COMPLETED`, `FAILED` |

## Usage Example

```java
CoreEvent event = new CoreEvent();
event.setTenantId("tenant-abc");
event.setType("DEVICE_CONNECTED");
event.setPayload("{\"deviceId\":\"dev-123\"}");
event.setTimestamp(Instant.now());
event.setUserId("user-456");
event.setStatus(CoreEvent.EventStatus.CREATED);

// Persisted to MongoDB "events" collection
mongoTemplate.save(event);

// Query by status
Query query = new Query(
    Criteria.where("tenantId").is("tenant-abc")
            .and("status").is(CoreEvent.EventStatus.PROCESSING)
);
List<CoreEvent> events = mongoTemplate.find(query, CoreEvent.class);
```

## Notes

- Stored in the MongoDB `events` collection via `@Document`
- Implements `TenantScoped` to enforce multi-tenant data isolation
- `tenantId` carries a MongoDB index for efficient per-tenant queries
- Lombok `@Data` generates getters, setters, `equals`, `hashCode`, and `toString`
