MongoDB document entity representing a PSA/ticketing system ticket, storing all ticket metadata including status, ownership, assignment, and device/organization associations.

## Key Components

| Member | Type | Description |
|---|---|---|
| `id` | `String` | MongoDB document identifier (`@Id`) |
| `tenantId` | `String` | Multi-tenancy scoping via `TenantScoped` |
| `ticketNumber` | `Integer` | Human-readable ticket number (unique per tenant) |
| `status` / `statusId` / `statusKind` | Mixed | Dual-track status fields during lifecycle migration |
| `owner` | `TicketOwner` | Embedded owner reference |
| `deviceId` / `organizationId` / `assignedTo` | `String` | Indexed foreign-key references |
| `createdAt` / `updatedAt` | `Instant` | Auto-managed audit timestamps |
| `resolvedAt` | `Instant` | Explicit resolution timestamp |
| `isAiDisabled()` | `boolean` | Returns `true` when `statusKind` is set and not `AI_ASSISTANCE` |

## Compound Indexes

```text
tenant_ticketNumber_idx  →  { tenantId, ticketNumber }  UNIQUE
status_order             →  { status, order }            (legacy — pending removal)
status_kind              →  { statusKind }
status_id_order          →  { statusId, order }
```

## Usage Example

```java
Ticket ticket = Ticket.builder()
    .tenantId("tenant-abc")
    .ticketNumber(1042)
    .title("VPN not connecting")
    .description("User cannot reach internal resources.")
    .statusKind(TicketStatusKind.AI_ASSISTANCE)
    .statusId("status-open")
    .creationSource(TicketCreationSource.PORTAL)
    .organizationId("org-xyz")
    .assignedTo("tech-007")
    .build();

// Check if AI assistance is active
boolean aiOff = ticket.isAiDisabled(); // false — statusKind is AI_ASSISTANCE
```

> **Migration note:** The legacy `status` field and `status_order` index are retained during the `lifecycle-rollout` transition. New code should read/write `statusKind` and `statusId` exclusively. See [`Ticket.java`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/data/document/ticket/Ticket.java) for the full rollout TODOs.
