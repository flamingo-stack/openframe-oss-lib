A flexible extension of `NotificationContext` that carries arbitrary notification data using a generic type identifier and raw payload string.

## Key Components

| Member | Type | Description |
|--------|------|-------------|
| `type` | `String` | Identifies the category or kind of the generic notification |
| `payload` | `String` | Raw string content (e.g., JSON, XML, plain text) representing the notification body |

Inherits all fields and behavior from `NotificationContext` via Lombok's `@SuperBuilder`, `@EqualsAndHashCode(callSuper = true)`, and `@ToString(callSuper = true)`.

## Usage Example

```java
// Build a GenericContext using the Lombok SuperBuilder
GenericContext context = GenericContext.builder()
    .type("ALERT")
    .payload("{\"message\": \"Disk usage exceeded 90%\", \"host\": \"server-01\"}")
    .build();

// Access fields
String notificationType = context.getType();    // "ALERT"
String notificationData = context.getPayload(); // raw JSON string

// No-args constructor + setters also available
GenericContext ctx = new GenericContext();
ctx.setType("INFO");
ctx.setPayload("System reboot scheduled.");
```

## Notes

- Extends [`NotificationContext`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/data/document/notification/NotificationContext.java) — parent-class fields are included in equality checks, hash codes, and `toString()` output.
- The `payload` field is intentionally untyped, making `GenericContext` suitable for forwarding notification data whose schema is defined externally or varies at runtime.
