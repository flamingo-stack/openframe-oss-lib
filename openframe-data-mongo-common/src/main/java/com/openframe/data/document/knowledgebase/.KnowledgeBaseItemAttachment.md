MongoDB document entity representing a file attachment linked to a knowledge base item, scoped to a specific tenant.

## Key Components

| Member | Type | Description |
|--------|------|-------------|
| `id` | `String` | MongoDB document identifier (`@Id`) |
| `tenantId` | `String` | Tenant scope identifier (implements `TenantScoped`) |
| `itemId` | `String` | Reference to the parent `KnowledgeBaseItem` |
| `fileName` | `String` | Original name of the uploaded file |
| `storagePath` | `String` | Path to the file in the backing object store |
| `fileSize` | `Long` | File size in bytes |
| `contentType` | `String` | MIME type of the file |
| `uploadedBy` | `String` | Identifier of the user who uploaded the file |
| `createdAt` | `Instant` | Auto-populated timestamp via `@CreatedDate` |

**Collection:** `knowledge_base_item_attachments`

**Index:** Compound index `tenant_item_idx` on `(tenantId, itemId)` for efficient per-tenant item attachment lookups.

## Usage Example

```java
KnowledgeBaseItemAttachment attachment = KnowledgeBaseItemAttachment.builder()
    .tenantId("tenant-abc")
    .itemId("kb-item-123")
    .fileName("network-diagram.pdf")
    .storagePath("attachments/tenant-abc/kb-item-123/network-diagram.pdf")
    .fileSize(204800L)
    .contentType("application/pdf")
    .uploadedBy("user-456")
    .build();

// Persist via repository
attachmentRepository.save(attachment);

// Query all attachments for a knowledge base item
List<KnowledgeBaseItemAttachment> attachments =
    attachmentRepository.findByTenantIdAndItemId("tenant-abc", "kb-item-123");
```

## Notes

- Implements [`TenantScoped`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/data/document/TenantScoped.java) to enforce multi-tenancy across all queries.
- `createdAt` is managed automatically by Spring Data's auditing — no manual assignment required.
- `storagePath` is storage-backend agnostic; consumers are responsible for resolving it against the configured provider (e.g., S3, GCS).
