MongoDB document entity representing a tenant-scoped integrated tool agent, storing configuration and lifecycle metadata for managing agent installations within the OpenFrame platform.

## Key Components

| Member | Type | Description |
|---|---|---|
| `id` | `String` | MongoDB document identifier (`@Id`) |
| `tenantId` | `String` | Tenant scoping identifier (part of compound unique index with `key`) |
| `key` | `String` | Agent key; combined with `tenantId` to enforce uniqueness |
| `documentVersion` | `Long` | Optimistic locking version field (`@Version`) |
| `toolId` | `String` | Reference to the associated tool |
| `releaseVersion` | `boolean` | Flags whether this is a production release |
| `version` | `String` | Version string for the agent |
| `sessionType` | `SessionType` | Defines the agent's session behaviour |
| `downloadConfigurations` | `List<DownloadConfiguration>` | Download sources/settings for agent artifacts |
| `assets` | `List<ToolAgentAsset>` | Associated binary or file assets |
| `installationCommandArgs` | `List<String>` | CLI args used during agent installation |
| `runCommandArgs` | `List<String>` | CLI args used to start the agent |
| `agentToolIdCommandArgs` | `List<String>` | CLI args for passing tool identity to the agent |
| `uninstallationCommandArgs` | `List<String>` | CLI args used during agent removal |
| `status` | `ToolAgentStatus` | Current lifecycle status of the agent |
| `publishState` | `PublishState` | Publication/visibility state of the agent |

## Usage Example

```java
IntegratedToolAgent agent = new IntegratedToolAgent();
agent.setTenantId("tenant-123");
agent.setKey("remote-support-agent");
agent.setToolId("tool-456");
agent.setVersion("2.1.0");
agent.setReleaseVersion(true);
agent.setSessionType(SessionType.PERSISTENT);
agent.setInstallationCommandArgs(List.of("--silent", "--accept-license"));
agent.setRunCommandArgs(List.of("--port", "9090"));
agent.setUninstallationCommandArgs(List.of("--purge"));
agent.setStatus(ToolAgentStatus.ACTIVE);
agent.setPublishState(PublishState.PUBLISHED);
```

## Notes

- The `@CompoundIndex` on `(tenantId, key)` enforces per-tenant uniqueness with `sparse = true`, allowing documents with null keys.
- Implements `TenantScoped` to support multi-tenant data isolation patterns used across OpenFrame.
