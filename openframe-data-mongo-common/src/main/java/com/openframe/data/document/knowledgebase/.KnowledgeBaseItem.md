Represents a single knowledge base item (article or category) stored in MongoDB, implementing multi-tenant scoping via the `TenantScoped` interface.

## Key Components

| Field | Type | Description |
|---|---|---|
| `id` | `String` | MongoDB document identifier (`@Id`) |
| `tenantId` | `String` | Tenant isolator, fulfills `TenantScoped` contract |
| `type` | `KnowledgeBaseItemType` | Discriminator enum (e.g., `ARTICLE`, `CATEGORY`) |
| `parentId` | `String` | Reference to parent item for hierarchical structure |
| `slug` | `String` | URL-friendly identifier |
| `status` | `KnowledgeBaseArticleStatus` | Publication state (e.g., `DRAFT`, `PUBLISHED`) |
| `sortOrder` | `Integer` | Controls display ordering within a parent |
| `content` | `String` | Full body content of the item |
| `summary` | `String` | Short excerpt or description |
| `publishedAt` | `Instant` | Timestamp of publication |
| `createdAt` / `updatedAt` | `Instant` | Auto-managed audit timestamps via Spring Data |

**Compound Indexes:**
- `tenant_parent_type_sort` — optimizes hierarchical tree queries filtered by tenant, parent, and type
- `tenant_type_status` — optimizes listing queries filtered by tenant, type, and publication status

## Usage Example

```java
KnowledgeBaseItem article = KnowledgeBaseItem.builder()
    .tenantId("tenant-abc")
    .type(KnowledgeBaseItemType.ARTICLE)
    .name("How to Reset Your Password")
    .slug("how-to-reset-password")
    .parentId("category-123")
    .status(KnowledgeBaseArticleStatus.PUBLISHED)
    .publishedAt(Instant.now())
    .content("Step 1: Navigate to the login page...")
    .summary("Quick guide to resetting your password.")
    .sortOrder(1)
    .createdBy("user-xyz")
    .build();
```
