MongoDB document entity representing an integrated third-party tool within a tenant's OpenFrame environment, storing connection metadata, categorization, layer assignments, and monitoring configuration.

## Key Components

| Member | Type | Description |
|---|---|---|
| `id` | `String` | MongoDB document identifier (`@Id`) |
| `tenantId` | `String` | Tenant scoping field (implements `TenantScoped`) |
| `key` | `String` | Unique tool identifier per tenant (compound index with `tenantId`) |
| `name` / `description` / `icon` | `String` | Display metadata |
| `toolUrls` | `List<ToolUrl>` | Endpoint URL configurations for the tool |
| `credentials` | `ToolCredentials` | Authentication/connection credentials |
| `type` / `toolType` / `category` / `platformCategory` | `String` | Classification fields |
| `layer` / `layerOrder` / `layerColor` | `String` / `Integer` | Visual layer placement in OpenFrame UI |
| `metricsPath` / `healthCheckEndpoint` | `String` | Monitoring integration paths |
| `healthCheckInterval` / `connectionTimeout` / `readTimeout` | `Integer` | Connectivity timing settings (milliseconds) |
| `allowedEndpoints` | `String[]` | Permitted API endpoint whitelist |
| `debeziumConnectors` | `Object[]` | CDC connector configurations |
| `enabled` | `boolean` | Activation toggle |

## Usage Example

```java
IntegratedTool tool = IntegratedTool.builder()
    .tenantId("tenant-abc")
    .key("psa-autotask")
    .name("Autotask PSA")
    .type("PSA")
    .toolType("psa")
    .category("service-management")
    .enabled(true)
    .layer("business")
    .layerOrder(1)
    .healthCheckEndpoint("/api/v1/health")
    .healthCheckInterval(30)
    .connectionTimeout(5000)
    .readTimeout(10000)
    .build();
```

> **Index:** A unique compound index (`tenant_key_idx`) on `{tenantId, key}` enforces that each tool key is unique per tenant, with `sparse = true` allowing null keys without conflict.
