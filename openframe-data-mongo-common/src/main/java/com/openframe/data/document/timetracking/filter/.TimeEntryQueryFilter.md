A filter model for querying time entries, supporting multi-dimensional filtering by user, ticket, organization, source, date range, state, and free-text search.

## Key Components

| Field | Type | Description |
|---|---|---|
| `userIds` | `List<String>` | Filter by one or more user IDs |
| `ticketIds` | `List<String>` | Filter by one or more ticket IDs |
| `organizationIds` | `List<String>` | Filter by one or more organization IDs |
| `sources` | `List<TimeEntrySource>` | Filter by time entry source (e.g. manual, integration) |
| `startedFrom` | `Instant` | Lower bound for time entry start timestamp |
| `startedTo` | `Instant` | Upper bound for time entry start timestamp |
| `state` | `TimeEntryStateFilter` | Filter by entry state (e.g. open, billed) |
| `search` | `String` | Free-text search term |

Lombok annotations (`@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor`) provide getters/setters, a fluent builder, and both default and all-args constructors.

## Usage Example

```java
TimeEntryQueryFilter filter = TimeEntryQueryFilter.builder()
    .userIds(List.of("user-123", "user-456"))
    .organizationIds(List.of("org-789"))
    .sources(List.of(TimeEntrySource.MANUAL))
    .startedFrom(Instant.parse("2024-01-01T00:00:00Z"))
    .startedTo(Instant.parse("2024-01-31T23:59:59Z"))
    .state(TimeEntryStateFilter.OPEN)
    .search("server maintenance")
    .build();
```
