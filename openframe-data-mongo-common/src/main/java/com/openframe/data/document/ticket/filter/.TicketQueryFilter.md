A filter data object used to query tickets with support for both legacy and lifecycle-enabled status filtering, along with a variety of shared filtering dimensions.

## Key Components

| Field | Type | Description |
|---|---|---|
| `statuses` | `List<TicketStatus>` | **Legacy** — filter by enum statuses (used when lifecycle flag is OFF) |
| `statusIds` | `List<String>` | **Lifecycle** — filter by status IDs (used when lifecycle flag is ON) |
| `statusKinds` | `List<TicketStatusKind>` | **Lifecycle** — filter by status kind categories |
| `organizationIds` | `List<String>` | Scope results to specific organizations |
| `assigneeIds` | `List<String>` | Filter by assigned technician/user IDs |
| `tagIds` | `List<String>` | Filter by applied tag IDs |
| `deviceIds` | `List<String>` | Filter tickets linked to specific devices |
| `creationSources` | `List<TicketCreationSource>` | Filter by how tickets were created |
| `createdAtFrom` / `createdAtTo` | `Instant` | Date range filter on ticket creation time |

> **Note:** `statuses` is marked for removal after the lifecycle feature flag rollout. New code should prefer `statusIds` and `statusKinds`.

## Usage Example

```java
// Legacy usage (lifecycle flag OFF)
TicketQueryFilter legacyFilter = TicketQueryFilter.builder()
    .statuses(List.of(TicketStatus.OPEN, TicketStatus.IN_PROGRESS))
    .organizationIds(List.of("org-123"))
    .build();

// Lifecycle usage (lifecycle flag ON)
TicketQueryFilter lifecycleFilter = TicketQueryFilter.builder()
    .statusKinds(List.of(TicketStatusKind.OPEN))
    .assigneeIds(List.of("user-456"))
    .createdAtFrom(Instant.parse("2024-01-01T00:00:00Z"))
    .createdAtTo(Instant.now())
    .build();
```
