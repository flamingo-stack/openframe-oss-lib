Represents a MongoDB document storing a tenant's cryptographic key pair, including the public PEM and encrypted private key, with support for key rotation tracking and activation state.

## Key Components

| Field | Type | Description |
|---|---|---|
| `id` | `String` | MongoDB document identifier (`@Id`) |
| `tenantId` | `String` | Indexed reference to the owning tenant |
| `keyId` | `String` | Logical identifier for the key pair |
| `publicPem` | `String` | PEM-encoded public key |
| `privateEncrypted` | `String` | Encrypted private key material |
| `active` | `boolean` | Indicates if this key is currently active |
| `createdAt` | `Instant` | Auto-populated creation timestamp |
| `rotatedAt` | `Instant` | Auto-updated timestamp on each modification (tracks rotation) |

**Interfaces:** Implements `TenantScoped` to enforce tenant isolation across the data layer.

**Collection:** `tenant_keys`

## Usage Example

```java
TenantKey tenantKey = new TenantKey();
tenantKey.setTenantId("tenant-abc-123");
tenantKey.setKeyId("key-v1");
tenantKey.setPublicPem("-----BEGIN PUBLIC KEY-----\n...");
tenantKey.setPrivateEncrypted("enc:base64encodedciphertext==");
tenantKey.setActive(true);

// Persist via Spring Data repository
tenantKeyRepository.save(tenantKey);

// Query active key for a tenant
TenantKey activeKey = tenantKeyRepository
    .findByTenantIdAndActiveTrue("tenant-abc-123");
```

> **Note:** `rotatedAt` is managed by Spring Data's `@LastModifiedDate` — it automatically updates on every save, making it a reliable audit trail for key rotation events.
