Brief enum defining the origin of a time entry — whether it was created via an automatic timer or entered manually.

## Key Components

| Constant | Description |
|---|---|
| `TIMER` | Time entry was created by starting and stopping a timer |
| `MANUAL` | Time entry was entered manually by a user |

## Usage Example

```java
TimeEntry entry = new TimeEntry();
entry.setSource(TimeEntrySource.TIMER);

if (entry.getSource() == TimeEntrySource.MANUAL) {
    // apply manual entry validation logic
}
```
