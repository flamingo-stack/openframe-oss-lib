MongoDB document entity representing an OAuth2 authorization record, supporting multi-tenant storage with automatic TTL-based expiration for token cleanup.

## Key Components

| Member | Description |
|---|---|
| `id` | Primary document identifier (`@Id`) |
| `tenantId` | Tenant isolation field (`@Indexed`), implements `TenantScoped` |
| `registeredClientId` / `principalName` | Compound-indexed pair for efficient client+user lookups |
| `ar*` fields | Minimal PKCE authorization request snapshot (flat strings to avoid MongoDB dotted-key issues) |
| `authorizationCode*` | Authorization code value, timestamps, and metadata |
| `accessToken*` | Access token value, type, scopes (space-delimited), timestamps, and metadata |
| `refreshToken*` | Refresh token value, timestamps, and metadata |
| `expiresAt` | TTL index field (`expireAfterSeconds = 0`); drives automatic MongoDB document expiration |
| `updateExpiresAt()` | Sets `expiresAt` to the latest non-null expiration across all three token types |

## Usage Example

```java
MongoOAuth2Authorization auth = new MongoOAuth2Authorization();
auth.setId(UUID.randomUUID().toString());
auth.setTenantId("tenant-abc");
auth.setRegisteredClientId("my-client");
auth.setPrincipalName("user@example.com");
auth.setAuthorizationGrantType("authorization_code");

// Set token expiration
auth.setAccessTokenValue("eyJ...");
auth.setAccessTokenIssuedAt(Instant.now());
auth.setAccessTokenExpiresAt(Instant.now().plusSeconds(3600));

// Sync the TTL index field
auth.updateExpiresAt();

mongoTemplate.save(auth);
```

> **Note:** Always call `updateExpiresAt()` after modifying any token expiration field to keep the MongoDB TTL index in sync and ensure stale authorizations are automatically purged.
