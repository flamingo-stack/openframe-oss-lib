MongoDB document entity representing the assignment of an item (such as a checklist or template) to a target entity (such as a company or device), scoped to a specific tenant.

## Key Components

| Element | Description |
|---|---|
| `ItemAssignment` | Main document class mapped to the `item_assignments` MongoDB collection |
| `TenantScoped` | Interface implemented to enforce tenant isolation across documents |
| `AssignmentItemType` | Enum defining the type of item being assigned (e.g., checklist, template) |
| `AssignmentTargetType` | Enum defining the target entity type (e.g., company, device) |

### Fields

| Field | Type | Notes |
|---|---|---|
| `id` | `String` | MongoDB `_id` |
| `tenantId` | `String` | Indexed; tenant isolation via `TenantScoped` |
| `itemId` | `String` | ID of the item being assigned |
| `itemType` | `AssignmentItemType` | Category of the assigned item |
| `targetType` | `AssignmentTargetType` | Category of the assignment target |
| `targetId` | `String` | Indexed; ID of the target entity |
| `displayName` | `String` | Human-readable label for the assignment |
| `createdAt` | `Instant` | Auto-populated by Spring Data on insert |

### Indexes

- **`item_target_unique`** — Compound unique index on `itemId`, `targetType`, `targetId`; prevents duplicate assignments
- **`target_lookup`** — Compound index on `targetType`, `targetId`; optimizes queries fetching all items assigned to a target

## Usage Example

```java
ItemAssignment assignment = ItemAssignment.builder()
    .tenantId("tenant-001")
    .itemId("checklist-42")
    .itemType(AssignmentItemType.CHECKLIST)
    .targetType(AssignmentTargetType.COMPANY)
    .targetId("company-99")
    .displayName("Onboarding Checklist")
    .build();

itemAssignmentRepository.save(assignment);
```
