Extends `SSOConfig` to add tenant-specific audit timestamps for SSO configurations stored per-tenant in a document database.

## Key Components

| Member | Type | Description |
|---|---|---|
| `createdAt` | `LocalDateTime` | Auto-populated creation timestamp via `@CreatedDate` |
| `updatedAt` | `LocalDateTime` | Auto-updated modification timestamp via `@LastModifiedDate` |

Inherits from [`SSOConfig`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/data/document/sso/SSOConfig.java): provider identity, client credentials, and enabled flag.

## Usage Example

```java
SSOPerTenantConfig config = new SSOPerTenantConfig();
config.setProvider("okta");
config.setClientId("client-abc");
config.setClientSecret("secret-xyz");
config.setEnabled(true);
// createdAt and updatedAt are managed automatically by Spring Data auditing
tenantRepository.save(tenant.setSsoConfig(config));
```

> **Note:** Requires Spring Data auditing enabled (`@EnableMongoAuditing` or equivalent) for `@CreatedDate` and `@LastModifiedDate` to populate automatically.
