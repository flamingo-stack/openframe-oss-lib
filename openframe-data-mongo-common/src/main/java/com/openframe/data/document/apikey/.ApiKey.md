MongoDB document entity representing an API key with tenant scoping, permission management, and lifecycle state tracking.

## Key Components

| Member | Type | Description |
|---|---|---|
| `keyId` | `String` (`@Id`) | Primary identifier for the API key |
| `tenantId` | `String` (`@Indexed`) | Tenant scope identifier (via `TenantScoped`) |
| `hashedKey` | `String` | Hashed secret; raw key is never stored |
| `userId` | `String` (`@Indexed`) | Owner of the API key |
| `scopes` / `roles` | `List<String>` | Permission scopes and roles (pending full implementation) |
| `enabled` | `boolean` | Soft-disable flag; defaults to `true` |
| `expiresAt` | `Instant` | Optional expiry timestamp |
| `isExpired()` | `boolean` | Returns `true` if `expiresAt` is set and in the past |
| `isActive()` | `boolean` | Returns `true` if the key is enabled **and** not expired |

## Usage Example

```java
// Create a new API key document
ApiKey apiKey = ApiKey.builder()
    .tenantId("tenant-abc")
    .userId("user-123")
    .hashedKey(hashService.hash(rawKey))
    .name("CI Pipeline Key")
    .description("Used by GitHub Actions")
    .scopes(List.of("read:devices", "write:tickets"))
    .expiresAt(Instant.now().plus(90, ChronoUnit.DAYS))
    .createdAt(Instant.now())
    .updatedAt(Instant.now())
    .build();

// Validate before use
if (apiKey.isActive()) {
    // proceed with authenticated request
}
```

## Notes

- Stored in the `api_keys` MongoDB collection
- Implements `TenantScoped` to enforce multi-tenant data isolation
- `scopes` and `roles` fields are defined but authorization enforcement is marked as TODO
- Raw keys must be hashed before assignment to `hashedKey`
