Represents a MongoDB document that records the assignment of a tag to a specific entity within a tenant's scope, stored in the `tag_assignments` collection.

## Key Components

| Member | Type | Description |
|---|---|---|
| `id` | `String` | MongoDB document identifier (`@Id`) |
| `tenantId` | `String` | Tenant scope identifier (implements `TenantScoped`) |
| `entityId` | `String` | ID of the entity the tag is assigned to |
| `tagId` | `String` | Reference to the assigned tag |
| `entityType` | `TagEntityType` | Enum classifying the entity type (e.g., device, site) |
| `values` | `List<String>` | Per-entity values for key-value tags; empty for simple label tags |
| `taggedAt` | `Instant` | Timestamp of when the tag was assigned |
| `taggedBy` | `String` | Identifier of the user or process that created the assignment |

**Compound Index:** A unique index on `(tenantId, entityId, tagId, entityType)` prevents duplicate tag assignments for the same entity within a tenant.

## Usage Example

```java
TagAssignment assignment = TagAssignment.builder()
    .tenantId("tenant-123")
    .entityId("device-456")
    .tagId("tag-789")
    .entityType(TagEntityType.DEVICE)
    .values(List.of("site1", "site2"))
    .taggedAt(Instant.now())
    .taggedBy("user-abc")
    .build();

// Simple label tag (no values)
TagAssignment labelAssignment = TagAssignment.builder()
    .tenantId("tenant-123")
    .entityId("device-456")
    .tagId("tag-critical")
    .entityType(TagEntityType.DEVICE)
    .values(List.of())
    .taggedAt(Instant.now())
    .taggedBy("user-abc")
    .build();
```

## Notes

- `values` supports both **key-value tags** (e.g., `site → ["site1"]`) and **simple label tags** (empty list).
- The unique compound index enforces that each `(tenant, entity, tag, entityType)` combination can only have one assignment — use an update operation to modify `values` rather than creating duplicates.
