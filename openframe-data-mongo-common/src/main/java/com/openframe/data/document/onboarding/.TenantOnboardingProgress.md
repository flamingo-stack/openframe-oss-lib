MongoDB document entity tracking the "Initial Setup" onboarding progress for a tenant, ensuring exactly one record exists per tenant and serving as the definitive onboarded marker.

## Key Components

| Member | Type | Description |
|---|---|---|
| `id` | `String` | MongoDB document identifier (`@Id`) |
| `tenantId` | `String` | Unique indexed field enforcing one record per tenant |
| `completedSteps` | `Set<TenantOnboardingStep>` | Ordered set of explicitly completed steps; add-only, idempotent |
| `completed` | `boolean` | Definitive "onboarded" flag; set only via explicit "Complete" action |
| `completedAt` | `Instant` | Timestamp when `completed` was set; `null` until completion |

**Implements:** `TenantScoped` — enforces tenant ownership at the domain level.

**Collection:** `tenant_onboarding_progress`

## Key Behaviors

- **Single record per tenant** — `tenantId` carries a unique MongoDB index.
- **No inference at read time** — `completedSteps` is the sole source of truth; nothing is derived.
- **Non-skippable flow** — `completed` is only set by an explicit "Complete" action, never inferred from step completion.

## Usage Example

```java
// Create a new onboarding progress record for a tenant
TenantOnboardingProgress progress = TenantOnboardingProgress.builder()
    .tenantId("tenant-abc-123")
    .build();

// Mark a step as completed (idempotent)
progress.getCompletedSteps().add(TenantOnboardingStep.CONNECT_PSA);

// Finalize onboarding explicitly
progress.setCompleted(true);
progress.setCompletedAt(Instant.now());
```
