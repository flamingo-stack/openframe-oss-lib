MongoDB document entity representing an external application event scoped to a tenant, stored in the `external_application_events` collection.

## Key Components

| Component | Description |
|---|---|
| `ExternalApplicationEvent` | Main document class implementing `TenantScoped` for multi-tenant isolation |
| `EventMetadata` | Nested static class holding event origin info: `source`, `version`, and arbitrary `tags` |
| `tenantId` | Indexed field enabling efficient tenant-based queries |
| `type` | Categorizes the event (e.g., webhook type, integration event name) |
| `payload` | Raw event payload string |
| `timestamp` | `Instant` recording when the event occurred |
| `userId` | Associates the event with a specific user |

## Usage Example

```java
// Constructing and persisting an ExternalApplicationEvent
ExternalApplicationEvent event = new ExternalApplicationEvent();
event.setTenantId("tenant-abc");
event.setType("ticket.created");
event.setPayload("{\"ticketId\": \"T-001\"}");
event.setTimestamp(Instant.now());
event.setUserId("user-xyz");

ExternalApplicationEvent.EventMetadata metadata = new ExternalApplicationEvent.EventMetadata();
metadata.setSource("connectwise");
metadata.setVersion("1.0");
metadata.setTags(Map.of("env", "production", "region", "us-east"));
event.setMetadata(metadata);

mongoTemplate.save(event);
```

## Notes

- Lombok `@Data` generates getters, setters, `equals`, `hashCode`, and `toString` for both classes.
- The `tenantId` index ensures queries scoped to a tenant remain performant at scale.
