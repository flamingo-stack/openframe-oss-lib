Defines the lifecycle states for a single RMM script execution, representing each possible outcome in the execution history.

## Key Components

| Value | Description |
|---|---|
| `RUNNING` | Initial state set immediately after persist; server has dispatched the script over NATS and is awaiting the agent's result frame |
| `SUCCESS` | Terminal state when the agent reports `exitCode == 0` with no timeout or error |
| `FAILED` | Terminal state for any failure condition: non-zero exit code, timeout, agent error, or watchdog-detected stuck execution |

## Usage Example

```java
ScriptExecution execution = repository.findById(executionId);

switch (execution.getStatus()) {
    case RUNNING:
        // Still awaiting agent response via NATS
        break;
    case SUCCESS:
        // Process successful output
        break;
    case FAILED:
        // Handle failure, notify technician
        break;
}
```

> **Note:** Transitions from `RUNNING` to `FAILED` can be triggered by either the agent itself or the management scheduler's watchdog, which detects stuck executions that never produce a result frame.
