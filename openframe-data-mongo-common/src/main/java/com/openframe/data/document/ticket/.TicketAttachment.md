MongoDB document model for file attachment metadata linked to a support ticket. Files are stored externally (S3/MinIO), while this document persists the associated metadata in the `ticket_attachments` collection.

## Key Components

| Field | Type | Description |
|---|---|---|
| `id` | `String` | MongoDB document ID (`@Id`) |
| `tenantId` | `String` | Indexed tenant identifier (implements `TenantScoped`) |
| `ticketId` | `String` | Indexed reference to the parent ticket |
| `fileName` | `String` | Original file name |
| `contentType` | `String` | MIME type of the file |
| `fileSize` | `Long` | File size in bytes |
| `storagePath` | `String` | External storage key (S3 object key or MinIO path) |
| `uploadedAt` | `Instant` | Auto-populated upload timestamp (`@CreatedDate`) |
| `uploadedBy` | `String` | Identifier of the user who uploaded the file |

## Usage Example

```java
TicketAttachment attachment = TicketAttachment.builder()
    .tenantId("tenant-abc")
    .ticketId("ticket-123")
    .fileName("screenshot.png")
    .contentType("image/png")
    .fileSize(204800L)
    .storagePath("tenants/tenant-abc/tickets/ticket-123/screenshot.png")
    .uploadedBy("user-456")
    .build();

ticketAttachmentRepository.save(attachment);
```

> **Note:** `storagePath` is a reference key only — actual file retrieval requires a separate call to your S3/MinIO client using this path.
