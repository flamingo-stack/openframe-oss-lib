Represents a multi-tenant authorization server user document stored in MongoDB, extending the base `User` model with authentication-specific fields such as password hashing, OAuth provider info, and login tracking.

## Key Components

| Member | Type | Description |
|---|---|---|
| `passwordHash` | `String` | Hashed password for local authentication |
| `loginProvider` | `String` | Auth provider identifier (e.g., `LOCAL`, `GOOGLE`) |
| `externalUserId` | `String` | User ID from an external OAuth/SSO provider |
| `lastLogin` | `Instant` | Timestamp of the most recent login |
| `imageUrl` | `String` | Cached profile picture URL; `null` if no picture is known yet |
| `getFullName()` | `String` | Returns best-available display name, falling back to email |

A compound MongoDB index on `{tenantId, email}` enforces unique users per tenant.

## Usage Example

```java
// Build a local auth user
AuthUser authUser = AuthUser.builder()
    .email("jane@example.com")
    .firstName("Jane")
    .lastName("Doe")
    .tenantId("tenant-123")
    .passwordHash(hashService.hash("secret"))
    .loginProvider("LOCAL")
    .lastLogin(Instant.now())
    .build();

// Build an SSO-provisioned user
AuthUser ssoUser = AuthUser.builder()
    .email("jane@example.com")
    .tenantId("tenant-123")
    .loginProvider("GOOGLE")
    .externalUserId("google-uid-456")
    .imageUrl("https://lh3.googleusercontent.com/photo.jpg")
    .build();

// Resolve display name safely
String displayName = authUser.getFullName(); // "Jane Doe"
```

> **Note:** `imageUrl` is used by the auth server to decide whether to push an SSO `picture` claim downstream on subsequent logins. Set this field when the avatar is first persisted (registration, SSO auto-provision, or invitation).
