Defines the ordered steps of the tenant-wide "Initial Setup" onboarding flow, used to track progress through MSP configuration.

## Key Components

| Constant | Description |
|---|---|
| `MSP_SETUP` | Initial MSP configuration step |
| `CUSTOMERS_SETUP` | Customer account setup step |
| `DEVICE_MANAGEMENT` | Device management configuration step |
| `COMPANY_TEAM` | Company and team setup step |

## Usage Example

```java
// Check if a specific onboarding step is complete
TenantOnboardingProgress progress = progressRepository.findByTenantId(tenantId);

if (progress.getCompletedSteps().contains(TenantOnboardingStep.MSP_SETUP)) {
    // Proceed to CUSTOMERS_SETUP
    progress.markComplete(TenantOnboardingStep.CUSTOMERS_SETUP);
}

// Iterate over all required steps in order
for (TenantOnboardingStep step : TenantOnboardingStep.values()) {
    System.out.println("Step: " + step);
}
```

> **Note:** Step ordering mirrors the Figma design. Each tenant has a single [`TenantOnboardingProgress`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/data/document/onboarding/TenantOnboardingProgress.java) record that tracks which of these steps have been completed.
