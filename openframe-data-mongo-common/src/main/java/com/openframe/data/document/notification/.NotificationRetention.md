Defines shared retention constants for the notifications domain, providing a centralized TTL value for MongoDB index configuration.

## Key Components

- **`HISTORY_TTL_SECONDS`** — `int` constant (`2,592,000`) representing a 30-day TTL in seconds, used as the `expireAfterSeconds` value on the MongoDB TTL index applied to the `createdAt` field of notification history and read-state documents.

## Usage Example

```java
// Applied when defining a MongoDB TTL index on the notifications collection
@Document(collection = "notifications")
public class NotificationDocument {

    @Indexed(expireAfterSeconds = NotificationRetention.HISTORY_TTL_SECONDS)
    private Instant createdAt;
}
```

## Notes

- This is a **non-instantiable utility class** (private constructor, `final` class) — import the constant statically where needed.
- Centralizing the TTL here ensures all notification-related collections (history, read-states) share a consistent expiry policy without duplicating the magic number.
