Defines the contract for describing a notification type, binding a string type identifier to its context class and category metadata.

## Key Components

| Member | Description |
|--------|-------------|
| `type()` | Returns the unique string identifier for the notification type |
| `contextClass()` | Returns the `Class` of the associated `NotificationContext` implementation |
| `graphqlTypeName()` | Derives the GraphQL type name from the context class simple name (default implementation) |
| `category()` | Returns the static `NotificationCategory` for this descriptor; defaults to `GENERIC` |
| `category(NotificationContext)` | Context-aware category resolution; delegates to `category()` by default, intended for descriptors whose category varies per notification instance |

## Usage Example

```java
public enum MyNotificationDescriptor implements NotificationContextDescriptor {

    TICKET_ASSIGNED {
        @Override
        public String type() {
            return "TICKET_ASSIGNED";
        }

        @Override
        public Class<? extends NotificationContext> contextClass() {
            return TicketAssignedContext.class;
        }

        @Override
        public NotificationCategory category() {
            return NotificationCategory.TICKET;
        }
    },

    APPROVAL_REQUESTED {
        @Override
        public String type() {
            return "APPROVAL_REQUESTED";
        }

        @Override
        public Class<? extends NotificationContext> contextClass() {
            return ApprovalRequestedContext.class;
        }

        // Dynamic category based on the notification's context at runtime
        @Override
        public NotificationCategory category(NotificationContext context) {
            ApprovalRequestedContext ctx = (ApprovalRequestedContext) context;
            return ctx.hasLinkedTicket()
                ? NotificationCategory.TICKET
                : NotificationCategory.GENERIC;
        }
    }
}
```

Override `category(NotificationContext)` instead of `category()` when the notification category depends on runtime data within the context instance.
