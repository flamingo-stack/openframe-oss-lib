MongoDB document entity representing a managed device within a tenant's infrastructure, storing hardware identity, OS info, operational status, and health metrics.

## Key Components

| Member | Type | Description |
|---|---|---|
| `id` | `String` | MongoDB document identifier (`@Id`) |
| `tenantId` | `String` | Indexed tenant scope for multi-tenancy isolation |
| `machineId` | `String` | Foreign reference to the associated `Machine` entity |
| `serialNumber` | `String` | Physical hardware serial number |
| `model` | `String` | Device model name/identifier |
| `osVersion` | `String` | Installed operating system version |
| `status` | `String` | Operational state: `ACTIVE`, `OFFLINE`, or `MAINTENANCE` |
| `type` | `DeviceType` | Device category enum (e.g., `DESKTOP`, `LAPTOP`, `SERVER`) |
| `lastCheckin` | `Instant` | Timestamp of the most recent agent check-in |
| `configuration` | `DeviceConfiguration` | Embedded configuration details |
| `health` | `DeviceHealth` | Embedded health metrics and diagnostics |

Implements `TenantScoped` to enforce multi-tenant data boundaries at the repository layer.

## Usage Example

```java
Device device = new Device();
device.setTenantId("tenant-abc");
device.setMachineId("machine-001");
device.setSerialNumber("SN-XYZ-9876");
device.setModel("Dell OptiPlex 7090");
device.setOsVersion("Windows 11 Pro 22H2");
device.setStatus("ACTIVE");
device.setType(DeviceType.DESKTOP);
device.setLastCheckin(Instant.now());
device.setConfiguration(new DeviceConfiguration());
device.setHealth(new DeviceHealth());

deviceRepository.save(device);
```

## Notes

- Stored in the `devices` MongoDB collection
- `tenantId` is indexed for efficient tenant-scoped queries
- `@Data` (Lombok) auto-generates getters, setters, `equals`, `hashCode`, and `toString`
