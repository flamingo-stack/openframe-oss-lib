MongoDB document entity representing an OAuth 2.0 registered client, stored in the `oauth_registered_clients` collection with multi-tenant isolation enforced via a compound unique index on `tenantId` and `clientId`.

## Key Components

| Member | Type | Description |
|---|---|---|
| `id` | `String` | MongoDB document `_id` |
| `tenantId` | `String` | Tenant identifier (from `TenantScoped`) |
| `clientId` | `String` | OAuth 2.0 client identifier |
| `clientSecret` | `String` | Hashed client secret |
| `authenticationMethods` | `Set<String>` | Allowed client authentication methods (e.g. `client_secret_basic`) |
| `grantTypes` | `Set<String>` | Supported OAuth grant types (e.g. `authorization_code`, `refresh_token`) |
| `redirectUris` | `Set<String>` | Allowed redirect URIs post-authorization |
| `scopes` | `Set<String>` | Permitted OAuth scopes |
| `requireProofKey` | `boolean` | Enforces PKCE on authorization requests |
| `requireAuthorizationConsent` | `boolean` | Prompts user consent screen |
| `accessTokenTtlSeconds` | `long` | Access token lifetime in seconds |
| `refreshTokenTtlSeconds` | `long` | Refresh token lifetime in seconds |
| `reuseRefreshTokens` | `boolean` | Whether refresh tokens are single-use or reusable |

## Usage Example

```java
MongoRegisteredClient client = MongoRegisteredClient.builder()
    .tenantId("tenant-abc")
    .clientId("my-app")
    .clientSecret("{bcrypt}$2a$10$...")
    .authenticationMethods(Set.of("client_secret_basic"))
    .grantTypes(Set.of("authorization_code", "refresh_token"))
    .redirectUris(Set.of("https://myapp.example.com/callback"))
    .scopes(Set.of("openid", "profile"))
    .requireProofKey(true)
    .requireAuthorizationConsent(false)
    .accessTokenTtlSeconds(3600)
    .refreshTokenTtlSeconds(86400)
    .reuseRefreshTokens(false)
    .build();
```
