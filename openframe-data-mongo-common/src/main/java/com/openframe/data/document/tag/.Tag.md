MongoDB document entity for storing tenant-scoped tag definitions, supporting configurable metadata like allowed values, color, and entity type classification.

## Key Components

| Component | Type | Description |
|---|---|---|
| `Tag` | `@Document` entity | Maps to the `tags` MongoDB collection |
| `TenantScoped` | Interface | Enforces multi-tenancy via `tenantId` field |
| `key` | `String` | Tag identifier (e.g., `"site"`, `"org_type"`), unique per tenant + entity type |
| `values` | `List<String>` | Optional predefined allowed values; `null` = free-text, non-empty = dropdown |
| `entityType` | `TagEntityType` | Classifies which entity this tag applies to |
| `tenant_key_entity_idx` | Compound index | Enforces uniqueness on `(tenantId, key, entityType)` |

## Usage Example

```java
Tag tag = Tag.builder()
    .tenantId("tenant-001")
    .key("site")
    .description("Office location tag")
    .color("#FF5733")
    .values(List.of("CHICAGO", "NEW_YORK", "AUSTIN"))
    .entityType(TagEntityType.DEVICE)
    .createdAt(Instant.now())
    .createdBy("admin-user-id")
    .build();
```

**`values` field behavior:**

| State | UI Behavior |
|---|---|
| `null` | Simple label / free-text input |
| `[]` (empty list) | Values explicitly cleared |
| `["A", "B"]` | Renders as dropdown or checkboxes |

## Notes

- The compound index `(tenantId, key, entityType)` prevents duplicate tag keys within the same entity type per tenant.
- Lombok annotations (`@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor`) handle boilerplate generation.
- `color` is optional and intended for UI display purposes.
