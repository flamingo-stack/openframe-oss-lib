An enum defining the entity types that can be tagged within the OpenFrame platform.

## Key Components

| Value | Description |
|---|---|
| `DEVICE` | Tags applied to device records |
| `TICKET` | Tags applied to support tickets |
| `KNOWLEDGE_ARTICLE` | Tags applied to knowledge base articles |
| `SCRIPT` | Tags applied to automation scripts |

## Usage Example

```java
TagEntity tag = new TagEntity();
tag.setEntityType(TagEntityType.TICKET);
tag.setEntityId(ticketId);
tag.setLabel("urgent");
```

## Notes

- Used to scope tags to specific entity domains, preventing cross-entity collisions
- Typically paired with an entity ID to form a composite tag target
