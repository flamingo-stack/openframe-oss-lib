An enumeration defining the supported tool types within the OpenFrame platform.

## Key Components

- **`MESHCENTRAL`** – Represents the [MeshCentral](https://meshcentral.com) remote management tool integration
- **`FLEET_MDM`** – Represents the [Fleet MDM](https://fleetdm.com) mobile device management tool integration
- **`OPENFRAME_RMM`** – Represents the OpenFrame native RMM tool integration

## Usage Example

```java
ToolType toolType = ToolType.MESHCENTRAL;

switch (toolType) {
    case MESHCENTRAL -> System.out.println("Using MeshCentral RMM");
    case FLEET_MDM -> System.out.println("Using Fleet MDM");
    case OPENFRAME_RMM -> System.out.println("Using OpenFrame RMM");
}
```

## Notes

- Used to distinguish between integrated MSP tooling backends within the OpenFrame platform
- New tool integrations should be added here to ensure type-safe references across the codebase
