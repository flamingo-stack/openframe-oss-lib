MongoDB document entity representing a tenant-scoped event record, storing event type, payload, timestamp, and user association for multi-tenant event tracking.

## Key Components

| Member | Type | Description |
|---|---|---|
| `id` | `String` | MongoDB document identifier (`@Id`) |
| `tenantId` | `String` | Indexed tenant identifier for multi-tenant isolation |
| `type` | `String` | Event type classifier |
| `payload` | `String` | Serialized event data/body |
| `timestamp` | `Instant` | UTC timestamp of when the event occurred |
| `userId` | `String` | Identifier of the user who triggered the event |

## Usage Example

```java
// Create a new Event document
Event event = Event.builder()
    .tenantId("tenant-123")
    .type("USER_LOGIN")
    .payload("{\"ip\":\"192.168.1.1\"}")
    .timestamp(Instant.now())
    .userId("user-456")
    .build();

// Persist via repository
eventRepository.save(event);

// Query by tenantId (leverages @Indexed for performance)
List<Event> tenantEvents = eventRepository.findByTenantId("tenant-123");
```

## Notes

- Implements [`TenantScoped`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/data/document/TenantScoped.java) to enforce multi-tenant data isolation patterns
- `tenantId` carries a MongoDB index (`@Indexed`) for efficient tenant-based queries at scale
- Lombok `@Data` and `@Builder` reduce boilerplate; all fields are accessed via generated getters/setters
- `payload` is stored as a raw `String` — callers are responsible for serialization/deserialization
