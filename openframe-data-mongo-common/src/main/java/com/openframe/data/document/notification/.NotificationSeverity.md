Enum defining the severity levels for notifications within the OpenFrame notification system.

## Key Components

| Value | Description |
|-------|-------------|
| `INFO` | Informational, neutral notifications |
| `SUCCESS` | Positive outcome or confirmation notifications |
| `WARNING` | Cautionary notifications requiring attention |
| `DANGER` | Critical notifications indicating errors or failures |

## Usage Example

```java
NotificationSeverity severity = NotificationSeverity.WARNING;

if (severity == NotificationSeverity.DANGER) {
    // handle critical alert
}
```
