Composed annotation that marks Spring Data repository interfaces as tenant-scoped, combining `@Repository` registration with a filter marker for shared-service exclusion.

## Key Components

| Element | Description |
|---|---|
| `@TenantAwareRepository` | Meta-annotation applied at the type level (`ElementType.TYPE`) with runtime retention |
| `@Repository` | Included via composition — registers the interface as a Spring-managed component |
| Exclusion marker | Acts as a `FilterType.ANNOTATION` target so shared-service contexts can exclude these repositories |

## Usage Example

**Annotate a tenant-scoped repository:**

```java
@TenantAwareRepository
public interface DeviceRepository extends MongoRepository<Device, String> {
    List<Device> findByTenantId(String tenantId);
}
```

**Exclude from shared-service `MongoRepositories` scan:**

```java
@EnableMongoRepositories(
    basePackages = "com.openframe.data.repository",
    excludeFilters = @ComponentScan.Filter(
        type = FilterType.ANNOTATION,
        classes = TenantAwareRepository.class
    )
)
public class SharedServiceMongoConfig { }
```

**Tenant-context config (where these repositories ARE loaded):**

```java
// tenant-isolation.enabled=true
@EnableMongoRepositories(basePackages = "com.openframe.data.repository")
public class TenantMongoConfig { }
```

## Notes

- Repositories annotated with `@TenantAwareRepository` are **only valid** when `TenantAwareMongoTemplate` is available (i.e., `tenant-isolation.enabled=true`).
- Loading these repositories in a shared-service context without the exclusion filter will cause startup failures due to the missing `TenantAwareMongoTemplate` bean.
- See [`TenantAwareMongoTemplate`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/data/repository/TenantAwareMongoTemplate.java) for the underlying template dependency.
