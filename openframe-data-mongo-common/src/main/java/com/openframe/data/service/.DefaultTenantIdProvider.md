Default fallback implementation of `TenantIdProvider` that resolves the tenant ID from the `TENANT_ID` environment variable, defaulting to `"oss"` when not set.

## Key Components

| Element | Description |
|---|---|
| `DefaultTenantIdProvider` | Spring `@Service` implementing `TenantIdProvider` |
| `@ConditionalOnMissingBean` | Auto-configures only when no other `TenantIdProvider` bean is present |
| `TENANT_ID` env var | Configures the active tenant; falls back to `"oss"` |
| `getTenantId()` | Returns the resolved tenant ID string |

## Usage Example

```java
// Auto-registered by Spring when no custom TenantIdProvider bean exists.
// Override by defining your own bean:
@Service
public class MyTenantIdProvider implements TenantIdProvider {
    @Override
    public String getTenantId() {
        return "my-tenant";
    }
}

// Or configure via environment variable:
// TENANT_ID=acme-corp → getTenantId() returns "acme-corp"
// (unset)             → getTenantId() returns "oss"
```

## Notes

- This bean is skipped automatically if any other `TenantIdProvider` implementation is registered — no exclusion config needed.
- The `"oss"` default aligns with the OpenFrame OSS single-tenant deployment model.
- For multi-tenant deployments, provide a custom `TenantIdProvider` that resolves the tenant from request context (e.g., JWT claims, subdomain, or HTTP header).
