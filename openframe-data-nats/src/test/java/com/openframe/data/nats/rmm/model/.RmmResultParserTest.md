Unit test suite for `RmmResultParser`, verifying JSON deserialization of RMM agent payloads (snake_case wire format) into Java message types within the OpenFrame NATS pipeline.

## Key Components

| Test Method | What It Validates |
|---|---|
| `parse_commandResultMessage` | Full snake_case payload deserializes correctly into `CommandResultMessage` with all camelCase fields mapped |
| `parse_scriptResultMessage_sameWireSameFields` | Same wire format routes to `ScriptResultMessage` when that target type is requested |
| `parse_ignoresUnknownFields` | Unknown JSON fields are silently ignored for forward-compatible agent evolution |
| `parse_malformedThrows` | Malformed JSON propagates `IOException` so NATS dispatchers can handle errors without crashing |

## Usage Example

```java
// Production usage mirrored by the tests
RmmResultParser parser = new RmmResultParser(new ObjectMapper());

// Deserialize a NATS message payload from a remote agent
byte[] rawPayload = natsMessage.getData();

// Route to the appropriate result type
CommandResultMessage result = parser.parse(rawPayload, CommandResultMessage.class);
System.out.println(result.getExecutionId());   // "exec-1"
System.out.println(result.getExitCode());      // 0
System.out.println(result.getTimedOut());      // false

// Same parser, different target type
ScriptResultMessage scriptResult = parser.parse(rawPayload, ScriptResultMessage.class);
```

## Notes

- Tests confirm snake_case → camelCase mapping (e.g., `execution_id` → `getExecutionId()`)
- `@DeserializationFeature.FAIL_ON_UNKNOWN_PROPERTIES` must be disabled — validated by `parse_ignoresUnknownFields`
- Error handling strategy: callers (NATS listeners) are responsible for catching `IOException` to keep the dispatcher alive
