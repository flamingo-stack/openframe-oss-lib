Unit tests for `ScriptArgsTokenizer`, validating shell-style argument tokenization behavior including quoting, whitespace handling, null/blank inputs, Windows path preservation, and non-idempotency semantics.

## Key Components

| Test Method | What It Covers |
|---|---|
| `nullPassthrough` | `null` input returns `null` (no-args passthrough) |
| `emptyList` | Empty list returns empty list |
| `multipleEntriesFlattenedInOrder` | Multiple entries tokenized and flattened, order preserved |
| `mixedEntries` | Bare tokens, named args, and quoted values in one call |
| `nullAndBlankElementsDropped` | `null`, blank, and whitespace-only elements are silently skipped |
| `largeAlreadyTokenizedListUnchanged` | Space-free tokens pass through 1:1 unchanged |
| `singleElementTokenization` | Parameterized suite covering 20+ edge cases (see below) |
| `emptyQuotesYieldEmptyToken` | `""` produces a single empty-string token |
| `emptyQuotedValueBetweenArgs` | Empty quoted value between real args is preserved |
| `loneQuoteYieldsEmptyToken` | Unmatched lone quote yields one empty-string token |
| `notIdempotentForSpacedValues` | Documents that tokenization is **not** idempotent — apply exactly once |

### Parameterized Edge Cases (`singleElementCases`)

Covers: space-splitting, tab/newline splitting, double-quote grouping, single-quote grouping, adjacent-quote token joining, cross-quote literal preservation, Windows backslash paths (`C:\Temp`), unterminated quotes, and inner quoted spans.

## Usage Example

```java
// Typical dispatch-time usage — apply tokenize exactly once
List<String> rawArgs = List.of("-Bucket 'my value'", "-Flag", null, "  ");
List<String> argv = ScriptArgsTokenizer.tokenize(rawArgs);
// → ["-Bucket", "my value", "-Flag"]

// Windows path survives unchanged (backslash is NOT a POSIX escape)
List<String> paths = ScriptArgsTokenizer.tokenize(List.of("-Path=C:\\Program Files\\App"));
// → ["-Path=C:\\Program Files\\App"]  — wait, actually use quotes for spaces:
List<String> paths2 = ScriptArgsTokenizer.tokenize(List.of("-Path \"C:\\Program Files\\App\""));
// → ["-Path", "C:\\Program Files\\App"]
```

> **Important:** Tokenization is **not idempotent**. Quotes are stripped on the first pass, so applying it a second time will re-split bare spaced values. Always tokenize at the dispatch boundary, never recursively.
