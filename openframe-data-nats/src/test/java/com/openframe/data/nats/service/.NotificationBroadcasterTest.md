Test suite for `NotificationBroadcaster`, verifying notification persistence, read-state creation, NATS publishing fan-out, and error/cleanup behavior across all audience routing paths.

## Key Components

| Test Method | What It Covers |
|---|---|
| `admin_only_command_fans_out_to_admin_path` | Admin-only audience creates `USER` read states and calls `publishToUser` per admin; no machine-side calls |
| `machine_only_command_fans_out_to_machine_path` | Machine-only audience creates `MACHINE` read states and calls `publishToMachine`; channel dispatcher never invoked |
| `mixed_audience_fans_out_to_both_paths` | Mixed audiences trigger two `createForAudience` calls (one per `RecipientType`) and both publish loops |
| `no_publisher_persists_without_nats` | When `NotificationNatsPublisher` is absent (`Optional.empty`), notification is still persisted and read states created |
| `persisted_notification_carries_command_fields` | Fields from `NotificationCommand` (title, description, severity, context) are copied verbatim onto the persisted document |
| `broadcast_returns_persisted_notification` | Returned `Notification` carries the repository-assigned ID, not a builder-only transient object |
| `category_resolved_from_registry_and_denormalized_into_read_state` | Category is resolved via `NotificationContextDescriptorRegistry` and passed into `createForAudience` for lookup-free aggregation |
| `create_for_audience_failure_triggers_orphan_cleanup_and_skips_nats` | `RuntimeException` from `createForAudience` deletes the persisted document and skips NATS publish to avoid orphaned notifications |

## Usage Example

```java
// Typical test setup pattern used across all cases
NotificationCommand cmd = NotificationCommand.builder()
        .title("Approval required")
        .severity(NotificationSeverity.INFO)
        .context(genericContext("APPROVAL"))
        .adminAudience(Set.of("admin-1", "admin-2"))
        .build();

Notification result = broadcaster.broadcast(cmd);

// Assert persistence
assertThat(result.getId()).isEqualTo("notif-id-1");

// Assert USER read-state fan-out
verify(readStateService).createForAudience(
        eq("notif-id-1"), eq(NotificationCategory.MINGO),
        anyString(), eq(RecipientType.USER), eq(Set.of("admin-1", "admin-2")));

// Assert per-admin NATS publish
verify(natsPublisher).publishToUser(eq("admin-1"), any(Notification.class), eq(NotificationCategory.MINGO));
```
