Integration test suite that verifies `NotificationNatsPublisher` correctly routes `Notification` documents to NATS subjects via the Spring Cloud Stream NATS binder.

## Key Components

| Component | Role |
|---|---|
| `NotificationNatsPublisher` | SUT — publishes notifications to user/machine NATS subjects |
| `BaseIntegrationTest` | Provides `natsUri()` and shared container setup |
| `PublisherIntegrationTestApplication` | Minimal Spring Boot context for publisher beans |
| `Subscription` / `Connection` (NATS client) | Raw NATS subscriber used to assert delivery independently of the binder |

## Test Cases

| Test | What It Proves |
|---|---|
| `publish_to_user_delivers_payload` | Full `NotificationMessage` payload (id, title, severity, category, context) arrives on `user.<userId>.notification` |
| `per_user_subjects_isolated` | Publishing to `bob` delivers nothing to `alice`'s subscription |
| `publish_to_machine_delivers_to_machine_subject` | `publishToMachine` routes exclusively to `machine.<machineId>.notification` |
| `unsaved_notification_throws` | A `Notification` without an id throws `IllegalArgumentException` before any broker call |

## Usage Example

```java
// Only runs when -Dintegration.tests=true is set
// Typical Maven invocation:
// mvn verify -Dintegration.tests=true

@Test
void publish_to_user_delivers_payload() throws Exception {
    Subscription sub = subscriber.subscribe("user.alice.notification");
    subscriber.flush(Duration.ofSeconds(2));

    Notification saved = persisted(Notification.builder()
            .title("Welcome aboard")
            .context(GenericContext.builder().type("welcome").payload("{\"k\":\"v\"}").build()));

    publisher.publishToUser("alice", saved, NotificationCategory.TICKETS);

    Message received = sub.nextMessage(Duration.ofSeconds(5));
    NotificationMessage decoded = objectMapper.readValue(received.getData(), NotificationMessage.class);
    assertThat(decoded.getCategory()).isEqualTo(NotificationCategory.TICKETS);
}
```

> **Activation:** Tests are guarded by `@EnabledIfSystemProperty(named = "integration.tests", matches = "true")` and tagged `integration`. A live NATS server (provided by `BaseIntegrationTest`) is required at runtime.
