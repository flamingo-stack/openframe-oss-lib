Unit tests for `ScriptScheduleExecutionNatsPublisher`, verifying subject routing, transport selection, null-message validation, and error propagation for scheduled script execution dispatches over NATS.

## Key Components

| Component | Role |
|---|---|
| `ScriptScheduleExecutionNatsPublisher` | Subject under test — wraps `NatsMessagePublisher` for schedule-triggered script dispatches |
| `NatsMessagePublisher` (mock) | Mocked NATS transport injected via constructor |
| `ScriptScheduleExecutionMessage` | Batched payload carrying `executionId`, `scheduleId`, `machineId`, and a list of `ScriptScheduleExecutionItem`s |
| `ScriptScheduleExecutionItem` | Per-script descriptor holding `scriptId`, `code`, `ScriptShell`, and `PrivilegeLevel` |

## Test Coverage

| Test | What It Asserts |
|---|---|
| `publish_routesToMachineSubjectWithUnchangedPayload` | Subject resolves to `machine.<machineId>.script-schedule-execution`; payload instance is forwarded verbatim (no repackaging) |
| `publish_usesCoreNatsNotJetStream` | `publish()` is called, `publishPersistent()` is **never** called — schedule fires must not be durable/replayable |
| `publish_rejectsNullMessage` | `null` message throws `IllegalArgumentException` before any broker interaction |
| `publish_propagatesTransportFailure` | `NatsException` from the transport layer bubbles up to the caller unchanged |

## Usage Example

```java
// Typical publisher invocation under test
ScriptScheduleExecutionMessage message = ScriptScheduleExecutionMessage.builder()
        .executionId("exec-1")
        .scheduleId("sched-1")
        .machineId("machine-42")
        .initiatedBy("cron")
        .scripts(List.of(
                ScriptScheduleExecutionItem.builder()
                        .scriptId("s1").code("df -h")
                        .shell(ScriptShell.BASH)
                        .privilegeLevel(PrivilegeLevel.ADMIN)
                        .build()))
        .build();

publisher.publish("machine-42", message);
// Expect subject: "machine.machine-42.script-schedule-execution"
```

## Design Notes

- **Core NATS over JetStream** — the test explicitly locks in `publish()` (not `publishPersistent()`), documenting the intentional decision that scheduled script dispatches are fire-and-forget and must not become durable/replayable without a deliberate design change.
- **Same-instance assertion** — `isSameAs(message)` guards against accidental payload wrapping or copying in the publisher.
