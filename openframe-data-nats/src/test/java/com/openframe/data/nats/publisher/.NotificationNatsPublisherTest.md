Unit test suite for `NotificationNatsPublisher`, verifying subject routing, message payload mapping, input validation, and broker failure handling for NATS-based notification publishing.

## Key Components

| Component | Role |
|---|---|
| `NotificationNatsPublisher` | System under test — wraps `NatsMessagePublisher` to route notifications over NATS |
| `NatsMessagePublisher` | Mocked broker dependency; receives subject + `NotificationMessage` payload |
| `publish_to_user_routes_to_user_subject` | Asserts subject resolves to `user.<userId>.notification` and payload preserves `id`, `title`, and `category` |
| `publish_to_machine_routes_to_machine_subject` | Asserts subject resolves to `machine.<machineId>.notification` |
| `broker_failure_swallowed` | Confirms `NatsException` from broker does not propagate — MongoDB is treated as source of truth |
| `blank_user_id_rejected` | Guards against malformed subjects like `user..notification` from blank `userId` |
| `blank_machine_id_rejected` | Same blank-ID invariant applied to `machineId` |
| `unpersisted_notification_throws_before_broker` | Enforces that callers must persist (call `save()`) before publishing |

## Usage Example

```java
// Arrange
NatsMessagePublisher messagePublisher = mock(NatsMessagePublisher.class);
NotificationNatsPublisher publisher = new NotificationNatsPublisher(messagePublisher);

Notification notification = Notification.builder()
        .id("notif-123")
        .title("Hello")
        .createdAt(Instant.now())
        .context(GenericContext.builder().type("welcome").build())
        .build();

// Act
publisher.publishToUser("user-42", notification, NotificationCategory.TICKETS);

// Assert — subject and payload
ArgumentCaptor<String> subject = ArgumentCaptor.forClass(String.class);
ArgumentCaptor<NotificationMessage> message = ArgumentCaptor.forClass(NotificationMessage.class);
verify(messagePublisher).publish(subject.capture(), message.capture());
assertThat(subject.getValue()).isEqualTo("user.user-42.notification");
assertThat(message.getValue().getId()).isEqualTo("notif-123");
```

## Key Invariants Tested

- **Subject pattern:** `user.<id>.notification` / `machine.<id>.notification`
- **Blank IDs** throw `IllegalArgumentException` *before* any broker call
- **Unpersisted notifications** (no `id`) are rejected at the publisher boundary
- **Broker failures** are swallowed silently — persistence layer is the authoritative store
