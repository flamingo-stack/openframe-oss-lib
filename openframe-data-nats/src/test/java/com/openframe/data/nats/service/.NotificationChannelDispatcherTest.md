Unit test suite for `NotificationChannelDispatcher`, verifying multi-channel delivery, fault tolerance, user mute enforcement, and grace-window read-state suppression of push notifications.

## Key Components

| Test | Behaviour Verified |
|---|---|
| `delivers_to_every_user_on_every_channel` | All registered channels receive a `deliver` call for every recipient |
| `a_throwing_channel_is_swallowed_and_others_still_deliver` | A channel exception is silently swallowed; remaining users still receive delivery |
| `no_channels_is_a_noop_and_skips_the_settings_lookup` | Empty channel list short-circuits execution without touching `NotificationSettingsRepository` |
| `muted_user_is_skipped_and_others_still_deliver` | Users with push disabled in settings are excluded server-side |
| `settings_lookup_failure_defaults_to_delivering_to_everyone` | Settings repository errors default to delivering to all (fail-open) |
| `grace_disabled_never_touches_read_state` | `webGraceSeconds = 0` disables read-state checks entirely |
| `grace_window_skips_recipients_who_already_read` | Users with `READ` status are suppressed; `UNREAD` users and `MACHINE` recipients proceed normally |
| `grace_window_lookup_failure_defaults_to_delivering_to_everyone` | Read-state lookup errors fail-open, ensuring no push is silently dropped |
| `grace_window_keeps_recipients_without_a_read_state_row` | Missing read-state rows are treated as unread (eventual consistency safe) |
| `grace_window_empty_read_state_delivers_to_everyone` | Empty read-state result never suppresses delivery |

## Usage Example

```java
// Construct dispatcher with a grace window of 30 seconds
NotificationChannelDispatcher dispatcher = new NotificationChannelDispatcher(
    List.of(fcmChannel, slackChannel),
    Optional.of(notificationSettingsRepository),
    readStateService
);
ReflectionTestUtils.setField(dispatcher, "webGraceSeconds", 30L);

// Dispatch to a set of user IDs
dispatcher.dispatch(
    Set.of("user-123", "user-456"),
    notification,
    NotificationCategory.MINGO
);
```

## Notes

- **Fail-open by design**: both settings and read-state lookups default to full delivery on error, preventing silent push loss.
- `webGraceSeconds` is injected via `ReflectionTestUtils` to keep configuration out of the constructor while remaining testable.
- `MACHINE` recipient types are never pushed regardless of read status.
