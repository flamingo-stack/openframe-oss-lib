Immutable value object representing a validated notification command to be dispatched via NATS, encapsulating all required routing and content fields for a notification.

## Key Components

| Member | Type | Description |
|---|---|---|
| `title` | `String` | Required non-blank display title of the notification |
| `description` | `String` | Optional free-text body of the notification |
| `severity` | `NotificationSeverity` | Required severity level (e.g. INFO, WARN, ERROR) |
| `context` | `NotificationContext` | Required context object with a non-blank `type` field |
| `correlationId` | `String` | Optional identifier for tracing related events |
| `adminAudience` | `Set<String>` | Set of admin recipient identifiers |
| `machineAudience` | `Set<String>` | Set of machine/device recipient identifiers |
| `sanitizeAudience()` | `private static` | Null-safe helper that copies and validates audience sets, rejecting blank entries |

**Validation rules enforced at construction time:**
- `title` must not be blank
- `severity` and `context` must not be null; `context.type` must not be blank
- At least one of `adminAudience` or `machineAudience` must be non-empty
- Neither audience set may contain blank entries

## Usage Example

```java
NotificationCommand command = NotificationCommand.builder()
    .title("Disk Usage Critical")
    .description("Disk usage has exceeded 90% on host web-01")
    .severity(NotificationSeverity.ERROR)
    .context(NotificationContext.builder()
        .type("DISK_ALERT")
        .build())
    .correlationId("corr-abc-123")
    .adminAudience(Set.of("admin-user-1", "admin-user-2"))
    .machineAudience(Set.of("machine-host-web01"))
    .build();
```

> Construction will throw `IllegalArgumentException` if any validation rule is violated, ensuring only fully valid commands enter the NATS dispatch pipeline.
