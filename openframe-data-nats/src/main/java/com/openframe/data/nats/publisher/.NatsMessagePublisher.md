A Spring service that publishes messages to NATS subjects, supporting both fire-and-forget core NATS publishing and persistent JetStream publishing with delivery acknowledgment.

## Key Components

| Member | Type | Description |
|---|---|---|
| `publish` | `<T> void` | Serializes payload to JSON bytes and publishes to a NATS subject via core NATS (no persistence guarantee) |
| `publishPersistent` | `<T> PublishAck` | Publishes to a NATS JetStream subject and returns a `PublishAck` confirming server-side persistence |
| `objectMapper` | `ObjectMapper` | Jackson serializer injected via constructor for converting payloads to `byte[]` |
| `natsConnection` | `Connection` | Active NATS connection injected via constructor |

The bean is only registered when `spring.cloud.stream.enabled` is `true`. Both methods throw `NatsException` on serialization or transport failure.

## Usage Example

```java
@Service
@RequiredArgsConstructor
public class TicketEventService {

    private final NatsMessagePublisher publisher;

    // Fire-and-forget — no delivery guarantee
    public void notifyTicketCreated(TicketCreatedEvent event) {
        publisher.publish("tickets.created", event);
    }

    // Persistent — JetStream stores message; ack confirms receipt
    public void notifyTicketClosed(TicketClosedEvent event) {
        PublishAck ack = publisher.publishPersistent("tickets.closed", event);
        log.info("Message persisted at sequence {}", ack.getSeqno());
    }
}
```

## Notes

- Enable this bean by setting `spring.cloud.stream.enabled=true` in your application properties.
- Prefer `publishPersistent` for critical events (alerts, billing, state changes) where at-least-once delivery is required.
- See the full library source at [flamingo-stack/openframe-oss-lib](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/data/nats/publisher/NatsMessagePublisher.java).
