NATS wire payload model for dispatching a single saved-script execution to an OpenFrame agent over core NATS on the `machine.{machineId}.script-execution` subject.

## Key Components

| Field | Type | Description |
|---|---|---|
| `executionId` | `String` | Unique identifier for this execution run |
| `scheduleId` | `String` | Optional schedule that triggered the execution |
| `scriptId` | `String` | Reference to the saved script definition |
| `machineId` | `String` | Target machine receiving the script |
| `code` | `String` | Inline script source code to execute |
| `shell` | `ScriptShell` | Shell interpreter (e.g., PowerShell, Bash) |
| `privilegeLevel` | `PrivilegeLevel` | Elevation level for the execution context |
| `args` | `List<String>` | Positional arguments passed to the script |
| `timeoutSeconds` | `Integer` | Maximum allowed execution duration |
| `envVars` | `List<ScriptEnvVar>` | Environment variables injected at runtime |

Null fields are omitted from serialization via `@JsonInclude(NON_NULL)`. The class uses Lombok `@Builder` for fluent construction.

## Usage Example

```java
ScriptMessage message = ScriptMessage.builder()
    .executionId(UUID.randomUUID().toString())
    .machineId("machine-abc123")
    .scriptId("script-xyz789")
    .shell(ScriptShell.POWERSHELL)
    .privilegeLevel(PrivilegeLevel.ADMIN)
    .code("Get-Process | Select-Object Name, CPU")
    .timeoutSeconds(60)
    .args(List.of("--verbose"))
    .envVars(List.of(new ScriptEnvVar("ENV", "production")))
    .build();

// Publish over NATS
String subject = "machine." + message.getMachineId() + ".script-execution";
natsConnection.publish(subject, objectMapper.writeValueAsBytes(message));
```
