A NATS message model representing a notification event payload, used to transport notification data across services via the NATS messaging system.

## Key Components

| Field | Type | Description |
|---|---|---|
| `id` | `String` | Unique identifier for the notification |
| `severity` | `NotificationSeverity` | Severity level of the notification |
| `title` | `String` | Short display title |
| `description` | `String` | Detailed notification message |
| `createdAt` | `Instant` | Timestamp of notification creation |
| `category` | `NotificationCategory` | Classification category |
| `context` | `NotificationContext` | Contextual metadata for the notification |
| `eventType` | `NotificationEventType` | NATS event type (e.g., create, update, delete) |

Lombok annotations (`@Builder`, `@Getter`, `@Setter`, `@NoArgsConstructor`, `@AllArgsConstructor`) generate boilerplate, making this a clean immutable-friendly DTO.

## Usage Example

```java
NotificationMessage message = NotificationMessage.builder()
    .id("notif-001")
    .severity(NotificationSeverity.HIGH)
    .title("Disk Usage Critical")
    .description("Disk usage on server-01 has exceeded 90%.")
    .createdAt(Instant.now())
    .category(NotificationCategory.INFRASTRUCTURE)
    .context(notificationContext)
    .eventType(NotificationEventType.CREATED)
    .build();
```
