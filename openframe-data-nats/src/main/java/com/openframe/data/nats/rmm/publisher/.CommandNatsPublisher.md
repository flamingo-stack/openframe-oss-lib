A Spring component that publishes RMM ad-hoc command and cancellation messages to target agents over NATS, routing each message to a machine-scoped subject.

## Key Components

| Member | Description |
|---|---|
| `MACHINE_SUBJECT_TEMPLATE` | NATS subject pattern `machine.<machineId>.command-execution` |
| `CANCEL_SUBJECT_TEMPLATE` | NATS subject pattern `machine.<machineId>.command-cancel` |
| `publishCommand(machineId, CommandMessage)` | Validates and publishes a command-execution message to the target agent |
| `publishCancel(machineId, CancelMessage)` | Validates and publishes a cancellation request for an in-flight execution |

**Activation:** Bean is only registered when `spring.cloud.stream.enabled` is `true`.

**Validation:** Both methods guard against null messages and blank `executionId` fields, throwing `IllegalArgumentException` before any NATS I/O occurs. The `machineId` token is expected to be subject-safe — enforced upstream via `@Pattern` on the GraphQL input.

## Usage Example

```java
// Publish a new command to a remote agent
CommandMessage cmd = CommandMessage.builder()
        .executionId("exec-001")
        .script("Get-Service | Where-Object { $_.Status -eq 'Running' }")
        .build();

commandNatsPublisher.publishCommand("machine-abc123", cmd);
// → publishes to: machine.machine-abc123.command-execution

// Cancel an in-flight execution
CancelMessage cancel = CancelMessage.builder()
        .executionId("exec-001")
        .build();

commandNatsPublisher.publishCancel("machine-abc123", cancel);
// → publishes to: machine.machine-abc123.command-cancel
```
