Represents the wire payload sent over NATS to abort an in-flight execution on the OpenFrame agent. Contains a single `executionId` field identifying the execution to cancel, with null fields excluded from JSON serialization.

## Key Components

| Component | Description |
|---|---|
| `executionId` | Unique identifier of the in-flight execution to abort |
| `@JsonInclude(NON_NULL)` | Omits null fields from the serialized NATS payload |
| `@Builder` | Enables fluent construction via `CancelMessage.builder()` |

## Usage Example

```java
// Build and publish a cancel message over NATS
CancelMessage cancelMessage = CancelMessage.builder()
    .executionId("exec-abc-123")
    .build();

String json = objectMapper.writeValueAsString(cancelMessage);
natsConnection.publish("openframe.agent.cancel", json.getBytes());
```

```java
// Deserialize an incoming cancel payload
CancelMessage message = objectMapper.readValue(rawPayload, CancelMessage.class);
executionService.abort(message.getExecutionId());
```

## Notes

- Null `executionId` values are excluded from the JSON output, keeping the NATS payload compact.
- Part of the `com.openframe.data.nats.rmm.model` package — see related models in [`openframe-oss-lib`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/data/nats/rmm/model/).
