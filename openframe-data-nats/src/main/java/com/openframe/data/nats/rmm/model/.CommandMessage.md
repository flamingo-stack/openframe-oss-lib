Wire payload model for dispatching a single ad-hoc command to an OpenFrame agent via NATS on the `machine.{machineId}.command-execution` subject.

## Key Components

| Field | Type | Description |
|---|---|---|
| `executionId` | `String` | Unique identifier for the command execution (ULID recommended) |
| `code` | `String` | The command/script body to execute |
| `shell` | `ScriptShell` | Target shell interpreter (e.g., `BASH`, `POWERSHELL`) |
| `privilegeLevel` | `PrivilegeLevel` | Execution privilege context (e.g., `ADMIN`, `USER`) |
| `timeout` | `Integer` | Maximum execution time in seconds; `null` omitted from wire payload |

**Lombok annotations:** `@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor` — provides getters/setters, builder pattern, and both constructors.

**`@JsonInclude(NON_NULL)`** — `null` fields are omitted from the serialized JSON payload.

## Usage Example

```java
CommandMessage message = CommandMessage.builder()
    .executionId("01HXYZ...")
    .code("echo hello")
    .shell(ScriptShell.BASH)
    .privilegeLevel(PrivilegeLevel.ADMIN)
    .timeout(30)
    .build();

// Publish to agent via NATS
String subject = "machine." + machineId + ".command-execution";
natsConnection.publish(subject, objectMapper.writeValueAsBytes(message));
```

## Notes

- `null` fields (e.g., omitting `timeout`) are excluded from the serialized payload automatically.
- `ScriptShell` and `PrivilegeLevel` are defined in `com.openframe.data.document.rmm`.
