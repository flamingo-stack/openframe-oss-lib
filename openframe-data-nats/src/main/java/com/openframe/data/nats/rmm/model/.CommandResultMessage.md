Represents the wire payload for an ad-hoc command execution result, published on the NATS subject `machine.{machineId}.command-execution.result`.

## Key Components

- **`CommandResultMessage`** — Final class extending [`RmmResultMessage`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/data/nats/rmm/model/RmmResultMessage.java), inheriting all fields and behavior. The distinct Java type (rather than an in-payload discriminator field) allows the result service to route messages to `MessageType.COMMAND_EXECUTED` downstream.

**Lombok annotations:**
- `@Data` — Generates getters, setters, `toString`, and `equals`/`hashCode`
- `@EqualsAndHashCode(callSuper = true)` — Includes parent class fields in equality checks
- `@SuperBuilder` — Enables builder pattern with inherited fields
- `@NoArgsConstructor` — Generates a no-argument constructor for deserialization

## Usage Example

```java
// Build a command result message after execution
CommandResultMessage result = CommandResultMessage.builder()
    .machineId("machine-abc-123")
    .success(true)
    .output("Disk cleanup completed successfully")
    .build();

// Publish to NATS subject
String subject = "machine." + result.getMachineId() + ".command-execution.result";
natsConnection.publish(subject, serialize(result));
```

## Notes

- This class carries no additional fields beyond those defined in `RmmResultMessage`; the type distinction alone drives downstream routing logic, keeping the wire format clean and discriminator-free.
- See the full model hierarchy at [`com.openframe.data.nats.rmm.model`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/data/nats/rmm/model).
