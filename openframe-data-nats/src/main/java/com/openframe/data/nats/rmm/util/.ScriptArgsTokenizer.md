Utility class that tokenizes user-supplied script argument strings into individual `argv`-style tokens before they are transmitted to the remote agent for positional interpreter execution (e.g., `powershell -File script.ps1 <tokens>` or `sh script.sh <tokens>`).

## Key Components

### `tokenize(List<String> args)`
Public entry point. Accepts a list of raw argument strings, tokenizes each element, and returns a flattened list of discrete tokens. Preserves `null` input as `null` output (signals "no arguments"); `null`, blank, or whitespace-only elements contribute nothing to the result.

### `splitInto(String s, List<String> out)` *(private)*
Core tokenization logic. Walks the input string character by character using three states:

- **Quoted spans** (`'` or `"`): content between matching quotes is treated as a single token fragment, enabling arguments like `-Path="C:\Program Files"` to remain one token.
- **Whitespace**: acts as a token delimiter; flushes the current token buffer.
- **Other characters**: accumulated into the current token buffer.

## Usage Example

```java
List<String> raw = List.of(
    "-Path=\"C:\\Program Files\\app\"",
    "--user admin --verbose"
);

List<String> tokens = ScriptArgsTokenizer.tokenize(raw);
// → ["-Path=C:\Program Files\app", "--user", "admin", "--verbose"]
```

```java
// null input preserves "no args" semantics
List<String> result = ScriptArgsTokenizer.tokenize(null);
// → null
```

## Notes

- Quotes are **consumed** (stripped) from the output; their content is embedded in the surrounding token.
- Unmatched/unclosed quotes silently consume to end-of-string.
- The class is `final` with a private constructor — stateless utility, not instantiable.
