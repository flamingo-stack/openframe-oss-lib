Publishes notification events to NATS subjects scoped to individual users or machines, wrapping `NatsMessagePublisher` with topic routing, input validation, and structured message building.

## Key Components

| Member | Description |
|---|---|
| `USER_TOPIC_TEMPLATE` | Topic pattern `user.<userId>.notification` for user-targeted events |
| `MACHINE_TOPIC_TEMPLATE` | Topic pattern `machine.<machineId>.notification` for machine-targeted events |
| `publishToUser()` | Publishes a `CREATED` notification event to a user subject |
| `publishToMachine()` | Publishes a `CREATED` notification event to a machine subject |
| `publishUpdateToUser()` | Publishes an `UPDATED` notification event to a user subject |
| `publishUpdateToMachine()` | Publishes an `UPDATED` notification event to a machine subject |
| `buildMessage()` | Constructs a `NotificationMessage` from a `Notification` document |

**Activation:** Conditional on the `spring.cloud.stream.enabled` property.

**Error handling:** `NatsException` is caught and logged as a warning (non-fatal); blank IDs and unpersisted notifications throw `IllegalArgumentException`.

## Usage Example

```java
// Publish a new notification to a user
notificationNatsPublisher.publishToUser(
    "user-123",
    savedNotification,
    NotificationCategory.ALERT
);

// Publish an update notification to a machine
notificationNatsPublisher.publishUpdateToMachine(
    "machine-456",
    updatedNotification,
    NotificationCategory.SYSTEM
);
```

> **Note:** `Notification` must be persisted (non-null `id`) before publishing. Calls with a blank target ID or an unpersisted notification throw `IllegalArgumentException` before any NATS I/O occurs.
