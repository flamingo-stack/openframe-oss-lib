Represents the NATS wire payload for a saved script execution result, extending `RmmResultMessage` with script-specific identifiers echoed back from the dispatch payload.

## Key Components

| Member | Type | Description |
|---|---|---|
| `scriptId` | `String` | ID of the executed saved script, mapped from `script_id` via superclass `@JsonNaming` |
| `scheduleId` | `String` | ID of the schedule that triggered execution, mapped from `schedule_id` |

**Inherited from `RmmResultMessage`:** standard result fields (exit code, stdout, stderr, etc.) and snake_case JSON naming strategy.

**NATS Subject:** `machine.{machineId}.script-execution.result`

The distinct Java type enables the result service to route messages to `MessageType.SCRIPT_EXECUTED` downstream without requiring an explicit discriminator field in the payload.

## Usage Example

```java
// Build a script result message from agent response
ScriptResultMessage result = ScriptResultMessage.builder()
        .scriptId("script-abc123")
        .scheduleId("sched-xyz789")
        // inherited RmmResultMessage fields
        .exitCode(0)
        .stdout("Script completed successfully")
        .stderr("")
        .build();

// Deserialize from NATS JSON payload (snake_case handled by superclass @JsonNaming)
// { "script_id": "script-abc123", "schedule_id": "sched-xyz789", "exit_code": 0, ... }
ScriptResultMessage msg = objectMapper.readValue(natsPayload, ScriptResultMessage.class);
```

## Notes

- `final` class — not intended for further subclassing
- Snake_case ↔ camelCase mapping (`script_id` → `scriptId`) is inherited from the superclass `@JsonNaming` annotation
- See [`RmmResultMessage`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/data/nats/rmm/model/RmmResultMessage.java) for base fields and JSON configuration
