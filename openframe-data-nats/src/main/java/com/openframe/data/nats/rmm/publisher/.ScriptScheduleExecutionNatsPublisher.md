Publishes RMM script schedule execution batches to a target agent via core NATS, sending one message per machine containing all scripts for a given schedule fire.

## Key Components

| Element | Description |
|---|---|
| `SUBJECT_TEMPLATE` | NATS subject pattern: `machine.<machineId>.script-schedule-execution` |
| `NatsMessagePublisher` | Injected low-level publisher that handles NATS transport |
| `publish(machineId, message)` | Serializes and dispatches a `ScriptScheduleExecutionMessage` to the target machine's NATS subject |

**Conditional Activation:** Bean is only registered when `spring.cloud.stream.enabled=true`.

## Usage Example

```java
@Service
@RequiredArgsConstructor
public class ScheduleFireService {

    private final ScriptScheduleExecutionNatsPublisher publisher;

    public void fireSchedule(String machineId, String executionId, String scheduleId, List<Script> scripts) {
        ScriptScheduleExecutionMessage message = ScriptScheduleExecutionMessage.builder()
                .executionId(executionId)
                .scheduleId(scheduleId)
                .scripts(scripts)
                .build();

        // Publishes to: machine.<machineId>.script-schedule-execution
        publisher.publish(machineId, message);
    }
}
```

> **Note:** `machineId` must be a subject-safe token (validated upstream via `@Pattern` on the GraphQL input). Passing a `null` message throws `IllegalArgumentException`; NATS transport failures throw `NatsException`.
