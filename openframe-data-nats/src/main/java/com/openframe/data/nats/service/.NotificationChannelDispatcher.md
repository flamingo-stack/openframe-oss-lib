Dispatches notifications to out-of-band channels (e.g., push, SMS) asynchronously after a configurable grace window, skipping recipients who have already read the notification in-browser and filtering users with push disabled.

## Key Components

| Member | Description |
|---|---|
| `dispatch(Set<String>, Notification, NotificationCategory)` | `@Async` entry point; runs on a dedicated executor, applies grace delay, mute filtering, and read-state checks before fanning out to all registered channels |
| `awaitGrace()` | Parks the virtual thread for `openframe.push.web-grace-seconds` (default `15`); returns `false` on interrupt to abort delivery cleanly at shutdown |
| `withoutMuted(Set<String>)` | Removes users who have disabled push notifications; fails open — a missing settings document or lookup error defaults to "enabled" |
| `stillUnread(Set<String>, Notification)` | After the grace window, drops any recipient whose `NotificationReadState` is no longer `UNREAD`; fails open on lookup errors to avoid silent drops |
| `deliverSafely(NotificationChannel, String, Notification, NotificationCategory)` | Per-channel, per-user delivery wrapper; swallows `RuntimeException` so a failing channel never affects in-app delivery |
| `webGraceSeconds` | Bound from `openframe.push.web-grace-seconds`; set to `0` to disable the grace window entirely |

## Usage Example

```java
// Inject and call from NotificationBroadcaster (must go through Spring proxy for @Async to fire)
@Service
public class NotificationBroadcaster {

    private final NotificationChannelDispatcher dispatcher;

    public void broadcast(Notification notification, NotificationCategory category) {
        Set<String> userIds = resolveRecipients(notification);
        // Returns immediately; channel delivery runs on CHANNEL_EXECUTOR thread pool
        dispatcher.dispatch(userIds, notification, category);
    }
}
```

```yaml
# application.yml — tune or disable the web-presence grace window
openframe:
  push:
    web-grace-seconds: 20   # 0 disables grace + read-state filtering entirely
```

> **Note:** This class is intentionally a separate Spring bean from `NotificationBroadcaster`. A self-invoked `@Async` method bypasses the Spring proxy and runs inline — see class-level Javadoc.
