Publishes tool installation instructions to NATS messaging topics targeting specific machines, enabling remote agent deployment and configuration across the OpenFrame platform.

## Key Components

| Member | Description |
|---|---|
| `TOPIC_NAME_TEMPLATE` | Topic pattern `machine.{machineId}.tool-installation` for per-machine routing |
| `publish(machineId, toolAgent, tool)` | Publishes a standard installation message for a given machine and tool agent |
| `publish(machineId, toolAgent, tool, reinstall)` | Overload supporting forced reinstall flag |
| `buildMessage(...)` | Constructs a `ToolInstallationMessage` from `IntegratedToolAgent` and `IntegratedTool` data |
| `mapAssets(...)` | Maps a list of `ToolAgentAsset` objects to `ToolInstallationMessage.Asset` DTOs |
| `mapAssetSource(...)` | Converts `ToolAgentAssetSource` enum to the message-layer `AssetSource` enum |

**Dependencies:**
- `NatsMessagePublisher` — handles persistent NATS message delivery
- `DownloadConfigurationMapper` — maps download config with version resolution
- `LocalFilenameConfigurationMapper` — maps local filename configuration for assets

> **Note:** Conditionally active via `spring.cloud.stream.enabled` property.

## Usage Example

```java
// Standard installation
toolInstallationNatsPublisher.publish(
    "machine-abc123",
    integratedToolAgent,
    integratedTool
);

// Force reinstall of an existing tool
toolInstallationNatsPublisher.publish(
    "machine-abc123",
    integratedToolAgent,
    integratedTool,
    true  // reinstall flag
);
```

The publisher will route the message to topic `machine.machine-abc123.tool-installation` as a persistent NATS message, ensuring delivery even if the target machine agent is temporarily offline.
