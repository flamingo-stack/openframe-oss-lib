Represents a single saved-script payload within a [`ScriptScheduleExecutionMessage`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/data/nats/rmm/model/ScriptScheduleExecutionMessage.java), carrying all fields an agent requires to execute a scheduled script using its stored defaults (no runtime overrides).

## Key Components

| Field | Type | Description |
|---|---|---|
| `scriptId` | `String` | Unique identifier for the saved script |
| `code` | `String` | Script source code to execute |
| `shell` | `ScriptShell` | Shell interpreter (e.g., PowerShell, Bash) |
| `privilegeLevel` | `PrivilegeLevel` | Execution privilege context (e.g., system, user) |
| `args` | `List<String>` | Positional arguments passed to the script |
| `timeoutSeconds` | `Integer` | Maximum allowed execution duration |
| `envVars` | `List<ScriptEnvVar>` | Environment variables injected at runtime |

Null fields are omitted from serialization via `@JsonInclude(NON_NULL)`.

## Usage Example

```java
ScriptScheduleExecutionItem item = ScriptScheduleExecutionItem.builder()
    .scriptId("script-abc123")
    .code("Get-Process | Select-Object Name, CPU")
    .shell(ScriptShell.POWERSHELL)
    .privilegeLevel(PrivilegeLevel.SYSTEM)
    .timeoutSeconds(60)
    .envVars(List.of(new ScriptEnvVar("LOG_LEVEL", "debug")))
    .build();
```

This item is typically assembled by the scheduler and embedded in a `ScriptScheduleExecutionMessage` dispatched over NATS to the target agent.
