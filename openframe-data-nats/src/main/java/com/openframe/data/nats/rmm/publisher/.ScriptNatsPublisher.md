Publishes RMM saved-script execution messages to a target agent via core NATS messaging.

## Key Components

| Element | Description |
|---|---|
| `ScriptNatsPublisher` | Spring `@Component` that wraps `NatsMessagePublisher` for script-execution dispatch |
| `SCRIPT_SUBJECT_TEMPLATE` | NATS subject pattern: `machine.<machineId>.script-execution` |
| `publishScript(String, ScriptMessage)` | Formats the subject and delegates to `NatsMessagePublisher#publish` |
| `@ConditionalOnProperty("spring.cloud.stream.enabled")` | Bean is only registered when streaming is enabled |

## Usage Example

```java
@Service
@RequiredArgsConstructor
public class ScriptExecutionService {

    private final ScriptNatsPublisher scriptNatsPublisher;

    public void runScript(String machineId, ScriptMessage scriptMessage) {
        // machineId must be subject-safe (validated at the GraphQL boundary)
        scriptNatsPublisher.publishScript(machineId, scriptMessage);
    }
}
```

## Error Handling

- Throws `IllegalArgumentException` if `ScriptMessage` is `null`
- Throws `NatsException` (from `com.openframe.core.exception`) if the underlying NATS publish fails

## Notes

- `machineId` must be a subject-safe token (no dots, wildcards, etc.) — enforced via `@Pattern` on the GraphQL input type upstream
- Conditional activation requires `spring.cloud.stream.enabled=true` in application properties
