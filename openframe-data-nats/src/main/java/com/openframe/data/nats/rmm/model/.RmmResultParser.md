Thin deserialization utility that provides a single, centralized JSON parsing seam for all `RmmResultMessage` subtypes received over NATS.

## Key Components

- **`RmmResultParser`** — Spring `@Component` wrapping an `ObjectMapper` to deserialize raw NATS message payloads into any `RmmResultMessage` subtype.
- **`parse(byte[] payload, Class<T> targetType)`** — Generic method that delegates directly to Jackson, inheriting all shared `ObjectMapper` configuration (snake_case mapping, unknown-property tolerance, custom serializers, etc.).

## Usage Example

```java
// In a NATS listener for command results
@Component
@RequiredArgsConstructor
public class CommandResultListener {

    private final RmmResultParser parser;

    public void onMessage(byte[] rawPayload) throws IOException {
        CommandResultMessage result = parser.parse(rawPayload, CommandResultMessage.class);
        // process result...
    }
}

// In a separate listener for script results
@Component
@RequiredArgsConstructor
public class ScriptResultListener {

    private final RmmResultParser parser;

    public void onMessage(byte[] rawPayload) throws IOException {
        ScriptResultMessage result = parser.parse(rawPayload, ScriptResultMessage.class);
        // process result...
    }
}
```

## Notes

- The generic bound `<T extends RmmResultMessage>` enforces that only known RMM result types can be parsed, preventing accidental misuse.
- Centralizing deserialization here ensures `ObjectMapper` configuration changes (e.g., new modules, naming strategies) apply uniformly across all NATS listeners without per-listener drift.
