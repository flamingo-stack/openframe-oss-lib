Orchestrates the full lifecycle of a notification broadcast: persisting the notification document, creating per-recipient read-state records, publishing real-time events over NATS, and dispatching to additional channels (e.g. email, SMS).

## Key Components

| Member | Description |
|---|---|
| `broadcast(NotificationCommand)` | Creates and persists a `Notification`, initializes read-state for all admin and machine recipients, publishes to NATS, and triggers channel dispatch. Returns `null` if the feature flag is disabled. Rolls back the persisted document if read-state creation fails. |
| `update(Notification)` | Persists an in-place content change to an existing notification and re-publishes an `UPDATED` event to all non-deleted recipients so live clients can upsert the card by ID. Read-state rows are left untouched. |
| `republishToRecipients(...)` | Internal helper that iterates `NotificationReadState` records, skips `DELETED` recipients, and delegates to `publishUpdateSafely`. |
| `publishSafely(Runnable, ...)` | Wraps any NATS publish call; swallows `RuntimeException` and logs a warning so a single unreachable recipient never aborts the broadcast. |
| `notificationsEnabled` | Feature flag (`openframe.features.notifications.enabled`, default `false`) that short-circuits all operations when disabled. |

## Usage Example

```java
// Build a command targeting two admins
NotificationCommand cmd = NotificationCommand.builder()
        .severity(NotificationSeverity.WARNING)
        .context(NotificationContext.PATCH_FAILURE)
        .title("Patch failed on web-01")
        .description("Exit code 1 during package update")
        .correlationId("job-abc-123")
        .adminAudience(Set.of("admin-1", "admin-2"))
        .machineAudience(Set.of("machine-xyz"))
        .build();

// Persist, create read-states, publish to NATS, and dispatch channels
Notification result = notificationBroadcaster.broadcast(cmd);

// Later — update notification content and re-push to live clients
result.setDescription("Exit code 1 — rollback completed successfully");
notificationBroadcaster.update(result);
```

> **Reliability note:** If `NotificationReadStateService.createForAudience` throws, the broadcaster deletes the orphaned notification document and re-throws, keeping storage consistent. NATS publish failures are non-fatal — clients reconcile via a GraphQL catch-up query.
