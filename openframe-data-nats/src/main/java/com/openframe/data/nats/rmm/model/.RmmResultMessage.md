Base sealed class for RMM (Remote Monitoring and Management) execution result wire payloads transmitted by the OpenFrame agent over core NATS. Defines shared fields common to both command and script execution results.

## Key Components

| Member | Type | Description |
|---|---|---|
| `executionId` | `String` | Unique identifier for the execution instance |
| `machineId` | `String` | Target machine that ran the command/script |
| `stdout` | `String` | Standard output captured from execution |
| `stderr` | `String` | Standard error captured from execution |
| `exitCode` | `Integer` | Process exit code returned by the execution |
| `executionTimeMs` | `Long` | Total execution duration in milliseconds |
| `timedOut` | `Boolean` | Whether the execution exceeded its time limit |
| `error` | `String` | Agent-level error message (distinct from `stderr`) |

**Permitted subtypes:**
- [`CommandResultMessage`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/data/nats/rmm/model/CommandResultMessage.java) — ad-hoc command results
- [`ScriptResultMessage`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/data/nats/rmm/model/ScriptResultMessage.java) — saved-script results, adds `scriptId`/`scheduleId`

## Usage Example

```java
// Pattern-matching switch — exhaustive at compile time due to sealed hierarchy
RmmResultMessage result = receiveFromNats();

switch (result) {
    case CommandResultMessage cmd -> auditService.recordCommand(cmd);
    case ScriptResultMessage script -> auditService.recordScript(
        script.getScriptId(),
        script.getScheduleId(),
        script
    );
}

// Deserializing from agent's snake_case JSON payload:
// { "execution_id": "abc123", "exit_code": 0, "execution_time_ms": 342 }
RmmResultMessage msg = objectMapper.readValue(json, CommandResultMessage.class);
System.out.println(msg.getExecutionId()); // "abc123"
System.out.println(msg.getExitCode());    // 0
```

## Notes

- Snake_case JSON keys from the agent (`execution_id`) are automatically mapped to camelCase fields via `@JsonNaming(SnakeCaseStrategy.class)`
- `@JsonInclude(NON_NULL)` suppresses absent optional fields (e.g. `error` on success) from serialization
- The `sealed` + `permits` declaration enforces exhaustive pattern matching — adding a new subtype requires updating all consumers
