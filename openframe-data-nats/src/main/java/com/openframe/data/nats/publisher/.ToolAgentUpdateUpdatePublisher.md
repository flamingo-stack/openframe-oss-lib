Publishes tool agent update messages to NATS JetStream when an `IntegratedToolAgent` is updated, handling optimistic locking conflicts and marking publish state in the database.

## Key Components

| Member | Type | Description |
|---|---|---|
| `TOPIC_NAME_TEMPLATE` | Constant | Topic pattern `machine.all.tool.<id>.update` used to route messages per tool agent |
| `publish()` | Method | Sends the update and marks the agent as published/non-published; tolerates concurrent writers via `OptimisticLockingFailureException` handling |
| `send()` | Method | Builds the topic name and `ToolAgentUpdateMessage` then delegates to `NatsMessagePublisher.publishPersistent()` |
| `buildMessage()` | Private | Assembles `ToolAgentUpdateMessage` from agent metadata, mapped download configurations, and assets |
| `mapAssets()` / `mapAsset()` | Private | Converts `ToolAgentAsset` list to `ToolAgentUpdateMessage.AssetUpdate` list, preserving download configs and executable flag |

**Conditional activation:** The bean is only created when `spring.cloud.stream.enabled=true`.

## Usage Example

```java
// Injected where tool agent changes are persisted
@Service
@RequiredArgsConstructor
public class ToolAgentChangeHandler {

    private final ToolAgentUpdateUpdatePublisher publisher;

    public void onToolAgentSaved(IntegratedToolAgent toolAgent) {
        // Publishes to "machine.all.tool.<toolAgentId>.update"
        // Marks agent as published; falls back gracefully on failure
        publisher.publish(toolAgent);
    }
}
```

On failure, the agent is flagged as non-published so a scheduler can retry. Concurrent-write races during state transitions are safely ignored via `OptimisticLockingFailureException` guards in both the success and failure paths.
