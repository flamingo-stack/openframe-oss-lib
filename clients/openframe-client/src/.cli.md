Entry point for the OpenFrame client CLI. Parses command-line arguments using `clap` and dispatches to the appropriate service operation (install, uninstall, run, health check, etc.).

## Key Components

### Structs

- **`Cli`** — Top-level `clap` parser; holds an optional subcommand.
- **`InstallArgs`** — CLI arguments for the `install` subcommand (`--serverUrl`, `--initialKey`, `--localMode`, `--orgId`, `--tag`). Converts to `InstallConfigParams` via `to_params()`.

### Enums

- **`Commands`** — Available subcommands:

| Command | Visibility | Description |
|---|---|---|
| `install` | Public | Install the agent as a system service |
| `uninstall` | Public | Remove the installed service |
| `run` | Public | Run the agent directly (no service wrapper) |
| `doctor` | Public | Post-install environment health check |
| `run-as-service` | Hidden | Called by the OS service manager |
| `check-permissions` | Hidden | Inspect admin/capability status |

### Functions

- **`run() -> Result<()>`** — Primary entry point. Configures the console, parses args, creates a Tokio runtime, and dispatches to the matched command branch.
- **`init_logging()`** — Initializes file + console logging; exits with code `1` on failure.

## Usage Example

```bash
# Install with a remote server
openframe install --serverUrl https://my.openframe.server --initialKey abc123 --orgId org-1

# Run a health check on an installed agent
openframe doctor

# Check current process permissions
openframe check-permissions

# Uninstall the service (requires admin)
openframe uninstall
```

```rust
// Invoke from main.rs
fn main() {
    if let Err(e) = openframe_client::cli::run() {
        eprintln!("Fatal error: {:#}", e);
        std::process::exit(1);
    }
}
```
