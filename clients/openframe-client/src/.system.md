Provides real-time system resource metrics collection, including CPU, memory, and disk usage, using the `sysinfo` and `sys-info` crates.

## Key Components

### `SystemMetrics`
A serializable struct capturing a snapshot of system resource usage:

| Field | Type | Description |
|---|---|---|
| `timestamp` | `u64` | Unix epoch seconds at collection time |
| `cpu_usage` | `f32` | Global CPU usage percentage |
| `memory_total` | `u64` | Total RAM in bytes |
| `memory_used` | `u64` | Used RAM in bytes |
| `disk_total` | `u64` | Total disk space in bytes |
| `disk_used` | `u64` | Used disk space in bytes |
| `uptime` | `u64` | Deprecated — always returns `0` |

### `SystemInfo`
Thread-safe wrapper around `sysinfo::System` using an internal `Mutex`.

- **`new() -> Result<Self>`** — Initializes the system handle with CPU and memory refresh capabilities.
- **`collect_metrics() -> Result<SystemMetrics>`** — Refreshes CPU and memory state, reads disk info via `sys_info::disk_info()`, and returns a populated `SystemMetrics` snapshot.

## Usage Example

```rust
use system::SystemInfo;

fn main() -> anyhow::Result<()> {
    let info = SystemInfo::new()?;
    let metrics = info.collect_metrics()?;

    println!("CPU usage: {:.1}%", metrics.cpu_usage);
    println!(
        "Memory: {} / {} bytes",
        metrics.memory_used, metrics.memory_total
    );
    println!(
        "Disk: {} / {} bytes",
        metrics.disk_used, metrics.disk_total
    );

    Ok(())
}
```

> **Note:** The `uptime` field is deprecated and hardcoded to `0`. Disk values from `sys_info::disk_info()` are converted from KB to bytes internally. `SystemInfo` is safe to share across threads via `Arc<SystemInfo>`.
