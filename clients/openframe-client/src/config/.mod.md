Configuration module for the OpenFrame client, centralizing constants and settings for subsystems including service lifecycle management and logging.

## Key Components

### Submodule
- **`update_config`** — Public submodule for update-related configuration (see [`update_config`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/config/update_config.rs))

### `service_stop` Module
A collection of timing and retry constants governing process and OS service teardown:

| Constant | Type | Description |
|---|---|---|
| `PROCESS_CHECK_INTERVAL_MS` | `u64` | Poll interval for process/service state (ms) |
| `GRACEFUL_SHUTDOWN_TIMEOUT_SECS` | `u64` | Grace period before force-kill escalation (s) |
| `FORCE_KILL_TIMEOUT_SECS` | `u64` | Wait after force-kill for process exit (s) |
| `MAX_KILL_RETRIES` | `u32` | Force-kill attempts per process |
| `SERVICE_STOP_MAX_ATTEMPTS` | `u32` | Polls awaiting Windows service STOPPED state |
| `SERVICE_FORCE_KILL_MAX_ATTEMPTS` | `u32` | Force-kill rounds for a stuck service |
| `SERVICE_STOP_CALL_TIMEOUT_SECS` | `u64` | Cap on blocking SCM `stop()` call (s) |
| `SERVICE_START_MAX_ATTEMPTS` | `u32` | Start attempts before giving up |

> **Note:** `SERVICE_*` constants are Windows-specific; `#![allow(dead_code)]` suppresses warnings on other platforms.

### Legacy Structs (Unused)
- **`Configuration`** — Top-level config wrapper holding a `LoggingConfig`
- **`LoggingConfig`** — Log level, JSON output toggle, rotation size, and max file count
- **`Configuration::default()`** — Returns `info`-level JSON logging, 10 MB rotation, 5 max files

## Usage Example

```rust
use openframe_oss_lib::config::service_stop;
use openframe_oss_lib::config::Configuration;

// Access service stop timing constants
let interval = service_stop::PROCESS_CHECK_INTERVAL_MS; // 500ms
let grace    = service_stop::GRACEFUL_SHUTDOWN_TIMEOUT_SECS; // 5s

// Instantiate default logging config
let cfg = Configuration::default();
assert_eq!(cfg.logging.level, "info");
assert_eq!(cfg.logging.rotation_size_mb, 10);
```
