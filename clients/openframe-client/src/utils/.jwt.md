Lightweight JWT utility for extracting the `exp` claim from a token's payload without performing signature verification.

## Key Components

| Item | Kind | Description |
|---|---|---|
| `token_exp_unix` | `pub fn` | Decodes a JWT's `exp` claim (Unix timestamp) from the payload segment, returning `None` for malformed tokens or missing claims |
| `ExpClaim` | `struct` | Private serde-deserializable struct used to extract only the `exp` field from the payload JSON |

## Usage Example

```rust
use openframe_oss_lib::jwt::token_exp_unix;

let token = "eyJhbGciOiJIUzI1NiJ9.eyJleHAiOjE3MDAwMDAwMDAsInN1YiI6Im1hY2hpbmUifQ.sig";

match token_exp_unix(token) {
    Some(exp) => {
        let now = std::time::SystemTime::now()
            .duration_since(std::time::UNIX_EPOCH)
            .unwrap()
            .as_secs() as i64;

        if exp < now {
            eprintln!("Token has expired");
        } else {
            println!("Token valid, expires at Unix timestamp {exp}");
        }
    }
    None => eprintln!("Malformed token or missing exp claim"),
}
```

## Behaviour Notes

- **No signature verification** — intended for expiry pre-checks only; always verify the signature through a proper JWT library before trusting any claims.
- **Strict segment validation** — requires exactly three `.`-separated parts (`header.payload.signature`); tokens with fewer or extra segments return `None`.
- **Tolerant Base64 padding** — trailing `=` padding is stripped before decoding to handle both padded and unpadded URL-safe Base64 variants.
