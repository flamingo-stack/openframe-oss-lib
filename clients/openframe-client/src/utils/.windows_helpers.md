Windows-specific registry and string utilities for managing OpenFrame tool autostart entries and persistent configuration under `HKEY_LOCAL_MACHINE`.

## Key Components

| Function | Description |
|---|---|
| `to_wide` | Converts a `&str` to a null-terminated UTF-16 `Vec<u16>` for Win32 wide-string APIs |
| `wcslen` | Unsafe C-style wide-string length counter; walks a `*const u16` until the null terminator |
| `build_command_line` | Builds a properly quoted/escaped Windows command-line string from a path and argument slice, following `CommandLineToArgvW` escaping rules |
| `register_autorun` | Writes a named value to the 64-bit `HKLM\...\Run` key and removes any stale entry from the WOW64 mirror to prevent double-launch at logon |
| `write_app_config` | Serialises `--key value` / `--flag` CLI args into `HKLM\SOFTWARE\OpenFrame\<name>` so a tool can recover its config when Windows relaunches it without arguments |
| `unregister_autorun` | Removes a named autorun entry from both the 64-bit Run key and the WOW64 mirror |

## Usage Example

```rust
use crate::windows_helpers::{register_autorun, write_app_config, unregister_autorun};

// Register a tool to launch at logon
let args = vec!["--serverUrl".to_string(), "https://openframe.example.com".to_string()];
register_autorun("OpenFrameAgent", r"C:\Program Files\OpenFrame\agent.exe", &args)?;

// Persist launch config so the tool can recover it without CLI args
write_app_config("OpenFrameAgent", &args)?;
// Stored as: HKLM\SOFTWARE\OpenFrame\OpenFrameAgent
//   serverUrl = "https://openframe.example.com"

// Remove autorun entries from both 64-bit and WOW64 registry views
unregister_autorun("OpenFrameAgent");
```

> **Note:** `register_autorun` always targets the 64-bit registry view (`KEY_WOW64_64KEY`) and explicitly cleans up the WOW64 mirror (`WOW6432Node\...\Run`) to ensure only one launch occurs at logon.
