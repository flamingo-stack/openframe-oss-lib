Manages the OpenFrame client service lifecycle — installation, uninstallation, and cross-platform OS service registration (Windows SCM, macOS launchd, Linux systemd).

## Key Components

- **`Service`** — Core struct providing static methods for service lifecycle management
- **`FULL_SERVICE_NAME`** — Canonical service identifier (`"com.openframe.client"`) used across all platforms
- **`windows_service_main`** *(Windows-only)* — SCM entry point handling start/stop/shutdown signals via `mpsc` channel and updating service state
- **`set_service_status`** *(Windows-only)* — Helper to update the Windows SCM service status handle
- **Recovery constants** — Configures Windows SCM restart policy (10s → 60s → 300s backoff, 1-day reset period)

## Key Methods

| Method | Description |
|---|---|
| `Service::is_installed()` | Checks platform-specific service registration (registry / plist / systemd unit) |
| `Service::install(params)` | Copies binary to install location, writes initial config, registers OS service |
| `Service::get_install_location()` | Returns the canonical binary install path for the current platform |
| `Service::kill_processes_running_from(path)` | Terminates stale processes holding the install-path binary before copy |

## Usage Example

```rust
use openframe_client::service::{Service, FULL_SERVICE_NAME};
use openframe_client::installation_initial_config_service::InstallConfigParams;

// Check if already installed before proceeding
if !Service::is_installed() {
    let params = InstallConfigParams {
        // ... enrollment token, server URL, etc.
    };

    Service::install(params).await?;
    println!("Service '{}' installed successfully.", FULL_SERVICE_NAME);
} else {
    println!("Service is already installed.");
}
```

## Platform Notes

- **Windows**: Uses `windows_service` crate; SCM entry point defined via `define_windows_service!` macro. Recovery escalates restart delays across three failure tiers.
- **macOS**: Installs as a `LaunchDaemon` plist under `/Library/LaunchDaemons/`.
- **Linux**: Registers a systemd unit under `/etc/systemd/system/`.
