Renders the OpenFrame CLI startup banner to stdout using ANSI escape codes for styled, colorized ASCII art.

## Key Components

- **`F` (Flamingo Pink)** — ANSI 24-bit color constant (`rgb(243, 87, 187)`) used for the flamingo logo art
- **`W` (White/Bold)** — ANSI bold white constant used for the "OpenFrame" wordmark text
- **`R` (Reset)** — ANSI reset constant to restore default terminal styling after output
- **`print()`** — Public function that writes the full multi-line banner to stdout

## Usage Example

```rust
// Call at application startup, typically in main.rs
fn main() {
    banner::print();
    // ... rest of CLI initialization
}
```

**Example output (simplified):**

```text
                 ####
               ########
    ...flamingo logo...    OpenFrame  (wordmark in bold white)
    ...
```

The banner combines two visual elements side-by-side:
- A **flamingo silhouette** (left) rendered in `rgb(243, 87, 187)` pink
- The **"OpenFrame" wordmark** (right) rendered in bold white

## Notes

- Color constants are intentionally short single-character names (`F`, `W`, `R`) to keep the multi-line `println!` statements readable and aligned
- All ANSI codes are inline escape sequences; no external crate dependencies are required
- The reset code `R` is applied on the final line to ensure the terminal returns to default styling after the banner prints
