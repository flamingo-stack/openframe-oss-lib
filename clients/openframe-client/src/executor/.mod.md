Cross-platform script execution module that provides a unified interface for running scripts with configurable privileges, shell selection, environment variables, and timeout control on both Unix and Windows systems.

## Key Components

### Enums

- **`Privilege`** — Execution privilege level: `Agent` (elevated/service context) or `User` (standard user context)

### Structs

- **`ScriptParams<'a>`** — Input configuration for script execution:
  - `code` — Script source code to execute
  - `shell` — Shell interpreter (e.g., `bash`, `powershell`)
  - `args` — Additional arguments passed to the script
  - `timeout_secs` — Maximum allowed execution time
  - `privilege` — Execution privilege level
  - `env_vars` — Environment variables to inject

- **`ExecResult`** — Output from a completed script run:
  - `stdout` / `stderr` — Captured output streams
  - `retcode` — Process exit code
  - `timed_out` — Whether the process was killed due to timeout

### Platform-Specific Exports

- **`execute_script`** — Primary entry point, conditionally compiled from `unix` or `windows` submodules

### Internal Submodules

| Module | Purpose |
|---|---|
| `env` | Environment variable handling |
| `output` | stdout/stderr capture utilities |
| `tempfile` | Temporary script file management |

## Usage Example

```rust
use script::{execute_script, ScriptParams, Privilege};

let params = ScriptParams {
    code: "echo Hello from script",
    shell: "bash",
    args: &[],
    timeout_secs: 30,
    privilege: Privilege::Agent,
    env_vars: &["MY_VAR=value".to_string()],
};

let result = execute_script(params).await?;

println!("stdout: {}", result.stdout);
println!("exit code: {}", result.retcode);

if result.timed_out {
    eprintln!("Script exceeded timeout");
}
```
