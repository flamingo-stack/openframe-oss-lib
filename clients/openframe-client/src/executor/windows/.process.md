Async process execution handler for running interpreter-based scripts as child processes with timeout enforcement and output capture.

## Key Components

- **`run_normal`** — Core async function that spawns a child process for a given interpreter and script file, captures stdout/stderr concurrently, enforces a configurable timeout, and returns a structured `ExecResult`.
- **`CREATE_NO_WINDOW`** — Windows-specific process creation flag (`0x0800_0000`) that suppresses console window creation for background script execution.
- **`JobHandle::for_pid`** — Associates the spawned process with a job object for reliable process tree termination on timeout.

## Behavior & Exit Codes

| Scenario | `retcode` | `timed_out` |
|---|---|---|
| Spawn failure | `85` | `false` |
| Normal exit | Process exit code | `false` |
| Wait error | `1` | `false` |
| Timeout | `98` | `true` |

On timeout, the job handle terminates the process tree before calling `start_kill` as a fallback, then waits for the child to fully reap.

## Usage Example

```rust
let result = run_normal(
    &interpreter,   // e.g. PowerShell or Python interpreter
    &tmp_script,    // Path to temp script file
    &ScriptParams {
        args: &["--silent"],
        env_vars: &[("MY_VAR", "value")],
        timeout_secs: 30,
    },
).await;

println!("exit: {}, stdout: {}", result.retcode, result.stdout);
if result.timed_out {
    eprintln!("Script exceeded timeout");
}
```

> **Note:** stdout and stderr are captured concurrently via `tokio::spawn` to prevent pipe buffer deadlocks, and output is sanitized via `clean_string` before being returned.
