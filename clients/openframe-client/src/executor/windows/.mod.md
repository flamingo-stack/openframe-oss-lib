Windows script execution engine for the OpenFrame agent. Resolves the correct interpreter (PowerShell or CMD), writes the script to a temporary file, waits for antivirus scan locks to clear, then dispatches to either a normal process runner or an interactive `run-as-user` runner based on the requested privilege level.

## Key Components

| Item | Description |
|---|---|
| `execute_script` | Async entry point — resolves interpreter, writes temp script, awaits readability, dispatches to `process::run_normal` or `run_as_user::run_as_interactive` |
| `Interpreter` | Struct holding the executable path, CLI flags, and file extension for a given shell |
| `resolve_interpreter` | Maps `"powershell"` → `.ps1` / `"cmd"` → `.bat`; returns `None` for unsupported shells |
| `resolve_exe` | Constructs the absolute `System32` path via `WINDIR`/`SystemRoot`, falling back to bare executable name |
| `wait_until_readable` | Retries file-open up to 3× (200 ms apart) to handle transient antivirus scan locks (OS error 5/32/33) |
| `create_temp_script` | Writes script code to `%PROGRAMDATA%\OpenFrame\<uuid>.<ext>` |
| `win_tmp_dir` | Resolves or creates the `%PROGRAMDATA%\OpenFrame` working directory |
| `spawn_error` | Constructs an `ExecResult` with `retcode = 85` for startup failures |

## Usage Example

```rust
use crate::executor::{Privilege, ScriptParams};
use crate::executor::windows::execute_script;

let result = execute_script(ScriptParams {
    code: "Write-Output $env:FOO",
    shell: "powershell",
    args: &[],
    timeout_secs: 30,
    privilege: Privilege::Agent,
    env_vars: &["FOO=bar"],
}).await;

assert_eq!(result.retcode, 0);
assert_eq!(result.stdout.trim_end(), "bar");
```

> **Unsupported shells** (anything other than `"powershell"` or `"cmd"`) return immediately with `retcode = 85` and a descriptive `stderr` message. The `Privilege::User` path delegates to `run_as_user::run_as_interactive`, which requires the agent to be running as `SYSTEM` with an active interactive session.
