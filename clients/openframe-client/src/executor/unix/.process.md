Async process execution engine that runs shell commands with configurable timeouts, output capture, and process-tree cleanup on Unix systems.

## Key Components

### `execute_with_timeout(cmd, timeout_secs) -> ExecResult`
The primary entry point. Spawns a command with piped stdout/stderr, waits up to `timeout_secs` for completion, and returns an [`ExecResult`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/executor/mod.rs) containing captured output and a return code. On timeout, kills the process group and sets `retcode = 98` with `timed_out = true`.

### `spawn_with_retry(cmd, max_retries)`
Wraps `Command::spawn()` with up to 5 retries (500 ms apart) specifically for `ETXTBSY` ("text file busy") errors, which occur when a script file is still being written to disk at spawn time.

### `join_reads(stdout_task, stderr_task, pid)`
Collects buffered stdout/stderr from background `JoinHandle`s within a 5-second grace window (`READ_GRACE`). If streams remain open (e.g., a backgrounded child holds them), it kills the process group and retries once more to avoid hanging indefinitely.

### `kill_process_tree(pid)`
Sends `SIGKILL` to the entire process group (`-pid`) via `libc::kill`. Explicitly refuses `pid = 0` to prevent accidentally killing the agent process itself.

## Return Codes

| Code | Meaning |
|------|---------|
| `0` | Success |
| `1` | Wait error |
| `85` | Spawn failure |
| `98` | Timed out |
| `128 + signal` | Killed by signal (e.g., `137` = SIGKILL, `143` = SIGTERM) |

## Usage Example

```rust
use tokio::process::Command;
use crate::executor::process::execute_with_timeout;

#[tokio::main]
async fn main() {
    let mut cmd = Command::new("/bin/sh");
    cmd.arg("-c").arg("echo hello && sleep 10");

    // Runs with a 5-second wall-clock timeout
    let result = execute_with_timeout(cmd, 5).await;

    println!("stdout:   {}", result.stdout);
    println!("stderr:   {}", result.stderr);
    println!("retcode:  {}", result.retcode);
    println!("timed_out:{}", result.timed_out);
    // retcode == 98, timed_out == true
}
```
