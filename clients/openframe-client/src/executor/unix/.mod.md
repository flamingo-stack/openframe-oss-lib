Entry point for the Unix shell script executor — orchestrates temp file creation, privilege resolution, environment setup, and timed process execution for shell scripts.

## Key Components

| Item | Description |
|---|---|
| `execute_script` | Main async entry point; resolves user privileges, writes a temp script, builds the command, applies env vars, and delegates to `execute_with_timeout` |
| `create_temp_script` | Writes script content to a temp file beside the current executable, sets `0o700` permissions, and optionally `chown`s it to the target user |
| `build_script_command` | Constructs a `tokio::process::Command` from the script path and argument list |
| `normalize_line_endings` | Strips Windows-style `\r\n` to `\n` before writing the script |
| `spawn_error` | Converts an `anyhow::Error` into a failed `ExecResult` with exit code `85` |
| `process` (submodule) | Provides `execute_with_timeout` for running the command with a deadline |
| `run_as_user` (submodule) | Provides `resolve_run_as` and `configure_preexec` for privilege switching |

## Usage Example

```rust
use crate::executor::{Privilege, ScriptParams};
use crate::executor::unix::execute_script;

let result = execute_script(ScriptParams {
    code: "#!/bin/sh\necho hello\n",
    shell: "/bin/sh",
    args: &[],
    timeout_secs: 30,
    privilege: Privilege::Agent,
    env_vars: &["FOO=bar".to_string()],
}).await;

assert_eq!(result.stdout, "hello\n");
assert_eq!(result.retcode, 0);
```

> **Note:** The temp script is written next to the running executable and cleaned up automatically via `TempFileGuard` on drop. A spawn failure always returns exit code `85` with the error message in `stderr`.
