Resolves which OS user a child process should run as, then configures a `pre_exec` hook that drops privileges (uid/gid/supplementary groups) before the process starts.

## Key Components

### Enums & Structs

- **`RunAs`** — discriminates between running as the current agent user (`Current`) or a specific named user (`User(UserInfo)`).
- **`UserInfo`** — holds the resolved username, `uid`, `gid`, and home directory for the target user.

### Functions

| Function | Description |
|---|---|
| `resolve_run_as` | Maps a `Privilege` variant to a `RunAs` value; performs user lookup for `Privilege::User`. |
| `lookup_user` | Calls `nix::unistd::User::from_name` to resolve a username into a `UserInfo`. |
| `resolve_active_user` (macOS) | Reads the console owner via `stat -f %Su /dev/console`. |
| `resolve_active_user` (Linux) | Tries `loginctl list-sessions` first, falls back to `who`, rejects `root`. |
| `configure_preexec` | Attaches a `pre_exec` closure to a `tokio::process::Command` that calls `setpgid`, `initgroups`, `setgid`, and `setuid`. |

## Usage Example

```rust
use tokio::process::Command;
use crate::executor::Privilege;
use crate::run_as_user::{resolve_run_as, configure_preexec};

async fn spawn_as_user() -> anyhow::Result<()> {
    let run_as = resolve_run_as(Privilege::User).await?;

    let mut cmd = Command::new("/bin/sh");
    cmd.arg("-c").arg("id -u");

    configure_preexec(&mut cmd, &run_as)?;

    let status = cmd.status().await?;
    assert!(status.success());
    Ok(())
}
```

> **Note:** Switching to another user requires the agent process to be running as `root`. Attempting a privilege switch from a non-root agent returns an error immediately, before any process is spawned.
