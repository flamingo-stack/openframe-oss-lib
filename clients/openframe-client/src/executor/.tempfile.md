Provides RAII-style cleanup for temporary script files, ensuring they are deleted from the filesystem when they go out of scope.

## Key Components

- **`TempFileGuard`** — A guard struct wrapping a `PathBuf` that implements `Drop` to automatically remove the file at `path` when it goes out of scope. Logs a warning via `tracing` if deletion fails.
- **`temp_script_name(ext: &str) -> String`** — Generates a unique temporary filename prefixed with `ofcmd_` using a UUID v4, e.g. `ofcmd_<uuid>.<ext>`.

## Usage Example

```rust
use crate::tempfile::{TempFileGuard, temp_script_name};

// Generate a unique temp file name
let filename = temp_script_name("sh"); // e.g. "ofcmd_4a3b...c1.sh"
let path = std::env::temp_dir().join(&filename);

// Write script content
std::fs::write(&path, b"#!/bin/sh\necho hello").unwrap();

// Guard ensures the file is deleted when this block exits
let _guard = TempFileGuard { path };

// ... execute script ...
// File is automatically removed when `_guard` drops
```

## Notes

- Both items are `pub(crate)`, scoping them to internal use within the library.
- `temp_script_name` supports any extension (`sh`, `ps1`, `bat`, etc.), making it suitable for cross-platform script generation.
- Deletion failures are non-fatal and emit a `WARN`-level trace log rather than panicking.
