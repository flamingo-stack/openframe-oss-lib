Writes the boot marker that openframe-client-updater uses to verify a client binary swap, and removes the last-known-good files earlier clients left behind.

## Key Components

| Item | Description |
|---|---|
| `BootMarkerService` | Owns the `boot.marker` path in the secured directory and the list of legacy last-known-good files |
| `write_boot_marker()` | Atomically writes the running version to `boot.marker` on every boot (temp file, then rename) |
| `remove_legacy_artifacts()` | Deletes `last_known_good.json` and the `.lkg` reserve binary (plus their temp files) that earlier clients kept |

## Usage Example

```rust
use crate::platform::directories::DirectoryManager;
use crate::services::boot_marker_service::BootMarkerService;

let boot_marker = BootMarkerService::new(directory_manager)?;

// On startup, before anything else can fail
boot_marker.write_boot_marker().await?;
boot_marker.remove_legacy_artifacts();
```
