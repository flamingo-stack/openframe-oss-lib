Manages persistent agent configuration by reading and writing `AgentConfiguration` data to a JSON file in a secured directory, with a mutex-guarded write lock to prevent concurrent update races.

## Key Components

- **`AgentConfigurationService`** — Main service struct holding the config file path and an `Arc<Mutex<()>>` write lock for safe concurrent access.
- **`new(directory_manager)`** — Constructor that resolves the config path to `<secured_dir>/agent_config.json` and ensures the directory exists.
- **`save_registration_data`** — Atomically updates `machine_id`, `client_id`, and `client_secret` under the write lock.
- **`update_tokens`** — Atomically replaces `access_token` and `refresh_token` under the write lock.
- **`get_machine_id`**, **`get_client_credentials`**, **`get_access_token`**, **`get_refresh_token`** — Read accessors that deserialize the current config from disk.
- **`get` (private)** — Reads and deserializes the JSON config file, returning a default `AgentConfiguration` if the file does not yet exist.
- **`save` (private)** — Serializes config to pretty-printed JSON and persists it via `atomic_write` to prevent partial writes.

## Usage Example

```rust
use crate::platform::directories::DirectoryManager;
use crate::services::AgentConfigurationService;

let dir_manager = DirectoryManager::new()?;
let svc = AgentConfigurationService::new(dir_manager)?;

// Persist registration credentials after enrollment
svc.save_registration_data(
    "machine-abc123".to_string(),
    "client-id-xyz".to_string(),
    "client-secret-xyz".to_string(),
).await?;

// Store refreshed OAuth tokens
svc.update_tokens(
    "new-access-token".to_string(),
    "new-refresh-token".to_string(),
).await?;

// Retrieve individual fields as needed
let machine_id = svc.get_machine_id()?;
let access_token = svc.get_access_token().await?;
```
