Handles agent registration for new and reinstalling devices, managing credential persistence and fallback logic across fresh installs and re-registrations.

## Key Components

### `AgentRegistrationService`

The primary struct, constructed with four dependencies:

| Field | Role |
|---|---|
| `registration_client` | HTTP client for the registration API |
| `device_data_fetcher` | Reads hostname, OS type, and agent version |
| `config_service` | Persists registration data post-registration |
| `initial_configuration_service` | Supplies the initial key, org ID, and tags |

### Methods

- **`register_agent`** — Public entry point. Checks for persisted credentials, delegates to `fresh_install` or `reinstall`, then persists the returned machine info and saves registration data via `config_service`.
- **`read_persisted_credentials`** — Retries reading persisted machine info up to 3 times with delays of 1s, 3s, and 5s. Falls back to `None` (fresh install) on exhaustion.
- **`fresh_install`** — Sends a registration request with no prior credentials; the server generates a new `machine_id` and `client_secret`.
- **`reinstall`** — Sends the saved `machine_id` and `client_secret`. If the server returns `ClientSecretInvalid`, transparently falls back to `fresh_install`.
- **`build_registration_request`** — Assembles `AgentRegistrationRequest` from device data and initial configuration.

## Usage Example

```rust
let service = AgentRegistrationService::new(
    registration_client,
    device_data_fetcher,
    config_service,
    initial_configuration_service,
);

let response = service.register_agent().await?;
println!("Registered with machine_id: {}", response.machine_id);
```

## Retry / Fallback Behaviour

```text
read_persisted_credentials()
  ├── attempt 1 (retry after 1s)
  ├── attempt 2 (retry after 3s)
  ├── attempt 3 (retry after 5s)
  └── failure → return None → fresh_install()

reinstall() → ClientSecretInvalid → fresh_install()
```
