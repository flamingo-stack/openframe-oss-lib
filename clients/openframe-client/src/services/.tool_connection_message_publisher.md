Publishes tool connection events to a NATS topic scoped to a specific machine, wrapping the generic `NatsMessagePublisher` with domain-specific topic construction and message building.

## Key Components

- **`ToolConnectionMessagePublisher`** — Cloneable struct that wraps `NatsMessagePublisher` to send `ToolConnectionMessage` payloads.
- **`new(nats_message_publisher)`** — Constructor that injects the underlying NATS publisher.
- **`publish(machine_id, agent_tool_id, tool_type)`** — Async method that builds the topic and message, then delegates to `NatsMessagePublisher`. Returns `anyhow::Result<()>`.
- **`build_topic_name(machine_id)`** — Produces a topic in the format `machine.<machine_id>.tool-connection`.
- **`build_message(agent_tool_id, tool_type)`** — Constructs a `ToolConnectionMessage` struct from the provided fields.

## Usage Example

```rust
use crate::services::nats_message_publisher::NatsMessagePublisher;
use crate::services::tool_connection_message_publisher::ToolConnectionMessagePublisher;

let nats_publisher = NatsMessagePublisher::new(nats_client);
let publisher = ToolConnectionMessagePublisher::new(nats_publisher);

publisher
    .publish(
        "machine-abc123".to_string(),
        "agent-tool-456".to_string(),
        "ssh".to_string(),
    )
    .await?;
// Publishes to: machine.machine-abc123.tool-connection
```
