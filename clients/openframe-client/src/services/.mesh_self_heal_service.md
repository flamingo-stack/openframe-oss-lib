Monitors the MeshCentral agent for connectivity failures and silently wedged states, automatically refreshing configuration and restarting the agent when unhealthy conditions are detected.

## Key Components

- **`MeshSelfHealService`** — Main service struct holding references to directory management, tool lifecycle services, HTTP client, and configuration providers.
- **`run()`** — Spawns the background watcher task via `tokio::spawn`.
- **`watch()`** — Core polling loop that reads new log lines every 30 seconds, tracks failure/healthy markers, detects stuck (`10 min`) and silent (`90 min`) states, and triggers healing actions under a 1-hour cooldown.
- **`restart_agent()`** — Delegates to `ToolRestartService::restart_guarded`; falls back to a process kill if the agent is absent from the registry.
- **`try_refresh_msh()`** — Fetches a fresh `.msh` config from the server's `/generate-msh` endpoint, performs an atomic write (`tmp` → rename) only when `MeshID` or `ServerID` has changed.
- **`current_msh_missing_serverid()`** — Quick check that gates an immediate heal when the on-disk `.msh` lacks a `ServerID` field.

### Key Constants

| Constant | Value | Purpose |
|---|---|---|
| `POLL_INTERVAL` | 30 s | Log scan frequency |
| `STUCK_DURATION` | 10 min | Max time in failure state before restart |
| `SILENCE_DURATION` | 90 min | Max log inactivity before restart |
| `ACTION_COOLDOWN` | 60 min | Minimum gap between heal attempts |
| `HTTP_TIMEOUT` | 30 s | Timeout for `/generate-msh` fetch |

## Usage Example

```rust
let svc = MeshSelfHealService::new(
    directory_manager,
    installed_tools,
    tool_kill,
    tool_restart,
    initial_config,
    agent_config,
    tool_run_manager,
);

// Spawns the background watcher; returns immediately.
svc.run().await?;
```

The watcher is entirely self-contained after `run()` returns. Host suspension is detected via `Instant` drift and resets all timers to prevent spurious restarts after a sleep/resume cycle.
