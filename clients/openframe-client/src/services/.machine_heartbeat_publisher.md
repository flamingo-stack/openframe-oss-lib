Publishes periodic heartbeat messages for a machine over NATS, with throttled logging to reduce noise in long-running agents.

## Key Components

- **`MachineHeartbeatPublisher`** — Cloneable struct that composes a NATS publisher, an agent configuration service, and an atomic counter for log throttling.
- **`publish_heartbeat()`** — Async method that retrieves the machine ID, constructs a `MachineHeartbeatMessage`, serializes it to JSON, and publishes to the topic `machine.<machine_id>.heartbeat`.
- **`log_heartbeat()`** — Internal method that increments an `AtomicU64` counter and emits a `debug` log on every heartbeat, upgrading to an `info`-level summary every 60 heartbeats before resetting the counter.
- **`HEARTBEAT_LOG_INTERVAL`** — Constant (`60`) controlling how frequently a consolidated `info` log is emitted instead of per-heartbeat `debug` logs.

## Usage Example

```rust
let publisher = MachineHeartbeatPublisher::new(
    nats_publisher,
    config_service,
);

// Call periodically from a scheduler or async loop
publisher.publish_heartbeat().await?;
```

The struct is `Clone`, so it can be safely shared across async tasks:

```rust
let publisher = Arc::new(publisher);
let p = publisher.clone();

tokio::spawn(async move {
    loop {
        p.publish_heartbeat().await.ok();
        tokio::time::sleep(Duration::from_secs(30)).await;
    }
});
```
