Manages persistent storage of OpenFrame client metadata — version, update status, and binary path — by reading and writing a JSON file in the secured directory.

## Key Components

### `OpenFrameClientInfoService`
A cloneable service struct that encapsulates the path to `openframe_client_info.json` within the secured directory.

| Method | Description |
|---|---|
| `new(directory_manager)` | Constructs the service, resolving the file path and ensuring the secured directory exists |
| `get()` | Reads and deserializes client info from disk; returns `Default` if the file is absent |
| `save(info)` | Serializes and writes client info to disk as pretty-printed JSON |
| `update_version(new_version)` | Updates `current_version` and stamps `last_updated` with the current UTC timestamp |
| `reconcile_version(running_version)` | Syncs `current_version` to match the running binary if they diverge |
| `set_update_status(status, target_version)` | Persists update lifecycle state and stamps `last_update_check` |
| `set_binary_path(binary_path)` | Records the path of the installed client binary |

## Usage Example

```rust
use crate::platform::directories::DirectoryManager;
use crate::services::openframe_client_info_service::OpenFrameClientInfoService;
use crate::models::openframe_client_info::ClientUpdateStatus;

let dir_manager = DirectoryManager::new()?;
let service = OpenFrameClientInfoService::new(dir_manager)?;

// Read current info (returns Default if not yet initialized)
let info = service.get().await?;
println!("Current version: {}", info.current_version);

// Reconcile version on startup
service.reconcile_version(env!("CARGO_PKG_VERSION")).await?;

// Mark an update as available
service
    .set_update_status(ClientUpdateStatus::UpdateAvailable, Some("1.2.0".into()))
    .await?;

// Persist the new binary location after an update
service.set_binary_path("/usr/local/bin/openframe".into()).await?;
```

## Notes

- All mutation methods follow a **read-modify-write** pattern via `get()` + `save()`.
- Timestamps are RFC 3339 UTC strings sourced from `chrono::Utc::now()`.
- Errors are propagated with contextual messages using `anyhow`.
