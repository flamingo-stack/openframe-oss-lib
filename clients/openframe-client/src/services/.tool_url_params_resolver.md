Resolves dynamic URL path placeholders by substituting runtime configuration values (e.g., server base URL) into tool URL templates.

## Key Components

- **`ToolUrlParamsResolver`** — Main struct that holds a reference to `InitialConfigurationService` and performs placeholder substitution.
- **`SERVER_URL_PLACEHOLDER`** — Constant string `"${client.serverUrl}"` used as the substitution token in URL templates.
- **`new()`** — Constructor accepting an `InitialConfigurationService` instance.
- **`process()`** — Replaces all occurrences of `${client.serverUrl}` in a given URL path with the resolved server URL from configuration.

## Usage Example

```rust
let resolver = ToolUrlParamsResolver::new(initial_configuration_service);

let resolved = resolver.process("${client.serverUrl}/api/v1/tickets")?;
// resolved => "https://your-server.example.com/api/v1/tickets"
```

## Notes

- Returns `anyhow::Result<String>`, propagating any errors from `InitialConfigurationService::get_server_url()`.
- The struct derives `Clone`, making it safe to share across services or pass by value.
- Additional placeholders can be added by extending the `process()` method with further `.replace()` calls.
