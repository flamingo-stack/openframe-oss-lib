Publishes installed agent messages to NATS topics scoped to a specific machine, wrapping the lower-level `NatsMessagePublisher` with domain-specific topic construction and message building.

## Key Components

- **`InstalledAgentMessagePublisher`** — Cloneable struct that composes a `NatsMessagePublisher` to handle agent installation event publishing.
- **`publish`** — Async method that constructs the topic and message, then delegates to NATS. Returns `anyhow::Result<()>` with contextual error messaging on failure.
- **`build_topic_name`** — Private helper that formats the NATS subject as `machine.<machine_id>.installed-agent`.
- **`build_message`** — Private helper that constructs an `InstalledAgentMessage` from `agent_type` and `version` fields.

## Usage Example

```rust
use crate::services::installed_agent_message_publisher::InstalledAgentMessagePublisher;
use crate::services::nats_message_publisher::NatsMessagePublisher;

let nats_publisher = NatsMessagePublisher::new(nats_client);
let publisher = InstalledAgentMessagePublisher::new(nats_publisher);

publisher
    .publish(
        "abc-1234".to_string(),
        "monitoring".to_string(),
        "1.2.0".to_string(),
    )
    .await?;
// Publishes to: machine.abc-1234.installed-agent
```

The topic format `machine.<machine_id>.installed-agent` enables per-machine subscriptions, allowing consumers to filter agent installation events by machine identity.
