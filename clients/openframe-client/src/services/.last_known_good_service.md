Manages rollback safety for the OpenFrame agent binary by tracking and persisting the last-known-good (LKG) version — a validated binary copy paired with a JSON anchor file — so the updater can recover from failed upgrades.

## Key Components

| Item | Description |
|---|---|
| `LastKnownGood` | Serializable struct holding the promoted version string, persisted to `last_known_good.json` |
| `LastKnownGoodService` | Core service managing LKG state, reserve binary copy, boot markers, and update transcripts |
| `load()` | Reads and deserializes the current LKG anchor version from disk |
| `promote(version)` | Atomically copies the running binary to `.lkg` reserve and writes the anchor JSON |
| `seed_if_missing()` | Bootstraps LKG state on first run; repairs degraded rollback protection if reserve is missing |
| `write_boot_marker()` | Atomically writes the current version to `boot.marker`, used to detect incomplete boots |
| `new_transcript_path(target)` | Generates a timestamped log path for a specific update attempt |
| `prune_transcripts(keep)` | Removes oldest updater log files, retaining only the `keep` most recent |

All file writes use a write-to-temp-then-rename pattern to ensure atomicity.

## Usage Example

```rust
use crate::platform::directories::DirectoryManager;
use crate::services::last_known_good_service::LastKnownGoodService;

let dir_manager = DirectoryManager::new(/* ... */);
let lkg = LastKnownGoodService::new(dir_manager)?;

// On startup: seed or repair LKG state
lkg.seed_if_missing().await?;

// After a successful update and boot validation
lkg.promote("1.4.2").await?;
lkg.write_boot_marker().await?;

// Check current LKG version
if let Some(version) = lkg.load().await? {
    println!("Last known good: {version}");
}

// Get rollback binary path for the updater
let reserve = lkg.reserve_path(); // e.g. /path/to/agent.lkg

// Clean up old update logs, keep 5 most recent
lkg.prune_transcripts(5).await;
```
