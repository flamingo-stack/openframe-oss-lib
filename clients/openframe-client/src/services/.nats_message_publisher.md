Provides a thin async wrapper around a NATS client for serializing and publishing JSON messages to a given subject.

## Key Components

- **`NatsMessagePublisher`** — Cloneable struct that holds a `NatsConnectionManager` and exposes a single publish method.
- **`new(nats_connection_manager: NatsConnectionManager) -> Self`** — Constructor that injects the connection manager.
- **`publish<T: Serialize>(&self, subject: &str, payload: T) -> Result<()>`** — Serializes `payload` to JSON, acquires a NATS client, publishes to the given subject, and flushes the connection. Returns an `anyhow::Result`.

## Usage Example

```rust
use crate::services::nats_connection_manager::NatsConnectionManager;
use crate::services::nats_message_publisher::NatsMessagePublisher;
use serde::Serialize;

#[derive(Serialize)]
struct TicketCreated {
    id: u64,
    title: String,
}

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let manager = NatsConnectionManager::new("nats://localhost:4222").await?;
    let publisher = NatsMessagePublisher::new(manager);

    let event = TicketCreated {
        id: 42,
        title: "Printer offline".to_string(),
    };

    publisher.publish("tickets.created", event).await?;
    Ok(())
}
```

## Notes

- The `flush()` call after `publish()` ensures the message is fully delivered before the function returns, which is important in short-lived tasks or batch operations.
- Errors at each step (serialization, client acquisition, publish, flush) are annotated with context via `anyhow` for clear diagnostics.
- Because `NatsMessagePublisher` is `Clone`, it can be cheaply shared across async tasks without wrapping in `Arc`.
