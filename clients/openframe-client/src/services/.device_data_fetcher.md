Provides basic device metadata retrieval for the OpenFrame agent, including hostname resolution, agent version, and OS type detection.

## Key Components

- **`DeviceDataFetcher`** — A zero-sized, cloneable struct that serves as the entry point for all device data queries.
  - `new()` / `Default` — Constructs a new instance.
  - `get_hostname() -> Option<String>` — Resolves the system hostname via the `hostname` crate; returns `None` and emits a warning on failure.
  - `get_agent_version() -> Option<String>` — Returns the agent version baked in at compile time via the `OPENFRAME_VERSION` environment variable.
  - `get_os_type() -> String` — Returns `"WINDOWS"` or `"MAC_OS"` based on the compile-time `target_os` flag.

## Usage Example

```rust
use crate::device_data_fetcher::DeviceDataFetcher;

let fetcher = DeviceDataFetcher::new();

if let Some(hostname) = fetcher.get_hostname() {
    println!("Hostname: {}", hostname);
}

if let Some(version) = fetcher.get_agent_version() {
    println!("Agent version: {}", version);
}

println!("OS type: {}", fetcher.get_os_type());
```

## Notes

- `get_agent_version` relies on the `OPENFRAME_VERSION` env var being set at **build time**; a missing variable will cause a compile error.
- OS detection is compile-time only — cross-compiled binaries will reflect the **target** OS, not the host.
- All methods are non-blocking and have no external I/O aside from hostname resolution.
