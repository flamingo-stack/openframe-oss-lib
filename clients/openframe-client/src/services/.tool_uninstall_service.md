Orchestrates the full lifecycle of tool uninstallation, handling process termination, command execution, filesystem cleanup, and registry removal for installed MSP tools.

## Key Components

### `UninstallOutcome`
An enum with two variants indicating the result of an uninstall attempt:
- `Removed` — tool was found and successfully uninstalled
- `NotInstalled` — tool was not present in the registry

### `ToolUninstallService`
The primary service struct holding injected dependencies:
- `installed_tools_service` — registry lookups and deletions
- `command_params_resolver` — resolves placeholder values in uninstall command args
- `tool_kill_service` — stops running tool processes
- `directory_manager` — resolves tool executable and data paths

### Public Methods

| Method | Description |
|---|---|
| `uninstall_by_tool_agent_id` | Uninstalls a single tool by ID; removes its directory and registry entry |
| `uninstall_all` | Iterates all installed tools and uninstalls each; continues on individual failures |

### Private Methods

| Method | Description |
|---|---|
| `uninstall_tool` | Core uninstall logic: stops processes, runs the uninstall command, cleans up |
| `stop_tool_process` | Delegates process termination to `ToolKillService` |
| `cleanup_tool_processes` | Kills any lingering processes by executable path post-uninstall |
| `cleanup_gui_app_bundle` | macOS-only: removes `.app` bundle for `GuiApp` installations |
| `cleanup_gui_app_autorun` | Windows-only: removes autorun registry entry for `GuiApp` installations |

## Usage Example

```rust
let service = ToolUninstallService::new(
    installed_tools_service,
    command_params_resolver,
    tool_kill_service,
    directory_manager,
);

// Uninstall a specific tool
match service.uninstall_by_tool_agent_id("fleet-agent").await? {
    UninstallOutcome::Removed => println!("Tool removed"),
    UninstallOutcome::NotInstalled => println!("Tool was not installed"),
}

// Uninstall all tools (e.g., during agent teardown)
service.uninstall_all().await?;
```

> **Note:** Fleet-based tools receive special handling — `osqueryd` is explicitly stopped before the main uninstall command runs, as it may not be cleanly managed by the Fleet uninstaller itself.
