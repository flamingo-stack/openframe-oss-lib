Manages the lifecycle of periodic machine heartbeat publishing, spawning an async background task that emits heartbeats on a fixed interval with timeout protection.

## Key Components

| Item | Description |
|------|-------------|
| `MachineHeartbeatRunManager` | Main struct holding a `MachineHeartbeatPublisher` instance |
| `new()` | Constructor accepting a `MachineHeartbeatPublisher` |
| `start()` | Spawns a Tokio background task that ticks every 60 seconds and publishes a heartbeat with a 30-second timeout |
| `HEARTBEAT_INTERVAL` | 60-second tick interval between heartbeat publishes |
| `HEARTBEAT_TIMEOUT` | 30-second per-publish timeout; logs a NATS disconnection warning on expiry |

## Usage Example

```rust
use crate::services::machine_heartbeat_publisher::MachineHeartbeatPublisher;
use crate::services::machine_heartbeat_run_manager::MachineHeartbeatRunManager;

let publisher = MachineHeartbeatPublisher::new(nats_client);
let manager = MachineHeartbeatRunManager::new(publisher);

// Spawns the background heartbeat loop — non-blocking
manager.start();
```

The background loop handles three outcomes per tick:

- **Success** — heartbeat published, continues silently
- **Publish error** — logs `"Failed to send heartbeat: {e}"`
- **Timeout** — logs `"Heartbeat timed out - NATS may be disconnected"`

The struct is `Clone`-able, allowing the publisher to be moved safely into the spawned async task without holding a reference across await points.
