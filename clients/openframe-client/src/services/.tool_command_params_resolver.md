Resolves placeholder variables in tool command arguments before execution, replacing client configuration tokens with runtime values such as server URL, machine ID, token paths, and dynamic asset paths.

## Key Components

### `ToolCommandParamsResolver` (struct)
Main resolver that holds references to `DirectoryManager`, `InitialConfigurationService`, and `AgentConfigurationService`.

### Constants (private placeholders)
| Placeholder | Resolves To |
|---|---|
| `${client.serverUrl}` | HTTPS server URL from initial config |
| `${client.openframeSecret}` | Hardcoded secret string |
| `${client.openframeTokenPath}` | Path to `shared_token.enc` |
| `${client.machineId}` | Machine ID from agent config |

### `ASSETS_PATH_REGEX` (static)
Lazy-compiled regex matching dynamic asset path patterns like `${client.assetPath.<name>}`.

### Methods
- **`new()`** — Constructor accepting the three service/manager dependencies.
- **`process(tool_agent_id, command_args)`** — Iterates over command arguments, resolving all standard and dynamic placeholders. Returns `Result<Vec<String>>`.
- **`build_token_path()`** — Builds the absolute path to the encrypted shared token file.
- **`process_assets_placeholders()`** — Uses `ASSETS_PATH_REGEX` to replace `${client.assetPath.<name>}` with the resolved executable asset path via `DirectoryManager::get_asset_path`.

## Usage Example

```rust
let resolver = ToolCommandParamsResolver::new(
    directory_manager,
    initial_configuration_service,
    agent_configuration_service,
);

let raw_args = vec![
    "--server=${client.serverUrl}".to_string(),
    "--token-path=${client.openframeTokenPath}".to_string(),
    "--osquery=${client.assetPath.osquery}".to_string(),
];

let resolved_args = resolver.process("my-tool-agent", raw_args)?;
// e.g. ["--server=https://example.com", "--token-path=/secure/shared_token.enc", "--osquery=/assets/my-tool-agent/osquery"]
```
