Manages the lifecycle termination of installed tool processes, providing graceful shutdown with automatic fallback to force kill and retry logic across GUI apps, standard executables, and system services.

## Key Components

| Item | Description |
|------|-------------|
| `ToolKillService` | Zero-field service struct (cloneable) that orchestrates all process stop operations |
| `stop_tool()` | Stops processes matching a tool's command pattern by `tool_id` |
| `stop_asset()` | Stops processes matching an asset's command pattern by `asset_id` + `tool_id` |
| `stop_installed_tool()` | Dispatches to the correct stop strategy based on `Installation` variant |
| `stop_for_installation()` | Core dispatch: handles `GuiApp`, `Standard`, and `Service` installation types |
| `is_installed_tool_running()` | Non-destructive check — returns `true` if any matching process is alive |
| `collect_matching_processes()` | Scans live processes via `sysinfo`, matching cmdline or exe path against patterns |
| `stop_process_with_retry()` | Orchestrates graceful → force kill → retry loop up to `MAX_KILL_RETRIES` |
| `try_graceful_stop()` | Sends default kill signal, waits up to `GRACEFUL_SHUTDOWN_TIMEOUT_SECS` |
| `try_force_kill()` | Sends `Signal::Kill`, waits up to `FORCE_KILL_TIMEOUT_SECS` |
| `wait_for_process_exit()` | Polls `sysinfo` every `PROCESS_CHECK_INTERVAL_MS` ms until PID disappears or timeout |

## Usage Example

```rust
use crate::services::tool_kill_service::ToolKillService;

let killer = ToolKillService::new();

// Stop all processes associated with a tool
killer.stop_tool("my-tool-agent-id").await?;

// Stop processes for a specific asset
killer.stop_asset("asset-123", "my-tool-agent-id").await?;

// Check if a tool is still running before taking action
if killer.is_installed_tool_running(&installed_tool).await {
    killer.stop_installed_tool(&installed_tool, true).await?;
}

// Dispatch based on installation type (GuiApp / Standard / Service)
killer
    .stop_for_installation("my-tool-agent-id", &installation, false)
    .await?;
```
