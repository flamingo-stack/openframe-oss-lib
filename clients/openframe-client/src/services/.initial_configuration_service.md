Manages reading, writing, and updating the device's initial configuration from a secured JSON file (`initial_config.json`). Provides typed accessors for individual config fields and supports mutating operations like updating or clearing the initial key.

## Key Components

**`InitialConfigurationService`** — Core service struct wrapping a path to the secured config file.

| Method | Description |
|---|---|
| `new(directory_manager)` | Constructs the service, resolving the config path and ensuring the secured directory exists |
| `get_initial_key()` | Returns the registration/initial key string |
| `get_server_url()` | Returns the server host URL |
| `is_local_mode()` | Returns whether the agent is running in local mode |
| `get_org_id()` | Returns the organization ID |
| `get_local_ca_cert_path()` | Returns the path to a local CA certificate |
| `get_tags()` | Returns the list of `DeviceTag` entries |
| `is_initial_key_missing()` | Returns `true` if the initial key is empty |
| `update_initial_key(key)` | Overwrites the initial key and persists the config |
| `clear_initial_key()` | Clears the initial key and persists the config |
| `save(config)` | Serializes and writes the full `InitialConfiguration` to disk |

The private `get()` method handles deserialization from disk and returns an error if the file does not yet exist.

## Usage Example

```rust
use crate::platform::directories::DirectoryManager;
use crate::services::InitialConfigurationService;

let dir_manager = DirectoryManager::new()?;
let svc = InitialConfigurationService::new(dir_manager)?;

// Read fields
let key = svc.get_initial_key()?;
let server = svc.get_server_url()?;
let tags = svc.get_tags()?;

// Update the initial key after first registration
svc.update_initial_key("new-reg-key-abc123".to_string())?;

// Clear the key once it has been consumed
svc.clear_initial_key()?;

println!("Registered against: {server}, org: {}", svc.get_org_id()?);
```
