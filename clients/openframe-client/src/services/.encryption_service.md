Provides AES-256-GCM symmetric encryption for string data, returning Base64-encoded ciphertext with a prepended random nonce.

## Key Components

- **`EncryptionService`** — A zero-sized, cloneable service struct that wraps AES-256-GCM encryption logic.
- **`EncryptionService::new()`** — Constructor; also available via `Default::default()`.
- **`EncryptionService::encrypt(&self, data: &str) -> Result<String>`** — Encrypts a plaintext string using AES-256-GCM with a 12-byte random nonce (via `OsRng`). Returns a Base64-encoded string of `[nonce (12 bytes) || ciphertext]`.
- **`KEY`** — Hardcoded 32-byte static key constant. ⚠️ Marked with a `TODO` to replace with a dynamically generated key before production use.

## Usage Example

```rust
use encryption_service::EncryptionService;

fn main() -> anyhow::Result<()> {
    let svc = EncryptionService::new();

    let plaintext = "sensitive-api-token";
    let encrypted = svc.encrypt(plaintext)?;

    // encrypted is Base64(nonce[12] || ciphertext)
    println!("Encrypted: {}", encrypted);

    Ok(())
}
```

## ⚠️ Security Notes

- The static key `"12345678901234567890123456789012"` is **not safe for production**. It must be replaced with a securely generated and stored key (e.g., from a KMS or environment secret).
- A fresh 12-byte nonce is generated per encryption call via `OsRng`, which is cryptographically secure.
- The `#![allow(deprecated)]` suppresses warnings from `aes-gcm 0.10`'s transitive dependency on `generic-array 0.x`; this should be removed once the upstream crate is updated.
