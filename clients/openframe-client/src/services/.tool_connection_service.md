Manages persistent storage of `ToolConnection` records in a JSON file located in the secured application directory, providing CRUD operations keyed on `tool_agent_id`.

## Key Components

| Item | Description |
|---|---|
| `ToolConnectionService` | Cloneable service struct holding the path to `tool_connections.json` |
| `new()` | Constructs the service, resolving the secured directory via `DirectoryManager` and ensuring it exists |
| `save()` | Upserts a `ToolConnection` — updates in place if `tool_agent_id` matches, otherwise appends |
| `get_all()` | Reads and deserializes all connections; returns an empty `Vec` if the file does not yet exist |
| `exists_by_tool_agent_id()` | Returns `true` if any stored connection matches the given `tool_agent_id` |
| `delete_by_tool_agent_id()` | Removes the matching connection and persists; returns `true` if a record was deleted |
| `persist()` | Private helper that serializes the full list to pretty-printed JSON and writes it atomically |

## Usage Example

```rust
use crate::platform::directories::DirectoryManager;
use crate::services::tool_connection_service::ToolConnectionService;
use crate::models::tool_connection::ToolConnection;

let dir_manager = DirectoryManager::new()?;
let svc = ToolConnectionService::new(dir_manager)?;

// Upsert a connection
let conn = ToolConnection {
    tool_agent_id: "agent-123".to_string(),
    // ...other fields
};
svc.save(conn).await?;

// Check existence
let found = svc.exists_by_tool_agent_id("agent-123").await?;

// List all
let all = svc.get_all().await?;

// Remove by ID
let deleted = svc.delete_by_tool_agent_id("agent-123").await?;
```

> **Storage:** All data is written to `<secured_dir>/tool_connections.json` as a pretty-printed JSON array. No database dependency is required.
