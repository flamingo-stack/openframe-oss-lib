Thin async service layer that wraps the low-level `execute_script` executor, maps its output into a structured `RmmResult`, and handles platform-specific execution guards.

## Key Components

| Item | Description |
|---|---|
| `ExecutionService` | Stateless, cloneable service struct (implements `Default`) |
| `execute()` | Async method that runs a script via `execute_script`, measures wall-clock time, and returns a fully populated `RmmResult` |
| Exit code `85` | Treated as a spawn/setup failure — promoted to the `error` field in addition to `stderr` |
| Timeout default | `timeout_secs = 0` is normalized to 900 seconds (15 min); otherwise capped at `u32::MAX` |
| Platform guard | Non-Unix/Windows targets receive an immediate `RmmResult` with exit code `85` and an "unsupported platform" error |

## Usage Example

```rust
use openframe_oss_lib::execution_service::ExecutionService;
use openframe_oss_lib::models::{ExecutionRequest, PrivilegeLevel, ScriptShell};

#[tokio::main]
async fn main() {
    let service = ExecutionService::new();

    let req = ExecutionRequest {
        execution_id: "exec-42",
        code: "#!/bin/sh\necho hello\n",
        shell: ScriptShell::Bash,
        privilege: PrivilegeLevel::User,
        args: &[],
        timeout_secs: 30,
        env_vars: vec![],
        script_id: Some("script-1"),
        schedule_id: None,
    };

    let result = service.execute(&req, "machine-abc").await;

    println!("stdout : {}", result.stdout);
    println!("exit   : {}", result.exit_code);
    println!("elapsed: {}ms", result.execution_time_ms);
}
```

## Error Mapping

| Condition | `exit_code` | `timed_out` | `error` field |
|---|---|---|---|
| Success | `0` | `false` | `None` |
| Script timeout | `98` | `true` | `None` |
| Spawn/setup failure | `85` | `false` | `Some(stderr)` |
| Unsupported platform | `85` | `false` | `Some("unsupported platform")` |
