Orchestrates the agent registration lifecycle, checking if the agent is already registered and retrying indefinitely until successful registration is achieved.

## Key Components

### `RegistrationProcessor` (struct)

A cloneable processor that coordinates between the registration and configuration services.

| Field | Type | Description |
|---|---|---|
| `registration_service` | `AgentRegistrationService` | Handles the actual registration API call |
| `config_service` | `AgentConfigurationService` | Reads/writes local agent configuration |

### Methods

- **`new(registration_service, config_service) -> Self`** — Constructs a new `RegistrationProcessor` with its required service dependencies.
- **`process() -> Result<()>`** — Entry point for registration. Skips if `machine_id` is already set; otherwise, enters a retry loop calling `attempt_registration()` every 60 seconds until success.
- **`attempt_registration() -> Result<AgentRegistrationResponse>`** *(private)* — Delegates to `AgentRegistrationService::register_agent()`, wrapping errors with additional context.

## Usage Example

```rust
let processor = RegistrationProcessor::new(
    registration_service,
    config_service,
);

// Skips silently if already registered;
// retries every 60s until successful otherwise.
processor.process().await?;
```

## Behavior Notes

- **Idempotent** — checks `machine_id` before attempting registration; safe to call on every startup.
- **Infinite retry** — loops with a fixed 60-second backoff on failure; no maximum retry cap.
- **Structured logging** — emits `tracing` events at `info` and `error` levels for observability.
