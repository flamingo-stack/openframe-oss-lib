Provides a local development TLS configuration provider that builds a `rustls` `ClientConfig` from a mkcert-generated CA certificate stored on disk.

## Key Components

### `LocalTlsConfigProvider`

A cloneable struct that wraps `InitialConfigurationService` to resolve and load a local CA certificate for NATS TLS connections.

| Method | Description |
|---|---|
| `new(initial_configuration_service)` | Constructs the provider with the given configuration service |
| `create_tls_config()` | Reads the PEM CA cert from disk and returns a `ClientConfig` with it added to the root store |
| `get_certificate_path()` (private) | Resolves and validates the CA cert file path from `InitialConfigurationService` |

**Error conditions handled:**
- `local_ca_cert_path` is empty or not set in initial configuration
- Cert file does not exist at the resolved path
- File read failure or PEM parse failure
- Certificate cannot be added to the root store

## Usage Example

```rust
use crate::services::InitialConfigurationService;
use crate::local_tls_config_provider::LocalTlsConfigProvider;

let config_service = InitialConfigurationService::new(/* ... */);
let tls_provider = LocalTlsConfigProvider::new(config_service);

let tls_config = tls_provider.create_tls_config()
    .expect("Failed to build local TLS config");

// Pass tls_config to your NATS client builder
let client = async_nats::ConnectOptions::new()
    .tls_client_config(tls_config)
    .connect("tls://localhost:4222")
    .await?;
```

> **Note:** This provider is intended for local development only. It trusts a single mkcert CA cert rather than the system root store. Do not use in production environments.
