Handles agent authentication flows, including initial authentication with client credentials, token refresh, and fallback re-authentication logic.

## Key Components

### `AgentAuthService`

A cloneable service struct that orchestrates authentication using three dependencies:

| Field | Type | Role |
|---|---|---|
| `auth_client` | `AuthClient` | Performs HTTP auth requests |
| `config_service` | `AgentConfigurationService` | Reads/writes credentials and tokens |
| `shared_token_service` | `SharedTokenService` | Propagates access tokens to shared state |

### Public Methods

- **`new(...)`** — Constructor; injects all three dependencies.
- **`authenticate_initial()`** — Performs first-time authentication using `client_id`/`client_secret` from config, then persists the resulting tokens.
- **`reauthenticate()`** — Attempts refresh token authentication first; falls back to client credentials if the refresh token is rejected (`401`/`403`) or absent.

### Private Methods

- **`try_refresh_token_authentication()`** — Fetches the stored refresh token and exchanges it for new tokens. Returns an error to trigger fallback on `401`/`403` responses.
- **`authenticate_with_client_credentials()`** — Re-authenticates using stored `client_id`/`client_secret`.
- **`save_tokens_to_config()`** — Persists `access_token` and `refresh_token` to both the config service and the shared token store.

## Usage Example

```rust
let auth_service = AgentAuthService::new(
    auth_client,
    config_service,
    shared_token_service,
);

// First-time authentication
let token = auth_service.authenticate_initial().await?;

// Subsequent calls — tries refresh token, falls back to client credentials
let token = auth_service.reauthenticate().await?;
```

> **Note:** The `401`/`403` fallback detection currently uses string matching on the error message. A [refactor is tracked](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/agent_auth_service.rs) to replace this with typed errors or status codes.
