Manages the lifecycle of tool processes, handling launching, monitoring, and session management across Windows and Unix platforms.

## Key Components

- **`get_active_user_session()`** *(Windows only)* — Detects the active Windows Terminal Services session, preferring RDP over Console sessions. Falls back from current process session to enumerated sessions when running as a service.
- **`launch_process_in_console_session()`** *(Windows only)* — Alternate launch path that spawns a process under the physical console session token using `CreateProcessAsUserW`. Retained for console-session use cases.
- **`launch_process_in_user_session()`** *(Windows only)* — Public entry point that resolves the active session and delegates to `launch_process_in_target_session`.
- **`launch_process_in_target_session()`** *(Windows only)* — Core Windows process launcher. Queries and duplicates the user token for the target session, builds a wide-char command line, and calls `CreateProcessAsUserW` with desktop context (`winsta0\default`).

Supporting services used by this module:
- `InstalledToolsService` — manages tool records and state
- `ToolCommandParamsResolver` — resolves executable paths and arguments
- `ToolKillService` — terminates running tool processes

## Usage Example

```rust
#[cfg(windows)]
use crate::services::tool_run_manager::launch_process_in_user_session;

// Launch a tool binary in the currently active user session
let command_path = "C:\\Tools\\my_tool.exe";
let args = vec!["--config".to_string(), "C:\\config.toml".to_string()];

match launch_process_in_user_session(command_path, &args) {
    Ok((pid, handle)) => {
        info!("Tool launched with PID: {}", pid);
        // Store handle for later cleanup via ToolKillService
    }
    Err(e) => error!("Failed to launch tool: {}", e),
}
```

> **Platform note:** Windows-specific functions use the Win32 API via the [`windows`](https://crates.io/crates/windows) crate. On non-Windows targets, process launching relies on `tokio::process::Command` with `RETRY_DELAY_SECONDS = 5` between restart attempts.
