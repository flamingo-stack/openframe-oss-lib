Handles downloading, extracting, and saving agent binaries from GitHub releases, with retry logic, size validation, and platform-aware archive format support (ZIP for Windows, tar.gz for others).

## Key Components

### `GithubDownloadService`
The main service struct holding an `reqwest::Client` and a `DmgExtractor`. Implements `Clone`.

### Primary Methods

| Method | Description |
|--------|-------------|
| `new(http_client, dmg_extractor)` | Constructor |
| `download_and_extract(config)` | Downloads archive and returns extracted binary bytes |
| `download_and_save(config, tool_folder_path, default_agent_path)` | Downloads, extracts, writes to disk; returns executable path for folder extractions |
| `find_config_for_current_os(configs)` | Selects the matching `DownloadConfiguration` for the current OS |

### Internal Methods

| Method | Description |
|--------|-------------|
| `download_with_retry(url)` | Retries up to `MAX_DOWNLOAD_RETRIES` with exponential backoff; falls back to jsDelivr CDN on HTTP 429 |
| `github_to_cdn_url(url)` | Converts a GitHub release URL to a jsDelivr CDN URL |
| `extract_from_zip(...)` | ZIP extraction (Windows only via `zip` crate) |
| `extract_from_tar_gz(...)` | tar.gz extraction (non-Windows via `flate2` + `tar` crates) |

## Usage Example

```rust
use reqwest::Client;

let client = Client::new();
let extractor = DmgExtractor::default();
let service = GithubDownloadService::new(client, extractor);

let configs = fetch_download_configurations().await?;
let config = service.find_config_for_current_os(&configs)?;

// Download and get raw bytes
let binary_bytes = service.download_and_extract(config).await?;

// Or download directly to disk
let exe_path = service
    .download_and_save(config, &tool_folder_path, &default_agent_path)
    .await?;
```

## Platform Behavior

| Platform | Archive Format | Fallback on 429 |
|----------|---------------|-----------------|
| Windows | `.zip` | jsDelivr CDN |
| macOS / Linux | `.tar.gz` / `.tgz` | jsDelivr CDN |

Configuration constants (`DOWNLOAD_TIMEOUT_SECS`, `MAX_DOWNLOAD_RETRIES`, `MIN_BINARY_SIZE_BYTES`) are sourced from `crate::config::update_config`.
