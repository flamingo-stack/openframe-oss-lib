Manages persistent storage of installed tools using a JSON file, providing async-safe CRUD operations with atomic writes to prevent data corruption.

## Key Components

**`InstalledToolsService`** — Core service struct with two fields:
- `file_path: PathBuf` — Path to `installed_tools.json` in the secured directory
- `writer: Arc<Mutex<()>>` — Async mutex guard ensuring serialized write access

**Public Methods**

| Method | Description |
|---|---|
| `new(directory_manager)` | Initializes service, resolves file path, ensures secured directory exists |
| `save(tool)` | Upserts an `InstalledTool` by `tool_agent_id` |
| `set_state(tool_agent_id, state)` | Updates a tool's `ToolRecordState`; returns `false` if not found |
| `get_by_tool_agent_id(tool_id)` | Fetches a single tool by ID |
| `get_all()` | Reads and deserializes all tools from disk; returns empty vec if file absent |
| `delete_by_tool_agent_id(tool_agent_id)` | Removes a tool entry; returns `false` if not found |

**Private Methods**

- `persist(tools)` — Writes JSON to a `.json.tmp` file, fsyncs, then atomically renames to the target path to guarantee crash-safe writes

## Usage Example

```rust
use crate::platform::directories::DirectoryManager;
use crate::services::InstalledToolsService;
use crate::models::{InstalledTool, ToolRecordState};

let dir_manager = DirectoryManager::new()?;
let service = InstalledToolsService::new(dir_manager)?;

// Upsert a tool
service.save(InstalledTool {
    tool_agent_id: "agent-123".to_string(),
    // ...other fields
}).await?;

// Update state
let updated = service.set_state("agent-123", ToolRecordState::Active).await?;

// Lookup
let tool = service.get_by_tool_agent_id("agent-123").await?;

// Remove
let removed = service.delete_by_tool_agent_id("agent-123").await?;
```

> **Note:** All write operations acquire the async mutex before reading and re-persisting, preventing race conditions under concurrent access.
