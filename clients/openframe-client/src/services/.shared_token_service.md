Manages secure storage of a shared authentication token by encrypting it and writing it atomically to a secured directory on disk.

## Key Components

- **`SharedTokenService`** — Cloneable service struct that composes a `DirectoryManager` for path resolution and an `EncryptionService` for token encryption.
- **`new(dir_manager, encryption_service)`** — Constructor that initializes the service with its two dependencies.
- **`update(token)`** — Encrypts the provided token string and atomically writes it to `<secured_dir>/shared_token.enc`, returning `Result<()>`.

## Usage Example

```rust
use crate::services::{SharedTokenService, EncryptionService};
use crate::platform::directories::DirectoryManager;

let dir_manager = DirectoryManager::new()?;
let encryption_service = EncryptionService::new(secret_key);
let token_service = SharedTokenService::new(dir_manager, encryption_service);

// Persist a new token securely
token_service.update("my-auth-token".to_string())?;
```

> The token is written via `atomic_write`, ensuring no partial writes are visible to other processes even if the operation is interrupted. The encrypted file is stored in the platform's secured directory, isolating it from unprivileged access.

## Notes

- The output file is always named `shared_token.enc` and located in the secured directory resolved by `DirectoryManager`.
- `SharedTokenService` is `Clone`, making it safe to share across threads or service boundaries that require ownership.
