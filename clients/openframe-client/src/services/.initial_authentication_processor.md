Handles the initial authentication flow for an agent, checking for an existing access token and entering a retry loop if none is found.

## Key Components

### `InitialAuthenticationProcessor`

A cloneable struct that orchestrates the startup authentication process using two injected services:

| Field | Type | Role |
|---|---|---|
| `auth_service` | `AgentAuthService` | Performs the actual authentication handshake |
| `config_service` | `AgentConfigurationService` | Reads persisted configuration (e.g., existing tokens) |

### Methods

- **`new(auth_service, config_service) -> Self`** — Constructor; injects both service dependencies.
- **`process() -> Result<()>`** — Public entry point. Skips authentication if a token already exists; otherwise enters a blocking retry loop with a 60-second delay between attempts.
- **`attempt_authentication() -> Result<()>`** — Private helper that delegates to `AgentAuthService::authenticate_initial()`, wrapping errors with context.

## Usage Example

```rust
let processor = InitialAuthenticationProcessor::new(
    auth_service,
    config_service,
);

processor.process().await?;
```
