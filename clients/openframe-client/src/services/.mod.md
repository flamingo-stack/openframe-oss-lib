The services module root for the OpenFrame OSS agent, declaring and re-exporting all service components that handle agent lifecycle, tool management, NATS messaging, authentication, and update workflows.

## Key Components

### Authentication & Registration
- `AgentAuthService` — Handles agent authentication flows
- `AgentRegistrationService` — Manages agent registration with the platform
- `InitialKeyService` — Bootstraps initial cryptographic keys
- `SharedTokenService` / `TokenRefreshRunManager` — Token lifecycle management
- `EncryptionService` — Cryptographic operations

### NATS Messaging
- `NatsConnectionManager` — Manages NATS broker connections
- `NatsMessagePublisher` — Publishes messages to NATS subjects
- `InstalledAgentMessagePublisher` / `ToolConnectionMessagePublisher` — Typed message publishers

### Tool Management
- `ToolInstallationService` / `ToolUninstallService` — Install and remove managed tools
- `ToolRunManager` / `ToolRestartService` / `ToolKillService` — Tool process lifecycle
- `ToolConnectionService` / `ToolConnectionProcessingManager` — Tool connectivity
- `ToolCommandParamsResolver` / `ToolUrlParamsResolver` — Parameter resolution

### Heartbeat & Health
- `MachineHeartbeatPublisher` / `MachineHeartbeatRunManager` — Periodic health signals
- `MeshSelfHealService` — Detects and recovers mesh connectivity issues
- `LastKnownGoodService` — Tracks last stable configuration state

### Updates
- `UpdateHandlerService` / `UpdateStateService` / `UpdateCleanupService` — Update pipeline stages
- `OpenFrameClientUpdateService` / `ToolAgentUpdateService` — Component-specific update logic
- `GithubDownloadService` — Fetches release artifacts from GitHub

## Usage Example

```rust
use crate::services::{
    NatsConnectionManager,
    AgentAuthService,
    ToolRunManager,
    MachineHeartbeatRunManager,
};

// Compose services during agent startup
let nats = NatsConnectionManager::new(&config).await?;
let auth = AgentAuthService::new(&nats, &config);
let heartbeat = MachineHeartbeatRunManager::new(&nats);
let runner = ToolRunManager::new(&nats, &config);
```
