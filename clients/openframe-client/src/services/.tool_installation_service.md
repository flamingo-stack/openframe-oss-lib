Orchestrates the full lifecycle of tool installation for the OpenFrame agent, handling install, reinstall, and uninstall operations including binary downloading, command execution, process management, and state tracking.

## Key Components

- **`ToolInstallationService`** — Central service struct managing tool install/uninstall workflows, composed of clients, resolvers, and sub-services
- **`install()`** — Public entry point; acquires a per-tool async lock, marks the tool as updating, delegates to `install_inner`, then clears the updating flag
- **`install_inner()`** — Core installation logic covering:
  - Reinstall path: stops running processes, runs uninstall commands, kills directory-locking child processes, removes the existing tool folder
  - Fresh install path: downloads binaries (GitHub or agent file client), sets Unix executable permissions, runs install commands
  - State persistence via `InstalledToolsService`
- **`TOOL_COMMAND_TIMEOUT_SECS`** (`300`) — Hard timeout for external install/uninstall commands; prevents hung installers from blocking the client self-update defer marker indefinitely

## Usage Example

```rust
let svc = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Trigger install from a deserialized AMQP/queue message
svc.install(tool_installation_message).await?;
```

The service is `Clone` and designed to be shared across async tasks. Per-tool locking in `install()` ensures concurrent install messages for the same `tool_agent_id` are serialized safely.
