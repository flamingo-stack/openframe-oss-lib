Orchestrates the construction and persistence of the agent's `InitialConfiguration` during installation, including optional local CA certificate resolution via `mkcert` for local mode deployments.

## Key Components

### `InstallationInitialConfigService`
The primary service struct wrapping `InitialConfigurationService`. Constructed via `new()` with a `DirectoryManager` dependency.

**Methods:**
- `new(directory_manager: DirectoryManager) -> Result<Self>` — Initializes the service with the underlying config service.
- `build_and_save(params: InstallConfigParams) -> Result<()>` — Validates required fields, builds an `InitialConfiguration`, optionally resolves the `mkcert` CA root path, and persists the config to disk.

### `InstallConfigParams`
Parameter bag passed to `build_and_save`. All string fields are `Option<String>` and validated as non-empty at runtime.

| Field | Type | Description |
|---|---|---|
| `server_url` | `Option<String>` | Required. Target server URL |
| `initial_key` | `Option<String>` | Required. Initial enrollment key |
| `org_id` | `Option<String>` | Required. Organization identifier |
| `local_mode` | `bool` | Enables local TLS CA resolution |
| `tags` | `Vec<String>` | Device tags parsed via `DeviceTag::parse_from_cli` |

## Usage Example

```rust
use crate::services::InstallationInitialConfigService;
use crate::services::InstallConfigParams;
use crate::platform::DirectoryManager;

let dir_manager = DirectoryManager::new()?;
let svc = InstallationInitialConfigService::new(dir_manager)?;

svc.build_and_save(InstallConfigParams {
    server_url: Some("https://openframe.example.com".to_string()),
    initial_key: Some("ik_abc123".to_string()),
    org_id:      Some("org_xyz".to_string()),
    local_mode:  true,   // triggers mkcert -CAROOT resolution
    tags:        vec!["env:prod".to_string(), "region:us-east".to_string()],
})?;
```

> **Local mode note:** When `local_mode` is `true`, the service shells out to `mkcert -CAROOT` and expects `rootCA.pem` to exist at the returned path. Ensure `mkcert` is installed and its CA has been initialized before calling `build_and_save`.
