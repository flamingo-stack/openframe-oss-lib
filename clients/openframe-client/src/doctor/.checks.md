Pre-installation check functions for the OpenFrame client installer, validating arguments, permissions, disk, and network connectivity before proceeding with setup.

## Key Components

| Function | Category | Description |
|---|---|---|
| `check_required_args` | `Command` | Validates `--serverUrl`, `--initialKey`, and `--orgId` are present |
| `check_admin_privileges` | `Admin` | Verifies the process is running as root/Administrator |
| `check_dir_writable` | `Disk` | Probes a path (or nearest ancestor) for write access |
| `check_disk_space` | `Disk` | Ensures a mount point has at least `min_mb` MB free |
| `check_service_config_writable` | `Disk` | Writable check on the OS-specific service config dir |
| `check_dns_resolve` | `Network` | Resolves the server hostname via the system resolver |
| `check_tcp_connect` | `Network` | Attempts a 5-second TCP connection to port 443 |
| `check_tls_handshake` | `Network` | Issues an HTTPS GET to verify TLS succeeds |
| `check_websocket_upgrade` | `Network` | Sends a WebSocket upgrade request to `/ws/nats` |
| `check_proxy_env` | `Network` | Detects `HTTP_PROXY` / `HTTPS_PROXY` environment variables |

All functions return `CheckResult` (pass / warn / fail / info); `check_websocket_upgrade` and `check_tls_handshake` are `async`.

## Usage Example

```rust
use crate::preflight::checks::*;
use crate::installation_initial_config_service::InstallConfigParams;

async fn run_preflight(params: &InstallConfigParams) {
    // Synchronous checks
    let args   = check_required_args(params);
    let admin  = check_admin_privileges();
    let disk   = check_disk_space(std::path::Path::new("/opt/openframe"), 500);
    let dns    = check_dns_resolve(params.server_url.as_deref().unwrap_or(""));
    let tcp    = check_tcp_connect(params.server_url.as_deref().unwrap_or(""));
    let proxy  = check_proxy_env(); // Returns Option<CheckResult>

    // Async network checks
    let tls = check_tls_handshake(params.server_url.as_deref().unwrap_or("")).await;
    let ws  = check_websocket_upgrade(params.server_url.as_deref().unwrap_or("")).await;

    for result in [args, admin, disk, dns, tcp, tls, ws] {
        println!("{:?}", result);
    }
}
```

> **Platform note:** `check_service_config_writable` resolves to `/Library/LaunchDaemons` on macOS, `/etc/systemd/system` on Linux, and `%ProgramFiles%\OpenFrame\bin` on Windows.
