Provides the core diagnostic framework for the OpenFrame agent's `doctor` subsystem, defining check result types, a report aggregator, and orchestrating pre-install and post-install health check pipelines.

## Key Components

- **`CheckCategory`** — Enum classifying checks by domain: `Command`, `Admin`, `Disk`, `Network`
- **`CheckStatus`** — Enum representing check outcomes: `Pass`, `Fail`, `Warn`, `Info`
- **`CheckResult`** — Structured result of a single check with convenience constructors (`pass`, `fail`, `warn`, `info`) that attach optional hint strings
- **`DoctorReport`** — Aggregates a `Vec<CheckResult>` with helpers `has_failures()`, `failure_count()`, `warn_count()`, and `print()` for human-readable terminal output
- **`run_preinstall()`** — Async pipeline validating CLI args, admin privileges, disk writability (bin dir, app support, secured, logs), and network reachability before installation
- **`run_healthcheck()`** — Async pipeline reading `initial_config.json` from the secured directory, verifying `server_host`, then running network checks against the configured server
- **`run_network_checks()`** — Internal helper running DNS, TCP, TLS, WebSocket, and proxy environment checks in sequence, short-circuiting on DNS failure

## Usage Example

```rust
use crate::doctor::{run_preinstall, run_healthcheck};
use crate::installation_initial_config_service::InstallConfigParams;

// Pre-install check
let params = InstallConfigParams { server_url: Some("https://openframe.example.com".into()), .. };
let report = run_preinstall(&params).await;
report.print();
if report.has_failures() {
    eprintln!("{} failure(s) detected", report.failure_count());
    std::process::exit(1);
}

// Post-install health check
let health = run_healthcheck().await;
health.print();
```
