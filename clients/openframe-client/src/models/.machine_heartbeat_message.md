Represents an empty heartbeat message payload sent by a machine to signal liveness, where the machine identity is derived from the MQTT topic name and the timestamp is generated server-side.

## Key Components

- **`MachineHeartbeatMessage`** — A zero-field struct implementing `Serialize`, `Deserialize`, and `Default`, used as the JSON body of a machine heartbeat event.

## Usage Example

```rust
use openframe_oss_lib::MachineHeartbeatMessage;

// Construct a new heartbeat message
let heartbeat = MachineHeartbeatMessage::new();

// Or via Default trait
let heartbeat: MachineHeartbeatMessage = Default::default();

// Serialize to JSON (produces `{}`)
let json = serde_json::to_string(&heartbeat).unwrap();
assert_eq!(json, "{}");
```

> **Note:** The serialized payload is always an empty JSON object (`{}`). Machine identity and event timestamp are not embedded in the message body — they are inferred from the MQTT topic and assigned by the receiving service respectively.
