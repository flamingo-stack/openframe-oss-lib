Defines the data structures for tracking OpenFrame client version state and update lifecycle, used for serialization and state management across the update pipeline.

## Key Components

### `ClientUpdateStatus` (enum)
Represents the current update state of the OpenFrame client binary.

| Variant | Description |
|---|---|
| `Current` | No update needed (default) |
| `Updating` | Update in progress |
| `Updated` | Update completed successfully |
| `Failed` | Update attempt failed |

Serializes to lowercase strings via `serde(rename_all = "lowercase")`.

### `OpenFrameClientInfo` (struct)
Holds full version and update metadata for the OpenFrame client.

| Field | Type | Description |
|---|---|---|
| `current_version` | `String` | Currently installed version |
| `target_version` | `Option<String>` | Version being updated to, if any |
| `status` | `ClientUpdateStatus` | Current update lifecycle state |
| `binary_path` | `String` | Filesystem path to the client binary |
| `last_update_check` | `Option<String>` | Timestamp of last update check |
| `last_updated` | `Option<String>` | Timestamp of last successful update |

## Usage Example

```rust
use openframe_oss_lib::openframe_client_info::{ClientUpdateStatus, OpenFrameClientInfo};

let info = OpenFrameClientInfo {
    current_version: "1.2.0".to_string(),
    target_version: Some("1.3.0".to_string()),
    status: ClientUpdateStatus::Updating,
    binary_path: "/usr/local/bin/openframe".to_string(),
    last_update_check: Some("2025-01-15T10:00:00Z".to_string()),
    last_updated: None,
};

// Serialize to JSON for transport or storage
let json = serde_json::to_string(&info).unwrap();
```
