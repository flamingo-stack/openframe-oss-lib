Defines the message structures for communicating tool agent update payloads, including version information and downloadable asset configurations.

## Key Components

- **`ToolAgentUpdateMessage`** — Top-level update message carrying a tool agent's ID, version string, required download configurations, and an optional list of asset updates.
- **`AssetUpdate`** — Describes an individual asset within an update, including its ID, optional version, executable flag (defaults to `false`), and optional per-asset download configurations.

Both structs derive `Debug`, `Clone`, `Serialize`, and `Deserialize`, with `camelCase` field renaming for JSON interop.

## Usage Example

```rust
use openframe_oss_lib::tool_agent_update_message::{AssetUpdate, ToolAgentUpdateMessage};
use openframe_oss_lib::download_configuration::DownloadConfiguration;

let update = ToolAgentUpdateMessage {
    tool_agent_id: "agent-123".to_string(),
    version: "1.2.0".to_string(),
    download_configurations: vec![DownloadConfiguration {
        url: "https://cdn.example.com/agent-123-v1.2.0.tar.gz".to_string(),
        checksum: Some("sha256:abc123".to_string()),
    }],
    assets: Some(vec![AssetUpdate {
        asset_id: "plugin-xyz".to_string(),
        version: Some("0.5.1".to_string()),
        executable: true,
        download_configurations: None,
    }]),
};

let json = serde_json::to_string(&update).unwrap();
// Serializes to camelCase JSON:
// {"toolAgentId":"agent-123","version":"1.2.0",...}
```
