Represents a deserialized message payload used to trigger a restart of a specific tool agent, identified by its unique ID.

## Key Components

- **`ToolRestartMessage`** — A deserializable struct carrying the target agent identifier for restart operations.
  - `tool_agent_id: String` — The unique ID of the tool agent to restart.

## Usage Example

```rust
use serde_json::json;

let payload = json!({ "toolAgentId": "agent-42" });
let msg: ToolRestartMessage = serde_json::from_value(payload).unwrap();

println!("Restarting agent: {}", msg.tool_agent_id);
```

> The struct uses `camelCase` deserialization, so JSON keys like `"toolAgentId"` map to the `tool_agent_id` field.
