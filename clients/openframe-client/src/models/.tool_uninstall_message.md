Defines the `ToolUninstallMessage` struct used to deserialize incoming requests for uninstalling a tool agent by its identifier.

## Key Components

- **`ToolUninstallMessage`** — A deserializable message struct containing the target tool agent's ID, deserialized from camelCase JSON fields.

## Usage Example

```rust
use serde_json::json;
use crate::tool_uninstall_message::ToolUninstallMessage;

let payload = json!({ "toolAgentId": "agent-42" });
let msg: ToolUninstallMessage = serde_json::from_value(payload).unwrap();

println!("Uninstalling agent: {}", msg.tool_agent_id);
```
