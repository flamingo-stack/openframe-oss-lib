Represents the server response payload returned after successfully registering an agent, deserializing the camelCase JSON fields into a Rust struct.

## Key Components

- **`AgentRegistrationResponse`** — Public struct containing the three fields returned by the registration endpoint:
  - `machine_id` — Unique identifier assigned to the registered machine
  - `client_id` — OAuth/API client identifier for the agent
  - `client_secret` — Secret credential used for subsequent authenticated requests

## Usage Example

```rust
use serde_json;
use crate::AgentRegistrationResponse;

let json = r#"{
    "machineId": "machine-abc123",
    "clientId": "client-xyz789",
    "clientSecret": "s3cr3t"
}"#;

let response: AgentRegistrationResponse = serde_json::from_str(json).unwrap();
println!("Registered machine: {}", response.machine_id);
```

## Notes

- Uses `#[serde(rename_all = "camelCase")]` to automatically map camelCase JSON keys (e.g., `machineId`) to Rust snake_case fields (e.g., `machine_id`).
- `client_secret` is sensitive — avoid logging or persisting it beyond its intended use scope.
