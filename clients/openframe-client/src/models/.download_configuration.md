Defines the `DownloadConfiguration` struct and `InstallationType` enum used to describe how a versioned asset should be fetched and installed for a specific operating system.

## Key Components

### `InstallationType` (enum)
Serializes as `SCREAMING_SNAKE_CASE`. Variants:
- `Standard` *(default)* — plain binary/file install
- `GuiApp` — macOS/desktop GUI application
- `Service` — system service (daemon)

### `DownloadConfiguration` (struct)
Holds all metadata for a downloadable asset. Key fields:
| Field | Description |
|---|---|
| `os` | Target OS string (e.g., `"windows"`, `"macos"`, `"linux"`) |
| `file_name` | Source archive or binary filename |
| `target_file_name` | Destination filename; also accepts aliases `agentFileName` / `assetFileName` |
| `link` | Download URL |
| `installation_type` | How the asset is installed (defaults to `Standard`) |
| `bundle_id` | Optional macOS bundle identifier |
| `service_name` | Optional service name for `Service` installs |

### Methods
- **`is_folder_extraction()`** — Returns `true` when `target_file_name` contains a path separator, indicating a full archive extraction is needed rather than a single file copy.
- **`with_version_override(original, override_version)`** — Returns a cloned config with the download URL rewritten to substitute a version string. Emits a `tracing::warn` if the original version string is not found in the link.
- **`matches_current_os()`** — Case-insensitive comparison of `self.os` against the compile-time target OS.

## Usage Example

```rust
let config = DownloadConfiguration {
    os: "linux".to_string(),
    file_name: "agent-1.2.0.tar.gz".to_string(),
    target_file_name: "bin/agent".to_string(),
    link: "https://releases.example.com/agent/1.2.0/agent-1.2.0.tar.gz".to_string(),
    installation_type: InstallationType::Service,
    bundle_id: None,
    service_name: Some("agent-svc".to_string()),
};

// Rewrite URL for a pinned version
let pinned = config.with_version_override("1.2.0", "1.3.1");

// Full archive extraction required because target path has components
assert!(config.is_folder_extraction()); // true — "bin/agent" has 2 components

// Only process on matching OS
if config.matches_current_os() {
    // proceed with download
}
```
