Defines the `AgentConfiguration` struct used to store agent identity and OAuth credentials for authenticating with the OpenFrame platform.

## Key Components

- **`AgentConfiguration`** — Primary configuration struct with the following fields:
  - `machine_id` — Unique identifier for the agent machine
  - `client_id` — OAuth client ID
  - `client_secret` — OAuth client secret
  - `access_token` — Current OAuth access token
  - `refresh_token` — OAuth refresh token for obtaining new access tokens

Derives `Debug`, `Clone`, `Serialize`, `Deserialize`, `PartialEq`, and `Default`.

## Usage Example

```rust
use openframe_oss_lib::AgentConfiguration;

// Create a default (empty) configuration
let config = AgentConfiguration::default();

// Populate with credentials
let config = AgentConfiguration {
    machine_id: "machine-abc123".to_string(),
    client_id: "my-client-id".to_string(),
    client_secret: "my-client-secret".to_string(),
    access_token: "eyJhbGci...".to_string(),
    refresh_token: "dGhpcyBp...".to_string(),
};

// Serialize to JSON (e.g., for persisting to disk)
let json = serde_json::to_string(&config)?;
```

## Notes

- Sensitive fields (`client_secret`, `access_token`, `refresh_token`) should be handled carefully and never logged in production.
- The `Default` derive produces an instance with all fields set to empty strings, useful for initialization before credentials are loaded.
