Root module for the OpenFrame OSS library's models, aggregating and re-exporting all data structures used for agent lifecycle management, tool orchestration, and device communication.

## Key Components

### Execution Types
- `ExecutionMessage`, `ExecutionRequest`, `CommandMessage`, `ScriptMessage` — message types for remote command/script execution
- `RmmResult`, `ScriptEnvVar`, `ScriptShell`, `PrivilegeLevel` — execution context and result types

### Agent Lifecycle
- `AgentConfiguration` — runtime configuration for an agent instance
- `AgentRegistrationRequest` / `AgentRegistrationResponse` — agent onboarding handshake
- `AgentTokenResponse` — authentication token issued after registration
- `InitialConfiguration` — bootstrap config delivered at first startup
- `InstalledAgentMessage` — reports installed agent state to the platform

### Tool Management
- `InstalledTool`, `InstalledAsset`, `Installation`, `ToolRecordState` — installed tool inventory
- `ToolInstallationMessage`, `ToolInstallationResult` — install request/response flow
- `ToolUninstallMessage`, `ToolRestartMessage` — tool lifecycle control
- `ToolAgentUpdateMessage`, `AssetUpdate` — tool update payloads
- `ToolConnection`, `ToolConnectionMessage` — tool connectivity state
- `ToolVersionOverrides` — pin or override tool versions

### Device & Heartbeat
- `MachineHeartbeatMessage` — periodic health/presence signal from a managed device
- `DeviceTag` — metadata tag attached to a device
- `OpenFrameClientInfo`, `OpenFrameClientUpdateMessage` — client version and update tracking
- `UpdateState`, `UpdatePhase` — tracks progress through an update workflow
- `DownloadConfiguration`, `InstallationType` — artifact download parameters
