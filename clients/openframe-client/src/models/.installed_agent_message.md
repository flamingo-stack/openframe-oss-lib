Defines a serializable message struct representing an installed agent's identity, used for agent registration or status reporting.

## Key Components

- **`InstalledAgentMessage`** — Public struct with `camelCase` JSON serialization containing:
  - `agent_type: String` — The type/category of the installed agent
  - `version: String` — The agent's version string

## Usage Example

```rust
use openframe_oss_lib::InstalledAgentMessage;

let msg = InstalledAgentMessage {
    agent_type: "monitoring".to_string(),
    version: "1.2.0".to_string(),
};

let json = serde_json::to_string(&msg).unwrap();
// Output: {"agentType":"monitoring","version":"1.2.0"}
```
