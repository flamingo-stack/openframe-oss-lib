Represents the result returned after a tool installation operation, containing the identifier of the newly created tool agent.

## Key Components

- **`ToolInstallationResult`** — A serializable/deserializable struct holding the outcome of a tool installation, with a single field:
  - `tool_agent_id: String` — The unique identifier assigned to the installed tool agent.

## Usage Example

```rust
use serde_json;
use crate::tool_installation_result::ToolInstallationResult;

// Deserialize from a JSON response
let json = r#"{"tool_agent_id": "agent-abc123"}"#;
let result: ToolInstallationResult = serde_json::from_str(json).unwrap();

println!("Installed tool agent ID: {}", result.tool_agent_id);

// Serialize back to JSON
let serialized = serde_json::to_string(&result).unwrap();
```

## Notes

- Derives `Debug`, `Serialize`, and `Deserialize` via [`serde`](https://serde.rs), making it compatible with JSON and other serde-supported formats out of the box.
- Typically consumed after calling a tool installation API endpoint to retrieve the resulting agent identifier for subsequent operations.
