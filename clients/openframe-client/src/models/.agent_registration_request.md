Defines the serializable request payload for registering an agent with the OpenFrame platform.

## Key Components

- **`AgentRegistrationRequest`** — A serializable struct representing the agent registration request body, serialized to camelCase JSON.

| Field | Type | Notes |
|---|---|---|
| `hostname` | `String` | The agent's hostname |
| `agent_version` | `String` | Version string of the running agent |
| `organization_id` | `String` | Optional; omitted from JSON if empty |
| `os_type` | `String` | Operating system type identifier |
| `tags` | `Vec<DeviceTag>` | Optional; omitted from JSON if empty |

## Usage Example

```rust
use openframe_oss_lib::AgentRegistrationRequest;

let request = AgentRegistrationRequest {
    hostname: "workstation-01".to_string(),
    agent_version: "1.2.3".to_string(),
    organization_id: "org_abc123".to_string(),
    os_type: "linux".to_string(),
    tags: vec![],
};

let json = serde_json::to_string(&request)?;
// → {"hostname":"workstation-01","agentVersion":"1.2.3","organizationId":"org_abc123","osType":"linux"}
```

> `organization_id` and `tags` are skipped in serialization when empty, keeping the payload minimal for unauthenticated or untagged registrations.
