Represents a device tag as a key with one or more associated values, used for filtering and categorizing devices in the OpenFrame platform.

## Key Components

### `DeviceTag`

A serializable struct with two fields:

- `key` — tag name (e.g., `"site"`, `"env"`)
- `values` — one or more values associated with that key

### `DeviceTag::parse_from_cli`

Parses a flat list of `"key=value"` strings (typically from CLI arguments) into a `Vec<DeviceTag>`, grouping multiple values under the same key. Invalid entries are silently skipped:

- Missing `=` separator → ignored
- Empty key or value (including whitespace-only) → ignored

## Usage Example

```rust
use openframe_oss_lib::device_tag::DeviceTag;

let raw_tags = vec![
    "site=CHICAGO".to_string(),
    "site=NEW YORK".to_string(),
    "env=production".to_string(),
    "invalid_no_equals".to_string(), // skipped
    "empty=".to_string(),            // skipped
];

let tags = DeviceTag::parse_from_cli(raw_tags);

// tags.len() == 2
// tags[0] => DeviceTag { key: "site", values: ["CHICAGO", "NEW YORK"] }
// tags[1] => DeviceTag { key: "env",  values: ["production"] }
```

## Notes

- Multiple `"key=value"` entries sharing the same key are merged into a single `DeviceTag` with multiple `values`.
- Implements `Serialize`/`Deserialize` (serde), `Clone`, `Debug`, and `PartialEq`.
