Defines the core data structures for tracking installed tools, their installation types, and associated assets within the OpenFrame tool management system.

## Key Components

### `Installation` (enum)
Represents three distinct installation modes with serde `tag = "type"` serialization:
- **`Standard`** — CLI/binary tool with an optional executable path
- **`GuiApp`** — GUI application with a required executable path and optional macOS `bundle_id`
- **`Service`** — System service with a required `service_name` and optional executable path

**Methods:**
- `executable_path() -> Option<&str>` — Unified accessor for the executable path across all variants
- `is_standard()`, `is_gui_app()`, `is_service()` — Variant type guards

### `InstalledAsset` (struct)
Represents a downloaded or installed artifact tied to a tool, with an `id`, `version`, and an `executable` flag.

### `ToolRecordState` (enum)
Tracks installation lifecycle: `Installing` or `Installed` (default).

### `InstalledTool` (struct)
The top-level record describing a fully installed tool, including runtime invocation args, uninstallation args, installation metadata, assets, and state.

## Usage Example

```rust
use openframe_oss_lib::installed_tool::{InstalledTool, Installation, ToolRecordState};

let tool = InstalledTool {
    tool_agent_id: "agent-123".to_string(),
    tool_id: "my-tool".to_string(),
    tool_type: "cli".to_string(),
    version: "1.0.0".to_string(),
    run_command_args: vec!["--config".to_string(), "default".to_string()],
    installation: Installation::Service {
        service_name: "my-tool-svc".to_string(),
        executable_path: Some("/usr/bin/my-tool".to_string()),
    },
    state: ToolRecordState::Installed,
    ..Default::default()
};

assert!(tool.installation.is_service());
assert_eq!(tool.installation.executable_path(), Some("/usr/bin/my-tool"));
```
