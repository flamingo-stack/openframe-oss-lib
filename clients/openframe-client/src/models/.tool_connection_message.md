Defines a serializable message structure for communicating tool connection details between agents and tools within the OpenFrame system.

## Key Components

- **`ToolConnectionMessage`** — A plain data struct representing a tool connection payload, with `Debug`, `Serialize`, and `Deserialize` derives. Fields are serialized using camelCase (`toolType`, `agentToolId`).
  - `tool_type: String` — Identifies the category or kind of tool being connected.
  - `agent_tool_id: String` — The unique identifier of the tool instance assigned to an agent.

## Usage Example

```rust
use openframe_oss_lib::tool_connection_message::ToolConnectionMessage;
use serde_json;

let msg = ToolConnectionMessage {
    tool_type: "browser".to_string(),
    agent_tool_id: "agent-42-tool-7".to_string(),
};

// Serialize to JSON (fields will be camelCase)
let json = serde_json::to_string(&msg).unwrap();
// {"toolType":"browser","agentToolId":"agent-42-tool-7"}

// Deserialize from JSON
let parsed: ToolConnectionMessage = serde_json::from_str(&json).unwrap();
assert_eq!(parsed.tool_type, "browser");
```

## Notes

- The `#[serde(rename_all = "camelCase")]` attribute ensures compatibility with JSON APIs and JavaScript/TypeScript consumers expecting camelCase keys.
- This struct is intentionally minimal — a pure data transfer object (DTO) with no business logic.
