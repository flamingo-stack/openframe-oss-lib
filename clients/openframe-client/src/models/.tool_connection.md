Represents a bidirectional connection between a tool and an agent, tracking the relationship identifiers and publication state.

## Key Components

- **`ToolConnection`** — Core struct linking a tool to an agent with the following fields:
  - `tool_agent_id`: The agent's identifier from the tool's perspective
  - `agent_tool_id`: The tool's identifier from the agent's perspective
  - `published`: Whether the connection is active/published

Derives `Debug`, `Clone`, `Serialize`, `Deserialize`, `PartialEq`, `Eq`, and `Default`.

## Usage Example

```rust
use openframe_oss_lib::tool_connection::ToolConnection;

// Create a new tool connection
let connection = ToolConnection {
    tool_agent_id: "agent-123".to_string(),
    agent_tool_id: "tool-456".to_string(),
    published: true,
};

// Default (unpublished, empty IDs)
let default_conn = ToolConnection::default();
assert_eq!(default_conn.published, false);

// Serialize to JSON
let json = serde_json::to_string(&connection).unwrap();
```

## Notes

- The dual-ID design (`tool_agent_id` / `agent_tool_id`) supports bidirectional lookup without additional join tables.
- `published: false` by default ensures connections are inactive until explicitly activated.
