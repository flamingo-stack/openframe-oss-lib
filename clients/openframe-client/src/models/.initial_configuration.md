Defines the `InitialConfiguration` struct used to bootstrap device registration and connection settings for the OpenFrame OSS library.

## Key Components

### `InitialConfiguration`
A serializable/deserializable configuration struct with the following fields:

| Field | Type | Description |
|---|---|---|
| `server_host` | `String` | Hostname or URL of the target server |
| `initial_key` | `String` | Authentication key used during initial device registration |
| `local_mode` | `bool` | Enables local-only operation without remote server communication |
| `org_id` | `String` | Optional organization identifier (defaults to empty string) |
| `local_ca_cert_path` | `String` | Optional path to a local CA certificate for TLS verification |
| `tags` | `Vec<DeviceTag>` | Optional list of tags to associate with the device on registration |

Fields marked with `#[serde(default)]` (`org_id`, `local_ca_cert_path`, `tags`) are optional in the serialized form and fall back to their `Default` values if absent.

## Usage Example

```rust
use openframe_oss_lib::InitialConfiguration;

let config = InitialConfiguration {
    server_host: "https://openframe.example.com".to_string(),
    initial_key: "my-registration-key".to_string(),
    local_mode: false,
    org_id: "org-abc123".to_string(),
    local_ca_cert_path: "/etc/ssl/certs/my-ca.pem".to_string(),
    tags: vec![],
};

// Or use Default for optional fields
let minimal_config = InitialConfiguration {
    server_host: "https://openframe.example.com".to_string(),
    initial_key: "my-registration-key".to_string(),
    ..Default::default()
};
```
