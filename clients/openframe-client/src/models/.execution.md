Defines the core data types and abstractions for script and command execution in the OpenFrame RMM agent, including message deserialization, execution request construction, and result serialization.

## Key Components

- **`ScriptShell`** — Enum of supported execution environments (`Powershell`, `Cmd`, `Bash`, `Python`, `Nushell`, `Shell`); `as_param()` returns the CLI invocation string.
- **`PrivilegeLevel`** — Enum specifying `User` or `Admin` execution context; defaults to `Admin` when omitted.
- **`ScriptEnvVar`** — Environment variable entry with optional `secret` flag for masking sensitive values.
- **`ScriptMessage`** — Deserialized inbound message for scheduled/identified script executions; carries `script_id`, `schedule_id`, args, env vars, and timeout.
- **`CommandMessage`** — Lightweight inbound message for ad-hoc command execution; no env vars or args.
- **`RmmResult`** — Serialized execution outcome sent back to the platform; `error`, `script_id`, and `schedule_id` are omitted from JSON when `None`.
- **`ExecutionRequest`** — Unified, shell-agnostic execution descriptor built from either message type.
- **`ExecutionMessage` trait** — Common interface over `ScriptMessage` and `CommandMessage`; provides `from_payload`, `execution_id`, `to_request`, and `schedule_id`.

## Usage Example

```rust
use execution::{ExecutionMessage, ScriptMessage};

// Deserialize an inbound MQTT/queue payload
let msg = ScriptMessage::from_payload(r#"{
    "executionId": "exec-123",
    "machineId": "mac-456",
    "scriptId": "scr-789",
    "code": "Get-Process",
    "shell": "POWERSHELL",
    "privilegeLevel": "ADMIN",
    "args": ["-v"],
    "timeoutSeconds": 60,
    "envVars": [{"name": "API_KEY", "value": "secret", "secret": true}]
}"#).unwrap();

// Convert to a shell-runner-agnostic request
let req = msg.to_request();
println!("Shell param: {}", req.shell.as_param()); // "powershell"
println!("Timeout: {}s", req.timeout_secs);        // 60
println!("Env: {:?}", req.env_vars);               // ["API_KEY=secret"]
```
