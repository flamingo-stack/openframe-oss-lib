Provides compile-time version override lookups for OpenFrame OSS tool components, resolving pinned version strings from environment variables via Cargo features.

## Key Components

### `lookup(tool_key: &str) -> Option<&'static str>`

Matches a tool identifier string against conditionally compiled feature flags, returning the associated version string baked in at build time. Returns `None` if no override is configured for the given key.

| Tool Key | Feature Flag | Env Variable |
|---|---|---|
| `openframe-chat` | `openframe-chat-version` | `OPENFRAME_CHAT_VERSION` |
| `meshcentral-server` | `meshcentral-agent-version` | `MESHCENTRAL_AGENT_VERSION` |
| `fleetmdm-server` | `fleetmdm-agent-version` | `FLEETMDM_AGENT_VERSION` |
| `osqueryd` | `osquery-version` | `OSQUERY_VERSION` |

## Usage Example

```rust
// Resolves a pinned version at runtime (set at compile time)
if let Some(version) = tool_version_overrides::lookup("osqueryd") {
    println!("Using pinned osquery version: {}", version);
} else {
    println!("No version override; using default resolution");
}
```

To activate an override, enable the feature and set the env var during build:

```bash
OSQUERY_VERSION=5.12.1 cargo build --features osquery-version
```

## Notes

- All version strings are resolved via `env!()`, making them **compile-time constants** — the build will fail if a feature is enabled without its corresponding environment variable set.
- The `#[allow(unused_variables)]` attribute suppresses warnings when no features are enabled and `tool_key` goes unused.
- Source: [`tool_version_overrides.rs`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/tool_version_overrides.rs)
