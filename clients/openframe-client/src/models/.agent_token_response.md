Defines the deserialized response structure for agent authentication token exchanges, mapping camelCase JSON fields to Rust snake_case fields.

## Key Components

- **`AgentTokenResponse`** — Public struct representing the token payload returned after an agent authenticates. Derives `Debug`, `Clone`, `Serialize`, and `Deserialize`, with automatic camelCase JSON mapping.

| Field | Type | Description |
|---|---|---|
| `access_token` | `String` | Bearer token for authenticating API requests |
| `refresh_token` | `String` | Token used to obtain a new access token |
| `token_type` | `String` | Token scheme (e.g., `"Bearer"`) |
| `expires_in` | `Option<i64>` | Token lifetime in seconds; `None` if not provided |

## Usage Example

```rust
use serde_json;
use openframe_oss_lib::AgentTokenResponse;

let json = r#"{
    "accessToken": "eyJhbGci...",
    "refreshToken": "dGhpcyBp...",
    "tokenType": "Bearer",
    "expiresIn": 3600
}"#;

let token_response: AgentTokenResponse = serde_json::from_str(json)?;

println!("Token type: {}", token_response.token_type);

if let Some(expires) = token_response.expires_in {
    println!("Expires in {} seconds", expires);
}
```
