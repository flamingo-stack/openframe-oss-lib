Provides the Linux-specific implementation stub for launching the application updater, currently returning an unimplemented error with a systemd fallback recommendation.

## Key Components

- **`launch_updater(params: UpdaterParams) -> Result<()>`** — Async function intended to handle Linux updater launches. Currently a stub that logs an info message and returns an error directing users to use systemd for service restarts.

## Usage Example

```rust
use crate::updater::linux::launch_updater;
use crate::updater::UpdaterParams;

let params = UpdaterParams { /* ... */ };
match launch_updater(params).await {
    Ok(_) => println!("Updater launched"),
    Err(e) => eprintln!("Linux updater error: {}", e),
    // Output: "Linux updater not yet implemented. Use systemd service restart instead."
}
```
