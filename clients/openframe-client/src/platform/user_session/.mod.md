Platform-specific OS utilities module that conditionally compiles and re-exports macOS system functions for user session and process management.

## Key Components

| Export | Description |
|---|---|
| `get_console_user` | Retrieves the currently logged-in console user |
| `is_gui_session_ready` | Checks whether a GUI session is available and ready |
| `is_process_running` | Determines if a given process is currently running |
| `launch_as_user` | Launches a process in the context of a specific user |

All exports are gated behind `#[cfg(target_os = "macos")]` and sourced from the `macos` submodule.

## Usage Example

```rust
#[cfg(target_os = "macos")]
use crate::os::{get_console_user, is_gui_session_ready, is_process_running, launch_as_user};

#[cfg(target_os = "macos")]
fn main() {
    if let Some(user) = get_console_user() {
        println!("Console user: {}", user);
    }

    if is_gui_session_ready() {
        launch_as_user("my_app", &["--flag"]);
    }

    if is_process_running("Finder") {
        println!("Finder is running");
    }
}
```

> **Note:** This module and all its exports are only available on macOS. Code using these APIs must be guarded with `#[cfg(target_os = "macos")]` to compile on other platforms.
