macOS-specific utilities for detecting the console user and launching processes in their GUI session context.

## Key Components

### `ConsoleUser`
A debug-cloneable struct holding the `username` (string) and `uid` (u32) of the currently logged-in console user.

### Public Functions

| Function | Description |
|---|---|
| `get_console_user()` | Reads `/dev/console` ownership via `stat` to identify the active GUI user; filters out root and system accounts (prefixed `_`). Returns `None` if no regular user is at the console. |
| `launch_as_user()` | Launches an executable in the console user's session. Tries `launchctl asuser` first, falls back to `sudo -u`. Validates the executable path before attempting launch. |
| `is_gui_session_ready()` | Checks whether the user's GUI session is fully initialized by verifying both `Dock` and `Finder` are running under the given UID. |
| `is_process_running()` | Uses `pgrep -f` to check if a process matching the given executable path is already running. Logs PIDs if found. |

### Private Helpers

- **`launch_via_launchctl()`** — Prefers `open -a <app.bundle>` for `.app` bundles; falls back to direct `launchctl asuser` for plain executables.
- **`launch_via_sudo()`** — Spawns the executable via `sudo -u <username>` as a last resort.
- **`extract_app_bundle_path()`** — Walks path ancestors to find the nearest `.app` bundle containing the executable.

## Usage Example

```rust
use macos::{get_console_user, is_gui_session_ready, launch_as_user};

async fn start_agent() -> anyhow::Result<()> {
    let user = get_console_user().ok_or_else(|| anyhow::anyhow!("No console user"))?;

    // Wait until Dock + Finder are up before launching
    if !is_gui_session_ready(user.uid).await {
        anyhow::bail!("GUI session not ready for UID {}", user.uid);
    }

    let args = vec!["--background".to_string()];
    let child = launch_as_user("/Applications/MyAgent.app/Contents/MacOS/MyAgent", &args, &user).await?;

    println!("Launched with PID: {:?}", child.id());
    Ok(())
}
```
