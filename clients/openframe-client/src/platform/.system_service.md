Cross-platform service lifecycle management for macOS (launchctl), Linux (systemctl), and Windows (SCM/WinAPI), providing start, stop, verification, and install-readiness checks.

## Key Components

| Function | Platform | Description |
|---|---|---|
| `start_service` | macOS/Linux/Windows | Starts a named service via the platform-native manager; Windows variant retries transient failures up to `SERVICE_START_MAX_ATTEMPTS` |
| `stop_service` | All | Stops a service with graceful SCM stop → force-kill fallback; `allow_delete` gates SCM delete of wedged services (install paths only) |
| `verify_service_running` | Windows (no-op elsewhere) | Confirms a freshly installed service reached `RUNNING`, starting it if left stopped |
| `service_clear_for_install` | Windows (always `true` elsewhere) | Returns `true` if the service is absent or `Stopped`, gating reinstall safety |
| `stop_service_windows` *(internal)* | Windows | SCM stop with configurable timeout, falls back to `force_stop_service_windows` |
| `force_stop_service_windows` *(internal)* | Windows | `taskkill /F /T /PID` loop up to `SERVICE_FORCE_KILL_MAX_ATTEMPTS` |
| `wait_for_service_running_windows` *(internal)* | Windows | Polls SCM until `ServiceState::Running` or timeout |
| `try_start_service_windows` *(internal)* | Windows | Single SCM start attempt; treats `ERROR_SERVICE_ALREADY_RUNNING` as success |

## Usage Example

```rust
use openframe_oss_lib::system_service::{
    start_service, stop_service, verify_service_running, service_clear_for_install,
};

// During install: allow SCM delete of wedged service
stop_service("my-agent-svc", true).await?;

// Guard against reinstalling over a live service
if !service_clear_for_install("my-agent-svc").await {
    anyhow::bail!("Service is still running; cannot reinstall");
}

// Register + start
start_service("my-agent-svc").await?;

// Confirm RUNNING (Windows-critical; no-op on macOS/Linux)
verify_service_running("my-agent-svc").await?;

// During update/restore: never allow SCM delete
stop_service("my-agent-svc", false).await?;
```

> **`allow_delete` safety rule:** pass `true` only from install/reinstall/uninstall flows that re-register the service afterward. Update and restore paths must pass `false`—a SCM delete without re-registration leaves the service permanently broken.
