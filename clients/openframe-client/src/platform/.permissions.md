Cross-platform file permission management and privilege elevation utilities for Unix, macOS, Windows, and Linux targets.

## Key Components

### `PermissionError`
An enum covering all error cases: `Io`, `InvalidMode`, `InvalidPath`, `AdminCheckFailed`, `ElevationRequired`, and `CommandFailed`. Implements `std::error::Error` and converts from `io::Error`.

### `Permissions`
A struct wrapping a Unix-style octal `mode` value with methods:
- `directory()` — returns mode `0o755`
- `file()` — returns mode `0o644`
- `apply(&Path)` — sets permissions on a path (Unix: `PermissionsExt`; Windows: readonly flag)
- `verify(&Path)` — checks current permissions match the stored mode
- `from_path(&Path)` — reads permissions from an existing path

### `PermissionUtils`
A stateless utility struct for privilege management:
- `is_admin()` — checks if the current process has root/admin rights (Unix: `geteuid`, Windows: `is_elevated`)
- `ensure_admin()` — requests elevation if not already privileged:
  - **macOS**: `osascript` with administrator privileges prompt
  - **Linux**: `pkexec` with `sudo` fallback
  - **Windows**: `ShellExecuteW` with `runas` UAC verb

### `ADMIN_PRIVILEGES_GRANTED`
A static `AtomicBool` that caches successful privilege elevation within a session to avoid redundant prompts.

## Usage Example

```rust
use std::path::Path;

// Apply standard file permissions
let perms = Permissions::file();
perms.apply(Path::new("/etc/openframe/config.toml"))?;

// Verify permissions match expected mode
let ok = perms.verify(Path::new("/etc/openframe/config.toml"))?;

// Ensure admin before privileged operations
PermissionUtils::ensure_admin()?;

// Read permissions from an existing path
let existing = Permissions::from_path(Path::new("/usr/local/bin/openframe"))?;
println!("Current mode: {:o}", existing.mode);
```
