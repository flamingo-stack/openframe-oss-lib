Root module for the `platform` crate, aggregating all platform-specific and cross-platform OS utilities used by the OpenFrame toolchain for installation, updates, and system management.

## Key Components

| Module | Description |
|---|---|
| `binary_writer` | Write and set executable permissions on binaries |
| `console` | Terminal/console configuration utilities |
| `directories` | Directory management and app bundle operations |
| `dmg_extractor` | macOS DMG archive extraction |
| `file_acl` | File access control list management |
| `file_lock` | Windows file lock detection and reporting |
| `installation_detector` | Detect existing tool installations |
| `machine_info_persistence` | Persist machine metadata to disk |
| `permissions` | Cross-platform capability and permission model |
| `system_service` | OS-level service management |
| `tool_updater` | Core update/migration orchestration |
| `uninstall` | Clean uninstallation helpers |
| `update_scripts` | Scripted update hooks |
| `updater_launcher` | Launch the updater process |
| `user_session` | User session detection and management |
| `powershell` *(Windows)* | Locate and invoke PowerShell |
| `preferences_writer` *(macOS)* | Write macOS preference files |
| `windows_cleanup` *(Windows)* | Post-install/uninstall cleanup |
| `windows_path_migration` *(Windows)* | PATH environment migration |

## Usage Example

```rust
use platform::{
    DirectoryManager,
    PermissionUtils,
    detect_actual_installation,
    create_updater,
    UpdateContext,
    run_update,
};

// Detect whether a tool is already installed
let installation = detect_actual_installation(&install_dir)?;

// Build and run an update
let updater = create_updater(deps);
run_update(&updater, &UpdateContext::default()).await?;

// Adjust permissions on a written binary
platform::write_executable(&dest_path, &binary_bytes)?;
platform::set_executable_permissions(&dest_path)?;

// Windows-only: check if a file is locked
#[cfg(target_os = "windows")]
{
    use platform::{get_locking_processes, format_locking_processes};
    if let Ok(procs) = get_locking_processes(&path) {
        eprintln!("{}", format_locking_processes(&procs));
    }
}
```

## Notes

- Platform-gated modules (`powershell`, `preferences_writer`, `windows_cleanup`, `windows_path_migration`) are compiled only for their respective targets via `#[cfg(target_os)]`.
- Commonly used types and functions are re-exported at the crate root for ergonomic imports.
