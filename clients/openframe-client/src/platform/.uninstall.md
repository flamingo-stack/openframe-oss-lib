Handles the uninstallation of the OpenFrame client service across Windows, macOS, and Linux platforms, including service removal, tool cleanup, and directory deletion with retry/force-removal logic.

## Key Components

- **`orbit_dir()`** — Returns the platform-specific Orbit installation path (`C:\Program Files\Orbit` on Windows, `/opt/orbit` on Unix).
- **`remove_directory_with_retry(path, max_retries)`** — Async function that attempts directory removal with exponential backoff, file unlocking on the penultimate attempt, and a final force-removal fallback.
- **`unlock_directory_files(path)`** — Platform-specific helper; uses `attrib -R -S -H /S /D` on Windows and `chmod -R 777` on Unix to clear locks before retrying removal.
- **`force_remove_directory(path)`** — Last-resort deletion using `cmd /C rd /S /Q` (Windows) or `rm -rf` (Unix), with post-command existence checks and timing delays.
- **`uninstall_integrated_tools(dir_manager)`** — Initializes the full service chain (`InstalledToolsService`, `InitialConfigurationService`, `AgentConfigurationService`, `ToolCommandParamsResolver`, `ToolKillService`, `ToolUninstallService`) and calls `uninstall_all()`.
- **`uninstall_windows(dir_manager, install_path)`** — Orchestrates the full Windows uninstall sequence: stop/remove service → uninstall tools → clean up logs, app-support, and Orbit directories → launch binary cleanup script.

## Usage Example

```rust
use std::path::Path;
use crate::uninstall::{uninstall_integrated_tools, remove_directory_with_retry, orbit_dir};

// Remove a directory with up to 5 attempts and exponential backoff
remove_directory_with_retry(Path::new("/opt/orbit/data"), 5).await?;

// Uninstall all managed tools using the directory manager
uninstall_integrated_tools(&dir_manager).await?;

// Get platform-specific Orbit directory
let orbit_path = orbit_dir(); // "/opt/orbit" on Linux/macOS

// Full Windows uninstall flow
#[cfg(target_os = "windows")]
uninstall_windows(&dir_manager, Path::new("C:\\Program Files\\OpenFrame\\client.exe")).await?;
```
