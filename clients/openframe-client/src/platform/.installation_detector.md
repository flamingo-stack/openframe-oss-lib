Detects whether a tool is already installed on the host system by inspecting platform-specific service registrations, returning structured `Installation` metadata if found.

## Key Components

### `detect_actual_installation`
Public entry point that dispatches detection logic based on the tool's `InstallationType`:
- `Service` → delegates to `detect_service`
- `GuiApp` / `Standard` → returns `None` (not yet implemented)

### `detect_service` (private)
Platform-conditional service detection:
- **macOS** — checks for a `.plist` file under `/Library/LaunchDaemons/`
- **Windows** — calls `crate::platform::system_service::service_exists`
- **Linux/other Unix** — no-op, always returns `None`

On a positive match, resolves the executable path via `DirectoryManager::get_tool_executable_path` and returns an `Installation::Service` variant.

## Usage Example

```rust
let config = DownloadConfiguration {
    installation_type: InstallationType::Service,
    service_name: Some("com.example.myagent".to_string()),
    target_file_name: "myagent".to_string(),
    // ...
};

let dir_manager = DirectoryManager::new();

if let Some(existing) = detect_actual_installation("my-tool", &config, &dir_manager) {
    match existing {
        Installation::Service { service_name, executable_path } => {
            println!("Found service '{}' at {:?}", service_name, executable_path);
        }
        _ => {}
    }
}
```

## Notes

- Linux service detection (e.g., systemd) is currently unimplemented — the stub explicitly silences unused-variable warnings with a destructuring no-op.
- `GuiApp` and `Standard` installation types are reserved for future detection strategies.
