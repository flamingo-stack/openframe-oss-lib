Async utility for writing binary executable files to disk with cross-platform permission handling and locked-file recovery.

## Key Components

### `write_executable(bytes: &[u8], path: &Path) -> Result<()>`
Writes raw bytes to a path as an executable file. Handles the full lifecycle:
- Creates parent directories if missing
- On first `File::create` failure, attempts lock/permission recovery via `crate::platform::file_acl::ensure_writable`
- **Windows-specific:** Renames the existing locked file to `.old` before retrying creation
- Calls `set_executable_permissions` after a successful write

### `set_executable_permissions(path: &Path) -> Result<()>`
Sets `0o755` permissions on the target file.
- **Unix:** Reads current metadata, applies `rwxr-xr-x` mode via `PermissionsExt`
- **Non-Unix:** No-op (suppresses unused variable warning)

## Usage Example

```rust
use std::path::Path;

let binary_bytes = std::fs::read("/tmp/source_binary").unwrap();
let target = Path::new("/usr/local/bin/my-tool");

write_executable(&binary_bytes, target).await?;
// Parent dirs created, bytes written, chmod 755 applied
```

## Notes

- All I/O is async via `tokio::fs` and `tokio::io::AsyncWriteExt`
- Locked-file recovery on Windows depends on `crate::platform::file_acl::ensure_writable`
- Logs progress and warnings via `tracing` (`info!`, `warn!`)
- Errors are enriched with path context using `anyhow::Context`
