Writes macOS application preferences using the `defaults` CLI tool, executing commands as the current console user via `sudo`. On non-macOS platforms, the `write` function is a no-op.

## Key Components

- **`write(bundle_id, prefs)`** — Iterates over key-value pairs and writes each to the specified bundle's preference domain by invoking `sudo -u <user> defaults write`. Resolves the active console user via `get_console_user()`. Returns an error if any `defaults write` command fails or exits with a non-zero status.
- **`args_to_pairs(args)`** — Utility that converts CLI-style `--key value` or boolean flag `--flag` arguments into `(&str, &str)` pairs. Boolean flags (no following value) are mapped to `"1"`.

## Usage Example

```rust
use crate::platform::preferences_writer::{write, args_to_pairs};

// Write preferences directly
write(
    "com.example.MyApp",
    [("serverUrl", "https://api.example.com"), ("devMode", "0")],
)?;

// Or convert CLI args first
let args = vec![
    "--serverUrl".to_string(),
    "https://api.example.com".to_string(),
    "--devMode".to_string(),
];
let pairs = args_to_pairs(&args);
// pairs => [("serverUrl", "https://api.example.com"), ("devMode", "1")]

write("com.example.MyApp", pairs)?;
```

## Notes

- macOS only: `write` is conditionally compiled with `#[cfg(target_os = "macos")]`; all other platforms receive a silent no-op.
- Requires `sudo` access to write preferences on behalf of the console user.
