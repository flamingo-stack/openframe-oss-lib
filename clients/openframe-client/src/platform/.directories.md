Cross-platform directory management for the OpenFrame agent, providing a unified API for resolving, creating, and securing platform-specific application directories on Windows, macOS, and Linux.

## Key Components

### Enums
- **`DirectoryError`** — Error variants for directory operations: `CreateFailed`, `PermissionDenied`, `ValidationFailed`, `FixFailed`, `HomeDirectoryNotFound`. Implements `From<PermissionError>` for ergonomic conversion.

### Free Functions
- **`get_app_support_directory()`** — Returns the OS-specific app support path (`ProgramData\OpenFrame`, `/Library/Application Support/OpenFrame`, `/var/lib/openframe`).
- **`get_logs_directory()`** — Returns the logs path, respecting the `OPENFRAME_LOG_DIR` environment variable override before falling back to OS defaults.
- **`get_secured_directory()`** — Returns the admin/root-only secured directory path.
- **`set_directory_permissions(path)`** — Applies standard `755` permissions (macOS/Linux) or system defaults (Windows).
- **`set_secured_directory_permissions(path)`** — Applies restrictive `700` permissions on Linux; relies on system defaults elsewhere.

### Struct: `DirectoryManager`
The primary interface for directory lifecycle management.

| Constructor | Description |
|---|---|
| `new()` | Default platform-specific paths |
| `with_custom_dirs(logs, app, secured)` | Override all three paths |
| `with_user_logs_dir()` | Adds a per-user logs path alongside system paths |
| `for_development()` | All paths point to user directories to avoid permission errors |

## Usage Example

```rust
use openframe_lib::platform::directories::DirectoryManager;

// Production setup
let mgr = DirectoryManager::new();

// Development setup (no elevated permissions required)
let dev_mgr = DirectoryManager::for_development();

// Custom paths for testing
let test_mgr = DirectoryManager::with_custom_dirs(
    PathBuf::from("/tmp/openframe/logs"),
    PathBuf::from("/tmp/openframe/app"),
    PathBuf::from("/tmp/openframe/secured"),
);
```

> Set `OPENFRAME_LOG_DIR` to override the default log directory at runtime without recompiling.
