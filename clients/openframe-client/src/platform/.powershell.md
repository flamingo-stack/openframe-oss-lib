Provides Windows-only utilities for locating a valid PowerShell executable, either via `PATH` resolution or fallback to known filesystem locations.

## Key Components

- **`get_powershell_path() -> Result<String, &'static str>`** *(pub, `#[cfg(windows)]`)*
  Entry point that first attempts to invoke `powershell.exe` from `PATH`. If that fails, delegates to `find_powershell_path()` and converts the result to a `String`.

- **`find_powershell_path() -> Option<PathBuf>`** *(private, `#[cfg(windows)]`)*
  Checks a prioritized list of known PowerShell install locations using environment variables (`SystemRoot`, `ProgramFiles`, `ProgramFiles(x86)`) with hardcoded fallbacks. Covers both Windows PowerShell 5.x (`powershell.exe`) and PowerShell 7+ (`pwsh.exe`).

## Usage Example

```rust
#[cfg(windows)]
fn main() {
    match get_powershell_path() {
        Ok(path) => {
            println!("Found PowerShell at: {}", path);
            // Use `path` with std::process::Command
            std::process::Command::new(&path)
                .arg("-NoProfile")
                .arg("-Command")
                .arg("Get-Date")
                .spawn()
                .expect("Failed to launch PowerShell");
        }
        Err(e) => eprintln!("Error: {}", e),
    }
}
```

## Notes

- Both functions are **Windows-only** (`#[cfg(windows)]`); calling code should gate usage accordingly.
- The `PATH` probe spawns a no-op process (`exit 0`) to confirm executability rather than relying solely on filesystem presence.
- Searched locations in order: `System32`, `SysWOW64`, hardcoded `C:\Windows` fallbacks, then PowerShell 7 under `ProgramFiles` and `ProgramFiles(x86)`.
