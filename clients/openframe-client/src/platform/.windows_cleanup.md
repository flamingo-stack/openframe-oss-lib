Generates and executes a self-deleting PowerShell cleanup script that removes the OpenFrame binary, empties installation directories, and updates the system `PATH` after the current process exits on Windows.

## Key Components

### `generate_binary_cleanup_script`

```rust
pub fn generate_binary_cleanup_script(
    install_path: &Path,
    current_pid: u32,
    bin_dir: Option<&PathBuf>,
) -> String
```

Produces a PowerShell script string that:

- **Waits** up to 30 seconds for the parent process (by PID) to exit, with forced termination as a fallback
- **Deletes the binary** with up to 5 retries and exponential backoff; escalates to `takeown`/`icacls` if standard removal fails
- **Prunes directories** — removes the `bin` dir and its parent OpenFrame dir if empty after binary deletion
- **Removes from system PATH** — edits `HKLM` registry, preserving `REG_EXPAND_SZ` type, and broadcasts `WM_SETTINGCHANGE` so running processes pick up the update

### `execute_binary_cleanup_script`

```rust
pub fn execute_binary_cleanup_script(
    install_path: &Path,
    bin_dir: Option<&PathBuf>,
) -> Result<()>
```

Orchestrates script execution:

1. Resolves the current PID via `std::process::id()`
2. Writes the generated script to a UUID-named temp file (`openframe_binary_cleanup_<uuid>.ps1`)
3. Spawns PowerShell detached with `CREATE_NO_WINDOW`, `-ExecutionPolicy Bypass`, and no stdin/stdout/stderr — fire-and-forget

## Usage Example

```rust
use std::path::PathBuf;

let install_path = PathBuf::from(r"C:\\Program Files\\OpenFrame\\bin\\openframe.exe");
let bin_dir = PathBuf::from(r"C:\\Program Files\\OpenFrame\\bin");

// Spawn the cleanup script — runs in background after this process exits
execute_binary_cleanup_script(&install_path, Some(&bin_dir))?;
```

> **Note:** On non-Windows targets the script is spawned via `powershell.exe` (useful for cross-compilation testing), but the registry and PATH logic inside the script is Windows-specific.
