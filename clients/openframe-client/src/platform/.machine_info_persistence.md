Persists machine identity (`machine_id` + `client_secret`) across uninstall/reinstall cycles using platform-native storage, with secure permissions enforced on every write.

## Key Components

- **`PersistedMachineInfo`** — Serializable struct holding `machine_id` and `client_secret`. Implements a custom `Debug` that redacts `client_secret` to prevent accidental secret leakage in logs.
- **`write(info)`** — Validates completeness, then delegates to a platform-specific `write_impl`. Errors if either field is empty.
- **`read()`** — Reads persisted credentials; auto-repairs permissions on `PermissionDenied` and retries once. Returns `Ok(None)` when no store exists (fresh install), `Ok(Some(...))` on success, or `Err` on corrupt/inaccessible stores.
- **`is_permission_denied(err)`** — Walks the `anyhow` error chain to detect `io::ErrorKind::PermissionDenied`.

### Platform Storage Backends

| OS | Storage | Key/Path | Permissions |
|---|---|---|---|
| Windows | `HKLM\SOFTWARE\OpenFrame` | `MachineInfo` (REG_SZ) | DACL: Administrators + SYSTEM only |
| macOS | `/Library/Preferences/com.openframe.client.plist` | `MachineInfo` | `0o600` (owner read/write) |
| Linux | `/etc/openframe/machine.json` | whole file | dir `0o700`, file `0o600` |

## Usage Example

```rust
use machine_info_persistence::{PersistedMachineInfo, read, write};

// On first install — persist new credentials
let info = PersistedMachineInfo {
    machine_id: "mach-abc123".to_string(),
    client_secret: "s3cr3t".to_string(),
};
write(&info)?;

// On reinstall — recover existing credentials
match read()? {
    Some(info) => println!("Reusing machine_id: {}", info.machine_id),
    None => println!("No prior record found; performing fresh install"),
}
```
