Defines the tool migration framework for transitioning installed tools between different installation types (e.g., `Standard` → `GuiApp`).

## Key Components

- **`MigrationContext`** — Shared state passed between migration phases; tracks whether the old installation was cleaned up (`old_cleaned`) and whether the tool needs to be restarted (`needs_start`).
- **`ToolMigrator` trait** — Async trait defining the four-phase migration lifecycle:
  - `prepare` — pre-flight checks and context setup
  - `migrate` — performs the actual installation type change
  - `finalize` — post-migration cleanup and validation
  - `rollback` — best-effort recovery on failure (logs a warning by default; implementors should override)
- **`create_migrator`** — Factory function that inspects the current `Installation` and target `InstallationType`, returning the appropriate `Arc<dyn ToolMigrator>` or `None` if no migration is needed. Currently supports `Standard → GuiApp` on macOS and Windows only.
- **`needs_migration`** — Utility predicate to check whether a migration is required.
- **`StandardToGuiAppMigrator`** — Platform-gated (`macos` / `windows`) concrete migrator, implemented in the `standard_to_gui_app` submodule.

## Usage Example

```rust
use std::sync::Arc;

// Check if migration is needed before committing
if needs_migration(&current_installation, InstallationType::GuiApp) {
    let migrator = create_migrator(&current_installation, InstallationType::GuiApp, deps)?
        .expect("Unsupported migration path");

    let ctx = migrator.prepare(&tool).await?;
    let new_installation = migrator.migrate(&tool, &download_config, &ctx).await?;

    if let Err(e) = migrator.finalize(&tool, &new_installation, &ctx).await {
        migrator.rollback(&tool, &ctx).await?;
        return Err(e);
    }
}
```

## Notes

- The `Standard → GuiApp` path is only compiled on macOS and Windows; calling `create_migrator` with an unsupported path returns an `anyhow::bail!` error.
- `rollback` has a default no-op implementation that emits a `warn!` log — concrete migrators should override this for safe recovery.
