Handles the migration of a tool from `InstallationType::Standard` (plain binary) to `InstallationType::GuiApp` (.app bundle on macOS, GUI executable on Windows), implementing the `ToolMigrator` trait with platform-specific install and launch logic.

## Key Components

- **`StandardToGuiAppMigrator`** — Core migrator struct holding `ToolUpdaterDeps` (directory manager, download service, kill service, command params resolver).
- **`ToolMigrator` impl** — Implements the four-phase migration lifecycle:
  - `prepare` — Stops the running tool process and signals that a post-migration start is needed.
  - `migrate` — Dispatches to `migrate_macos` or `migrate_windows` based on compile target.
  - `finalize` — Launches the newly installed GUI app in the user session.
  - `rollback` — Emits a warning; no automatic recovery (reinstall required if binary was lost).
- **`migrate_macos`** — Removes the old standard binary, downloads and extracts the `.app` bundle to `/Applications`, then resolves the executable path via `DirectoryManager::find_app_bundle_path`.
- **`finalize_macos`** — Writes NSUserDefaults-style preferences via `args_to_pairs`/`write_preferences`, then launches the app under the console user with `launch_as_user`. Adds `--background` for `openframe-chat`.
- **`migrate_windows`** — Downloads and writes the binary to the agent path using `download_and_write_binary`.
- **`finalize_windows`** — Resolves command args, appends `--background` for `openframe-chat`, and launches the process in the user session via `launch_process_in_user_session`. Closes the process handle after a fire-and-forget launch.

## Usage Example

```rust
use crate::platform::tool_updater::StandardToGuiAppMigrator;

let migrator = StandardToGuiAppMigrator::new(deps.clone());

let ctx = migrator.prepare(&installed_tool).await?;
let new_installation = migrator.migrate(&installed_tool, &download_config, &ctx).await?;
migrator.finalize(&installed_tool, &new_installation, &ctx).await?;
```
