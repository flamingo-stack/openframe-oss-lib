The root module for the tool update subsystem, defining the `ToolUpdater` trait, shared update/migration orchestration logic, and common binary management utilities used across all updater implementations.

## Key Components

### Trait & Types
- **`ToolUpdater`** — Async trait with four lifecycle methods: `prepare`, `apply`, `finalize`, and `rollback`
- **`UpdateContext`** — Carries per-update state (`backup_path`, `needs_restart`) through the lifecycle
- **`ToolUpdaterDeps`** — Dependency bundle injected into all updater implementations (download service, kill service, run manager, directory manager, command resolver)

### Concrete Updaters (re-exported)
- **`StandardToolUpdater`** — Handles plain binary installs
- **`ServiceToolUpdater`** — Handles system service installs
- **`GuiAppToolUpdater`** *(macOS only)* — Handles `.app` bundle installs

### Factory Functions
- **`create_updater`** — Selects the correct `ToolUpdater` impl based on `Installation` variant
- **`create_migrator`** — Selects a `ToolMigrator` for cross-type migrations (re-exported from `migration`)

### Orchestration
- **`run_update`** — Drives the three-phase update lifecycle (prepare → apply → finalize) with automatic rollback on failure
- **`run_migration`** — Drives the three-phase migration lifecycle with automatic rollback on failure

### Shared Binary Utilities *(crate-internal)*
- **`backup_binary`** — Copies existing binary to a `.backup` sibling file
- **`download_and_write_binary`** — Downloads via GitHub service and writes an executable to disk
- **`cleanup_backup`** — Removes the `.backup` file after a successful update
- **`restore_from_backup`** — Copies `.backup` back to the original path and removes the backup

## Usage Example

```rust
use crate::updaters::{run_update, ToolUpdaterDeps};

let deps = ToolUpdaterDeps {
    github_download_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    command_params_resolver,
};

// Runs prepare → apply → finalize, rolls back automatically on failure
let new_installation = run_update(&installed_tool, &download_config, deps).await?;
```
