Implements the standard tool update strategy for managed agent binaries, handling the full update lifecycle: stop, backup, download, finalize, and rollback.

## Key Components

- **`StandardToolUpdater`** — Concrete implementation of the `ToolUpdater` trait for standard (non-special-case) tools.
- **`prepare`** — Stops the running tool process and creates a binary backup before applying any changes.
- **`apply`** — Downloads and writes the new binary to the agent path; returns `None` (no installation metadata update required).
- **`finalize`** — Cleans up the backup file and logs that the tool will auto-restart via the run manager.
- **`rollback`** — Restores the original binary from backup if the update fails.

## Usage Example

```rust
use standard::StandardToolUpdater;

let updater = StandardToolUpdater::new(deps);

// Prepare: stops the tool and backs up the binary
let ctx = updater.prepare(&installed_tool).await?;

// Apply: downloads and writes the new binary
updater.apply(&installed_tool, &download_config, &ctx).await?;

// Finalize: cleans up backup; tool auto-restarts via run manager
updater.finalize(&installed_tool, &ctx).await?;

// On failure, rollback restores the previous binary
updater.rollback(&installed_tool, &ctx).await?;
```

> The `apply` step returns `Option<Installation>` — `StandardToolUpdater` always returns `None`, deferring installation record management to the caller.
