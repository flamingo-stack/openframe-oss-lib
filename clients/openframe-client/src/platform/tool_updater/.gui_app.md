Implements the `GuiAppToolUpdater`, which handles the full lifecycle of updating macOS GUI application bundles (`.app`) as part of the OpenFrame tool update pipeline.

## Key Components

### `GuiAppToolUpdater`

A struct implementing the `ToolUpdater` trait for macOS GUI applications. Constructed via `new(deps: ToolUpdaterDeps)`.

### Trait Methods

| Method | Responsibility |
|---|---|
| `prepare` | Stops the running GUI app process before update begins; sets `needs_restart: true` |
| `apply` | Removes the old `.app` bundle, downloads and extracts the new version to `/Applications`, and returns the updated `Installation::GuiApp` |
| `finalize` | Waits for a console user session, resolves command args/preferences via `command_params_resolver`, writes macOS preferences (`plist`), and relaunches the app as the current user |
| `rollback` | Logs a warning — no backup is maintained, so reinstallation from the server is required |

## Usage Example

```rust
use crate::updaters::gui_app::GuiAppToolUpdater;
use crate::updaters::{ToolUpdater, ToolUpdaterDeps};

let updater = GuiAppToolUpdater::new(deps);

// Prepare: stops the running app
let ctx = updater.prepare(&installed_tool).await?;

// Apply: removes old bundle, installs new one
let new_installation = updater.apply(&installed_tool, &download_config, &ctx).await?;

// Finalize: resolves preferences, relaunches as console user
updater.finalize(&installed_tool, &ctx).await?;
```

## Notes

- **macOS-only**: Targets `/Applications` and uses `bundle_id` for plist-based preference injection.
- **`openframe-chat` special case**: When relaunching, the `--background` flag is appended automatically for the `openframe-chat` tool agent.
- **No rollback support**: The updater explicitly skips backup creation; rollback logs a warning directing the user to reinstall.
- **Console user polling**: `finalize` blocks in a 5-second retry loop until `get_console_user()` returns a valid session, ensuring the app is launched in the correct user context.
