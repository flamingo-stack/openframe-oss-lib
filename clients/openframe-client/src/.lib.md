Serves as the root library crate for the OpenFrame agent client, wiring together all subsystems including authentication, NATS messaging, tool management, service orchestration, and configuration into a single `Client` struct.

## Key Components

### Configuration Structs
- **`ClientConfiguration`** — Top-level agent config with `Default` impl pointing to `https://api.openframe.org`
- **`ServerConfig`** — Server URL, polling interval, optional update URL
- **`ClientConfig`** — Agent ID (UUID), log level, update channel
- **`MetricsConfig`** — Metrics toggle and collection interval
- **`SecurityConfig`** — TLS verification flag and certificate path

### Core Struct
- **`Client`** — Aggregates all runtime services and listeners; constructed via `Client::new()`

### Public Modules

| Module | Purpose |
|---|---|
| `clients` | HTTP/API client wrappers (auth, registration, tool API) |
| `listener` | NATS message listeners (execution, updates, install/uninstall) |
| `services` | Business logic services (auth, registration, heartbeat, updates) |
| `platform` | OS-level abstractions (`DirectoryManager`, `DmgExtractor`) |
| `service_adapter` | Cross-platform service manager (Windows/macOS/Linux) |
| `executor` | Unix/Windows command executor |
| `cli` | CLI entry point (`run` re-exported at crate root) |
| `updater` / `monitoring` / `doctor` | Agent lifecycle utilities |

## Usage Example

```rust
use openframe_oss_lib::Client;

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    // Optionally enable dev mode (uses user dirs, skips TLS verification)
    // std::env::set_var("OPENFRAME_DEV_MODE", "1");

    let client = Client::new()?;
    // client.run().await?;
    Ok(())
}
```

```rust
use openframe_oss_lib::ClientConfiguration;

// Inspect or override defaults
let config = ClientConfiguration::default();
assert_eq!(config.client.update_channel, "stable");
assert_eq!(config.server.check_interval, 3600);
```

> **Dev mode:** Set the `OPENFRAME_DEV_MODE` environment variable to switch to user-scoped directories and disable TLS certificate verification — useful for local development against a self-signed server.
