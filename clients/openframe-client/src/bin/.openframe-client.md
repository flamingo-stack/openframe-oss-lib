Thin binary entry point for the OpenFrame client. Delegates all execution logic to the `openframe::run()` function in the core library crate.

## Key Components

- **`main()`** — Entry point that calls `openframe::run()` and propagates errors via `anyhow::Result`.

## Usage Example

```rust
// This binary is built with the `bin` feature flag.
// Run via Cargo:
// cargo run --features bin
fn main() -> anyhow::Result<()> {
    openframe::run()
}
```

## Notes

- Only compiled when the `bin` feature is enabled (`--features bin`).
- Contains no application logic itself; all behavior is implemented in the `openframe` library crate.
- Error handling is delegated to `anyhow`, which provides human-readable error output on failure.
