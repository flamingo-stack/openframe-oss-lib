A test binary that validates runtime privilege detection and cross-platform elevated command execution using the `openframe` permission utilities.

## Key Components

- **`PermissionUtils::is_admin()`** — Detects whether the current process is running with root/administrator privileges.
- **`PermissionUtils::has_capability(Capability)`** — Checks for specific system capabilities (`ManageServices`, `WriteSystemDirectories`, `ReadSystemLogs`, `WriteSystemLogs`).
- **`PermissionUtils::run_as_admin(cmd, args)`** — Executes a shell command with elevated privileges. Triggers `sudo` on macOS/Linux or a UAC prompt on Windows.
- **Platform-specific branches** (`#[cfg(target_os)]`) — Runs OS-appropriate privileged commands:
  - **macOS**: `system_profiler SPSoftwareDataType`
  - **Linux**: `lsb_release -a`
  - **Windows**: `systeminfo /fo list /nh`

## Usage Example

```rust
use openframe::platform::permissions::{Capability, PermissionUtils};

fn main() -> anyhow::Result<()> {
    openframe::logging::init(None, None)?;

    // Check privilege level
    let is_admin = PermissionUtils::is_admin();

    // Query a specific capability
    let can_manage = PermissionUtils::has_capability(Capability::ManageServices);

    // Elevate a command if needed
    if !is_admin {
        PermissionUtils::run_as_admin("echo", &["elevated"])?;
    }

    Ok(())
}
```

## Notes

- This is a **test/diagnostic binary**, not a library module — intended to be run directly to verify permission logic on the target machine.
- When not running as admin, `run_as_admin` may prompt for credentials interactively.
