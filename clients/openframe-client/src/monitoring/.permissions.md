Periodic filesystem permission monitoring daemon that checks directory health, automatically attempts to fix permission issues, and records observability metrics.

## Key Components

| Item | Description |
|---|---|
| `PermissionMonitor` | Core struct wrapping a `DirectoryManager`, configurable check interval, and a shared `MetricsStore` |
| `new()` | Constructs a monitor with a default 1-hour check interval |
| `with_interval()` | Builder method to override the check interval |
| `start_monitoring()` | Async loop that ticks on the configured interval and triggers permission checks |
| `perform_check()` | Internal method that runs a health check, auto-fixes on failure, and records metrics |
| `get_metrics()` | Returns a static list of tracked metric names with placeholder values |

**Tracked Metrics:**
- `openframe_permission_errors_total` — incremented on health check failure
- `openframe_permission_fixes_total` — incremented on successful auto-repair
- `openframe_last_permission_check_timestamp` — Unix timestamp of last check

## Usage Example

```rust
use std::sync::Arc;
use std::time::Duration;

let dir_manager = Arc::new(DirectoryManager::new());

let monitor = PermissionMonitor::new(Arc::clone(&dir_manager))
    .with_interval(Duration::from_secs(1800)); // Check every 30 minutes

// Spawn as a background task
tokio::spawn(async move {
    monitor.start_monitoring().await;
});
```

> **Note:** `start_monitoring()` runs an infinite loop and consumes `self`; always spawn it on a dedicated async task. The `RwLock` on `MetricsStore` uses `try_write()` (non-blocking) — metric updates are best-effort and silently skipped under write contention.
