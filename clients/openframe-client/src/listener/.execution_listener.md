NATS-based execution listener that subscribes to machine-specific subjects, dispatches incoming execution requests with bounded concurrency, and publishes results back via NATS.

## Key Components

### `ExecutionListener<M>`

Generic struct parameterized over `M: ExecutionMessage` that owns all dependencies needed to subscribe, process, and respond to execution messages.

| Field | Purpose |
|---|---|
| `nats_connection_manager` | Provides the NATS client on demand |
| `nats_message_publisher` | Publishes execution results |
| `execution_service` | Runs the actual execution |
| `config_service` | Resolves the local machine ID |
| `semaphore` | Caps concurrent in-flight executions |

### `start(&self) -> Result<JoinHandle<()>>`

Spawns a supervised background task that calls `listen()` in a loop, reconnecting after `RECONNECTION_DELAY_MS` on any exit (normal or error).

### `listen(&self) -> Result<()>`

Subscribes to `machine.<machine_id>.<M::KIND>` and feeds messages into `run_bounded`, which enforces the semaphore concurrency limit.

### `handle_message`

Parses the raw NATS payload via `M::from_payload`, runs the execution, logs outcome fields (`exit_code`, `timed_out`, `execution_time_ms`), and publishes to `machine.<machine_id>.<M::KIND>.result`.

### `run_bounded`

Free function that drains any `futures::Stream`, acquiring a semaphore permit before spawning each handler task. The owned permit is dropped when the task finishes, naturally releasing capacity even on panic.

## Usage Example

```rust
let semaphore = Arc::new(Semaphore::new(4)); // max 4 concurrent executions

let listener = ExecutionListener::<MyExecutionMessage>::new(
    nats_connection_manager,
    nats_message_publisher,
    execution_service,
    config_service,
    semaphore,
);

// Spawns a self-reconnecting background task
let handle = listener.start().await?;
handle.await?;
```

The `M::KIND` constant determines both the NATS subscription subject and the result subject, allowing multiple `ExecutionListener` instances with different message types to coexist on the same machine.
