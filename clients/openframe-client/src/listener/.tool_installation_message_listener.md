A NATS JetStream push consumer listener that processes tool installation messages for a specific machine, with automatic reconnection, retry logic, and per-tool serialized dispatch.

## Key Components

- **`ToolInstallationMessageListener`** — Core struct holding references to the NATS connection manager, installation service, agent config service, and tool run manager
- **`start()`** — Spawns a background `tokio` task with an infinite reconnection loop, re-invoking `listen()` after failures with a configurable delay
- **`listen()`** — Establishes the JetStream context, creates a durable push consumer, and drives the `tokio::select!` message loop; handles NATS reconnect signals by re-provisioning the consumer
- **`handle_message()`** — Deserializes the raw NATS payload into `ToolInstallationMessage`; ACKs malformed messages immediately to prevent redelivery loops; delegates to `park_or_dispatch` for per-tool serialization
- **`dispatch()`** — Calls `ToolInstallationService::install()`; ACKs on success, leaves unacked on failure to allow JetStream redelivery
- **`create_consumer()`** — Cyclic retry loop with exponential back-off per attempt and a configurable pause between cycles; gracefully recovers from "consumer name already in use" conflicts by fetching the existing consumer
- **`build_consumer_configuration()`** — Constructs a durable push `Config` with machine-scoped filter/deliver subjects and ACK wait/max-deliver limits

## Usage Example

```rust
let listener = ToolInstallationMessageListener::new(
    nats_connection_manager,
    tool_installation_service,
    config_service,
    tool_run_manager,
);

// Spawns a self-healing background task
let _handle = listener.start().await?;
```

**Subject conventions** (keyed by `machine_id`):

```text
Filter subject:   machine.<id>.tool-installation
Deliver subject:  machine.<id>.tool-installation.inbox
Durable name:     machine_<id>_tool-installation_consumer
```

All retry timing (`CONSUMER_ACK_WAIT_SECS`, `RECONNECTION_DELAY_MS`, etc.) is driven by constants from [`update_config`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/config/update_config.rs).
