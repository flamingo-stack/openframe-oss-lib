Listens for tool uninstall messages from a NATS JetStream subject and coordinates safe, ordered uninstallation of agent tools on a specific machine.

## Key Components

### `ToolUninstallMessageListener`

The primary struct holding references to:

- **`NatsConnectionManager`** — manages NATS client connections and reconnect signals
- **`ToolRunManager`** — provides per-tool locking and state tracking (`mark_updating`, `clear_running_tool`)
- **`ToolUninstallService`** — executes the actual uninstall logic, returning `UninstallOutcome`
- **`AgentConfigurationService`** — supplies the machine ID used to scope NATS subjects

### Key Methods

| Method | Description |
|---|---|
| `start()` | Spawns a background `tokio` task with auto-reconnect loop |
| `listen()` | Inner loop: creates a JetStream push consumer and dispatches incoming messages |
| `handle_message()` | Deserializes `ToolUninstallMessage`, then delegates to `park_or_dispatch` for ordered execution |
| `dispatch()` | Acquires a per-tool try-lock, runs uninstall under panic guard, acks or defers the NATS message |
| `create_consumer()` | Retries consumer creation with exponential backoff; recovers existing durable consumers on name conflict |
| `build_consumer_configuration()` | Constructs a machine-scoped push consumer config with ack-wait and max-deliver limits |

### NATS Subject Pattern

```text
Filter:  machine.<machine_id>.tool-uninstall
Deliver: machine.<machine_id>.tool-uninstall.inbox
Durable: machine_<machine_id>_tool-uninstall_consumer
Stream:  TOOL_INSTALLATION
```

## Usage Example

```rust
let listener = ToolUninstallMessageListener::new(
    nats_connection_manager,
    tool_run_manager,
    tool_uninstall_service,
    config_service,
);

let handle = listener.start().await?;
handle.await?;
```

> Messages left unacknowledged on failure are redelivered up to `UNINSTALL_CONSUMER_MAX_DELIVER` times. A `try_lock` failure defers processing to the next redelivery cycle, preventing conflicts with concurrent install or run operations on the same tool.
