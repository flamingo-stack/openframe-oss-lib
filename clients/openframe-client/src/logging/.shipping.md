Provides asynchronous, batched log shipping over HTTP for the OpenFrame agent, buffering log entries and flushing them either when a batch reaches 100 entries or after a 30-second timeout.

## Key Components

- **`LogBatch`** — Serializable struct representing a batch payload sent to the remote endpoint; contains log lines, the originating agent ID, and a UTC timestamp.
- **`LogShipper`** — Main struct owning an `mpsc::Sender` and shipping configuration. Spawns a background Tokio task on construction that handles batching and transmission.
- **`LogShipper::new`** — Constructor that creates a bounded channel (capacity 1000), clones endpoint/agent_id for the background task, and returns the shipper immediately.
- **`LogShipper::send`** — Async method to enqueue a single log line into the channel.
- **`ship_logs`** (private) — Background loop using `tokio::select!` to accumulate logs and flush on size (`BATCH_SIZE = 100`) or timeout (`BATCH_TIMEOUT = 30s`).
- **`send_batch`** (private) — Constructs a `LogBatch` and POSTs it as JSON via `reqwest`, returning an error on non-2xx responses.

## Usage Example

```rust
use shipping::LogShipper;

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let shipper = LogShipper::new(
        "https://logs.example.com/ingest".to_string(),
        "agent-42".to_string(),
    );

    // Enqueue individual log lines; batching is handled automatically
    shipper.send("Device connected: 192.168.1.10".to_string()).await?;
    shipper.send("Ticket #1234 auto-resolved".to_string()).await?;

    Ok(())
}
```

> **Note:** The background shipping task runs for the lifetime of the Tokio runtime. Logs buffered at shutdown that have not yet reached the batch threshold may be dropped; consider adding a graceful drain mechanism for production use.
