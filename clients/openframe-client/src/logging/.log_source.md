Defines log source abstractions and implementations for reading structured log entries from files, with offset-based position tracking and a multi-source registry.

## Key Components

### `LogSourceKind`
Enum identifying the two supported log origins: `Openframe` and `Meshcentral`.

### `LogSource` (trait)
Core interface for log ingestion. Implementors must provide:
- `name()` — source identifier
- `read(max_count)` — fetch up to `max_count` new entries
- `commit()` — persist the current read position
- `rollback()` — revert to the last committed position

### `FileLogSource`
Reads log entries from a file using byte-offset tracking. Persists the committed offset to a separate file so reads survive restarts. Handles file truncation by resetting to offset 0 when the file is shorter than the stored position.

### `LogSourceRegistry`
Aggregates multiple `LogSource` implementations and coordinates reads across them. Key behaviors:
- **Fair quota distribution** — divides `max_total` evenly across active sources each round
- **Deduplication** — calls `.deduplicate()` on the final merged set via `LogDeduplicator`
- `commit_all()` / `rollback_all()` — propagates commit/rollback to every registered source

## Usage Example

```rust
use std::path::PathBuf;

let mut registry = LogSourceRegistry::new();

let source = FileLogSource::new(
    LogSourceKind::Openframe,
    PathBuf::from("/var/log/openframe/app.log"),
    PathBuf::from("/var/lib/openframe/log.offset"),
);
registry.register(Box::new(source));

// Read up to 500 deduplicated entries across all sources
let entries = registry.read_all(500);

if entries.is_empty() {
    registry.rollback_all();
} else {
    // process entries...
    registry.commit_all();
}
```
