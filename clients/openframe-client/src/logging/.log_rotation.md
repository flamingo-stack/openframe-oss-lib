Manages log file rotation with gzip compression for the OpenFrame log streaming pipeline, triggering rotation when all logs have been streamed and the file exceeds a 10 MB size threshold.

## Key Components

**`LogRotationManager`** — Core struct managing rotation state via two file paths:
- `log_file_path` — Path to the active log file being monitored
- `offset_file_path` — Path to a file persisting the current read offset

**Public Methods:**
| Method | Description |
|---|---|
| `new(log_file_path, offset_file_path)` | Constructs a new manager instance |
| `rotate_if_ready(current_offset)` | Triggers rotation when offset ≥ file size and file ≥ 10 MB |
| `load_offset()` | Reads the persisted byte offset from disk, defaults to `0` |
| `save_offset(offset)` | Writes the current byte offset to the offset file |

**Private Methods:**
- `rotate()` — Compresses the active log to `openframe.log.gz` via gzip, then truncates the original file

## Usage Example

```rust
use std::path::PathBuf;
use log_rotation::LogRotationManager;

let manager = LogRotationManager::new(
    PathBuf::from("/var/log/openframe/openframe.log"),
    PathBuf::from("/var/log/openframe/openframe.offset"),
);

// Restore offset from previous run
let mut offset = manager.load_offset();

// Called in the log streaming loop after consuming entries
manager.rotate_if_ready(&mut offset);

// Persist updated offset
manager.save_offset(offset);
```

> **Note:** Rotation only triggers when `current_offset >= file_size` (all bytes streamed) **and** `file_size >= 10 MB`. The archive overwrites any existing `openframe.log.gz` in the same directory.
