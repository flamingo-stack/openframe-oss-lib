Cross-platform logging initialization module that sets up structured logging using the `tracing` ecosystem, with support for both JSON and plain-text output formats, non-blocking file writers, and optional metrics collection.

## Key Components

- **`init(log_endpoint, agent_id)`** — Primary entry point; initializes the global tracing subscriber with file + stdout output.
- **`init_file_only(log_endpoint, agent_id)`** — Variant that suppresses stdout output; useful for daemon/service contexts.
- **`manual_log(level, message)`** — Fallback logger that writes directly to the log file and stdout, bypassing `tracing` entirely.
- **`JsonLayer`** — Custom `tracing_subscriber::Layer` that serializes log events to structured JSON, merges parent span fields into each event, and feeds the `MetricsStore`.
- **`JsonVisitor`** — `tracing::field::Visit` implementation that extracts `message`, `error`, and arbitrary fields from events into a `serde_json::Map`.
- **`LogEntry`** — Serializable struct capturing timestamp, level, target, module path, file/line, thread ID, message, and flattened context fields.
- **Submodules** — `log_parser`, `log_rotation`, `log_source`, `metrics`, `nats_streaming`, `shipping`.

## Usage Example

```rust
use openframe_lib::logging;

#[tokio::main]
async fn main() -> std::io::Result<()> {
    // Initialize with default text format (set OPENFRAME_LOG_FORMAT=json for JSON)
    logging::init(None, Some("agent-123".to_string()))?;

    tracing::info!(tool_id = "my_tool", "Processing request");

    // Fallback manual log if tracing setup is unavailable
    logging::manual_log("WARN", "Tracing unavailable, writing directly");

    Ok(())
}
```

**Environment variables:**

| Variable | Effect |
|---|---|
| `OPENFRAME_LOG_FORMAT=json` | Switch from text one-liners to structured JSON |
| `OPENFRAME_DEV_MODE` | Use user-writable log directory instead of system path |
| `RUST_LOG` | Standard `EnvFilter` directive (default: `info,async_nats=warn`) |

## Notes

- The `WorkerGuard` from `tracing_appender::non_blocking` is stored in a `OnceLock` to prevent the background writer thread from being dropped prematurely.
- Initialization is guarded by `std::sync::Once`, making repeated calls to `init()` safe.
