Parses structured log lines from OpenFrame and external tools (logrus format), reads incremental file positions, and deduplicates repeated tool log entries.

## Key Components

| Item | Description |
|------|-------------|
| `LogEntry` | Serializable struct representing a single log line with `level`, `ts`, `msg`, and optional repeat `count` |
| `LogBatchMessage` | Wrapper struct for sending a batch of `LogEntry` values with host/tenant metadata |
| `read_new_logs()` | Reads new lines from a log file starting at a byte offset; handles log rotation by resetting to `0` on truncation |
| `parse_log_line()` | Dispatches to format-specific parsers; supports OpenFrame tracing format and logrus `time=`/`level=`/`msg=` format (with optional `stdout:` prefix) |
| `parse_tracing_format()` | Parses ISO 8601-prefixed compact tracing lines; validates timestamps via `chrono` |
| `LogDeduplicator` | Trait implemented on `Vec<LogEntry>`; collapses consecutive identical tool log messages into a single entry with an incremented `count` |

## Usage Example

```rust
use std::path::PathBuf;
use log_parser::{read_new_logs, LogDeduplicator};

// Read up to 100 new log lines from a tracked position
let path = PathBuf::from("/var/log/openframe.log");
let (entries, new_position) = read_new_logs(&path, last_position, 100)?;

// Deduplicate repeated tool messages before shipping
let entries = entries.deduplicate();

for entry in &entries {
    println!("[{}] {} - {}{}", 
        entry.level, 
        entry.ts, 
        entry.msg,
        entry.count.map(|c| format!(" (×{c})")).unwrap_or_default()
    );
}

// Persist new_position for the next polling cycle
last_position = new_position;
```
