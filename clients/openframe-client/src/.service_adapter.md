Cross-platform service lifecycle manager that wraps the `service_manager` crate, providing a unified API for installing, uninstalling, starting, and stopping system services across macOS (launchd), Windows (SCM), and Linux (systemd).

## Key Components

### `RecoveryConfig`
Windows SCM failure-action configuration controlling restart delay intervals (first, second, subsequent), reset period, and whether recovery applies to non-crash failures.

### `ServiceConfig`
Comprehensive service descriptor holding identity fields (name, display name, description), process control flags (keep-alive, restart-on-crash, throttle), environment variables, log paths, user/group identity, resource limits, and an optional `RecoveryConfig`.

### `CrossPlatformServiceManager`
The primary entry point. Wraps a `ServiceConfig` and delegates to the native platform service manager via `service_manager::ServiceManager`.

| Method | Description |
|---|---|
| `new()` | Construct with minimal required fields |
| `with_config()` | Construct from a fully populated `ServiceConfig` |
| `set_*()` | Builder-style mutators for optional fields |
| `install()` | Register service, create log dirs, start it, apply Windows recovery |
| `uninstall()` | Stop, wait for termination (Windows), deregister, clean up files |
| `start()` / `stop()` | Lifecycle control via native manager |

Service labels follow the reverse-DNS convention `com.openframe.<name>`.

## Usage Example

```rust
use std::path::PathBuf;
use service_adapter::{CrossPlatformServiceManager, RecoveryConfig, ServiceConfig};

// Minimal construction
let mut mgr = CrossPlatformServiceManager::new(
    "agent",
    "OpenFrame Agent",
    "OpenFrame background agent service",
    PathBuf::from("/usr/local/bin/openframe-agent"),
);

mgr.set_stdout_path(PathBuf::from("/var/log/openframe/agent.log"))
   .set_stderr_path(PathBuf::from("/var/log/openframe/agent.err"))
   .set_restart_throttle(30)
   .set_user("openframe");

mgr.install()?;  // installs + starts the service

// Full config with Windows recovery
let config = ServiceConfig {
    name: "agent".into(),
    recovery: Some(RecoveryConfig {
        first_restart_secs: 10,
        second_restart_secs: 30,
        subsequent_restart_secs: 60,
        reset_period_days: 1,
        enable_on_non_crash_failures: true,
    }),
    ..ServiceConfig::default()
};
let mgr = CrossPlatformServiceManager::with_config(config);
mgr.uninstall()?;
```
