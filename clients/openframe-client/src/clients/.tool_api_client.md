HTTP client for fetching tool assets from the agent tool API, handling authentication via bearer token injection.

## Key Components

### `ToolApiClient`
A cloneable HTTP client struct wrapping `reqwest::Client` with:
- `http_client` — underlying async HTTP client
- `base_url` — root URL for the tool API
- `config_service` — `AgentConfigurationService` used to retrieve access tokens at request time

### Methods

| Method | Description |
|---|---|
| `new(http_client, base_url, config_service)` | Constructs a new `ToolApiClient` instance |
| `get_tool_asset(tool_id, asset_path)` | Fetches raw bytes for a specific asset belonging to a tool |

## Usage Example

```rust
let client = ToolApiClient::new(
    reqwest::Client::new(),
    "https://api.example.com".to_string(),
    config_service,
);

let asset_bytes = client
    .get_tool_asset(
        "my-tool-id".to_string(),
        "/manifest.json".to_string(),
    )
    .await?;
```

The resolved request URL follows the pattern:

```text
{base_url}/tools/agent/{tool_id}{asset_path}
```

## Notes

- Access tokens are fetched dynamically per request via `AgentConfigurationService::get_access_token()`, ensuring tokens are always fresh.
- Non-2xx responses return an `Err` containing the HTTP status code and response body for diagnostics.
- Returns raw `bytes::Bytes`, leaving deserialization to the caller.
