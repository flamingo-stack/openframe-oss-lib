HTTP client for downloading tool agent binary files from a remote server, with automatic OS detection to request the appropriate platform-specific binary.

## Key Components

- **`ToolAgentFileClient`** — Struct wrapping a `reqwest::Client` and a base URL, providing a scoped HTTP client for tool agent file downloads.
- **`new(http_client, base_url)`** — Constructor accepting an existing `reqwest::Client` and base URL string.
- **`get_tool_agent_file(asset_id)`** — Async method that fetches a tool agent binary by asset ID, automatically appending `?os=windows` or `?os=mac` based on the compile-time target OS. Returns raw `bytes::Bytes` on success or a descriptive `anyhow::Error` on HTTP failure.

## Usage Example

```rust
use reqwest::Client;
use tool_agent_file_client::ToolAgentFileClient;

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let http_client = Client::new();
    let client = ToolAgentFileClient::new(
        http_client,
        "https://api.example.com".to_string(),
    );

    let asset_id = "v1.2.3".to_string();
    let binary_bytes = client.get_tool_agent_file(asset_id).await?;

    std::fs::write("tool-agent", binary_bytes)?;
    println!("Downloaded {} bytes", binary_bytes.len());

    Ok(())
}
```

The constructed request URL follows the pattern `/clients/tool-agent/{asset_id}?os={mac|windows}`. Non-2xx responses are surfaced as errors including the HTTP status code and response body for easier debugging.
