Barrel module that re-exports the primary client types for interacting with OpenFrame's authentication, registration, file, and API services.

## Key Components

| Export | Source Module | Description |
|---|---|---|
| `AuthClient` | `auth_client` | Handles authentication flows |
| `RegistrationClient` | `registration_client` | Manages tool/agent registration |
| `RegistrationError` | `registration_client` | Error type for registration failures |
| `ToolAgentFileClient` | `tool_agent_file_client` | File operations for tool agents |
| `ToolApiClient` | `tool_api_client` | General API interactions |

## Usage Example

```rust
use openframe_oss_lib::clients::{
    AuthClient,
    RegistrationClient,
    RegistrationError,
    ToolAgentFileClient,
    ToolApiClient,
};

// Clients are accessible directly from the top-level clients module
// without needing to reference individual submodule paths
let auth = AuthClient::new(/* ... */);
let registration = RegistrationClient::new(/* ... */);
let file_client = ToolAgentFileClient::new(/* ... */);
let api_client = ToolApiClient::new(/* ... */);
```

## Notes

- All submodules remain `pub` for direct access when needed (e.g., `clients::auth_client::AuthClient`)
- `RegistrationError` is the only error type explicitly re-exported at this level, indicating it is intended for use across module boundaries
- Source: [`clients/mod.rs`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/clients/mod.rs)
