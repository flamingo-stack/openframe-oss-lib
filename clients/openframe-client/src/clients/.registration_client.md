HTTP client for agent registration and reinstallation against the OpenFrame platform API, handling both fresh registration and credential-based reinstall flows with structured error discrimination.

## Key Components

### `RegistrationClient`
The primary struct wrapping a `reqwest::Client` and base URL. Cloneable for shared use across async tasks.

- **`new(base_url, http_client)`** — Constructs a new client instance.
- **`register(initial_key, machine_info, request)`** — Posts to `/register` (no `machine_info`) or `/reinstall` (with `machine_info`). Attaches `X-Initial-Key`, and optionally `X-Client-Secret` / `X-Machine-Id` headers. Returns `AgentRegistrationResponse` on success.

### `RegistrationError`
Typed error enum allowing callers to branch on failure cause:

| Variant | Description |
|---|---|
| `ClientSecretInvalid` | HTTP 401 with a `CLIENT_SECRET_*` error code — saved credentials rejected |
| `Other(anyhow::Error)` | Network failures, validation errors, non-401 server errors |

### `is_client_secret_error` (private)
Detects the specific `HTTP 401 + CLIENT_SECRET_*` error code pattern by deserializing the response body into `ApiError`. Returns `false` for non-JSON bodies rather than propagating parse errors.

## Usage Example

```rust
use reqwest::Client;
use crate::registration_client::RegistrationClient;

let client = RegistrationClient::new(
    "https://api.openframe.ai".to_string(),
    Client::new(),
)?;

match client.register("initial-key-here", None, request).await {
    Ok(response) => println!("Registered: {:?}", response),
    Err(RegistrationError::ClientSecretInvalid) => {
        // Saved credentials are stale — clear persisted state and re-register
    }
    Err(RegistrationError::Other(e)) => {
        eprintln!("Registration failed: {e:#}");
    }
}
```
