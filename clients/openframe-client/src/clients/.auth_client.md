HTTP authentication client that handles OAuth2 token acquisition for the OpenFrame agent, supporting both client credentials and refresh token grant flows against the `/clients/oauth/token` endpoint.

## Key Components

### `AuthClient`

A cloneable HTTP client wrapper holding a `reqwest::Client` and a base URL.

| Method | Description |
|---|---|
| `new(base_url, http_client)` | Constructs a new `AuthClient` instance |
| `authenticate_with_secret(client_id, client_secret)` | OAuth2 `client_credentials` grant — exchanges a client ID and secret for an `AgentTokenResponse` |
| `authenticate_with_refresh_token(refresh_token)` | OAuth2 `refresh_token` grant — exchanges a refresh token for a new `AgentTokenResponse` |

Both authentication methods POST `application/x-www-form-urlencoded` form data and return an error if the server responds with a non-2xx status code.

## Usage Example

```rust
use reqwest::Client;
use crate::auth_client::AuthClient;

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let http_client = Client::new();
    let auth = AuthClient::new(
        "https://api.openframe.ai".to_string(),
        http_client,
    );

    // Authenticate using client credentials
    let token = auth
        .authenticate_with_secret(
            "my-client-id".to_string(),
            "my-client-secret".to_string(),
        )
        .await?;

    println!("Access token: {}", token.access_token);

    // Refresh an existing token
    let refreshed = auth
        .authenticate_with_refresh_token(token.refresh_token)
        .await?;

    println!("New access token: {}", refreshed.access_token);
    Ok(())
}
```

## Notes

- Errors from non-success HTTP responses include the status code and response body for easier debugging.
- The `AuthClient` is `Clone`, making it safe to share across async tasks.
