Build script that forwards required environment variables (version strings) into the compiled binary as compile-time constants, failing the build if any required variable is missing.

## Key Components

- **`main()`** — Entry point executed by Cargo during build. Always forwards `OPENFRAME_VERSION`; conditionally forwards additional version variables based on active crate features.
- **`forward_required(var: &str)`** — Helper that reads an environment variable at build time, emits it as a compile-time `rustc-env` constant, and registers a `rerun-if-env-changed` directive so Cargo rebuilds when the value changes. Panics with a descriptive message if the variable is unset.

### Feature-gated version variables

| Feature flag | Environment variable |
|---|---|
| *(always)* | `OPENFRAME_VERSION` |
| `openframe-chat-version` | `OPENFRAME_CHAT_VERSION` |
| `meshcentral-agent-version` | `MESHCENTRAL_AGENT_VERSION` |
| `fleetmdm-agent-version` | `FLEETMDM_AGENT_VERSION` |
| `osquery-version` | `OSQUERY_VERSION` |

## Usage Example

Set the required environment variables before building:

```bash
export OPENFRAME_VERSION="1.2.3"
export OPENFRAME_CHAT_VERSION="0.9.1"   # only needed with that feature
cargo build --features openframe-chat-version
```

Access the forwarded values anywhere in the crate at runtime:

```rust
const VERSION: &str = env!("OPENFRAME_VERSION");

fn main() {
    println!("Running OpenFrame v{}", VERSION);
}
```

If `OPENFRAME_VERSION` is not set, the build fails immediately:

```text
error: OPENFRAME_VERSION environment variable must be set at build time
```
