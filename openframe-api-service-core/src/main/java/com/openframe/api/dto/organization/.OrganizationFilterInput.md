GraphQL input DTO used to filter organizations by category, size, contract status, and activity date range. Maps directly to the `OrganizationFilterInput` type defined in the GraphQL schema.

## Key Components

| Field | Type | Description |
|---|---|---|
| `category` | `String` | Filter by organization category |
| `minEmployees` | `Integer` | Minimum employee count (inclusive) |
| `maxEmployees` | `Integer` | Maximum employee count (inclusive) |
| `hasActiveContract` | `Boolean` | Filter by active contract presence |
| `status` | `String` | Filter by organization status |
| `lastActivityFrom` | `Instant` | Inclusive lower bound of last-activity range (UTC) |
| `lastActivityTo` | `Instant` | Inclusive upper bound of last-activity range (UTC) |

## Usage Example

```java
OrganizationFilterInput filter = new OrganizationFilterInput();
filter.setCategory("MSP");
filter.setMinEmployees(10);
filter.setMaxEmployees(500);
filter.setHasActiveContract(true);
filter.setStatus("ACTIVE");
filter.setLastActivityFrom(Instant.parse("2024-01-01T00:00:00Z"));
filter.setLastActivityTo(Instant.now());

List<Organization> results = organizationService.findAll(filter);
```

> **Note:** All fields are optional. Only non-null fields are applied as filter predicates. Date bounds are inclusive on both ends.
