Data Transfer Object (DTO) for updating an existing time entry record in the OpenFrame time tracking system.

## Key Components

| Field | Type | Constraints | Description |
|---|---|---|---|
| `id` | `String` | `@NotBlank` | Required identifier of the time entry to update |
| `userId` | `String` | — | Associated user for the time entry |
| `ticketId` | `String` | — | Linked ticket reference |
| `organizationId` | `String` | — | Organization scope |
| `notes` | `String` | — | Descriptive notes for the time entry |
| `startedAt` | `Instant` | — | Timestamp when work began |
| `durationSeconds` | `Long` | — | Total duration of work in seconds |

**Lombok annotations:** `@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor` generate boilerplate (getters/setters, builder pattern, constructors).

## Usage Example

```java
// Build a partial update using the builder pattern
UpdateTimeEntryInput input = UpdateTimeEntryInput.builder()
    .id("entry-abc123")
    .notes("Investigated network latency issue")
    .durationSeconds(3600L)
    .startedAt(Instant.parse("2024-06-01T09:00:00Z"))
    .build();

// Pass to the service layer
timeTrackingService.updateEntry(input);
```

> Only `id` is required; all other fields are optional, allowing partial updates where only the provided fields are modified.
