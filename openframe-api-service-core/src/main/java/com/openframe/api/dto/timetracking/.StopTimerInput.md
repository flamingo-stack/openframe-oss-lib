Data Transfer Object (DTO) used to capture the required input when stopping an active time-tracking timer for a ticket.

## Key Components

| Field | Type | Description |
|---|---|---|
| `ticketId` | `String` | Identifier of the ticket whose timer is being stopped |
| `organizationId` | `String` | Identifier of the organization associated with the ticket |
| `notes` | `String` | Optional notes to attach to the time entry upon stopping |

Lombok annotations provide boilerplate reduction:
- `@Data` — generates getters, setters, `equals`, `hashCode`, and `toString`
- `@Builder` — enables the fluent builder pattern
- `@NoArgsConstructor` / `@AllArgsConstructor` — generates both default and full constructors

## Usage Example

```java
// Builder pattern
StopTimerInput input = StopTimerInput.builder()
    .ticketId("TICKET-42")
    .organizationId("org-001")
    .notes("Resolved network configuration issue.")
    .build();

// All-args constructor
StopTimerInput input = new StopTimerInput("TICKET-42", "org-001", "Resolved network configuration issue.");
```
