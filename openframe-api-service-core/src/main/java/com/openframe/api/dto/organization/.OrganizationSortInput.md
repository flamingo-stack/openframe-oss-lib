Typed sort input DTO for the `organizations` GraphQL query, pairing a constrained `OrganizationSortField` enum with a `SortDirection` to define supported orderings.

## Key Components

| Member | Type | Description |
|---|---|---|
| `field` | `OrganizationSortField` | Enum restricting which fields clients may sort by |
| `direction` | `SortDirection` | Shared enum for ascending or descending order |

Lombok annotations (`@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor`) generate boilerplate for accessors, builder pattern, and constructors.

## Usage Example

```java
// Ascending sort by organization name
OrganizationSortInput sort = OrganizationSortInput.builder()
    .field(OrganizationSortField.NAME)
    .direction(SortDirection.ASC)
    .build();

// Pass to the organizations query service
List<Organization> results = organizationService.findAll(filter, sort);
```

```java
// Direct constructor usage
OrganizationSortInput sort = new OrganizationSortInput(
    OrganizationSortField.CREATED_AT,
    SortDirection.DESC
);
```

## Notes

- Accepts only fields defined in `OrganizationSortField`, preventing arbitrary or unsupported sort columns at the type level.
- `SortDirection` is a shared DTO — see [`com.openframe.api.dto.shared`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/api/dto/shared) for the full enum definition.
