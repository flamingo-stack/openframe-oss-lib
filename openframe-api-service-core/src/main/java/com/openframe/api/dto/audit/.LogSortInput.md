Data Transfer Object (DTO) for specifying sort parameters when querying audit logs, combining a sort field and direction into a single input object.

## Key Components

- **`field`** — A `LogSortField` enum value indicating which audit log field to sort by (e.g., timestamp, severity, user).
- **`direction`** — A `SortDirection` enum value from the shared DTO package specifying ascending or descending order.

## Usage Example

```java
// Sort audit logs by timestamp in descending order
LogSortInput sortInput = LogSortInput.builder()
    .field(LogSortField.TIMESTAMP)
    .direction(SortDirection.DESC)
    .build();

// Or via constructor
LogSortInput sortInput = new LogSortInput(LogSortField.USER, SortDirection.ASC);
```

## Notes

- Lombok annotations (`@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor`) auto-generate getters, setters, builder, and constructors.
- Typically passed as part of a paginated audit log query request alongside filter and pagination inputs.
