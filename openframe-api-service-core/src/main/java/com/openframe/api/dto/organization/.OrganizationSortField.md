Enum defining the sortable fields available for the `organizations` GraphQL query, providing a typed and extensible surface for sort operations.

## Key Components

| Member | Description |
|---|---|
| `LAST_ACTIVITY` | Sort by the organization's canonical last-activity timestamp |

## Usage Example

```java
// Used when constructing a sort parameter for the organizations query
OrganizationSortField sortField = OrganizationSortField.LAST_ACTIVITY;

OrganizationSortInput sortInput = OrganizationSortInput.builder()
    .field(sortField)
    .direction(SortDirection.DESC)
    .build();
```

## Notes

- Currently exposes a single sortable field (`LAST_ACTIVITY`); additional fields can be added here as the API evolves without breaking existing GraphQL clients.
- Keeping sort fields in a dedicated enum ensures the GraphQL schema remains strongly typed rather than accepting arbitrary string values.
