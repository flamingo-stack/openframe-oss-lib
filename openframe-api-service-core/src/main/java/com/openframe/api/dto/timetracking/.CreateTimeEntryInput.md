Data Transfer Object (DTO) for capturing the input required to create a new time tracking entry in the OpenFrame platform.

## Key Components

| Field | Type | Constraints | Description |
|---|---|---|---|
| `userId` | `String` | `@NotBlank` | ID of the user logging the time |
| `ticketId` | `String` | Optional | Associated ticket reference |
| `organizationId` | `String` | Optional | Associated organization reference |
| `notes` | `String` | Optional | Descriptive notes for the entry |
| `startedAt` | `Instant` | `@NotNull` | UTC timestamp when work began |
| `durationSeconds` | `long` | `@Positive` | Duration of the entry in seconds |

## Usage Example

```java
CreateTimeEntryInput input = CreateTimeEntryInput.builder()
    .userId("user-abc123")
    .ticketId("ticket-xyz789")
    .organizationId("org-456")
    .notes("Investigated and resolved network latency issue.")
    .startedAt(Instant.now())
    .durationSeconds(3600L) // 1 hour
    .build();
```

> **Validation:** Bean validation annotations (`@NotBlank`, `@NotNull`, `@Positive`) are enforced at the API layer. Submitting a negative or zero `durationSeconds`, a blank `userId`, or a null `startedAt` will result in a `400 Bad Request` response.
