A GraphQL input DTO for filtering audit log queries, supporting date ranges, timestamps, event types, severities, and scoping by organization or device.

## Key Components

| Field | Type | Description |
|---|---|---|
| `startDate` / `endDate` | `LocalDate` | Inclusive date range filter |
| `timestampFrom` / `timestampTo` | `Instant` | Precise timestamp range filter |
| `eventTypes` | `List<String>` | Filter by specific audit event types |
| `toolTypes` | `List<String>` | Filter by tool/integration type |
| `severities` | `List<String>` | Filter by log severity levels |
| `organizationIds` | `List<String>` | Scope results to specific organizations |
| `deviceId` | `String` | Scope results to a single device |

Lombok annotations (`@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor`) generate accessors, a fluent builder, and both default and all-args constructors.

## Usage Example

```java
// Builder pattern — typical for GraphQL resolver input mapping
LogFilterInput filter = LogFilterInput.builder()
    .startDate(LocalDate.of(2024, 1, 1))
    .endDate(LocalDate.of(2024, 1, 31))
    .severities(List.of("ERROR", "CRITICAL"))
    .organizationIds(List.of("org-123", "org-456"))
    .eventTypes(List.of("DEVICE_OFFLINE", "AUTH_FAILURE"))
    .build();

// No-args constructor — typical for GraphQL framework deserialization
LogFilterInput emptyFilter = new LogFilterInput();
emptyFilter.setDeviceId("dev-789");
emptyFilter.setToolTypes(List.of("RMM", "PSA"));
```

## Notes

- `LocalDate` fields are suited for day-level filtering in GraphQL date scalars; `Instant` fields enable sub-second precision for event stream queries.
- All fields are optional — the consuming service should treat `null` values as "no filter applied" for that dimension.
