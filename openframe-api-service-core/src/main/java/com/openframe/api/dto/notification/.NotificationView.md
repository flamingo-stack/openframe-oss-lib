A read-only DTO record representing a notification as exposed to API consumers, carrying all display and metadata fields needed to render a notification in the UI.

## Key Components

| Field | Type | Description |
|---|---|---|
| `id` | `String` | Unique identifier of the notification |
| `severity` | `NotificationSeverity` | Severity level (e.g., INFO, WARNING, ERROR) |
| `title` | `String` | Short display title of the notification |
| `description` | `String` | Full notification message body |
| `createdAt` | `Instant` | UTC timestamp of notification creation |
| `category` | `NotificationCategory` | Logical grouping/type of the notification |
| `context` | `NotificationContext` | Contextual metadata linking the notification to a resource |
| `read` | `boolean` | Whether the notification has been read by the user |

## Usage Example

```java
NotificationView view = NotificationView.builder()
    .id("notif_abc123")
    .severity(NotificationSeverity.WARNING)
    .title("Backup Job Failed")
    .description("The nightly backup for device DEV-001 did not complete.")
    .createdAt(Instant.now())
    .category(NotificationCategory.BACKUP)
    .context(notificationContext)
    .read(false)
    .build();
```

> Uses Lombok `@Builder` for fluent construction — typically assembled from a persisted `Notification` document before being returned in an API response.
