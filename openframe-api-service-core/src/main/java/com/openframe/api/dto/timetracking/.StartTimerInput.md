Data Transfer Object (DTO) used to carry the input payload for starting a time-tracking timer, encapsulating the ticket reference, organization scope, and optional notes.

## Key Components

| Field | Type | Description |
|---|---|---|
| `ticketId` | `String` | ID of the ticket to track time against |
| `organizationId` | `String` | ID of the organization owning the ticket |
| `notes` | `String` | Optional notes to attach to the timer session |

## Usage Example

```java
// Build a StartTimerInput using the generated builder
StartTimerInput input = StartTimerInput.builder()
    .ticketId("TICK-1234")
    .organizationId("org-abc")
    .notes("Working on network issue investigation")
    .build();

// Or use the all-args constructor
StartTimerInput input = new StartTimerInput("TICK-1234", "org-abc", "Initial diagnosis");
```

## Notes

- Lombok annotations (`@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor`) auto-generate getters, setters, constructors, and the builder pattern — no boilerplate required.
- All fields are optional at the type level; validation constraints should be enforced at the service or controller layer.
- Part of the `com.openframe.api.dto.timetracking` package — see related DTOs in the [timetracking package](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/api/dto/timetracking).
