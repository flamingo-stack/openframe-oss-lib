Implements a DGS (Domain Graph Service) BatchLoader that resolves `Organization` objects by ID in a single batched query, preventing N+1 database calls when organizations are fetched across multiple GraphQL resolvers.

## Key Components

| Component | Description |
|---|---|
| `@DgsDataLoader(name = "organizationDataLoader")` | Registers this class as a named DGS data loader, injectable via `DataLoaderRegistry` |
| `BatchLoader<String, Organization>` | Typed batch interface mapping `organizationId` strings to `Organization` documents |
| `load(List<String> organizationIds)` | Core batch method; deduplicates IDs, executes a single repository query, and returns results ordered to match input |
| `OrganizationRepository.findByOrganizationIdIn` | Bulk repository lookup used to fetch all requested organizations in one query |

## Key Behaviors

- **Null safety** — Filters `null` IDs before querying; maps them back to `null` in the result list
- **Deduplication** — Collects IDs into a `Set` to avoid redundant DB lookups
- **Order preservation** — Result list is re-mapped to match the original input order, as required by the DataLoader contract
- **Async execution** — Wraps the load in `CompletableFuture.supplyAsync()` for non-blocking resolution

## Usage Example

```java
// Inject the loader in a DGS data fetcher
@DgsComponent
public class MachineDataFetcher {

    @DgsData(parentType = "Machine", field = "organization")
    public CompletableFuture<Organization> organization(
            DgsDataFetchingEnvironment dfe) {

        DataLoader<String, Organization> loader =
                dfe.getDataLoader("organizationDataLoader");

        String orgId = ((Machine) dfe.getSource()).getOrganizationId();
        return loader.load(orgId);
    }
}
```
