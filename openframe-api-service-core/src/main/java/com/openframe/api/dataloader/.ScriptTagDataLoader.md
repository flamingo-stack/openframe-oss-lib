Batches GraphQL `Script.tags` field resolution into a single bulk tag-assignment lookup, preventing N+1 queries when resolving tags across multiple scripts.

## Key Components

| Element | Description |
|---|---|
| `@DgsDataLoader(name = "scriptTagDataLoader")` | Registers this loader with the DGS framework under the name `"scriptTagDataLoader"` |
| `BatchLoader<String, List<Tag>>` | Accepts a list of script IDs and returns a corresponding list of tag collections |
| `load(List<String> scriptIds)` | Delegates to `ScriptTagService.getTagsByScriptIds()` asynchronously via `CompletableFuture` |

## Usage Example

```java
// Inject the DataLoader in a DGS data fetcher
@DgsData(parentType = "Script", field = "tags")
public CompletableFuture<List<Tag>> tags(
        DgsDataFetchingEnvironment env) {

    DataLoader<String, List<Tag>> loader =
            env.getDataLoader("scriptTagDataLoader");

    String scriptId = env.<Script>getSource().getId();
    return loader.load(scriptId);
}
```

When a GraphQL query resolves `tags` for multiple `Script` objects simultaneously, DGS batches the individual `load()` calls and invokes `ScriptTagService.getTagsByScriptIds()` once with all collected IDs—replacing N separate queries with one.

## Notes

- Mirrors the pattern established by `KnowledgeBaseTagDataLoader`; both follow the same bulk-lookup contract.
- `getTagsByScriptIds` must return results **in the same order** as the input `scriptIds` list to satisfy the `BatchLoader` contract.
