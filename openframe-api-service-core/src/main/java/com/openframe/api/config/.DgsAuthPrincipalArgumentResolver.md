Resolves `@AuthenticationPrincipal AuthPrincipal` method parameters within the DGS/GraphQL execution path, mirroring the equivalent Spring MVC resolver for REST controllers.

## Key Components

| Member | Description |
|---|---|
| `supportsParameter` | Returns `true` when the parameter is annotated with `@AuthenticationPrincipal` and the declared type is `AuthPrincipal` (or a subtype). |
| `resolveArgument` | Reads the current `Authentication` from the `SecurityContextHolder`; if it is a `JwtAuthenticationToken`, converts it to an `AuthPrincipal` via `AuthPrincipal.fromJwt(...)`. Returns `null` for unauthenticated or non-JWT requests. |

## Usage Example

Inject the resolved principal directly into any DGS data fetcher the same way you would in an MVC controller:

```java
@DgsComponent
public class MeDataFetcher {

    @DgsQuery
    public UserProfile me(
            @AuthenticationPrincipal AuthPrincipal principal) {

        if (principal == null) {
            throw new AccessDeniedException("Not authenticated");
        }
        return userService.findById(principal.getUserId());
    }
}
```

No additional wiring is required — Spring picks up the `@Component`-annotated resolver automatically, and DGS delegates parameter resolution to it before invoking the fetcher.

## Notes

- This resolver only handles `JwtAuthenticationToken`. Sessions or other `Authentication` subtypes resolve to `null`.
- It is intentionally symmetric with the `AuthPrincipalArgumentResolver` in `openframe-security-core`, keeping REST and GraphQL authentication handling consistent across the platform.
