Implements the GraphQL Relay `Node` interface type resolver, mapping Java domain objects to their corresponding GraphQL type names for the DGS (Domain Graph Service) framework.

## Key Components

### `NodeTypeResolver`
- **Annotation:** `@DgsComponent` — registers this class as a DGS-managed component
- **Method:** `resolveNode(Object node)` — annotated with `@DgsTypeResolver(name = "Node")`, dispatches runtime type resolution for all entities implementing the GraphQL `Node` interface

### Supported Type Mappings

| Java Class | GraphQL Type |
|---|---|
| `Machine` | `"Machine"` |
| `Organization` | `"Organization"` |
| `Event` | `"Event"` |
| `IntegratedTool` | `"IntegratedTool"` |
| `Tenant` | `"Tenant"` |
| `ItemAssignment` | `"ItemAssignment"` |
| `Ticket` | `"Ticket"` |
| `KnowledgeBaseItem` | `"KnowledgeBaseItem"` |
| `User` | `"User"` |
| `ScriptResponse` | `"Script"` |
| `ScriptExecutionResponse` | `"ScriptExecution"` |

Throws `IllegalArgumentException` for any unregistered type.

## Usage Example

```java
// Resolved automatically by the DGS framework during GraphQL execution.
// When a Node interface field is queried, DGS calls resolveNode() internally:

// Example GraphQL query:
// { node(id: "abc123") { id ... on Machine { hostname } } }

// DGS passes the fetched domain object to resolveNode():
NodeTypeResolver resolver = new NodeTypeResolver();
String typeName = resolver.resolveNode(new Machine()); // returns "Machine"
String typeName = resolver.resolveNode(new Ticket());  // returns "Ticket"
```

## Notes

- **Registration required:** Any new entity implementing the `Node` interface must be added here to avoid `IllegalArgumentException` at runtime.
