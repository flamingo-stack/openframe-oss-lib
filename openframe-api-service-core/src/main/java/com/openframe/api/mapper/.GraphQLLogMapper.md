Maps GraphQL audit log inputs to service-layer criteria and converts query results into Relay-style paginated connections for the OpenFrame API.

## Key Components

| Method | Description |
|---|---|
| `toLogFilterCriteria(LogFilterInput)` | Converts GraphQL filter input to `LogFilterCriteria`, returning an empty criteria object when input is `null` |
| `toCursorPaginationCriteria(ConnectionArgs)` | Delegates `ConnectionArgs` to `CursorPaginationCriteria.fromConnectionArgs()` |
| `toSortInput(LogSortInput)` | Translates typed `LogSortField` enum to a generic `SortInput`; maps `TIMESTAMP` → `eventTimestamp` (Pinot column); returns `null` to trigger service default ordering |
| `toLogConnection(GenericQueryResult<LogEvent>)` | Builds a Relay-compatible `GenericConnection` with cursor-encoded edges from a raw query result |
| `createLogCursor(LogEvent)` | (private) Generates a stable cursor string as `epochMillis_toolEventId` for deterministic pagination |

## Usage Example

```java
@Autowired
private GraphQLLogMapper logMapper;

// Map filter + pagination + sort inputs from the GraphQL resolver
LogFilterCriteria criteria  = logMapper.toLogFilterCriteria(filterInput);
CursorPaginationCriteria pagination = logMapper.toCursorPaginationCriteria(connectionArgs);
SortInput sort = logMapper.toSortInput(sortInput); // null → service default

// After fetching from the service layer, convert to a paginated connection
GenericQueryResult<LogEvent> result = logService.queryLogs(criteria, pagination, sort);
GenericConnection<GenericEdge<LogEvent>> connection = logMapper.toLogConnection(result);
```

## Notes

- Cursor format is `{epochMillis}_{toolEventId}`, encoded via `CursorCodec.encode()` for opaque transmission to clients.
- Extending sort fields requires adding a new `case` to `toSortField()` and a corresponding entry in the `LogSortField` enum.
