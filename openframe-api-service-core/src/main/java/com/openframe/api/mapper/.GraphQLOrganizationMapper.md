Maps GraphQL organization inputs to internal DTOs and converts query results to GraphQL-compatible connection types for cursor-based pagination.

## Key Components

| Method | Description |
|---|---|
| `toFilterOptions(OrganizationFilterInput)` | Converts GraphQL filter input into `OrganizationFilterOptions`, returning `null` for null input |
| `toCursorPaginationCriteria(ConnectionArgs)` | Delegates to `CursorPaginationCriteria.fromConnectionArgs()` to build pagination criteria |
| `toSortInput(OrganizationSortInput)` | Maps `OrganizationSortInput` to a generic `SortInput`; defaults to `LAST_ACTIVITY DESC` when no sort is provided |
| `toOrganizationConnection(CountedGenericQueryResult)` | Transforms a paginated query result into a `CountedGenericConnection` with keyset cursors encoded via `CursorCodec` |

## Usage Example

```java
@Autowired
private GraphQLOrganizationMapper mapper;

// Convert filter input
OrganizationFilterInput filterInput = new OrganizationFilterInput();
filterInput.setStatus("ACTIVE");
filterInput.setMinEmployees(10);
OrganizationFilterOptions options = mapper.toFilterOptions(filterInput);

// Build sort — defaults to LAST_ACTIVITY DESC if null
SortInput sort = mapper.toSortInput(null);

// Convert pagination args
ConnectionArgs args = new ConnectionArgs(20, null, null, null);
CursorPaginationCriteria pagination = mapper.toCursorPaginationCriteria(args);

// Transform service result to GraphQL connection
CountedGenericQueryResult<Organization> result = organizationQueryService.query(options, sort, pagination);
CountedGenericConnection<GenericEdge<Organization>> connection = mapper.toOrganizationConnection(result);
```

> **Cursor encoding:** Each edge cursor is a compound `(lastActivityAt, _id)` keyset value encoded via `CursorCodec`, ensuring stable keyset pagination consistent with the page-info cursors produced by `OrganizationQueryService`.
