Assembles Relay-style GraphQL Connection envelopes for script execution results and converts `ConnectionArgs` into `CursorPaginationCriteria` for paginated queries.

## Key Components

| Member | Description |
|---|---|
| `toCursorPaginationCriteria(ConnectionArgs)` | Delegates to `CursorPaginationCriteria.fromConnectionArgs()` to translate GraphQL pagination arguments into persistence-layer criteria |
| `toConnection(CountedGenericQueryResult)` | Maps a counted query result into a Relay `CountedGenericConnection`, building `GenericEdge` wrappers with Base64-encoded cursors derived from each execution's ID |

## Usage Example

```java
@Component
public class ScriptExecutionResolver {

    private final GraphQLScriptExecutionMapper mapper;
    private final ScriptExecutionService service;

    public CountedGenericConnection<GenericEdge<ScriptExecutionResponse>> executions(
            ConnectionArgs args) {

        CursorPaginationCriteria criteria = mapper.toCursorPaginationCriteria(args);
        CountedGenericQueryResult<ScriptExecutionResponse> result =
                service.findExecutions(criteria);

        return mapper.toConnection(result);
    }
}
```

## Notes

- Cursor values are encoded via `CursorCodec.encode(id)` — one cursor per execution node.
- Entity ↔ DTO conversion is intentionally delegated to `ScriptExecutionMapper` in `openframe-api-lib`; this class handles only the GraphQL envelope layer.
- Mirrors the structure of `GraphQLScriptMapper` for consistency across the RMM module.
