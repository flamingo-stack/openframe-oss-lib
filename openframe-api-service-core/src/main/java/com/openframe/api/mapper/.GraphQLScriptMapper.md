Assembles Relay-compliant GraphQL Connection envelopes for script queries and converts `ConnectionArgs` into cursor-based pagination criteria.

## Key Components

| Member | Description |
|---|---|
| `toCursorPaginationCriteria(ConnectionArgs)` | Delegates to `CursorPaginationCriteria.fromConnectionArgs()` to translate Relay pagination arguments into internal pagination criteria |
| `toConnection(CountedGenericQueryResult<ScriptResponse>)` | Builds a `CountedGenericConnection` by mapping each `ScriptResponse` item into a `GenericEdge` with a Base64-encoded cursor derived from the script's ID |

## Usage Example

```java
@Component
public class ScriptDataFetcher {

    private final GraphQLScriptMapper graphQLScriptMapper;
    private final ScriptService scriptService;

    public CountedGenericConnection<GenericEdge<ScriptResponse>> scripts(ConnectionArgs args) {
        CursorPaginationCriteria criteria = graphQLScriptMapper.toCursorPaginationCriteria(args);
        CountedGenericQueryResult<ScriptResponse> result = scriptService.findAll(criteria);
        return graphQLScriptMapper.toConnection(result);
    }
}
```

## Notes

- Follows the same mapper split pattern as `GraphQLDeviceMapper` and `GraphQLNotificationMapper`: pure entity ↔ DTO mapping stays in `ScriptMapper` (in `openframe-api-lib`) while this class handles only GraphQL/Relay envelope concerns.
- Cursors are opaque encoded values generated via `CursorCodec.encode(id)`, keeping pagination stable against reordering.
