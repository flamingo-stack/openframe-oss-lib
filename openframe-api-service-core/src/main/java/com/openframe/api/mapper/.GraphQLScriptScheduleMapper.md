Assembles GraphQL Relay Connection envelopes for script schedules and converts `ConnectionArgs` to `CursorPaginationCriteria` for cursor-based pagination at the GraphQL layer.

## Key Components

| Member | Description |
|---|---|
| `toCursorPaginationCriteria(ConnectionArgs)` | Converts Relay-style `ConnectionArgs` (first/after/last/before) into `CursorPaginationCriteria` by delegating to `CursorPaginationCriteria.fromConnectionArgs()` |
| `toConnection(CountedGenericQueryResult)` | Maps a paginated query result into a `CountedGenericConnection`, building cursor-encoded `GenericEdge` wrappers for each `ScriptScheduleResponse` item |

## Usage Example

```java
@Autowired
GraphQLScriptScheduleMapper mapper;

// Convert Relay pagination args to internal criteria
CursorPaginationCriteria criteria = mapper.toCursorPaginationCriteria(args);

// Fetch data using criteria, then wrap result in a Relay Connection
CountedGenericQueryResult<ScriptScheduleResponse> result = scheduleService.find(criteria);
CountedGenericConnection<GenericEdge<ScriptScheduleResponse>> connection = mapper.toConnection(result);

// connection.edges()      → list of cursor-encoded edges
// connection.pageInfo()   → hasNextPage / hasPreviousPage
// connection.filteredCount() → total count for pagination UI
```

## Notes

- Pure entity ↔ DTO mapping is delegated to `ScriptScheduleMapper` in `openframe-api-lib`; this class handles only the GraphQL transport envelope.
- Mirrors the structure of [`GraphQLScriptMapper`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/api/mapper/GraphQLScriptMapper.java) for consistency across script-related GraphQL resolvers.
- Each edge cursor is Base64-encoded from `ScriptScheduleResponse.getId()` via `CursorCodec.encode()`.
