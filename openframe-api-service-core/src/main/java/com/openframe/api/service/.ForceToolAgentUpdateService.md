Orchestrates forced update operations for integrated tool agents across managed machines, publishing update events via NATS and returning per-machine status results.

## Key Components

| Member | Type | Description |
|---|---|---|
| `process(ForceToolAgentUpdateRequest)` | Public method | Triggers a forced update for a specific tool agent on a provided list of machine IDs |
| `processAll(String toolAgentId)` | Public method | Triggers a forced update for a specific tool agent across **all** registered machines |
| `processMachines(List<String>, String)` | Private method | Streams machine IDs and delegates each to `processMachine` |
| `processMachine(String, String)` | Private method | Fetches the `IntegratedToolAgent` config, publishes the update event, and returns a `PROCESSED` or `FAILED` status item |
| `buildResponseItem(...)` | Private method | Constructs a `ForceToolAgentUpdateResponseItem` with machine ID, tool agent ID, and status |
| `validateToolAgentId(String)` | Private method | Throws `IllegalArgumentException` if the tool agent ID is blank |
| `validateMachineIds(List<String>)` | Private method | Throws `IllegalArgumentException` if the machine list is empty |

## Usage Example

```java
// Force update a specific tool agent on selected machines
ForceToolAgentUpdateRequest request = new ForceToolAgentUpdateRequest();
request.setToolAgentId("crowdstrike-agent");
request.setMachineIds(List.of("machine-001", "machine-002"));

ForceToolAgentUpdateResponse response = forceToolAgentUpdateService.process(request);
response.getItems().forEach(item ->
    log.info("Machine: {}, Status: {}", item.getMachineId(), item.getStatus())
);

// Force update across all registered machines
ForceToolAgentUpdateResponse allResponse =
    forceToolAgentUpdateService.processAll("crowdstrike-agent");
```

## Error Handling

Per-machine failures are caught individually — a single machine failure returns `ForceAgentStatus.FAILED` for that item without halting the rest of the batch. Missing tool agent configuration throws `IllegalStateException` and is captured in the same per-machine error path.
