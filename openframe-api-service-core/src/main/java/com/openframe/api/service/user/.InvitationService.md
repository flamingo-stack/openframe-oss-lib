Manages the full lifecycle of user invitations within a tenant, including creation, listing, revocation, and renewal, while enforcing email domain policies and delegating post-processing and email delivery to collaborating services.

## Key Components

| Method | Description |
|---|---|
| `createInvitation(CreateInvitationRequest)` | Validates email domain and uniqueness, persists the invitation, sends an invitation email, and triggers post-processing hooks |
| `listInvitations(int page, int size)` | Returns a paginated list of invitations excluding `ACCEPTED` and `REVOKED` statuses |
| `revokeInvitation(String id)` | Marks a `PENDING` invitation as `REVOKED` and fires a post-revocation event |
| `renewInvitation(String expiredInvitationId)` | Creates a replacement invitation for an expired-but-pending invite, then revokes the old one |

**Dependencies:**
- `InvitationRepository` — MongoDB/data persistence
- `InvitationMapper` — DTO ↔ entity mapping
- `EmailService` — sends invitation emails
- `UserService` — checks for existing active users
- `InvitationProcessor` — post-processing hooks (e.g., audit, notifications)
- `EmailDomainPolicy` — enforces allowed email domain rules

## Usage Example

```java
// Create a new invitation
CreateInvitationRequest request = CreateInvitationRequest.builder()
    .email("technician@acme.com")
    .roles(List.of(Role.TECHNICIAN))
    .build();

InvitationResponse response = invitationService.createInvitation(request);

// List active (non-accepted, non-revoked) invitations
InvitationPageResponse page = invitationService.listInvitations(0, 20);

// Revoke a pending invitation
invitationService.revokeInvitation("inv_abc123");

// Renew an expired invitation (creates a new one, revokes the old)
InvitationResponse renewed = invitationService.renewInvitation("inv_expired456");
```

> **Note:** `createInvitation` will throw `IllegalStateException` if the email already belongs to an active tenant user, or if the domain is blocked by `EmailDomainPolicy`. `renewInvitation` requires the original invitation to be both `PENDING` status and past its `expiresAt` timestamp to avoid inconsistent states.
