Provides read-only access to the current release version document stored in the repository, returning the first available `ReleaseVersion` record.

## Key Components

| Element | Description |
|---|---|
| `ReleaseVersionQueryService` | Spring `@Service` bean responsible for querying release version data |
| `getReleaseVersion()` | Returns an `Optional<ReleaseVersion>` containing the first release version record found, or empty if none exists |
| `ReleaseVersionRepository` | Injected repository used to perform the underlying data lookup via `findFirstBy()` |

## Usage Example

```java
@RestController
@RequiredArgsConstructor
public class VersionController {

    private final ReleaseVersionQueryService releaseVersionQueryService;

    @GetMapping("/version")
    public ResponseEntity<ReleaseVersion> getVersion() {
        return releaseVersionQueryService.getReleaseVersion()
                .map(ResponseEntity::ok)
                .orElse(ResponseEntity.notFound().build());
    }
}
```

## Notes

- Returns `Optional.empty()` if no release version document exists, allowing callers to handle the absence gracefully.
- Delegates directly to `ReleaseVersionRepository.findFirstBy()`, making it a thin query wrapper with debug-level logging.
