GraphQL DGS component that resolves the Script Execution History tab, providing paginated execution records scoped to a specific saved script with Relay-compliant cursor pagination and batched field resolution.

## Key Components

| Member | Type | Description |
|---|---|---|
| `scriptExecutionNodeId` | `@DgsData` field resolver | Encodes raw execution ID as a Relay global ID (`ScriptExecution:<rawId>`) |
| `scriptExecutions` | `@DgsQuery` | Paginated, filterable list of executions for a given `scriptId`; decodes Relay global IDs before delegating to `ScriptExecutionService` |
| `scriptExecutionFilters` | `@DgsQuery` | Returns available filter facets (e.g. initiators) for the execution list; re-encodes raw user IDs to Relay global IDs in the response |
| `initiator` | `@DgsData` field resolver | Batches `UserResponse` lookups via `userDataLoader` |
| `scriptName` | `@DgsData` field resolver | Batches `ScriptResponse` lookups via `scriptDataLoader`, extracting only the name |
| `machine` | `@DgsData` field resolver | Batches `Machine` lookups via `machineDataLoader` |
| `decodeId` / `decodeIds` | Private helpers | Decode Relay global IDs to raw document IDs before service calls |
| `encodeNodeOptions` | Private helper | Re-encodes raw facet option values to Relay global IDs in place |

## Usage Example

```java
// GraphQL query — scriptId must be a Relay global ID
query {
  scriptExecutions(
    scriptId: "U2NyaXB0OjY2YWI..."
    filter: { initiatorIds: ["VXNlcjo2NmFi..."] }
    search: "deploy"
    sort: { field: "executedAt", direction: DESC }
    first: 20
    after: null
  ) {
    totalCount
    edges {
      node {
        id
        status
        scriptName
        initiator { id displayName }
        machine { id hostname }
      }
    }
    pageInfo { hasNextPage endCursor }
  }
}
```

> **ID handling:** All `scriptId` and `initiatorIds` inputs are expected as Relay global IDs. The resolver decodes them to raw document IDs before forwarding to `ScriptExecutionService`, and re-encodes filter facet values before returning them to the client — keeping the API surface consistently opaque.
