GraphQL DGS data fetcher that handles tag-related queries and mutations, including CRUD operations for tags and autocomplete/filtering support across device and script entity types.

## Key Components

| Member | Type | Description |
|---|---|---|
| `tagNodeId` | `@DgsData` | Converts internal tag ID to a Relay-compliant global ID |
| `tags` | `@DgsQuery` | Lists all tenant-wide device tags |
| `tagValueOptions` | `@DgsQuery` | Returns filter options for a given tag key |
| `tagKeySuggestions` | `@DgsQuery` | Autocompletes tag keys by optional search string and limit |
| `tagValueSuggestions` | `@DgsQuery` | Autocompletes tag values scoped to a specific key |
| `tagsByEntityType` | `@DgsQuery` | Filters tags by `TagEntityType` enum |
| `scriptsTags` | `@DgsQuery` | Retrieves script tags, with optional archived filter |
| `createTag` | `@DgsMutation` | Creates a new tag with key, entity type, description, and color |
| `updateTag` | `@DgsMutation` | Updates an existing tag by Relay global ID |
| `deleteTag` | `@DgsMutation` | Deletes a tag by Relay global ID, returns `true` on success |

## Usage Example

```java
// Query: fetch all tenant-wide tags
List<Tag> allTags = tagService.listTags();

// Query: get autocomplete suggestions for a tag key
List<Tag> suggestions = tagService.searchTagKeys("env", 10);

// Query: get tags filtered by entity type
List<Tag> deviceTags = tagService.findByEntityType(TagEntityType.DEVICE);

// Mutation: create a new tag
Tag created = tagService.createTag("environment", TagEntityType.DEVICE, "Deployment environment", "#FF5733");

// Mutation: update via Relay global ID
String rawId = RELAY.fromGlobalId(globalId).getId();
Tag updated = tagService.updateTag(rawId, "env", "Updated description", "#00FF00");

// Mutation: delete via Relay global ID
tagService.deleteTag(rawId);
```

## Notes

- All IDs exposed in the GraphQL API are **Relay global IDs** — `updateTag` and `deleteTag` decode them internally before delegating to `TagService`.
- Input validation uses `@NotBlank` / `@NotNull` (Jakarta), enforced via Spring's `@Validated`.
