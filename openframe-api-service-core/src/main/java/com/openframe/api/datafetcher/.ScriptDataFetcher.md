GraphQL data fetcher for RMM script operations, handling CRUD, execution, and filter queries via the DGS framework. Translates Relay global IDs to raw IDs before delegating to the service layer, and re-encodes raw IDs back to global IDs on responses.

## Key Components

| Member | Type | Description |
|---|---|---|
| `script` | `@DgsQuery` | Fetch a single script by Relay global ID |
| `scripts` | `@DgsQuery` | Paginated, filtered, and sorted script list returning a counted connection |
| `scriptFilters` | `@DgsQuery` | Faceted filter options for the script list view |
| `createScript` | `@DgsMutation` | Create a new script, stamped with the current user ID |
| `updateScript` | `@DgsMutation` | Update script content and metadata |
| `deleteScript` | `@DgsMutation` | Hard-delete a script by ID |
| `archiveScript` / `unarchiveScript` | `@DgsMutation` | Soft archive/restore lifecycle |
| `runScript` | `@DgsMutation` | Dispatch a script to a single device |
| `batchRunScript` | `@DgsMutation` | Dispatch a script to multiple devices |
| `scriptNodeId` | `@DgsData` | Field resolver — encodes raw ID to `Script:<id>` Relay global ID |
| `tags` | `@DgsData` | Batched field resolver for `Script.tags` via `scriptTagDataLoader` |
| `author` | `@DgsData` | Batched field resolver for `Script.author` via `userDataLoader` |

## Usage Example

```java
// GraphQL query — client sends Relay global IDs
query {
  scripts(
    filter: { tagIds: ["VGFnOjEyMw=="], authorIds: ["VXNlcjphYmMxMjM="] }
    first: 20
  ) {
    edges {
      node {
        id        # re-encoded Script:<rawId>
        name
        tags { id name }
        author { id email }
      }
    }
    totalCount
  }
}

// GraphQL mutation — IDs are decoded internally before reaching ScriptService
mutation {
  createScript(input: {
    name: "Disk Cleanup"
    content: "Remove-Item -Recurse C:\\Temp\\*"
    tagIds: ["VGFnOjEyMw=="]
  }) {
    id
    name
  }
}
```

> **ID handling:** All incoming Relay global IDs (`Script:*`, `Tag:*`, `User:*`) are decoded to raw document IDs before service calls. The `scriptNodeId` field resolver and `encodeNodeOptions` re-encode IDs outbound, so clients always work exclusively with opaque global IDs.
