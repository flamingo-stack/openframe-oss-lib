GraphQL DGS component that handles all CRUD operations, filtering, and field resolution for RMM script schedules. Acts as a passthrough layer to `ScriptScheduleService`, delegating tenant scoping to the service tier while managing Relay global ID encoding/decoding at the API boundary.

## Key Components

### Queries
- **`scriptSchedule`** — Fetches a single schedule by Relay global ID
- **`scriptSchedules`** — Paginated, filterable, sortable list of schedules with cursor-based pagination
- **`scriptScheduleFilters`** — Returns faceted filter options (authors re-encoded as Relay global IDs)

### Mutations
- **`createScriptSchedule`** — Creates a new schedule tied to the authenticated user
- **`updateScriptSchedule`** — Updates an existing schedule's fields and script assignments
- **`deleteScriptSchedule`** / **`archiveScriptSchedule`** / **`unarchiveScriptSchedule`** — Lifecycle management
- **`setScriptScheduleDevices`** — Replaces the full device assignment list for a schedule
- **`runScheduleJobNow`** — Ad-hoc immediate execution of a schedule via `ScriptDispatchService`

### Field Resolvers (`@DgsData`)
- **`id`** — Encodes raw MongoDB ID to `ScriptSchedule:<id>` Relay global ID
- **`scripts`** — Resolves script objects from stored script IDs via `ScriptService`
- **`assignedDevices`** — Relay connection of assigned `Machine` records with full filter/sort/pagination support; resolved synchronously to avoid DataLoader deadlocks
- **`deviceCount`** — Batched via `scriptScheduleDeviceIdsDataLoader` DataLoader
- **`author`** — Batched via `userDataLoader` DataLoader from `createdBy` field

### Utilities
- **`decodeId` / `decodeIds`** — Strips Relay type prefix from incoming global IDs before service calls
- **`encodeNodeOptions`** — Re-encodes raw IDs in filter facet options to Relay global IDs
- **`getCurrentUserId`** — Extracts user ID from JWT via `SecurityContextHolder`

## Usage Example

```java
// GraphQL query example (called via DGS framework, not instantiated directly)

// List schedules with filter and pagination
query {
  scriptSchedules(
    filter: { authorIds: ["VXNlcjoxMjM="] }
    first: 20
    after: "cursor=="
    sort: { field: "createdAt", direction: DESC }
  ) {
    totalCount
    edges {
      node {
        id
        author { id name }
        deviceCount
        scripts { id name }
        assignedDevices(first: 10) {
          edges { node { id hostname } }
        }
      }
    }
  }
}

// Mutation: assign devices to a schedule
mutation {
  setScriptScheduleDevices(
    scheduleId: "U2NyaXB0U2NoZWR1bGU6YWJjMTIz"
    machineIds: ["TWFjaGluZTp4eXo="]
  ) {
    id
    deviceCount
  }
}
```

> **Note:** All IDs crossing the GraphQL boundary are Relay global IDs (Base64-encoded `Type:rawId`). The fetcher handles encoding/decoding transparently — services always receive raw internal IDs.
