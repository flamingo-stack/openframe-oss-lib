Implements the GraphQL Relay `node` and `nodes` interface queries, resolving opaque global IDs to their corresponding domain objects across all supported entity types in the OpenFrame platform.

## Key Components

| Member | Description |
|---|---|
| `node(id)` | `@DgsQuery` — decodes a single Relay global ID and returns the matching entity |
| `nodes(ids)` | `@DgsQuery` — batch-resolves a list of global IDs; returns `null` for any unresolvable entry instead of failing the entire request |
| `resolveNode(globalId)` | Private dispatch method; decodes the type name via `NodeType.fromTypeName()` and routes to the appropriate service |
| `RELAY` | Static `graphql.relay.Relay` instance used for global ID decoding |

**Supported `NodeType` values:** `MACHINE`, `ORGANIZATION`, `EVENT`, `INTEGRATED_TOOL`, `TAG`, `TOOL_CONNECTION`, `INSTALLED_AGENT`, `SCRIPT`, `SCRIPT_EXECUTION`, `TENANT`

> `TenantRepository` is injected with `required = false` — tenant resolution is silently skipped when the repository bean is absent.

## Usage Example

```java
// GraphQL query — resolve a single node
query {
  node(id: "TWFjaGluZToxMjM=") {
    ... on Machine {
      id
      hostname
    }
  }
}

// GraphQL query — batch-resolve multiple nodes
query {
  nodes(ids: ["TWFjaGluZToxMjM=", "T3JnYW5pemF0aW9uOjQ1Ng=="]) {
    ... on Machine  { hostname }
    ... on Organization { name }
  }
}
```

```java
// The encoded ID decodes to e.g.:
Relay.ResolvedGlobalId globalId = RELAY.fromGlobalId("TWFjaGluZToxMjM=");
// globalId.getType()  → "Machine"
// globalId.getId()    → "123"
```
