Unit test suite for `ScriptMapper`, verifying field mapping correctness for `toEntity`, `updateEntity` (PUT semantics), and `toResponse` operations on RMM Script documents.

## Key Components

| Test Method | Purpose |
|---|---|
| `toEntity_mapsAllFieldsIncludingPrivilegeLevel` | Verifies all `CreateScriptInput` fields — including `shell` and `privilegeLevel` — are mapped onto a new `Script` entity |
| `updateEntity_nullsInInput_clearFieldsOnEntity` | Confirms PUT semantics: explicit `null` values on `UpdateScriptInput` clear corresponding entity fields |
| `updateEntity_doesNotTouchInternalFields` | Ensures immutable fields (`id`, `tenantId`, `status`) are never overwritten during an update |
| `updateEntity_fullyPopulatedInput_overwritesAllFields` | Validates that all writable fields are overwritten when a fully populated input is provided |
| `updateEntity_emptyListInput_clearsListField` | Confirms empty lists (`[]`) explicitly clear list fields, distinct from `null` |
| `toResponse_mapsStatusName` | Checks that the `ScriptStatus` enum is serialized to its string name |
| `toResponse_mapsPrivilegeLevel` | Verifies `PrivilegeLevel` and `createdBy` pass through to the response |
| `toResponse_nullPrivilegeLevel_fallsBackToUser` | Guards the non-null GraphQL schema field by defaulting `null` privilege to `USER` |
| `toResponse_nullStatus_fallsBackToActive` | Guards the non-null GraphQL schema field by defaulting `null` status to `"ACTIVE"` |

## Usage Example

```java
// Real mapper instance — no mocking (ScriptServiceTest handles that separately)
ScriptMapper mapper = new ScriptMapper();

// toEntity: create a new Script from tenant input
CreateScriptInput input = new CreateScriptInput();
input.setName("Backup");
input.setShell(ScriptShell.BASH);
input.setPrivilegeLevel(PrivilegeLevel.ADMIN);
Script entity = mapper.toEntity("tenant-1", input);

// updateEntity: PUT semantics — nulls clear existing values
UpdateScriptInput update = new UpdateScriptInput(); // all fields null
mapper.updateEntity(entity, update);                // clears all writable fields

// toResponse: null-safe fallbacks for non-null schema fields
entity.setStatus(null);
ScriptResponse response = mapper.toResponse(entity);
// response.getStatus() == "ACTIVE" (fallback)
```
