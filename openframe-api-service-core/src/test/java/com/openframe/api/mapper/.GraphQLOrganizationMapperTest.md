Unit tests for [`GraphQLOrganizationMapper`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/api/mapper/GraphQLOrganizationMapper.java), validating sort/filter mapping and compound cursor encoding for the Organization GraphQL layer.

## Key Components

| Test Method | What It Covers |
|---|---|
| `toSortInputDefaultsToLastActivityDesc` | Null `orderBy` defaults to `updatedAt` / `DESC` |
| `toSortInputMapsAscending` | `LAST_ACTIVITY` enum maps to `updatedAt` field and preserves `ASC` direction |
| `toFilterOptionsMapsLastActivityRange` | `lastActivityFrom`/`lastActivityTo` are propagated to `OrganizationFilterOptions` |
| `toOrganizationConnectionCompoundCursorAndCount` | Edge cursors encode as `<millis>_<id>` and `filteredCount` is passed through |

## Usage Example

```java
GraphQLOrganizationMapper mapper = new GraphQLOrganizationMapper();

// Sort mapping — null input falls back to default
SortInput defaultSort = mapper.toSortInput(null);
// → field: "updatedAt", direction: DESC

// Explicit sort
SortInput ascSort = mapper.toSortInput(
    OrganizationSortInput.builder()
        .field(OrganizationSortField.LAST_ACTIVITY)
        .direction(SortDirection.ASC)
        .build()
);
// → field: "updatedAt", direction: ASC

// Filter mapping
OrganizationFilterInput filter = new OrganizationFilterInput();
filter.setLastActivityFrom(Instant.ofEpochMilli(1_000));
filter.setLastActivityTo(Instant.ofEpochMilli(2_000));
OrganizationFilterOptions options = mapper.toFilterOptions(filter);

// Compound cursor format: "<updatedAt millis>_<id>"
// e.g. org with updatedAt=1234ms and id="the-id" → cursor decodes to "1234_the-id"
String raw = CursorCodec.decode(connection.getEdges().get(0).getCursor());
```

> **Cursor format:** Cursors combine the `updatedAt` epoch milliseconds and the document `id` as `<millis>_<id>`, enabling stable pagination when records share the same timestamp.
