Unit test suite for `ScriptDataFetcher`, verifying that the GraphQL resolver correctly wires queries and mutations to their backing services, handles Relay global ID encoding/decoding, and stamps the authenticated user's ID on write operations.

## Key Components

| Test Method | What It Verifies |
|---|---|
| `scriptNodeId_returnsGlobalId` | Node ID resolver returns Base64-encoded `"Script:<rawId>"` |
| `runScript` / `batchRunScript` | JWT `sub` claim extracted and forwarded to `ScriptDispatchService` |
| `script` | Relay global ID decoded to raw before `ScriptService.get()` |
| `scripts` | `ConnectionArgs` built, filter/sort/pagination forwarded, result mapped to connection |
| `scripts_decodesTagIdsAndAuthorIds` | Tag and User global IDs decoded in-place on `ScriptFilterInput` |
| `scriptFilters` | IDs decoded on input; author facet values re-encoded to User global IDs on output |
| `createScript` | JWT `sub` stamped on create; delegates to `ScriptService.create()` |
| `updateScript` | Global ID decoded in-place on `UpdateScriptInput` before service call |
| `deleteScript` / `archiveScript` / `unarchiveScript` | Global ID decoded before each service call |

**Mocked Dependencies:** `ScriptService`, `ScriptDispatchService`, `ScriptFilterService`, `GraphQLScriptMapper`

## Usage Example

```java
// Typical pattern: authenticate, call a mutation, verify service delegation
Jwt jwt = Jwt.withTokenValue("t").header("alg", "none").subject("user-1").build();
SecurityContextHolder.getContext().setAuthentication(
        new UsernamePasswordAuthenticationToken(jwt, null));
try {
    CreateScriptInput input = new CreateScriptInput();
    when(scriptService.create(input, "user-1")).thenReturn(expectedResp);

    assertThat(dataFetcher.createScript(input)).isSameAs(expectedResp);
    verify(scriptService).create(input, "user-1");
} finally {
    SecurityContextHolder.clearContext(); // always clean up
}
```
