Unit tests for `ScriptExecutionDataFetcher`, verifying that the GraphQL resolver correctly handles Relay global ID encoding/decoding, DataLoader-based batch field resolution, and null-safety across the `scriptExecutions` query and its related field resolvers.

## Key Components

| Test Method | What It Covers |
|---|---|
| `scriptExecutions` | Decodes Relay global IDs for `scriptId` and `initiatorIds`; passes raw machine UUIDs through unchanged |
| `scriptExecutionFilters` | Decodes IDs inbound, re-encodes `initiators` facet values as User global IDs outbound |
| `scriptExecutionNodeId_returnsGlobalId` | `id` field returns `Base64("ScriptExecution:<rawId>")`, not the raw Mongo ID |
| `scriptName_*` (3 tests) | Script name resolved at read time via `scriptDataLoader`; handles null `scriptId` and missing scripts |
| `initiator_*` (2 tests) | Initiator resolved via `userDataLoader`; null `initiatedBy` short-circuits without loader interaction |
| `machine_*` (3 tests) | Machine resolved via `machineDataLoader`; handles null `machineId` and deleted/missing devices |

**Mocks:** `ScriptExecutionService`, `ScriptExecutionFilterService`, `GraphQLScriptExecutionMapper`

## Usage Example

```java
// Run the full test suite
./mvnw test -pl api -Dtest=ScriptExecutionDataFetcherTest

// Run a specific test by display name pattern
./mvnw test -pl api -Dtest=ScriptExecutionDataFetcherTest#scriptName_resolvedViaLoader
```

## Key Design Decisions Validated

- **Relay ID contract:** `scriptId` and `initiatorIds` are always decoded from global IDs before hitting the service layer; machine IDs are plain UUIDs and bypass decoding.
- **No snapshotting:** Script display names are resolved at read time from `scriptId` via `scriptDataLoader`, not stored on the execution document.
- **Null-safety:** All three DataLoader field resolvers (`scriptName`, `initiator`, `machine`) return `null` without contacting the loader when their source ID is `null`, and gracefully return `null` when the loader itself returns `null` (e.g., deleted devices).
