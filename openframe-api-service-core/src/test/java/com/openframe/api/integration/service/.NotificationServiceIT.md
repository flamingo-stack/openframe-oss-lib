Integration test suite for `NotificationService.list`, verifying cursor-paginated notification retrieval with read-flag merging, audience isolation, filtering, search normalization, soft-delete exclusion, and sort behavior against a real MongoDB instance.

## Key Components

| Element | Purpose |
|---|---|
| `list_user_with_read_flag` | Asserts read state is correctly merged into `NotificationView.read` |
| `list_machine_recipient` | Verifies `MACHINE` recipient type receives its own notifications |
| `audience_isolation_by_id` | Confirms notifications addressed to another user are hidden |
| `audience_isolation_by_type` | Ensures `recipientType` disambiguates same-ID users vs. machines |
| `read_filter_narrows_page` | Validates `NotificationFilter(read=true/false)` returns only matching rows |
| `short_search_normalized_to_no_search` | Guards against single-character regex pollution |
| `whitespace_search_normalized_to_no_search` | Prevents untrimmed whitespace from acting as a search term |
| `search_no_match_returns_empty_page` | Confirms in-query search push-down returns empty result with `hasNextPage=false` |
| `deleted_excluded` | Asserts soft-deleted read states are excluded from default listings |
| `sort_asc_returns_oldest_first` | Validates explicit `ASC` sort override |
| `sort_null_defaults_to_desc` | Confirms `null` sort falls back to newest-first |
| `sort_invalid_field_falls_back_to_direction_only` | Unknown sort fields are ignored; direction is still honored |

## Usage Example

```java
// Run the integration tests (requires MongoDB)
// Pass system property to enable:
// -Dintegration.tests=true

@Test
void list_user_with_read_flag() {
    Notification n = mongoTemplate.save(NotificationFixtures.basic("welcome"));
    readStateService.createForAudience(
        n.getId(), NotificationCategory.TICKETS, "title", U, Set.of(ALICE));
    readStateService.markRead(ALICE, U, n.getId());

    GenericQueryResult<NotificationView> result =
        notificationService.list(ALICE, U, NotificationFilter.EMPTY, page10());

    assertThat(result.getItems()).hasSize(1);
    assertThat(result.getItems().get(0).read()).isTrue();
}
```

> **Note:** Tests are guarded by `@EnabledIfSystemProperty(named = "integration.tests", matches = "true")` and require a live MongoDB instance via `BaseMongoIntegrationTest`. See the [source](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/test/java/com/openframe/api/integration/service/NotificationServiceIT.java) for the full fixture setup.
