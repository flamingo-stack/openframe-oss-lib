Integration test suite for the `NotificationDataFetcher` GraphQL layer, verifying notification query, mutation, and read-state behavior against a real MongoDB instance using DGS and Spring Boot.

## Key Components

| Component | Role |
|---|---|
| `DgsQueryExecutor` | Executes raw GraphQL query/mutation strings against the DGS runtime |
| `NotificationReadStateService` | Creates and manages per-recipient read-state rows seeded before each test |
| `MongoTemplate` | Drops `Notification` and `NotificationReadState` collections in `@BeforeEach` for isolation |
| `BaseMongoIntegrationTest` | Base class providing embedded MongoDB lifecycle and `loginAsAdmin`/`loginAsAgent` helpers |
| `NotificationFixtures` | Factory for minimal `Notification` documents used as test data |

## Test Coverage

| Test | Scenario |
|---|---|
| `admin_lists_own_rows` | Admin JWT resolves USER-addressed read-state rows |
| `agent_lists_machine_rows` | Agent JWT with `machine_id` claim resolves MACHINE-addressed rows |
| `has_unread` | `hasUnreadNotifications` flips from `true` → `false` after `markRead` |
| `mark_as_read` | `markNotificationAsRead` mutation accepts a Relay global ID and returns `true` |
| `mark_all_as_read` | `markAllNotificationsAsRead` returns count of updated rows |
| `delete_notification` | `deleteNotification` soft-deletes a single row by Relay global ID |
| `delete_all_read` | `deleteAllReadNotifications` transitions only READ rows, leaves UNREAD untouched |
| `admin_lists_oldest_first_with_sort_asc` | `sort: { direction: ASC }` returns edges oldest-first |
| `admin_lists_newest_first_by_default` | Default (no sort arg) returns edges newest-first |

## Usage Example

```java
// Activate with -Dintegration.tests=true; requires a running/embedded MongoDB
@Test
void mark_as_read() {
    loginAsAdmin(ALICE);
    Notification n = mongoTemplate.save(NotificationFixtures.basic());
    readStateService.createForAudience(
        n.getId(), NotificationCategory.TICKETS, "title",
        RecipientType.USER, Set.of(ALICE));

    String globalId = RELAY.toGlobalId("Notification", n.getId());
    ExecutionResult res = queryExecutor.execute(
        "mutation($id: ID!) { markNotificationAsRead(notificationId: $id) }",
        Map.of("id", globalId));

    assertThat(res.getErrors()).isEmpty();
    assertThat(res.<Map<String, Object>>getData()
        .get("markNotificationAsRead")).isEqualTo(true);
}
```

> Tests are gated by `@EnabledIfSystemProperty(named = "integration.tests", matches = "true")` and require the `integration` tag.
