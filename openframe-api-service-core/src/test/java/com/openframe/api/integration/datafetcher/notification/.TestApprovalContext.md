Concrete `NotificationContext` implementation carrying the payload for test-approval notification events, pairing a ticket identifier with an approval request identifier.

## Key Components

| Member | Type | Description |
|---|---|---|
| `TYPE` | `static final String` | Constant sourced from `TestApprovalContextDescriptor.TYPE`; returned by `getType()` to identify this context variant |
| `ticketId` | `String` | ID of the ticket associated with the approval request |
| `approvalRequestId` | `String` | ID of the specific approval request being actioned |
| `getType()` | `@Override` | Returns `TYPE`; used by the notification framework for polymorphic deserialization |

**Lombok annotations:** `@Data`, `@SuperBuilder`, `@NoArgsConstructor`, `@AllArgsConstructor`, `@EqualsAndHashCode(callSuper = true)`, `@ToString(callSuper = true)` — generate accessors, builder, constructors, and inherited-field-aware equality/toString.

`@JsonIgnoreProperties(value = "type", allowGetters = true)` prevents Jackson from attempting to deserialize the `type` field while still serializing it via `getType()`.

## Usage Example

```java
// Build via Lombok SuperBuilder
TestApprovalContext ctx = TestApprovalContext.builder()
    .ticketId("TKT-4821")
    .approvalRequestId("APR-0093")
    .build();

// Type discrimination
String contextType = ctx.getType(); // TestApprovalContextDescriptor.TYPE

// Pass to notification dispatch
notificationService.send(recipientId, ctx);
```
