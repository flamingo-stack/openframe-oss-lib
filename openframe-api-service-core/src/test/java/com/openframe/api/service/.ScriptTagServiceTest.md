Unit test suite for `ScriptTagService`, verifying tag retrieval and replacement behavior for script entities using Mockito mocks.

## Key Components

| Component | Description |
|---|---|
| `getTagsByScriptIds_alignedPerScript` | Verifies tags are returned per-script in input order; scripts with no assignments receive an empty list |
| `getTagsByScriptIds_empty` | Asserts empty input short-circuits without touching any repository |
| `replaceTags_deletesThenSavesDistinct` | Confirms existing assignments are deleted before saving, and duplicate tag IDs are deduplicated |
| `replaceTags_nullClears` | Validates that `null` tag list clears all assignments without calling `save` |

## Usage Example

```java
// Arrange
when(tagAssignmentRepository.findByEntityIdInAndEntityType(List.of("s1", "s2"), SCRIPT))
    .thenReturn(List.of(assignment("s1", "t1"), assignment("s1", "t2")));
when(tagRepository.findAllById(any()))
    .thenReturn(List.of(tag("t1"), tag("t2")));

// Act
List<List<Tag>> result = service.getTagsByScriptIds(List.of("s1", "s2"));

// Assert — s1 has two tags, s2 has none
assertThat(result.get(0)).extracting(Tag::getId).containsExactlyInAnyOrder("t1", "t2");
assertThat(result.get(1)).isEmpty();
```

## Coverage Summary

- **Repository isolation**: `verifyNoInteractions` guards against unnecessary DB calls on empty input
- **Deduplication**: `replaceTags` with `["t1", "t2", "t1"]` results in exactly two `save` calls
- **Entity type enforcement**: All saved `TagAssignment` instances carry `TagEntityType.SCRIPT`
