Unit test suite for `ScriptExecutionService`, verifying script execution creation, batch dispatch, and list filtering behavior using Mockito mocks.

## Key Components

| Test Method | Purpose |
|---|---|
| `create_persistsRunningRow` | Asserts a `RUNNING` `ScriptExecution` document is saved with correct fields; result-side fields (`stdout`, `stderr`, etc.) are null on dispatch |
| `create_alwaysUsesTenantIdProvider` | Enforces pod-scoped tenant isolation — `tenantId` always comes from `TenantIdProvider`, never caller input |
| `create_acceptsNullInitiatedBy` | Validates null `initiatedBy` is persisted without NPE, maintaining history row integrity |
| `create_forwardsPrivilegeLevelVerbatim` | Confirms `USER` vs `ADMIN` privilege level is forwarded exactly as dispatched |
| `createBatch_persistsOneRowPerMachine` | Verifies one `RUNNING` row per `machineId` under a shared `executionId`, with a single `dispatchedAt` timestamp across the batch |
| `list_translatesStatusFilterToRepository` | Confirms `ScriptExecutionFilterInput.statuses` is translated to `ScriptExecutionQueryFilter` and forwarded to both count and page queries |
| `list_translatesInitiatorFilterToRepository` | Confirms `initiatorIds` is translated to `initiatedByIds` in the query filter for both repository calls |

## Usage Example

```java
// Service wired with mocks — mirrors setUp() in the test class
ScriptExecutionService service = new ScriptExecutionService(
    scriptExecutionRepository,
    tenantIdProvider,
    new ScriptExecutionMapper()
);

// Single ad-hoc dispatch
ScriptExecutionResponse response = service.create(
    "exec-abc", "script-1", "machine-42",
    PrivilegeLevel.ADMIN, 90, "user-mr-anderson"
);

// Scheduled batch dispatch across multiple machines
service.createBatch(
    "exec-abc", "script-1", "sched-1",
    List.of("m-1", "m-2", "m-3"),
    PrivilegeLevel.ADMIN, 90, "user-mr-anderson"
);

// Paginated list with status filter
service.list(
    "script-1",
    ScriptExecutionFilterInput.builder()
        .statuses(List.of(ExecutionStatus.SUCCESS, ExecutionStatus.FAILED))
        .build(),
    null, null,
    CursorPaginationCriteria.builder().limit(10).build()
);
```
