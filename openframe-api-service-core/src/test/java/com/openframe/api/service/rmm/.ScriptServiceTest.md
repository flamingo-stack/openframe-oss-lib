Unit test suite for `ScriptService`, verifying CRUD operations, pagination, soft-delete behavior, batch resolution, and conflict/not-found error handling using Mockito.

## Key Components

| Component | Description |
|---|---|
| `ScriptServiceTest` | Main test class annotated with `@ExtendWith(MockitoExtension.class)` |
| `scriptRepository` | Mocked `ScriptRepository` for data access isolation |
| `scriptMapper` | Mocked `ScriptMapper` for entity↔DTO conversion |
| `tenantIdProvider` | Mocked `TenantIdProvider` returning `"tenant-1"` |
| `scriptTagService` | Mocked `ScriptTagService` for tag assignment verification |
| `UNIQUE_STATUSES` | Mirrors the service constant — only `ACTIVE` and `ARCHIVED` (not `DELETED`) are checked for name uniqueness |

## Usage Example

```java
// Run the full suite
./mvnw test -pl openframe-api -Dtest=ScriptServiceTest

// Run a single test by display name (JUnit 5 / Maven Surefire 3.x)
./mvnw test -pl openframe-api \
  -Dtest="ScriptServiceTest#create_whenNameUnique_persistsAndReturnsResponse"
```

## Key Scenarios Covered

| Test | Behavior Verified |
|---|---|
| `create_whenNameUnique` | Entity persisted, `createdBy` stamped, tags replaced |
| `create_whenNameAlreadyExists` | `ConflictException` thrown, `save()` never called |
| `create_whenInputHasEnvVars` | Env vars (including secrets) flow through mapper unchanged |
| `get_whenExists` | Mapped response returned |
| `get_whenNotFound` | `NotFoundException` thrown |
| `findById_whenDeleted` | Returns `Optional.empty()` without throwing |
| `getScriptsByIds_includesSoftDeleted` | Soft-deleted scripts still resolved (required for history nodes) |
| `getScriptsByIds_emptyInput` | Short-circuits — no repository or tenant lookup performed |
| `list_forwardFirstPage` | Fetches `limit+1` rows, drops sentinel, sets `hasNextPage=true` |

## Notes

- **Tenant isolation** — every repository call is scoped to `TENANT_ID`; the `lenient()` stub on `getTenantId()` prevents unnecessary stubbing failures on the early-exit `getScriptsByIds` path.
- **Soft-delete semantics** — `findById` returns `Optional.empty()` for `DELETED` scripts, while `getScriptsByIds` intentionally includes them so historical references (e.g. script run history) can still resolve a script's name.
- **Name-uniqueness scope** — collision detection intentionally excludes `DELETED` records, mirroring the `UNIQUE_STATUSES` constant in `ScriptService`.
