Unit test suite for `ScriptFilterOptionMapper`, verifying that raw aggregation maps (`Map<String, Integer>`) are correctly converted into labeled `ScriptFilterOption` lists for script filter dropdowns in the RMM service.

## Key Components

| Test Method | What It Covers |
|---|---|
| `selfLabeled_valueEqualsLabel` | Raw key is used as both `value` and `label`; count is preserved |
| `userLabeled_labelFallbacks` | Label resolution: full name → email → raw ID |
| `userLabeled_missingUser_fallsBackToId` | Unresolvable user ID falls back to the raw ID as label |
| `userLabeled_empty_skipsLookup` | Empty input returns empty list without hitting `UserRepository` |
| `machineLabeled_labelsByHostname` | Label resolution: hostname → displayName → raw ID |
| `machineLabeled_missingMachine_fallsBackToId` | Unresolvable machine ID falls back to the raw ID as label |
| `machineLabeled_empty_skipsLookup` | Empty input returns empty list without hitting `MachineRepository` |

**Mocks:** `UserRepository`, `MachineRepository`
**Subject under test:** `ScriptFilterOptionMapper`

## Usage Example

```java
// Typical assertion pattern used in this suite
when(userRepository.findAllById(any())).thenReturn(List.of(
    user("u-1", "Neo", "Anderson", "neo@example.com"),  // resolved to full name
    user("u-2", null, null, "trinity@example.com")));   // resolved to email

List<ScriptFilterOption> options = mapper.userLabeled(Map.of("u-1", 4, "u-2", 2));

assertThat(options)
    .anySatisfy(o -> {
        assertThat(o.getValue()).isEqualTo("u-1");
        assertThat(o.getLabel()).isEqualTo("Neo Anderson");
    });
```

## Label Resolution Priority

```text
User:    fullName (first + last) → email → raw ID
Machine: hostname → displayName → raw ID
Self:    raw key (value == label)
```
