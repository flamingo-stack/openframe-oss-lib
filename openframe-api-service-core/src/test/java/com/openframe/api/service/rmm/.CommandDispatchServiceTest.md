Unit test suite for `CommandDispatchService`, validating command dispatch, cancellation, and batch execution behavior across single and multi-machine scenarios using Mockito mocks for NATS publishing and device/execution services.

## Key Components

| Component | Role |
|---|---|
| `CommandDispatchService` | Subject under test — dispatches run/cancel/batch commands |
| `CommandNatsPublisher` | Mocked NATS publisher for asserting wire payloads |
| `DeviceService` | Mocked device lookup; controls machine-found/not-found paths |
| `CommandExecutionService` | Mocked persistence layer for batch execution records |
| `RunCommandInput` / `BatchRunCommandInput` / `CancelExecutionInput` | DTOs used to build test inputs |

## Test Coverage

| Test | Scenario |
|---|---|
| `runCommand_rejectsUnknownMachine` | Throws `DeviceNotFoundException`; nothing published |
| `runCommand_publishesAndReturnsExecutionId` | Valid machine → publishes full wire payload, returns matching `executionId` |
| `runCommand_forwardsPrivilegeLevelVerbatim` | `USER` vs `ADMIN` privilege is not silently overridden |
| `runCommand_forwardsOptionalFieldsVerbatim` | `timeoutSeconds` is passed through unchanged |
| `runCommand_generatesDistinctExecutionIds` | Three consecutive calls produce three unique IDs |
| `cancelExecution_publishesCancelAndEchoesExecutionId` | Relays caller's `executionId` in `CancelMessage` |
| `cancelExecution_doesNotGenerateNewExecutionId` | Cancel never mints a new ID |
| `cancelExecution_doesNotPublishCommand` | Cancel and run use separate NATS subjects |
| `batchRunCommand_persistsPendingThenFansOut` | Single shared `executionId`, one row + publish per machine |
| `batchRunCommand_savesBeforePublishing` | DB write happens before any NATS publish (ordering assertion) |
| `batchRunCommand_dedupsMachineIds` | Duplicate machine IDs collapse to one row/publish |

## Usage Example

```java
// Typical pattern: verify full wire payload using ArgumentCaptor
ArgumentCaptor<CommandMessage> captor = ArgumentCaptor.forClass(CommandMessage.class);
verify(commandNatsPublisher).publishCommand(eq(MACHINE_ID), captor.capture());

CommandMessage sent = captor.getValue();
assertThat(sent.getExecutionId()).isEqualTo(response.getExecutionId());
assertThat(sent.getShell()).isEqualTo(ScriptShell.BASH);
assertThat(sent.getPrivilegeLevel()).isEqualTo(PrivilegeLevel.ADMIN);
```
