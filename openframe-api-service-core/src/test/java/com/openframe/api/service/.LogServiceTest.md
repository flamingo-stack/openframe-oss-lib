Unit test suite for `LogService#queryLogs`, verifying that timestamp range bounds and sort direction are correctly passed to `PinotLogRepository`, and that a search term routes to `searchLogs` instead of `findLogs`.

## Key Components

| Component | Description |
|---|---|
| `findLogsReceivesRangeAndDirection` | Asserts `FROM`/`TO` timestamps and `ASC` sort direction are forwarded to `pinotLogRepository.findLogs` |
| `searchTermRoutesToSearchLogs` | Asserts a non-null search term routes to `pinotLogRepository.searchLogs`, carrying the same range and `DESC` direction |
| `setUp()` | Wires a `LogService` instance with mocked `PinotLogRepository`, `UnifiedLogEventRepository`, and `TenantIdProvider` |
| `rangeFilter()` | Helper that builds a `LogFilterCriteria` with a fixed 1–2 second epoch range |
| `page()` | Helper that builds a `CursorPaginationCriteria` with a limit of 20 |

## Usage Example

```java
// Reproducing test setup for a custom scenario
PinotLogRepository pinotRepo = mock(PinotLogRepository.class);
UnifiedLogEventRepository cassandraRepo = mock(UnifiedLogEventRepository.class);
TenantIdProvider tenantProvider = mock(TenantIdProvider.class);

LogService service = new LogService(pinotRepo, cassandraRepo, tenantProvider);

when(tenantProvider.getTenantId()).thenReturn("tenant-xyz");
when(pinotRepo.isSortableField(any())).thenReturn(true);
when(pinotRepo.getDefaultSortField()).thenReturn("eventTimestamp");
when(pinotRepo.findLogs(...)).thenReturn(List.of());

SortInput sort = SortInput.builder()
    .field("eventTimestamp")
    .direction(SortDirection.ASC)
    .build();

LogFilterCriteria filter = LogFilterCriteria.builder()
    .timestampFrom(Instant.ofEpochMilli(1_000))
    .timestampTo(Instant.ofEpochMilli(2_000))
    .build();

service.queryLogs(filter, page, null, sort);

// Verify range and direction passed through
verify(pinotRepo).findLogs(eq("tenant-xyz"), ..., eq(FROM), eq(TO), ..., eq("ASC"));
```

## Notes

- Tests use Mockito stubs; no real database or Spring context is loaded.
- Both `findLogs` and `searchLogs` method signatures are wide (14–15 args); `any()` matchers cover non-critical positional parameters.
