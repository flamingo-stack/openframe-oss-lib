Handles machine tag event processing by listening for save and delete operations on `Machine`, `Tag`, and `TagAssignment` entities, then publishing enriched `MachinePinotMessage` events to a Kafka topic.

## Key Components

| Method | Description |
|---|---|
| `processMachineSave` | Processes a single machine save event and publishes to Kafka |
| `processMachineSaveAll` | Iterates over multiple machines and publishes each to Kafka |
| `processTagAssignmentSave` | Handles tag assignment saves, filtered to `DEVICE` entity type only |
| `processTagAssignmentSaveAll` | Batch-processes tag assignments, deduplicating by `entityId` |
| `processTagSave` | Propagates a tag update to all associated machines via Kafka |
| `processTagSaveAll` | Batch version of tag save propagation |
| `processTagAssignmentDelete` | Publishes a machine event excluding a removed tag assignment |
| `processTagAssignmentDeleteByTagId` | Bulk removes a tag from all affected machines and republishes each |

## Usage Example

```java
// Injected via Spring context
@Autowired
private MachineTagEventService machineTagEventService;

// Trigger after saving a machine document
machineTagEventService.processMachineSave(machine);

// Trigger after assigning a tag to a device
machineTagEventService.processTagAssignmentSave(tagAssignment);

// Trigger after deleting a specific tag-machine relationship
machineTagEventService.processTagAssignmentDelete(machineId, tagId);

// Trigger after deleting a tag entirely (propagates to all machines)
machineTagEventService.processTagAssignmentDeleteByTagId(tagId);
```

## Notes

- Only active when `openframe.device.aspect.enabled=true` (default: `true`)
- Kafka topic is configured via `openframe.oss-tenant.kafka.topics.outbound.devices-topic`
- All public methods include exception handling to prevent event loss from propagating upstream
- Tag propagation on delete reconstructs the remaining tag list before publishing, ensuring Pinot receives accurate state
