Configuration properties class that binds Fleet MDM multi-tenancy settings from `openframe.fleet.multi-tenancy.*` YAML properties for the OpenFrame API gateway.

## Key Components

| Member | Type | Description |
|--------|------|-------------|
| `enabled` | `boolean` | Master switch for Fleet multi-tenancy; defaults to `false` |
| `allowedEndpoints` | `List<String>` | Allowlisted `"METHOD pattern"` strings checked against paths under `/tools/fleetmdm-server/**` |
| `upstream` | `Upstream` | Nested container for shared-Fleet upstream routing targets |
| `Upstream.api` | `Endpoint` | HTTP API upstream URL and port |
| `Upstream.websocket` | `Endpoint` | WebSocket upstream URL and port |
| `Endpoint` | static class | Simple `url` + `port` pair for a single upstream target |

## Usage Example

```yaml
openframe:
  fleet:
    multi-tenancy:
      enabled: true
      allowed-endpoints:
        - "GET /api/{v}/fleet/hosts"
        - "DELETE /api/{v}/fleet/labels/id/{id}"
      upstream:
        api:
          url: http://fleet.fleet-shared.svc.cluster.local
          port: "8080"
        websocket:
          url: ws://fleet.fleet-shared.svc.cluster.local
          port: "8080"
```

```java
@Service
public class FleetProxyFilter {

    private final FleetMultiTenancyProperties props;

    public FleetProxyFilter(FleetMultiTenancyProperties props) {
        this.props = props;
    }

    public boolean isRequestAllowed(String method, String path) {
        if (!props.isEnabled()) {
            return true; // multi-tenancy off — no restrictions apply
        }
        String candidate = method.toUpperCase() + " " + path;
        return props.getAllowedEndpoints().stream()
                    .anyMatch(candidate::matches);
    }

    public String getApiUpstreamUrl() {
        FleetMultiTenancyProperties.Endpoint api = props.getUpstream().getApi();
        return api.getUrl() + ":" + api.getPort();
    }
}
```

> **Note:** When `enabled` is `false` (default), the allowlist and shared upstream are ignored entirely — only the Fleet browser proxy path is affected when the flag is `true`.
