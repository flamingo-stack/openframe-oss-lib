A reactive WebSocket client decorator that wraps a delegate `WebSocketClient` to add session cleanup, connection lifecycle logging, and upstream relay state tracking for the OpenFrame API gateway proxy.

## Key Components

| Member | Description |
|---|---|
| `execute(URI, WebSocketHandler)` | Delegates execution while injecting relay tracking and wrapped handler |
| `execute(URI, HttpHeaders, WebSocketHandler)` | Overload that also extracts tenant ID from routing headers for log context |
| `decorateConnection(...)` | Attaches debug/warn lifecycle logging to the upstream connection using the authenticated JWT `sub` claim |
| `wrapHandler(...)` | Returns a `WebSocketHandler` that sets the `relayStarted` flag on session open and triggers cleanup on completion |
| `closeIfLeaked(...)` | Races the session's natural close signal against a configurable grace timer; force-closes only if the session is genuinely leaked, preventing double-release of `CloseWebSocketFrame` |
| `isPeerClosed(Throwable)` | Classifies an exception as an expected peer-initiated close versus a genuine connect/handshake failure |
| `authenticatedSub()` | Reads the authenticated principal name (JWT `sub`) from the reactive security context for log correlation |

## Usage Example

```java
WebSocketClient rawClient = new ReactorNettyWebSocketClient();
WebSocketLoggingProperties loggingProps = new WebSocketLoggingProperties();

ProxySessionCleanupWebSocketClient proxyClient =
    new ProxySessionCleanupWebSocketClient(rawClient, loggingProps, /* cleanupEnabled= */ true);

// Used as a drop-in WebSocketClient replacement in the gateway proxy configuration
proxyClient.execute(
    URI.create("ws://backend-service/ws"),
    requestHeaders,
    upstreamHandler
).subscribe();
```

The `cleanupEnabled` flag allows cleanup to be toggled via configuration without replacing the bean, and `WebSocketLoggingProperties.isDebugPath()` gates per-path verbose logging independently of the cleanup logic.
