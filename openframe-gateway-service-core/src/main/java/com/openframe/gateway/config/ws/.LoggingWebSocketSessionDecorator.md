A decorator for Spring WebFlux `WebSocketSession` that taps inbound and outbound WebSocket frames for debug logging without consuming or releasing the underlying Netty buffers, ensuring the proxied stream remains intact.

## Key Components

| Component | Description |
|---|---|
| `LoggingWebSocketSessionDecorator` | Implements `WebSocketSession`; wraps a delegate session and intercepts `receive()` / `send()` to log frame metadata |
| `receive()` | Taps client→gateway frames via `doOnNext`, logging type, byte count, and payload preview |
| `send(Publisher)` | Taps gateway→client frames by wrapping the upstream `Publisher` in a logging `doOnNext` |
| `logFrame(String, WebSocketMessage)` | Core logging method; guarded by `isDebugEnabled()`, handles TEXT, binary, and control frames separately |
| `truncate(String, int)` | Trims TEXT payloads to `maxChars` and appends a length suffix when truncated |
| `toPrintablePreview(DataBuffer, int)` | Renders binary payloads as printable ASCII (non-printable bytes → `'.'`) using absolute `getByte()` reads that do not advance the reader index |
| `WebSocketLoggingProperties` | Injected config controlling `maxLoggedPayloadChars` and the `logBinaryPayload` flag |

## Usage Example

```java
// Wrap the incoming WebSocketSession before passing it to your handler
WebSocketHandler loggingHandler = session -> {
    String path = session.getHandshakeInfo().getUri().getPath();
    String tenant = extractTenant(session);

    WebSocketSession loggingSession = new LoggingWebSocketSessionDecorator(
        session,
        path,
        tenant,
        loggingProperties  // injected WebSocketLoggingProperties bean
    );

    return upstreamHandler.handle(loggingSession);
};
```

At `DEBUG` log level, each relayed frame produces a line such as:

```text
Debug ws frame client->gw sessionId=abc123 path=/ws/mesh tenant=acme
    type=TEXT bytes=42 payload={"action":"hello","sessionid":"..."}
```

All other `WebSocketSession` methods (`getId`, `close`, `bufferFactory`, etc.) are pure pass-throughs to the wrapped delegate.
