Configuration properties class for WebSocket logging behavior in the OpenFrame gateway, binding external config under the `openframe.gateway.websocket.logging` prefix.

## Key Components

| Member | Type | Default | Description |
|---|---|---|---|
| `debugPathPrefixes` | `List<String>` | `["/ws/"]` | Path prefixes that trigger debug-level WebSocket logging |
| `framePathPrefixes` | `List<String>` | `[]` | Path prefixes for frame payload logging; falls back to `debugPathPrefixes` if empty |
| `framePayloadLoggingEnabled` | `boolean` | `false` | Master switch for frame-level payload logging |
| `maxLoggedPayloadChars` | `int` | `1024` | Character cap applied to all logged payloads |
| `logBinaryPayload` | `boolean` | `false` | Hex-renders binary/PING/PONG frames up to `maxLoggedPayloadChars`; useful for tunnels like MeshCentral `agent.ashx` |
| `isDebugPath(String)` | method | — | Returns `true` if path starts with any `debugPathPrefixes` entry |
| `isFramePath(String)` | method | — | Returns `true` if frame logging is enabled and path matches frame or debug prefixes |

## Usage Example

```java
// Injected automatically by Spring Boot
@Autowired
private WebSocketLoggingProperties wsLogging;

// Check before emitting verbose logs
if (wsLogging.isDebugPath(request.getURI().getPath())) {
    log.debug("WebSocket upgrade request: {}", request);
}

// Check before logging frame payloads
if (wsLogging.isFramePath(session.getUri().getPath())) {
    log.trace("Frame payload (capped at {} chars): {}",
        wsLogging.getMaxLoggedPayloadChars(), truncate(payload));
}
```

Corresponding `application.yml` override:

```yaml
openframe:
  gateway:
    websocket:
      logging:
        debug-path-prefixes: ["/ws/", "/mesh/"]
        frame-payload-logging-enabled: true
        max-logged-payload-chars: 512
        log-binary-payload: true
```

> **Note:** `logBinaryPayload` can generate high log volume on active binary tunnels — keep `maxLoggedPayloadChars` at a reasonable cap in production.
