Configures Spring Cloud Gateway's WebSocket routing and service infrastructure for the OpenFrame API gateway, wiring up routes for tool agents, tool APIs, and NATS messaging with tenant-aware filtering and security decoration.

## Key Components

### Constants
| Constant | Path |
|---|---|
| `TOOLS_AGENT_WS_ENDPOINT_PREFIX` | `/ws/tools/agent` |
| `TOOLS_API_WS_ENDPOINT_PREFIX` | `/ws/tools` |
| `NATS_WS_ENDPOINT_PATH` | `/ws/nats` |
| `NATS_API_WS_ENDPOINT_PATH` | `/ws/nats-api` |

### Beans

- **`customRouteLocator`** — Defines four WebSocket routes:
  - `agent_gateway_websocket_route` — Proxies `/ws/tools/agent/{toolId}/**` via `ToolAgentWebSocketProxyUrlFilter`
  - `api_gateway_websocket_route` — Proxies `/ws/tools/{toolId}/**` via `ToolApiWebSocketProxyUrlFilter`
  - `nats_websocket_route` / `nats_api_websocket_route` — Forwards NATS paths to `nats-ws-url`, applying `NamespaceRewriteGatewayFilter` for multi-tenant namespace resolution

- **`proxyCleanupWebSocketClient`** (`@Primary`) — Wraps the default Reactor Netty `WebSocketClient` with `ProxySessionCleanupWebSocketClient` when proxy cleanup or frame-level payload logging is enabled; falls back to the delegate otherwise

- **`webSocketServiceDecorator`** (`@Primary`) — Decorates the default `WebSocketService` with `WebSocketServiceSecurityDecorator` to enforce JWT claims validation and record traffic metrics

## Usage Example

```java
// Route resolution at runtime (handled automatically by Spring Cloud Gateway)
// Incoming request: GET /ws/tools/agent/my-tool-123/stream
// → matched by "agent_gateway_websocket_route"
// → ToolAgentWebSocketProxyUrlFilter rewrites the upstream target URL
// → proxied to the resolved backend WebSocket server

// NATS route with namespace rewrite (multi-tenant)
// Incoming request: GET /ws/nats (from tenant "acme")
// → NamespaceRewriteGatewayFilter substitutes namespace placeholder in nats-ws-url
// → forwarded to nats://acme-namespace:4222
```

## Configuration Properties

```yaml
nats-ws-url: ws://nats-placeholder-namespace:4222
openframe:
  gateway:
    websocket:
      proxy-cleanup:
        enabled: true
```
