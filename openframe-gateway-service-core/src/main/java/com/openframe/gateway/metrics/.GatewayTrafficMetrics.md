Micrometer-based metrics component for tracking WebSocket traffic on the OpenFrame tenant gateway. It exposes a live gauge for active connections and low-cardinality counters for upgrade rejections and session closures.

## Key Components

| Member | Type | Description |
|---|---|---|
| `activeWebSocketConnections` | `AtomicInteger` (Gauge) | Live count of open WebSocket sessions; published as `openframe.tenant.gateway.websocket.connections.active` |
| `webSocketOpened()` | Method | Increments the active connection gauge and logs session context |
| `webSocketClosed()` | Method | Decrements the active connection gauge (floor-clamped to 0) and logs session context |
| `recordUpgradeRejected()` | Method | Increments `openframe.tenant.gateway.websocket.upgrade.rejected` tagged by `tool` and `reason` |
| `recordSessionClosed()` | Method | Increments `openframe.tenant.gateway.websocket.sessions.closed` tagged by `tool`, `code`, and `lifetime` bucket |
| `lifetimeBucket()` | Static helper | Buckets a session duration in seconds into `0s`, `<1m`, `<10m`, `<1h`, `>=1h`, or `unknown` |

## Usage Example

```java
@Service
public class GatewayWebSocketHandler {

    private final GatewayTrafficMetrics metrics;

    public void onOpen(WebSocketSession session) {
        metrics.webSocketOpened(session.getId(), session.getUri().getPath(), getSub(session));
    }

    public void onClose(WebSocketSession session, CloseStatus status) {
        long lifetimeSeconds = computeLifetime(session);
        metrics.webSocketClosed(session.getId(), session.getUri().getPath(), getSub(session));
        metrics.recordSessionClosed("meshcentral", status.getCode(), lifetimeSeconds);
    }

    public void onUpgradeRejected(String tool, String reason) {
        // reason examples: "expired_token", "missing_token", "invalid_token"
        metrics.recordUpgradeRejected(tool, reason);
    }
}
```

## Metric Tagging Strategy

Tags are kept **intentionally low-cardinality** — no tenant ID or subject is included in counter tags. This prevents time-series cardinality explosion on the shared multi-tenant gateway. Per-tenant and per-agent detail is preserved in structured logs, which carry `sessionId`, `path`, and `sub`.

> **Operational tip:** A sustained rise in `reason="expired_token"` on the upgrade-rejected counter is an early signal that agent JWT rotation is broken, detectable before devices go offline.
