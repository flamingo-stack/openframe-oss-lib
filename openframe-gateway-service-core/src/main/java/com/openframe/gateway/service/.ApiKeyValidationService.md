Reactive Spring service that validates API keys in the format `ak_{keyId}.sk_{secret}`, handling format parsing, credential verification, and usage statistics delegation.

## Key Components

| Component | Type | Description |
|---|---|---|
| `validateApiKey(String, String)` | Public method | Main validation entry point — parses format, checks active status, and verifies hashed secret |
| `recordSuccessfulRequest(String, String)` | Public method | Delegates successful request tracking to `ApiKeyStatsService` |
| `recordFailedRequest(String, String)` | Public method | Delegates failed request tracking to `ApiKeyStatsService` |
| `parseApiKey(String)` | Private method | Splits and validates the `ak_` / `.sk_` structure before any DB lookup |
| `ParsedApiKey` | Private record | Internal value object holding `keyId`, `secret`, and parse validity |
| `ApiKeyValidationResult` | Public static class | Returned to callers — carries validity flag, error message, and resolved `ApiKey` document |

## Usage Example

```java
// Inject the service
@RequiredArgsConstructor
public class GatewayAuthFilter {

    private final ApiKeyValidationService apiKeyValidationService;

    public Mono<Void> authenticate(String rawApiKey, String tenantId) {
        return apiKeyValidationService.validateApiKey(rawApiKey, tenantId)
            .flatMap(result -> {
                if (!result.isValid()) {
                    // e.g. "Invalid API key format - missing secret separator"
                    return Mono.error(new UnauthorizedException(result.getErrorMessage()));
                }

                // result.getApiKey() is the resolved ApiKey document
                apiKeyValidationService.recordSuccessfulRequest(
                    result.getApiKey().getId(), tenantId
                );
                return Mono.empty();
            });
    }
}
```

## Key Format

```text
ak_1a2b3c4d5e6f7890.sk_abcdefghijklmnopqrstuvwxyz123456
↑                    ↑
keyId (≥ 12 chars)   secret (≥ 16 chars)
```

## Notes

- Statistics (success/failure counts) are intentionally delegated to `ApiKeyStatsService` to keep this class focused on validation only.
- All DB and encoder errors are caught via `onErrorResume`, returning a safe `"Internal validation error"` result rather than propagating exceptions upstream.
