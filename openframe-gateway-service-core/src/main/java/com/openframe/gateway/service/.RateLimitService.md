Reactive Spring service that enforces API rate limits across multiple time windows (minute, hour, day) using atomic Redis operations via `ReactiveRateLimitRepository`.

## Key Components

| Member | Type | Description |
|---|---|---|
| `isAllowed(keyId, tenantId)` | `Mono<Boolean>` | Checks and increments counters for all three windows; returns `false` if any window is exceeded |
| `getRateLimitStatus(keyId, tenantId)` | `Mono<RateLimitStatus>` | Returns current usage counts and limit thresholds without side effects |
| `checkAndIncrement(...)` | `Mono<RateLimitResult>` | Atomically increments a counter and evaluates the limit for one window |
| `getStatus(...)` | `Mono<RateLimitResult>` | Reads current counter for one window without incrementing |
| `createFailureResult(limit)` | `RateLimitResult` | Builds a safe fallback result when Redis is unavailable; respects `failOpen` flag |
| `createEmptyStatus(keyId)` | `RateLimitStatus` | Builds a zeroed-out status object used as an error fallback in `getRateLimitStatus` |

**Configuration properties (injected):**

- `openframe.rate-limit.redis-ttl` — minimum Redis key TTL in seconds
- `openframe.rate-limit.fail-open` — when `true`, allows requests through on Redis errors
- `RateLimitProperties` — per-window default limits (minute / hour / day) and global enabled flag

## Usage Example

```java
@RestController
@RequiredArgsConstructor
public class GatewayController {

    private final RateLimitService rateLimitService;

    @GetMapping("/api/resource")
    public Mono<ResponseEntity<String>> handleRequest(
            @RequestHeader("X-Key-Id") String keyId,
            @RequestHeader("X-Tenant-Id") String tenantId) {

        return rateLimitService.isAllowed(keyId, tenantId)
                .flatMap(allowed -> {
                    if (!allowed) {
                        return Mono.just(ResponseEntity
                                .status(HttpStatus.TOO_MANY_REQUESTS)
                                .<String>build());
                    }
                    return Mono.just(ResponseEntity.ok("OK"));
                });
    }

    // Expose rate limit status for monitoring/debugging
    @GetMapping("/api/rate-limit/status")
    public Mono<RateLimitStatus> getStatus(
            @RequestParam String keyId,
            @RequestParam String tenantId) {

        return rateLimitService.getRateLimitStatus(keyId, tenantId);
    }
}
```

> **Fail-open behaviour:** if Redis is unreachable, `checkAndIncrement` and `getStatus` both fall back to `createFailureResult`. When `fail-open=true` the request is allowed through; when `false` it is blocked. `getRateLimitStatus` always falls back to a zeroed status rather than propagating the error.
