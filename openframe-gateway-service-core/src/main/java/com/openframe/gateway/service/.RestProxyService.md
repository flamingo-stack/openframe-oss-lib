Reactive HTTP proxy service that forwards API and agent requests to integrated tools, handling tenant routing, endpoint allowlisting, authentication header injection, and SSL configuration.

## Key Components

| Member | Description |
|--------|-------------|
| `proxyApiRequest()` | Proxies browser/API requests to a tool after validating enabled state and endpoint allowlist |
| `proxyAgentRequest()` | Proxies machine/agent requests, forwarding `Tool-Authorization` header |
| `findTool()` | Resolves the `IntegratedTool` by key, scoped by tenant in multi-tenant mode |
| `isProxyEndpointAllowed()` | Checks the request path against `FleetEndpointAllowlist` before forwarding |
| `addFleetTenantHeader()` | Injects `X-Tenant-Id` into outbound headers for Fleet tool requests |
| `buildApiRequestHeaders()` | Builds outbound headers including resolved API key headers |
| `buildAgentRequestHeaders()` | Builds outbound headers forwarding `Tool-Authorization` as `Authorization` |
| `proxy()` | Executes the proxied call via `WebClient` with a 60 s timeout and 16 MB buffer |
| `buildHttpClient()` | Constructs a Reactor Netty `HttpClient` with SSL bypass, curl logging, and tuned TCP options |
| `tenantRoutingEnabled` | Feature flag (`openframe.gateway.tenant-routing.enabled`) that gates scoped vs. unscoped tool lookup |

## Usage Example

```java
// Injected via Spring — not instantiated directly
@Autowired
RestProxyService restProxyService;

// Forward an incoming API request to tool "connectwise"
Mono<ResponseEntity<String>> result = restProxyService.proxyApiRequest(
    "connectwise",
    serverHttpRequest,
    requestBody
);

// Forward an agent request (device → tool)
Mono<ResponseEntity<String>> agentResult = restProxyService.proxyAgentRequest(
    "ninja",
    serverHttpRequest,
    requestBody
);
```

> **Note:** `proxyApiRequest` enforces the `FleetEndpointAllowlist` and returns `403 Forbidden` for non-allowlisted paths. `proxyAgentRequest` skips the allowlist but still checks the tool's enabled state.
