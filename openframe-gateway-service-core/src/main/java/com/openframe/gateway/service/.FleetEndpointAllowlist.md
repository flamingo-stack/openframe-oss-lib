Enforces an HTTP endpoint allowlist for the Fleet MDM browser proxy, restricting which method+path combinations are permitted when multi-tenancy is active.

## Key Components

| Member | Description |
|---|---|
| `FLEET_TOOL_ID` | Constant `"fleetmdm-server"` identifying the only tool subject to filtering |
| `multiTenancyEnabled` | Gate flag sourced from `FleetMultiTenancyProperties.isEnabled()` |
| `fleetPatterns` | Compiled `Map<HttpMethod, List<PathPattern>>` built once at startup from configuration |
| `isAllowed(toolId, method, path)` | Primary check — returns `true` if the request is permitted to pass through |
| `compile(entries)` | Private parser that converts `"METHOD pattern"` strings into Spring `PathPattern` objects |

## Usage Example

```java
// Configuration (application.yml)
// openframe.fleet.multi-tenancy.enabled: true
// openframe.fleet.multi-tenancy.allowed-endpoints:
//   - "GET /api/v1/hosts"
//   - "PATCH /api/v1/hosts/{id}"

@Autowired
FleetEndpointAllowlist allowlist;

// In the browser proxy handler:
boolean permitted = allowlist.isAllowed(
    "fleetmdm-server",
    HttpMethod.GET,
    "/api/v1/hosts"
);

if (!permitted) {
    response.setStatus(403); // blocked — not in allowlist
}
```

## Behavior Notes

- **No-op by default**: returns `true` unconditionally when `multi-tenancy.enabled=false` or when `toolId` is anything other than `"fleetmdm-server"`.
- **Agent plane exempt**: only the browser proxy (`proxyApiRequest`) calls `isAllowed`; the agent-plane proxy is never filtered.
- **Global, not per-tenant**: all tenants share one allowlist because the Fleet UI surface is identical across tenants.
- **Fail-closed**: an unknown HTTP method (no matching key in `fleetPatterns`) returns `false`, not `true`.
- Allowlist entries must follow `"METHOD /path/pattern"` syntax; malformed entries throw `IllegalArgumentException` at startup.
