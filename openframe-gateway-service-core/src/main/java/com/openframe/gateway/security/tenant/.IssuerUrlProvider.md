Defines the contract for resolving JWT issuer URLs accepted by a gateway pod, supporting both single-tenant (OSS) and multi-tenant (SaaS) deployment models.

## Key Components

| Member | Type | Description |
|---|---|---|
| `resolveIssuerUrls()` | `Mono<List<String>>` | Asynchronously fetches the current list of accepted JWT issuer URLs |
| `getCachedIssuerUrl()` | `List<String>` | Returns the synchronous in-memory cache of issuer URLs |
| `accepts(String issuer)` | `default boolean` | Fail-closed check — returns `true` only if the issuer exists in the cached list |

## Design Notes

The interface uses a **fail-closed default**: an absent or empty cache rejects all issuers. This ensures security by default in the OSS single-tenant path (backed by the local DB), while SaaS `@Primary` overrides can loosen the check to accept a family of issuers (e.g., `<base>/<tenantId>`) without enumerating every tenant individually. Per-request tenant boundary enforcement is delegated to a separate layer.

## Usage Example

```java
@Component
public class OssIssuerUrlProvider implements IssuerUrlProvider {

    private final TenantRepository tenantRepository;
    private volatile List<String> cache = List.of();

    @Override
    public Mono<List<String>> resolveIssuerUrls() {
        return tenantRepository.findSingle()
            .map(tenant -> List.of(tenant.getIssuerUrl()))
            .doOnNext(urls -> this.cache = urls);
    }

    @Override
    public List<String> getCachedIssuerUrl() {
        return cache;
    }

    // accepts() uses default fail-closed logic — no override needed
}
```
