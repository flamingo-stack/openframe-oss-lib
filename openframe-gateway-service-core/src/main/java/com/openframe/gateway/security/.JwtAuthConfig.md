Configures multi-tenant JWT authentication for the OpenFrame API gateway, supporting both internal (public-key) and external (OIDC discovery) token issuers with a Caffeine-backed cache of per-issuer `ReactiveAuthenticationManager` instances.

## Key Components

| Component | Description |
|---|---|
| `issuerManagersCache` | Caffeine `LoadingCache` that maps issuer URLs to `ReactiveAuthenticationManager` instances; respects `expireAfterWrite` and `refreshAfterWrite` TTLs |
| `createStrictIssuerValidator` | Private factory that returns an `OAuth2TokenValidator<Jwt>` delegating issuer acceptance to `IssuerUrlProvider`; rejects unknown issuers with `INVALID_TOKEN` |
| `jwtIssuerAuthenticationManagerResolver` | Spring Security `JwtIssuerReactiveAuthenticationManagerResolver` bean that lazily resolves the correct manager from the cache via `Mono.fromCallable` |

### Issuer branching logic

- **Internal issuer** (`jwtConfig.getIssuer()`) — decoded with a static RSA public key loaded from `JwtConfig`.
- **External issuer** — decoded via OIDC discovery (`ReactiveJwtDecoders.fromIssuerLocation`), then validated with a delegating validator that combines Spring's default checks with the strict issuer whitelist.

### Configuration properties

```yaml
openframe:
  security:
    jwt:
      cache:
        expire-after: 60m
        refresh-after: 45m
        maximum-size: 500
```

## Usage Example

```java
// The resolver bean is injected automatically into SecurityWebFilterChain:
@Bean
public SecurityWebFilterChain securityFilterChain(
        ServerHttpSecurity http,
        JwtIssuerReactiveAuthenticationManagerResolver resolver) {

    return http
        .oauth2ResourceServer(oauth2 -> oauth2
            .authenticationManagerResolver(resolver))
        .build();
}
```

> External issuers must be registered with `IssuerUrlProvider`; any JWT whose `iss` claim is not accepted by that provider will be rejected with an `INVALID_TOKEN` error regardless of signature validity.
