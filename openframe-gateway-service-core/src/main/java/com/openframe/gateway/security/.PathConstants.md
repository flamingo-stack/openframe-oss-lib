Defines path prefix constants used throughout the OpenFrame Gateway for routing and security configuration.

## Key Components

| Constant | Value | Description |
|---|---|---|
| `CLIENTS_PREFIX` | `/clients` | Client-facing endpoint paths |
| `API_PREFIX` | `/api` | General API endpoint paths |
| `TOOLS_PREFIX` | `/tools` | Tool-related HTTP endpoint paths |
| `WS_TOOLS_PREFIX` | `/ws/tools` | WebSocket tool endpoint paths |
| `CHAT_PREFIX` | `/chat` | Chat service endpoint paths |
| `CONTENT_PREFIX` | `/content` | Content service endpoint paths |

## Usage Example

```java
import com.openframe.gateway.security.PathConstants;

// Use in security configuration to whitelist or restrict routes
http.authorizeHttpRequests(auth -> auth
    .requestMatchers(PathConstants.API_PREFIX + "/**").authenticated()
    .requestMatchers(PathConstants.CLIENTS_PREFIX + "/**").hasRole("CLIENT")
    .requestMatchers(PathConstants.WS_TOOLS_PREFIX + "/**").authenticated()
);
```

## Notes

- `PathConstants` is a non-instantiable utility class (private constructor).
- Centralising path prefixes here ensures consistency across security filters, route handlers, and middleware — avoiding scattered string literals throughout the Gateway.
