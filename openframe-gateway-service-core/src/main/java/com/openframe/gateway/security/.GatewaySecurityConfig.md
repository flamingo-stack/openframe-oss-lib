Configures Spring Security for the OpenFrame reactive gateway, establishing JWT-based OAuth2 resource server authentication with role-based access control across all gateway routes.

## Key Components

| Component | Description |
|---|---|
| `reactiveJwtAuthenticationConverter()` | Builds a JWT converter that extracts both `roles` (prefixed `ROLE_`) and `scope` (prefixed `SCOPE_`) claims, merging them into a combined authority flux |
| `springSecurityFilterChain()` | Defines the full `SecurityWebFilterChain`: disables CSRF/CORS/form login, wires the multi-issuer resolver, injects `AddAuthorizationHeaderFilter`, and declares path-level authorization rules |
| `passwordEncoder()` | Exposes a `BCryptPasswordEncoder` bean for password hashing |

## Authorization Rules Summary

| Path Pattern | Access |
|---|---|
| `OPTIONS /**` | Public |
| `/clients/metrics/**`, `/clients/oauth/token`, agent register/reinstall | Public |
| `/api/**` | `ROLE_ADMIN` only |
| `/tools/agent/**`, `/ws-tools/agent/**` | `ROLE_AGENT` only |
| NATS WebSocket endpoints | `ROLE_AGENT` or `ROLE_ADMIN` |
| `/chat/**`, `/content/**` | `ROLE_AGENT` or `ROLE_ADMIN` |
| `/clients/**` | `ROLE_AGENT` only |
| `/tools/**`, `/ws-tools/**` | `ROLE_ADMIN` only |
| `/**` (catch-all) | Public |

## Usage Example

```java
// The filter chain and JWT converter are auto-wired by Spring.
// To test role enforcement in an integration test:

@SpringBootTest
@AutoConfigureWebTestClient
class SecurityIntegrationTest {

    @Autowired
    WebTestClient webTestClient;

    @Test
    void adminEndpoint_requiresAdminRole() {
        webTestClient.get()
            .uri("/api/some-resource")
            .exchange()
            .expectStatus().isUnauthorized(); // No token → 401
    }
}
```
