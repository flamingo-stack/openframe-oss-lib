Extends Spring Security's `BearerTokenServerAuthenticationEntryPoint` to make WebSocket upgrade rejections observable via structured logs and Micrometer metrics, preventing silent agent disconnections when JWT tokens expire or are invalid.

## Key Components

| Member | Description |
|---|---|
| `commence(exchange, ex)` | Entry point called on 401; detects WS upgrades and emits metrics/logs before delegating to the standard bearer-token handler |
| `isWebSocketUpgrade(request)` | Checks for `Upgrade: websocket` header or `/ws/` path prefix |
| `classify(rawToken, ex)` | Returns a low-cardinality reason tag: `missing_token`, `expired_token`, or `invalid_token` |
| `subOf(rawToken)` | Extracts JWT `sub` claim without signature verification — for log correlation only |
| `rawToken(request)` | Extracts the bearer token from `Authorization` header or `authorization` query parameter |
| `gatewayTrafficMetrics` | Records `openframe.tenant.gateway.websocket.upgrade.rejected{tool,reason}` counter |
| `delegate` | Internal `BearerTokenServerAuthenticationEntryPoint` that handles the actual HTTP 401 response |

## Usage Example

```java
// Registered automatically as a @Component; wire into your security config:
@Bean
SecurityWebFilterChain securityChain(
        ServerHttpSecurity http,
        WsAwareAuthenticationEntryPoint entryPoint) {

    return http
        .exceptionHandling(e -> e
            .authenticationEntryPoint(entryPoint))
        // ... other config
        .build();
}
```

When an agent WebSocket upgrade is rejected, the component emits:

```text
// Micrometer counter (scraped within one interval):
openframe.tenant.gateway.websocket.upgrade.rejected{tool="rmmAgent", reason="expired_token"}

// Log output (DEBUG):
WS upgrade REJECTED path=/ws/rmmAgent sub=agent-42 reason=expired_token : JWT expired at ...
```

> **Why this matters:** Without this component, expired-token rejections are silent — agents appear to go offline with no gateway-side evidence. See [`GatewayTrafficMetrics`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/gateway/metrics/GatewayTrafficMetrics.java) and [`WebSocketServiceSecurityDecorator`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/gateway/config/ws/WebSocketServiceSecurityDecorator.java) for the tool-name resolution and counter registration.
