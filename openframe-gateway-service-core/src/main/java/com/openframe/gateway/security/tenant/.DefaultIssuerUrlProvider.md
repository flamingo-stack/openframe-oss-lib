Fallback `IssuerUrlProvider` implementation for self-hosted (OSS/single-tenant) deployments. Returns a single, statically configured JWT issuer URL without any database lookup.

## Key Components

| Member | Type | Description |
|---|---|---|
| `allowedIssuerBase` | `@Value` field | Base URL for the JWT issuer, bound from `openframe.security.jwt.allowed-issuer-base` |
| `superTenantId` | `@Value` field | Tenant ID appended to the base URL, bound from `openframe.security.jwt.super-tenant-id` |
| `resolveIssuerUrls()` | Method | Returns a reactive `Mono` wrapping the single issuer URL list |
| `getCachedIssuerUrl()` | Method | Constructs and returns `[allowedIssuerBase + "/" + superTenantId]` synchronously |

**Activation condition:** `@ConditionalOnMissingBean` — only registered when no other `IssuerUrlProvider` bean exists (e.g. a SaaS-tier `SaasIssuerUrlProvider`).

## Usage Example

```java
# application.yml — minimal self-hosted configuration
openframe:
  security:
    jwt:
      allowed-issuer-base: https://auth.example.com/realms
      super-tenant-id: my-org

# Resolved issuer URL: https://auth.example.com/realms/my-org
```

```java
// Resolved automatically via Spring DI in single-tenant deployments
@Autowired
IssuerUrlProvider issuerUrlProvider;

issuerUrlProvider.resolveIssuerUrls()
    .subscribe(urls -> System.out.println(urls));
// Output: [https://auth.example.com/realms/my-org]
```

> **Note:** In multi-tenant (SaaS) deployments, this bean is replaced by a custom `IssuerUrlProvider` implementation. No code changes are required — Spring's `@ConditionalOnMissingBean` handles the swap automatically.
