Unit test suite for `FleetUpstreamResolver`, verifying that REST and WebSocket upstream routing correctly routes to a shared Fleet API endpoint when multi-tenancy is enabled and configured, or delegates to per-tenant routing otherwise.

## Key Components

| Method | Description |
|---|---|
| `routesRestToSharedFleetApiWhenEnabledAndConfigured` | Verifies REST requests route to the shared Fleet API URL when multi-tenancy is enabled |
| `agentPlaneRoutesToSharedFleetApiToo` | Confirms agent-plane REST paths (`/tools/agent/...`) also resolve to the shared upstream |
| `routesWsToSharedFleetWebsocketEndpoint` | Verifies WebSocket requests route to the shared Fleet WebSocket URL |
| `flagOffDelegatesToPerTenantDocRouting` | Ensures per-tenant routing is used when the multi-tenancy flag is disabled |
| `apiConfiguredButWebsocketMissingDelegatesWsToPerTenant` | Regression test: partial config (API set, WebSocket blank) delegates WS to per-tenant without passing a blank URL to the proxy resolver |
| `enabledWithoutApiUrlDelegatesToPerTenantDocRouting` | Covers the allowlist-only rollout phase where flag is on but no shared upstream is configured yet |

**Test Collaborators:**

- `ProxyUrlResolver` — mocked; resolves upstream URI from tool ID, URL, port, request, and strip prefix
- `DefaultToolUpstreamResolver` — mocked; handles per-tenant routing fallback
- `FleetMultiTenancyProperties` — real instance; configured inline per test case

## Usage Example

```java
// Configure shared upstream in properties, then exercise the resolver:
FleetMultiTenancyProperties props = new FleetMultiTenancyProperties();
props.setEnabled(true);
props.getUpstream().getApi().setUrl("http://fleet.fleet-shared.svc.cluster.local");
props.getUpstream().getApi().setPort("8080");

FleetUpstreamResolver resolver = new FleetUpstreamResolver(props, proxyUrlResolver, defaultResolver);

URI upstream = resolver.resolveRest(tool, request, "/tools");
// → http://fleet.fleet-shared.svc.cluster.local:8080/api/latest/fleet/hosts
```
