Unit tests for `MeshCentralUpstreamResolver`, verifying WebSocket upstream URI resolution under both multi-tenant and single-tenant routing configurations.

## Key Components

| Component | Role |
|---|---|
| `rewritesNamespaceAndPathPrefixForCallingTenant` | Asserts that when `X-Tenant-*` headers are present and tenant routing is enabled, the resolver rewrites the Kubernetes namespace (`tenant-ns` → `acme`) and substitutes the tenant UUID placeholder in the path prefix (`/tenant-uuid` → `/abc-123`) |
| `leavesHostAndPrefixUntouchedForSingleTenantPod` | Asserts that without `X-Tenant-*` headers the resolver leaves the configured namespace and literal path prefix unchanged (single-tenant / sidecar deployment) |
| `setUp` (`@BeforeEach`) | Bootstraps `MeshCentralRoutingProperties` with a WebSocket upstream pointing to `ws://meshcentral.tenant-ns.svc.cluster.local:8383/{tenant-uuid}`, then wires a mocked `ProxyUrlResolver` into the resolver under test |

## Usage Example

```java
// Run the full test class via Maven
// mvn test -pl gateway -Dtest=MeshCentralUpstreamResolverTest

// The multi-tenant scenario in isolation:
@Test
void rewritesNamespaceAndPathPrefixForCallingTenant() {
    ReflectionTestUtils.setField(resolver, "tenantRoutingEnabled", true);
    when(proxyUrlResolver.resolve(anyString(), anyString(), anyString(), any(), anyString()))
            .thenReturn(URI.create("ws://meshcentral.tenant-ns.svc.cluster.local:8383/meshrelay.ashx"));

    ServerHttpRequest request = MockServerHttpRequest
            .get("/ws/tools/meshcentral-server/meshrelay.ashx")
            .header(TenantRoutingHeaders.TENANT_NS_HEADER, "acme")
            .header(TenantRoutingHeaders.TENANT_ID_HEADER, "abc-123")
            .build();

    URI uri = resolver.resolveWs(null, request, "/tools");

    assertThat(uri.getHost()).isEqualTo("meshcentral.acme.svc.cluster.local");
    assertThat(uri.getRawPath()).isEqualTo("/abc-123/meshrelay.ashx");
}
```

## Notes

- `ReflectionTestUtils.setField` is used to toggle the `tenantRoutingEnabled` flag without exposing it as a public setter — keep this in mind if the field is ever renamed.
- The mocked `ProxyUrlResolver` returns a pre-built URI; the assertions focus on the **post-rewrite** state applied by `MeshCentralUpstreamResolver`, not the resolver mock itself.
