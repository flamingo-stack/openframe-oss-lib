Unit tests for `TenantRoutingHeaders`, validating namespace substitution logic in Kubernetes `*.svc.cluster.local` hostnames and URIs within the OpenFrame gateway's tenant routing layer.

## Key Components

| Test Method | What It Covers |
|---|---|
| `rewritesNamespaceLabelBeforeSvc` | Happy-path: replaces the namespace segment preceding `.svc.cluster.local` with the resolved tenant namespace |
| `leavesHostUnchangedWhenNamespaceMissing` | No-op guard when the namespace argument is `null` or blank |
| `leavesNonClusterLocalHostUnchanged` | External hostnames and lookalike hosts (contain `svc` but not `*.svc.cluster.local`) are never rewritten |
| `rejectsNamespaceThatIsNotADnsLabel` | Security fence: forged values (dots, slashes, uppercase) are rejected and the original host is returned unchanged |
| `rewritesUriHostPreservingSchemePortPathAndRawQuery` | Full URI rewrite preserves scheme, port, path, and raw query string (including base64 `=` padding) |
| `uriRewriteIsNoOpWhenNamespaceAbsentOrHostNotClusterLocal` | `applyToUri` is a no-op for missing namespace or external URIs |

## Usage Example

```java
// Rewrite a cluster-local host for tenant "acme"
String rewritten = TenantRoutingHeaders.applyToHost(
    "meshcentral-backend.tenant-ns.svc.cluster.local",
    "acme"
);
// → "meshcentral-backend.acme.svc.cluster.local"

// Rewrite a full URI, preserving all components
URI in  = URI.create("ws://nats.tenant-ns.svc.cluster.local:8080/ws/nats?auth=YWJjZA==");
URI out = TenantRoutingHeaders.applyToUri(in, "acme");
// out.getHost() → "nats.acme.svc.cluster.local"
// out.getRawQuery() → "auth=YWJjZA=="   (base64 padding preserved)
```

## Notes

- All rewrite methods are **pure / side-effect-free** — invalid or non-applicable inputs return the original value unchanged.
- The DNS-label validation in `rejectsNamespaceThatIsNotADnsLabel` is a **security control**: it prevents namespace injection via forged routing headers (e.g. path-traversal strings or uppercase labels that violate RFC 1123).
