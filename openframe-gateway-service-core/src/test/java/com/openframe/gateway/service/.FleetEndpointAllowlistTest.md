Unit tests for `FleetEndpointAllowlist`, verifying that the gateway's Fleet MDM endpoint allowlist correctly permits or blocks proxied requests based on HTTP method, URL path pattern, target service identity, and multi-tenancy configuration state.

## Key Components

| Element | Description |
|---|---|
| `allowlist(boolean, List<String>)` | Factory helper that wires `FleetMultiTenancyProperties` into a `FleetEndpointAllowlist` instance |
| `FLEET_ENDPOINTS` | Representative slice of the configured allowlist using `{v}` and `{id}` path variable templates |
| `allowsFleetEndpointsInTheConfiguredList` | Confirms path-template matching resolves concrete values (`latest`, `v1`, numeric IDs) |
| `blocksFleetEndpointsNotInTheList` | Ensures unlisted Fleet paths are denied when multi-tenancy is enabled |
| `blocksAllowedFleetPathUnderAWrongMethod` | Validates that method + path must both match; correct path with wrong method is blocked |
| `doesNotFilterOtherTools` | Confirms allowlist only applies to `fleetmdm-server`; other service IDs pass through unconditionally |
| `doesNotFilterWhenMultiTenancyDisabled` | Verifies the allowlist is a no-op when the feature flag is off |
| `enabledWithEmptyListBlocksAllFleetRequests` | Documents fail-closed behaviour: enabled flag + empty list blocks all Fleet traffic |

## Usage Example

```java
// Construct via FleetMultiTenancyProperties (mirrors what the test factory does)
FleetMultiTenancyProperties props = new FleetMultiTenancyProperties();
props.setEnabled(true);
props.setAllowedEndpoints(List.of(
    "GET /api/{v}/fleet/hosts",
    "GET /api/{v}/fleet/hosts/{id}"
));

FleetEndpointAllowlist allowlist = new FleetEndpointAllowlist(props);

// Allowed: path and method both match a configured template
allowlist.isAllowed("fleetmdm-server", HttpMethod.GET, "/api/latest/fleet/hosts");      // true

// Blocked: path matches but method does not
allowlist.isAllowed("fleetmdm-server", HttpMethod.DELETE, "/api/latest/fleet/hosts/1"); // false

// Bypassed: non-Fleet service identifier skips filtering entirely
allowlist.isAllowed("tactical-rmm", HttpMethod.POST, "/anything/at/all");               // true
```

## Notes

- Path templates use `{v}` for the Fleet API version segment and `{id}` for numeric/string identifiers, both resolved at match time against concrete request paths.
- The fail-closed contract (`enabledWithEmptyListBlocksAllFleetRequests`) is explicitly documented in the test comment — enabling the flag without a configured list is a safe default that prevents unintended Fleet exposure.
