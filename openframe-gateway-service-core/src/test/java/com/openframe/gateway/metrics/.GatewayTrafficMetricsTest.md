Unit tests for `GatewayTrafficMetrics`, verifying session lifetime bucket boundaries, WebSocket upgrade rejection counters, and session close counters using an in-memory `SimpleMeterRegistry`.

## Key Components

| Test Method | What It Verifies |
|---|---|
| `lifetimeBucketBoundaries()` | Correct bucket label assignment across all boundary values (`unknown`, `0s`, `<1m`, `<10m`, `<1h`, `>=1h`) |
| `recordUpgradeRejectedIncrementsTaggedCounter()` | `recordUpgradeRejected()` increments the `openframe.tenant.gateway.websocket.upgrade.rejected` counter with correct `tool` and `reason` tags |
| `recordSessionClosedIncrementsTaggedCounter()` | `recordSessionClosed()` increments the `openframe.tenant.gateway.websocket.sessions.closed` counter with correct `tool`, `code`, and `lifetime` tags |

## Usage Example

```java
// Replicate the in-memory registry pattern used in these tests
SimpleMeterRegistry registry = new SimpleMeterRegistry();
GatewayTrafficMetrics metrics = new GatewayTrafficMetrics(registry);

// Simulate a rejected WebSocket upgrade
metrics.recordUpgradeRejected("meshcentral-server", "expired_token");

// Simulate a closed session (tool, close code, lifetime in seconds)
metrics.recordSessionClosed("meshcentral-server", 1002, 0);

// Verify lifetime bucket labelling directly
String bucket = GatewayTrafficMetrics.lifetimeBucket(3600); // returns ">=1h"
```

## Bucket Boundaries Reference

```text
lifetime (seconds)  →  bucket label
─────────────────────────────────────
< 0                 →  "unknown"
  0                 →  "0s"    (flap/immediate close)
  1 – 59            →  "<1m"
 60 – 599           →  "<10m"
600 – 3599          →  "<1h"
≥ 3600              →  ">=1h"
```
