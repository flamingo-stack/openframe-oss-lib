Unit tests for `ProxySessionCleanupWebSocketClient`, verifying peer-closed detection logic, log-level routing, security context propagation, and upstream session leak cleanup behavior.

## Key Components

| Test / Helper | Purpose |
|---|---|
| `isPeerClosed_*` | Asserts the static helper correctly classifies teardown-race errors vs. real connection failures |
| `peerClosedBeforeRelayStarts_logsWarn` | Verifies a peer abort during connect/handshake emits a `WARN` log |
| `peerClosedAfterRelayStarts_logsDebug` | Verifies a peer abort mid-relay (after the handler was invoked) emits `DEBUG` only |
| `upstreamLogs_takeSubFromSecurityContext` | Confirms the `sub=` field in relay-finished logs is populated from the reactive security context |
| `upstreamLogs_fallBackToDashWithoutSecurityContext` | Confirms the `sub=` field falls back to `-` when no authentication is present |
| `closeIfLeaked_alreadyClosed_*` | No force-close is issued when the session is already closed |
| `closeIfLeaked_naturalCloseWinsTheRace_*` | No force-close is issued when `closeStatus()` signals before the grace period expires |
| `closeIfLeaked_stillOpenAfterGrace_*` | `session.close(GOING_AWAY)` is called exactly once for a genuinely leaked upstream |
| `attachAppender` / `detachAppender` | Logback `ListAppender` lifecycle attached to `ProxySessionCleanupWebSocketClient`'s logger |
| `client(delegate)` | Factory that wires a mock `WebSocketClient` with `WebSocketLoggingProperties` |
| `levelOf(substring)` | Scans captured log events and returns the level of the first line matching a substring |

## Usage Example

```java
// Verify teardown-race classification
assertThat(ProxySessionCleanupWebSocketClient.isPeerClosed(
    new RuntimeException("AbortedException: Connection has been closed BEFORE send operation"))
).isTrue();

// Verify no double CloseWebSocketFrame on natural close
WebSocketSession session = mock(WebSocketSession.class);
when(session.isOpen()).thenReturn(true);
when(session.closeStatus()).thenReturn(Mono.empty()); // close signal wins

ProxySessionCleanupWebSocketClient
    .closeIfLeaked(session, "s2", "/ws/nats-api", false,
                   SignalType.ON_COMPLETE, Duration.ofMinutes(1))
    .block();

verify(session, never()).close(any());
```
