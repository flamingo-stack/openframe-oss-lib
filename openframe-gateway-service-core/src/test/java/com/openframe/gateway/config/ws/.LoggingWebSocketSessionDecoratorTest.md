Unit tests for `LoggingWebSocketSessionDecorator`, validating the `truncate` and `toPrintablePreview` static utility methods used for safe WebSocket message logging.

## Key Components

| Test Method | Covers |
|---|---|
| `shouldAppendLengthSuffixWhenTextExceedsMax` | `truncate()` appends `...(N chars)` suffix when text exceeds max length |
| `shouldReturnTextUnchangedWhenWithinMax` | `truncate()` returns original text when at or under max |
| `shouldReturnTextUnchangedWhenMaxIsNonPositive` | `truncate()` is a no-op for zero or negative max values |
| `shouldRenderBinaryPayloadAsPrintableTextWithoutConsumingIt` | `toPrintablePreview()` replaces non-printable bytes with `.` and leaves buffer position unchanged |
| `shouldRenderJsonOverBinaryFrameAsReadableText` | `toPrintablePreview()` passes through ASCII-printable JSON sent over binary WebSocket frames |
| `shouldTruncatePrintablePreviewToMaxChars` | `toPrintablePreview()` truncates at `maxChars` with a `…(N bytes total)` suffix |

## Usage Example

```java
// truncate() — safe for log lines with unpredictable text payloads
String preview = LoggingWebSocketSessionDecorator.truncate(rawText, 128);
// "Hello, world!"          → "Hello, world!"   (≤ 128 chars)
// "0123456789..." (long)   → "01234567...(512 chars)"

// toPrintablePreview() — non-destructive inspection of a DataBuffer
// (buffer read position is not advanced; the relay still receives the full frame)
String binaryPreview = LoggingWebSocketSessionDecorator.toPrintablePreview(dataBuffer, 256);
// {0x00, 0x1e, 'H', 'i', 0x00} → "..Hi."
// "{\"action\":\"serverInfo\"}"  → "{\"action\":\"serverInfo\"}"
```

## Notes

- `toPrintablePreview` must be **non-consuming** — tests assert that `readPosition()` and `readableByteCount()` are identical before and after the call, ensuring the relay pipeline receives the unmodified payload.
- Both methods are designed for structured log output in the OpenFrame WebSocket gateway; truncation suffixes differ by type: `...(N chars)` for text, `…(N bytes total)` for binary previews.
