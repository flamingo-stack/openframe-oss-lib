Unit tests for `WebSocketServiceSecurityDecorator` that guard against a path-scoping bug where frame logging decisions must be based on the original gateway request path rather than the rewritten upstream URL.

## Key Components

| Component | Description |
|---|---|
| `wrapsClientSessionForFrameLogging_whenRequestPathMatchesFramePrefix` | Verifies the client session is wrapped in `LoggingWebSocketSessionDecorator` when the request path matches a configured frame prefix |
| `doesNotWrapClientSession_whenRequestPathDoesNotMatchFramePrefix` | Verifies no wrapping occurs when the request path does not match any configured prefix |
| `toolFromPath_extractsLowCardinalityToolLabel` | Validates the static `toolFromPath()` utility extracts the correct low-cardinality tool label from various path patterns |
| `handleAndCaptureProxiedSession` | Helper that wires up mocks, drives the full `handleRequest` flow, and captures the `WebSocketSession` passed to the downstream proxy handler |
| `exchangeWithPath` | Helper that builds a minimal mocked `ServerWebExchange` with a given request path |

## Usage Example

```java
// The test simulates how Spring's reactive stack drives the relay:
// defaultService delegates to the security handler, which decides
// whether to wrap the client session before forwarding it.

WebSocketLoggingProperties props = new WebSocketLoggingProperties();
props.setFramePayloadLoggingEnabled(true);
props.setFramePathPrefixes(List.of("/ws/tools/agent/meshcentral-server/"));

WebSocketSession proxied = handleAndCaptureProxiedSession(props, MESH_REQUEST_PATH);

// Asserts the wrap decision was made on the gateway request path,
// not the upstream rewritten URL (pre-fix behaviour).
assertThat(proxied).isInstanceOf(LoggingWebSocketSessionDecorator.class);
```

> **Bug context:** Before the fix, the frame-logging check ran against the upstream URL visible to `WebSocketClient`, which never matched the configured prefixes. These tests lock in that the decision is always evaluated against the original inbound request path.
