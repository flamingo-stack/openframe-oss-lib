Unit tests for `WebSocketLoggingProperties.isFramePath()`, verifying prefix-matching behavior under three conditions: logging disabled, specific prefixes configured, and fallback to debug prefixes when frame prefixes are empty.

## Key Components

| Test Method | Scenario Covered |
|---|---|
| `shouldReturnFalseFromIsFramePathWhenFramePayloadLoggingDisabled` | `isFramePath()` always returns `false` when frame payload logging is disabled |
| `shouldReturnTrueFromIsFramePathOnlyForConfiguredPrefixWhenEnabled` | `isFramePath()` matches only configured prefixes; rejects non-matching paths and `null` |
| `shouldFallBackToDebugPathPrefixesWhenFramePathPrefixesEmpty` | Falls back to `debugPathPrefixes` when `framePathPrefixes` is an empty list |

## Usage Example

```java
// Typical production configuration
WebSocketLoggingProperties props = new WebSocketLoggingProperties();
props.setFramePayloadLoggingEnabled(true);
props.setFramePathPrefixes(List.of("/ws/tools/agent/meshcentral-server/"));

props.isFramePath("/ws/tools/agent/meshcentral-server/agent.ashx"); // true
props.isFramePath("/ws/nats");                                       // false
props.isFramePath(null);                                             // false

// Fallback: empty framePathPrefixes → uses debugPathPrefixes
props.setFramePathPrefixes(List.of());
props.setDebugPathPrefixes(List.of("/ws/"));
props.isFramePath("/ws/tools/agent/meshcentral-server/agent.ashx"); // true
```

## Notes

- Tests use **AssertJ** (`assertThat`) for readable fluent assertions.
- The `null`-path guard is explicitly verified, ensuring `isFramePath` is null-safe.
- The fallback behavior ties frame-level logging to the broader debug prefix list, preventing silent misconfiguration when `framePathPrefixes` is left empty.
