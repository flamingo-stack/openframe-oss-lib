Defines the contract for notification delivery channels, providing a unified interface for sending notifications to users across different transport mechanisms (e.g. email, SMS, push).

## Key Components

| Member | Description |
|---|---|
| `name()` | Returns the unique identifier/name of the channel implementation |
| `deliver(String userId, Notification notification, NotificationCategory category)` | Dispatches a notification to a user; implementations **must not throw** on unreachable recipients or dead providers |

## Usage Example

```java
public class EmailNotificationChannel implements NotificationChannel {

    @Override
    public String name() {
        return "email";
    }

    @Override
    public void deliver(String userId, Notification notification, NotificationCategory category) {
        try {
            emailClient.send(userId, notification.getBody());
        } catch (EmailProviderException e) {
            // Swallow — delivery failures must never propagate
            log.warn("Email delivery failed for user {}: {}", userId, e.getMessage());
        }
    }
}
```

## Notes

- Implementations are expected to handle all internal errors gracefully — a failed delivery should be logged or queued, never thrown.
- The `category` parameter allows channel implementations to apply filtering or formatting logic based on notification type (e.g. suppress low-priority alerts on SMS).
