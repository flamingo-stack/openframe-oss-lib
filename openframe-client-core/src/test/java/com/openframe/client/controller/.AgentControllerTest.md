Unit test suite for `AgentController`, covering agent registration and reinstallation endpoints via MockMvc with mocked `AgentRegistrationService` dependencies.

## Key Components

| Component | Role |
|---|---|
| `AgentControllerTest` | Main test class using `@ExtendWith(MockitoExtension.class)` |
| `AgentRegistrationService` | Mocked service dependency injected into `AgentController` |
| `MockMvc` | Standalone MVC test harness with `BasicAuthenticationFilter` and `BaseGlobalExceptionHandler` |
| `setupTestData()` | Shared fixture builder for `AgentRegistrationRequest` / `AgentRegistrationResponse` |

## Tested Endpoints

**`POST /api/agents/register`**
- Valid request with `X-Initial-Key` header → `200 OK` with credentials
- Missing `X-Initial-Key` header → `400 BAD_REQUEST`
- Invalid initial key (throws `AgentRegistrationSecretValidationErrorException`) → `401 UNAUTHORIZED`
- Duplicate machine (throws `DuplicateConnectionException`) → `409 CONFLICT`
- Missing mandatory `hostname` field → `400 VALIDATION_ERROR`
- Verifies service receives correct request payload via `argThat`

**`POST /api/agents/reinstall`**
- Valid headers (`X-Initial-Key`, `X-Machine-Id`, `X-Client-Secret`) → `200 OK`
- Missing any required header → `400 BAD_REQUEST` with descriptive message
- Invalid client secret → (test truncated in source)

## Usage Example

```java
// Typical test pattern used throughout this suite
@Test
void register_WithValidRequest_ReturnsOk() throws Exception {
    when(agentRegistrationService.register(any(), any()))
        .thenReturn(registrationResponse);

    mockMvc.perform(post("/api/agents/register")
            .header("X-Initial-Key", "test-key")
            .contentType(MediaType.APPLICATION_JSON)
            .content(objectMapper.writeValueAsString(registrationRequest)))
        .andExpect(status().isOk())
        .andExpect(jsonPath("$.machineId").value("test-machine-id"));
}
```
