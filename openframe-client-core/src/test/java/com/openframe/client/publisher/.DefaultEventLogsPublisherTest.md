Unit test for `DefaultEventLogsPublisher`, verifying that the publisher correctly delegates event log messages to the `OssTenantRetryingKafkaProducer` with the expected topic, key, payload, and headers.

## Key Components

| Component | Description |
|---|---|
| `publishesToOssTenantProducer()` | Asserts that `publish()` forwards all arguments to the underlying Kafka producer unchanged |
| `OssTenantRetryingKafkaProducer` (mock) | Mocked dependency injected into the publisher under test |
| `DefaultEventLogsPublisher` (SUT) | Subject under test, created via `@InjectMocks` |
| `ReflectionTestUtils.setField` | Injects the `topic` field (`"logs.events"`) that would normally be set by Spring's `@Value` |

## Usage Example

```java
// Mirrors the production call path being tested:
// 1. Construct a KafkaMessage payload
KafkaMessage event = new CommonDebeziumMessage();

// 2. Supply routing headers
Map<String, Object> headers = Map.of(KafkaHeader.MESSAGE_TYPE_HEADER, "RMM");

// 3. Publish — internally delegates to OssTenantRetryingKafkaProducer
publisher.publish("machine-42", event, headers);

// The test verifies this exact delegation:
verify(kafkaProducer).publish("logs.events", "machine-42", event, headers);
```

## Notes

- The `topic` field is populated via `ReflectionTestUtils` to simulate `@Value("${...}")` injection without a full Spring context.
- The machine ID string (`"machine-42"`) is used as the Kafka partition key, ensuring per-machine message ordering.
- See the production implementation at [`DefaultEventLogsPublisher.java`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/client/publisher/DefaultEventLogsPublisher.java).
