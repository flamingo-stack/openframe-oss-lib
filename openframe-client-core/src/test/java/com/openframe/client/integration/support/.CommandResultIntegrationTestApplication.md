Minimal Spring Boot test configuration that wires only the NATS-to-Kafka command result processing path, deliberately omitting auto-configuration to avoid unwanted infrastructure connections (MongoDB, Cassandra, Redis) during integration tests.

## Key Components

| Bean / Class | Role |
|---|---|
| `natsConnection` | Live NATS `Connection` using `nats.spring.server` property; closed on context shutdown |
| `objectMapper` | Standard Jackson `ObjectMapper` |
| `commandResultPublisher` | Mockito mock of `EventLogsPublisher`; replaces Kafka producer so no Kafka broker is required |
| `tenantIdProvider` | Hardcoded lambda returning `"tenant-it"` for test isolation |
| `propertySourcesPlaceholderConfigurer` | Enables `@Value` placeholder resolution |

**Imported beans (via `@Import`):**
- `CommandResultListener` — NATS subscriber under test
- `RmmResultService` — result processing logic
- `RmmResultParser` — parses raw NATS payloads
- `NatsTopicMachineIdExtractor` — extracts machine ID from topic

## Usage Example

```java
@SpringBootTest
@ContextConfiguration(classes = CommandResultIntegrationTestApplication.class)
@TestPropertySource(properties = "nats.spring.server=nats://localhost:4222")
class CommandResultListenerIT {

    @Autowired
    private CommandResultListener listener;

    @MockBean // already mocked in test app, but can be retrieved for verification
    private EventLogsPublisher publisher;

    @Test
    void shouldProcessRmmResult() throws Exception {
        // publish a message to NATS and assert the mock publisher was invoked
        Mockito.verify(publisher, timeout(3000)).publish(any());
    }
}
```

> **Requirements:** A running NATS broker is needed. No Kafka broker is required — the `EventLogsPublisher` boundary is fully mocked.
