End-to-end integration test verifying the full NATS → `CommandResultListener` → `EventLogsPublisher` pipeline, using a real NATS broker via Testcontainers and a mocked publisher to assert on transformed `CommonDebeziumMessage` envelopes.

## Key Components

| Component | Role |
|---|---|
| `NATS` (Testcontainers) | Spins up a live `nats:2.10-alpine` broker with JetStream enabled (`-js`) |
| `@DynamicPropertySource` | Registers the container's dynamic port as `nats.spring.server` before context startup |
| `resetPublisher()` | Resets the mocked `EventLogsPublisher` bean between tests to prevent cross-test bleed |
| `commandResult_consumedTransformedAndForwarded()` | Core happy-path: publishes a `CommandResultMessage`, awaits publisher invocation, then asserts on headers (`MESSAGE_TYPE_HEADER = COMMAND_EXECUTED`) and the `after` payload fields |
| `commandResult_perMachineKey()` | Verifies per-machine Kafka routing — the `machineId` extracted from the subject is used as the publish key |
| `nonCommandResultSubject_isIgnored()` | Uses a sentinel message on the correct subject to prove that a `machine.<id>.heartbeat` message is filtered and never forwarded |

## Usage Example

```java
// Run only when integration.tests system property is set
// e.g., via Maven: mvn verify -Dintegration.tests=true

@Test
void commandResult_consumedTransformedAndForwarded() throws Exception {
    CommandResultMessage payload = CommandResultMessage.builder()
            .executionId("exec-1")
            .machineId("machine-42")
            .stdout("hey\n")
            .exitCode(0)
            .build();

    // Publish to the NATS subject the listener subscribes to
    natsConnection.publish(
        "machine.machine-42.command-execution.result",
        objectMapper.writeValueAsBytes(payload)
    );
    natsConnection.flush(Duration.ofSeconds(2));

    // Assert asynchronously — listener processes off the test thread
    await().atMost(Duration.ofSeconds(5)).untilAsserted(() ->
        verify(eventLogsPublisher).publish(
            eq("machine-42"),
            any(CommonDebeziumMessage.class),
            anyMap()
        )
    );
}
```

> **Activation:** Tests are gated by `@EnabledIfSystemProperty(named = "integration.tests", matches = "true")` and tagged `integration`. Pass `-Dintegration.tests=true` to your test runner to enable them.
