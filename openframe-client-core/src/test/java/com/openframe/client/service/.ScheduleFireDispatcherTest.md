Unit tests for `ScheduleFireDispatcher`, locking the batch dispatch contract: one shared `executionId` per schedule fire, a header `ScheduleScriptExecution` row, per-(script, machine) leaf `ScriptExecution` rows persisted as `RUNNING` before publish, and one batched NATS message per machine.

## Key Components

| Test Method | Description |
|---|---|
| `dispatch_fansOutOneBatchPerMachine` | Full happy-path: 2 scripts × 2 machines → 1 header row, 4 leaf rows, 2 NATS publishes sharing one `executionId` |
| `dispatch_noScriptsOrDevices_isNoOp` | Empty assigned-device list → zero repository or publisher interactions |
| `dispatch_noRunnableScripts_isNoOp` | All script IDs unresolvable → no persistence or publish |
| `dispatch_tokenizesCombinedArgs` | Combined `"-Name value"` default arg strings are split into separate `argv` tokens on the wire |
| `dispatch_toSpecificMachines_bypassesAssignmentLookup` | Overloaded `dispatch(schedule, machineIds, now)` skips `assignedRepository` entirely (device-online path) |

**Mocked dependencies:** `ScriptScheduleMachineAssignedRepository`, `ScriptRepository`, `ScriptExecutionRepository`, `ScheduleScriptExecutionRepository`, `ScriptScheduleExecutionNatsPublisher`

## Usage Example

```java
// Verifying the fan-out shape in the full dispatch path
dispatcher.dispatch(schedule, Instant.now());

// Assert header row
ArgumentCaptor<ScheduleScriptExecution> headerCaptor =
        ArgumentCaptor.forClass(ScheduleScriptExecution.class);
verify(scheduleScriptExecutionRepository).save(headerCaptor.capture());
assertThat(headerCaptor.getValue().getStatus()).isEqualTo(ExecutionStatus.RUNNING);

// Assert leaf rows: 2 scripts x 2 machines = 4 rows, all sharing the header executionId
ArgumentCaptor<List<ScriptExecution>> rowsCaptor =
        ArgumentCaptor.forClass(List.class);
verify(scriptExecutionRepository).saveAll(rowsCaptor.capture());
assertThat(rowsCaptor.getValue()).hasSize(4);
```
