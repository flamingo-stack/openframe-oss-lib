Unit tests for `NatsTopicMachineIdExtractor`, verifying that the second segment of a `machine.<id>.<suffix>` NATS subject is correctly parsed and that malformed inputs are rejected.

## Key Components

| Test | Description |
|---|---|
| `extractsMachineId` | Confirms valid subjects return the correct machine ID regardless of suffix length |
| `rejectsNullOrEmpty` | Ensures `null` or empty strings throw `IllegalArgumentException` |
| `rejectsWrongPrefix` | Rejects subjects not starting with `machine`, expecting an `"Invalid NATS subject"` message |
| `rejectsTooFewParts` | Rejects subjects with fewer than 3 dot-separated segments |
| `rejectsEmptyMachineId` | Rejects subjects where the machine ID segment is blank (e.g., `machine..result`) |

## Usage Example

```java
NatsTopicMachineIdExtractor extractor = new NatsTopicMachineIdExtractor();

// Valid extraction
String machineId = extractor.extract("machine.abc-123.command-execution.result");
// → "abc-123"

// Invalid — throws IllegalArgumentException("Invalid NATS subject")
extractor.extract("device.m1.heartbeat");

// Invalid — throws IllegalArgumentException("Machine ID is empty")
extractor.extract("machine..result");
```

## Notes

- Expected subject format: `machine.<machineId>.<oneOrMoreSuffixSegments>`
- The extractor is used in the command-result routing path; malformed subjects indicate a misconfigured publisher or routing bug.
