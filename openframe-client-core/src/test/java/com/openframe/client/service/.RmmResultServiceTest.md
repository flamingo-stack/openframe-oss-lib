Unit test suite for `RmmResultService`, verifying that RMM command and script execution results are correctly transformed into Debezium-shaped Kafka events and published via `EventLogsPublisher`.

## Key Components

| Component | Role |
|---|---|
| `processResult_commandResult_publishesWithCommandExecutedHeader` | Verifies full envelope shape, `COMMAND_EXECUTED` Kafka header, and all `payload.after` fields for a `CommandResultMessage` |
| `processResult_scriptResult_publishesWithScriptExecutedHeader` | Confirms the runtime subtype discriminator sets the header to `SCRIPT_EXECUTED` for a `ScriptResultMessage` |
| `processResult_scriptResult_carriesScriptAndScheduleIds` | Asserts `scriptId` and `scheduleId` are propagated to `payload.after` for scheduled script results |
| `processResult_commandResult_hasNoScriptOrScheduleIds` | Confirms ad-hoc commands produce no `scriptId` or `scheduleId` fields (absent, not null) |
| `processResult_sparsePayload` | Validates that a minimal payload (only `executionId`) still publishes and omits unset fields from `payload.after` |

## Usage Example

```java
// Typical scenario: processing a command result
CommandResultMessage message = CommandResultMessage.builder()
        .executionId("exec-1")
        .machineId("machine-42")
        .stdout("output\n")
        .exitCode(0)
        .executionTimeMs(12L)
        .timedOut(false)
        .build();

rmmResultService.processResult("machine-42", message);

// Expected: eventLogsPublisher.publish() called with:
// - MACHINE_ID routing key
// - CommonDebeziumMessage with operation="c", positive timestamp
// - Kafka header: MESSAGE_TYPE_HEADER = "COMMAND_EXECUTED"
// - payload.after containing tenantId, machineId, executionId, stdout, exitCode, etc.
```

## Envelope Contract

The tests enforce the following `payload.after` rules:

- **Always present:** `tenantId`, `machineId`, `executionId`, `eventTimestamp`
- **Conditional (CommandResultMessage):** `stdout`, `stderr`, `exitCode`, `executionTimeMs`, `timedOut`
- **Conditional (ScriptResultMessage only):** `scriptId`, `scheduleId`
- **Absent fields:** serialized with `NON_NULL` — missing rather than `null`
