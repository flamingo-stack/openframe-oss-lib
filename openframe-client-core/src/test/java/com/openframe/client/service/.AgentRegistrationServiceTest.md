Unit test suite for `AgentRegistrationService`, validating agent registration and reinstallation workflows including credential generation, machine persistence, tag assignment, and validation ordering.

## Key Components

| Test Method | Purpose |
|---|---|
| `registerAgent_WithNewMachine_ReturnsCredentials` | Verifies full registration flow: ID generation, OAuth client creation, machine persistence, and credential response |
| `registerAgent_WithExistingMachine_ThrowsException` | Ensures duplicate machine IDs throw `IllegalStateException` and no saves occur |
| `registerAgent_WithTags_AssignsTagsToDevice` | Confirms tag assignment is invoked when tags are present in the request |
| `registerAgent_WithoutTags_DoesNotAssignTags` | Confirms `assignTags` is called with `null` when no tags are provided |
| `reinstall_WithValidKeyAndSecret_OverwritesMachineAndReturnsExistingCreds` | Validates reinstall resets machine state, disconnects stale connections, preserves existing credentials, and respects validator ordering |

**Mocked Dependencies:** `OAuthClientRepository`, `MachineRepository`, `AgentRegistrationSecretValidator`, `ClientSecretValidator`, `AgentSecretGenerator`, `MachineIdGenerator`, `OrganizationIdResolver`, `PasswordEncoder`, `RegistrationTagAssignmentService`, `InstalledAgentService`, `ToolConnectionService`, `AgentRegistrationProcessor`

## Usage Example

```java
// Typical new agent registration assertion pattern
when(machineIdGenerator.generate()).thenReturn(MACHINE_ID);
when(oauthClientRepository.existsByMachineId(MACHINE_ID)).thenReturn(false);
when(agentSecretGenerator.generate()).thenReturn(CLIENT_SECRET);

AgentRegistrationResponse response = agentRegistrationService.register(INITIAL_KEY, request);

assertEquals(MACHINE_ID, response.getMachineId());
assertEquals("agent_" + MACHINE_ID, response.getClientId());

// Verify validator ordering on reinstall
InOrder inOrder = inOrder(agentRegistrationSecretValidator, clientSecretValidator);
inOrder.verify(agentRegistrationSecretValidator).validate(INITIAL_KEY);
inOrder.verify(clientSecretValidator).validate(existingClient, CLIENT_SECRET);
```

## Notes

- Reinstall flow resets `DeviceStatus` to `PENDING`, disconnects all tool connections and installed agents via `toolConnectionService.disconnectAll()` and `installedAgentService.disconnectAll()`, then re-runs setup processors.
- `ArgumentCaptor` is used on both `OAuthClient` and `Machine` saves to assert field-level correctness without requiring `equals()` implementations.
