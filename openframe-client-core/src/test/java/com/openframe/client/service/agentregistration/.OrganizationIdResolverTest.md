Unit tests for `OrganizationIdResolver`, verifying organization ID resolution logic across four scenarios: known org lookup, unknown org fallback, blank input shortcut, and missing default org error.

## Key Components

| Method | Scenario Tested |
|---|---|
| `resolve_WithExistingRequestedOrg_ReturnsIt` | Returns the requested org ID when found; skips default lookup |
| `resolve_WithUnknownRequestedOrg_FallsBackToDefault` | Falls back to the default organization when the requested ID is not found |
| `resolve_WithBlank_ReturnsDefaultWithoutLookup` | Skips the org-by-ID lookup entirely for blank/whitespace input |
| `resolve_WhenNoDefaultOrganization_Throws` | Throws `IllegalStateException` when no default organization exists |

**Mocked dependencies:**
- `OrganizationService` — provides `getOrganizationByOrganizationId()` and `getDefaultOrganization()`

**System under test:** `OrganizationIdResolver`

## Usage Example

```java
// Simulates how OrganizationIdResolver behaves at runtime:

// Known org → returned directly
when(organizationService.getOrganizationByOrganizationId("org-1"))
    .thenReturn(Optional.of(organization("org-1")));
assertEquals("org-1", resolver.resolve("org-1"));

// Unknown org → falls back to default
when(organizationService.getOrganizationByOrganizationId("org-x"))
    .thenReturn(Optional.empty());
when(organizationService.getDefaultOrganization())
    .thenReturn(Optional.of(organization("default-uuid")));
assertEquals("default-uuid", resolver.resolve("org-x"));

// Null/blank → skips ID lookup, goes straight to default
when(organizationService.getDefaultOrganization())
    .thenReturn(Optional.of(organization("default-uuid")));
assertEquals("default-uuid", resolver.resolve(null));
```

- Uses `@ExtendWith(MockitoExtension.class)` for lightweight JUnit 5 + Mockito integration
- `verify(..., never())` assertions confirm no unnecessary service calls are made on short-circuit paths
