Unit tests for `CommandResultListener`, verifying NATS message handling including deserialization, machine ID extraction, and error swallowing behavior.

## Key Components

| Component | Description |
|---|---|
| `handleMessage_extractsMachineIdDeserializesAndDelegates` | Verifies snake_case JSON payload is deserialized into `CommandResultMessage` and forwarded to `RmmResultService` with the correct `machineId` |
| `handleMessage_ignoresUnknownFields` | Confirms forward-compatible wire contract — unknown JSON fields do not cause failures |
| `handleMessage_swallowsMalformedPayload` | Ensures malformed (non-JSON) payloads are silently discarded without propagating exceptions to the NATS dispatcher thread |
| `handleMessage_swallowsInvalidSubject` | Ensures subjects missing a valid `machineId` segment are silently discarded |
| `captureSubscribedHandler()` | Helper that triggers `subscribeToCommandResults()` and captures the registered `MessageHandler` via Mockito |
| `message()` | Helper that produces a mocked NATS `Message` with a given subject and UTF-8 payload |

## Usage Example

```java
// Typical flow exercised by the tests:
// 1. Listener subscribes via NATS connection
listener.subscribeToCommandResults();

// 2. NATS delivers a message to the captured handler
String json = "{\"execution_id\":\"exec-1\",\"machine_id\":\"machine-42\","
        + "\"stdout\":\"ok\\n\",\"stderr\":\"\",\"exit_code\":0,"
        + "\"execution_time_ms\":10,\"timed_out\":false}";

// 3. Handler deserializes, extracts machineId from subject, delegates to service
// Subject pattern: machine.{machineId}.command-execution.result
handler.onMessage(message("machine.machine-42.command-execution.result", json));

// 4. Verify downstream delegation
verify(rmmResultService).processResult(eq("machine-42"), any(CommandResultMessage.class));
```

> **Design note:** Real `RmmResultParser` and `NatsTopicMachineIdExtractor` instances are used in setup — only NATS transport and `RmmResultService` are mocked — locking in the actual deserialization contract.
