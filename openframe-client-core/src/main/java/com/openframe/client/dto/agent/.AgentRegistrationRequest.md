Data Transfer Object (DTO) for agent registration requests, carrying device identification, network, hardware, and OS metadata required to register an endpoint with the OpenFrame platform.

## Key Components

| Field | Type | Required | Description |
|---|---|---|---|
| `hostname` | `String` | ✅ | Primary device identifier |
| `organizationId` | `String` | ✅ | Tenant/org scoping for the agent |
| `agentVersion` | `String` | ✅ | Version of the installed agent |
| `osType` | `String` | ✅ | Operating system type (e.g., `Windows`, `macOS`) |
| `ip` | `String` | ❌ | Device IP address |
| `macAddress` | `String` | ❌ | Network adapter MAC address |
| `osUuid` | `String` | ❌ | OS-level unique identifier |
| `status` | `DeviceStatus` | ❌ | Initial device status enum |
| `type` | `DeviceType` | ❌ | Device category enum |
| `tags` | `List<AgentRegistrationTagInput>` | ❌ | Tags to assign at registration time |

## Usage Example

```java
AgentRegistrationRequest request = new AgentRegistrationRequest();

// Required fields
request.setHostname("workstation-042");
request.setOrganizationId("org_abc123");
request.setAgentVersion("2.4.1");
request.setOsType("Windows");

// Optional network/hardware info
request.setIp("192.168.1.42");
request.setMacAddress("AA:BB:CC:DD:EE:FF");
request.setManufacturer("Dell");
request.setModel("Latitude 5520");
request.setOsVersion("11");
request.setOsBuild("22H2");
request.setTimezone("America/New_York");
request.setStatus(DeviceStatus.ONLINE);
request.setType(DeviceType.WORKSTATION);

// Attach registration-time tags
AgentRegistrationTagInput tag = new AgentRegistrationTagInput();
tag.setName("office-nyc");
request.setTags(List.of(tag));
```

> **Validation:** `@NotBlank` constraints on `hostname`, `organizationId`, `agentVersion`, and `osType` are enforced via Bean Validation. The `tags` list uses `@Valid` for cascaded validation of each [`AgentRegistrationTagInput`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/client/dto/agent/AgentRegistrationTagInput.java).
