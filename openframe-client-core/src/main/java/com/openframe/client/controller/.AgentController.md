REST controller handling agent registration and reinstallation endpoints for the OpenFrame client platform.

## Key Components

| Element | Description |
|---|---|
| `@RestController` | Exposes endpoints at `/api/agents` |
| `INITIAL_KEY_HEADER` | `X-Initial-Key` — provisioning token passed in request header |
| `MACHINE_ID_HEADER` | `X-Machine-Id` — unique machine identifier for reinstall flows |
| `CLIENT_SECRET_HEADER` | `X-Client-Secret` — existing agent secret required for reinstallation |
| `AgentRegistrationService` | Injected service delegating registration and reinstall logic |

## Endpoints

| Method | Path | Description |
|---|---|---|
| `POST` | `/api/agents/register` | Registers a new agent using an initial key and request body |
| `POST` | `/api/agents/reinstall` | Reinstalls an existing agent, requiring machine ID and client secret headers |

## Usage Example

**Register a new agent:**

```java
POST /api/agents/register
X-Initial-Key: <provisioning-key>
Content-Type: application/json

{
  "hostname": "desktop-abc123",
  "os": "Windows 11"
}
```

**Reinstall an existing agent:**

```java
POST /api/agents/reinstall
X-Initial-Key: <provisioning-key>
X-Machine-Id: <machine-id>
X-Client-Secret: <existing-secret>
Content-Type: application/json

{
  "hostname": "desktop-abc123",
  "os": "Windows 11"
}
```

Both endpoints accept a `@Valid`-annotated `AgentRegistrationRequest` body and return an `AgentRegistrationResponse`.
