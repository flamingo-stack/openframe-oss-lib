Cron-based scheduler that triggers the RMM script schedule sweep on a half-hour UTC grid (`xx:00` and `xx:30`), delegating all execution logic to `ScriptScheduleExecutionService` while using ShedLock to ensure exactly-once dispatch across multiple replicas.

## Key Components

| Member | Description |
|---|---|
| `run()` | Scheduled entry point; invokes `ScriptScheduleExecutionService.runDueSchedules()` and swallows exceptions to prevent cron disruption |
| `@ConditionalOnProperty` | Disabled by default; requires `openframe.rmm.schedule.runner.enabled=true` |
| `@Scheduled` | Fires on the half-hour grid (`0 0,30 * * * *`, UTC); overridable via `openframe.rmm.schedule.runner.cron` |
| `@SchedulerLock` | Serialises sweep across replicas; lock window configurable via `lock-at-most-for` (default `5m`) and `lock-at-least-for` (default `10s`) |

## Configuration Properties

```text
openframe.rmm.schedule.runner.enabled          = true          # required to activate
openframe.rmm.schedule.runner.cron             = 0 0,30 * * * *  # UTC half-hour grid
openframe.rmm.schedule.runner.lock-at-most-for = 5m
openframe.rmm.schedule.runner.lock-at-least-for= 10s
```

## Usage Example

```java
// application.yml — enable for a specific environment
openframe:
  rmm:
    schedule:
      runner:
        enabled: true
        cron: "0 0,30 * * * *"      # fires at xx:00 and xx:30 UTC
        lock-at-most-for: "5m"
        lock-at-least-for: "10s"
```

The scheduler fires, acquires the ShedLock named `scriptScheduleRunner`, and calls `ScriptScheduleExecutionService.runDueSchedules()`. If the lock is already held by another replica the current pod skips the sweep — preventing duplicate dispatches in a multi-instance deployment.
