Scheduled Spring component that periodically triggers the script execution watchdog, acting as the cron wiring layer for detecting and marking stuck `RUNNING` execution rows as failed.

## Key Components

| Member | Description |
|---|---|
| `watchdogService` | Injected `ScriptExecutionWatchdogService` that contains the core stuck-execution detection logic |
| `sweep()` | Scheduled method that invokes `markStuckExecutionsAsFailing()` at a configurable fixed delay (default: 60s) |

## Configuration Properties

| Property | Default | Description |
|---|---|---|
| `openframe.rmm.execution.watchdog.enabled` | `false` | Must be `true` to activate this component |
| `openframe.rmm.execution.watchdog.interval` | `60000` ms | Fixed delay between sweeps |
| `openframe.rmm.execution.watchdog.grace-seconds` | `120` | Added to each script's `timeoutSeconds` before marking stuck |
| `openframe.rmm.execution.watchdog.threshold-seconds` | `600` | Fallback threshold for executions without a defined timeout |

## Usage Example

Enable and tune the watchdog via `application.properties` or environment-specific config:

```yaml
openframe:
  rmm:
    execution:
      watchdog:
        enabled: true
        interval: 30000         # sweep every 30s
        grace-seconds: 60       # allow 60s buffer past script timeout
        threshold-seconds: 300  # 5-minute hard cutoff for untimed scripts
```

The scheduler then fires automatically — no manual wiring required:

```java
// Triggered automatically by Spring scheduler
@Scheduled(fixedDelayString = "${openframe.rmm.execution.watchdog.interval:60000}")
public void sweep() {
    watchdogService.markStuckExecutionsAsFailing();
}
```

> **Note:** This class contains no business logic. All stuck-detection rules live in [`ScriptExecutionWatchdogService`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/client/service/rmm/ScriptExecutionWatchdogService.java). Disable the scheduler per environment by omitting or setting `enabled=false`.
