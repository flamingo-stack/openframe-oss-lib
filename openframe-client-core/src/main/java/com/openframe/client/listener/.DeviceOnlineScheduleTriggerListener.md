Listens for `DeviceCameOnlineEvent` in-process Spring events and delegates to `DeviceOnlineScheduleTriggerService` to fire the `DEVICE_ONLINE` schedule trigger when a device transitions from offline to online.

## Key Components

- **`onDeviceCameOnline(DeviceCameOnlineEvent event)`** — `@EventListener` method that extracts `tenantId` and `machineId` from the event's `Machine` payload and calls `triggerService.onDeviceOnline(...)`.

## Usage Example

```java
// Published elsewhere in client-service when a device comes online:
applicationEventPublisher.publishEvent(new DeviceCameOnlineEvent(machine));

// DeviceOnlineScheduleTriggerListener picks it up automatically,
// no NATS broker or cross-process hop required:
// triggerService.onDeviceOnline(machine.getTenantId(), machine.getMachineId());
```

> **Note:** This listener replaces a previous NATS-based flow (`client → device.status.online → management`). Since both the trigger and the schedule engine now live in `client-service`, the event is dispatched in-process via Spring's `@EventListener`, eliminating broker latency and network failure modes.
