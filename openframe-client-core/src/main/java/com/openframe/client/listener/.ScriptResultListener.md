Listens for script execution result messages from agents over core NATS and forwards them to `RmmResultService` for processing. Acts as the script-specific counterpart to `CommandResultListener`, sharing the same wire format and result-processing pipeline.

## Key Components

| Member | Type | Description |
|---|---|---|
| `SUBJECT` | Constant | NATS wildcard subject `machine.*.script-execution.result` |
| `subscribeToScriptResults()` | `@EventListener` | Creates a NATS dispatcher and subscribes on `ApplicationReadyEvent` |
| `handleMessage(Message)` | Private | Parses incoming bytes into `ScriptResultMessage`, extracts machine ID, delegates to `RmmResultService` |
| `cleanup()` | `@PreDestroy` | Drains the dispatcher with a 5-second timeout on shutdown |

**Dependencies:**

- `NatsTopicMachineIdExtractor` — parses the machine ID from the wildcard segment of the subject
- `RmmResultParser` — deserializes raw NATS payload into `ScriptResultMessage`
- `RmmResultService` — shared result processor; derives `MessageType.SCRIPT_EXECUTED` from the message subtype

## Usage Example

```java
// ScriptResultListener is auto-registered as a Spring @Component.
// No manual wiring required — subscription starts when ApplicationReadyEvent fires.

// Agent publishes to:
// machine.<machineId>.script-execution.result

// Handled internally:
ScriptResultMessage result = resultParser.parse(data, ScriptResultMessage.class);
rmmResultService.processResult(machineId, result);
```

> **Note:** Error handling in `handleMessage` intentionally logs only subject and payload size — never raw content — to avoid leaking potentially sensitive script output.
