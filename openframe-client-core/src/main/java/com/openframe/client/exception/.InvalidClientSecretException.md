Specialized exception for invalid client secret authentication failures, extending `UnauthorizedException` to signal unauthorized access due to incorrect client credentials.

## Key Components

- **`InvalidClientSecretException`** — Extends `UnauthorizedException`; thrown when a client provides an invalid or mismatched secret during authentication.
- **Constructor** — Accepts an `ErrorCode` and a descriptive `message`, delegating to the parent `UnauthorizedException`.

## Usage Example

```java
if (!clientSecret.equals(storedSecret)) {
    throw new InvalidClientSecretException(
        ErrorCode.INVALID_CLIENT_SECRET,
        "The provided client secret is invalid."
    );
}
```

## Notes

- Inherits HTTP 401 Unauthorized semantics from `UnauthorizedException`.
- Use `ErrorCode` values from `com.openframe.core.exception.ErrorCode` to ensure consistent error classification across the OpenFrame platform.
- Pair with a global exception handler (e.g., `@ControllerAdvice`) to map this exception to a structured API error response.
