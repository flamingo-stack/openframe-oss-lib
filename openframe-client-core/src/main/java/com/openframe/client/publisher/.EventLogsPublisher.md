Defines the contract for publishing command-result events to Kafka, with deployment-specific implementations selected at runtime via Spring's `@ConditionalOnMissingBean` mechanism.

## Key Components

| Element | Description |
|---|---|
| `EventLogsPublisher` | Core interface with a single `publish` method |
| `publish(key, event, headers)` | Sends a `KafkaMessage` to the appropriate Kafka cluster |

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `key` | `String` | Partition/routing key (typically `machineId`) |
| `event` | `KafkaMessage` | The command-result event payload |
| `headers` | `Map<String, Object>` | Kafka headers — must include `message-type` |

### Deployment Strategy

| Deployment | Implementation | Kafka Cluster |
|---|---|---|
| OSS | `DefaultEventLogsPublisher` | oss-tenant Kafka |
| SaaS | saas-client service bean | Shared Kafka |

The SaaS bean, when present, suppresses `DefaultEventLogsPublisher` via `@ConditionalOnMissingBean`, requiring no conditional logic in this interface.

## Usage Example

```java
@Service
public class CommandResultHandler {

    private final EventLogsPublisher publisher;

    public CommandResultHandler(EventLogsPublisher publisher) {
        this.publisher = publisher;
    }

    public void handleResult(String machineId, KafkaMessage result) {
        Map<String, Object> headers = Map.of("message-type", "command-result");
        publisher.publish(machineId, result, headers);
    }
}
```
