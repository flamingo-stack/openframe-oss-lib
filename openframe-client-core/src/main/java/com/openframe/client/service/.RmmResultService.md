Transforms an RMM execution-result message (command or saved script) received from an agent over NATS into a `RmmResultEvent` and publishes it to Kafka as a Debezium-wrapped envelope.

## Key Components

| Member | Description |
|---|---|
| `processResult(String, RmmResultMessage)` | Entry point — resolves message type, builds the Kafka event, and publishes with a `MESSAGE_TYPE` header |
| `resolveMessageType(RmmResultMessage)` | Pattern-matches `CommandResultMessage` → `COMMAND_EXECUTED` or `ScriptResultMessage` → `SCRIPT_EXECUTED` |
| `getRmmResultEvent(...)` | Maps NATS payload fields onto `RmmResultEvent`; conditionally sets `scriptId` / `scheduleId` for script results only |
| `toDebeziumMessage(RmmResultEvent, long)` | Wraps the event in a `CommonDebeziumMessage` with a `create` operation (`"c"`) and epoch-millis timestamp |
| `EventLogsPublisher` | Downstream Kafka publisher injected via constructor |
| `TenantIdProvider` | Resolves the current tenant context at publish time |

## Usage Example

```java
// Injected by Spring — not instantiated directly
@Autowired
private RmmResultService rmmResultService;

// Called from a NATS message handler
CommandResultMessage result = new CommandResultMessage();
result.setExecutionId("exec-001");
result.setStdout("Hello, world!");
result.setExitCode(0);
result.setTimedOut(false);
result.setExecutionTimeMs(342L);

rmmResultService.processResult("machine-abc123", result);
// → publishes to Kafka with header MESSAGE_TYPE=COMMAND_EXECUTED
```

> **Note:** Script-specific fields (`scriptId`, `scheduleId`) are only populated when the message is a `ScriptResultMessage`; they are left `null` for plain command results. Downstream enrichment and persistence are delegated to the stream-service consuming the Kafka topic.
