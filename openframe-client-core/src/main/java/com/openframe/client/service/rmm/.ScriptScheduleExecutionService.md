Orchestrates time-driven execution of RMM `ScriptSchedule` entries — sweeping for all `ACTIVE` schedules that are due and dispatching them via `ScheduleFireDispatcher`, with per-schedule error isolation and cadence advancement.

## Key Components

| Method | Description |
|---|---|
| `runDueSchedules()` | Queries all `ACTIVE` schedules with `nextRunAt <= now`, dispatches each via `ScheduleFireDispatcher`, and advances cadence regardless of dispatch success/failure |
| `advanceAndSave(schedule, now)` | Computes the next fire time and persists the updated schedule |
| `nextRunAfter(currentNextRun, repeatSeconds, now)` | Pure utility — rolls `nextRunAt` forward in whole `repeatSeconds` steps past `now`; returns `null` for one-shot schedules |

## Usage Example

```java
// Typically invoked on a ShedLock-protected scheduler, e.g.:
@Scheduled(fixedDelay = 60_000)
@SchedulerLock(name = "ScriptScheduleExecutionService_runDueSchedules")
public void tick() {
    scriptScheduleExecutionService.runDueSchedules();
}
```

Internally, the service resolves due schedules and processes each independently:

```java
// A broken schedule does NOT block the sweep:
// dispatch failure is logged, cadence is still advanced.
// One-shot schedules (repeatSeconds null/<=0) get nextRunAt = null after firing.
```

## Notes

- **Error isolation**: a dispatch exception on schedule N is logged but does not abort schedules N+1…M, and `nextRunAt` is still advanced to prevent hot-looping.
- **Missed-interval collapse**: `nextRunAfter` rolls forward in whole steps, so a schedule that lagged multiple intervals does not fire repeatedly — it catches up in a single sweep cycle.
- **Tenant safety**: each `ScriptSchedule` carries its own `tenantId`, propagated verbatim to the downstream dispatch path; the sweep query is intentionally tenant-agnostic.
- **ShedLock**: expected to be applied at the call site to serialise sweeps across replicas.
