Manages machine connectivity state transitions by processing online/offline status updates and heartbeats, publishing domain events when devices first connect or return online.

## Key Components

| Member | Description |
|---|---|
| `updateToOnline(String, Instant)` | Marks a machine as `ONLINE` at the given event timestamp |
| `updateToOffline(String, Instant)` | Marks a machine as `OFFLINE` at the given event timestamp |
| `processHeartbeat(String, Instant)` | Treats a heartbeat as an `ONLINE` status update |
| `update(...)` *(private)* | Core update logic: loads the machine, guards against stale events, delegates to `applyStatusUpdate` |
| `applyStatusUpdate(...)` *(private)* | Persists new status and publishes `DeviceFirstConnectedEvent` (PENDING → any) or `DeviceCameOnlineEvent` (OFFLINE → ONLINE) |
| `isEventNewer(...)` *(private)* | Returns `true` if `eventTimestamp` is after `lastSeen`, or if `lastSeen` is null (first event) |
| `logStaleEvent(...)` *(private)* | Warns and discards out-of-order events without mutating state |

## Usage Example

```java
// Injected via Spring — called from an event consumer or webhook handler
@Component
@RequiredArgsConstructor
public class DeviceEventConsumer {

    private final MachineStatusService machineStatusService;

    public void onOnlineEvent(String machineId, Instant timestamp) {
        // Persists ONLINE status and fires DeviceCameOnlineEvent if previously OFFLINE
        machineStatusService.updateToOnline(machineId, timestamp);
    }

    public void onHeartbeat(String machineId, Instant timestamp) {
        // Keeps lastSeen fresh; no duplicate events published
        machineStatusService.processHeartbeat(machineId, timestamp);
    }

    public void onOfflineEvent(String machineId, Instant timestamp) {
        machineStatusService.updateToOffline(machineId, timestamp);
    }
}
```

## Event Publishing Rules

| Transition | Event Published |
|---|---|
| `PENDING` → `ONLINE` or `OFFLINE` | `DeviceFirstConnectedEvent` |
| `OFFLINE` → `ONLINE` | `DeviceCameOnlineEvent` |
| Any other transition | *(none)* |
| Stale timestamp (event older than `lastSeen`) | *(dropped, warn logged)* |
