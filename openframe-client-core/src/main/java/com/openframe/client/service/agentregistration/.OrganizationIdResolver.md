Resolves an organization ID for agent registration by validating a requested ID against the data store and falling back to the default organization when the requested ID is absent or not found.

## Key Components

- **`resolve(String requestedOrganizationId)`** — Public entry point. Returns the requested organization ID if valid and found, otherwise falls back to the default organization ID. Logs a warning when a non-empty ID is provided but not found.
- **`existsRequested(String)`** *(private)* — Guards against blank or non-existent IDs by checking presence in the data store via `OrganizationService`.
- **`getDefaultOrganizationId()`** *(private)* — Fetches the default organization and extracts its ID, throwing `IllegalStateException` if no default exists (e.g., tenant setup incomplete).

## Usage Example

```java
@Component
@RequiredArgsConstructor
public class AgentRegistrationService {

    private final OrganizationIdResolver organizationIdResolver;

    public void registerAgent(AgentRegistrationRequest request) {
        // Resolves to the provided ID if valid, or falls back to default
        String organizationId = organizationIdResolver.resolve(request.getOrganizationId());

        // Proceed with registration using the resolved ID
        processRegistration(organizationId, request);
    }
}
```

## Fallback Behavior

| Scenario | Result |
|---|---|
| Valid, existing organization ID provided | Returns provided ID |
| Non-empty ID provided but not found | Logs warning, returns default |
| Blank or null ID provided | Returns default silently |
| No default organization exists | Throws `IllegalStateException` |
