Transforms a Fleet MDM agent UUID into a numeric host ID by querying the Fleet MDM API, resolving the correct host based on UUID match, osquery version presence, and most recent enrollment timestamp.

## Key Components

| Member | Description |
|---|---|
| `transform(machineId, agentToolId, lastAttempt)` | Core method implementing `ToolAgentIdTransformer`; resolves a Fleet MDM UUID to an integer host ID |
| `getToolType()` | Returns `ToolType.FLEET_MDM` to identify this transformer |
| `validateTenantConfig()` | `@PostConstruct` hook that validates multi-tenancy configuration on startup |
| `processMatchingHost(...)` | Returns the numeric `host.getId()` as a string when a valid match is found |
| `processNoMatchingHost(...)` | On final attempt, falls back to the raw UUID; otherwise throws to trigger a retry |
| `TOOL_ID` | Constant `"fleetmdm-server"` used to look up the integrated tool record |

**Dependencies injected:**
- `IntegratedToolService` — fetches the registered Fleet MDM tool and its credentials
- `ToolUrlService` — resolves the API base URL and port
- `FleetMdmClient` — SDK client used to call `searchHosts`

**Configuration properties:**
- `TENANT_ID` — tenant identifier for multi-tenant Fleet MDM deployments
- `openframe.fleet.multi-tenancy.enabled` — enables tenant header injection

## Usage Example

```java
// Injected automatically by Spring; called during agent registration
@Autowired
private FleetMdmAgentIdTransformer transformer;

// Resolve a Fleet MDM UUID to a numeric host ID
String hostId = transformer.transform(
    "machine-abc123",   // internal machine ID
    "550e8400-e29b-...", // Fleet MDM UUID (agentToolId)
    false               // not the last retry attempt
);
// hostId → "42" (Fleet MDM numeric host ID)
```

**Resolution logic:**
1. Looks up the Fleet MDM tool and API credentials from the database
2. Calls `FleetMdmClient.searchHosts(uuid, 0, 2)` to find candidates
3. Filters for exact UUID match with a non-blank `osqueryVersion`
4. Selects the host with the latest `lastEnrolledAt` timestamp
5. Returns the numeric `id`; on no match, retries or falls back to the raw UUID on the last attempt
