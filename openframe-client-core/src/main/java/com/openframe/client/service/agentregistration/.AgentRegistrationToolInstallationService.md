Handles asynchronous tool installation for newly registered agents by retrieving all enabled integrated tool agents and triggering their installation on a specified machine.

## Key Components

| Element | Description |
|---|---|
| `process(String machineId)` | Async method that fetches all enabled `IntegratedToolAgent` records and dispatches installation for each on the given machine |
| `IntegratedToolAgentService` | Dependency used to retrieve all enabled tool agent configurations |
| `ToolInstallationService` | Dependency that executes the per-agent installation logic against the target machine |
| `@Async(AsyncConfig.TOOL_INSTALL_EXECUTOR)` | Runs on a dedicated thread pool defined in `AsyncConfig` to avoid blocking the registration flow |

## Usage Example

```java
// Triggered during agent registration to install all enabled tools on the new machine
@Service
public class AgentRegistrationService {

    private final AgentRegistrationToolInstallationService toolInstallationService;

    public void onAgentRegistered(String machineId) {
        // Dispatches asynchronously; returns immediately
        toolInstallationService.process(machineId);
    }
}
```

## Notes

- The `process` method is **fire-and-forget** — callers are not blocked and receive no direct result.
- All enabled tool agents are installed on every registration; filtering logic lives within `ToolInstallationService.process`.
