Orchestrates a single scheduled script fire: resolves target machines and runnable scripts, persists execution records, and fans out NATS messages to each assigned device.

## Key Components

| Member | Description |
|---|---|
| `dispatch(ScriptSchedule, Instant)` | Time-driven entry point; resolves all assigned machines then delegates |
| `dispatch(ScriptSchedule, List<String>, Instant)` | Core dispatch logic; used directly by `DEVICE_ONLINE` triggers for a specific machine subset |
| `resolveMachineIds(...)` | Queries `ScriptScheduleMachineAssigned` for distinct, non-null machine IDs assigned to the schedule |
| `resolveRunnableScripts(...)` | Filters script IDs to `ACTIVE`-status scripts only, preserving schedule-defined order |
| `saveHeader(Fire)` | Persists one `ScheduleScriptExecution` snapshot row covering the entire fire attempt |
| `saveLeafRows(Fire)` | Persists one `ScriptExecution` row per `(script, machine)` pair in `RUNNING` state before publishing |
| `publish(Fire)` | Builds `ScriptScheduleExecutionItem` payloads once and fans out one `ScriptScheduleExecutionMessage` per machine over NATS |
| `Fire` (record) | Internal value object bundling schedule, executionId, scripts, machineIds, and timestamp for a single fire |

All records share one `executionId` (random UUID); `scriptId` disambiguates individual leaf rows and result frames.

## Usage Example

```java
// Time-driven path (scheduler calls this)
scheduleFireDispatcher.dispatch(schedule, Instant.now());

// Device-online trigger path (single machine just came online)
scheduleFireDispatcher.dispatch(schedule, List.of(machineId), Instant.now());
```

A fire is a no-op (logged, not thrown) when the schedule has no script IDs, no assigned machines, or all scripts are inactive/missing.
