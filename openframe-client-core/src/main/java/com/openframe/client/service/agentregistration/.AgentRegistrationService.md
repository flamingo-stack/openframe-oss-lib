Handles agent registration and reinstallation for OpenFrame client machines, orchestrating OAuth client creation, machine record persistence, and post-registration processing.

## Key Components

| Member | Type | Description |
|---|---|---|
| `register()` | Method | Registers a new agent: validates the initial key, generates IDs/secrets, creates OAuth client and machine records, then runs post-processing |
| `reinstall()` | Method | Reinstalls an existing agent: validates credentials, updates the machine record, disconnects existing tools/agents, and re-runs post-processing |
| `createOAuthClient()` | Private | Persists a new `OAuthClient` with hashed secret, `AGENT` role, and `client_credentials` grant type |
| `createMachine()` | Private | Creates and persists a `Machine` document with `PENDING` status and `DESKTOP` type |
| `updateMachine()` | Private | Overwrites machine fields and resets status to `PENDING` on reinstall |
| `postProcessMachine()` | Private | Saves installed agent record, assigns tags, triggers tool installation, and invokes the `AgentRegistrationProcessor` |
| `applyRegistrationRequestFields()` | Private | Maps hostname, OS type, agent version, and last-seen timestamp from the request onto a `Machine` |

## Usage Example

```java
// New agent registration
AgentRegistrationRequest request = new AgentRegistrationRequest();
request.setHostname("workstation-01");
request.setOsType("WINDOWS");
request.setAgentVersion("2.1.0");
request.setOrganizationId("org_abc123");

AgentRegistrationResponse response = agentRegistrationService.register(initialKey, request);
// response.getMachineId()    → generated machine UUID
// response.getClientId()     → "agent_<machineId>"
// response.getClientSecret() → generated secret (store securely)

// Reinstall on existing machine
AgentRegistrationResponse reinstallResponse = agentRegistrationService.reinstall(
    initialKey,
    existingMachineId,
    existingClientSecret,
    updatedRequest
);
```

> **Note:** The `clientSecret` returned during `register()` is not stored in plaintext — it is hashed before persistence. Clients must retain it immediately; it cannot be recovered later.
