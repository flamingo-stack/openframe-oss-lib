A Spring `ApplicationEvent` that signals when a device (machine) transitions to an online state, carrying the associated `Machine` document as event payload.

## Key Components

| Element | Description |
|---|---|
| `DeviceCameOnlineEvent` | Extends `ApplicationEvent`; published when a device comes online |
| `machine` | The `Machine` document representing the device that came online |
| `DeviceCameOnlineEvent(Object source, Machine machine)` | Constructor accepting the event source and the associated machine |

## Usage Example

**Publishing the event:**

```java
// Inside a service or component
@Autowired
private ApplicationEventPublisher eventPublisher;

public void handleDeviceOnline(Machine machine) {
    eventPublisher.publishEvent(new DeviceCameOnlineEvent(this, machine));
}
```

**Listening for the event:**

```java
@Component
public class DeviceOnlineListener {

    @EventListener
    public void onDeviceCameOnline(DeviceCameOnlineEvent event) {
        Machine machine = event.getMachine();
        // React to the machine coming online
    }
}
```

## Notes

- Uses Lombok `@Getter` to auto-generate `getMachine()`, avoiding boilerplate.
- Follows standard Spring eventing patterns — publish via `ApplicationEventPublisher`, consume via `@EventListener` or `@TransactionalEventListener`.
- Pairs logically with a `DeviceWentOfflineEvent` counterpart for full online/offline lifecycle tracking.
