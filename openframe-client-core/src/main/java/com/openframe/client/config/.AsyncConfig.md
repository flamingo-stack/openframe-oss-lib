Configures asynchronous execution support for the OpenFrame client, enabling Spring's async processing with a virtual-thread-based executor optimized for tool installation tasks.

## Key Components

| Component | Description |
|---|---|
| `TOOL_INSTALL_EXECUTOR` | Constant (`"toolInstallExecutor"`) used to reference the executor bean by name |
| `toolInstallExecutor()` | Bean providing an `AsyncTaskExecutor` backed by Java virtual threads (Project Loom) |

## Usage Example

Inject the executor by name to run tool installation tasks asynchronously on lightweight virtual threads:

```java
import org.springframework.scheduling.annotation.Async;
import org.springframework.stereotype.Service;

import static com.openframe.client.config.AsyncConfig.TOOL_INSTALL_EXECUTOR;

@Service
public class ToolInstallService {

    @Async(TOOL_INSTALL_EXECUTOR)
    public CompletableFuture<Void> installTool(String toolName) {
        // Runs on a virtual thread — no thread pool exhaustion
        performInstall(toolName);
        return CompletableFuture.completedFuture(null);
    }
}
```

> **Note:** `Executors.newVirtualThreadPerTaskExecutor()` spawns a new virtual thread per task, making it well-suited for I/O-bound installation workflows without requiring manual thread pool sizing.
