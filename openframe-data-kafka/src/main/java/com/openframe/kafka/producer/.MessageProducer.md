Defines the contract for sending Kafka messages in the OpenFrame messaging layer, supporting both async and blocking send patterns with optional header customization.

## Key Components

| Member | Description |
|---|---|
| `sendAsyncMessage` | Non-blocking send; returns a `CompletableFuture` resolving to a `SendResult` |
| `sendAndAwaitMessage` (3-arg) | Blocking send without custom headers |
| `sendAndAwaitMessage` (4-arg) | Blocking send with a `Map<String, Object>` of Kafka message headers |

## Usage Example

```java
@Service
public class OrderService {

    private final MessageProducer messageProducer;

    public void publishOrder(Order order) {
        KafkaMessage message = new KafkaMessage(order);

        // Fire-and-forget (async)
        messageProducer.sendAsyncMessage("orders.topic", message, order.getId())
            .thenAccept(result -> log.info("Sent to partition {}", result.getRecordMetadata().partition()));

        // Blocking send with custom headers
        Map<String, Object> headers = Map.of(
            "correlationId", UUID.randomUUID().toString(),
            "source", "order-service"
        );
        messageProducer.sendAndAwaitMessage("orders.topic", message, order.getId(), headers);
    }
}
```

## Notes

- All methods accept a `specificKey` to control Kafka partition routing.
- `sendAndAwaitMessage` blocks the calling thread until the broker acknowledges the message — avoid on latency-sensitive paths.
- Implementations are registered as Spring beans; inject via `@Autowired` or constructor injection.
