Tenant-scoped Kafka producer that wraps `GenericKafkaProducer` to send `KafkaMessage` payloads to a dedicated OSS tenant Kafka template, supporting both async and blocking delivery modes.

## Key Components

| Member | Description |
|---|---|
| `OssTenantKafkaProducer(KafkaTemplate)` | Constructor accepting a tenant-specific `KafkaTemplate<String, Object>` injected via Spring |
| `sendAsyncMessage(topic, message, key)` | Non-blocking send; returns a `CompletableFuture<SendResult>` for async result handling |
| `sendAndAwaitMessage(destination, message, key)` | Blocking send that waits for broker acknowledgement before returning |
| `sendAndAwaitMessage(destination, message, key, headers)` | Blocking send with additional custom message headers passed as `Map<String, Object>` |

Implements the `MessageProducer` interface and delegates all send operations to the parent `GenericKafkaProducer`.

## Usage Example

```java
// Wire via Spring context or construct directly
KafkaTemplate<String, Object> template = context.getBean("ossTenantKafkaTemplate");
OssTenantKafkaProducer producer = new OssTenantKafkaProducer(template);

KafkaMessage message = new KafkaMessage("payload-data");

// Async send
CompletableFuture<SendResult<String, Object>> future =
    producer.sendAsyncMessage("tenant.events", message, "tenant-123");
future.thenAccept(result -> log.info("Sent to offset {}", result.getRecordMetadata().offset()));

// Blocking send with headers
Map<String, Object> headers = Map.of("x-source", "openframe", "x-tenant", "acme");
producer.sendAndAwaitMessage("tenant.events", message, "tenant-123", headers);
```
