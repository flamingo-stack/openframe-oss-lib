Abstract base class providing Spring Retry-backed Kafka message publishing with automatic exponential backoff and delegated failure recovery.

## Key Components

| Member | Description |
|---|---|
| `publish(topic, key, payload)` | Publishes a `KafkaMessage` with up to 5 attempts; retries on `TransientKafkaSendException`, fails fast on `NonRetryableKafkaException` |
| `publish(topic, key, payload, headers)` | Overload supporting custom Kafka headers with identical retry semantics |
| `recover(...)` | `@Recover` handlers (×4) that delegate exhausted/non-retryable failures to `KafkaRecoveryHandler.enqueue(...)` |
| `producer` | Injected `MessageProducer` used to call `sendAndAwaitMessage` |
| `recoveryHandler` | Injected `KafkaRecoveryHandler` for DLQ, outbox, or notification routing |

**Retry policy** (both `publish` overloads):
- Max attempts: `5`
- Initial delay: `500ms`, multiplier: `2.0×`, max delay: `5000ms`

## Usage Example

```java
@Component
public class OrderEventProducer extends BaseRetryingKafkaProducer {

    public OrderEventProducer(MessageProducer producer,
                               KafkaRecoveryHandler recoveryHandler) {
        super(producer, recoveryHandler);
    }

    public void sendOrderCreated(OrderCreatedEvent event) {
        KafkaMessage message = KafkaMessage.of(event);
        Map<String, Object> headers = Map.of("eventType", "ORDER_CREATED");
        publish("orders.created", event.getOrderId(), message, headers);
    }
}
```

Subclasses only need to wire dependencies and call `publish(...)`. Retry orchestration and failure routing are handled entirely by this base class.
