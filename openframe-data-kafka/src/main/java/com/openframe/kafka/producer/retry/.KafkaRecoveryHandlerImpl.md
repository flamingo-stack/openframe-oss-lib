Fallback implementation of `KafkaRecoveryHandler` that logs structured error details when Kafka message delivery fails after all retry attempts are exhausted.

## Key Components

- **`enqueue(Throwable, String, String, Object)`** — Delegates to the full overload with `null` headers.
- **`enqueue(Throwable, String, String, Object, Map<String, Object>)`** — Logs a structured error summary including topic, key, headers, exception class/message, payload preview, and full stack trace.

## Usage Example

```java
@Service
@RequiredArgsConstructor
public class MyProducer {

    private final KafkaRecoveryHandler recoveryHandler;

    public void send(String topic, String key, MyEvent payload) {
        try {
            kafkaTemplate.send(topic, key, payload).get();
        } catch (Exception ex) {
            // Called automatically by retry exhaustion, or manually:
            recoveryHandler.enqueue(ex, topic, key, payload, Map.of("source", "myProducer"));
        }
    }
}
```

**Sample log output:**

```text
ERROR Kafka RECOVER invoked: topic=device.events key=device-42
      headers={source=myProducer} errorClass=org.apache.kafka.common.errors.TimeoutException
      errorMsg=Topic not present in metadata payload~=MyEvent(deviceId=42, ...)
```

> **Note:** This is a no-op recovery implementation — messages are logged but **not** persisted or re-queued. For production use, replace or extend this class to forward failed messages to a dead-letter topic, a database outbox, or an alerting system. See [`KafkaRecoveryHandler`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/kafka/producer/retry/KafkaRecoveryHandler.java) for the interface contract.
