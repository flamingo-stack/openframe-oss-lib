Abstract base class providing thread-safe, fault-tolerant Kafka message production with automatic error classification, structured logging, and both async and synchronous send variants.

## Key Components

| Member | Description |
|---|---|
| `sendAsync(topic, key, payload)` | Fire-and-forget async send; returns a `CompletableFuture` and logs outcomes via `whenComplete` |
| `sendAsync(topic, key, payload, headers)` | Async send with additional Kafka record headers (e.g. `message-type`) |
| `sendAndAwait(topic, key, payload)` | Blocking send; joins the future and classifies failures as fatal or transient |
| `sendAndAwait(topic, key, payload, headers)` | Blocking send with extra headers |
| `classifyCompletion(ce, topic, key)` | Maps `CompletionException` causes to `NonRetryableKafkaException` or `TransientKafkaSendException` |
| `handleSendFailure(...)` | Pattern-matched async callback logger — never throws |
| `redact(key)` | Truncates message keys in logs to avoid leaking sensitive data |

**Error classification:**

| Exception | Classification |
|---|---|
| `RecordTooLargeException`, `AuthorizationException`, `SerializationException`, `InvalidTopicException` | `NonRetryableKafkaException` (fail fast) |
| `UnknownTopicOrPartitionException` | `TransientKafkaSendException` (broker may be auto-creating topic) |
| All other `RetriableException` | `TransientKafkaSendException` |

## Usage Example

```java
@Component
public class OrderEventProducer extends GenericKafkaProducer {

    private static final String TOPIC = "orders.created";

    public OrderEventProducer(KafkaTemplate<String, Object> kafkaTemplate) {
        super(kafkaTemplate);
    }

    // Fire-and-forget
    public void publishAsync(OrderCreatedEvent event) {
        sendAsync(TOPIC, event.getOrderId(), event);
    }

    // Blocking — safe to wrap with Spring @Retryable
    public void publishSync(OrderCreatedEvent event) {
        sendAndAwait(TOPIC, event.getOrderId(), event);
    }

    // With custom headers
    public void publishWithHeaders(OrderCreatedEvent event) {
        sendAsync(TOPIC, event.getOrderId(), event,
            Map.of("message-type", "order-created", "source", "order-service"));
    }
}
```

> **Subclassing note:** Inject `KafkaTemplate<String, Object>` and delegate directly to the provided send methods. Topic validation, error classification, and key redaction are handled automatically by the base class.
