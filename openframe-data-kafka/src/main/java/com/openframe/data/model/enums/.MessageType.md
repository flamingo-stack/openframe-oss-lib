Defines the `MessageType` enum, which classifies each incoming integration event by its source tool, enrichment pipeline, storage destinations, and handler strategy.

## Key Components

| Enum Constant | Source Tool | Destinations |
|---|---|---|
| `MESHCENTRAL_EVENT` | MeshCentral | Cassandra Event Log, Kafka/Pinot |
| `COMMAND_EXECUTED` | RMM | Cassandra Event Log, Kafka/Pinot, Cassandra Command Result, Mongo Command History |
| `SCRIPT_EXECUTED` | RMM | Cassandra Event Log, Kafka/Pinot, Mongo History |
| `FLEET_MDM_EVENT` | Fleet MDM | Cassandra Event Log, Kafka/Pinot |
| `FLEET_MDM_QUERY_RESULT_EVENT` | Fleet MDM | Cassandra Event Log, Kafka/Pinot |
| `FLEET_MDM_POLICY_ACTIVITY_EVENT` | Fleet MDM | Cassandra Event Log, Kafka/Pinot |
| `FLEET_MDM_POLICY_MEMBERSHIP_EVENT` | Fleet MDM | Cassandra Event Log, Kafka/Pinot |

**Fields (all `@Getter`-exposed):**

- `integratedToolType` — the originating tool (`MESHCENTRAL`, `RMM`, `FLEET`)
- `dataEnrichmentServiceType` — enrichment pipeline to apply before routing
- `destinationList` — ordered list of `Destination` targets for the message
- `eventHandlerType` — handler strategy (currently `COMMON_TYPE` for all)

## Usage Example

```java
MessageType type = MessageType.COMMAND_EXECUTED;

IntegratedToolType tool = type.getIntegratedToolType();
// → RMM

List<Destination> destinations = type.getDestinationList();
// → [CASSANDRA_EVENT_LOG, KAFKA_PINOT, CASSANDRA_COMMAND_RESULT, MONGO_COMMAND_HISTORY]

DataEnrichmentServiceType enrichment = type.getDataEnrichmentServiceType();
// → RMM_RESULTS
```

Use `MessageType` when routing inbound events through the OpenFrame data pipeline to determine which enrichment service processes the message and which storage backends receive it.
