Enum defining the supported data enrichment service types used to categorize sources of enriched data within the OpenFrame data pipeline.

## Key Components

| Value | Description |
|---|---|
| `INTEGRATED_TOOLS_EVENTS` | Represents enrichment data originating from integrated third-party tool events |
| `RMM_RESULTS` | Represents enrichment data sourced from Remote Monitoring and Management (RMM) tool results |

## Usage Example

```java
DataEnrichmentServiceType serviceType = DataEnrichmentServiceType.RMM_RESULTS;

switch (serviceType) {
    case INTEGRATED_TOOLS_EVENTS:
        // handle integrated tools event enrichment
        break;
    case RMM_RESULTS:
        // handle RMM result enrichment
        break;
}
```

## Notes

- Part of the `com.openframe.data.model.enums` package
- Used to distinguish enrichment pipelines when processing incoming data from different service integrations
