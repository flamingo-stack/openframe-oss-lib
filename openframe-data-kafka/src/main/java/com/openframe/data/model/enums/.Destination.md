Defines the routing destinations available for data dispatch within the OpenFrame pipeline, mapping to specific storage backends and messaging systems.

## Key Components

| Variant | Description |
|---|---|
| `KAFKA_PINOT` | Routes data to Apache Kafka for ingestion into Apache Pinot |
| `CASSANDRA_EVENT_LOG` | Writes event log entries to Apache Cassandra |
| `CASSANDRA_COMMAND_RESULT` | Persists command execution results in Apache Cassandra |
| `MONGO_HISTORY` | Stores general history records in MongoDB |
| `MONGO_COMMAND_HISTORY` | Stores command-specific history records in MongoDB |

## Usage Example

```java
import com.openframe.data.model.enums.Destination;

// Route a payload to Kafka/Pinot for real-time analytics
Destination dest = Destination.KAFKA_PINOT;

// Route a command result to Cassandra
Destination dest = Destination.CASSANDRA_COMMAND_RESULT;

// Switch-based dispatch
switch (destination) {
    case KAFKA_PINOT             -> kafkaPinotDispatcher.send(payload);
    case CASSANDRA_EVENT_LOG     -> cassandraWriter.logEvent(payload);
    case CASSANDRA_COMMAND_RESULT -> cassandraWriter.saveResult(payload);
    case MONGO_HISTORY           -> mongoWriter.saveHistory(payload);
    case MONGO_COMMAND_HISTORY   -> mongoWriter.saveCommandHistory(payload);
}
```

## Notes

- Variants follow a `<BACKEND>_<PURPOSE>` naming convention, making the target storage technology and data type immediately clear.
- Extend this enum when adding new storage backends or data categories to the pipeline.
