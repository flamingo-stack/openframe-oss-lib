Defines the enumeration of supported integrated tool types within the OpenFrame platform, mapping each tool to its corresponding database identifier string.

## Key Components

| Member | DB Name | Description |
|---|---|---|
| `RMM` | `"rmm"` | Remote Monitoring and Management tool |
| `MESHCENTRAL` | `"meshcentral"` | MeshCentral open-source remote management |
| `FLEET` | `"fleet-mdm"` | Fleet MDM mobile device management |

**`getDbName()`** — Returns the database-persisted string identifier for the enum constant.

## Usage Example

```java
// Retrieve the DB name for storage or querying
IntegratedToolType tool = IntegratedToolType.MESHCENTRAL;
String dbIdentifier = tool.getDbName(); // "meshcentral"

// Common use case: matching a stored string to an enum value
String storedValue = "fleet-mdm";
IntegratedToolType matched = Arrays.stream(IntegratedToolType.values())
    .filter(t -> t.getDbName().equals(storedValue))
    .findFirst()
    .orElseThrow();
// matched == IntegratedToolType.FLEET
```

> **Note:** The `dbName` field decouples the enum constant name from its persisted representation, allowing safe Java identifier naming (e.g., `FLEET`) while preserving hyphenated DB values like `"fleet-mdm"`.
