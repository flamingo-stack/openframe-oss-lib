Unit tests verifying that `FleetMdmClient` and `FleetMdmSetupClient` correctly attach (or omit) the tenant ID header on outbound HTTP requests, and that `FleetTenantHeader.validate()` enforces multi-tenancy constraints.

## Key Components

| Test Method | Purpose |
|---|---|
| `sendsTenantHeaderWhenTenantIdProvided` | Asserts the tenant header is present when a valid tenant ID is supplied to `FleetMdmClient` |
| `sendsNoTenantHeaderWithoutTenantId` | Asserts no tenant header is sent when the three-arg constructor (no tenant ID) is used |
| `sendsNoTenantHeaderForBlankTenantId` | Asserts a blank/whitespace tenant ID is treated as absent — no header sent |
| `setupClientSendsTenantHeaderWhenTenantIdProvided` | Same tenant header behavior verified on `FleetMdmSetupClient.login()` |
| `setupClientSendsNoTenantHeaderWithoutTenantId` | Asserts `FleetMdmSetupClient` omits the header when tenant ID is `null` |
| `validateRejectsBlankTenantIdWhenMultiTenancyEnabled` | Asserts `FleetTenantHeader.validate()` throws `IllegalStateException` for blank/null IDs when multi-tenancy is enabled, and passes through valid IDs |

**Supporting helper:** `sentRequest()` stubs a 404 response, triggers `getHostById(1)`, and captures the outgoing `HttpRequest` via Mockito `ArgumentCaptor`.

## Usage Example

```java
// Verify tenant header injection in your own FleetMdmClient tests
@Mock HttpClient httpClient;
@Mock HttpResponse<String> httpResponse;

when(httpResponse.statusCode()).thenReturn(404);
when(httpClient.send(any(), any())).thenReturn(httpResponse);

FleetMdmClient client = new FleetMdmClient(
    "https://fleet.example.com", "token", "my-tenant-id", httpClient
);
client.getHostById(1);

ArgumentCaptor<HttpRequest> captor = ArgumentCaptor.forClass(HttpRequest.class);
verify(httpClient).send(captor.capture(), any());
assertEquals(List.of("my-tenant-id"),
    captor.getValue().headers().allValues(FleetMdmClient.TENANT_ID_HEADER));
```
