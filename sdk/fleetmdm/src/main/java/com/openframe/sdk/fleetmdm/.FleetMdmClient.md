A Java HTTP client for interacting with the Fleet MDM REST API, providing methods for host management, osquery execution, and policy/query administration.

## Key Components

| Class / Member | Description |
|---|---|
| `FleetMdmClient` | Main client class wrapping Fleet MDM's REST API |
| `getHostById(long id)` | Fetches a single host by numeric ID |
| `searchHosts(...)` | Overloaded methods to search hosts by query string with optional pagination |
| `runQuery(long hostId, String query)` | Executes an osquery SQL statement on a specific host (blocking) |
| `runQueryAsync(long hostId, String query)` | Non-blocking variant returning `CompletableFuture<QueryResult>` |
| `buildSearchUrl(HostSearchRequest)` | Internal helper constructing the paginated/filtered search URL |
| `MAPPER` | Shared, thread-safe `ObjectMapper` instance reused across all requests |
| `TENANT_ID_HEADER` | Header name `X-Tenant-Id` for multi-tenant routing |

**Exceptions thrown:**

- `FleetMdmApiException` — API-level errors (HTTP 4xx/5xx with status + body)
- `FleetMdmException` — SDK-level processing errors

## Usage Example

```java
// Basic client setup
FleetMdmClient client = new FleetMdmClient(
    "https://fleet.example.com",
    "your-api-token"
);

// Multi-tenant setup
FleetMdmClient tenantClient = new FleetMdmClient(
    "https://fleet.example.com",
    "your-api-token",
    "tenant-123"
);

// Fetch a host by ID
Host host = client.getHostById(42);

// Search hosts with pagination
List<Host> hosts = client.searchHosts("macbook", 0, 25);

// Run a blocking osquery on a host
QueryResult result = client.runQuery(42, "SELECT * FROM users;");

// Run an async osquery
client.runQueryAsync(42, "SELECT * FROM os_version;")
      .thenAccept(r -> System.out.println(r.getRows()));
```

## Notes

- All blocking methods declare `IOException` and `InterruptedException`
- HTTP timeout is **30 seconds** for host/search requests and **90 seconds** for query execution
- `getHostById` returns `null` on 404; `searchHosts` throws `FleetMdmApiException` on non-200 responses
