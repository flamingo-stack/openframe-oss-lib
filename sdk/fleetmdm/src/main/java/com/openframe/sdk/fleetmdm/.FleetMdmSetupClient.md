Handles initial Fleet MDM instance provisioning by exposing setup, login, and admin user creation over HTTP — operations that precede full API authentication.

## Key Components

| Member | Description |
|---|---|
| `FleetMdmSetupClient(String baseUrl)` | Constructor for single-tenant use; no tenant header sent |
| `FleetMdmSetupClient(String baseUrl, String tenantId)` | Constructor for multi-tenant deployments; injects tenant header on every request |
| `setup(SetupRequest)` | Calls `POST /api/v1/setup` to initialize a new Fleet MDM instance |
| `login(LoginRequest)` | Calls `POST /api/v1/fleet/login` and returns a bearer token via `LoginResponse` |
| `createApiOnlyUser(String adminToken, CreateUserRequest)` | Calls `POST /api/v1/fleet/users/admin` with an admin bearer token to create a service account |
| `requireSuccess(HttpResponse, String)` | Throws `FleetMdmApiException` on any non-2xx status, including raw response body |
| `deserialize(String, Class<T>)` | Wraps Jackson deserialization; throws `FleetMdmException` on parse failure |

## Usage Example

```java
// 1. Initialize a new Fleet MDM instance
FleetMdmSetupClient setupClient = new FleetMdmSetupClient("https://fleet.example.com", "tenant-42");

SetupResponse setupResp = setupClient.setup(new SetupRequest("admin@example.com", "s3cur3P@ss"));

// 2. Login to obtain a bearer token
LoginResponse loginResp = setupClient.login(new LoginRequest("admin@example.com", "s3cur3P@ss"));
String adminToken = loginResp.getToken();

// 3. Create an API-only service account for automation
CreateUserRequest userReq = new CreateUserRequest("svc-openframe", "svc@example.com", true);
CreateUserResponse userResp = setupClient.createApiOnlyUser(adminToken, userReq);
```

> **Note:** This client is intended for **bootstrapping only**. Once setup is complete, use [`FleetMdmClient`](https://github.com/flamingo-stack/openframe-oss-lib/blob/main/src/main/java/com/openframe/sdk/fleetmdm/FleetMdmClient.java) for ongoing operations. The underlying `HttpClient` uses a 5-second connect timeout; no retry logic is applied.
