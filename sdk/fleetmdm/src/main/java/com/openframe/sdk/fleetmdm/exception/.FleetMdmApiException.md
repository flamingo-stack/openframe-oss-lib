Represents an HTTP-level API error returned by the Fleet MDM service, extending `FleetMdmException` with the HTTP status code and raw response body from the failed request.

## Key Components

| Member | Type | Description |
|---|---|---|
| `statusCode` | `int` | HTTP status code returned by the Fleet MDM API |
| `responseBody` | `String` | Raw response body from the failed API call |
| `getStatusCode()` | method | Returns the HTTP status code |
| `getResponseBody()` | method | Returns the raw response body string |
| `toString()` | method | Formats exception details including status code and response body |

## Usage Example

```java
try {
    fleetMdmClient.enrollHost(hostPayload);
} catch (FleetMdmApiException e) {
    System.err.println("API call failed with status: " + e.getStatusCode());
    System.err.println("Response body: " + e.getResponseBody());
    // e.g. "FleetMdmApiException(statusCode=404, responseBody={\"error\":\"host not found\"})"
}
```

> **Tip:** Use `getStatusCode()` to branch error-handling logic — for example, retry on `429 Too Many Requests` or surface a user-friendly message on `401 Unauthorized`.
